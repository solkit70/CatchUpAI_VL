## 진행 내용

### 1. 기존 M3 초안 검토

기존 `video-brief.md`는 "AI로 데모는 만들었는데, 왜 서비스는 안 될까?"라는 문제 중심 angle에 맞춰 작성되어 있었다. 그러나 사용자의 최신 피드백에 따라 첫 영상은 특정 문제나 사례 하나가 아니라, 송재희님의 Build with AI 12부작 전체를 소개하고, 사용자의 생각과 실제 경험을 이해 보조 사례로 더하는 통합 소개형 영상이 되어야 한다.

### 2. Working title과 thesis 재작성

Working title을 "도메인 지식이 있다면, AI로 제품을 만들 수 있습니다: Build with AI 쉽게 보기"로 수정했다. Thesis는 도메인 지식이 있는 비개발자도 AI로 제품화에 도전할 수 있지만, AI가 모든 것을 대신하지는 않으므로 문제 정의, 맥락 기록, 데이터 준비, 도구 조합, 검증, 배포와 책임을 이해하며 AI를 리드해야 한다는 방향으로 정리했다.

### 3. Opening Script Starter 작성

Opening script는 다음 순서로 구성했다.

1. AI 시대에 코딩을 몰라도 아이디어를 제품으로 만들 수 있다는 가능성 호출
2. 송재희님의 Build with AI 출처 소개
3. 도메인 지식이 많은 비개발자·시니어 대상임을 명시
4. AI가 모든 것을 대신해 주지는 않으므로 AI를 리드하는 법을 배워야 한다는 핵심 약속 제시

### 4. Explanation Blocks 구성

설명 block은 5개로 제한했다.

1. Build with AI는 무엇인가
2. 도메인 지식이 제품의 씨앗이다
3. AI에게 줄 맥락과 재료를 준비해야 한다
4. 만들 수 있다는 것과 남이 쓰게 하는 것은 다르다
5. AI를 리드하는 비개발자가 되어야 한다

각 block은 Build with AI Part 0-12와 연결되도록 source connection을 기록했다.

## 문제 해결 로그

### 문제: 기존 M3 초안이 M2 수정 방향과 맞지 않음

**증상**: 기존 초안은 데모-서비스 간극과 Builders Lounge bridge 중심으로 되어 있었고, Build with AI 12부작 전체 소개라는 사용자 목적을 충분히 담지 못했다.

**원인**: 기존 초안은 사용자 피드백으로 M2 angle이 통합 소개형으로 재조정되기 전에 작성되었다.

**해결**: `video-brief.md`를 통합 소개형 영상에 맞춰 다시 작성했다. Build with AI 출처 소개, 12부작 큰 그림, 쉬운 설명, 사용자 해석과 경험 예시, 도메인 전문가 대상 메시지를 모두 포함하도록 구성했다.

## Daily Retrospective

### What went well

- M2의 통합 소개형 angle을 실제 영상 brief로 전환했다.
- Build with AI 출처와 송재희님 자료 소개가 영상 초반에 분명히 드러나도록 했다.
- 대상 시청자를 기술 초보자가 아니라 도메인 지식이 풍부한 사람으로 존중하는 톤을 유지했다.

### What could be improved

- M4에서는 12부 전체를 한 영상에 넣을 때 길어지지 않도록 시각 구조를 잘 잡아야 한다.
- 12부 쉬운 설명은 표나 4개 묶음 도식으로 압축하지 않으면 영상이 산만해질 수 있다.

### Insights

- 이 영상의 핵심은 "AI 도구 소개"가 아니라 "도메인 지식을 제품으로 바꾸는 사고의 순서"다.
- 사용자의 경험 사례는 opening hook이 아니라 설명 block 중간중간의 이해 보조 사례로 배치하는 편이 맞다.
- M4의 핵심은 12부를 네 묶음으로 보여주는 큰 지도와, 각 Part를 한 줄로 설명하는 장면을 만드는 것이다.
