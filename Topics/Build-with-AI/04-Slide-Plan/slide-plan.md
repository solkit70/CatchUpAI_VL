## Core Diagram Candidates

### Diagram 1: Build with AI 12부 큰 지도

```mermaid
flowchart LR
  A["사고 전환<br/>Part 0-2"] --> B["재료 준비<br/>Part 3-6"]
  B --> C["만들기 방식<br/>Part 7-9"]
  C --> D["서비스화와 미래<br/>Part 10-12"]
```

**용도**: 12부작을 모두 다루되 시청자가 길을 잃지 않게 하는 메인 지도.

### Diagram 2: 도메인 지식이 AI 제품이 되는 흐름

```mermaid
flowchart LR
  A["도메인 지식"] --> B["기록/context"]
  B --> C["문제 정의"]
  C --> D["AI 브리핑"]
  D --> E["작은 데모"]
  E --> F["검증과 개선"]
  F --> G["제품화 후보"]
```

**용도**: 이 영상의 대상 시청자가 자기 지식을 어떻게 제품화로 옮길지 보여주는 핵심 도식.

### Diagram 3: 내가 쓰는 데모와 남이 쓰는 제품

```mermaid
flowchart LR
  A["내가 쓰는 데모"] --> B["공유/배포"]
  B --> C["다른 사람의 사용 환경"]
  C --> D["오류/비용/데이터"]
  D --> E["검증/책임"]
  E --> F["남도 쓰는 제품"]
```

**용도**: Part 10-11을 비개발자 대상 생활 언어로 설명하는 장면.
