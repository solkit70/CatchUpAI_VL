## Purpose

이 폴더는 Build with AI 12부작 자료를 영상 제작 관점에서 재구성한 Source Map을 보관한다. 원본의 순서를 그대로 옮기는 것이 아니라, Catch Up AI 시청자에게 설명할 핵심 논지와 장면 단위로 바꾸는 것이 목적이다.

## Prerequisite

Source Map을 읽기 전에 먼저 [source-materials.md](source-materials.md)를 확인한다. 이 문서에 Build with AI의 공식 웹사이트, 다운로드 페이지, Topic 안의 로컬 원본 PDF/EPUB/치트시트 위치, 학습 순서가 정리되어 있다.

## Learning Order

1. [source-materials.md](source-materials.md) — Build with AI 설명, 공식 다운로드 정보, `vl_materials/` 원본 파일 위치, 읽기 순서 확인.
2. [reading-notes.md](reading-notes.md) — Build with AI 완전판을 Part 0~12까지 읽고, 각 파트의 핵심 주장과 개인 해석을 정리한 M1 실습1 산출물.
