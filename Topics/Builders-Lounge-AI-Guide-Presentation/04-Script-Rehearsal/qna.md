# 예상 Q&A

## Q1. 무료 기본 가이드에는 정확히 무엇이 포함되나요?

무료 기본 가이드는 처음 시작할 수 있게 만드는 과정입니다. `VS Code + Claude Code / Codex Extension` 기본 세팅, VibeLearn AI 작업 흐름 소개, AI 활용에 도움이 되는 기본 정보, 질문 답변, 그리고 첫 번째 앱 개발이나 사업 진행 방향 잡기까지 포함합니다. 다만 개인별 장기 코칭이나 지속적인 구현 지원은 추가 가이드로 분리합니다.

## Q2. 멤버십에 가입하면 누구나 무료 가이드를 받을 수 있나요?

현재는 최저 레벨인 `Coffee Supporter` 월 $1.99 이상 멤버십 회원에게 월 1회 무료 가이드 기회를 드리는 방식으로 시작하려고 합니다. 한 달에 최대 10명으로 운영해 보고, 실제 수요와 운영 가능성을 보면서 조정하겠습니다.

## Q3. 상위 멤버십 레벨 혜택은 어떻게 되나요?

현재 채널에는 `Seattle AI Insider`, `Catch Up AI Crew`, `Say the Word VIP` 같은 상위 레벨이 있습니다. 다만 아직 상위 레벨별 무료 가이드 횟수나 추가 혜택은 구체적으로 정하지 않았습니다. 실제 상위 레벨 회원이 생기고 수요가 확인되면, 상위 레벨일수록 더 많은 혜택을 드리는 방향으로 설계하겠습니다.

## Q4. 유료 추가 가이드는 얼마인가요?

기본 단위는 2시간입니다. 일반 추가 가이드는 시간당 $100입니다. 가이드 과정을 녹화해서 제 YouTube 콘텐츠로 사용하는 데 동의해 주시면 50% 할인해서 시간당 $50로 진행하려고 합니다.

## Q5. 녹화 할인은 무엇을 의미하나요?

가이드 과정을 녹화하고, 그 내용을 제 YouTube 채널 콘텐츠로 사용할 수 있도록 동의해 주시는 경우 할인하는 방식입니다. 공개가 부담스러운 내용이나 개인정보가 포함되는 경우에는 당연히 조정이 필요합니다. 녹화 공개 동의가 없으면 일반 가격으로 진행합니다.

## Q6. 시니어나 시민단체 실무자에게 왜 이 방식이 적합한가요?

이 방식은 단순히 코딩을 가르치는 것이 아니라, 본인이 하고 싶은 일이나 해결하고 싶은 문제를 AI와 함께 구조화하는 방식입니다. Topic을 만들고, Roadmap을 세우고, WorkLog를 남기면서 실제 산출물을 만들어 가기 때문에 컴퓨터에 익숙하지 않은 분들도 단계적으로 따라올 수 있습니다.

## Q7. 첫 앱 개발까지 무료로 다 만들어 주는 건가요?

무료 기본 가이드는 첫 앱이나 사업의 방향을 잡고 시작할 수 있게 돕는 범위입니다. 완성된 앱을 끝까지 대신 만들어 주는 것은 아닙니다. 어디서 시작할지, 어떤 환경으로 할지, 어떤 순서로 진행할지를 함께 잡는 과정이라고 보시면 됩니다.

## Q8. 지금 바로 신청 링크가 있나요?

Vibe Coding 온보딩 신청 Form은 이미 만들어 두었습니다. 다만 이번 발표에서는 링크보다 주변에 필요한 분을 소개해 달라는 요청을 먼저 드리는 것이 목적입니다. 실제 안내가 필요하면 YouTube 멤버십 링크나 신청 Form을 별도로 공유하겠습니다.
