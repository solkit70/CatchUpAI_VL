# 발표 핵심 메시지와 청중 정의

## 핵심 메시지

> 저는 제가 실제로 쓰고 검증한 `VS Code + Claude Code / Codex Extension + VibeLearn AI` 작업 방식을 바탕으로, 시니어와 시민단체 실무자들이 자기 일에 맞는 AI 활용을 시작할 수 있도록 돕는 가이드 프로그램을 준비하고 있습니다.

이 발표의 중심은 단순한 유튜브 채널 운영 팁이 아니다. “몰락해가는 유튜브 채널 회생 프로젝트”에서 출발했지만, 실제 메시지는 채널 회생을 위해 만든 작업 방식과 Skill들이 다른 사람을 돕는 AI 활용 가이드 프로그램으로 확장되고 있다는 점이다.

## 발표 청중

**직접 청중**은 2026-08-06 Builders Lounge 4차 모임 참석자다. 이들은 Product 소개, 커뮤니티 실험, AI 활용 사례에 관심이 있는 사람들이므로, 발표 톤은 강한 판매보다는 “제가 이렇게 실험했고, 이제 필요한 사람들에게 열어 보려 합니다”가 적합하다.

**간접 청중**은 발표 후 소개받을 수 있는 시니어, 시민단체 실무자, 앱/사업 아이디어가 있는 비개발자다. Builders Lounge 멤버가 직접 대상자가 아닐 수 있어도, 주변에 이런 사람이 있을 가능성이 높기 때문에 마지막 CTA는 “직접 신청하세요”보다 “주변에 필요한 분이 있으면 소개해 주세요”가 자연스럽다.

## 검증 사례

| 사례 | 검증된 점 | 발표에서의 역할 |
|---|---|---|
| 본인 작업 환경 | `VS Code + Claude Code / Codex Extension + VibeLearn AI`가 실제 개인 작업에 유용함 | “제가 직접 쓰는 방식입니다”라는 신뢰 근거 |
| 유타주 이선생님 프로젝트 | 다른 사람에게도 VibeLearn AI 기반 가이드가 유용할 수 있음을 확인 | 시니어/비개발자 대상 가능성 |

## 가이드 대상별 가치

| 대상 | 필요 | 제공 가치 |
|---|---|---|
| 시니어 | AI를 써보고 싶지만 개발 환경과 첫 시작이 어렵다 | 기본 세팅부터 첫 앱 개발까지 함께 진행해 진입 장벽을 낮춘다 |
| 시민단체 실무자 | 행사 기획, 문서 정리, 홍보, 운영 자료가 흩어져 있다 | 실제 업무 자료를 AI와 함께 정리하고 실행 가능한 산출물로 만든다 |
| 앱/사업 아이디어 보유자 | 아이디어는 있지만 구현과 실행 로드맵이 막힌다 | 첫 번째 앱 또는 사업 진행 방향을 VibeLearn AI 방식으로 구조화한다 |

## 무료 기본 가이드 범위

무료로 제공할 범위는 “처음 시작할 수 있게 만드는 것”과 “AI 활용의 기본 방향을 이해할 수 있게 돕는 것”까지다.

- `VS Code + Claude Code / Codex Extension` 기본 세팅
- VibeLearn AI 작업 흐름 소개
- 첫 번째 앱 개발 또는 사업 진행 방향 잡기
- 초기 Topic/Roadmap/WorkLog 구조 만들기
- AI 활용에 도움이 되는 기본 정보 제공
- 질문이 들어오면 그동안 공부하고 실제 프로젝트에서 경험한 내용을 바탕으로 충실히 답변

무료 범위는 개인별 장기 코칭이 아니라 첫 진입 장벽을 낮추고 기본적인 방향 감각을 만들어 주는 과정이다. 다만 단순히 도구 설치만 하고 끝내는 것이 아니라, 참여자가 실제로 궁금해하는 질문에는 본인이 그동안 공부하고 경험한 내용을 바탕으로 성실히 답변한다. 이 경계를 발표에서 분명히 해야 이후 유료 추가 가이드와 혼동이 줄어든다.

## 추가 유료 가이드 구조

기본 과정 이후 개인별 추가 가이드는 유료로 진행한다.

| 구분 | 조건 | 가격/제공 방식 |
|---|---|---|
| YouTube 멤버십 회원 | 현재 최저 레벨 `Coffee Supporter` 월 $1.99 이상 멤버십 가입 | 월 1회 무료 가이드 기회, 월 최대 10명 |
| 일반 추가 가이드 | 멤버십 외 개인 요청 | 시간당 $100, 기본 2시간 |
| 콘텐츠 공개 할인 | 가이드 과정을 녹화해 YouTube 콘텐츠로 사용하는 데 동의 | 50% 할인, 시간당 $50, 기본 2시간 |

현재 확인된 멤버십 레벨은 `Coffee Supporter`($1.99/month), `Seattle AI Insider`($9.99/month), `Catch Up AI Crew`($19.99/month), `Say the Word VIP`($99.99/month)이다. 아직 무료 가이드 혜택은 구체적으로 최저 레벨 이상 회원에게 월 1회 제공하는 수준으로만 정한다. 상위 레벨 회원에게는 더 많은 무료 가이드 횟수나 추가 혜택을 제공하는 방향으로 갈 수 있지만, 구체적인 설계는 실제 상위 레벨 회원이 생긴 뒤 별도로 정한다.

발표에서는 가격표를 길게 설명하지 않는다. 무료 기본 과정으로 문턱을 낮추고, 더 깊은 개인 가이드가 필요하면 멤버십 또는 유료 옵션이 있다는 정도로 짧게 말한다. 멤버십은 $1.99 옵션 하나만 있는 것이 아니라 여러 단계가 있으며, 현재는 최저 레벨 이상 회원에게 월 1회 무료 가이드 혜택을 제공한다는 점만 명확히 한다.

## 발표 순서 원칙

1. 문제: AI 도구는 많지만 자기 일에 붙여 쓰기는 어렵다.
2. 검증: 본인 작업, 유타주 이선생님, Federal Way 한인회 사례로 유용성을 확인 중이다.
3. 방법: `VS Code + Claude Code / Codex Extension + VibeLearn AI` 환경으로 가이드한다.
4. 무료 범위: 세팅, 기본 AI 활용 정보, Q&A, 첫 앱/사업 방향 잡기까지는 무료로 돕는다.
5. 추가 옵션: 개인별 추가 가이드는 멤버십/유료/녹화 할인 구조로 운영한다.
6. CTA: 주변에 필요한 시니어, 시민단체 실무자, 앱/사업 아이디어가 있는 분을 소개해 달라고 요청한다.
