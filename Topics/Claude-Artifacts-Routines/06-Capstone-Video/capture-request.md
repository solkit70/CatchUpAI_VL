## 현재 확보 상태

Topic 전체에서 png·jpg·jpeg 자료를 검색했지만 저장된 화면 캡처는 찾지 못했다. 실습 HTML·실행 기록·공개 문서는 있고, 기록에 과거 캡처를 봤다는 내용도 있으나 원본 파일 위치는 확인되지 않았다. 현재 화면을 새로 캡처할 수 있는 경우와, 재현하면 조건이 바뀔 수 있는 과거 실험을 구분한다.

기획 리뷰에서는 아래 목록을 보고 실제 화면으로 보여 줄 범위를 정한다. 계정의 공유 설정 변경·메일 재발송·루틴 실행·카운터 초기화는 캡처 요청만으로 실행하지 않는다. 옛 상태를 지금 화면인 것처럼 만들어 보여 주지 않으며, 당시 캡처를 찾지 못하면 기록을 재구성한 도식을 사용한다.

## 선택 자료와 촬영 방식

회의 당시 사진은 공개 가능 여부가 확인된 경우에만 S04에 쓴다. 사진이 없어도 사용자 원문과 배치 도식으로 같은 경험을 전달할 수 있으며, 사진을 찾기 위해 내부 행사 문서의 이름·금액·원본 이미지를 외부로 옮기지 않는다.

화면 캡처는 가능하면 원본 해상도의 png로 받고, 각 장면에 필요한 영역을 별도로 잘라 사용한다. 개인 식별 정보는 원본을 제작 폴더에 복사하기 전에 가린다. 공개용 자료만 `06-Capstone-Video/assets/`에 두고, 확보 시 이 문서에 경로·캡처 날짜·실제/기록 재구성 여부를 기록한다. 에셋이 없으므로 빈 assets 폴더는 아직 만들지 않는다.

## AI 시각 자료 후보

Hook의 결과 카드 전환과 학습 기록이 플레이북으로 모이는 장면에는 개념 이미지나 짧은 무음 클립을 선택적으로 쓸 수 있다. 실제 UI·로그·메일은 생성 이미지로 대신하지 않는다. 플랜 승인 후 `image-prompts.md`와 필요할 때 `video-prompts.md`를 만들고, 사용자가 직접 생성할 수 있도록 각 코드블록에 모든 규격을 넣는다.
