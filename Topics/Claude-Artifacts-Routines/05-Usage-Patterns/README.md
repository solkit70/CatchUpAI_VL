# M5 — 사용 패턴 가이드

**모듈**: M5 · **상태**: ✅ 초안 완료 (2026-09-27) — 「다른 사람이 따라 할 수 있는가」 사용자 판단 대기 · **실소요**: 약 25분

M1~M4 에서 직접 겪고 확인한 것만 모아 「이럴 땐 이렇게」 가이드로 묶었다. 근거가 추론뿐인 것은 패턴이 아니라 후보로 남겼다. 정리하다가 M2(9/13)의 「이 계정에서는 댓글 불가」 결론이 M3(9/27) 실측과 어긋난 것을 찾아 정정했다.

## 📚 학습 순서

1. [guides/artifacts-routines-playbook.md](guides/artifacts-routines-playbook.md) — **만들기 전에 여는 한 장** (결정 흐름 · 체크리스트 · 실물 8개) — 먼저 읽기
2. [guides/patterns.md](guides/patterns.md) — 패턴 카드 6장 · 후보 2개 (상황 · 하는 것 · 하지 않는 것 · 실물 · 근거)
3. [guides/anti-patterns.md](guides/anti-patterns.md) — 실제로 겪은 안티패턴 10개 (날짜 · 출처) · 문서로만 확인한 2개

## 이 모듈에서 알아낸 것

- 패턴 6장 모두 실물 링크와 `[실측]` 근거가 붙었다. 「회의 중 즉석 제작」 · 「AI 가 도구를 고르게」는 비교 실측이 없어 후보로 내렸다
- 가장 큰 발견은 정리 과정에서 나왔다 — **문서 한 문장으로 「불가」라고 닫은 기능(댓글)이 실제로는 됐다.** 「안 된다」도 실측으로 닫는다 (안티패턴 10)
