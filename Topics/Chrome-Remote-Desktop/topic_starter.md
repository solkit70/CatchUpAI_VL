- IT 지식이 없는 사람도 혼자 설치하고 안전하게 쓸 수 있는 안내를 만든다

### 비교 대상 — 대안으로 실제 쓸 수 있는 수준까지 (2026-09-20 사용자)

Chrome Remote Desktop 을 고른 이유는 **① 구글이 만들어 믿을 수 있고 ② 무료**여서다.
그러면 나머지도 같은 기준으로 봐야 한다 — **무료이고 안전하면, CRD 에 문제가 생겼을 때
바로 갈아탈 수 있을 만큼** 알아 둔다. 「이름만 아는」 수준이 아니라 설치·접속까지 해 본다.

#### A. 같은 부류 — 내 컴퓨터 화면을 원격으로 조작

| 도구 | 만든 곳 | 비용 | 눈여겨볼 점 |
|---|---|---|---|
| **Chrome Remote Desktop** | Google | 무료 | 지금 쓰는 것. 브라우저만 있으면 되고 공유기 설정이 필요 없다 |
| **RustDesk** | 오픈소스 | 무료 (자체 서버도 가능) | 코드가 공개돼 있고, **중계 서버를 내 것으로** 둘 수 있다 — CRD 대안 1순위 후보 |
| **AnyDesk** | 독일 | 개인 무료 / 상업용 유료 | 빠르다는 평. 과거 계정·중계 관련 보안 사고 이력을 함께 확인 |
| **TeamViewer** | 독일 | 개인 무료 / 상업용 유료 | 가장 널리 쓰이지만 「상업적 사용」 판정으로 차단되는 사례가 많다 |
| **Windows 원격 데스크톱(RDP)** | Microsoft | Windows 기능 | ⚠️ **Home 에디션은 호스트 불가** — 이 집 컴퓨터로는 못 쓴다. 왜 안 되는지 확인 |
| **Parsec** | (Unity) | 개인 무료 | 지연이 가장 낮은 편. 화면 작업·영상 편집에 유리 |
| **Tailscale + VNC/RDP** | Tailscale | 개인 무료 | 「화면 공유」가 아니라 **내 기기들을 한 네트워크로 묶는** 방식. 다른 층위의 해법 |

**확인할 질문** (도구마다 같은 잣대로):
1. 무료 범위가 어디까지인가 — 개인 사용의 경계, 「상업적 사용」 판정 기준
2. 내 화면·파일이 **누구의 서버를 지나는가**, 종단 암호화인가
3. 계정이 털리면 무슨 일이 생기는가 — 2단계 인증, 기기 승인, 접속 기록
4. 만든 곳이 어디인가 — 데이터가 어느 나라 법을 따르는가
5. 내 컴퓨터(Windows 11 Home)에서 **실제로 설치·접속이 되는가**

#### B. 다른 부류 — AI 에게 컴퓨터를 따로 주는 방식

지인이 편하다고 한 **Grok Bot**(xAI)은 위 도구들과 **범주가 다르다.** 내 컴퓨터를 보여 주는 것이
아니라, **AI 가 쓸 컴퓨터를 클라우드에 따로 두는 것**이다.

| 항목 | 공식 문서 기준 (2026-09-20 확인) |
|---|---|
| 무엇인가 | 이름·역할·맥락을 가진 AI 「봇」. 여러 앱·웹을 오가며 여러 단계 작업을 수행 |
| 어디서 도나 | **전용 클라우드 컴퓨터** — 브라우저·파일 시스템·터미널을 갖춤. 봇들이 한 컴퓨터를 공유 |
| 내 PC 를 꺼도 | **계속 돈다.** 노트북을 닫아도 작업이 이어지고 결과만 받아 본다 |
| 원격 데스크톱처럼 | 봇 창을 클릭하면 그 클라우드 컴퓨터를 원격 데스크톱처럼 쓸 수 있다 |
| 어디서 쓰나 | 데스크톱(mac·Win·Linux) · 모바일(iOS·Android) 앱 |
| 비용 | **유료 구독에 포함** — 정확한 요금·플랜 조건은 학습 때 공식 페이지에서 직접 확인 |

→ 공식: https://docs.x.ai/grok-bot/overview · 시작 가이드 https://docs.x.ai/grok-bot/get-started

**왜 비교해야 하나**: 이 Topic 의 둘째 목적(밖에서 AI 작업을 이어 가기)과 **정확히 같은 문제**를
다른 방식으로 푼다. CRD 는 「내 컴퓨터를 원격으로 본다」, Grok Bot 은 「AI 에게 자기 컴퓨터를 준다」.

| | Chrome Remote Desktop | Grok Bot |
|---|---|---|
| 작업이 도는 곳 | **내 집 컴퓨터** | 클라우드 (남의 컴퓨터) |
| 내 컴퓨터를 꺼도 | ❌ 멈춘다 (켜 두고 절전 꺼야 함) | ✅ 계속 |
| 내 파일·프로그램 | 그대로 다 쓴다 (볼트·OBS·Remotion) | 클라우드로 옮기거나 연결해야 |
| 비용 | 무료 | 유료 |
| 내가 쓰는 AI(Claude Code) | 그대로 | 다른 AI(Grok) 생태계 |
| 전기·소음·집 컴퓨터 상태 | 켜 둬야 한다 | 상관없다 |

**확인할 질문**: 내 작업(볼트 편집 · Remotion 렌더 · OBS)이 클라우드 컴퓨터에서 **되는가**,
비용이 얼마이고 무엇까지 포함인가, 그리고 **둘을 같이 쓸 수 있는가**(집 컴퓨터는 CRD 로,
긴 작업은 클라우드로).

## 🎯 두 번째 목적 — 밖에서도 AI 작업을 이어 가기 (2026-09-20 사용자)

> AI 와 같이 일을 하다 보니까 제가 하는 일은 AI 가 한 일을 리뷰하고 승인 여부를 결정하는 것이
> 많더라구요. 이런 일들은 굳이 제가 컴퓨터 앞에 앉아 있을 필요가 없고 리모트로 조정만 가능하면
> 제가 밖에서 활동할 때에도 AI 를 시켜서 일을 계속 할 수 있게 되었습니다.

이 Topic 은 「집 컴퓨터를 원격으로 본다」로 끝나지 않는다. **작업 시간의 구조가 바뀌었기 때문에**
원격 접속이 필요해진 것이다.

| 예전 | 지금 |
|---|---|
| 내가 직접 만든다 → 컴퓨터 앞에 있어야 한다 | **AI 가 만든다 → 나는 보고 정한다** |
| 자리를 비우면 작업이 멈춘다 | 자리를 비워도 **확인·승인만 해 주면 이어진다** |
| 필요한 것: 키보드·큰 화면·긴 시간 | 필요한 것: **결과를 볼 화면 + 「좋다/고쳐라」를 전할 수단** |

그래서 이 Topic 의 실사용 검증은 「화면이 보이나」가 아니라 **「밖에서 AI 작업 한 바퀴가 도나」**로 한다.

- 결과물 확인 (영상 프리뷰 · 문서 diff · 렌더 진행률)
- 승인 또는 수정 지시 (한두 줄 타이핑 · 버튼 클릭)
- 다음 작업 시작시키기
- 이 세 가지를 **폰·태블릿의 작은 화면에서** 할 수 있는가 — 되는 것과 안 되는 것을 갈라 기록한다

이 목적은 영상에도 들어간다. 「외출 중에도 컴퓨터를 쓴다」보다 **「AI 에게 맡긴 일을 밖에서
확인하고 계속 시킨다」**가 이 도구를 지금 쓰는 진짜 이유이기 때문이다.

## 👥 이 Topic 의 독자 · 시청자 (2026-09-20 사용자 확정)

**대상은 모든 사용자다.** 특정 집단을 위한 자료가 아니다.

다만 **기준선은 「IT 지식이 없는 일반인」**에 맞춘다 — 시민단체 실무자와 시니어도 그 안에 포함되고,
집에 컴퓨터 한 대 두고 쓰는 보통 사람 누구나 포함된다. 아는 사람은 빨리 넘기면 되지만,
모르는 사람은 한 줄만 막혀도 멈추기 때문이다.

### 이 기준이 산출물에 적용되는 방식

| 지킬 것 | 어떻게 |
|---|---|
| **용어를 쓰면 그 자리에서 푼다** | 「호스트」→「집에 켜 둘 컴퓨터」 · 「클라이언트」→「밖에서 들고 다니는 기기」 · 「세션」→「접속해 있는 동안」 |
| **누를 곳을 화면으로 보여 준다** | 글로만 설명하지 않는다. 버튼 이름과 위치를 캡처로 (개인 정보는 마스킹) |
| **왜 하는지 한 줄 먼저** | 「PIN 을 6자리 이상으로」가 아니라 「누가 내 컴퓨터를 몰래 켤 수 없게 하려고」 |
| **막히는 자리를 미리 적는다** | 안 될 때 어디를 보는지 — troubleshooting 문서를 모듈마다 둔다 |
| **영상은 따라 하기 속도로** | 한 화면에 한 가지. 설치 단계는 실제 화면 순서 그대로 |
| **읽는 사람을 한정하지 않는다** | 「시민단체 담당자라면」 같은 한정 표현을 쓰지 않는다. 필요하면 「사무실 컴퓨터를 쓰는 경우」처럼 상황으로 쓴다 |

> 📌 선례: DFS Crowd Management 영상(9/18)에서 Codex 초안의 「개장·capacity·시정 판단」을
> 「문을 열어도 되는지, 몇 명까지 받을지, 문제가 고쳐졌는지」로 바꿔 쓴 것과 같은 기준이다.
