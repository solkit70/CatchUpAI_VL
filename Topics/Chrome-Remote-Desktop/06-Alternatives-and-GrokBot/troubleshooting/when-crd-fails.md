## 현재 전제

사용자는 2026-09-27 추가 원격 접속 앱을 설치하지 않기로 결정했다. 따라서 RustDesk는 비교 대상으로만 남고, CRD 장애 때 즉시 전환할 수 있는 두 번째 도구는 없다. 장애를 해결하려고 공유기 설정을 급히 바꾸거나 모르는 사람의 원격 지원 제안을 받지 않는다.

## 확인 순서

1. iPhone의 Wi-Fi 또는 모바일 데이터가 작동하는지 확인한다. 한 회선만 문제라면 다른 회선에서 CRD 접속 페이지를 다시 연다.
2. 집 노트북이 켜져 있고 전원·인터넷에 연결됐는지, 절전 상태는 아닌지 확인한다. 집 밖이라 직접 확인할 수 없으면 집에 있는 사람에게 상태 확인만 요청한다.
3. iPhone의 CRD가 노트북에 등록한 **같은 Google 계정**인지 확인한다. 기기가 보이는데 접속이 안 되면 화면의 오류 문구를 기록하고, PIN을 반복 추측하지 않는다.
4. 집 노트북에 접근할 수 있게 되면 [M2 문제 해결 표](../../02-Install-and-First-Connect/troubleshooting/cannot-connect.md)에 따라 호스트 서비스와 네트워크를 점검한다.
5. 당장 집 노트북 화면을 볼 수 없다면, 휴대폰에서 직접 열 수 있는 문서·서비스로 가능한 작업만 이어가고 원격 Windows 작업은 보류한다. 비밀값이나 개인 파일을 임시 원격 지원 서비스에 넘기지 않는다.

## 대안 설치를 다시 판단할 때

같은 장애가 반복되고 위 순서로 해결되지 않을 때 [비교표](../guides/comparison-table.md)와 [설치 보류 결정](../guides/backup-tool-setup.md)을 다시 읽는다. 설치 여부는 사용자가 그때 CPU·메모리·저장 공간 부담을 포함해 결정한다. 현재 RustDesk 접속 성공 기록은 없으므로 이 문서를 실제 전환 성공 사례로 소개하지 않는다.
