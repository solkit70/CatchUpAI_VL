## 같은 원격이 아니다

CRD와 RustDesk는 **집에 켜 둔 내 컴퓨터의 화면을 다른 기기에서 조작**하는 도구다. 볼트·OBS·설치된 프로그램은 집 컴퓨터에 있고, 집 컴퓨터가 꺼지거나 절전이면 작업도 멈춘다.

Grok Bot은 **AI가 지속형 클라우드 컴퓨터에서 일하는 방식**이다. 공식 문서에 따르면 브라우저·파일 시스템·터미널이 있는 클라우드 컴퓨터에서 봇이 일하므로, 내 노트북을 닫아도 백그라운드 작업은 계속된다. [Grok Bot 개요](https://docs.x.ai/grok-bot/overview)

| 질문            | CRD·RustDesk      | Grok Bot                                                                                                          |
| ------------- | ----------------- | ----------------------------------------------------------------------------------------------------------------- |
| 작업이 도는 곳      | 집 컴퓨터             | 제공사의 클라우드 컴퓨터                                                                                                     |
| 집 컴퓨터를 꺼도 되는가 | 안 된다              | 된다. 단, 집 PC의 로컬 파일·앱을 쓰는 일은 별도다.                                                                                  |
| 내가 하는 일       | 직접 화면을 보고 조작      | 결과를 검토하고 승인·수정 지시                                                                                                 |
| 중요한 주의점       | 계정·PIN·Windows 잠금 | 클라우드 컴퓨터의 파일·브라우저 로그인은 같은 계정의 모든 Bot이 공유한다. [공식 보안 안내](https://docs.x.ai/grok-bot/approvals-security-and-privacy) |

## 핵심 판단

둘 중 하나가 다른 하나를 대체하지 않는다. 집 PC의 OBS·볼트·로컬 파일을 써야 하면 CRD 또는 RustDesk가 필요하다. 여러 단계의 웹 작업을 AI에게 맡기고 밖에서 승인만 하려면 Grok Bot 같은 클라우드 컴퓨터가 더 맞을 수 있다.
