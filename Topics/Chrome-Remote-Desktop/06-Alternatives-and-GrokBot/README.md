## 이 모듈에서 하는 일

Chrome Remote Desktop(CRD)의 대안을 여섯 도구의 동일 기준으로 비교하고, 추가 설치 여부를 내 컴퓨터의 자원과 저장 공간까지 고려해 판단한다. 내 집 컴퓨터 화면을 원격으로 조작하는 방식과 AI가 클라우드 컴퓨터에서 일하는 방식도 Grok Bot과 비교한다. 사용자는 2026-09-27 **RustDesk를 설치하지 않고 비교 분석 문서만 남기기로** 결정했다.

## 현재 상태

2026-09-27 공식 문서 조사와 RustDesk 후보 선정을 마친 뒤, 사용자가 추가 설치를 원치 않는다고 결정했다. Codex가 앞서 설치한 Windows RustDesk는 제거했고 서비스·프로세스·설치 항목이 사라진 것을 확인했다. **RustDesk 원격 접속은 검증하지 않았고 현재 사용 가능한 두 번째 도구가 아니다.** 상대 링크 144개는 정상이며 M6 문서의 첫 독자 검증만 남았다. 사용자 영역의 잔여 파일 약 102MB는 삭제 요청이 자동 승인 검토에서 거부되어 남아 있다. 경로는 [설치 보류 기록](guides/backup-tool-setup.md#설치와-제거-기록)에 적었다.
