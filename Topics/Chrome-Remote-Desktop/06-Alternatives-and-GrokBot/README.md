## 이 모듈에서 하는 일

Chrome Remote Desktop(CRD)가 안 되는 날에도 일을 멈추지 않도록, 무료 대안을 한 가지 실제로 써 본다. 또한 내 집 컴퓨터 화면을 원격으로 조작하는 방식과 AI가 클라우드 컴퓨터에서 일하는 방식을 혼동하지 않도록 Grok Bot과 비교한다.

## 현재 상태

2026-09-27에 공식 문서 조사와 후보 선정을 마쳤다. **RustDesk 설치·iPhone/iPad 접속·문서 저장은 아직 실측하지 않았다.** 방송 후 이 세 가지를 완료해야 M6를 완료로 표시할 수 있다.
