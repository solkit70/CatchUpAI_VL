## 진행 내용

### 활동 1 — 개념 문서 두 편 (40분)

공식 도움말을 먼저 읽고 **문서에 실제로 적힌 것만** 골라 썼다.

**[what-is-remote-access.md](../01-Concepts-and-Choice/concepts/what-is-remote-access.md)**
- 한 줄 정의: 「멀리 있는 컴퓨터의 화면을 내 손 안으로 가져와 마우스·키보드를 대신 움직이는 것」
- **용어를 본문 안에서 풀었다** — 호스트 → 집에 켜 둘 컴퓨터 · 클라이언트 → 밖에서 쓰는 기기 · 세션 → 접속해 있는 동안 · PIN → 두 번째 열쇠
- 핵심 그림: **화면은 밖으로, 손가락은 안으로**
- 오해하기 쉬운 세 가지: ①파일이 내 폰으로 내려오지 않는다 ②내 폰 성능은 상관없다(인터넷은 상관있다) ③끊어도 컴퓨터는 꺼지지 않는다
- ③이 이 Topic 둘째 목적(밖에서 AI 작업 이어 가기)의 토대다 — 세션을 끊어도 집 컴퓨터의 작업은 계속 돈다

**[why-no-router-setup.md](../01-Concepts-and-Choice/concepts/why-no-router-setup.md)**
- 옛날 방식(밖→안, 문을 뚫는다 = 포트포워딩·고정 IP)과 CRD 방식(안→밖, 먼저 나와 기다린다)을 Mermaid 두 장으로 대비
- 비유: 「밖에서 문을 여는 것이 아니라, 집에 있는 사람이 먼저 전화를 걸어 놓고 기다리는 것」
- **결론을 보안으로 연결**: 열쇠가 공유기에서 **구글 계정**으로 옮겨 갔다. 「구글이 만들었으니 안전하다」는 절반만 맞다 — 통로는 암호화돼도 **열쇠를 흘리면 소용없다**

### 활동 2 — 내 구성 그림 (20분)

[my-setup-diagram.md](../01-Concepts-and-Choice/examples/my-setup-diagram.md) — 집(컴퓨터·공유기) / 구글 서버 / 밖(폰·태블릿·노트북)을 Mermaid 로.

가장 쓸모 있는 부분은 **「막히면 어디를 보나」 5지점 표**다.

| 지점 | 증상 | 볼 곳 |
|---|---|---|
| 1 집 컴퓨터 꺼짐·절전 | 「오프라인」 | 전원·절전 설정 |
| 2 집 인터넷 끊김 | 「오프라인」 | 공유기 |
| 3 계정이 다름 | **기기가 아예 안 보임** | 로그인 계정 |
| 4 PIN 틀림 | 보이는데 못 들어감 | PIN |
| 5 내 쪽 회선 느림 | **들어가지는데 느림** | 회선·화면 크기 |

→ **「안 보인다」(1~3)와 「보이는데 느리다」(5)는 원인이 완전히 다르다**는 것을 그림으로 분리한 것이 이 문서의 값어치다.

### 활동 3 — 선택 기준표 (30분)

[choice-criteria.md](../01-Concepts-and-Choice/guides/choice-criteria.md) — 질문 5개를 확정하고 **CRD 열만** 공식 출처와 함께 채웠다.

**Q1** 무료 범위 · **Q2** 누구의 서버를 지나나/암호화 · **Q3** 계정 털리면 · **Q4** 만든 곳·법 · **Q5** Win11 Home 에서 되나

내 우선순위도 적었다: Q5 → Q1 → Q3 → Q2 → Q4. (Q2 는 「구글에 이미 메일·캘린더를 맡기고 있으니 새로 늘어나는 위험은 아니다」로 판단)

빈 칸 6개(RustDesk·AnyDesk·TeamViewer·Windows RDP·Parsec·Tailscale)는 M6 에서 채운다. **Q5 칸에 미리 경고를 박아 뒀다** — Windows RDP 는 Home 에디션에서 호스트 불가.

## Daily Retrospective

### What went well
- 공식 도움말을 먼저 읽고 **거기 적힌 것만** 문서에 넣었다. 「PIN 은 보통 6자리」처럼 그럴듯한 추측을 안 쓴 것이 이 방법론의 핵심이다
- 「공유기 설정이 왜 필요 없나」를 **보안 이야기로 착지시킨 것**이 예상 밖의 수확이다. 원래는 기술 설명 문서였는데, 쓰다 보니 「그래서 열쇠가 어디로 옮겨 갔나」가 나왔고 그게 M3 의 도입부가 됐다
- 「막히면 어디를 보나」 5지점 표는 M2 의 troubleshooting 문서로 바로 이어진다

### What could be improved
- 그림은 Mermaid 로 그렸지만 **실제 화면 캡처가 하나도 없다.** M1 은 개념 모듈이라 괜찮지만, 영상(M7)에 쓸 그림은 결국 캡처가 필요하다 — M2 에서 반드시 남긴다
- 선택 기준표의 「내 우선순위」는 지금 판단이다. M6 에서 실제로 대안을 설치해 보면 바뀔 수 있다 — 그때 **바뀌었으면 바뀐 이유를 적는다**

### Insights

**「무료라서 골랐다」는 이유가 아니라 기준의 한 칸이다.**
CRD 를 고른 이유가 「구글 + 무료」였는데, 그걸 질문 5개로 펼쳐 보니 내가 실제로 중요하게 보는 순서는 **Q5(내 컴퓨터에서 되나) → Q1(무료) → Q3(털리면)** 이었다. 「무료」는 2등이고, 1등은 **아예 되는가**다. 이 순서를 적어 두지 않았으면 M6 에서 「RustDesk 가 더 안전하다더라」 같은 말에 흔들렸을 것이다.

**설명을 쉽게 쓰려니 내가 모르는 곳이 드러났다.**
「공유기 설정이 왜 필요 없나」를 한 문장으로 쓰려다 막혔다. 「NAT 를 우회한다」는 말은 알지만 그건 설명이 아니라 용어 바꾸기다. 「집에서 먼저 나와서 기다린다」까지 가서야 그림이 그려졌다. **IT 지식 없는 사람 기준으로 쓰는 것은 배려가 아니라 내 이해도 점검이다.**

### Tomorrow's focus — M2 (설치와 첫 연결)

1. **집 컴퓨터 앞에서** 호스트 설치 화면을 처음부터 캡처 (방송 때는 캡처를 못 남겼다)
2. 기기 이름을 **개인 정보 없는 이름**으로 정했는지 확인 · PIN 재점검
3. 폰에서 **LTE 로** 접속해 메모장에 글자 입력·저장까지
4. 실습 3 — 일부러 막아 보기(절전·다른 계정·PIN 오입력·인터넷 끊기)로 증상 표 만들기
5. 캡처 7장 이상, **계정 이메일·PIN·기기 이름 마스킹 확인**
