## 영상 기획 v2

**대상**: 원격 데스크톱을 처음 접하는 한국어 사용자. 네트워크·AI 용어는 짧게 풀어 말한다.

**영상 약속**: Chrome Remote Desktop(CRD)으로 집 노트북 화면에 안전하게 접속하고, 연결·작업·종료의 기본 흐름을 익힌다. 실제 검증 결과와 미검증 조건을 따로 밝힌다.

**범위**: CRD의 기본 개념과 선택 이유, 집 Windows 컴퓨터 준비·설치, iPhone Safari 접속, 입력·저장, 잠금·연결 종료·재접속, 간단한 장애 점검. Post & Pour 카페 Wi-Fi에서 문서 읽기·원격 입력·잠금·Disconnect·재접속과 결과 유지를 확인한 실제 사례를 반영한다. 연결 시간 약 5초는 사용자 추정이며, 모든 공용 네트워크의 성능 보장으로 일반화하지 않는다.

**화면 안전 기준**: 실화면 사용 전 계정 이메일, 기기 이름, PIN, 알림, 문서 내용, 브라우저 프로필을 확인하고 가린다. PIN 입력 화면은 재현하거나 촬영하지 않는다. 비밀값을 편집 중 블러 처리하는 것만 믿지 말고, 가능한 경우 테스트 계정·빈 문서·재구성 화면을 쓴다.

### 슬라이드 플랜 원본과 변경 이유

최신 원본은 [M7 슬라이드 플랜 v2](../07-Public-Guide-Video/examples/slide-plan.md)이다. 기존 WorkLog의 15장 요약표를 대체해 18장으로 다시 구성했고, 도구 비교를 줄이는 대신 설치·접속·작업·종료를 실제 화면별로 나눴다. 예상 길이는 시연 여유를 포함해 약 9분 45초다.

- 시작에 카페에서 집 문서가 필요한 상황의 Hook을 둔다.
- 밝은 L1 분위기를 기본으로 하고, 실제 Windows 잠금 화면 등 필요한 원본 부분만 어두울 수 있게 한다.
- 각 장에 핵심·클릭 순서·확인할 결과·내레이션 초안·관련 문서 근거를 붙인다.
- 설명되는 내용의 GitHub 페이지별 QR 목적지를 지정한다. 공개 페이지 확인과 QR 생성·스캔 검수는 남아 있다.
- 기존 설치 캡처를 활용하고, 추가 iPhone·전원·입력·잠금·Disconnect 캡처 요청 목록을 적는다.
- AI 이미지 2개와 Gemini 짧은 영상 2개의 사용자 생성용 프롬프트를 포함한다. 생성 API는 호출하지 않는다.

### 제작 진행 게이트

1. 사용자가 18장 흐름·분량·설명 깊이·내레이션 초안을 검토한다.
2. GitHub 공개 페이지와 캡처를 확인하고, 시각 자료 프롬프트 및 최종 나레이션을 확정한다.
3. Studio에서 시각 미리보기를 확인하고 edge-tts 초벌 → Qwen3-TTS 최종 음성 검토를 진행한다.
4. 자막 사용 시 동기화를 검수하고, 승인된 자료로 최종 렌더링·검수·공개 준비를 한다.

현재는 **슬라이드 플랜 v2 검토 대기**다. 사용자가 정리한 영상 기준을 적용해 플랜과 내레이션 초안을 작성했고, M7 정규 폴더에서 볼 수 있게 했다. 코드·TTS·렌더·공개는 아직 완료되지 않았으며 M7 DoD는 사용자 플랜 승인 전 0/8을 유지한다.

## Daily Retrospective

### 오늘 배운 것
- M1~M6의 학습 내용과 실제 Post & Pour 카페 Wi-Fi 실측을 바탕으로, 초보자가 CRD에 접속하고 작업한 뒤 안전하게 종료·재접속하는 안내 영상의 범위를 정리했다.
- 실제 확인한 동작과 아직 확인하지 않은 조건을 구분하고, 화면 캡처에서 계정·기기·PIN 등 민감정보를 보호하는 기준을 세웠다.

### 잘한 점
- 사용자가 정리한 영상 스타일 기준을 반영해 18장 슬라이드 플랜 v2를 만들고, 장면별 설명·캡처 요청·시각 자료 프롬프트와 근거 링크를 연결했다.
- 플랜과 README·WorkLog의 내부 링크 및 슬라이드 길이를 점검해 다음 검토 단계로 넘길 수 있는 상태를 만들었다.

### 개선할 점
- 플랜 검토와 제작 단계는 아직 진행하지 않았다. 사용자 리뷰와 공개 페이지·QR·실제 화면 확인을 마친 뒤 제작 자료를 확정해야 한다.

### 다음 세션
- 영상 제작을 이어 간다. 먼저 플랜 v2 검토 의견을 반영하고, 승인된 흐름에 따라 공개 링크와 첫 캡처 묶음(C01·C02·C04)을 확인한다.
- M7은 플랜 검토 대기 상태로 유지한다. 사용자가 검토하기 전까지 DoD 완료 항목으로 계산하지 않는다.
