## 준비한 실습

검토 대상은 [M6 대안 비교표의 「이번 선택」](../06-Alternatives-and-GrokBot/guides/comparison-table.md#이번-선택)이다. 사용자는 iPhone CRD에서 이 부분을 읽었고 Pinch 확대 후 문제없이 읽을 수 있었다고 보고했다. 현재 세션에서 내용 승인을 받아 [M5 실습 문서](../05-Remote-AI-Review-Loop/README.md)를 작성했다. 승인 입력 경로와 재접속 후 결과 확인은 아직 받지 않았으며, 노트북에 새 원격 앱을 설치하지 않았다.

**환경 확인**: [M4 실측](20260923_M4_Chrome-Remote-Desktop.md#활동-4--iphone-모바일-데이터-첫-실측)에서 iPhone 모바일 데이터 접속, 한글·영문 입력·저장, Windows 잠금·Disconnect·재접속이 작동했다. 이번 M5에서는 실제 AI 결과 검토·지시·후속 작업을 새로 검증한다. 사용자가 물리적으로 집 밖에 있는지는 확인하지 않았으므로 외출 실측으로 쓰지 않는다.

## iPhone 문서 검토와 내용 승인

이전 세션의 미처리 보고 원문을 [[Journal/2026-09-27#Chrome Remote Desktop iPhone AI 문서 검토 (구술 원문)|Journal 원문]]에 먼저 보존했다. 사용자는 iPhone CRD로 노트북 Obsidian의 비교표를 열고 ‘이번 선택’을 읽었다. 작은 글씨는 Pinch 확대 후 읽을 수 있었으며, 별도의 폰용 원격 앱 추가 설치는 필요하지 않았다.

> 처음에는 글자가 작아서 읽기 힘들었지만 Pinch 로 화면을 확대할 수가 있어서 문제 없이 글을 읽을 수 있었습니다.

[[Journal/2026-09-27#Chrome Remote Desktop 비교 내용 승인 (구술 원문)|승인 원문]]은 다음과 같다. 내용 승인을 수신한 뒤 실제 후속 작업으로 M5 README, 외출 전 체크리스트, 폰 검토 안내서, 한 바퀴 기록, 여덟 동작 표, 입력 문제 해결 문서 여섯 개를 저장했다. 결과 확인 → 내용 판단 → 후속 작업은 진행됐으나, 승인 지시가 원격 노트북 창에서 입력됐는지는 아직 확인하지 못했다.

> 내용 승인 — 다음 실습 진행

**재개 시각**: 사용자 제공 2026-09-27 19:37. 이전 문서 읽기의 정확한 시각과 이번 회선·장소는 미확인이다. 사용량 제한 중 대기 시간을 학습 시간으로 계산하지 않는다.

## DoD 진행

- [ ] 외출 상태에서 확인 → 승인/수정 → 다음 작업 시작 한 바퀴 완료
- [ ] 되는 일/안 되는 일 8항목 이상 기록
- [ ] 외출 전 체크리스트 1장 작성·사용
- [ ] 세션 종료 후 작업 계속 여부 확인
- [ ] README·링크·WorkLog·Retrospective
- [ ] 문서를 처음 보는 사람이 자기 작업에 따라 적용 가능한지 확인

**현재**: 0/6. 문서 읽기·내용 승인·후속 파일 작성은 확인했다. 여덟 동작 표는 미확인 칸이 남고, 체크리스트는 실제 사용 대기다. 외출 여부·원격 지시 입력·Disconnect 뒤 결과 확인·문서 따라 하기·회고를 검증하기 전에는 모듈 완료로 체크하지 않는다.

## 다음 확인

Windows 잠금 → 잠금 화면 확인 → CRD Disconnect → 재접속 뒤, Obsidian에서 `05-Remote-AI-Review-Loop/README.md`를 열어 저장 결과를 확인한다. 원격 노트북의 AI 대화 창에서 짧은 확인 문구를 보내고, 집 밖 여부·회선·입력 경로도 함께 기록한다. 긴 작업이 접속 종료 중 계속 실행됐는지는 문서 저장 유지와 구분해 별도로 실측한다.
