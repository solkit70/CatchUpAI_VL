## 목표와 현재 상태

일반 시청자가 집 Windows 컴퓨터를 준비하고 iPhone에서 접속해 짧은 작업·저장·잠금·연결 종료·재접속까지 따라 할 수 있는 한국어 영상을 만든다. 사용자 스타일 기준을 적용한 18장 슬라이드 플랜을 작성했으며, 현재는 흐름과 설명 수준을 검토하는 단계다.

## 읽는 순서

1. [슬라이드 플랜 v2](examples/slide-plan.md) — Hook·밝은 분위기·실제 화면 중심의 18장 구성, 장면별 내레이션 초안, GitHub QR, 캡처 요청 목록, AI 이미지·영상 프롬프트.
2. [M7 작업 기록](../vl_worklog/20260927_M7_Chrome-Remote-Desktop.md) — 기획 변경 이유와 남은 작업.

## 다음 제작 단계

플랜 검토 뒤 실제 캡처와 GitHub 링크를 확인하고 시각 자료를 준비한다. Studio 미리보기와 초벌·최종 음성을 검토한 다음 렌더링·공개로 진행하며, M7 완료 여부는 로드맵의 DoD로 판단한다.
