## 비교 기준

**왜 같은 표에 모으나**: 집 Wi-Fi에서 잘 되던 작업이 외부 Wi-Fi나 휴대폰 핫스팟에서도 같은 속도·안정성을 보이는지 구분하려는 것이다. M2의 [첫 접속 실측](../../02-Install-and-First-Connect/examples/first-connect-log.md)은 기준선으로 남기고, M4의 외부 세션과 날짜·작업 범위가 달라 엄밀한 속도 비교로 해석하지 않는다.

| 날짜·구분 | 접속 기기 | 접속 회선 | 접속 시간 | 한글 입력·지연 | 끊김 | 확인한 작업 |
|---|---|---|---|---|---|---|
| 9/20 M2 · 집 | iPad | 집 Wi-Fi (+VPN) | 약 2분, 첫 접속 | 한글 입력 성공 · 빠름 | 미기록 | 접속·웹앱 실행 |
| 9/20 M2 · 집 | iPad | 휴대폰 핫스팟 (LTE) | 미기록 | 한글 입력·저장 성공 · 정적 화면에서 빠름 | 미기록 | 메모장 입력·저장 |
| 9/23 M4 · 집 밖 스타벅스 | iPad | 매장 Wi-Fi | 10초 미만 추정 | 한글 입력 지연 크게 느끼지 못함 | 0회 | 문서 편집·내용 유지, 테스트 폴더, OBS·Task Manager 확인 |

## 현재 판단과 다음 측정

이번 iPad·스타벅스 Wi-Fi 조합은 약 20분의 문서·상태 확인 작업에 불편 없이 사용할 수 있었다. 그러나 첫 접속 여부와 작업 범위가 다르므로 집 Wi-Fi의 약 2분과 스타벅스의 10초 미만을 회선 속도의 우열로 해석할 수 없다. 외부에서 다른 회선으로 **같은 작업**을 반복하고 접속 시간을 실제 타이머로 재야 비교가 된다.

로드맵에는 기기 3종 × 회선 2종의 실측이 적혀 있지만 Android 기기는 보유하지 않고 두 번째 컴퓨터 사용 가능 여부도 확인되지 않았다. 불가능한 조합을 채워 넣지 않으며, 사용자와 보유 기기·회선을 정한 뒤 완료 기준을 조정한다.
