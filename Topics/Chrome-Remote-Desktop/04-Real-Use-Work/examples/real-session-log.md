## 실제 작업 한 건 — 2026-09-23

**왜 기록하나**: 집 밖에서도 연결만 되는지와 실제 작업을 끝내는지는 다르다. 사용자 보고 원문은 [[2026-09-23#Chrome Remote Desktop M4 실사용 실습 (구술 원문)|실습 원문]]과 [[2026-09-23#Chrome Remote Desktop M4 외부 접속 결과 보충 (구술 원문)|보충 원문]]에 보존하고, 여기에는 재현 가능한 결과만 적는다.

| 항목 | 실측·보고 결과 |
|---|---|
| 장소 | 집 밖 스타벅스 · 정확한 매장 위치는 기록하지 않음 |
| 기기·회선 | iPad · 매장 Wi-Fi |
| 전체 작업 시간 | 약 20분 |
| 접속 소요 | 10초 미만으로 추정 · 정확한 타이머 측정은 아님 |
| 문서 작업 | 원격으로 편집하고, 이후 내용이 남아 있음을 확인 |
| 다른 작업 | 테스트 폴더 정리 · OBS 실행 및 상태 확인 · Task Manager 열어 확인 |
| 한글 입력·끊김 | 지연이 크게 느껴지지 않음 · 끊김 0회 |
| 종료·복구 | Windows Lock → 잠금 확인 → Disconnect 적용 · 재접속 시 Windows 잠금 화면과 PIN 요구 확인 |
| 사용자 불편 | 보고된 불편 없음 |

## 되는 일 / 안 되는 일 / 아직 시험하지 않은 일

**이번에 된 일**: 외부 Wi-Fi에서 문서를 편집하고 내용 유지를 확인했다. 파일 탐색기로 테스트 폴더를 정리했고 OBS와 Task Manager 화면을 열었다. 안전 종료 순서를 적용한 뒤 재접속도 가능했다.

**이번에 안 된 일**: 사용자가 보고한 실패나 불편은 없었다. 실패가 없었다는 것과 모든 작업이 가능하다는 것은 다르다.

**아직 시험하지 않은 일**: 원격 Task Manager에서 프로세스를 실제로 종료하기, CPU·메모리가 높은 상황에서 복구하기, 장시간 사용·다른 외부 회선의 품질 비교는 이 세션에서 확인되지 않았다. 재접속 때 Windows 잠금 화면과 PIN 요구는 이후 사용자 보고로 확인됐다.
