## M4 — Real-World Use ① Work Away from Home

> Go beyond checking whether a connection works: complete real work away from home and verify the result.

**Status**: 🟡 In progress · **Estimated study time**: 2 hours. On 2026-09-23, the first remote work session lasted about 20 minutes at Starbucks using an iPad and venue Wi-Fi. On 9/27, an iPhone connected over mobile data; Korean and English Notepad input, saved-content persistence, Windows lock, and reconnection were verified. Connection time was estimated at about 2 seconds, with no reported drops. A timed comparison using identical work remains to be done.

## Verified Results So Far

| Item | Result |
|---|---|
| External place, device, connection | Starbucks · iPad · venue Wi-Fi |
| Actual work | Edited a document and confirmed content remained; organized a test folder; opened OBS and checked its status |
| Remote Task Manager | Opened and inspected · ending a process was not tested |
| Connection and input quality | Estimated under 10 seconds to connect · 0 drops · no noticeable Korean input lag |
| Safe exit | Windows Lock → confirmed lock → Disconnect · after reconnect, Windows lock screen and PIN prompt appeared |
| iPhone mobile data | Connected with Wi-Fi off · about 2 seconds estimated · 0 drops · Korean and English Notepad input and saved content confirmed · Windows lock/unlock, Disconnect, and reconnect reported successful |
| Additional iPhone observation | A Windows Command Processor UAC prompt appeared during practice. It coincided with RustDesk installation time, so it was attributed tentatively to that install, not conclusively to CRD input |
