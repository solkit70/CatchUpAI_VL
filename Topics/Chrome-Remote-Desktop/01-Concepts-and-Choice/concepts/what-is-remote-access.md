## 한 줄로

**원격 접속은 멀리 있는 컴퓨터의 화면을 내 손 안으로 가져와, 마우스와 키보드를 대신 움직이는 것이다.**

집에 있는 컴퓨터를 밖에서 그대로 쓴다. 파일을 옮겨 오는 것이 아니라, **그 컴퓨터 앞에 앉아 있는 것과 같은 상태**가 된다.

## 먼저, 말부터 풀어 두자

이 문서와 앞으로 나올 문서에서 계속 쓰는 말이다. 어려운 말이 아니니 한 번만 보고 넘어가면 된다.

| 흔히 쓰는 말 | 이 문서에서는 | 무슨 뜻인가 |
|---|---|---|
| 호스트 (host) | **집에 켜 둘 컴퓨터** | 내가 접속해 들어갈 대상. 켜져 있어야 하고 잠들면 안 된다 |
| 클라이언트 (client) | **밖에서 쓰는 기기** | 폰·태블릿·노트북. 화면을 받아 보고 조작하는 쪽 |
| 세션 (session) | **접속해 있는 동안** | 연결된 시간. 끊어도 집 컴퓨터는 계속 켜져 있다 |
| PIN | **두 번째 열쇠** | 구글 계정과 별개로, 접속할 때 한 번 더 묻는 번호 |
| 원격 지원 | **남에게 내 화면 보여 주기** | 일회성 코드로 다른 사람이 잠깐 들어오게 하는 기능 |

## 무엇이 오가는가

한 가지만 기억하면 된다. **화면은 밖으로, 손가락은 안으로.**

```mermaid
flowchart LR
  A["밖에서 쓰는 기기<br/>(폰·태블릿·노트북)"] -- "마우스·키보드 입력" --> B["집에 켜 둘 컴퓨터"]
  B -- "화면 그림" --> A
```

- 집 컴퓨터가 지금 보여 주고 있는 **화면을 사진처럼 계속 찍어 보낸다**
- 내가 폰에서 손가락으로 누르면 그 위치가 **집 컴퓨터의 마우스 클릭**이 된다
- 그래서 **프로그램은 집 컴퓨터에서 돌고**, 내 폰은 화면만 보여 준다

### 여기서 오해하기 쉬운 것 세 가지

1. **파일이 내 폰으로 내려오지 않는다.**
   원격 화면에서 문서를 열어 고쳐도, 그 파일은 계속 집 컴퓨터에 있다. 폰의 저장 공간을 쓰지 않는다.
2. **내 폰의 성능은 상관없다.**
   영상 편집처럼 무거운 일도 집 컴퓨터가 한다. 폰은 화면을 받아 보기만 하므로 오래된 기기여도 된다.
   대신 **인터넷이 느리면 화면이 늦게 온다.**
3. **끊어도 컴퓨터는 꺼지지 않는다.**
   접속을 종료하는 것은 「보던 것을 그만 본다」이지 「컴퓨터를 끈다」가 아니다.
   돌고 있던 작업은 계속 돈다. (이것이 이 Topic 의 두 번째 목적에서 중요하다)

## 언제 쓰나 — 내 경우

| 상황 | 원격 접속으로 하는 일 |
|---|---|
| 외출했는데 집 컴퓨터에서 뭘 확인해야 할 때 | 문서·사진·설정을 그 자리에서 본다 |
| 긴 작업을 걸어 두고 나왔을 때 | 진행 상황을 보고, 끝났으면 다음 작업을 시작시킨다 |
| **AI 에게 맡긴 일을 확인·승인할 때** | 결과를 보고 「좋다」 또는 「이렇게 고쳐라」만 전하면 작업이 계속 돈다 |
| 방송 장비를 두고 나왔을 때 | OBS 상태·설정을 밖에서 확인한다 |

마지막 두 가지가 이 Topic 을 시작한 이유다. **AI 와 일하는 시간의 상당 부분이 「AI 가 한 일을 보고 승인 여부를 정하는 것」인데, 그 일은 컴퓨터 앞에 앉아 있을 필요가 없다.** 화면만 볼 수 있으면 밖에서도 일이 돈다.

## 무엇이 필요한가

| 필요한 것 | 왜 |
|---|---|
| 집 컴퓨터가 **켜져 있을 것** | 꺼져 있거나 잠들면 들어갈 곳이 없다 (절전 설정은 M3 에서) |
| **인터넷** 양쪽 다 | 집도, 내가 있는 곳도 |
| **같은 구글 계정** 로그인 | 내 컴퓨터를 찾는 기준이 계정이다 |
| **PIN** | 접속할 때 한 번 더 확인 |

공유기 설정을 바꾸거나, 인터넷 회사에 전화하거나, 고정 IP 를 사는 일은 **없다.** 왜 필요 없는지는 다음 문서에서 본다.

## 확인된 사실 (공식 문서 기준, 2026-09-20 확인)

- Chrome Remote Desktop 은 **Mac · Windows · Linux** 컴퓨터와 **모바일 기기**(전용 앱)에서 쓸 수 있다
- 설치는 Chrome 에서 `remotedesktop.google.com/access` 에 들어가 다운로드 버튼을 누르는 것으로 시작한다. 설치 중 **컴퓨터 비밀번호를 물을 수 있다**
- 다른 컴퓨터에 접속할 때 **PIN 을 입력**해야 한다
- **모든 원격 데스크톱 세션은 완전히 암호화된다** (공식 문구)
- 접속 권한을 받은 사람은 **앱·파일·이메일·문서·방문 기록에 모두 접근할 수 있다** — 그래서 아무에게나 열어 주면 안 된다 (M3 보안에서 다룬다)
- 남에게 화면을 보여 주는 「원격 지원」의 **액세스 코드는 한 번만 유효**하고, 공유가 계속되면 **30분마다 계속할지 묻는다**
