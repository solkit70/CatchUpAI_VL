# M1 — What Is Remote Access?

**Module:** M1 · **Difficulty:** ⭐ · **Status:** ✅ Complete (2026-09-20) · **Estimated study time:** 1.5 hours

This module explains **what it means to use a computer at home while you are away**, why it works without router setup, and **what questions to ask when choosing a tool**. Installation is covered in the next module (M2).

> You do not need to be good with computers. Unfamiliar terms are explained where they first appear.

## 📚 Learning sequence

1. [What is remote access?](concepts/what-is-remote-access.en.md)—**What remote access does.** The screen goes out and your touches go in; terms such as host, client, session, and PIN; three common misunderstandings.
2. [Why is no router setup needed?](concepts/why-no-router-setup.en.md)—**Why no router setup is needed.** The home computer connects first and waits instead of opening a door. Why the keys shift to **your Google Account and PIN**.
3. [My setup diagram](examples/my-setup-diagram.en.md)—**How home, Google’s server, and your device connect**, plus five places to check when something fails.
4. [Five tool-selection criteria](guides/choice-criteria.en.md)—**Five questions for choosing a tool.** Start with Chrome Remote Desktop, then compare six other tools using the same table in M6.

## ✅ After this module, you can

- Explain remote access to someone else in under a minute.
- Know **where to start checking** when you cannot connect.
- Ask five useful questions when you encounter a new tool.
- Explain why “Google made it, so it must be safe” is **only half right**.

## 📌 Key facts checked in this module

| Fact | Source |
|---|---|
| All remote desktop sessions are **fully encrypted** | [Official help](https://support.google.com/chrome/answer/1649523?hl=en) |
| Someone granted access can reach **apps, files, email, documents, and browsing history** | Same source |
| A Remote Support **access code works once**; during continued sharing, the service asks every **30 minutes** whether to continue | Same source |
| Available for Windows, Mac, and Linux computers, and mobile apps | Same source |
