# M1 — 원격 접속이란 무엇인가

**모듈 번호**: M1 · **난이도**: ⭐ · **상태**: ✅ 완료 (2026-09-20) · **예상 학습 시간**: 1.5시간

집에 있는 컴퓨터를 밖에서 쓴다는 것이 **무엇을 하는 일인지**, 왜 공유기 설정 없이 되는지, 그리고 **도구를 고를 때 무엇을 물어야 하는지**를 정리한다. 설치는 다음 모듈(M2)에서 한다.

> 컴퓨터를 잘 모르셔도 괜찮습니다. 어려운 말은 나올 때마다 그 자리에서 풀어 썼습니다.

## 📚 학습 순서

1. [concepts/what-is-remote-access.md](concepts/what-is-remote-access.md) — **원격 접속이 무엇인가.** 화면은 밖으로, 손가락은 안으로. 용어 풀이(호스트·클라이언트·세션·PIN)와 오해하기 쉬운 세 가지
2. [concepts/why-no-router-setup.md](concepts/why-no-router-setup.md) — **공유기 설정이 왜 필요 없나.** 문을 뚫는 것이 아니라 집에서 먼저 나와 기다린다. 그래서 열쇠가 **구글 계정과 PIN** 으로 옮겨 간 이유
3. [examples/my-setup-diagram.md](examples/my-setup-diagram.md) — **내 구성 그림.** 집·구글 서버·내 기기가 어떻게 이어지는지, **막히면 어디를 보는지 5지점**
4. [guides/choice-criteria.md](guides/choice-criteria.md) — **도구 선택 기준 5가지.** 지금 쓰는 Chrome Remote Desktop 을 먼저 채우고, 나머지 6개 도구는 M6 에서 같은 표에 채운다

## ✅ 이 모듈을 마치면

- 원격 접속을 다른 사람에게 1분 안에 설명할 수 있다
- 연결이 안 될 때 **어디부터 볼지** 순서를 안다
- 새 도구를 만났을 때 물어볼 질문 5개를 갖고 있다
- 「구글이 만들었으니 안전하다」가 왜 **절반만 맞는지** 안다

## 📌 이 모듈에서 확인한 핵심 사실

| 사실 | 출처 |
|---|---|
| 모든 원격 데스크톱 세션은 **완전히 암호화**된다 | [공식 도움말](https://support.google.com/chrome/answer/1649523?hl=ko) |
| 접속 권한을 받은 사람은 **앱·파일·이메일·문서·방문 기록에 모두 접근**할 수 있다 | 〃 |
| 원격 지원의 **액세스 코드는 한 번만 유효**, 공유 중에는 **30분마다 계속할지 묻는다** | 〃 |
| Windows·Mac·Linux 컴퓨터와 모바일 앱에서 사용 가능 | 〃 |
