## 왜 기준을 먼저 만드나

지금 Chrome Remote Desktop 을 쓰는 이유는 단순하다 — **구글이 만들어 믿을 수 있고, 무료여서**다. 좋은 이유지만, 그것만으로는 **다른 도구를 만났을 때 비교할 수가 없다.**

그래서 **질문 5개**를 먼저 정해 둔다. 이 질문은 도구가 바뀌어도, 몇 년 뒤에 새 도구가 나와도 그대로 쓸 수 있다. M6 에서 RustDesk·AnyDesk·TeamViewer·Windows 원격 데스크톱·Parsec·Tailscale 을 같은 표에 채워 넣을 것이다.

## 질문 5개

| # | 질문 | 왜 묻나 |
|---|---|---|
| **Q1** | **무료는 어디까지인가?** | 「무료」라고 해 놓고 어느 선을 넘으면 막히는 도구가 많다. 특히 「업무용으로 쓰는 것 같다」고 판정되면 갑자기 끊기기도 한다 |
| **Q2** | **내 화면이 누구의 서버를 지나는가?** | 집 컴퓨터 화면에는 내 문서·메일이 다 보인다. 그 그림이 어느 회사 서버를 거치는지, 암호화돼 있는지 |
| **Q3** | **계정이 털리면 무슨 일이 생기는가?** | 열쇠를 잃었을 때 얼마나 나쁜가. 2단계 인증이 되는가, 접속 기록을 볼 수 있는가 |
| **Q4** | **누가 만들었고 어느 나라 법을 따르는가?** | 문제가 생겼을 때 누구에게 묻나. 데이터가 어느 나라에 저장되나 |
| **Q5** | **내 컴퓨터(Windows 11 Home)에서 실제로 되는가?** | 되는 줄 알았는데 Home 에디션이라 안 되는 경우가 있다 (Windows 원격 데스크톱이 그렇다) |

## 기준표

> ✅ = 확인함 · ⬜ = M6 에서 채운다

| 기준 | **Chrome Remote Desktop** ✅ | RustDesk ⬜ | AnyDesk ⬜ | TeamViewer ⬜ | Windows 원격 데스크톱 ⬜ | Parsec ⬜ | Tailscale+VNC ⬜ |
|---|---|---|---|---|---|---|---|

| **Q2 지나는 서버 / 암호화** | 구글 서버를 거쳐 연결. **「모든 원격 데스크톱 세션은 완전히 암호화됩니다」**(공식) | | | | | | |
| **Q3 계정이 털리면** | 심각. 권한을 받은 사람은 **앱·파일·이메일·문서·방문 기록에 모두 접근**(공식). 구글 계정 2단계 인증 + **PIN** 2중 | | | | | | |
| **Q4 만든 곳 / 법** | Google (미국) | | | | | | |
| **Q5 Win11 Home 에서** | ✅ 된다 (Windows·Mac·Linux 지원) | | | | | | ⚠️ 이 칸이 핵심 — Home 은 RDP **호스트 불가** |

### Chrome Remote Desktop — 확인한 사실 (2026-09-20)

- **지원 기기**: Mac · Windows · Linux 컴퓨터, 그리고 모바일 기기(전용 앱). Linux 는 64비트 Debian 패키지
- **설치**: Chrome 에서 `remotedesktop.google.com/access` → 다운로드. 설치 중 **컴퓨터 비밀번호를 물을 수 있고**, 환경설정에서 보안 설정 변경을 요청받을 수 있다
- **접속**: 다른 컴퓨터에 들어갈 때 **PIN 입력**. (PIN 길이·규칙은 공식 문서에 명시돼 있지 않다 — 그래서 우리가 스스로 6자리 이상·추측 불가로 정한다. M3)
- **암호화**: 「모든 원격 데스크톱 세션은 완전히 암호화됩니다」
- **권한의 범위**: 접속 권한을 받은 사람은 **앱·파일·이메일·문서·방문 기록에 모두 접근**할 수 있다
- **남에게 보여 주기(원격 지원)**: `remotedesktop.google.com/support` 에서 코드 생성 → 상대가 입력 → **이메일 주소가 표시되고 승인**. **코드는 한 번만 유효**하고, 공유가 계속되면 **30분마다 계속할지 묻는다**

출처: [Chrome 원격 데스크톱 도움말](https://support.google.com/chrome/answer/1649523?hl=ko) · [접속 페이지](https://remotedesktop.google.com/access)

## 이 표를 읽는 법

**모든 칸이 ✅ 인 도구는 없다.** 그래서 「가장 좋은 것」이 아니라 **「내 경우에 맞는 것」**을 고르는 것이다.

내 기준에서는 이렇다:

| 나에게 중요한 순서 | 이유 |
|---|---|
| 1. Q5 — 내 컴퓨터에서 되는가 | 안 되면 나머지는 볼 필요도 없다 |
| 2. Q1 — 무료인가 | 도구 하나에 돈을 더 쓰고 싶지 않다 |
| 3. Q3 — 털렸을 때 얼마나 나쁜가 | 집 컴퓨터에는 볼트·작업 파일이 다 있다 |
| 4. Q2 — 어느 서버를 지나는가 | 구글은 이미 메일·캘린더를 맡기고 있으니 새로 늘어나는 위험은 아니다 |
| 5. Q4 — 만든 곳 | 참고 사항 |

> 📌 **M6 에서 할 일**: 빈 칸 6개를 같은 방식으로 채우고, 그중 **무료이면서 Q3 가 괜찮은 도구 하나를 실제로 설치**한다. Chrome Remote Desktop 에 문제가 생긴 날 바로 갈아탈 수 있는 「두 번째 카드」를 만들어 두는 것이 목적이다.

## 표를 채울 때 지킬 것

1. **공식 문서에서 확인한 것만 쓴다.** 블로그·유튜브에서 본 것은 「확인 필요」로 표시
2. **각 칸에 출처 URL 을 붙인다** — 1년 뒤에 정책이 바뀌면 다시 확인해야 한다
3. **확인 날짜를 적는다** — 요금제와 무료 범위는 자주 바뀐다
4. 모르면 **비워 둔다.** 짐작해서 채우면 나중에 그것을 사실로 믿게 된다
