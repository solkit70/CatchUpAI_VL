## 여덟 동작의 현재 확인 범위

○는 이번 M5에서 확인한 동작, △는 조건이나 검증 범위에 제약이 있는 동작이다. 미확인은 실패를 뜻하지 않는다. 실제로 시도하지 않은 동작에 ✗를 붙이지 않으며, 이번 결과를 집 밖의 모든 환경에 일반화하지 않는다.

| 동작 | 현재 판정 | 근거·다음 확인 |
|---|---|---|
| 문서 읽기 | ○ | iPhone CRD로 Obsidian 비교표를 읽음 |
| 작은 글씨 확대 | ○ | Pinch로 확대 후 문제 없이 읽음 |
| 짧은 승인 지시 | △ | 내용 승인 수신, 원격 노트북 창에서 입력했는지는 미확인 |
| 긴 수정 지시 | 미확인 | 이번 M5에서 입력해 보지 않음 |
| 음성으로 지시 입력 | 미확인 | 원격 창의 음성 입력 시도·전달 결과 필요 |
| 영상 프리뷰 | 미확인 | 이번 M5에서 재생·화질·음성 확인하지 않음 |
| 긴 작업 진행률 확인 | 미확인 | 렌더 등 실제 작업을 시작하고 확인해야 함 |
| Disconnect 뒤 결과 재확인 | 미확인 | 재접속 후 M5 새 문서 확인 대기 |

문서 읽기와 확대 근거는 [M5 WorkLog](../../vl_worklog/20260927_M5_Chrome-Remote-Desktop.md#iphone-문서-검토와-내용-승인)에 있다. 여덟 항목을 나열했지만 아직 대부분 미확인이라 로드맵의 실측 완료 기준은 체크하지 않는다.
