## 여덟 동작의 현재 확인 범위

○는 이번 M5에서 확인한 동작, △는 조건이나 검증 범위에 제약이 있는 동작이다. 미확인은 실패를 뜻하지 않는다. 실제로 시도하지 않은 동작에 ✗를 붙이지 않으며, 이번 결과를 집 밖의 모든 환경에 일반화하지 않는다.

| 동작 | 현재 판정 | 근거·다음 확인 |
|---|---|---|
| 문서 읽기 | ○ | 집 안·iPhone Wi-Fi Off에서 M6 비교표를 읽고, Post & Pour 카페 Wi-Fi에서 M7 기획안을 다시 열어 읽기 편하다고 확인 |
| 작은 글씨 확대 | ○ | Pinch로 확대 후 문제 없이 읽음 |
| 짧은 지시·결과 보고 | ○ | 집 안에서 원격 대화 입력 성공. 집 밖 카페 Wi-Fi에서도 테스트 문구를 입력해 보내고 재접속 후 남아 있음을 확인 |
| 긴 수정 지시 | 미확인 | 이번 M5에서 입력해 보지 않음 |
| 음성으로 지시 입력 | 미확인 | 원격 창의 음성 입력 시도·전달 결과 필요 |
| 영상 프리뷰 | 미확인 | 이번 M5에서 재생·화질·음성 확인하지 않음 |
| 백그라운드 작업 지속 | ○ | CRD Disconnect 중 45초 대기 작업이 WorkLog에 기록됐고 재접속 후 확인됨 |
| Disconnect 뒤 결과 재확인 | ○ | 집 밖 카페 Wi-Fi에서 재접속 성공, 대화 테스트 문구와 M7 기획안 내용이 그대로임을 확인 |

문서 읽기와 확대 근거는 [읽기 실측](../../vl_worklog/20260927_M5_Chrome-Remote-Desktop.md#iphone-문서-검토와-내용-승인), 카페 밖 접속·재접속은 [Post & Pour 실측](../../vl_worklog/20260927_M5_Chrome-Remote-Desktop.md#집-밖-접속--post--pour)에 있다. 여덟 항목 중 긴 수정 지시·음성 입력·영상 프리뷰는 계속 미확인이다. 확인되지 않은 동작을 실패로 분류하지 않으며, 한 카페 Wi-Fi의 결과를 모든 장소로 일반화하지 않는다.
