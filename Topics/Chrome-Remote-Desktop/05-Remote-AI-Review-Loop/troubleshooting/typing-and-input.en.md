## Text Is Too Small to Read

The user found the text on the iPhone remote screen small, but read the comparison after pinching to zoom. Start by enlarging the passage with two fingers. For a long comparison table, do not try to view the whole table at once; start with its conclusion, “This time’s choice.” Evidence: [M5 reading test](../../vl_worklog/20260927_M5_Chrome-Remote-Desktop.md#iphone-document-review-and-content-approval).

## Text Does Not Appear in the Remote Laptop Window

Tap the input box in the AI conversation and confirm where the cursor is. Try one short sentence; send it only after it appears in the field. If input is blocked, record which window, keyboard, and result you used. If you reported through the iPhone’s own chat, identify that route; do not count it as successful remote input.

## Long Instructions or Voice Input Are Difficult

Start with a short instruction about one sentence or one numbered item. Voice input has not been verified in this environment, so check which input tool you used and whether the words actually reached the laptop’s input field. Do not mark voice input as a success or failure if it was not attempted.

## The Document Is Missing After Reconnecting

Open the [M5 README](../README.en.md) directly in Obsidian and refresh the file list. If it is still missing, record the path and file name in your report. If you cannot connect at all, follow [Chrome Remote Desktop troubleshooting](../../06-Alternatives-and-GrokBot/troubleshooting/when-crd-fails.en.md).
