## 글자가 작아서 읽기 어려움

사용자는 iPhone 원격 화면의 글씨가 작았지만 Pinch 확대 후 비교 문서를 읽었다. 따라서 먼저 두 손가락으로 읽을 부분을 확대해 본다. 긴 비교표는 표 전체를 동시에 보려 하지 말고 결론인 ‘이번 선택’부터 읽는다. 근거: [M5 읽기 실측](../../vl_worklog/20260927_M5_Chrome-Remote-Desktop.md#iphone-문서-검토와-내용-승인).

## 원격 노트북 창에 입력되지 않음

AI 대화의 입력 칸을 눌러 글자가 들어갈 위치를 먼저 확인한다. 짧은 문장 한 줄을 입력해 보고 실제로 표시되면 보낸다. 막힌 경우에는 사용한 창·키보드·입력 결과를 기록하고, iPhone 자체 채팅으로 보고했다면 그 경로를 명시한다. 원격 입력 성공으로 계산하지 않는다.

## 긴 지시 또는 음성 입력이 어려움

수정할 문장이나 번호 하나를 정해 짧게 지시하는 방식부터 시도한다. 음성 입력은 이번 환경에서 아직 검증하지 않았으므로, 사용한 입력 도구와 노트북 입력 칸에 실제 전달됐는지를 확인해야 한다. 시도하지 않은 음성 입력을 성공이나 실패로 기록하지 않는다.

## 접속 종료 후 문서가 보이지 않음

Obsidian에서 [M5 README](../README.md)를 직접 열고 파일 목록을 새로 확인한다. 그래도 보이지 않으면 저장 경로와 파일명을 사용자 보고에 남긴다. 접속 자체가 안 되는 경우에는 [설치 없는 CRD 점검](../../06-Alternatives-and-GrokBot/troubleshooting/when-crd-fails.md)을 따른다.
