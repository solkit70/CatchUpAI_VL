## This Practice

The item under review is [“This time’s choice” in the M6 comparison table](../../06-Alternatives-and-GrokBot/guides/comparison-table.en.md#this-times-choice). The user opened it in Obsidian through iPhone CRD and successfully enlarged the small text with a pinch gesture. The user approved the content, after which M5 practice documents were created. Evidence is in the [M5 WorkLog](../../vl_worklog/20260927_M5_Chrome-Remote-Desktop.md#iphone-document-review-and-content-approval).

## Follow These Steps

1. Connect to the laptop from iPhone using CRD and open the review document in Obsidian.
2. If the text is small, pinch to zoom and move the passage you are reading to the center of the screen.
3. Switch to the AI conversation window on the laptop and enter a short approval or revision instruction. Record separately an instruction sent in the iPhone’s own chat and one sent in the remote laptop window.
4. Check the AI response and file changes to confirm whether follow-up work started.
5. Lock Windows, confirm the lock screen, then Disconnect from CRD.
6. Reconnect, unlock the computer, and open this module’s README and test log in Obsidian. Confirm the new files’ saved content remains.
7. In the AI conversation window on the remote laptop, send a short report such as “Reconnected and confirmed the M5 documents.”

Record whether you tried keyboard input and voice input separately. This practice checks written results again; whether a long rendering job continues while disconnected requires a separate test.

## Report the Result

Report: “away from home / at home · mobile data / Wi-Fi · document visible / not visible after reconnect · remote laptop input worked / blocked.” If you could not verify the place or input route, mark it untested instead of guessing that it succeeded.
