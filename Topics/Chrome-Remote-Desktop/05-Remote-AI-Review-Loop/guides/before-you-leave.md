## 체크리스트 사용

이번 실습은 문서 검토와 짧은 지시를 대상으로 한다. 아래 항목을 직접 확인하고, 사용한 결과를 [실측 기록](../examples/loop-session-log.md)에 남긴다. 현재는 체크리스트를 작성한 상태이며 실제 사용 완료는 아니다.

- [ ] 노트북 전원을 연결한다. 배터리가 소진되면 다시 접속할 수 없다.
- [ ] 전원 연결 상태의 절전 설정을 확인한다. 컴퓨터가 잠들면 원격 접속이 끊길 수 있다.
- [ ] Obsidian에서 검토할 문서와 노트북의 AI 대화를 열어 둔다.
- [ ] AI에 맡길 후속 작업을 한 문장으로 정한다. 이번에는 M5 실습 문서 작성·기록이다.
- [ ] 공개·전송·삭제처럼 별도 판단이 필요한 작업이 포함되는지 확인한다.
- [ ] iPhone 회선과 장소를 기록한다. 모바일 데이터인지 Wi-Fi인지, 집 밖인지 구분한다.
- [ ] 짧은 지시를 준비한다: “내용 승인, 다음 실습 진행” 또는 “이 문장만 고쳐 주세요”.
- [ ] 종료할 때 Windows 잠금 → 잠금 화면 확인 → Disconnect 순서를 사용한다.

전원·종료 절차의 이전 검증은 [M4 iPhone 실측](../../vl_worklog/20260923_M4_Chrome-Remote-Desktop.md#활동-4--iphone-모바일-데이터-첫-실측)에 있다. 이번에 체크리스트를 실제로 썼는지는 따로 확인한다.
