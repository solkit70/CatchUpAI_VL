# 다른 컴퓨터의 브라우저에서 들어가기

**걸리는 시간**: 5분 · **준비물**: 다른 컴퓨터(노트북·사무실 PC 등), Chrome 또는 Firefox, 같은 구글 계정, PIN

> 폰·태블릿과 달리 **설치할 것이 하나도 없다.** 브라우저만 있으면 된다.
> 사무실 컴퓨터·도서관 컴퓨터·남의 노트북에서도 들어갈 수 있다 — 그래서 **더 조심할 것**도 있다 (아래).

## 순서

1. 그 컴퓨터에서 **Chrome**(또는 Firefox)을 연다
2. `remotedesktop.google.com/access`
3. 집 컴퓨터에 설정한 **같은 구글 계정**으로 로그인
4. **Remote Access** → 목록의 내 컴퓨터를 클릭 → **PIN**
5. 집 컴퓨터 화면이 브라우저 탭 안에 뜬다

## 폰과 다른 점

| | 폰·태블릿 | 컴퓨터 브라우저 |
|---|---|---|
| 마우스 | 손가락으로 흉내 | **진짜 마우스** 그대로 |
| 키보드 | 화면 키보드 또는 블루투스 | **진짜 키보드** 그대로 |
| 화면 | 작아서 확대·이동 필요 | 전체 화면 버튼으로 **집 화면과 거의 같게** |
| 단축키 | 일부만 | 오른쪽 옆 패널에서 **Ctrl+Alt+Del** 등 특수 키 보내기 |
| 파일 | 불가 | 옆 패널에서 **파일 업로드·다운로드** 가능 |
| 클립보드 | 제한적 | 복사·붙여넣기가 양쪽으로 동기화 (옆 패널에서 켜고 끌 수 있다) |

> 오른쪽 가장자리의 **작은 화살표(‹)** 를 누르면 옆 패널이 열린다. 전체 화면·특수 키·파일 전송·화면 크기 조절이 다 거기 있다.

## ⚠️ 남의 컴퓨터에서 쓸 때 — 반드시 할 것

브라우저 방식은 **로그인이 남는다.** 사무실·공용 컴퓨터에서 썼다면:

1. 원격 세션 **연결 끊기**
2. 「Remember my PIN」은 **절대 체크하지 않는다**
3. 구글 계정 **로그아웃** (계정 아이콘 → 로그아웃)
4. 가능하면 **시크릿 창**에서 처음부터 하는 것이 가장 안전하다 — 창을 닫으면 로그인이 남지 않는다

> 이 항목은 M3(보안 점검)의 「기기 목록·접속 기록 확인」과 이어진다. 남의 컴퓨터에서 쓴 뒤엔
> 구글 계정의 **보안 → 내 기기** 에서 그 컴퓨터가 남아 있는지 확인하고 지운다.

## 실측 기록

| 항목 | 값 |
|---|---|
| 시험한 컴퓨터 | ⬜ (아직 — 집 컴퓨터가 노트북이라 두 번째 컴퓨터가 필요하다) |
| 브라우저 | ⬜ |
| 접속 | ⬜ |
| 전체 화면 | ⬜ |
| 클립보드 동기화 | ⬜ |
| 시크릿 창에서 시험 | ⬜ |

> 📌 **왜 아직인가**: 이번에 설치한 「집 컴퓨터」가 `CatchUpAI_laptop` 이라는 이름 그대로 **노트북**이다.
> 같은 컴퓨터의 다른 브라우저에서 목록이 보이는 것은 확인했지만, 그건 진짜 원격 접속이 아니다.
> 다른 컴퓨터를 쓸 기회(사무실·모임 장소)가 오면 그때 채운다 — M4(집을 비우고 작업하기)와 겹친다.
