## 확인된 것

- **VPN 이 켜진 iPad 에서도 접속된다** — VPN 이 원격 접속을 막지 않았다
- **LTE 에서도 속도 차이를 못 느꼈다** — 화면이 정적(문서·메뉴)일 때 기준. 영상이 움직이는 화면은 M4 에서 다시 본다
- **한글 입력이 된다** — iPad 화면 키보드 기준
- 접속 중 집 컴퓨터 화면에 뜨는 표시가 무엇인지, 끊으면 잠기는지는 M3 에서 본다

## 아직 없는 것

2026-09-23 보강 실습: 잘못된 PIN에는 오류 문구가 표시됐고 올바른 PIN으로 정상 접속했다. iPad Wi-Fi를 끄면 Safari가 인터넷 연결 없음으로 페이지를 열지 못했으며, Wi-Fi를 켜자 즉시 회복됐다. 원격 접속은 PIN을 다시 입력한 뒤 정상 동작했다. → [문제 해결 기록](../troubleshooting/cannot-connect.md)
