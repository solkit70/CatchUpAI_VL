## 점검 전에

**왜 먼저 보나**: Chrome Remote Desktop의 첫 번째 열쇠가 Google 계정이기 때문이다. 이 문서에는 이메일 주소, 전화번호, 복구 이메일, 기기 위치를 적거나 캡처하지 않고 **상태만** 기록한다.

## 1. 2단계 인증

1. [Google 계정 보안](https://myaccount.google.com/security)을 연다.
2. **Google에 로그인하는 방법**에서 **2단계 인증**을 연다.
3. 상태가 켜짐인지 확인한다.
4. 비상시에 쓸 수 있는 백업 방법이 있는지 확인한다. 백업 코드 자체는 이 Topic에 저장하지 않는다.

Google은 비밀번호가 노출돼도 두 번째 단계가 계정을 보호하는 데 도움을 준다고 안내한다. 출처: [2단계 인증으로 개인 정보 보호](https://support.google.com/accounts/answer/10956730?hl=ko)

## 2. 로그인된 기기

1. [내 기기](https://google.com/devices)를 연다.
2. 현재 로그인 중이거나 최근 몇 주 안에 사용된 기기와 세션을 본다.
3. 이름만 보지 말고 기기 종류·브라우저·최근 활동 시각·대략적인 위치를 함께 확인한다.
4. 모르는 항목은 바로 삭제하기 전에 내 다른 브라우저나 앱 세션인지 먼저 확인한다.

같은 기기에도 브라우저나 앱마다 여러 세션이 표시될 수 있다. 정말 모르는 기기라면 해당 세션에서 로그아웃하고 계정 보안 절차를 진행한다. 출처: [계정에 접근한 기기 확인](https://support.google.com/accounts/answer/3067630?hl=ko)

## 3. 최근 보안 활동

1. Google 계정 보안 페이지에서 **최근 보안 활동**을 연다.
2. 내가 한 로그인·보안 설정 변경인지 확인한다.
3. 모르는 활동이 있으면 **내 활동이 아님**을 선택하고 안내에 따라 계정을 보호한다.

Google은 낯선 활동을 발견하면 최근 보안 이벤트와 로그인 기기를 함께 검토하라고 안내한다. 출처: [해킹되거나 도용된 Google 계정 보호](https://support.google.com/accounts/answer/6294825?hl=ko)

## 4. 복구 정보

1. 복구 전화번호와 복구 이메일이 현재 사용할 수 있는 것인지 확인한다.
2. 화면에 보이는 실제 주소나 번호는 WorkLog나 캡처에 넣지 않는다.
3. 변경이 필요하면 이 점검을 멈추고, 본인이 직접 인증을 거쳐 수정한다.

복구 정보는 휴대전화를 잃었거나 로그인할 수 없을 때 계정을 되찾는 수단이다. 출처: [2단계 인증 문제 해결](https://support.google.com/accounts/answer/185834?hl=ko)

## 결과 기록

### 2026-09-23 실제 확인

| 항목 | 확인 결과 | 다음 확인 |
|---|---|---|
| 2단계 인증 | **켜짐** — 사용자가 화면과 함께 확인 | 없음 |
| 로그인된 기기 | Windows 5세션, iPhone 9세션, iPad 3세션, **Mac 3세션** 표시. 사용자는 기기 목록에서 이상이 없다고 판단. 세션 수는 기기 수와 같지 않음 | 없음 |
| 최근 보안 활동 | 사용자가 의심되는 활동은 없다고 판단. Security Checkup에는 녹색 방패와 보안 팁이 표시됨 | 저장된 비밀번호 점검 등은 별도 선택 사항 |
| 복구 정보 | 복구 이메일·전화 모두 현재 사용 가능하며 확인 절차를 마쳤다고 사용자가 보고 | 없음 |

공개 문서에는 화면의 전화번호·이메일 주소·정확한 위치·계정 활동 캡처를 싣지 않는다. Google의 [기기 목록 설명](https://support.google.com/accounts/answer/3067630?hl=ko)에 따르면 같은 기기에서 여러 로그인 세션이 표시될 수 있으므로, 숫자만으로 낯선 기기나 침입을 판정할 수 없다.

Security Checkup의 다른 팁에는 저장된 비밀번호 점검과 Enhanced Safe Browsing 제안이 있다. 후자는 사용자의 선택이므로 M3 완료를 위해 임의로 켜지 않는다. 복구 연락처의 실제 값은 이 문서에 기록하지 않으며, 확인 완료 여부만 남긴다.
