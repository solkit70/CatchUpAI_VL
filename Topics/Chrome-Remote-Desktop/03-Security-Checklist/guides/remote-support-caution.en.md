## Why This Is Different from Access to Your Own Computer

**Remote access to your own computer** uses your Google Account and host PIN to connect to a computer you registered. **Remote Support** is a separate flow: the person sharing their screen creates a one-time code and approves the connection. You can connect to someone else’s computer or allow someone else to connect to yours. You do not need to create a support code for ordinary access to your own computer. Source: [Google Chrome Remote Desktop Help](https://support.google.com/chrome/answer/1649523?co=GENIE.Platform%3DDesktop&hl=en)

## Safer Steps When Receiving Support

**Why be careful**: Once approved, the other person may be able to see apps, files, email, and browser history. Do not give a code to someone you do not know or whose identity you have not verified. Source: [Google — Share your computer](https://support.google.com/chrome/answer/1649523?co=GENIE.Platform%3DDesktop&hl=en)

1. Confirm that you really need help and that you trust the person providing it.
2. Close sensitive documents and notifications before sharing. Start the **Get Support** flow at `remotedesktop.google.com/support`.
3. Give the generated code only to the intended person. Do not include the code or approval screen in public screenshots or WorkLogs.
4. When the other person enters the code, check the displayed email before selecting **Share**.
5. When finished, select **Stop Sharing** and confirm the session has ended.

Google explains that a support code works once and that an ongoing share periodically asks for confirmation. Being one-time does not make it safe to send to a stranger. Source: [Google’s official guidance](https://support.google.com/chrome/answer/1649523?co=GENIE.Platform%3DDesktop&hl=en)
