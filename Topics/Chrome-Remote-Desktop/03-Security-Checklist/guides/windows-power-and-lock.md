## 목표 상태

**왜 나누나**: 원격 접속을 기다리는 컴퓨터는 깨어 있어야 하지만, 화면이 계속 켜져 있으면 주변 사람에게 내용이 노출되고 전기도 더 쓴다.

| 설정 | 전원 연결 시 목표 | 이유 |
|---|---|---|
| 화면 끄기 | 10분 | 사용하지 않을 때 물리 화면 노출을 줄인다 |
| 절전 | 안 함 | 밖에서 접속할 때 호스트가 잠들어 있지 않게 한다 |
| 다시 로그인 요구 | 확인·설정 | Windows가 잠기거나 절전에서 돌아왔을 때 인증을 요구하도록 한다. 화면 끄기만으로 잠금이 보장되지는 않는다 |

## 2026-09-23 확인값

| 항목 | 전원 연결 | 배터리 |
|---|---:|---:|
| 화면 끄기 | **10분 ✅** | 3분 |
| 절전 | 안 함 ✅ | 3분 |
| Chrome Remote Desktop 서비스 | 실행 중 · 자동 시작 | 동일 |

전원 연결 시 화면 끄기의 초기값은 **안 함**이었으나, 사용자가 **10분**으로 바꾼 화면을 제공했다. 절전은 **안 함**을 유지했다. 배터리 사용 중에는 3분 뒤 절전되므로 원격 접속을 기다릴 때 전원 어댑터가 연결돼 있어야 한다. 재로그인 요구는 **Every Time**으로 표시됐고 Windows Hello 때문에 메뉴가 비활성화돼 있었다. **Disconnect만 하면 작업 화면이 그대로 남지만, 원격에서 Windows Lock을 먼저 실행하면 Disconnect 후에도 잠금이 유지됐다.**

## 1. 화면 끄기와 절전

1. Windows **설정 → 시스템 → 전원 및 배터리**를 연다.
2. **화면, 절전 및 최대 절전 모드 시간 제한**을 펼친다.
3. 전원 연결 시 **화면 끄기: 10분**으로 바꾼다.
4. 전원 연결 시 **절전: 안 함**은 그대로 둔다.

Microsoft의 Windows 11 안내도 같은 화면에서 화면과 절전 시간을 각각 바꾸도록 설명한다. 출처: [Windows 11 전원 설정](https://support.microsoft.com/windows/experience/power-battery/power-settings-in-windows-11)

## 2. 다시 로그인 요구

1. Windows **설정 → 계정 → 로그인 옵션**을 연다.
2. **추가 설정**의 **자리를 비웠다가 돌아오면 언제 다시 로그인해야 하나요?** 항목을 찾고 현재 선택값을 확인한다. 실제 화면의 문구·선택지가 다르면 그 화면을 기준으로 확인한다.
3. 실제 Windows PIN이나 암호는 WorkLog·캡처에 넣지 않는다.

화면 끄기 타이머는 Windows 잠금 타이머가 아니다. 이 설정을 확인하더라도 iPad 연결을 끊었을 때 노트북이 잠기는지는 아래 실험으로 별도 검증한다.

Microsoft는 절전에서 깨어날 때 로그인을 요구하도록 설정할 것을 권장한다. 출처: [Microsoft — 기기 보안](https://support.microsoft.com/security/securing-your-device)

## 3. 원격 세션 종료 뒤 잠금 실측

**왜 직접 보나**: 세션 종료가 자동으로 Windows 잠금을 뜻한다고 가정하면 안 된다.

1. 노트북에서 개인 정보가 없는 메모장을 하나 연다.
2. iPad에서 Chrome Remote Desktop으로 접속한다.
3. iPad의 원격 도구 막대에서 **연결 끊기**를 누른다.
4. 노트북 화면을 직접 보고 로그인 화면인지, 메모장이 그대로 보이는지 확인한다.
5. 결과만 아래 표에 기록한다. 사진을 찍는다면 이메일·문서 내용·알림을 먼저 가린다.

| 확인 항목 | 결과 |
|---|---|
| 연결 끊기 직후 노트북 화면 | **메모장 작업 화면 그대로** (2026-09-23 실측) |
| 다시 접속 가능 | **정상** (2026-09-23 실측) |
| 추가 조치 필요 | **있음** — Disconnect 전에 Windows Lock을 명시적으로 실행할 것. 아래 절차 실측 완료 |

**실무상 주의**: Disconnect만 누르고 자리를 비우면 이 노트북의 작업 화면이 주변 사람에게 보일 수 있다. 노트북 앞에 있다면 Windows 키 + L로 직접 잠근다. 밖에서 iPad로 작업할 때는 아래에서 실측한 **Windows Lock → Disconnect** 순서를 사용한다. Windows의 잠금 방법은 [Microsoft 계정 접근 안내](https://support.microsoft.com/en-us/accounts-billing/security/user-account-access-in-windows)를 참조한다.

## 4. 실측 완료 — iPad에서 먼저 잠그고 연결 종료

**왜 노트북 옆에서 먼저 했나**: 잠근 뒤 원격에서 다시 들어갈 수 있는지 알 수 없었기 때문이다. 지문 로그인은 정상 작동하지만 외출 중에는 노트북 지문 센서를 사용할 수 없어, 원격 Windows PIN 해제 가능 여부도 별도로 확인했다.

1. 노트북 바로 옆에서 iPad로 접속하고 개인정보 없는 메모장을 띄운다.
2. 원격 Windows의 **시작 메뉴 → 전원 아이콘 → 잠금(Lock)**을 선택한다. Windows 버전에 따라 **시작 메뉴 → 사용자 사진·계정 아이콘 → 잠금**에 있을 수도 있다. 두 메뉴 모두 보이지 않으면 진행을 멈추고 화면을 확인한다.
3. 노트북 물리 화면이 잠금 화면인지 확인한 뒤 iPad에서 Disconnect한다.
4. iPad로 재접속해 잠금 화면이 보이는지, 원격에서 로그인할 수 있는지 확인한다. 로그인 정보는 기록하거나 공유하지 않는다.

**2026-09-23 결과**: iPad에서 Windows Lock을 눌러도 CRD 연결은 끊기지 않았다. 그 뒤 Disconnect해도 노트북 물리 화면은 잠겨 있었고, iPad 재접속 후 **Windows PIN**으로 잠금을 해제해 작업 화면으로 돌아왔다. 이는 CRD 접속 PIN과 Windows 로그인 PIN이라는 **서로 다른 인증 단계**이며, 실제 숫자는 어느 문서에도 적지 않는다.

## 노트북 덮개 주의

덮개를 닫을 때 절전으로 들어가면 밖에서 접속할 수 없다. 덮개 동작은 기기별 설정이 다르므로 먼저 실측하고, 단순히 원격 접속을 위해 보안·발열 조건을 무시한 채 변경하지 않는다. 현재 이 항목은 아직 확인하지 않았다.
