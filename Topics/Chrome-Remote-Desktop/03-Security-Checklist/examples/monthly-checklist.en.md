## How to Use This Checklist

**Why review monthly**: Sign-in sessions, recovery contacts, and Windows power settings can change after a safe initial setup. Review them once a month. Do not write a PIN, phone number, email address, precise location, or support code in this public document. Google recommends reviewing [your devices](https://support.google.com/accounts/answer/3067630?hl=en) and [recent security activity](https://support.google.com/accounts/answer/6294825?hl=en).

**Review date**: `YYYY-MM-DD` · **Next review**: `YYYY-MM-DD` · **Recurring reminder**: ✅ Default Google Calendar · first day of every month, 10:00–10:20 Seattle time · first reminder 2026-10-01

| Check | Done | If something looks wrong |
|---|---|---|
| Google two-step verification and backup methods | ⬜ | Check settings in your own account. Do not record verification or backup codes |
| Recognize every signed-in device and session | ⬜ | Review device type and session details; follow Google’s security steps if activity is unfamiliar |
| Recent security activity and recommendations | ⬜ | Confirm events are yours and investigate unfamiliar events using Google’s guidance |
| Recovery phone and email are usable | ⬜ | Update them yourself if needed; do not write the actual contact details here |
| Host PIN is hard to guess and has not been shared | ⬜ | Change it on the host if needed. Do not record the digits |
| When plugged in: screen off after 10 minutes; never sleep | ⬜ | Check the two settings separately in [the setup guide](../guides/windows-power-and-lock.en.md#1-screen-off-and-sleep) |
| Windows is locked at the end of a remote session | ⬜ | Disconnect alone does not lock it. Review the [tested Lock → Disconnect steps](../guides/windows-power-and-lock.en.md#4-tested-lock-first-then-disconnect-from-ipad) |
| No one-time remote support session left open | ⬜ | End any unneeded support session. See [support-code precautions](../guides/remote-support-caution.en.md) |

## What to Record

Record only a status such as **No issue / Needs review / Action completed**. If you find an unknown device or event, do not copy its details into a public document; follow [Google’s account-protection steps](https://support.google.com/accounts/answer/6294825?hl=en). The recurring calendar reminder was created on 2026-09-23; record each monthly result separately in the checklist.
