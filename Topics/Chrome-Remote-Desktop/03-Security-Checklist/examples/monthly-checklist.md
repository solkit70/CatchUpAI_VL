## 사용법

**왜 매달 보나**: 처음 안전하게 설정해도 로그인 세션과 복구 연락처, Windows 전원 설정은 시간이 지나며 바뀔 수 있다. 매달 한 번 상태만 확인하고 PIN·전화번호·이메일·정확한 위치·지원 코드는 이 공개 문서에 적지 않는다. Google은 [기기 목록](https://support.google.com/accounts/answer/3067630?hl=ko)과 [최근 보안 활동](https://support.google.com/accounts/answer/6294825?hl=ko)을 검토하도록 안내한다.

**점검일**: `YYYY-MM-DD` · **다음 점검일**: `YYYY-MM-DD` · **반복 일정 등록**: ✅ 기본 Google Calendar · 매월 1일 10:00–10:20 (시애틀 시간) · 첫 일정 2026-10-01

| 확인 항목 | 완료 | 이상이 있으면 |
|---|---|---|
| Google 2단계 인증 및 대체 인증 수단 | ⬜ | 본인 계정에서 설정 확인. 인증 코드·백업 코드는 기록하지 않기 |
| 로그인된 기기·세션 전부 인식 | ⬜ | 기기 종류와 세션 세부 정보를 확인하고, 모르는 활동이면 Google 보안 절차 따르기 |
| 최근 보안 활동·보안 권장 사항 | ⬜ | 본인 활동인지 확인하고 낯선 이벤트는 Google 안내에 따라 조사 |
| 복구 전화·이메일이 현재 사용 가능 | ⬜ | 본인이 직접 수정. 실제 연락처는 여기에 적지 않기 |
| 호스트 PIN이 추측하기 어렵고 공유되지 않음 | ⬜ | 필요하면 호스트에서 변경. PIN 숫자는 기록하지 않기 |
| 전원 연결 시 화면 끄기 10분·절전 안 함 | ⬜ | [설정 안내](../guides/windows-power-and-lock.md#1-화면-끄기와-절전)를 보고 두 설정을 따로 확인 |
| 원격 작업 종료 시 Windows 잠금 확인 | ⬜ | Disconnect만으로는 잠기지 않음. [실측된 Lock → Disconnect 절차](../guides/windows-power-and-lock.md#4-실측-완료--ipad에서-먼저-잠그고-연결-종료) 확인 |
| 일회성 원격 지원 세션을 열어 두지 않음 | ⬜ | 필요 없는 지원 세션은 종료. [지원 코드 주의사항](../guides/remote-support-caution.md) 참고 |

## 이번 점검에서 남길 기록

결과는 **이상 없음 / 확인 필요 / 조치 완료** 같은 상태로만 남긴다. 모르는 기기나 활동을 발견하면 세부 정보를 공개 문서에 복사하지 말고 [Google 계정 보호 절차](https://support.google.com/accounts/answer/6294825?hl=ko)를 따른다. 반복 캘린더 일정은 2026-09-23에 등록했고, 매달 실제 점검 결과는 위 체크리스트에 별도로 기록한다.
