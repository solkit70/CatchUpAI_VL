## 학습 순서

1. [summary/final-recommendation.md](summary/final-recommendation.md) - M1~M5 전체 산출물을 학습 순서로 정리하고 최종 추천 구조를 확정한다.
2. [summary/next-steps.md](summary/next-steps.md) - 문서화만 하고 미적용한 항목과 조건부 후속 과제를 정리한다.

## 핵심 요약

이 모듈은 새로운 실습이 아니라 지금까지의 학습을 "다음 학습자와 시청자가 바로 쓸 수 있는" 형태로 패키징하는 단계다. 최종 추천 구조는 `iPhone/iPad -> Tailscale -> Windows OpenSSH -> catchupai -> Claude Code -> vault`이며, 맥미니/맥 스튜디오 홈서버는 특정 조건이 충족될 때만 재검토하는 2차 후보로 유지한다. 영상화는 완성된 가이드가 아니라 M4~M5에서 실제로 겪은 실패 3건(iPad Tailscale 미설치, GitHub 계정 두 개, 한글 IME 자모 분리)을 중심으로 설계했다.

## 산출물

- 전체 모듈 산출물 링크 정리와 최종 추천 구조
- 후속 개선 과제 (보안/운영/클라이언트/구조 전환 우선순위별)
- Remotion AI 영상 기획 브리프와 제작 전 확인 조건
