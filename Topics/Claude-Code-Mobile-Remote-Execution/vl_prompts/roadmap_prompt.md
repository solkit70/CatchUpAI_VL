## [1단계] Topic 정보

### 기본 정보

**Topic 이름**: `Claude-Code-Mobile-Remote-Execution`

**Topic 설명**:
```
모바일에서 Claude Code를 조작하고, 실제 명령과 파일 작업은 집의 로컬 노트북 또는 맥미니/맥 스튜디오 홈서버에서 실행되도록 구성하는 원격 AI 코딩 환경 학습 및 실험.
```

**학습 목적**:
```
- 모바일 지시가 로컬/홈서버 머신에서 실행되는 기술 구조를 이해한다.
- 현재 Windows 노트북 기준으로 외부에서 안전하게 Claude Code 작업을 실행하는 1차 실험 환경을 만든다.
- 맥미니 또는 맥 스튜디오를 상시 서버로 두고 노트북을 이동 작업기로 사용하는 구조를 비교 평가한다.
- 성공한 구성을 운영 가이드와 재사용 가능한 학습 산출물로 정리한다.
- 내용이 충분하면 Remotion AI 영상 제작 단계로 확장한다.
```

**예상 학습 기간**: `2주 (총 8-12시간)`

---

### 환경 및 사전 지식

**운영 체제**: `Windows 11 현재 노트북, iPhone 모바일 클라이언트, 향후 macOS 기반 맥미니/맥 스튜디오 서버 후보`

**주요 도구 및 기술 스택**:
```
- Claude Code
- PowerShell / Windows Terminal
- Git
- Node.js / npm
- SSH
- Tailscale 또는 ZeroTier
- iPhone SSH/terminal client
- macOS Remote Login / SSH 후보
- Obsidian vault
- Remotion AI / Remotion video workflow 후보
```

**사전 지식**:
```
필수:
- Git 기본 사용법
- 터미널 기본 명령어
- 로컬 파일 시스템과 vault 작업 구조 이해

권장:
- SSH 키 인증 개념
- VPN 또는 사설 네트워크 개념
- macOS 원격 로그인 기본 개념
- 홈 네트워크, 절전 설정, 백업 전략에 대한 기본 이해
```

## [2단계] AI에게 요청할 작업

위에 주입된 Topic 정보를 바탕으로 VibeLearn AI 방법론에 맞는 학습 로드맵을 생성해주세요.

### STEP 1: 학습 기간 적정성 검토

로드맵 생성 전 반드시 사용자가 입력한 학습 기간 `2주 (총 8-12시간)`이 해당 Topic에 적절한지 분석하고 피드백을 제공하세요.

분석 기준:
1. Topic 복잡도: 모바일 원격 조작, 로컬 실행 구조, SSH/VPN, Windows/macOS 서버 옵션, 보안, 실제 검증을 포함하므로 중간-복잡 범위입니다.
2. 사전 지식: Git/터미널 기본은 있다고 가정하지만 SSH/VPN/홈서버 운영은 보강이 필요할 수 있습니다.
3. 학습 목표 범위: 개념 이해와 비교 조사뿐 아니라 실제 원격 실행 실험 및 운영 가이드까지 포함합니다.

피드백 형식:

```markdown
## 학습 기간 적정성 분석

**사용자 입력 기간**: 2주 (총 8-12시간)
**Topic 복잡도**: 중간-복잡
**권장 기간**: 2-3주 (총 10-15시간)

**분석 결과**:
- 2주 8-12시간은 핵심 구조 이해와 Windows 노트북 기반 1차 실험까지는 가능합니다.
- 맥미니/맥 스튜디오 실제 구매/도입까지 포함하면 3주 이상이 더 적절합니다.
- 이번 Roadmap은 "현재 노트북으로 구조 검증 + 홈서버 도입 설계"까지를 1차 범위로 두는 것이 현실적입니다.

**사용자 확인 필요**:
아래 중 선택해 주세요.
1. "그대로 진행" - 2주 8-12시간으로 진행
2. "기간 조정" - 3주 10-15시간으로 변경
3. "범위 조정" - 2주는 유지하되 실제 세팅 범위를 더 좁힘
```

중요: 사용자가 확인하고 최종 결정할 때까지 로드맵 파일 생성을 중단하고 대기하세요.

### STEP 2: 로드맵 생성 요구사항

사용자가 기간을 최종 확정한 후 아래 요구사항에 따라 로드맵을 생성하세요.

전체 구조:
- 2주 이하: 5-7개 모듈
- 3주: 7-8개 모듈
- 첫 모듈은 개념 구조와 빠른 성공 경험
- 중간 모듈은 조사, 비교, 환경 점검, 보안 설계, 실제 실험
- 마지막 모듈은 운영 가이드와 Remotion AI 영상화 후보 정리

각 모듈은 다음 9가지 항목을 반드시 포함해야 합니다:
1. 모듈 기본 정보: 번호, 제목, 난이도, 예상 시간, 산출물 폴더
2. 학습 목표: 3-5개, 검증 가능
3. 주요 개념: 3-5개, 오해하기 쉬운 포인트 포함
4. 실습 과제: 2-3개, 70-80% 실습 중심
5. 산출물: 파일/폴더 구조 포함
6. Definition of Done: 5-8개 체크리스트
7. Self-Assessment: 개념 이해 + 실무 활용 + 문제 해결
8. 시간 배분: 20% 버퍼 포함
9. 참조 자료: 공식 문서 또는 검증 가능한 자료 중심

필수 포함 모듈:
- 모바일에서 Claude Code를 조작하는 구조 이해
- 명령이 집/로컬 머신에서 실행되는 방식 이해
- 가능한 기술 구조 비교: SSH, Tailscale/ZeroTier, 클라우드 개발 환경, 홈서버, 노트북 클라이언트 구조
- 맥미니/맥 스튜디오 홈서버 활용 구조 비교
- 현재 Windows 노트북 기반 1차 실험
- 보안/운영/백업 가이드
- Remotion AI 영상화 후보 정리

Roadmap에는 반드시 다음 섹션도 포함하세요:
- 전체 모듈 개요 표
- WorkLog 작성 가이드
- Daily / Module / Topic Retrospective 가이드
- 학습 진행 상황 추적 표
- 성공 기준
