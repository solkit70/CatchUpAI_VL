## [2단계] AI에게 요청할 작업

위 정보를 바탕으로 VibeLearn AI 방법론에 맞는 오늘의 학습 계획을 수립해주세요.

### Step 1: Roadmap 및 이전 WorkLog 분석

1. `vl_roadmap/`의 최신 Roadmap을 읽고 현재 모듈을 확인합니다.
2. `vl_worklog/`의 가장 최근 WorkLog를 확인합니다. 첫 세션이면 M1부터 시작합니다.
3. 현재 상태를 다음 형식으로 요약합니다.

```markdown
## 현재 학습 상태

**Topic**: Claude-Code-Mobile-Remote-Execution
**전체 진행률**: M{X} / M{Total}
**현재 모듈**: M{X} - {모듈명}
**모듈 DoD 달성률**: X/Y

**완료된 작업**:
- [x] ...

**미완료 작업**:
- [ ] ...

**이전 세션 이슈**:
- ...

**Tomorrow's focus**:
- ...
```

### Step 2: 오늘의 학습 계획 수립

사용자의 가용 시간과 상태를 고려하여 다음을 포함한 계획을 작성합니다:
- 우선순위
- 시간 배분
- 20% 버퍼
- 산출물 경로
- 성공 기준
- 오늘의 DoD

### Step 3: 사용자 승인 대기

계획을 제시한 뒤 반드시 사용자의 승인을 기다립니다.

```markdown
## 사용자 확인 필요

위 학습 계획으로 진행하시겠습니까?

옵션:
1. 승인 - "시작합니다" 또는 "Go"
2. 수정 요청 - 조정하고 싶은 부분을 알려주세요
3. 난이도 조정 - 더 쉽게 또는 더 심화해서 진행
```

### Step 4: 승인 후 WorkLog 생성 및 학습 진행

사용자가 승인한 경우에만 다음 경로에 WorkLog를 생성/업데이트합니다.

```
vl_worklog/YYYYMMDD_M{X}_Claude-Code-Mobile-Remote-Execution.md
```

WorkLog에는 다음을 포함합니다:
- 오늘의 학습 목표
- 진행 내용
- 문제 해결 로그
- DoD 체크리스트
- Daily Retrospective
- 참조 및 산출물

### Step 5: 진행 중 추적

각 활동이 끝날 때마다 진행 상황을 요약하고, 시간이 초과되거나 보안/설정 변경이 필요한 경우 사용자에게 확인을 받습니다.

## [3단계] 학습 계획 수립 원칙

- 실습 70-80%, 이론 20-30%
- 매 세션 시작 전 계획 제시 및 승인
- 공식 문서와 실제 환경 확인 우선
- 공개 포트 개방, 계정 연결, 보안 설정 변경은 별도 승인
- 모바일/로컬/홈서버 역할을 혼동하지 않도록 구조 다이어그램과 실행 위치를 항상 명시
- 맥미니/맥 스튜디오 관련 내용은 실제 구매 전 설계/비교 산출물로 먼저 정리
- Remotion AI 영상화는 실험 성공 후 별도 모듈 또는 후속 Topic으로 진행
