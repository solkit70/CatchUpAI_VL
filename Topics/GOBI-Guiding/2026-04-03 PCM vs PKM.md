## PCM이 무엇인가

### 기존 PKM (Personal Knowledge Management)

- 내가 정리
- 내가 저장
- 내가 관리

인간이 주체가 되어 지식을 수집하고 구조화하는 방식. 노트, 태그, 링크 — 모든 것을 사람이 직접 한다.

### PCM (Personal Context Management)

- AI가 나의 context를 이해
- 자동으로 구조화
- 필요할 때 활용

AI가 주체가 되어 나의 맥락을 파악하고, 필요한 순간에 적절한 정보를 꺼내주는 방식. 사람은 저장이 아니라 활용에 집중한다.

## 핵심 차이

| PKM | PCM |
|-----|-----|
| 내가 정리 | AI가 정리 |
| static notes | dynamic context |
| 저장 중심 | 활용 중심 |

## 왜 중요한가

PKM은 "더 잘 저장하는 법"을 고민한다. PCM은 "AI가 나를 더 잘 이해하게 하는 법"을 고민한다.

이 전환의 핵심은 **주체의 이동**이다. 인간이 지식을 관리하던 시대에서, AI가 인간의 컨텍스트를 관리하는 시대로.

PKM 툴(Obsidian, Notion, Roam)이 "저장소"라면, PCM은 "살아있는 컨텍스트 레이어"다. 노트가 죽어있는 파일이 아니라, AI가 언제든 꺼내 쓸 수 있는 동적인 지식이 된다.

## Vibe 시스템과의 연결

PCM 개념을 나의 Vibe 시스템에 대입하면:

- **현재 GOBI**: Input → Brain 생성 (Context를 만드는 시스템)
- **Vibe Learning**: Learning → Manual 생성 (Build the Brain)
- **Vibe Guiding**: Manual → Personalized Guidance (Activate the Brain)

통합하면 하나의 파이프라인이 된다:

```
Voice / Code / Chat
      ↓
Brain (GOBI PCM)
      ↓
Structured Manuals (Vibe Learning)
      ↓
Personalized Guiding (Vibe Guiding)
```

핵심 인사이트:
- **GOBI는**: Context를 만드는 시스템
- **나는**: Context를 행동으로 바꾸는 시스템을 만들고 있다

## 두 개의 Layer

여기서 중요한 구분이 생긴다 — **Build the Brain** 과 **Activate the Brain** 이라는 두 개의 레이어.

- **Vibe Learning = Build the Brain**: 주제에 대한 깊은 이해와 구조화된 문서를 만드는 단계. Brain을 채우는 과정.
- **Vibe Guiding = Activate the Brain**: 그 Brain을 실제 사용자에게 연결해서 행동으로 전환시키는 단계. Brain을 쓰는 과정.

그리고 중요한 확장: **Vibe Guiding은 Vibe Learning에 국한되지 않는다.** Vibe Learning이 만든 문서뿐 아니라, 어떤 방식으로 만들어진 Brain이든 — GOBI, 기존 매뉴얼, 소스코드 분석 — 그 위에서 작동할 수 있다. Vibe Guiding의 적용 범위는 훨씬 더 넓다.

## 연결 아이디어

- Vibe Learning이 만드는 문서 → PCM의 Topic Context가 될 수 있다
- Vibe Guiding은 PCM의 실제 구현체 중 하나
