## 이 Topic 에 대해

[English](README.en.md)

> **진행 중인 버전입니다 (2026-10-25).** 요구사항 정리와 5개 범주·9개 후보 문서 조사와 리뷰 보완을 마치고 조건부 추천·체험 계획을 작성했습니다. 의뢰인 답변은 미확인이고 로컬 발표 분리 초안 7개를 생성했습니다. B·C 경계를 파형 대조하고 검토본 4개의 사용자 리뷰를 마쳤습니다. 이어서 발표 B의 2분 27.7초 발췌 요약 초안을 생성했습니다. Vidio Free의 첫 파일(126.912초)과 한국어 수정 결과(UI 1:13)를 비교 기록했으며 사용자는 비교 청취 후 마무리가 깔끔한 로컬 요약을 조금 더 선호했습니다. Transcript 수동 v3는 UI 2:30으로 저장했으며 출력·청취 검증은 남아 있습니다. Topic 을 마칠 때 검증 결과와 추천안을 담은 최종판으로 바꿉니다.

행사를 몇 시간씩 촬영한 영상을 **AI 에게 말로 지시해서 원하는 장면만 골라 3분 안팎의 하이라이트로 편집하고, 인트로와 중간 효과까지 넣는 방법**을 찾는 리서치입니다. 지금 Adobe Premiere Pro 를 주로 쓰시고 After Effects · CapCut 으로 수작업 편집을 하시는 행사 촬영 기자(의뢰인)의 요청에서 시작했습니다. 여러 방법을 조사 · 비교해 의뢰인께 맞는 방법을 추천하고, **설치 · 사용 매뉴얼**까지 만들어 드리는 것이 목표입니다.

이 문서는 공개 저장소에 있으므로 의뢰인의 이름 · 연락처 · 행사 주최 측 정보와 실제 행사 영상은 올리지 않습니다.

## 무엇을 찾고 있나요

> 몇 시간 동안 촬영한 행사 영상을 AI 에게 「이런 장면으로」라고 지시하면, 그 지시에 맞는 부분만 골라 3분 안팎의 짧은 영상으로 편집하고, 인트로와 중간 효과까지 넣어 주는 방법

이 일을 세 부분으로 나눠서 봅니다. 수작업에서 시간이 가장 많이 드는 곳은 **① 장면 고르기**일 것으로 봅니다(확인 필요).

| 부분 | AI 가 해 주길 바라는 일 | 예 |
|---|---|---|
| **① 장면 고르기** | 긴 영상에서 지시에 맞는 구간을 찾아 자른다 | 「축사 핵심, 시상 장면, 참가자들이 웃는 모습으로 3분」 |
| **② 이어 붙이기** | 고른 구간을 3분에 맞게 순서 · 길이를 조절한다 | 컷 길이 다듬기, 음악 박자에 맞추기 |
| **③ 꾸미기** | 인트로 · 전환 · 자막 · 로고 · 음악 | 행사명 인트로, 하단 자막, 전환 효과 |

## 지금까지 정리한 것 (M1)

### 요구사항

| 항목 | 정리한 내용 |
|---|---|
| 입력 | 단체 행사를 몇 시간 동안 찍은 영상 (여러 클립일 수 있음) |
| 지시 | 말(글)로 원하는 내용을 설명한다 |
| 출력 | 3분 안팎의 짧은 영상 |
| 꾸미기 | 시작 인트로, 중간의 전환 · 자막 · 로고 · 음악 |
| 예산 | 일에 도움이 되면 **유료도 괜찮음** |
| 지금 쓰는 도구 | **Adobe Premiere Pro**(주 도구) · After Effects · CapCut |

**꼭 필요한 것**: 긴 영상을 올리거나 읽을 수 있을 것 · 말로 지시해서 장면을 고를 것(말이 있는 장면과 없는 장면 모두) · 결과를 고쳐 지시할 수 있을 것 · **결과를 Premiere 로 넘겨 마무리**할 수 있을 것 · 납품 가능한 화질로 워터마크 없이 내보낼 것

**있으면 좋은 것**: 한국어 지시 · 자막 · 행사마다 다시 쓰는 인트로 틀 · 세로(9:16) SNS 버전 · 영상을 외부 서버에 올리지 않는 방식

### 먼저 알아 둘 구분 — 편집형과 생성형

| 구분 | 무엇을 하나 | 행사 하이라이트에서 |
|---|---|---|
| **편집형 AI** | **이미 찍은 영상**에서 장면을 찾아 자르고 이어 붙인다 | ① 장면 고르기 · ② 이어 붙이기 — **몸통** |
| **생성형 AI** | 글 · 이미지로 **새 영상**을 만든다 | ③ 꾸미기 중 인트로 · 배경 장면 |

말씀하신 「시덴스」가 ByteDance의 **Seedance**인지는 미확인입니다. 최신 공식 자료는 생성뿐 아니라 참조 영상 편집도 안내하므로, 기존의 「편집은 못 한다」는 설명을 정정합니다. 다만 수시간 촬영본에서 실제 장면을 골라 3분으로 조립하는 기능은 이번 자료에서 확인하지 못했습니다. → [Seedance 조사와 정정 근거](02-Methods-Research/cards/seedance.md#기능과-기존-설명-정정)

### 조사할 방법 — 다섯 갈래

| 갈래 | 무엇 | 초기 후보 예시 (현재 조사 상태는 아래 대조표 참조) |
|---|---|---|
| **A. Claude · ChatGPT + 연결 도구** | AI 가 편집 프로그램을 대신 조작하거나 생성형 AI 를 부른다 | Premiere 를 조작하는 커뮤니티 연결 도구(MCP), Seedance 연결 |

| **C. 지금 쓰시는 프로그램의 AI 기능** | Premiere · CapCut 안의 AI 기능 | Premiere 텍스트 기반 편집 · 장면 감지, Premiere 확장 |

**Premiere 를 쓰시니 Premiere 와 이어지는 방법부터** 봅니다: ① Premiere 자체 AI 기능(추가 비용 없이 쓸 수 있는 것) → ② 하이라이트를 Premiere 로 넘겨 주는 서비스 → ③ Premiere 안에서 AI 가 조작하는 방식 → ④ 인트로 생성 → ⑤ 코드 기반(비교용).

## 앞으로의 진행

의뢰인께 [확인 질문](01-Requirements-Map/client-questions.md)의 답을 받으면 요구사항과 추천 기준을 구체화합니다. **2026-10-24 사용자 승인으로 답변은 미확인 상태로 두고 M2 사전 조사를 시작했습니다.** 답변 이후 전체 진행은 약 3주를 예상합니다(주당 5~6시간).

| 단계 | 하는 일 | 이 단계의 결과물 |
|---|---|---|
| **M1** 요구사항과 방법 지도 | 요구 정리 · 조사 범위 나누기 · 확인 질문 | 요구사항 카드 · 방법 지도 · 확인 질문 (답변 미확인) |
| **M2** 방법별 리서치 | 후보 8개 이상을 공식 자료(요금 · 한도 · 한국어 · Premiere 연계)로 조사 | **리뷰 보완: 5개 범주·후보 카드 9개·비교표·연결 방식 분석** |
| **M3** 추천안 고르기 | 조건부 추천과 체험 계획 작성 | 한 장 요약·추천안·평가 계획·원본·첫 시험 구간·로컬/Vidio 접근 확인 |
| **M4** 체험 ① 하이라이트 | 같은 영상 · 같은 지시문으로 두 방법을 시험한다 | 단계별 화면 캡처 · 결과 비교표(지시를 잘 따랐나 · 시간 · 손볼 양 · 비용) |
| **M5** 체험 ② 인트로 · 효과 | 템플릿 인트로와 생성형 인트로 비교, AI 지시로 효과 · 자막 넣기 | **3분 데모 영상**(공개 가능한 영상으로) |
| **M6** 매뉴얼과 전달 | 추천안별 매뉴얼과 요약을 만든다 | **설치 · 사용 매뉴얼** · 지시문 예시 · 한 쪽 요약 · 참고 링크 |

## 진행 방식 — 세 가지 중에서 고르실 수 있습니다

가까이 살고 있어 만나서 진행할 수도 있습니다. 섞어서 써도 됩니다(예: 나로 시작해 다로 넘어가기).

| 방식 | 어떻게 | 좋은 점 | 고려할 것 |
|---|---|---|---|
| **가. 박창수가 리서치 → 매뉴얼 전달** | 위 순서대로 박창수가 진행하고 결과와 매뉴얼을 드립니다 | 의뢰인의 시간이 가장 적게 듭니다 | 유료 도구는 「자료로만」 정리됩니다 |
| **나. 만나서 박창수 컴퓨터로 함께** | M2 이후를 만나서 함께 진행하고, 유료 도구는 의뢰인 계정으로 시험합니다 | 과정을 보며 배우시고 유료 도구도 실제로 확인합니다 | 일정 맞추기 · Premiere 연계는 의뢰인 컴퓨터에서 확인 |
| **다. 의뢰인 컴퓨터에 VibeLearn AI 설치 + 안내** | 박창수가 쓰는 AI 학습 도구를 설치해 드리고 쓰는 법을 안내한 뒤, 원하시는 방향으로 직접 리서치하시고 막히면 돕습니다 | 의뢰인의 Premiere · 유료 계정에서 바로 체험하고, 리서치하는 방법도 익히십니다 | Claude 유료 구독이 필요 · 설치와 첫 안내에 시간이 듭니다 |

## 해 드릴 수 있는 것과 못 하는 것

**유료 서비스는 박창수가 직접 써 볼 수 없습니다.** 카드를 등록해야 시작되는 체험판도 여기에 들어갑니다. 그래서 결과물에는 도구마다 아래 표시를 붙여, 직접 해 본 것과 자료로 정리한 것을 구분합니다.

| 표시 | 뜻 | 매뉴얼에서 |
|---|---|---|
| ✅ 직접 체험 | 무료 플랜 · 카드 없는 무료 체험으로 박창수가 써 본 도구 | 화면 캡처 · 막힌 곳 · 무료 한계가 들어간 단계별 매뉴얼 |
| 🤝 함께 체험 | 유료이지만, 의뢰인이 자기 계정으로 쓰실 때 만나서(또는 화면 공유로) 함께 본 도구 | 공식 자료 + 함께 본 결과 |
| 📄 자료로만 | 유료이고 함께 보기도 어려운 도구 (Premiere · After Effects 안의 작업 포함) | 공식 문서 · 튜토리얼 링크 기반, 「직접 체험 안 함」 표시 |

- 시험에는 **공개해도 되는 긴 영상**(박창수의 공개 세미나 · 모임 녹화)을 씁니다. 의뢰인의 실제 행사 영상은 의뢰인과 주최 측이 동의할 때만 시험에 쓰고, 공개하지 않습니다.
- 박창수의 컴퓨터는 GPU 가 없어 로컬 AI 처리 체험은 어렵습니다. 클라우드 서비스 위주로 체험합니다.
- 요금과 기능은 자주 바뀌므로 **확인한 날짜**와 공식 요금 페이지를 함께 적습니다.

## 받으시게 될 결과물

1. **비교표** — 8개 이상의 방법을 같은 기준(지시 이행 · 장면 정확도 · 걸린 시간 · 손볼 양 · Premiere 연계 · 비용 · 한국어 · 영상 업로드 여부)으로 비교
2. **추천안 1~2개와 대안** — 왜 이 방법인지, 지금 작업 흐름(Premiere · After Effects · CapCut)과 어떻게 이어지는지
3. **체험 기록** — 직접 해 본 방법의 단계별 화면 캡처와 막히는 곳
4. **3분 데모 영상** — 공개 가능한 영상으로 만든 하이라이트 + 인트로 · 효과
5. **설치 · 사용 매뉴얼** — 추천안별로 가입 · 설치 → 영상 올리기 → 지시하기 → 고치기 → 효과 넣기 → 내보내기 → Premiere 마무리까지
6. **바로 쓰는 지시문 예시 5개** — 축사 · 시상 · 공연 · 단체 사진 · 분위기 몽타주
7. **한 쪽 요약과 참고 링크 모음** — 비용 · 장단점, 공식 문서 · 튜토리얼 영상

매뉴얼 형태(문서 · PDF / 화면 녹화 영상 / 함께 보는 설명 시간)는 의뢰인께서 편하신 쪽으로 정합니다.

## 지금 필요한 것 — 확인 질문의 답

정리한 요구가 맞는지, 그리고 매뉴얼을 의뢰인의 환경에 맞추기 위해 18가지를 여쭙고 있습니다. **아시는 것만 답해 주셔도 됩니다.** 현재 답변은 미확인으로 유지하며, 공개 공식 자료를 먼저 조사하고 최종 추천·실제 영상 체험은 조건 확인 후 진행합니다.

- **작업 환경**: Windows / Mac, Adobe 플랜과 Premiere 버전, Claude · ChatGPT 유료 사용 여부, 플러그인 설치 경험
- **촬영본과 완성 영상**: 촬영본 길이 · 카메라 · 해상도, 녹음 상태, 납품 형식(가로 · 세로), 최근 3분 영상 예시, 한 편 만드는 데 걸리는 시간과 월 건수
- **AI 에게 바라는 것**: 가장 필요한 부분(①②③), 「시덴스」의 용도, 인트로 틀 · 음악, 한국어 지시 · 자막
- **비용과 영상 관리**: 월 예산, 외부 서버 업로드 가능 여부, 시험용 촬영본 제공 가능 여부
- **매뉴얼과 진행 방식**: 매뉴얼 형태 · 기한, 가 · 나 · 다 중 진행 방식

## 로컬 발표 분리 실습 — M4 시작

사용자 지정 연속 발표 촬영본으로 [구간표와 분리 초안](04-HandsOn-Highlight/method-A.md)을 만들었다. 발표별 본문과 질의응답을 구분한 로컬 검토 영상 7개이며 실제 영상은 공개 저장소에 넣지 않는다. [2026-10-25 경계 검사](04-HandsOn-Highlight/method-A.md#2026-10-25-경계-파형-점검과-청취-준비)에서 B·C 음성의 짧은 중복을 확인하고 검토본 4개를 준비했다. 이후 검토본 4개의 사용자 리뷰 완료를 확인하고 [발표 B의 2분 27.7초 발췌 요약](04-HandsOn-Highlight/method-A.md#2026-10-25-발표-b-요약-초안)을 만들었다. 요약 초안에 대한 긍정적인 피드백 후 [두 번째 방법 비교 준비](04-HandsOn-Highlight/method-B.md#현재-결과)로 진행했다. 사용자는 지정 5분 사본의 Vidio 또는 OpusClip 업로드를 허용했고 시험 파일·지시문·평가표를 준비했다. 이후 Vidio Free 업로드와 한국어 지시 실행을 마쳐 첫 편집 결과를 생성하고 사용자 다운로드 파일을 실측 126.912초·1280×720으로 검증했다. 한국어 수정 v2는 UI 1:13으로 더 짧아지고 PR 설명이 전부 제외돼 목표 미달을 기록했다. 사용자 비교 청취는 완료했고 핵심 선택은 비슷하나 종료가 깔끔한 로컬을 조금 더 선호했다. 수동 v3는 UI 2:30으로 저장했고 출력·청취·최종 추천 검증은 미완료다.
