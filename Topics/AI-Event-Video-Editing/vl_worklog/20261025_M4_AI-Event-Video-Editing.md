## 진행 내용

### 1. B·C 경계 파형 정렬

원본 27:32와 37:59를 기준으로 각각 8초 앞에서 시작하는 20초 참조 음성을 읽었다. 16kHz 모노 파형에 기존 앞 분리본의 마지막 2초와 뒤 분리본의 첫 2초를 정규화 상호상관으로 정렬했다. B는 약 9ms, C는 약 17ms의 음성 중복이 추정됐으며 해당 경계에서 누락은 검출되지 않았다. 이 결과는 검사한 음성 구간에 한정하며 청취·의미·영상 동기 검증은 아니다. → [측정값과 검사 한계](../04-HandsOn-Highlight/method-A.md#2026-10-25-경계-파형-점검과-청취-준비)

### 2. A 접합부와 추가 답변

기존 IMG_5249 전사 끝은 안내를 마무리하는 발언이고 IMG_5250 전사 시작은 “copilot app”이다. 연속된 문장이나 녹화가 보존됐다고 확정하지 않고 두 파일을 그대로 유지했다. IMG_5251은 비교 질문의 대상이 전사에 없어 기존 발표 말미와의 연결을 확정하지 않았다. 인물 표본 프레임은 참고했지만 화자 식별이나 질문 위치를 확정하는 근거로 사용하지 않았다.

### 3. 검토 영상 생성

A 안내 마지막 15초, 본 발표 첫 20초, B 전환 주변 34초, C 전환 주변 40초를 가로 640픽셀 H.264/AAC로 별도 생성했다. 4개 모두 전체 디코딩 검사를 통과했다. 파형 검사와 검토 영상 생성 실행은 합계 32.96초였으며 기존 7개 초안과 원본은 읽기 대상으로만 사용했다. 외부 업로드·새 전사 API·가입·결제는 실행하지 않았다.

실제 영상과 명령 인자·측정값을 담은 `boundary-review-20261025.json`은 공개 Topic 밖 로컬 작업 폴더에 보관했다. 기존 7개는 `AI/VideoEditing/20260908-GitHub/drafts/`, 새 검토본과 manifest는 `AI/VideoEditing/20260908-GitHub/review/`에 있다. 공개 문서에는 로컬 영상 임베드나 사용자명이 포함된 원본 절대 경로를 넣지 않는다.

### 4. 사용자 리뷰 완료와 요약 제작 재개

사용자가 “검토본 4개 영상은 다 리뷰 완료 했습니다. 이어서 계속 진행해 주세요.”라고 알려 로컬 요약 초안 제작으로 이어갔다. 리뷰 완료 사실을 기록하되 A의 접합 연속성·22초 답변의 위치·개별 컷의 명시적 승인까지 추정하지 않는다. 기존 7개 분리 초안은 유지한다.

첫 비교 샘플 IMG_5252.MP4 25:00~30:00에서 PR 리뷰용 Skill 설명과 Skill 범위에 대한 질문·답변을 골랐다. 새 AI 전사·외부 서비스 대신 기존 전사본을 읽고 FFmpeg의 저음량 구간 검출(-32dB, 최소 0.12초)을 보조 근거로 삼아 25:21.500~26:24.000, 27:52.000~29:17.200의 두 구간을 정했다. 합계 목표는 147.7초이며 원본 순서를 보존한다. 이는 5분 샘플 내 특정 주제 발췌이며 발표 전체나 행사 전체의 요약이 아니다.

[요약 렌더 스크립트](../04-HandsOn-Highlight/render_highlight.py)를 작성해 Python이 FFmpeg를 실행하도록 했다. 원본은 읽기만 하고 새 출력명에 1280×720 H.264/AAC MP4로 렌더링한다. 실제 출력은 147.714초·23,042,176바이트이며 전체 디코딩 오류·FFmpeg 경고가 없었다. 원본 크기·수정 시각도 동일했다. 영상과 음성 스트림 길이는 각각 147.714초·147.700초다. 시작·접합 전후·말미 4개 표본 프레임을 확인했으며 직접 청취와 새 요약본 사용자 리뷰는 아직 하지 않았다. 실행·검사는 65.542초였고 전체 편집 시간은 별도 측정하지 않았다.

출력과 실행 manifest는 `AI/VideoEditing/20260908-GitHub/highlights/talk-B-skills-highlight-v1.mp4`와 같은 이름의 JSON에 저장했다. 자막·인트로·음악은 넣지 않았고 전사 내용의 전문 용어를 임의로 교정해 영상에 표시하지 않았다. → [구간표·제작 결과·한계](../04-HandsOn-Highlight/method-A.md#2026-10-25-발표-b-요약-초안)

### 5. 외부 비교 준비와 접근 장애

요약 초안에 대해 사용자가 긍정적인 피드백과 다음 단계 진행을 요청했다. 외부 업로드 범위를 별도로 확인했고 사용자는 “5분 시험 영상만 업로드 허용”이라고 답했다. IMG_5252.MP4 25:00~30:00 사본의 Vidio 또는 OpusClip 전송에 한정하며 전체 원본·다른 파일·결제·카드 등록은 포함하지 않는다.

5분 사본을 로컬 비교 폴더에 만들었다. 실제 길이 300.0327초·31,502,623바이트이며 전체 디코딩 검사 정상, 원본 크기·수정 시각 동일을 확인했다. 생성·검사 실행은 279.974초였고 실행 명령은 로컬 manifest에 저장했다. 한국어·영어 공통 지시문, 수정 요청, 평가표를 [두 번째 방법 기록](../04-HandsOn-Highlight/method-B.md#공통-시험-입력과-지시문)에 고정했다.

공개 공식 요금표·가이드로 무료 범위를 재확인했으나 in-app 브라우저의 탭 생성·상태 조회가 모두 시간 초과됐다. Windows Computer Use도 `list_apps`가 시간 초과됐고 재시도·세션 초기화 후 재시도까지 같은 오류여서 UI 조작을 중단했다. 업로드·가입·로그인·서비스 편집은 실행하지 못했으며 서비스 자체 기능 불가로 판정하지 않는다. [관찰된 접근 장애](../04-HandsOn-Highlight/method-B.md#브라우저-접근-시도)를 기록했다.

### 6. Vidio 연결 복구와 실제 시험 시작

### 7. 첫 결과와 무료 내보내기 한계

Export에서 Free preview export를 실행했고 무료 출력은 720p·워터마크 포함이라는 안내를 확인했다. XML(Premiere Pro)은 Paid plan only로 표시돼 실행하지 않았다. 무료 내보내기 진행이 89%에 도달한 뒤 Export가 다시 활성화됐지만 브라우저 다운로드 이벤트가 저장 위치를 반환하지 않았다. 재시도에서도 같은 문제가 있어 반복 실행을 중단했고, 당시에는 실제 출력 파일 수령을 확인하지 못했다. 후속으로 사용자가 저장 경로를 알려 파일 수령·ffprobe·디코딩 검증을 완료했으며 원본과의 파형 대조는 미실시다.

다운로드 이벤트 대기 후 브라우저 제어 연결도 다시 시간 초과됐다. 생성 완료·무료 내보내기 메뉴·UI 길이와 실제 파일 저장 성공을 구분한다. 한국어 지시로 두 번째 경로의 첫 편집 시도는 실행했지만 이후 수정 요청 시험까지 실행했으며 세부 청취 평가는 남아 있다. 실제 계정·영상 화면은 공개 Topic 밖 로컬에만 보관한다. → [첫 결과 기록](../04-HandsOn-Highlight/method-B.md#첫-결과--길이와-선택-내용)

### 8. 사용자 다운로드 확인과 수정 요청 실제 시험

사용자가 다운로드된 vidio-output.mp4의 위치를 알려 첫 결과를 로컬 비교 폴더의 vidio-talk-B-v1.mp4로 보존했다. SHA-256을 기록했고 126.912초·1280×720·41,182,201바이트 및 전체 디코딩 정상을 확인했다. 사용자 Usage Reset 발언을 Vidio 잔량 초기화로 추정하지 않고 실제 화면의 무료 메시지 9개를 확인했다.

공통 수정 요청에 143~153초의 실측 목표와 불완전한 다음 질문 제외 조건을 추가한 한국어 복합 지시를 보냈다. 메시지는 9→8로 줄었고 Apply changes를 적용했다. 서비스는 질의응답을 추가해 길이를 맞췄다고 설명했으나 실제 UI는 1:13, 선택 전사는 12/53이었다. 첫 결과에서 PR 설명 6개와 다음 질문 1개가 제외됐고 기존 관련 질의응답 12개만 유지됐다. 수정으로 PR 설명 전부가 빠지고 길이도 더 짧아져 요구 미충족으로 기록한다.

수동 보정 v3의 사용자 미리보기 검토는 양호로 기록한다. 첨부 화면의 경고는 미리보기 스트리밍 지연 안내이고 Free preview export 메뉴와 유료 고해상도·XML 항목이 따로 있다. v1 무료 파일 다운로드 성공 이력도 있으므로 v3 미수령을 무료 플랜 차단으로 확정하지 않는다. 후속 상태는 v3 사용자 검토 완료·로컬 파일 저장 미확인이다.

### 12. M4 비교 결론 정리

사용자 승인으로 [M4 비교 결론](../04-HandsOn-Highlight/results-comparison.md)을 작성하고 조건부 추천안·모듈 README를 실제 결과에 맞춰 갱신했다. 로컬 147.714초와 Vidio v1 126.912초는 파일 실측, v2 1:13과 수동 v3 2:30은 UI 관찰로 구분했다. 사용자 평가·에이전트 자동 UI 조작 48.216초·전체 제작 시간 미측정도 분리했다.

핵심 선택은 비슷하고 로컬 종료를 조금 더 선호한 평가와 Vidio 수동 보정본 양호 평가를 반영했다. 후속 데모 기준 영상은 로컬 v1로 정리하지만 의뢰인 최종 도구 추천·서비스 일반 성능 순위로 확대하지 않는다. 원래 M4 DoD의 사전 동일 문구 비교와 전체 단계 화면 묶음은 미완료로 남겼다.

### M4 중간 회고 — 비교 결론 정리 시점

자동 응답의 완료 설명보다 실제 길이·선택 상태·사용자 재생 평가가 중요했다. 수동 복원으로 품질을 개선할 수 있었지만 에이전트 UI 조작 시간은 사람의 보정 시간과 다르며 전체 작업 속도 비교도 불가능했다. 비교 실습의 결론은 확보했으나 미검증 범위를 유지하고 M5에서 장면 선택과 꾸미기 효과를 분리해 평가할 준비를 마쳤다.
