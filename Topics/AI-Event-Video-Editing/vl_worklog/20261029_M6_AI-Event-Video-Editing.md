## 진행 내용

### 1. 근거 대조와 공식 문서 확인

기존 도구 우선, 외부 업로드가 가능하면 Vidio 비교라는 [조건부 추천](../03-Recommendation/recommendation.md#추천-1--기존-premiere와-capcut에서-줄일-일부터-확인)을 유지했다. 의뢰인 환경은 미확인이고 M4는 5/7, M5는 6/7이다. Seedance 결과가 생겼어도 CapCut 템플릿 비교와 편집기 전달 실증은 완료되지 않았다.

2026-10-29 Adobe의 소스 전사·텍스트 기반 시퀀스 편집 문서와 CapCut의 자동 자막 도움말·자막 출력 가이드를 읽었다. Premiere는 전사 선택과 문장 편집이 타임라인에 반영되는 순서를 안내하며, CapCut은 플랫폼·버전별 차이를 명시한다. 실제 앱에서 실행한 것으로 기록하지 않았다. 출처와 해당 단계는 [매뉴얼 초안](../06-Client-Manual/manual-existing-tools.md)에 연결했다.

### 2. 매뉴얼과 지시문 작성

시험 준비 → Premiere 발언 편집 → CapCut 자막 → 인트로 → 출력과 전달 검수 순으로 매뉴얼을 구성했다. M5에서 직접 확인한 Seedance 설정·60 credits 표시·템플릿 네트워크 오류를 넣었고 캡처와 전체 따라 하기 검증은 미완료로 표시했다. 화면을 보지 않고 메뉴를 추가로 추정하지 않았다.

[지시문 5개](../06-Client-Manual/prompt-examples.md)는 축사·시상·공연·단체 사진·분위기 몽타주를 대상으로 작성했다. 목표 길이, 실제 촬영 장면, 이름·발언 의미, 언어와 원본 시간표를 명시하며 각 예시가 미실행 초안임을 표시했다. 도구의 자연어 편집 지원 여부도 따로 확인하도록 안내했다.

### 다음 세션

## 2026-10-30 추가 세션 — 다운로드 파일 검증 및 매뉴얼 정정

기존 Seedance 2.0 Mini 결과를 새로 생성하지 않고 AI Creator에서 다운로드했다. 파일은 `Video 1.mp4`로 저장됐고, 2,015,277 bytes, 5.061995초, H.264 1280×720 24fps, AAC 44.1kHz 스테레오였다. 실제 영상은 공개 Topic 밖의 로컬 작업 폴더에 보관했다. FFmpeg 전체 디코드는 오류 없이 끝났다. DOM 미리보기의 854×480·약 5.125초 정보와 내려받은 파일 규격을 구분했다.

초당 대표 프레임으로 전체 구간을 살펴본 결과 중간 프레임에 요청하지 않은 `Penhin` 문구가 중앙에 나타나고 좌측 상단에 `Ai` 표시가 보였다. 앞 세션의 일부 프레임만 보고 중앙 여백이 있다고 적은 관찰은 부정확했으므로 M5 실습 기록·기존 도구 매뉴얼·한 쪽 요약·한영 Topic README를 수정했다. 오디오 트랙은 비무음이지만 내용을 청취하지 않아 음악·음성 분류는 보류했다. 새 생성·결제는 하지 않았다.
