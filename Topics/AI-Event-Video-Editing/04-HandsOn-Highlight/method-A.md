## 로컬 발표 분리 1차 결과

**상태:** AI가 기존 전사본과 표본 화면을 대조해 로컬 FFmpeg로 검토용 파일 7개를 생성했다. 외부 AI 서비스 시험·사용자 직접 실습·전체 청취 검수·최종 납품 검증과는 구분한다. 이번 경계 선택은 자동 화자 분리 모델 결과가 아니라 AI의 전사 내용 판독과 화면 대조를 바탕으로 한 편집 판단이다.

사용자는 한 행사에서 여러 발표를 연속 촬영한 원본을 발표별로 재편집하거나 1~3분으로 요약하도록 허용했다. 발표 분리 1차에서는 구간 나누기에 집중했고, 2026-10-25 검토본 4개의 사용자 리뷰 완료 후 발표 B의 특정 주제 발췌 요약을 추가했다. 원본과 실제 영상·인물 화면은 공개 Topic 밖 로컬에 보존하고 여기에는 재현에 필요한 파일명과 시간만 기록한다.

## 입력과 확인 방법

MP4 5개, 합계 7,269.29초다. 같은 폴더의 기존 `transcripts_medium/*.json`에서 영어 전사와 시간 정보를 재사용했으며 새로운 전사 API나 외부 업로드는 사용하지 않았다. 추가 경계 점검에서는 설치·캐시되어 있던 로컬 Whisper medium 모델을 사용했다. 전사본의 모델·생성 과정 전체를 이번 작업에서 검증한 것은 아니다. 날짜 메타데이터는 파일명 순서와 일관되지 않아 촬영 시각이나 파일 간 공백을 확정하는 근거로 쓰지 않았다.

기존 전사본에서 자기소개·발표 마무리·질문 전환을 읽고 파일 앞뒤 및 수분 간격 표본 화면을 확인했다. 파일별 도입 화면은 발표 A → B → C의 순서를 지지하지만 파일 간 누락·중복과 음성 연결은 전체 청취 전까지 미확인이다. 질문 중 다른 발표자가 답하는 구간을 새 독립 발표로 단정하지 않았다.

## 발표 구간표

시간은 각 원본 파일 내부 기준이고 끝은 미포함이다. 소수점 끝 시간은 ffprobe 길이이며 발표 내용의 정확한 마지막 음절을 의미하지 않는다. 발표자 실명 대신 A/B/C를 사용한다.

27:32와 37:59 부근 화면은 큰 장면 전환 없이 슬라이드가 유지되었다. 따라서 영상의 장면 전환 감지만으로는 이 두 경계를 찾았다고 볼 수 없고 발언 내용이 필요했다. 짧은 답변의 순서를 억지로 정하거나, 녹화되지 않은 소개·질문을 새로 만들지 않았다.

## 생성과 검증

[재현 스크립트](split_presentations.py)는 `--source`와 `--output`으로 지정된 경로만 사용한다. 원본 폴더와 분리된 출력 폴더를 요구하고 같은 이름의 기존 산출물이 있으면 중단한다. 영상·오디오만 스트림 복사하므로 재인코딩에 따른 화질 저하는 없지만 키프레임·오디오 패킷 때문에 검토용 컷에 경계 여유가 남을 수 있다.

실제 7개 출력의 길이는 순서대로 319.935초, 1366.933초, 21.844초, 1652.072초, 570.932초, 2279.077초, 1058.663초다. 계획 길이 대비 최대 차이는 약 0.077초이며, 이는 내용상 정확한 절단이나 음성 동기 검증을 대신하지 않는다. 각 파일의 시작·끝 2초를 디코딩했을 때 오류가 없었고 FFmpeg 경고도 없었다. 원본 5개의 크기·수정 시각은 작업 전후 동일했다.

스크립트 실행과 경계 디코딩은 합계 46.913초였으며 전사 판독·화면 확인·문서화 시간은 포함하지 않는다. 기존 전사 비용·생성 시간은 미확인이고 이번 작업에는 새 결제·업로드·워터마크가 없었다. 로컬 `cut-manifest.json`에 입력 구간·출력 길이·실행 시간·디코딩 결과를 기록했다. 사람의 수정 시간·수동 기준 시간·다른 도구와의 우열은 측정하지 않았다.

## 짧은 구간 재전사로 경계 점검

B 원본 27:18~27:52의 34초 음성을 로컬 Whisper medium으로 다시 전사했다. 27:32 부근에 마무리와 질문 접수 발언이 있고 첫 질문이 약 27:35.28에 시작해, 검토용 컷 27:32가 발언 전환 앞쪽을 포함하는 후보임을 다시 확인했다. ASR 재실행은 사람이 직접 청취한 검수와 같지 않으며 원본 전체의 정확성을 보증하지 않는다.

C 원본 37:40~38:20의 40초도 같은 로컬 모델로 재전사했다. 마무리 발언은 약 37:58.28에 끝나고 “Yeah, go for it.”은 37:59.66, 첫 비교 질문은 약 38:00.58에 시작해 현재 컷 37:59는 그 사이에 놓인다. 두 구간의 재전사·모델 로드 등 추가 점검은 총 238.6초였으며 영상 생성 46.913초와 별도다.

이 원본은 영어이므로 한국어 음성·지시 지원에 대한 실습 근거로 사용하지 않는다.

## 2026-10-25 경계 파형 점검과 청취 준비

사용자가 경계 검수 계획을 승인해 기존 분리본의 오디오를 원본과 대조했다. 두 경계 전후의 원본 20초를 16kHz 모노 PCM으로 디코딩하고, 앞 분리본의 마지막 2초와 뒤 분리본의 첫 2초를 정규화 상호상관으로 정렬했다. 이는 같은 음성이 원본의 어디에 해당하는지 확인하는 검사이며, 발언 의미·영상 동기·사람의 청취 검수를 대신하지 않는다.

## 2026-10-25 발표 B 요약 초안

사용자가 검토본 4개를 모두 리뷰했다고 알리고 계속 진행하도록 요청했다. 리뷰 완료 사실을 반영해 기존 분리 초안은 유지한 채 다음 실습으로 넘어갔다. 개별 컷의 구체적 수정 의견이나 A 연결에 대한 확정 판단까지 전달된 것은 아니므로 이를 추정하지 않는다.

첫 5분 샘플 안에서 **PR 리뷰용 Skill 설명 → Skill의 범위를 묻는 질문·답변** 순서로 147.7초의 발췌 요약을 구성했다. 기존 전사본을 AI가 읽어 구간을 선정하고, 컷 주변에서 FFmpeg `silencedetect`(-32dB, 최소 0.12초)로 찾은 저음량 구간을 보조 근거로 사용했다. 저음량을 발언 종료의 정답으로 취급하지 않았고 최종 의미·청취 검수는 남겨 둔다.

| 순서 | IMG_5252.MP4 원본 구간 | 요청 길이 | 출력 내 위치 | 선정 이유 |
|---|---|---|---|---|
| 1 | 25:21.500~26:24.000 | 62.5초 | 00:00~01:02.500 | PR 리뷰에 Skill을 활용하는 설명과 예시 |
| 2 | 27:52.000~29:17.200 | 85.2초 | 01:02.500~02:27.700 | Skill을 넓게 구성할지 목적별로 구성할지에 관한 질문·답변 |

발표 전체나 행사 전체를 대표하는 요약이 아니라 **선정한 5분 샘플의 한 주제를 설명하는 발췌 초안**이다. 두 구간은 원본 순서를 유지하며 각 구간 내부의 발언은 중간 삭제하지 않았다. 이 원본에 없는 시상·공연·분위기 장면은 추가하지 않았고, ASR의 전문 용어 오류를 자막으로 고정하지 않도록 이번 버전에는 자막을 넣지 않았다.

[요약 렌더 스크립트](render_highlight.py)는 원본의 해당 두 구간을 FFmpeg로 직접 디코딩해 하드 컷으로 연결한다. 기존 분리본의 패킷 여유를 재사용하지 않고 1280×720, 약 29.97fps, H.264/AAC 스테레오 MP4로 재인코딩했다. 새 출력명만 허용하며 원본 크기·수정 시각이 유지됐는지 확인한다. 인트로·전환 효과·음악은 이번 장면 선택 시험에 넣지 않았다.

실제 출력 `talk-B-skills-highlight-v1.mp4`는 **147.714초, 23,042,176바이트**다. 전 구간 디코딩 오류와 FFmpeg 경고가 없었고 원본 크기·수정 시각은 동일했다. 시작·접합 전후·말미 4개 표본 프레임에서 영상 방향과 원본 화면 유지도 확인했다. 출력·검사 실행은 65.542초이며 전사 판독·구간 선택·문서화·사람의 리뷰 시간은 포함하지 않는다.

실제 영상·표본 화면·실행 명령과 측정값 manifest는 로컬 작업 폴더에 보관한다. 이번 결과는 **AI의 전사 판독 + Python + FFmpeg 한 가지 로컬 경로**이며, 외부 AI 편집 서비스의 자동 선정·한국어 지시 지원·Premiere 전달 성능을 검증한 결과는 아니다. → [이번 WorkLog의 요약 제작 기록](../vl_worklog/20261025_M4_AI-Event-Video-Editing.md#4-사용자-리뷰-완료와-요약-제작-재개)

## 첫 비교 구간과 다음 단계
