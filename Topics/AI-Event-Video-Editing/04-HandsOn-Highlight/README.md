## M4 — 발표 분리와 하이라이트 실습

**상태:** 로컬 발표 분리 초안 7개를 만들고, 경계 검토본 4개의 사용자 리뷰 완료 후 발표 B의 2분 27.7초 발췌 요약 초안을 추가했다. 기존 전사본·표본 화면과 FFmpeg를 이용한 한 가지 방식이며 이후 Vidio Free에서 5분 샘플과 한국어 지시로 첫 편집 결과를 생성했다. Vidio v1 파일은 126.912초·1280×720으로 검증했으나 목표 길이에 미달했다. 한국어 수정 v2는 UI 1:13으로 더 짧아지고 PR 설명이 전부 제외돼 요구를 충족하지 못했다. 실제 영상과 인물 화면은 공개 Topic 밖 로컬에 저장한다.

## 읽고 실행하는 순서

1. [M4 비교 결론](results-comparison.md) — 네 결과의 차이·사용자 평가·시간 측정 범위·미검증 조건을 먼저 읽는다.
2. [방법 A와 발표 구간표](method-A.md) — 로컬 분리·발췌 요약의 선택 근거와 검증 결과를 확인한다.
3. [분리 스크립트](split_presentations.py) — 기존 출력을 덮어쓰지 않고 발표 분리를 재현한다.
4. [요약 렌더 스크립트](render_highlight.py) — 로컬 발췌 요약을 재현한다.
5. [Vidio 실제 시험과 수정 기록](method-B.md) — 자동 편집·자동 수정 실패·수동 복원·다운로드 확인 범위를 읽는다.
6. [최신 M4 WorkLog](../vl_worklog/20261025_M4_AI-Event-Video-Editing.md) — 실행 경과와 실제 DoD 상태를 확인한다.

## 완료 범위

로컬 분리 초안 7개·경계 검토본 4개·로컬 요약 147.714초·Vidio v1 파일 126.912초를 만들고 검증했다. 사용자는 핵심 선택이 비슷하지만 마무리에서 로컬을 조금 더 선호했다. Vidio 자동 수정 v2는 UI 1:13으로 요구를 충족하지 못했고, 이후 수동 v3는 12개 복원·UI 2:30·Saved를 확인해 사용자에게 양호한 평가를 받았다.

비교 결론과 평가표는 작성 완료다. 원래 DoD는 5/7이며 사전 고정된 동일 문구 비교와 전체 매뉴얼용 단계 화면 묶음은 미완료다. v3 로컬 파일·A 연결 확정·한국어 음성·긴 원본·Premiere 전달·사용자 자기평가는 별도 미검증이다. 다음 데모의 기준은 파일 검증된 로컬 v1로 정리한다.
