## 현재 결과

사용자는 로컬 요약 초안에 긍정적인 피드백을 주고 다음 단계 진행을 요청했다. 이어서 외부 서비스 시험 범위를 확인하자 **“5분 시험 영상만 업로드 허용”**이라고 답했다. 허용 범위는 IMG_5252.MP4 25:00~30:00의 시험 사본을 Vidio 또는 OpusClip에 올리는 것에 한정되며, 전체 원본·다른 영상·결제·카드 등록으로 확대하지 않는다.

이전 브라우저 제어 연결 장애 이후 사용자가 직접 로그인했고, 연결 복구 후 에이전트가 허용된 5분 사본 업로드와 한국어 공통 지시문 전송을 실행했다. 계정 화면은 Free이며 파일은 All requirements met로 표시됐다. 무료 메시지는 전송 전 10개에서 전송 후 9개로 줄었고 첫 편집이 완료됐다. 미리보기는 약 2분 06초로 목표 길이 미달이며 무료 내보내기 후 사용자가 다운로드 위치를 알려줘 파일을 보존·검증했다. 실제 길이는 126.912초, 1280×720, 전체 디코딩 정상이다. 최종 품질·비용 우열은 아직 판정하지 않는다.

## 공통 시험 입력과 지시문

시험 입력은 로컬 `talk-B-sample-25m-30m.mp4`로 준비했다. 실제 길이 300.0327초·31,502,623바이트이며 1280×720 H.264/AAC 사본이다. 샘플 내 00:00은 원본 25:00에 해당하며 모든 비교 결과의 시간을 이 기준으로 변환한다. 원본 전체나 먼저 만든 요약본을 외부 서비스의 입력으로 사용하지 않는다.

> 이 5분짜리 발표 영상에서 Skill을 PR 리뷰에 활용하는 핵심 설명과, Skill을 어떤 범위로 구성할지에 대한 관련 질문·답변을 골라 하나의 요약 영상으로 만들어 주세요. 가로 16:9, 목표 길이는 2분 28초이며 ±5초를 허용합니다. 질문과 답변의 관계 및 발언의 뜻을 보존하고 원본의 시간 순서를 유지해 주세요. 원본에 없는 장면·발언은 만들지 마세요. 이번 시험에서는 인트로·음악·전환 효과·자막을 넣지 마세요. 수행하지 못하는 요구는 알려 주세요.

이 지시문은 **비교 실습을 위해 이번에 고정한 문구**다. 기존 로컬 요약은 이전의 포괄적 요청을 바탕으로 구간을 선택했으므로, 아직 문자 그대로 같은 프롬프트의 두 번 실행 결과가 아니다. 엄밀한 동일 조건 비교로 평가할 때는 이 문구로 로컬 선택도 다시 검토하고, 기존 컷의 시간을 외부 서비스에 정답으로 주지 않는다. 한국어를 지원하지 않으면 아래 영어 문구를 별도 시도로 기록한다.

> From this five-minute presentation, select the key explanation of using a Skill for PR reviews and the related question and answer about how narrowly to scope a Skill. Assemble one 16:9 summary, targeting 2 minutes 28 seconds with a tolerance of 5 seconds. Preserve the question-answer relationship, the meaning of the statements, and chronological order. Use only the original footage and speech. Do not add an intro, music, transitions, or captions for this test. Tell me which requirements you cannot perform.

수정 시험은 “PR 리뷰 활용 설명을 줄이고, Skill 범위에 대한 질문·답변을 늘려 주세요. 전체 길이는 같은 목표 범위로 유지해 주세요.”로 통일한다. 새 수정 요청의 실행 결과와 자동 처리·사람 조작 시간을 분리해 기록한다.

## 샘플 생성 검증

전체 디코딩 검사는 정상이며 원본 크기·수정 시각은 유지됐다. 샘플 생성과 검사 실행은 279.974초였고 원본 판독·문서화·브라우저 접근 대기 시간은 포함하지 않는다. 영상과 명령·측정값 manifest는 공개 Topic 밖 로컬 `AI/VideoEditing/20260908-GitHub/comparison/`에 저장했다.

## 접근 조건 재확인

2026-10-25 [Vidio 공식 요금표](https://www.vidio.ai/pricing)에서 무료 Basic의 VibeEdit·워터마크·1GB 파일 한도·10분 입력 한도를 다시 확인했다. [Vidio 가이드](https://www.vidio.ai/guide)는 지시로 편집하고 채팅으로 수정하는 경로를 안내한다. 이 문단은 공개 문서 확인 기록이다. 아래 실제 시험에서 Free 계정 접근과 무료 미리보기 내보내기 메뉴를 확인했지만 로컬 출력 파일 수령까지 검증한 것은 아니다.

[OpusClip 공식 요금표](https://www.opus.pro/pricing)는 카드 없는 무료 체험 문구와 무료 플랜의 워터마크·편집 제한을 안내한다. 따라서 Vidio가 접근되지 않을 때의 대안으로 유지하되 체험 계정에서 한국어 지시·가로 화면비·한 편으로 조립하기가 가능한지는 각각 확인한다. 새 계정·결제·유료 플랜을 사용한 것으로 기록하지 않는다.

## 실제 계정 접근과 1차 실행

사용자가 직접 로그인한 뒤 화면을 확인하며 진행했다. 실제 진입 경로는 **Dashboard → Create의 New project → VibeEdit**이며 왼쪽 Create 하위 메뉴에 VibeEdit가 직접 있는 것은 아니었다. VibeEdit의 Media composer → Add files → Choose Files에서 허용된 5분 사본을 선택했다. Add files는 먼저 업로드 패널을 열기 때문에 그 버튼에서 곧바로 운영체제 파일 선택 창을 기다리면 시간 초과가 발생했고, 패널의 Choose Files에서 정상 진행했다.

업로드된 파일은 Main visuals의 A-roll 1개, 05:00.0, All requirements met로 확인됐다. 업로드 패널에는 Free 계정의 1GB 한도와 당시 오늘 무료 처리 프로젝트 3개가 표시됐다. Media Composer의 X로 패널을 닫아도 입력 영상 1개가 유지됐고, 위 한국어 공통 지시문을 그대로 입력해 전송했다. 무료 메시지 잔량은 10→9로 변했고 화면은 Analyzing your request / Processing 35%를 표시했다. 이는 한국어 요청을 접수한 관찰이며 결과의 한국어 이해 정확도 검증은 아니다.

Vidio는 한국어로 148초±5초·16:9·원본 순서 유지·인트로/음악/전환/자막 제외 요구를 되풀이하고 Run task 실행을 안내했다. Show the plan에서 원본 1개, 약 148초의 best moments, 촬영 순서, 원본 소리, 16:9를 확인한 뒤 Run task를 실행했다. 처리는 0%→60%→72%로 진행됐으며 결과 영상 검증 전까지 요구 충족으로 판정하지 않는다. Vidio는 문장이 정확히 같은 지점에서 끊기지 않을 수 있다고 응답했다.

새 계정 생성·카드 등록·결제·YouTube 연결·외부 미디어 검색은 실행하지 않았다. 이 절의 출처는 2026-10-25 실제 계정 화면 관찰이며 최종 결과는 처리 완료 후 갱신한다.

## 첫 결과 — 길이와 선택 내용

Run task의 처리가 완료돼 Preview에서 첫 결과를 열었다. 타임라인은 5개 묶음, 약 **2분 06초**로 표시됐다. 목표 148±5초보다 짧아 길이 기준은 미달이다. 이는 UI 표시 기준이며 후속 다운로드 파일의 ffprobe 실측은 126.912초이며 허용 하한 143초보다 16.088초 짧다.

Transcript에는 전체 53개 중 19개가 영상에 선택된 것으로 표시됐다. PR 리뷰용 Skill 설명과 Skill 구성 범위를 묻는 질문·답변이 선택된 것을 확인했다. 다만 선택 발언 끝에 다른 주제의 다음 질문 앞부분도 포함됐다. 또한 일부 유머·정의 구간이 제외돼 맥락 검수와 수정이 필요하다. 이는 선택된 전사와 상태 버튼을 읽은 관찰이며 직접 청취한 평가로 대신하지 않는다.

Export 메뉴에는 Free preview export — Low resolution with watermark가 있고 안내는 720p 제한을 명시했다. Premium export와 Download XML (Premiere Pro)는 별도이며 XML은 Paid plan only로 표시됐다. 무료 미리보기만 실행했고 내보내기 진행률이 89%까지 올라간 뒤 Export 버튼이 다시 활성화됐다. 다운로드 이벤트로 저장 위치를 받지 못해 첫 결과를 다시 무료 내보내기했으나 같은 이벤트 대기가 시간 초과됐다. 재시도 때 진행률 21%를 확인한 후 반복 실행을 중단했다. 다운로드 이벤트 감지 시도 중 브라우저 제어 연결도 다시 시간 초과돼 당시에는 로컬 저장 완료를 확인하지 못했다. 이후 사용자가 실제 다운로드 파일을 지정해 저장 성공을 확인했으므로 서비스 출력 생성 실패나 다운로드 실패로 판정하지 않는다. 유료 출력·XML은 실행하지 않았다.

## 다운로드 확인과 수정 요청 시험

사용자가 실제 다운로드 파일 위치를 알려줘 첫 결과를 `vidio-talk-B-v1.mp4`로 별도 보존했다. 41,182,201바이트이며 전체 디코딩 검사에서 오류가 없었다. 컨테이너 길이는 126.912초, 영상 126.860067초, 음성 126.912초이며 영상은 1280×720 H.264, 음성은 48kHz 스테레오 AAC다. 시작·중간·말미 4개 표본 프레임도 확인했다. 직접 청취·발언 의미 검증까지 완료한 것은 아니다.

공통 수정 요청에 첫 결과의 실측과 발견한 문제를 덧붙여 다음 한국어 문구를 보냈다. 이는 단순 공통 문구 실행과 달리 **길이 교정·질의응답 비중 변경·불완전한 다음 질문 제거를 함께 요청한 복합 수정 시험**으로 구분한다. 원본의 관련 질의응답 분량에 제약이 있으므로 요구를 동시에 충족할 수 있는지와 불가능할 때 이를 알리는지도 관찰한다.

> PR 리뷰 활용 설명을 줄이고, Skill 범위에 대한 질문·답변을 늘려 주세요. 전체 길이는 같은 목표 범위로 유지해 주세요. 첫 결과는 실제 126.912초로 요청한 148초±5초에 미달했습니다. 수정본은 143~153초 범위로 맞춰 주세요. 마지막에 들어간 별도의 open source/security 질문 앞부분은 답변 없이 잘리므로 제외해 주세요. 관련 질문과 답변은 문장이 완결되도록 보존하고 원본 순서를 유지해 주세요. 16:9와 원본 소리를 유지하며 인트로·음악·전환·자막은 추가하지 마세요. 이 조건을 함께 충족할 수 없으면 무엇이 불가능한지 알려 주세요.

사용자가 Usage Reset을 했다고 알렸지만 그 대상이나 Vidio 사용량 초기화로 해석하지 않았다. 수정 전 실제 Vidio 화면은 무료 메시지 9개로 표시됐다. 첫 결과를 보존한 뒤 같은 프로젝트의 대화 입력란으로 수정 요청을 전송했다. 후속 응답은 PR 설명을 줄이고 질의응답을 추가해 길이를 맞췄다고 설명했으나 실제 적용 결과는 아래와 달랐다.

## 수정 적용 결과 — 설명과 실제 타임라인의 불일치

수정 요청 전송으로 무료 메시지는 9→8로 줄었다. Vidio는 한국어로 PR 설명 제거·질의응답 추가·불완전한 다음 질문 제거·143~153초 조정을 설명했고 Apply changes 버튼을 제시했다. 적용 후 Preview의 타임라인은 **1분 13초**, 묶음 2개로 표시됐다. 이는 UI 표시값이며 수정본 파일을 내려받아 측정한 값은 아니다.

Transcript 선택은 19/53에서 12/53으로 줄었다. 첫 결과의 PR 리뷰 설명 6개와 다음 질문 앞부분 1개는 모두 제외됐고 관련 질의응답 12개는 유지됐다. 이전에 제외돼 있던 RACI 질문·정의 등은 여전히 Add to video로 표시돼 실제로 추가된 클립은 확인되지 않았다. 따라서 이번 관찰에서는 PR 설명을 간결하게 남기는 대신 전부 제거됐고, 질의응답의 절대 분량도 늘어나지 않았다. 설명에서 주장한 길이 충족·클립 추가를 실제 상태와 구분한다.

복합 수정 요청의 조건이 원본 분량상 동시에 가능한지는 별도 검토가 필요하다. 다만 Vidio가 불가능한 조건을 알리는 대신 목표를 맞췄다고 설명한 점과 실제 1:13을 보여 준 점은 직접 관찰한 불일치다. 이 한 샘플만으로 서비스 전체 성능을 일반화하지 않으며, 이번 작업에서는 자연어 응답만으로 요구 충족을 판단할 수 없었다.

당시 수정본은 실패 상태를 확인할 수 있도록 유지했고 Undo는 누르지 않았다. 이후 실패 화면을 보존한 채 아래 수동 보정 v3로 이어갔다. 첫 결과 파일은 로컬에 따로 보존했다. 수정 화면은 공개 Topic 밖 `vidio-revision-v2.png`로 저장했다. 이 자동 수정 단계와 이후의 수동 보정은 구분한다. 실제 영상과 인물 화면은 공개 문서에 첨부하지 않는다.

## 사용자 비교 청취 결과 — 2026-10-25

사용자는 로컬 요약과 Vidio v1을 모두 시청하고, 두 결과가 강의와 Q&A의 핵심 부분을 골랐다는 점에서는 비슷하다고 평가했다. 차이는 마무리에서 드러났으며 Vidio v1은 관련 Q&A가 끝난 뒤 두 번째 Q&A가 조금 나와 깔끔하게 끝나지 않는다고 지적했다. 그 이유로 **이번 샘플에서는 로컬 요약을 조금 더 선호**했다. → [[Journal/2026-10-25#AI 행사 영상 편집 비교 평가 (구술 원문)|사용자 비교 평가 원문]]

이번 평가는 핵심 내용 선택의 큰 차이보다 **발언·질의응답의 완결성과 종료 컷**이 선호도에 영향을 줬다는 근거다. 선호 강도를 강한 우열이나 수치 점수로 확대하지 않으며, 모든 문장의 의미 왜곡·자막·음성 동기까지 검증했다고 처리하지 않는다. Vidio 수정 v2는 이번 사용자 비교 대상이 아니었다.

## 수동 보정 v3 — Transcript에서 12개 복원

사용자가 Transcript 탭을 열고 에이전트의 직접 조작을 요청했다. 자동 수정 v2의 선택 12개를 시작점으로 Add to video를 12회 눌러 PR 리뷰 설명 9개와 Q&A의 RACI 질문·정의 3개를 복원했다. 샘플 내 시작 시각은 아래와 같으며 원본 시간은 여기에 25분을 더한다.

| 복원 대상 | 샘플 내 시작 시각 |
|---|---|
| PR 설명과 연결 문맥 9개 | 0:21, 0:30, 0:34, 0:45, 0:48, 0:53, 0:57, 1:01, 1:11 |
| RACI 질문·정의 3개 | 3:37, 3:41, 3:46 |

0:45·0:57은 서비스가 No speech로 표시했지만 원본의 설명 흐름을 복원하는 연속 구간에 해당해 포함했다. 이 분류를 발언 유무의 정답으로 취급하지 않았으며 세부 음성 경계는 후속 청취로 확인한다. 관련 없는 다음 질문(4:20 이후)은 추가하지 않았다.

선택은 12/53→24/53, 길이는 UI 1:13→1:45→2:16→**2:30**으로 변했다. Timeline에는 **0:00~1:02의 설명 + 1:02~2:30의 질의응답** 두 묶음이 표시됐고 Saved를 확인했다. 150초의 UI 표시는 목표 범위 143~153초에 들어오지만 출력 파일 실측과 자연스러운 컷 검수는 별도다.

첫 추가부터 마지막 추가까지 **48.216초**였으며 에이전트가 브라우저 API로 선택한 12회의 UI 조작 경과 시간이다. 사전 판독·선정 판단·후속 재생 검수·문서화·내보내기는 제외한다. 따라서 사람의 수동 편집 시간이나 일반 사용자 숙련도를 측정한 수치로 사용하지 않는다. 드래그나 코드 렌더링 없이 문장별 Add to video만 사용했고 AI 채팅 메시지 잔량은 8개로 유지됐다.

자동 수정 실패(v2)는 화면과 기록에 보존하고 현재 프로젝트는 수동 보정 v3 상태로 저장했다. 수동 보정의 결과를 AI 자동 수정 성공으로 집계하지 않는다. 화면·선택 로그·시간은 로컬 비교 폴더의 vidio-manual-v3.png·vidio-manual-v3.json에 저장했다. 무료 720p 워터마크 출력을 한 번 실행했고 진행 표시 종료 후 Export가 다시 활성화됐다. 그러나 Downloads의 vidio-output 계열 새 파일은 확인되지 않아 로컬 파일 저장 성공으로 처리하지 않는다. 같은 내보내기를 반복하지 않았고 현재 프로젝트의 Saved·UI 2:30 상태를 보존했다. 실제 파일 길이와 청취 검증은 후속 확인 사항이다.

## 수동 보정 v3 사용자 검토와 다운로드 해석

사용자는 수동 보정본에 대해 “영상 편집된 것은 잘 된 것 같습니다.”라고 평가했다. 따라서 v3의 사용자 미리보기 검토는 완료로 반영하되 세부 기술 검수·로컬 파일 수령·전체 Topic 자기평가까지 완료한 것으로 확대하지 않는다. → [[Journal/2026-10-25#Vidio 수동 보정본 검토와 다운로드 추정 (구술 원문)|수동 보정본 사용자 평가 원문]]

사용자는 다운로드 문제가 무료 플랜 제한일 가능성을 추정했다. 첨부 화면은 Free preview export(저해상도·워터마크), Premium export(고해상도), XML(Paid plan only)을 구분하며, 별도 경고는 미리보기 스트리밍이 느리다는 내용이다. 이 경고만으로 다운로드 차단을 뜻한다고 해석할 수 없다. 또한 앞선 v1 무료 출력 파일은 실제로 다운로드·보존·검증했다. 따라서 현재 결론은 **v3 로컬 저장 미확인·원인 미확정**이며 무료 플랜의 모든 다운로드가 불가능하다고 기록하지 않는다.
