## M5 실습 범위

사용자가 M5 진행을 요청해 로컬 기준 영상에 코드 기반 타이틀·효과를 적용하는 실습을 시작했다. 원래 로드맵 예상은 3시간이며 실제 학습 시간으로 집계하지 않는다. CapCut 템플릿·생성형 인트로·발언 자막·Premiere 연계는 아직 실행하지 않았고 실제 영상은 공개 Topic 밖 로컬 작업 폴더에 보관한다.

## 학습 순서

1. [인트로 방식 비교](intro-template-vs-generative.md) — 이번에 실행한 코드 템플릿과 미실시 생성형 경로를 구분한다.
2. [AI 지시 효과 적용](ai-directed-effects.md) — 인트로·하단 제목·Q&A 카드와 원본 보존 기준을 확인한다.
3. [재현 스크립트](render_effects.py) — 원본과 새로운 출력 폴더를 지정해 데모를 만든다.
4. [데모 조립과 검증](demo-assembly.md) — 타임라인·출력 실측·검증 결과·검토 항목을 확인한다.
5. [M5 WorkLog](../vl_worklog/20261025_M5_AI-Event-Video-Editing.md) — 현재 DoD와 미완료 작업을 확인한다.
