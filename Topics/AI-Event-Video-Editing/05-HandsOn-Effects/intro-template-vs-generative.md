## 실제 실행한 인트로

이번에는 FFmpeg와 Pillow로 중립적인 제목 카드를 만들었다. 주제명은 기존 발언 내용에 따른 “Skill 활용 / PR 리뷰와 Q&A”이며 행사명·발표자 이름·고객 로고를 새로 확정하지 않았다. 5초 카드에 페이드 인·아웃을 넣어 재사용 가능한 코드 템플릿의 첫 사례로 삼는다. → [원본 발췌 주제](../04-HandsOn-Highlight/method-A.md#2026-10-25-발표-b-요약-초안)

| 경로 | 이번 상태 | 해석 |
|---|---|---|
| 코드 기반 타이틀 템플릿 | 로컬 제작·렌더 실행 | Python이 글자·도형을 배치하고 FFmpeg가 영상으로 조립 |
| CapCut 템플릿 | 미실시 | 실제 템플릿 선택·편집 시간·계정 조건을 평가하지 않음 |
| 생성형 인트로 | 미실시 | 프롬프트 생성 영상의 품질·무료 접근·비용을 비교하지 않음 |

코드가 그래픽을 그린 결과를 생성형 영상 AI 체험으로 표시하지 않는다. 원래 M5의 템플릿·생성형 인트로 2종 비교 DoD는 미완료다. 기존 Remotion 슬라이드·TTS 제작 스킬은 이번의 촬영본 타이틀 효과 작업에 적용하지 않았고 새 내레이션도 만들지 않았다.

## 사용한 시각·음원 자료

제목·선·배경은 이 실습의 코드로 만들고 음악·외부 이미지·생성형 장면은 사용하지 않았다. 로컬 설치된 맑은 고딕을 렌더에 사용하며 글꼴 파일 자체는 배포하지 않는다. 원본 촬영 영상은 사용자가 허용한 로컬 실습 범위로만 사용하며 공개 게시나 다른 서비스 업로드 허용으로 확대하지 않는다. 글꼴·촬영본의 모든 용도에 대한 권리를 검증한 법적 판단으로 기록하지 않는다.
