## 반영 범위

사용자가 전달한 Claude 리뷰와 수정 계획 승인을 바탕으로 요금·후보 누락·독자 관점을 보완했다. **화면 대조는 AI가 수행했으며, 사용자 본인의 화면 확인이나 계정 내 실제 구매 조건 확인을 대신하지 않는다.** 의뢰인 답변과 실제 체험은 미확인으로 유지한다.

## OpusClip 플랜 재검증

[공식 요금표](https://www.opus.pro/pricing)의 플랜 카드와 비교표를 실제 브라우저에서 대조했다. 비교표의 열은 Free → Starter → Pro → Business이고, Premiere·Resolve 내보내기 행은 차례로 미포함·미포함·체크·체크였다. [공식 FAQ](https://help.opus.pro/docs/article/import-to-adobe-premiere)도 Pro 전용이라고 안내한다. 따라서 이번 확인에서는 **Business 전용으로 정정할 근거가 없으며 Pro 포함을 유지**한다. 리뷰가 잘못되었다고 일반화하거나 다른 시점·계정에서의 표시 차이 원인을 추정하지 않는다.

월·연 결제 스위치를 직접 전환해 Pro 1팩 기준 **월 $29**와 **연 $174, 월 환산 $14.50**를 확인했다. 무료 Pro 체험이 유료 플랜 전체 기능을 제공하는지와 실제 계정의 XML 제공 여부는 별도 검증 대상이다. 이 결과는 공개 안내의 확인이며 결제·로그인·체험은 하지 않았다.

사용자 검토용: 연 결제 화면에서 가운데 카드의 제목이 Pro임을 확인한 뒤 같은 카드 하단 기능 화면과 비교하면 된다. 실제 계정 화면이 다르면 이 기록과 날짜·지역·결제 주기를 비교하고, 충돌이 풀릴 때까지 도입 비용 판단을 보류한다.

Vidio는 [요금표](https://www.vidio.ai/pricing)의 USD·기본 크레딧 선택값에서 월·연을 전환해 확인했다. [XML 전달 안내](https://www.vidio.ai/guide)는 자막·타이틀·전환·색·속도·화면 재구성이 다시 만들어지지 않는다고 설명하며, 기존 카드의 제약을 유지했다.

이 표의 숫자를 사용자가 직접 대조한 것으로 체크하지 않았다. 상담 시에는 먼저 가격표의 적용 조건을 설명하고, 실제 도입 직전에 계정 화면과 대조한다.

초기 8개 선정 당시 다른 후보를 검토해 제외했다는 기록은 없었다. 따라서 빠진 항목은 **미조사였음**을 밝히고, 아래의 후속 분류를 이번 리뷰 반영 시점에 결정했다. 보류는 기능이 부족하다는 제품 판정이 아니다.

현재 심층 카드는 **5개 범주·9개**이며, M1 후보 전부를 심층 조사했다는 뜻은 아니다. 추가 카드 수를 늘리기보다 조건부 추천과 실제 체험을 먼저 준비한다.

## 독자·언어·이름 표기

주 독자는 한국어를 쓰는 비개발자 영상 전문가다. 본문·카드는 한국어로 유지하고 영어 README에는 상태와 핵심 결과를 요약한다. M2 전 문서의 영어 번역은 이번 범위에서 만들지 않는다.

새 의뢰인용 안내에는 「진행자」를 사용한다. 과거 작성자·구술·WorkLog는 원래 기록을 보존하며, M1에서부터 있던 표현을 이번 작업에서 새로 작성한 것처럼 설명하지 않는다. 기술 설명은 조사 카드에 두고 상담용 요약에서는 필요한 말로 풀어 쓴다.
