## 요약

**범주 C · 공식 자료 확인일 2026-10-24 · 체험 상태: 자료로만 / 직접 체험 안 함.** 의뢰인의 Premiere 버전·구독 플랜·PC는 미확인이다. 기존 편집 환경을 유지할 후보이지만, 검색·전사 기능과 AI Assistant 공개 베타를 나누어 평가한다.

## 기존 검색·전사 기능

> “Currently, visual search supports English language searches only.”
> — Adobe, [Media Intelligence 사용법](https://helpx.adobe.com/premiere/desktop/organize-media/file-organization/search-for-media-using-ai-powered-media-intelligence.html), 2026-10-24 확인

| 기준 | 공식 자료로 확인한 내용 |
|---|---|
| 장면 고르기 | 시각 묘사로 일치 구간을 찾아 소스 모니터·시퀀스로 가져온다. 검색 자체가 완성본을 자동 구성하는 것은 아니다. |
| 이어 붙이기 | Text-Based Editing은 대본의 문장을 복사·삭제·이동하면 타임라인에 적용한다. 작업자가 내용을 선택한다. |
| 한국어 | Speech to Text는 한국어 지원. 시각 검색은 영어 검색만 지원한다고 안내한다. 서로 다른 기능이다. |
| 꾸미기 | 자막 생성 후 일반 편집 도구로 제목·효과·색·소리를 다듬는 흐름이다. |
| 비용 | Speech to Text는 Premiere 구독에 포함. 의뢰인의 추가 구독 필요 여부는 미확인이다. |
| 영상 처리 | Media Intelligence 분석·검색은 로컬. 고정 업로드 한도 대신 PC 성능·원본 포맷·버전을 확인해야 한다. |

근거: [Media Intelligence FAQ](https://helpx.adobe.com/premiere/desktop/organize-media/file-organization/media-intelligence-and-search-panel.html), [텍스트 기반 시퀀스 편집](https://helpx.adobe.com/premiere/desktop/edit-projects/edit-video-using-text-based-editing/edit-sequences-using-text-based-editing.html), [Speech to Text 요금·언어·오프라인 안내](https://www.adobe.com/products/premiere/speech-to-text.html). 검색·전사만으로 「행사 전체를 보고 좋은 3분을 자동 완성」한다고 판단할 근거는 확보하지 않았다.

## 공식 AI Assistant 공개 베타

Adobe의 [AI Assistant FAQ](https://helpx.adobe.com/premiere/desktop/premiere-ai-assistant/assistant-faq.html)는 자연어 지시로 프로젝트 정리와 첫 편집본·stringout 조립을 수행하며, 결과가 편집 가능한 Premiere 시퀀스로 나온다고 설명한다. 공개 베타이며 영어에 최적화되어 있고, 접근 가능한 사용자에게 베타 전용 일일 크레딧을 제공한다. 버전별 제공 조건과 의뢰인의 접근 가능 여부는 미확인이다.

기존 Media Intelligence와 달리 일부 Assistant 도구는 클라우드에 미디어를 보낸다. FAQ상 versioning·cut-downs는 아직 제공되지 않으므로, 「긴 행사 → 정확히 3분 하이라이트 → 수정 지시」가 끝까지 된다고 확정하지 않는다. 별도 플러그인 없이 시도할 후보라는 판단은 공식 기능을 바탕으로 한 **조사자의 추론**이다.

## 후속 검증

1. 의뢰인의 정식 Premiere와 베타 버전·Assistant 접근 여부를 확인한다.
2. 의뢰인 계정에서 함께 볼 경우, 공개 가능한 시험 영상으로 검색 구간과 첫 편집본을 확인한다.
3. 한국어 음성·영어 시각 검색·한국어 Assistant 지시는 따로 평가한다.
4. 3분 구성, 말 없는 장면, 수정 지시, 외부 서버 전송 여부를 기록한다.

Premiere 체험이나 신규 결제는 하지 않았다. 사용 매뉴얼의 실제 화면·클릭 순서는 아직 검증되지 않았다.
