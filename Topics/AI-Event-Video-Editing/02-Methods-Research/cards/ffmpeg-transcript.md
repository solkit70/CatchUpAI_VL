## 요약

**범주 E · 확인일 2026-10-24 · 자료로만 / 이번 Topic 실습 안 함.** 전사와 장면 메모로 편집 계획을 만든 뒤 FFmpeg가 구간을 잘라 영상으로 만드는 조합이다. 기존 사용 경험이 있다는 M1 기록을 이번 Topic의 실습 성공으로 바꾸지 않는다.

## 역할과 한계

| 단계 | 하는 일 | 확인할 점 |
|---|---|---|
| 전사 | 발언을 타임스탬프가 있는 글로 변환 | 말 없는 시상·공연·표정은 전사만으로 찾을 수 없음 |
| AI 편집 계획 | 어떤 원본의 어느 구간을 어떤 순서로 쓸지 결정 | 영상 관찰·장면 메모가 없으면 실제 장면을 추측할 수 있음 |
| FFmpeg | 지정 구간 자르기·연결·인코딩 | 자연어 의미를 판단하는 편집 에이전트 자체는 아님 |

[FFmpeg 문서](https://ffmpeg.org/ffmpeg.html)는 `-ss` 탐색과 시간·길이 제어를 설명하고, [공식 FAQ](https://ffmpeg.org/faq.html)는 concat 방식들을 안내한다. Stream copy와 재인코딩은 컷 정확도·호환성 조건이 달라 한 줄 명령만으로 프레임 단위 결과를 보장하지 않는다.

## 비용·언어·입력·Premiere

FFmpeg 자체는 오픈소스이며 [공식 라이선스 설명](https://ffmpeg.org/legal.html)에 빌드별 LGPL/GPL 조건이 있다. 로컬 컷 편집에는 원본 업로드가 필수가 아니지만, 전사·AI 판단을 클라우드에 맡기면 별도 비용과 데이터 전송이 생긴다. 고정 서비스 업로드 한도 대신 저장공간·코덱·처리시간을 확인해야 한다.

전사 예로 [OpenAI File transcription](https://developers.openai.com/api/docs/guides/speech-to-text)은 API 업로드 25MB 한도와 큰 파일의 분할을 안내한다. API의 `whisper-1`은 종료 예정 모델로 안내되어 있으므로 새 매뉴얼을 그 모델에 고정하지 않는다. 이 API 안내를 로컬 오픈소스 Whisper의 한도나 종료로 해석하지 않으며, 전사 모델·한국어 품질·전체 비용은 별도 선택·검증한다.

Premiere에는 출력 영상·개별 클립·자막 파일을 가져올 수 있는 흐름을 설계할 수 있지만, **이 조합 자체가 편집 가능한 Premiere XML을 자동 제공하는 것은 아니다.** 타임라인 전달은 별도 구현·검증 항목이다.

## 이 Topic에서의 판단

명시한 구간과 길이를 재현하는 비교 기준으로 유용하지만, 의뢰인이 코드 없이 반복 사용하기에는 추가 도구가 필요하다. 이는 문서 기반 판단이며, M4에서 동일 원본·지시·구간 기록으로 실제 비용과 손볼 양을 비교할 때 검증한다.
