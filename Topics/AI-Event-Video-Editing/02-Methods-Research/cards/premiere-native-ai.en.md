## Existing search and transcription features

> “Currently, visual search supports English language searches only.”
> — Adobe, [How to use Media Intelligence](https://helpx.adobe.com/premiere/desktop/organize-media/file-organization/search-for-media-using-ai-powered-media-intelligence.html), checked 2026-10-24

| Criterion | What official documentation shows |
|---|---|
| Selecting scenes | Finds matching segments from a visual description and brings them into the source monitor or sequence. Search by itself does not build a finished piece automatically. |
| Assembling | In Text-Based Editing, copying, deleting or moving sentences in the transcript applies to the timeline. The editor chooses the content. |
| Korean | Speech to Text supports Korean. Visual search is described as supporting English searches only. These are different features. |
| Finishing | After captions are generated, titles, effects, color and sound are refined with the general editing tools. |
| Cost | Speech to Text is included in the Premiere subscription. Whether the client needs an extra subscription is unverified. |
| Video processing | Media Intelligence analysis and search are local. Instead of a fixed upload limit, PC performance, source format and version need checking. |

Evidence: [Media Intelligence FAQ](https://helpx.adobe.com/premiere/desktop/organize-media/file-organization/media-intelligence-and-search-panel.html), [Text-based sequence editing](https://helpx.adobe.com/premiere/desktop/edit-projects/edit-video-using-text-based-editing/edit-sequences-using-text-based-editing.html), [Speech to Text pricing, languages and offline guidance](https://www.adobe.com/products/premiere/speech-to-text.html). I have no evidence to conclude that search and transcription alone "watch the whole event and automatically complete a good 3 minutes."

## Official AI Assistant public beta

Adobe's [AI Assistant FAQ](https://helpx.adobe.com/premiere/desktop/premiere-ai-assistant/assistant-faq.html) explains that it organizes projects and assembles a first cut / stringout from natural-language instructions, and that the result comes out as an editable Premiere sequence. It is a public beta, optimized for English, and gives users with access beta-only daily credits. The conditions by version and whether the client has access are unverified.

Unlike the existing Media Intelligence, some Assistant tools send media to the cloud. Per the FAQ, versioning and cut-downs are not yet offered, so I do not conclude that "long event → exactly 3-minute highlight → revision instructions" works end to end. The judgment that it is a candidate to try without a separate plugin is **the researcher's inference** based on the official features.
