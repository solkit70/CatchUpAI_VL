## Features and delivery path

The [Long video to short tool](https://www.capcut.com/tools/ai-long-video-to-short-video) describes highlight detection, short clip generation and length selection. The [auto caption help](https://www.capcut.com/help/how-to-recognise-subtitles) explains how it works on web, desktop and mobile, and the differences by region and version. **Generating several short clips is different from building one landscape 3-minute event video**, so the latter has to be checked with real source footage.

| Criterion | Current judgment |
|---|---|
| Scene selection | Automatic highlight feature is described. Accuracy for Korean natural-language instructions and event scenes without speech is not verified |
| Assembling · finishing | Candidate for checking follow-up editing and captions in the existing editor. Not assumed to be automatic up to completion |
| Premiere handoff | Importing the output video is included in the verification plan. Handoff of an editable timeline was not confirmed in the official documentation this time |
| Korean | Korean video, instructions and captions each need practice; I do not conclude it supports them all just from the "20+ languages" claim |
| Video / file limits | Maximum length and size per feature, platform and account unverified |
| Data | Web tools are an upload path. I do not assume desktop AI is all processed locally either |

## Pricing and free scope

The [official pricing page](https://www.capcut.com/pricing) separates Free basic editing from paid plans, but states that the displayed prices are for reference and that the final price, tax and benefits should be checked after logging in. This lookup was displayed in KRW, so I did not use it as a USD quote for a US account. Subscription names, the account and AI usage per feature also need to be checked together.

**The fact that free basic editing exists is kept separate from any claim that the wanted AI features, delivery quality and watermark-free output are free.** First check whether it can be tried without a card and what the actual export screen shows. If paid features are required, stop the hands-on trial and keep it as an item to check together in the client's account.

## Judgment for this Topic

Because it is a tool the client is familiar with, its research and check priority is raised. If moving the result to Premiere is required, first check whether a normal output video is enough, or whether individual cuts and captions need to keep being edited. It is not finally recommended just because it is a tool already in use.
