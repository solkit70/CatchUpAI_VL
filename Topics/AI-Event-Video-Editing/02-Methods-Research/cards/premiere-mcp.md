## 요약

**범주 A · 확인일 2026-10-24 · 자료로만 / 설치·직접 체험 안 함.** 여러 동명 프로젝트 중 `leancoderkavy/premiere-pro-mcp`를 조사했다. Adobe 공식 Assistant와 다른 커뮤니티 프로젝트이며, 저장소 설명은 실제 의뢰인 환경에서의 검증 결과가 아니다.

> “independent, local-first server for supported workflows”
> — [프로젝트 작성자 README](https://github.com/leancoderkavy/premiere-pro-mcp), 2026-10-24 확인

## 기능·조건

| 기준 | 작성자 자료로 확인한 내용과 남은 조건 |
|---|---|
| 연결 | 로컬 MCP 서버와 Premiere CEP 연결 패널을 각각 설치한다. |
| 편집 | 프로젝트·타임라인 조회와 지원되는 컷·효과·내보내기 조작 도구를 제공한다. |
| 자동 판단 | 도구가 존재하는 것과 AI가 좋은 장면을 고르는 것은 별개다. 전사·장면 설명 등 근거가 필요하다. |
| Adobe AI | 작성자는 Speech-to-Text 시작 등 일부 Adobe AI 작업을 사용자 보조·미지원으로 구분한다. 모든 Premiere AI 기능을 직접 호출한다고 보지 않는다. |
| 버전 | 권장 로컬 구성은 같은 PC의 Premiere·브리지·MCP 클라이언트. README는 Premiere 2020–2026을 안내하지만 실제 호환성은 미검증이다. |
| 비용 | 저장소의 MIT 라이선스 표시와 별개로 Premiere·AI 클라이언트 비용이 든다. 도구 설치 자체를 구독 포함으로 가정하지 않는다. |
| 한도·한국어 | 고정 업로드 한도는 제시하지 않는다. PC 성능·클라이언트 모델과 컨텍스트에 좌우되며 한국어 명령 품질은 미확인이다. |

근거는 [작성자 README의 Quick Start·AI feature boundaries·Technical Details](https://github.com/leancoderkavy/premiere-pro-mcp)다. 같은 이름의 다른 패키지와 설치 방법을 섞지 않으며, 지원된다고 적힌 버전도 의뢰인 PC에서 확인할 사항으로 둔다.

## 이 Topic에서의 판단

Premiere 안의 편집 가능한 타임라인을 유지하는 이점이 있지만 설치와 문제 해결 부담이 크다. 이는 문서 기반 추론이며, [Premiere 공식 Assistant](premiere-native-ai.md#공식-ai-assistant-공개-베타)로 부족한 작업이 무엇인지 확인한 뒤 비교할 후보로 둔다.

연결을 시험한다면 복사한 프로젝트에서 읽기 전용 연결 확인부터 수행한다. 이 문서는 설치 매뉴얼이 아니며, 해당 도구로 컷·효과·내보내기가 성공했다는 실습 증거는 아직 없다.
