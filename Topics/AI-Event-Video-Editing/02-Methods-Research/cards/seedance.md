## 기능과 기존 설명 정정

공식 페이지는 한 번에 최대 30초 생성과 참조 영상 기반 편집을 안내한다. 따라서 M1에서 쓴 **「생성형이라 촬영본 편집은 못 한다」는 단정은 수정**한다. 다만 수시간 촬영본을 검색해 실제 장면을 고르고 3분으로 조립하는 행사 편집 기능은 이번 자료에서 확인하지 못했다. [공식 모델 설명](https://seed.bytedance.com/en/seedance2_5)

이 Topic에서는 인트로·짧은 보조 장면·참조 편집 후보로 분류한다. 실제 행사 기록을 골라 보존하는 컷 편집과 생성·변형된 장면을 만드는 일은 구분하며, 긴 영상 자동 편집의 대체재라는 추천은 하지 않는다.

## 가격·출력·연계

| 항목 | 공식 자료 확인 결과 |
|---|---|
| 가격 예시 | 영상 참조 없이 16:9·720p·5초 생성의 추정 $1.156/개. 월 구독 가격이 아님 |
| 과금 | 토큰 기반. 해상도·원본 참조 영상·생성 길이 등에 따라 달라짐 |
| 길이 | ByteDance 모델 페이지의 단일 생성 최대 30초 |
| 무료 체험 | 의뢰인 지역·계정의 무료량, 카드 필요 여부 미확인 |
| 한국어 | 지시·음성·화면 글자의 정확도 미검증 |
| Premiere | 영상 파일을 가져오는 경로를 예상하나 타임라인 XML·편집 가능한 효과 전달은 미확인 |

가격 근거: [BytePlus 공식 요금 문서의 Seedance 2.5 예시](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/model-pricing). API 비용과 외부 서비스 구독은 다르며, 반복 생성·폐기한 시도까지 고려해야 실제 비용이 나온다. 입력 파일 한도·상업 이용·콘텐츠별 조건은 이용할 서비스에서 별도 확인한다.

**리뷰 후 재확인(2026-10-24)**: 공식 요금 본문의 「Input without video」「720p」「16:9」「5초」행에서 $1.156 예시를 다시 대조했다. 사용자 본인의 확인이나 실제 API 청구 검증은 아직 하지 않았다. [중요 수치 검증 기록](../review-followup.md#중요-수치-재확인)
