## 요약과 적용 범위

**2026-10-24 자료 조사 · 5개 범주·9개 후보 · 직접 체험 0건 · 의뢰인 답변 미확인.** 리뷰 후 CapCut을 추가하고 중요 가격을 원문·화면으로 재검증했다. [전체 후보 상태와 검증 기록](review-followup.md#m1-후보-전체-대조)을 함께 읽는다. 지원 설명과 실제 품질을 구분하고, 공개 자료로 확인하지 못한 값은 미확인으로 남겼다. 아래 판단은 최종 추천이나 실습 점수가 아니다.

## 기능 비교

| 범주·후보 | 장면 고르기 | 이어 붙이기 | 꾸미기 | Premiere 전달 | 중요한 제약 |
|---|---|---|---|---|---|
| C · [Premiere 자체 AI](cards/premiere-native-ai.md#요약) | 시각·대본 검색, 베타 Assistant 조립 | 정식 텍스트 편집 / 베타 첫 편집본 | 일반 편집 기능 | 편집 가능한 시퀀스 | 버전·Assistant 접근, 정확한 3분 결과 미검증 |
| C · [CapCut AI](cards/capcut-ai.md#요약) | 자동 하이라이트, 지시 품질 미검증 | 클립 생성·일반 편집 | 자동 자막 등 | 영상 출력, 타임라인 전달 미확인 | 플랫폼·지역·플랜별 무료 AI 범위와 가로 3분 구성 확인 |
| B · [Vidio.ai / VibeEdit](cards/vidio-vibeedit.md#요약) | 프롬프트 선택 | 목표 길이·순서·채팅 수정 | 음악·타이틀 등 | XML·원본 재연결 | XML에 자막·전환 등 꾸미기 전체가 안 넘어옴 |
| B · [OpusClip / ClipAnything](cards/opusclip-clipanything.md#요약) | 시각·음성·감정 기반 클리핑 | 클립 생성, 한 편의 행사 구성은 미검증 | 자막·리프레이밍 등 | Pro XML·SRT | 무료 체험 효과 제한, XML 길이 안내 확인 필요 |
| A · [Premiere MCP](cards/premiere-mcp.md#요약) | AI가 쓸 전사·장면 근거 필요 | 지원되는 Premiere 작업 조작 | 지원 도구 범위 내 | Premiere 내부 | 커뮤니티 도구, 설치·API 지원·호환성 미검증 |
| B · [Memories.ai VEA](cards/memories-vea.md#요약) | 개요는 긴 영상 이해·하이라이트 | 개요는 조립, 관리형 API는 길이 직접 지정 불가 | 개요상 음악·자막 | 개요의 FCP XML, API 동일 지원은 미확인 | VEA 개요·관리형 API·완성형 웹 도구를 혼동하지 않음 |
| D · [Seedance](cards/seedance.md#요약) | 수시간 영상 구간 선택 미확인 | 짧은 영상 생성·참조 편집 | 인트로·보조 장면 후보 | 출력 영상, XML 미확인 | 생성·참조 편집과 기록 영상의 컷 편집 구분 |
| E · [FFmpeg + 전사](cards/ffmpeg-transcript.md#요약) | 전사·장면 메모로 별도 판단 | 지정 구간·길이 제어 | 필터·별도 코드 구성 | 영상·개별 클립, XML은 별도 구현 | 말 없는 장면은 전사만으로 선택 불가 |
| E · [Remotion](cards/remotion.md#요약) | 별도 분석 필요 | 코드·프레임 기반 조립 | 반복 인트로·자막·로고 | 렌더 영상, 코드 효과는 별도 | 코딩 부담·조직/협업 라이선스 조건 |

각 행의 링크는 원본 조사 카드의 요약 절이다. 세부 근거는 카드 본문의 공식 링크를 따른다. A는 연결 방식, B는 편집 서비스·시스템, C는 기존 프로그램, D는 생성·참조 편집, E는 코드 기반 방식이다. 한 도구가 여러 역할을 할 수 있으나 비교용 주 범주로 세었다.

## 비용·무료 체험·입력 한도

| Premiere | 전사는 구독 포함, Assistant는 베타 전용 크레딧 | 로컬 PC 성능·버전·베타 접근·클라우드 기능 범위 |
| CapCut | Free 기본 편집과 유료 플랜. 계정 최종 가격 미확인 | 지역·앱·기능별 AI 제공량·길이·내보내기 조건 확인 |
| Vidio | Pro 20 월 $10 / 연 $96(환산 $8). Business 400 월 $50 / 연 $480(환산 $40) | Free 총 10분·1GB, Pro 총 60분·4GB. 원본 1시간 일반 AI edit 108크레딧 |
| OpusClip | Starter 월 $15, XML 포함 Pro 월 $29 / 연 $174 | Free 월 60크레딧, 체험은 기능 제한. 원본 처리 분량·XML 길이 조건 별도 |
| Premiere MCP | 저장소 MIT 표시, Premiere·AI 비용 별도 | 고정 업로드량보다 PC·클라이언트·지원 기능. 무료 설치와 무료 실무를 구분 |
| VEA | 관리형 Edit Video API $0.15/분 표시 | 색인·저장 등 합계와 과금 대상 길이·최대 파일 한도·무료량 미확인 |
| Seedance | BytePlus 예시: 참조 영상 없이 720p·16:9·5초 추정 $1.156 | 토큰·해상도·참조에 따라 변동. 단일 생성 최대 30초, 무료량·입력 한도 미확인 |
| FFmpeg + 전사 | FFmpeg 자체 오픈소스, AI·전사 비용 별도 | 로컬 자원, 선택한 API 한도·한국어 품질. 서버 API와 로컬 전사 조건 구분 |
| Remotion | 개인·3명 이하 회사 Free License, 협업·규모 조건 별도 | Creators 월 $25/좌석 / Automators 최소 월 $100. 적용 형태 확인 필요 |

금액은 USD이며 세금·추가 서비스·재시도 비용을 포함한 견적이 아니다. 자료별 과금 단위가 달라 가격 순위를 매기지 않는다. 상세 출처와 유보 사항: [Vidio 가격 절](cards/vidio-vibeedit.md#가격과-입력-한도), [OpusClip 가격 절](cards/opusclip-clipanything.md#가격무료-체험처리량), [VEA 비용 절](cards/memories-vea.md#비용한도한국어), [Seedance 가격 절](cards/seedance.md#가격출력연계), [Remotion 라이선스 절](cards/remotion.md#비용과-라이선스).

## 한국어·데이터·실제 검증

| 후보 | 한국어 확인 범위 | 데이터 경로 / 체험 실적 |
|---|---|---|
| Premiere | 전사 지원 / 시각 검색 영어 / Assistant 영어 최적화 | 검색 로컬, Assistant 일부 클라우드 / 자료로만 |
| Vidio | 지시·음성·자막 범위 미확인 | 업로드 / 자료로만 |
| OpusClip | 영상 언어 한국어 베타, 한국어 지시 미검증 | 업로드 / 자료로만 |
| Premiere MCP | 클라이언트 이해와 한국어 작업 결과 별도 | 브리지는 로컬, AI에 전달할 정보는 설정에 따라 다름 / 자료로만 |
| VEA | 관리형 API 영어 권장, 다른 언어 보장 안 함 | 업로드·webhook / 자료로만 |
| Seedance | 지시·음성·글자 정확도 미검증 | 사용 서비스·API에 전송 / 자료로만 |
| CapCut | 지시·한국어 자막 품질 미검증 | 웹은 업로드, 데스크톱 AI 처리도 확인 필요 / 자료로만 |
| FFmpeg + 전사 | 선택한 전사기·모델·폰트에 의존 | 로컬 가능, 클라우드 조합 시 전송 / 이번 Topic 미체험 |
| Remotion | 한국어 폰트·줄바꿈·실제 렌더 미검증 | 로컬 또는 선택한 렌더 환경 / 이번 Topic 미체험 |

한국어 자막을 지원한다는 사실은 한국어 장면 선택 지시의 정확도를 뜻하지 않는다. 사용자 원본을 올릴 수 있는지, 어떤 계정을 쓸지, 유료 도구를 함께 볼지는 여전히 미확인이다. [M1 질문](../01-Requirements-Map/client-questions.md#보낼-메시지)의 답을 받은 뒤 적용 조건을 좁힌다.

## 범주별 한 줄 판단

- **A 연결 도구**: Premiere를 조작할 경로는 있으나, 지원 API와 장면 선택 근거가 작업 품질을 결정한다. → [연결 방식 분석](claude-chatgpt-plugins.md#되는-것과-아직-증거가-없는-것)
- **B 편집 시스템**: Vidio·OpusClip·VEA는 요구에 가까운 부분이 있지만, 길이·언어·효과 전달·총비용이 다르다. → [기능 비교](#기능-비교)
- **C 기존 프로그램**: 이미 쓰는 Premiere의 검색·전사·공식 Assistant 베타를 먼저 비교할 이유가 있다. 의뢰인의 접근 조건은 아직 모른다. → [Premiere 카드](cards/premiere-native-ai.md#후속-검증)
- **D 생성·참조 편집**: 인트로·보조 장면 후보이며, 수시간 원본의 실제 장면을 고르는 기능과 구분한다. → [Seedance 정정](cards/seedance.md#기능과-기존-설명-정정)
- **E 코드 방식**: 재현 가능한 길이·반복 템플릿에 유리할 가능성이 있으나, 사용 편의성과 유지보수는 체험으로 확인한다. → [FFmpeg 판단](cards/ffmpeg-transcript.md#이-topic에서의-판단)·[Remotion 판단](cards/remotion.md#이-topic에서의-판단)

## M3에서 확인할 조건

[M3 조건부 추천](../03-Recommendation/recommendation.md#작업-흐름)은 기존 Premiere·CapCut 확인 → Vidio 비교·OpusClip 대안 → 기존 인트로 틀이다. 최종 도입을 확정한 것은 아니며, 계정·영상·일정은 [체험 계획](../03-Recommendation/test-plan.md#시험-준비-상태)에서 미확정으로 유지한다.

| 미확인 항목 | 선택에 미치는 영향 |
|---|---|
| OS·Premiere 버전·플랜·베타 접근 | 자체 AI·MCP 사용 가능 여부 |
| 원본 길이·카메라·화질 | 입력 한도·처리비용·XML 분할 |
| 납품 화면비·좋은 완성본 예시 | 숏폼 클립과 행사 몽타주 중 무엇이 필요한지 |
| 예산·외부 업로드 허용 | 유료·클라우드 후보 적용 여부 |
| 진행 방식·설치 수용도 | 의뢰인 직접 사용·함께 체험·자료 전달의 범위 |
