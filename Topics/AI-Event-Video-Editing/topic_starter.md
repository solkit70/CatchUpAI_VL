# VibeLearn AI Topic Starter

> 이 파일은 새로운 Topic 학습을 시작할 때 작성하는 템플릿입니다.
>
> **사용 방법**:
> 1. 이 파일을 복사하여 `[TopicName]_topic_starter.md`로 저장
> 2. 아래 항목들을 채워서 작성
> 3. AI에게 이 파일을 전달하여 Topic 폴더 구조 생성 요청
> 4. 생성된 폴더에서 학습 시작!

## 📌 Topic 기본 정보

### Topic 이름
**형식**: 영문, 하이픈 또는 언더스코어 사용 (공백 없음)
**예시**: `MCP-Basics`, `Docker_Fundamentals`, `FastAPI-Tutorial`

```
Topic 이름: AI-Event-Video-Editing
```

### Topic 설명
**목적**: 이 Topic이 무엇인지 한두 문장으로 설명

```
설명: 단체 행사를 몇 시간씩 촬영한 영상을, AI 에게 「이런 장면으로 3분 영상을 만들어 줘」라고 지시해서
원하는 부분만 골라 짧은 하이라이트 영상으로 편집하고, 인트로 · 중간 효과까지 넣는 방법을 리서치한다.
지금 Premiere · After Effects · CapCut 으로 수작업 편집을 하는 행사 촬영 전문가(의뢰인)가 실제로
쓸 수 있는 방법을 찾아 추천하고, 설치 · 사용 매뉴얼을 만든다.
```

### 학습 목적
**왜 이것을 배우는가?**

```
학습 목적:
- 의뢰인(행사 사진 · 동영상 촬영을 하는 기자)이 몇 시간짜리 행사 영상을 AI 지시만으로 3분 하이라이트로 만드는 방법을 찾는다
- Claude · ChatGPT 에 영상 도구를 연결하는 방식(의뢰인이 언급한 「시덴스(Seedance로 추정)」 같은 플러그인 · 연결)과 그 밖의 방법(영상 편집 전용 AI, 기존 Premiere · CapCut 의 AI 기능, 코드 기반 편집)을 비교한다
- 비즈니스용이라 유료도 괜찮으므로, 비용 대비 실제로 일을 줄여 주는 방법을 추천한다
- 추천 방법의 설치 · 사용 매뉴얼을 의뢰인이 혼자 따라 할 수 있는 수준으로 만든다 (무료 체험이 되면 박창수가 직접 해 보고 반영)
```

### 예상 학습 기간
**현실적으로 예상되는 기간**

```
예상 기간: 2주 (주당 5~6시간)
```

## 🎯 학습 목표

**이 Topic을 완료했을 때 달성하고 싶은 구체적 목표**

```
- [ ] 「긴 행사 영상 → AI 지시 → 3분 하이라이트 + 효과」를 할 수 있는 방법을 5가지 이상 찾아 기능 · 비용 · 난이도 · 한국어 지원으로 비교표를 만든다
- [ ] 의뢰인이 언급한 「Claude · ChatGPT + 플러그인(Seedance 등)」 방식이 실제로 무엇을 할 수 있고 무엇은 못 하는지 설명할 수 있다
- [ ] 의뢰인의 작업 흐름(Premiere · After Effects · CapCut)에 맞는 추천안 1~2개를 이유와 함께 고른다
- [ ] 추천 방법 중 무료 체험이 되는 것을 박창수가 직접 해 보고, 그 결과를 넣은 단계별 설치 · 사용 매뉴얼을 만든다
- [ ] 유료 방법은 의뢰인이 따라 할 수 있는 매뉴얼과 참조 링크(공식 문서 · 튜토리얼 영상)를 정리한다
```

**권장**: 3-5개의 명확하고 검증 가능한 목표

## 🛠️ 학습 환경

### 운영 체제
```
OS: Windows 11 (박창수 실습 PC — i7-1355U · 16GB RAM · GPU 없음)
버전: 의뢰인은 **Adobe Premiere Pro 를 쓴다**(10/17 확인 — Adobe 구독 중으로 보임). PC 사양 · OS(Windows / Mac)는 확인 필요
```

### 주요 도구 및 기술 스택
**이 Topic 학습에 필요한 도구들**

```
- 의뢰인이 지금 쓰는 도구: Adobe Premiere Pro · After Effects · CapCut
- 조사 대상 (리서치에서 확정): Claude · ChatGPT 와 연결하는 영상 도구 · 플러그인, 영상 편집 전용 AI 서비스,
  Premiere · CapCut 에 들어간 AI 기능, 전사(Transcript) 기반 편집 도구, 코드 기반 편집(Remotion · FFmpeg)
- 체험용: 무료 체험이 되는 서비스 계정, 샘플 행사 영상 (박창수가 녹화한 세미나 · 모임 영상)
```

### 사전 지식 (Prerequisites)
**이 Topic을 학습하기 전에 알아야 할 것**

```
필수:
- 영상 편집 기본 개념 (컷 · 트랙 · 전환 · 자막 · 렌더) — 의뢰인은 이미 능숙하다
- 클라우드 서비스 가입 · 파일 업로드

권장:
- 전사(Transcript) · 자막 파일(SRT)의 개념
- 박창수의 Remotion · FFmpeg 영상 제작 경험 (코드 기반 편집 비교용)
```
