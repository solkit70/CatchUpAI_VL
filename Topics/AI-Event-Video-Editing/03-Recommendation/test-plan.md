## 목적과 현재 상태

사용자가 지정한 연속 발표 촬영본으로 발표 경계 찾기와 실제 편집 시간을 비교한다. 원본 묶음과 첫 5분 시험 구간을 정하고 기존 영어 전사본·표본 화면을 대조해 [로컬 분리 초안 7개](../04-HandsOn-Highlight/method-A.md#발표-구간표)를 생성했다. 2026-10-25 사용자는 지정 5분 샘플만 Vidio 또는 OpusClip 업로드를 허용했다. 이후 Vidio Free에 해당 사본을 올리고 한국어 지시로 첫 편집과 수정 요청을 실행했다. v1 파일은 실측 126.912초·1280×720으로 확인했고 수정 v2는 UI 1:13으로 목표에 미달했다. 새 서비스 가입·전체 원본 업로드·전체 원본 청취 검수는 실행하지 않았다. 두 경계 주변의 짧은 음성 74초는 캐시된 로컬 Whisper medium으로 추가 점검했다. M3는 두 체험 방법 접근 미확인으로 6/7이며 전체 완료는 아니다.

## 시험 준비 상태

| 항목 | 상태·결정 기준 |
|---|---|
| 영상 | 사용자 지정 2026-09-08 GitHub 행사 촬영본 5개. 아래 목록의 원본 묶음 선정 완료, 첫 시험 구간은 IMG_5252.MP4 25:00~30:00으로 선정 |
| 허용 범위 | 2026-10-25 사용자 승인: IMG_5252.MP4 25:00~30:00의 5분 사본만 Vidio 또는 OpusClip 업로드 허용. 전체 원본·다른 영상은 미허용 |
| 짧은 시험본 | IMG_5252.MP4 25:00~30:00. 발표→질문 전환 후보 27:32 포함. 발표자 교체 시험과는 구분 |
| 긴 원본 검증 | 짧은 시험 후 총 약 2시간 1분의 5개 파일로 확장. 촬영 순서·중복·누락을 확인한 뒤 발표별 분리 |
| 작업 기준 | 수동 편집 기준 시간 또는 최근 작업 기록 미확인. 없으면 같은 구간을 수동으로 편집해 비교 |
| 계정·앱 | Premiere·CapCut 버전·유료 기능 접근 미확인, Vidio·OpusClip 무료 가입·기능 미확인 |
| 평가자·일정 | 진행자 1차, 의뢰인 결과 선호 확인. 실제 일정은 미정 |

사용자는 한 행사에서 여러 발표를 연속 촬영했으며 발표마다 시작·끝이 명확하지 않다고 설명했다. 발표별 재편집 또는 원래 목표인 1~3분 요약에 이 영상을 사용하도록 지정했다. 지정 5분 사본만 외부 서비스 시험에 허용됐으며 나머지 원본의 업로드는 미확인이다. [두 번째 방법 준비와 접근 기록](../04-HandsOn-Highlight/method-B.md#현재-결과)을 따른다. 공개 문서에는 사용자명이 포함된 절대 경로를 기록하지 않는다.

## 지정 원본과 우선 실습

아래는 2026-10-24 로컬 ffprobe 조회 결과다. 파일명 순서는 확인용 목록이며 실제 촬영 순서·발표 순서로 확정한 것이 아니다. 모든 파일에 오디오와 1280×720 영상 스트림이 있으며 화면 방향은 아직 확인하지 않았다.

| 파일 | 길이(반올림) | 용량(십진 GB) |
|---|---|---|
| IMG_5249.MP4 | 5분 20초 | 0.144 |
| IMG_5250.MP4 | 22분 47초 | 0.610 |
| IMG_5251.MP4 | 22초 | 0.010 |
| IMG_5252.MP4 | 37분 03초 | 0.993 |
| IMG_5253.MP4 | 55분 38초 | 1.492 |

합계 7,269.29초(약 2시간 1분 9초), 3.249GB다. 동반 info.txt의 행사 안내는 발표 순서 확인의 보조 자료로만 사용하고 실제 촬영 내용과 일치한다고 가정하지 않는다.

1. **발표 구간표 먼저:** 파일별 앞뒤와 전환 후보를 확인하고 소개 멘트·화자 교체·슬라이드·박수를 함께 보아 발표 시작과 끝을 찾는다. 단순 침묵이나 화면 전환만으로 발표 교체를 확정하지 않는다.
2. **발표별 분리:** 구간표에 원본 파일명·파일 내 시작/끝·발표자/주제 근거·확신도·확인 필요 사항을 기록한다. 한 발표가 여러 파일에 걸치면 연결 후보로 묶고 중복·누락을 표시한다. 이름을 모르면 발표 A/B로 두며 질문·답변의 포함 여부도 기록한다.
3. **요약은 후속:** 구간표를 검토한 후 발표 하나 또는 행사 전체를 대상으로 1~3분 요약을 만든다. 발표별 전체 영상과 요약본은 별도 결과물로 구분한다.

첫 산출물은 재생 가능한 최종 영상보다 검토 가능한 발표 구간표를 우선한다. 원본은 보존하고 분할 파일은 별도 출력하며, 실제 영상 제작 전 로컬 출력 위치를 정한다.

## 잠정 시험 경로

| 경로 | 먼저 확인할 일 | 진행 조건·분리할 결과 |
|---|---|---|
| A. Premiere / CapCut | 이미 쓰는 환경에서 검색·하이라이트·자막 접근 확인 | 유료 기능은 진행자가 직접 체험하지 않음. 의뢰인 화면에서 함께 볼 수 있을 때만 평가 |
| B. Vidio 미리보기 | 10분 이내 원본, 카드 없는 무료 기능 확인 | 카드 등록·결제를 요구하면 중단. 무료 미리보기와 XML·최종 출력은 별도 기록 |
| C. OpusClip 대안 | 카드 없는 시험과 필요한 화면비·지시 기능 확인 | B가 맞지 않거나 클립 비교가 필요할 때 대체. 무료 제공 범위를 추측하지 않음 |

이 표는 계정·원본 확인 전의 잠정 목록이다. 무료로 실제 접근 가능한 두 경로를 정한 뒤 M4 비교를 시작하며, 조건이 안 맞으면 새 결제 없이 계획을 조정한다.

## 발표 분리용 지시문

> 여러 발표가 연속 촬영된 원본입니다. 먼저 발표별 시작과 끝의 후보를 찾아 원본 파일명과 파일 내 시간을 표로 제시해 주세요. 파일 하나가 발표 하나라고 가정하지 마세요. 발표가 파일 사이에서 이어지거나 녹화가 빠진 경우 표시해 주세요. 소개 멘트, 발언 내용, 화자와 슬라이드 변화를 근거로 적고 애매한 경계와 발표자 이름은 미확인으로 남겨 주세요. 주요 발언이나 질의응답을 임의로 삭제하지 마세요.

분리 평가에서는 누락·중복·문장 중간 절단·질의응답 연결·경계 수정 시간과 사람이 확인한 경계를 기록한다. 전사만으로 정한 후보와 화면·음성으로 확인한 경계를 구분하며, 분리 기능이 없는 도구는 해당 시험을 미지원으로 기록한다.

## 요약용 공통 지시문

아래 문구는 **시험용 초안**이며 의뢰인의 최종 납품 요구가 아니다. 발언·장면이 실제 원본에 있는지 확인하고, 없는 항목은 모든 도구에서 같은 방식으로 바꾼다.

> 이 행사 촬영본에서 실제로 찍힌 장면만 사용해 가로 16:9, 1~3분의 하이라이트를 만들어 주세요. 핵심 발언, 행사 분위기, 시상 또는 주요 프로그램, 마무리를 포함해 주세요. 긴 침묵과 반복 장면은 줄이고, 주요 발언의 뜻이 달라지지 않게 해 주세요. 새 행사 장면을 생성하지 마세요. 지원하지 않는 작업은 알려 주세요.

한국어 지시를 먼저 입력하고, 지원되지 않으면 의미가 같은 영어 번역으로 별도 실행한다. 번역 경로의 결과를 한국어 지시 성공으로 집계하지 않는다. 검색만 제공하는 도구에는 같은 요구를 검색어·선택 단계로 나눠 사용하고, 자동 처리 단계와 사람의 조작 시간을 각각 기록한다.

수정 시험은 「발언 부분을 줄이고 주요 프로그램 장면을 늘려 주세요」 한 가지로 통일한다. 꾸미기는 우선 제외해 장면 선택을 비교한 뒤, 동일 로고·행사명·음악 사용 조건으로 별도 평가한다.

## 평가표와 성공 기준

아래는 진행자가 제안한 비교 기준이며 실험 결과가 아니다. 원본과 의뢰인의 납품 예시를 확인하면 기준을 조정하고 모든 경로에 동일하게 적용한다.

| 평가 항목 | 기록할 값 | 제안 기준 |
|---|---|---|
| 지시 이행 | 요구한 구성 중 충족한 항목과 빠진 항목 | 실제 존재하는 필수 장면을 빠뜨리지 않는지 확인 |
| 길이·화면비 | 초 단위 길이·비율 | 비교 전에 60~180초 중 동일 목표 길이를 정하고 ±5초·16:9 기준과 조절 수작업을 기록 |
| 장면 정확도 | 원본 파일·구간·선정 이유 | 발언·말 없는 장면 각각의 적합성을 사람이 확인 |
| 발언·자막 | 의미가 달라진 편집·이름 오류·수정 건수 | 의미 왜곡은 수정 전 통과시키지 않음 |
| 시간 | 준비·업로드·처리 대기·수정·마무리 시간 | 능동 작업 시간과 전체 경과 시간을 따로 비교 |
| 수정 가능성 | 첫 결과와 수정 후 결과·추가 지시 횟수 | 동일 수정 요구를 반영하는지 확인 |
| Premiere 전달 | 컷·음악·자막·전환 중 유지/누락 항목 | 누락을 다시 만드는 시간 포함 |
| 비용·출력 | 사용량·결제 조건·화질·워터마크 | 실제 표시값 기록. 무료 미리보기만으로 납품 가능 판정 안 함 |

## 인트로 비교 — M5 준비

기존 After Effects·CapCut 템플릿의 행사명·날짜·로고 교체 시간을 기준으로 삼는다. 반복 템플릿이 필요하면 Remotion의 5~10초 인트로와 비교하며, 생성형 인트로는 사용 목적·비용·표기 조건이 정해질 때 별도 시험한다. 이 작업은 이번 계획 작성에 포함된 실제 제작이 아니다.

## 기록과 중단 기준

실제 시험 시 원본·버전·플랜·지시문·처리량·결과 파일을 재현할 수 있게 기록한다. 의뢰인 정보나 사용 허용이 확인되지 않은 영상은 공개 Topic 폴더에 저장하지 않는다. 외부 업로드 허용이 없거나 유료 기능이 요구되면 해당 경로를 보류하고 그 지점을 결과로 기록한다.
