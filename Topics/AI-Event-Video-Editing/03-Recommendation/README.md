## M3 — 조건부 추천안과 체험 준비

**상태**: 조건부 추천안·체험 계획 초안 작성. 원본·첫 시험 구간 선정, 로컬 경로와 Vidio Free 접근 확인. M3 DoD 7/7
**로드맵 예상 시간**: 2시간 (실제 학습 시간 아님)

의뢰인 답변이 늦어져도 상담에 쓸 수 있도록 현재 근거로 시험 순서를 좁혔다. 결과 품질을 평가한 추천이 아니라, 기존 도구를 먼저 확인하고 필요할 때 외부 편집 서비스를 비교하는 계획이다. 2026-10-25 Vidio Free에서 지정 샘플 업로드와 한국어 편집 요청을 실행해 첫 결과를 생성했다. 사용자 자기평가는 별개로 미실시다. 별도 요청으로 [로컬 발표 분리 초안](../04-HandsOn-Highlight/method-A.md)을 만들었다.

## 읽는 순서

1. [의뢰인용 한 장 요약](client-summary.md) — 개발 용어 없이 지금 확인할 것과 비용·한계를 읽는다.
2. [조건부 추천안](recommendation.md) — 두 작업 흐름과 대안, 가정·변경 조건·전달 흐름을 확인한다.
3. [체험 계획](test-plan.md) — 같은 원본·지시문·평가표로 비교할 방법과 미확정 준비물을 확인한다.
4. [M2 리뷰 반영](../02-Methods-Research/review-followup.md) — 가격 화면 대조와 누락 후보 처리 결과를 본다.
5. [M3 WorkLog](../vl_worklog/20261024_M3_AI-Event-Video-Editing.md) — 이번 결정·미완료 항목·다음 단계를 확인한다.

## 완료와 미완료

추천안·작업 흐름·준비 문서와 지정 원본·첫 5분 구간을 갖췄다. M3는 2026-10-25 로컬 방식과 Vidio Free의 실제 접근을 확인해 7/7로 갱신했다. [M4의 실제 시험 기록](../04-HandsOn-Highlight/method-B.md#실제-계정-접근과-1차-실행)에는 첫 결과와 무료 내보내기 확인 한계가 있다. M3 준비 완료는 M4 품질 검증이나 의뢰인 최종 추천 확정을 의미하지 않는다. 이 한 장 요약은 M6 최종 전달 때 실제 체험 결과로 갱신해 재사용한다.
