# 요구사항 카드 — 행사 촬영본을 AI 로 3분 하이라이트로

> 의뢰인(행사 사진 · 동영상을 촬영하는 기자)의 요청을 정리한 카드다. **확인되지 않은 부분은 「가정」으로 표시**했고, [client-questions.md](client-questions.md) 로 의뢰인에게 확인한다.

## 1. 한 문장 요구

**몇 시간 동안 촬영한 행사 영상을 AI 에게 「이런 장면으로」라고 지시하면, 그 지시에 맞는 부분만 골라 3분 안팎의 짧은 영상으로 편집하고, 인트로와 중간 효과까지 넣어 주는 방법이 필요하다.**

## 2. 6칸 정리

| 칸 | 내용 | 확인 |
|---|---|---|
| **입력** | 단체 행사를 몇 시간 동안 찍은 영상(여러 클립일 가능성) | 촬영 장비 · 해상도 · 파일 형식 · 총 길이 → **확인** |
| **지시** | 말(글)로 원하는 내용을 설명 — 예: 「축사 핵심, 시상 장면, 참가자들이 즐거워하는 모습으로 3분」 | 한국어로 지시하고 싶은지 → **확인** |
| **출력** | 3분 안팎의 짧은 영상 | 화면비(가로 16:9 / 세로 9:16 SNS용) · 해상도 · 납품처 → **확인** |
| **꾸미기** | 시작할 때 인트로 효과, 영상 중간 여러 효과(전환 · 자막 · 로고 · 음악) | 행사명 · 로고 자막, 음악 사용 여부 → **확인** |
| **예산** | 비즈니스용이라 **유료도 괜찮다** — 일에 도움이 되면 지불할 의향 | 월 예산 범위 → **확인** |
| **지금 쓰는 도구** | **Adobe Premiere Pro**(주 도구, 10/17 확인) · After Effects · CapCut 으로 수작업 편집 | PC(Windows/Mac) · Adobe 구독 플랜 → **확인** |

## 3. 세 부분으로 나눈 기능

| 부분 | 해야 할 일 | 수작업에서 시간이 드는 곳 (가정) |
|---|---|---|
| **① 장면 고르기** | 몇 시간 영상에서 지시에 맞는 구간 찾기 | 전체를 다시 보며 쓸 장면을 찾는 일 — **가장 큰 시간 절약 지점** |
| **② 이어 붙이기** | 고른 구간을 3분에 맞게 순서 · 길이 조절 | 컷 길이 다듬기, 음악 박자 맞추기 |
| **③ 꾸미기** | 인트로 · 전환 · 자막 · 로고 · 음악 | 행사마다 비슷한 인트로를 새로 만드는 일 |

## 4. 「좋은 3분 행사 영상」의 예 (평가 기준용)

행사 하이라이트의 한 예다(가정 — 의뢰인의 실제 납품 형식으로 바꾼다).

| 순서 | 길이 | 내용 |
|---|---|---|
| 인트로 | 5~10초 | 행사명 · 날짜 · 주최 로고 |
| 여는 장면 | 20초 | 행사장 전경 · 입장 · 분위기 |
| 축사 · 핵심 발언 | 30~40초 | 말의 핵심 한두 문장 (자막) |
| 행사 몽타주 | 60~80초 | 프로그램 장면 · 웃는 얼굴 · 박수 · 공연 |
| 시상 · 하이라이트 | 30~40초 | 시상 · 단체 사진 · 클라이맥스 |
| 마무리 | 10~15초 | 단체 사진 · 감사 문구 · 로고 |

## 5. 반드시 필요한 것 / 있으면 좋은 것

**반드시 필요한 것**
- 몇 시간짜리(또는 여러 클립) 영상을 **올리거나 읽을 수 있다**
- **말로 지시해서 장면을 고른다** (말이 있는 장면 + 말이 없는 장면)
- 결과를 **고쳐 지시**할 수 있다 (「축사를 줄이고 시상을 늘려 줘」)
- 결과를 **Premiere 로 넘겨 마무리**할 수 있다 (XML · 프로젝트 · 플러그인) — 의뢰인이 Premiere 사용자이므로
- 납품 가능한 화질로 **워터마크 없이** 내보낼 수 있다 (유료 플랜 포함)

**있으면 좋은 것**
- 한국어 지시 · 한국어 자막
- 인트로 · 전환 효과를 자동으로 넣기, 행사마다 다시 쓰는 인트로 틀
- 세로(9:16) SNS 버전을 함께 만들기
- 로컬 처리(행사 영상을 외부 서버에 올리기 꺼려질 때)

## 6. 비교 · 평가 기준 (M2 · M4 에서 사용)

| 기준 | 질문 |
|---|---|
| 지시 이행 | 말한 대로 장면을 골랐나 |
| 장면 정확도 | 말이 없는 장면(시상 · 공연)도 찾나 |
| 걸린 시간 | 업로드 · 처리 · 고쳐 지시까지 |
| 손볼 양 | Premiere 에서 얼마나 다시 손봐야 하나 |
| Premiere 연계 | XML · 플러그인으로 넘어가나 |
| 비용 | 무료 체험 범위 · 월 요금 · 긴 영상 추가 비용 |
| 한국어 | 지시 · 자막 · 화면 |
| 데이터 | 영상이 외부 서버에 올라가는지 (행사 주최 측 동의 필요 여부) |

## 7. 박창수가 해 드릴 수 있는 것 / 못 하는 것

**유료 서비스는 박창수가 직접 실습하거나 체험할 수 없다(2026-10-17 확정).** 카드를 등록해야 시작되는 무료 체험(예: Adobe 체험판)도 유료 서비스로 본다. 그래서 매뉴얼은 **「직접 해 본 것」과 「공식 자료로 정리한 것」을 구분해 표시**한다.

| 구분 | 해 드릴 수 있는 것 | 못 하는 것 |
|---|---|---|
| **조사** | 방법별 기능 · 요금 · 한도 · Premiere 연계를 공식 문서 · 요금표 · 튜토리얼로 정리하고 확인 날짜를 적는다 | 공식 자료에 없는 실제 품질(장면을 잘 고르는지)을 유료 도구에서 확인하는 것 |
| **체험** | **무료 플랜 · 카드 없는 무료 체험** 도구를 직접 써 보고 캡처 · 막힌 곳 · 무료 한계를 기록한다 | **유료 플랜 · 카드 등록 체험판** 실습 — Premiere Pro · After Effects 안에서의 시연도 여기에 들어간다 |
| **시험 영상** | 공개해도 되는 긴 영상(박창수의 공개 세미나 · 모임 녹화)으로 같은 지시문을 시험한다 | 의뢰인의 실제 행사 영상으로 시험하기 — 의뢰인 · 주최 측 동의가 있을 때만, 공개 레포에는 올리지 않는다 |
| **코드 방식** | Claude Code + FFmpeg · Remotion 으로 장면 자르기 · 인트로 틀을 직접 시연한다(박창수가 쓰는 도구) | 의뢰인이 코딩 없이 쓰게 만드는 것은 보장하기 어렵다 |
| **매뉴얼** | 체험한 도구는 캡처가 있는 단계별 매뉴얼, 유료 도구는 공식 자료 기반 단계와 참조 링크를 「직접 체험 안 함」 표시와 함께 만든다 | 유료 도구 매뉴얼의 화면 · 단계가 실제와 같다고 보장하기 |
| **함께 하기** | 의뢰인이 유료 도구를 쓸 때 **만나서 옆에서**(가까이 살아 가능) 또는 화면 공유로 함께 보며 안내하고, 그 결과를 매뉴얼에 넣는다(의뢰인 동의 시) — 아래 8절 옵션 B · C | 의뢰인 대신 유료 도구에 가입 · 결제하기 |
| **장비** | 클라우드 서비스 위주로 체험한다 | 박창수 PC 는 GPU 가 없어(i7-1355U · 16GB) 로컬 AI 처리 체험은 느리거나 불가능하다 |

## 8. 진행 방식 — 세 가지 옵션 (의뢰인과 정한다)

의뢰인과 사는 곳이 가까워 **만나서 진행할 수 있다**(2026-10-17 박창수). M1 이후를 어떻게 진행할지 의뢰인 답을 받아 정하고, 섞어서 쓸 수도 있다(예: B 로 시작해 C 로 넘기기).

| 옵션 | 어떻게 | 좋은 점 | 고려할 것 |
|---|---|---|---|
| **A. 박창수가 리서치 → 매뉴얼 전달** | 로드맵대로 박창수 PC 에서 M2~M6 를 하고 결과와 매뉴얼을 드린다 | 의뢰인 시간이 가장 적게 든다 | 유료 도구는 「자료로만」 정리된다 |
| **B. 만나서 박창수 PC 로 함께** | M2 이후 과정을 만나서 박창수 PC 에서 함께 진행한다. 유료 도구는 의뢰인이 자기 계정으로 로그인해 시험한다 | 의뢰인이 과정을 보며 배우고, 유료 도구도 실제로 확인한다 | 일정 맞추기 · 의뢰인 계정은 시험 뒤 로그아웃 · 박창수 PC 에 Premiere 가 없으면 Premiere 연계는 의뢰인 PC 에서 확인 |
| **C. 의뢰인 PC 에 VibeLearn AI 설치 + 가이드** | 박창수가 VibeLearn AI(VS Code · Claude Code 와 학습 템플릿)를 의뢰인 PC 에 설치해 드리고 쓰는 법을 안내한다. 그 뒤 의뢰인이 **원하는 방향으로 직접 리서치 · 체험**하고, 박창수는 막힐 때 돕는다 | 의뢰인 PC · Premiere · 유료 계정에서 바로 체험한다. 리서치하는 방법 자체를 익혀 다음 주제에도 쓴다 | 의뢰인에게 Claude 유료 구독이 필요하다 · 설치와 첫 안내에 시간이 든다 · 의뢰인이 직접 공부할 시간이 필요하다 |
