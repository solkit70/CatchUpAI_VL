# M1 — 요구사항 정리와 방법 지도

**상태**: 🔄 진행 중 — 산출물 작성 완료, **의뢰인 확인 대기** (2026-10-17)
**예상 학습 시간**: 2시간

의뢰인(행사 촬영 기자)의 요청을 「장면 고르기 · 이어 붙이기 · 꾸미기」 세 부분으로 정리하고, 조사할 방법을 5개 범주로 나눈 모듈이다. 정리한 요구가 맞는지 의뢰인에게 먼저 묻는다.

## 📚 학습 순서

1. [requirements-card.md](requirements-card.md) — 요구사항 카드: 6칸 정리 · 세 부분 기능 · 좋은 3분 영상의 예 · 반드시/있으면 좋은 것 · 평가 기준 · **박창수가 해 드릴 수 있는 것 / 못 하는 것** · **진행 방식 옵션 A · B · C**
2. [methods-map.md](methods-map.md) — 방법 지도: 편집형 vs 생성형 · 5개 범주(A~E) 후보 15개 · M2 조사 순서
3. [client-questions.md](client-questions.md) — 의뢰인 확인 질문: 범위 안내 + 18개 질문을 담은 메시지 · 질문별 이유

## 이 모듈에서 알아낸 것

- 의뢰인이 말한 **「시덴스」는 Seedance(생성형)로 추정**된다. 생성형은 인트로 같은 새 장면을 만들 뿐 **촬영본 편집은 못 한다** — 기대한 용도를 확인해야 한다.
- **Claude 가 Premiere 를 직접 조작하는 연결 도구(MCP)**가 커뮤니티에 여럿 있다. 다만 Adobe 공식이 아니고 설치가 어렵다.
- **긴 영상 → 프롬프트 → 하이라이트 → Premiere XML** 흐름을 내세우는 서비스(Vidio.ai · OpusClip · VEA 등)가 있다 — 의뢰인이 Premiere 사용자라 이 연계가 핵심이다.
- **유료 서비스는 박창수가 직접 체험할 수 없다**(카드 등록 체험판 포함). 매뉴얼은 「직접 해 본 것」과 「공식 자료로 정리한 것」을 구분해 표시한다.
- 의뢰인과 가까이 살아 **만나서 진행**할 수 있다. 진행 방식은 세 가지 중 의뢰인과 정한다 — A. 박창수가 리서치해 매뉴얼 전달 · B. 만나서 박창수 PC 로 함께 · C. 의뢰인 PC 에 VibeLearn AI 를 설치하고 안내한 뒤 의뢰인이 직접 리서치 (요구사항 카드 8절).
