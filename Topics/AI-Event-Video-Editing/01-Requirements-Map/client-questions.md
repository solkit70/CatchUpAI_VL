# 의뢰인 확인 질문

> 요구사항 카드가 맞는지 확인하고, 매뉴얼을 의뢰인 환경에 맞추기 위해 묻는다. **M1 에서 한 번에 다 묻는다** — M2 이후 다시 묻지 않아도 되게. 아래 **메시지를 그대로 보내면** 된다(카톡 · 이메일). 답을 받으면 [requirements-card.md](requirements-card.md) 의 「확인」 칸과 「7. 해 드릴 수 있는 것 / 못 하는 것」을 맞춘다.

## 보낼 메시지

```
안녕하세요, 박창수입니다.
말씀하신 「AI로 행사 영상 편집하기」 리서치를 시작했습니다. 제가 이해한 내용이 맞는지, 그리고 제가 해 드릴 수 있는 범위를 먼저 말씀드리고 몇 가지 여쭙고 싶습니다.

■ 제가 이해한 내용
몇 시간 동안 촬영한 행사 영상을 AI에게 「이런 장면으로」라고 지시하면, 그 지시에 맞는 부분만 골라 3분 안팎의 영상으로 편집하고, 시작 인트로와 중간 효과까지 넣고 싶으신 것으로 이해했습니다. 지금은 프리미어 프로를 주로 쓰시고 애프터 이펙트·캡컷도 쓰시며, 일에 도움이 되면 유료 서비스도 괜찮으시다고 들었습니다.

■ 제가 해 드릴 수 있는 것과 못 하는 것
- 여러 방법(Claude·ChatGPT 연결 도구, 영상 편집 전용 AI, 프리미어 자체 AI 기능, 생성형 AI 등)을 조사해 비교표로 정리하고, 추천 방법의 설치·사용 매뉴얼을 만들어 드립니다.
- 무료로 써 볼 수 있는 도구는 제가 공개 행사 영상으로 직접 해 보고, 화면 캡처와 막히는 곳까지 매뉴얼에 넣겠습니다.
- 유료 서비스(프리미어·애프터 이펙트 포함, 카드 등록이 필요한 체험판 포함)는 제가 직접 써 볼 수 없습니다. 이런 도구는 공식 자료와 튜토리얼로 매뉴얼을 만들고 「직접 체험 안 함」이라고 표시하겠습니다. 대신 대표님이 쓰실 때 만나서 옆에서, 또는 화면 공유로 함께 보며 안내해 드릴 수 있습니다.

■ 진행 방식 (편하신 쪽으로 고르시면 됩니다, 섞어도 됩니다)
- 가) 제가 리서치해서 결과와 매뉴얼을 드리기
- 나) 만나서 제 컴퓨터로 함께 리서치·체험하기 (유료 도구는 대표님 계정으로 시험)
- 다) 제가 쓰는 AI 학습 도구(VibeLearn AI)를 대표님 컴퓨터에 설치해 드리고 쓰는 법을 안내한 뒤, 대표님이 원하시는 방향으로 직접 리서치하시기 (막히시면 제가 도와드림. Claude 유료 구독이 필요합니다)

■ 여쭙고 싶은 것 (아시는 것만 답해 주셔도 됩니다)

[작업 환경]
1. 컴퓨터는 Windows인가요, Mac인가요?
2. 어도비는 어떤 플랜을 쓰시고, 프리미어는 몇 버전인가요? (프리미어 단일 / Creative Cloud 전체)
3. Claude나 ChatGPT를 유료로 쓰고 계신가요?
4. 프로그램에 플러그인이나 확장 기능을 직접 설치해 보신 적이 있나요?

[촬영본과 완성 영상]
5. 보통 촬영본은 몇 시간 정도이고, 어떤 카메라로 어떤 해상도(예: 4K, 1080p)로 찍으시나요? 카메라 여러 대인가요?
6. 축사·발표 소리는 마이크로 깨끗하게 녹음되나요? (AI가 말을 글로 바꿔 장면을 찾을 때 중요합니다)
7. 완성 영상은 어떤 형태로 납품하시나요? (가로 16:9 / 세로 SNS용 9:16 / 둘 다, 길이)
8. 최근에 만드신 3분 영상 하나를 링크로 보여 주실 수 있을까요? 「좋은 결과」의 기준으로 삼겠습니다.
9. 지금 3분 영상 하나를 만드는 데 보통 몇 시간이 걸리고, 한 달에 행사 영상을 몇 건 정도 만드시나요?

[AI에게 바라는 것]
10. AI가 꼭 해 줬으면 하는 것은 무엇인가요? 가장 시간이 많이 드는 것도 알려 주세요.
   - 가) 긴 영상에서 쓸 장면 골라 주기
   - 나) 고른 장면을 3분으로 이어 붙이기
   - 다) 인트로·전환 효과·자막 넣기
11. 말씀하신 「시덴스」는 ByteDance의 Seedance(글로 새 영상을 만드는 AI)를 말씀하신 건가요? 촬영본을 편집하는 용도로 생각하셨는지, 인트로 같은 새 장면을 만드는 용도로 생각하셨는지 궁금합니다. 어디서 보셨는지도 알려 주시면 찾아보겠습니다.
12. 인트로·효과는 행사마다 같은 틀(로고, 행사명 자막)을 쓰시나요? 이미 쓰시는 애프터 이펙트 템플릿이나 음악 출처가 있나요?
13. AI에게 한국어로 지시하고 싶으신가요? 자막도 한국어가 필요하신가요?

[비용과 영상 관리]
14. 한 달에 어느 정도까지 비용을 쓰실 수 있을까요? (대략적인 범위면 됩니다)
15. 행사 영상을 외부 AI 서버에 올려도 괜찮은가요? 주최 측이 꺼리는 경우가 있는지요.
16. 시험용으로 지난 행사 촬영본 일부(20~30분)를 주실 수 있을까요? 주최 측이 괜찮다고 할 때만, 시험에만 쓰고 어디에도 공개하지 않겠습니다. 어려우시면 제 공개 영상으로 시험하겠습니다.

[매뉴얼]
17. 매뉴얼은 어떤 형태가 편하신가요? (문서·PDF / 화면 녹화 영상 / 함께 보는 설명 시간) 언제까지 필요하신가요?
18. 위 진행 방식 가)·나)·다) 중 어느 쪽이 편하신가요? 나)나 다)라면 만나기 좋은 요일·시간대도 알려 주세요.

답을 주시면 그에 맞는 방법을 골라 사용 매뉴얼까지 만들어 드리겠습니다.
```

## 질문별 이유

| # | 질문 | 왜 묻나 |
|---|---|---|
| 1 | PC (Windows/Mac) | 매뉴얼 화면 · 설치 방법이 다르다 |
| 2 | Adobe 플랜 · Premiere 버전 | Premiere 자체 AI 기능 범위, XML 가져오기 지원(일부 서비스는 Premiere 2022 이상) |
| 3 | Claude · ChatGPT 유료 구독 | A 범주(연결 도구 · MCP)를 추가 비용 없이 쓸 수 있는지 |
| 4 | 플러그인 설치 경험 | MCP · 확장(CEP 패널) 방식이 의뢰인에게 맞는지 |
| 5 | 촬영본 길이 · 장비 · 해상도 · 대수 | 업로드 한도 · 처리 비용 · 다중 카메라 지원 여부 |
| 6 | 녹음 상태 | 전사(말 → 글) 기반 장면 찾기의 정확도 |
| 7 | 납품 형식 | 가로 하이라이트 도구와 세로 숏폼 도구가 다르다 |
| 8 | 완성본 예시 | 「좋은 3분 영상」의 기준 · M4 평가표 |
| 9 | 지금 걸리는 시간 · 월 건수 | 시간 절약 효과와 월 비용을 비교하는 기준 |
| 10 | 꼭 필요한 기능 · 가장 시간이 드는 일 | 추천의 우선순위 |
| 11 | 「시덴스」의 뜻 · 출처 | 생성형(새 영상)과 편집형(촬영본 편집)을 구분 |
| 12 | 인트로 틀 · 템플릿 · 음악 | 꾸미기를 AI 로 할지, 기존 템플릿 재사용으로 충분한지 · 음악 저작권 |
| 13 | 한국어 | 한국어 지시 · 자막 지원 도구로 좁힘 |
| 14 | 월 예산 | 추천안 범위 |
| 15 | 외부 서버 업로드 | 클라우드 서비스를 쓸 수 있는지 |
| 16 | 시험용 촬영본 | 실제 행사 영상으로 무료 도구를 시험할 수 있는지 — 동의 없으면 박창수 공개 영상 사용 |
| 17 | 매뉴얼 형태 · 기한 | M6 산출물 형식과 일정 |
| 18 | 진행 방식 (가 · 나 · 다) | 박창수가 못 하는 유료 도구 체험을 채우는 방법 — 요구사항 카드 8절 옵션 A · B · C. 나 · 다는 만나서 진행 |
