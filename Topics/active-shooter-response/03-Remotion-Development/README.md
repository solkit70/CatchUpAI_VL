## 📘 모듈 소개

본 모듈에서는 미 국토안보부(DHS) 행동 강령 및 시민단체 자원 정보를 담은 12장 슬라이드 기획안(`video-slide-plan.md`)을 실제 고화질 동영상으로 구동하기 위해, **React 및 Remotion 프레임워크 기반의 비주얼 요소와 특화 모션 컴포넌트를 설계하고 개발**합니다.

주요 테마는 **L3 밝기 대역의 Slate Charcoal 테마**이며, 눈의 피로를 최소화하는 어두운 배경에 시인성이 높은 하이라이트 배지와 Spring 물리 기반의 Stagger 등장 동작을 적용해 시청자의 긴장감과 집중력을 동시에 유지합니다.
