## 📘 모듈 소개

본 모듈에서는 슬라이드 기획안(`video-slide-plan.md`)에서 추출한 나레이션 원고를 바탕으로, Microsoft Edge의 뉴럴 목소리 합성 기술인 **edge-tts**를 사용하여 **12개 슬라이드 전체의 고화질 공익안전 안내 오디오 파일(.mp3)**을 자동 생성합니다.

또한, 각 슬라이드 오디오의 실측 재생 시간을 **ffprobe**를 사용해 정밀 계측하고, 이를 Remotion 타임라인 제어 원본 파일인 `data.ts`에 동적으로 반영함으로써 100% 한 치의 오차도 없는 슬라이드-오디오 싱크 매핑 환경을 보장합니다.

## 🎙️ 오디오 패딩 공식 (Audio Padding Formula)

나레이션이 시작되거나 끝나는 부분에서 화면 전환 트랜지션(Fade 또는 Slide)이 맞물릴 때 첫 음절이나 끝 음절이 "씹히는(Clipping)" 오디오 사고를 원천 방지하기 위해 다음과 같은 전후방 정밀 패딩 연산 공식을 도입하고 타임라인에 삽입했습니다.

$$총\ 슬라이드\ 기간 = 실측\ 오디오\ 길이 + HEAD\_PAD\ (0.10초) + TAIL\_PAD\ (0.12초) + 추가\ holdSec$$

*   **`HEAD_PAD_SEC` (0.10초)**: 슬라이드가 처음 등장하여 트랜지션이 부드럽게 완료되는 극초반 0.1초 동안 음성을 대기(Delay)시켜 첫 마디의 가청도를 보존합니다.
*   **`TAIL_PAD_SEC` (0.12초)**: 음성 발화가 끝난 후 다음 화면으로 넘어가기 전 0.12초간의 고요 구간을 두어 음성 잔향이 부자연스럽게 끊기지 않도록 여운을 줍니다.
