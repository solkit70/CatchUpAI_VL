## Core Concepts

### Crowd Manager의 역할

Crowd Manager는 public assembly venue에서 **fire and life safety**를 책임지는 certified individual이다. 무대 운영, 티켓 등록, 음식 서비스 담당자가 아니라, 화재와 생명 안전을 위해 통로, 출구, 인원 제한, 비상 안내, 체크리스트를 확인하는 역할이다.

### Occupant Load

Occupant load는 facility에 있는 employees, performers, patrons를 모두 포함한 인원 기준이다. 실제 순간 방문객 수만 보는 것이 아니라, Certificate of Inspection에 표시된 legal capacity가 기준이 된다.

### 필요한 인원

Owner 또는 operator는 **250 occupants 또는 그 일부마다 Crowd Manager 1명**을 지정해야 한다. 예를 들어 225명은 1명, 450명은 2명, 525명은 3명이 필요하다.

### Checklist

Crowd Manager는 facility를 열기 전 또는 event 전에 Fire and Building Safety Checklist를 완료하고 서명해야 한다. 점검 중 발견된 deficiency는 public에게 open하기 전에 반드시 corrected 되어야 하며, 완료된 checklist는 premises에 1년간 보관해야 한다.

## Checklist Focus

Crowd Manager가 확인해야 하는 주요 항목은 다음과 같다.

| 항목 | 확인 내용 |
|---|---|
| Exits | 출구가 막혀 있지 않고 잠겨 있지 않은지 확인 |
| Doors | 문이 정상적으로 열리고 사용할 수 있는지 확인 |
| Stairways | 실내외 계단이 막혀 있지 않은지 확인 |
| Exit signs | exit sign lighting이 정상 작동하는지 확인 |
| Emergency lighting | emergency lighting이 작동하는지 확인 |
| Fire extinguishers | 압력 게이지, seal, inspection tag 등 정상 상태 확인 |
| Exit announcements | 프로그램 시작 전 비상시 사용할 출구 위치 안내 |
| Occupant load | posted limit을 넘지 않도록 담당자 지정 |

## Sorting Practice

수강 중 나온 sorting 문제는 `Requires Crowd Manager`와 `Exempt`를 구분하는 연습이다.

| Scenario | Sorting |
|---|---|
| A museum hosting a public exhibit with 300 visitors | Requires Crowd Manager |
| A community center open to the public for a dance night with 200 attendees | Requires Crowd Manager |
| A yoga studio with 60 participants in a scheduled class | Exempt |
| A corporate training session with 80 employees in a reserved room | Exempt |
| A birthday party at a rented hall with 40 invited guests | Exempt |
| A private wedding dinner with 45 seated guests and a guest list | Exempt |
| A school auditorium hosting a public play with 275 attendees | Requires Crowd Manager |
| A concert venue with 300 standing attendees | Requires Crowd Manager |

주의할 점은 `auditorium`이라는 단어만 보고 exempt로 판단하면 틀릴 수 있다는 것이다. 이 course의 sorting 기준에서는 public event이고 100명 이상이면 `Requires Crowd Manager`로 처리되었다.

## BigHug Event Application

BigHug RPD+ K-Pop Play Day Season 2에서는 예상 참석자 1,500명을 기준으로 Crowd Manager 6명 이상이 필요하다는 계산이 공유되었다. 실제 운영에서는 6명이 총 수료자 수인지, 동시에 현장 근무해야 하는 최소 인원인지 Bellevue Fire에 최종 확인해야 한다.

행사 현장에서는 특히 다음 항목이 중요하다.

- 출구와 통로가 부스, 줄, 테이블, 케이블로 막히지 않도록 관리
- 실내외 stairway와 egress path 확인
- 프로그램 시작 전 exit announcement 준비
- emergency lighting과 exit sign 확인
- fire extinguisher 위치와 상태 확인
- occupant load에 volunteers, performers, vendors, guests가 모두 포함된다는 점 반영
- checklist 작성자와 보관 위치 확정
