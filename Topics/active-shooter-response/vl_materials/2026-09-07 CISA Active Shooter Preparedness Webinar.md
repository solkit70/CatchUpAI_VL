## 행사 식별 및 확인 상태

사용자가 Google Calendar에서 확인한 행사는 **CISA Active Shooter Preparedness Webinar**이며, 일정은 **10월 30일 오전 10시**였다. 공개 CISA 자료는 이 교육이 지역별·회차별로 반복 운영되는 온라인 과정임을 확인해 주지만, 이번에 확인한 공개 아카이브만으로는 해당 일정의 **연도와 시간대**를 독립적으로 확정하지 못했다. 따라서 이 노트에서는 사용자 확인 일정은 보존하고, 후속으로 캘린더 초대장 또는 수강 확인 이메일이 확보되면 연도·시간대·등록 링크를 보완한다.

| 항목 | 정리 |
|---|---|
| 행사명 | CISA Active Shooter Preparedness Webinar |
| 주관 | Cybersecurity and Infrastructure Security Agency (CISA), U.S. Department of Homeland Security |
| 일정 | 10월 30일 오전 10시 — 사용자 확인; 연도·시간대는 추가 확인 필요 |
| 형식 | 가상/온라인, 강사 진행형 웨비나 |
| 성격 | 전술·현장 대응기술 교육이 아닌 조직의 인식, 비상계획, 예방·대응·복구 준비 교육 |
| 비용·대상 | CISA는 이 과정을 폭넓은 이해관계자에게 제공하는 무상 자원·교육으로 안내함 |

> “THIS IS NOT A TACTICAL TRAINING COURSE.”

위 문구는 CISA의 지역별 행사 안내에 명시된 과정의 성격이다. 시민단체·비영리단체에는 개인이 위기 상황에서 무엇을 할지 아는 것에 더해, 행사장·사무실·예배 공간의 비상행동계획(Emergency Action Plan), 연락 체계, 신고와 안내 절차를 함께 점검하는 학습으로 이해하는 것이 적절하다.

## 학습 목표와 구성

CISA 공식 안내에 따르면 이 웨비나는 활성 총격 사건에 대한 인식과 대응을 높이고, 조직의 회복력을 강화하기 위해 설계되었다. 사건은 예측하기 어렵고 빠르게 전개될 수 있으므로, 사전 계획과 역할 분담이 행사 운영자·자원봉사자·참가자 모두의 대응 시간을 줄이는 기반이 된다.

| 구성 | 핵심 질문 |
|---|---|
| Recognition | 위협과 위험 신호를 어떻게 인식할 것인가? |
| Prevention | 잠재적 폭력과 우려 행동을 발견·보고하기 위한 절차는 있는가? |
| Protection | 출입, 현장 안내, 의사소통, 물리적 안전 조치는 적절한가? |
| Mitigation | 피해를 줄이기 위해 어떤 준비와 자원이 필요한가? |
| Response | 사건 중 구성원·방문객에게 어떤 선택지와 기대 행동을 안내할 것인가? |
| Recovery | 사건 후 안전, 소통, 지원, 정상화는 어떻게 이어갈 것인가? |
| EAP 개발 | 위 요소를 실행 가능한 비상행동계획으로 어떻게 문서화·연습할 것인가? |

## BigHug 행사 안전 준비에의 적용

이 과정은 BigHug처럼 자원봉사자와 다수의 방문객이 함께하는 행사에 특히 유용하다. 기존 [[Ingest/CatchUpAI_VL/Topics/active-shooter-response/vl_materials/2026-07-27 BigHug RPD KPOP 안전 대비 - 시애틀센터 총격사건 관련#BigHug RPD+ K-pop Play Day 2 (9/26) 안전 대비 시사점|BigHug 안전 대비 시사점]]에서 제안한 대피 동선, 911 연락, 현장 스태프 브리핑을 단순 체크리스트에 머물게 하지 않고, 아래처럼 실제 운영 절차로 연결할 수 있다.

1. 행사 전: 장소별 출입구·대피 경로·집결 장소·역할별 연락 방법을 비상행동계획에 기록하고 스태프에게 공유한다.
2. 행사 중: 이상 행동 또는 위협을 보고할 단일 연락 경로와, 방문객에게 전달할 짧고 명확한 안내 문구를 준비한다.
3. 행사 후: 관찰된 문제와 대응 결과를 검토하여 After Action Report와 개선 조치 목록으로 남긴다.

이는 개별 자원봉사자에게 위험한 개입을 요구하는 접근이 아니다. CISA가 강조하는 계획·의사소통·관계기관과의 사전 협력을 바탕으로, 각 사람이 자신의 안전을 우선하면서 조직이 더 빠르고 일관되게 행동하도록 만드는 준비이다.
