### S10: 제작 후작업 — Draft 이후 무슨 일이 생기나

**파트**: 전환
**예상 시간**: 2분

#### 📊 슬라이드 내용
- **1단계 나레이션 수정**: AI가 만든 스크립트 → 내 말투로 수정
- **2단계 Edge-TTS 재생성**: 수정한 나레이션으로 초안 오디오 재확인
- **3단계 Qwen3-TTS**: 나레이션 확정 후 → 내 목소리 클론으로 최종 교체
- **4단계 슬라이드 수정**: 배치·색상·애니메이션 세부 조정
- **비용 절약 포인트**: 이미지 = API 대신 웹 생성, 음성 = Edge-TTS→Qwen3-TTS 순서

#### 🎤 발표자 노트
"Draft 완성이 끝이 아닙니다. AI가 만든 나레이션은 대체로 정확하지만 제 말투가 아닐 수 있습니다. 그래서 수정하고, 무료 edge-tts로 다시 들어보고, 마음에 들면 그 때 Qwen3-TTS로 교체합니다. Qwen3-TTS는 제 목소리를 복제한 모델인데 API 비용이 발생합니다. 이미지도 마찬가지입니다. ChatGPT나 Gemini 웹에서 프롬프트를 넣어 생성하면 API 비용 없이 이미지를 만들 수 있습니다. 비용 절약을 위해 설계된 순서입니다."

#### 🖥️ 데모/시각 자료
- 플로우차트: Draft → 수정 → Edge-TTS 검토 → Qwen3-TTS → 최종
- 비용 절약 포인트 하이라이트

### S11: Tehaleh는 인터넷 정보. 하지만 내 실험 기록은?

**파트**: 브릿지
**예상 시간**: 1.5분

#### 📊 슬라이드 내용
- **Tehaleh 영상**: 인터넷에 정보가 있다 → 누구나 AI로 만들 수 있다
- **하지만** — 내가 실험을 통해 얻은 인사이트, 내 방송에서 한 말, 내 경험은?
- → 인터넷에 없다. **내가 기록해야만 AI가 쓸 수 있다.**
- "기록하지 않은 경험은 AI에게 존재하지 않는 경험이다"

#### 🎤 발표자 노트
"Tehaleh 영상이 36분에 가능했던 이유 중 하나는 Tehaleh에 대한 정보가 인터넷에 있기 때문입니다. AI가 검색하고 구조화할 수 있었습니다. 그런데 제가 매주 라이브 방송에서 실험하고 발견한 인사이트, 제가 미팅에서 나눈 대화, 제가 학습하면서 정리한 생각들은 인터넷에 없습니다. 그것들을 콘텐츠 소재로 쓰려면, 제가 기록해야 합니다. 기록하지 않은 경험은 AI에게 존재하지 않는 경험입니다."

#### 🖥️ 데모/시각 자료
- 두 단의 대비: "인터넷 정보 → AI 활용 가능" vs "내 경험 → 기록 없으면 AI가 모름"

### S15: 기록 → Context → AI → 배포 순환

**파트**: 2부: 기록 논리
**예상 시간**: 3분

#### 📊 슬라이드 내용
```
📝 기록  →  🧠 Context  →  🤖 AI 협업  →  🎬 콘텐츠  →  📢 배포
  ↑                                                              |
  └──────────────── 새 경험 ←─────────────────────────────────┘
```
- **기록 없이**: AI에게 "만들어줘" → Generic 결과
- **기록 있을 때**: AI + 내 Context → 나만의 결과, 내 언어, 내 스타일
- **공식**: 기록 + AI = 아이디어 즉시 실현 _(Live #14 인트로)_

#### 🎤 발표자 노트
"기록이 왜 중요한지, 구조로 설명드리겠습니다. 기록은 그 자체로는 텍스트입니다. 하지만 AI에게 전달하면 Context가 됩니다. Context가 있는 AI는 나만의 결과물을 만들어냅니다. 그 결과물이 콘텐츠가 되고, 배포되고, 새로운 경험이 생기고, 그게 다시 기록이 됩니다. 이 루프가 돌면 돌수록 AI가 나를 더 잘 알게 됩니다. Live #14 방송에서 제가 한 말입니다. '기록 + AI = 아이디어 즉시 실현'"
