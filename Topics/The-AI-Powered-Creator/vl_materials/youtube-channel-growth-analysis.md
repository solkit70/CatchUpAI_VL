## 4단계 성장 궤적

### Phase 1 — DL 입문: 채널 시작 (2024-02-13 ~ 2024-03-19)

**기간**: 1.2개월 | **일반 영상 조회 추정**: ~1,200 views | **월평균 구독**: ~12명

- **2024-02-13**: 첫 영상 "DL Basic 01 — AI는 진짜 인간처럼 생각할까?" 업로드
- DL Basic 01~07 시리즈 완결 (총 7편, 2,971 views 누적)
- **DL Basic 07 — Transformer Model** (2024-03-19): 시리즈 최고 조회수 1,380 views
- Transformer까지 마친 뒤 LangChain 실습으로 전환

**주요 콘텐츠**: Deep Learning 기초 (DL Basic 01~07)

---

### Phase 2 — 외부 기술 학습·전달 (2024-03-20 ~ 2025-03-31)

**기간**: 12.4개월 | **월평균**: ~5,750 views | **월평균 구독**: ~231명 | **월평균 시청**: 354h  
**콘텐츠 성격**: 외부 기술을 학습·정리해서 전달하는 튜토리얼 형식

**성장 흐름**:

| 기간 | 월평균 조회 | 대표 주제 |
|---|---:|---|
| 2024-03~06 | ~1,900 | AI Web App 개발, LangChain 입문 |
| 2024-07~09 | ~3,900 | LangGraph, AI Agent 기초 |
| 2024-10~12 | ~8,300 | **IONQ 바이럴**, Multi-Agent, 직장 그만 둔 선언 |
| 2025-01~03 | ~10,680 | Hierarchical Teams, LLMCompiler, 추론 방법론 — **채널 피크** |

**주요 이벤트**:
- **2024-10-25**: IONQ 양자 컴퓨터 현장 방문 — 당일 4,576 views, 누적 8,731 views (+239명 구독)
- **2024-11-10**: "AI에 All In 하려고 직장 그만 두었습니다" 영상 발행
- **2025-02**: 구독자 월 최고 +427명 / 시청시간 최고 572h / 조회수 12,218

**성장 이유**: 명확한 학습 니즈 + 기술 키워드 검색 유입 + 정제된 튜토리얼 형식

**주요 콘텐츠**: LangChain / LangGraph / 추론 방법론(LLMCompiler, ReWOO) / AI Agent 아키텍처

### Phase 3 — 라이브 방송 시대 (2025-04-01 ~ 2026-02-23)

**기간**: 10.8개월 | **월평균**: ~4,831 views (Shorts 제외) | **월평균 구독**: 125명

**핵심 변화**: "외부 기술 학습·정리 전달" → **"내가 직접 실험하는 과정을 라이브로 공유"**

| 구분 | Phase 2 (외부 기술 전달) | Phase 3 (라이브 방송) |
|---|---|---|
| 형식 | 정제된 학습 영상 | 라이브 방송 + 요약 클립 |
| 내용 | 외부 기술 학습·정리 | 내 실험 과정 실시간 공유 |
| 주제 | LangChain, AI Agent, 추론 방법론 | Vibe Coding, PKM, 일상 실험 |
| 검색 유입 | 높음 (기술 키워드) | 낮음 (라이브는 검색 약함) |
| 월평균 조회 | ~5,750 | ~4,831 (-16%) |
| 월평균 구독 | ~231명 | ~125명 (-46%) |

**주요 이벤트**:
- 2025-04: "재미로 하는 Vibe Coding" 라이브 방송 시작
- 2025-06: 구독자 증가 현저히 감소 (107명 → 이후 50~80명대)
- 2025-07: 전체 12,938 views이나 **Shorts 제외 시 4,023 views** — 반등이 아닌 하락세 지속
- 2025-10~11: 2,362~2,635 views — 실질 최저점
- **2026-01**: 전체 43,158 views이나 **Shorts 제외 시 3,990 views** — K-Ristmas K-Pop 이벤트 영상 34편(39,168 views)이 90.8% 차지. AI 콘텐츠 실제 성과는 평월 이하
