## 상세 구성

### 오프닝: 뚝딱 순간 (3분)

> **목적**: 시각적 후킹 → 핵심 질문 제기

1. Remotion으로 만든 영상 재생 (1~2분짜리, membership-promo 또는 live-summary)
2. "이 영상을 AI로 만들었습니다. 얼마나 걸렸을까요?"
3. "그런데 이게 가능하려면 한 가지가 먼저 있어야 합니다."
4. → 오늘 이야기: **기록**

**슬라이드**: 영상 재생 → 타이틀 슬라이드 "AI 크리에이터에게 가장 중요한 것"

---

### 1부: 나는 어떤 AI 크리에이터인가 (7분)

> **목적**: 신뢰 구축 + 채널 변화로 "기록" 이야기 복선 깔기

**① 짧은 자기소개**
- IT 엔지니어 → AI 크리에이터 전환
- Catch Up AI 채널: 새 기술 강의도 아니고 AI 뉴스도 아닌 "함께 실험하는 채널"

**② 채널 관심사 변화 타임라인**

```
Deep Learning        AI의 기반 다지기
    ↓
AI App 개발          LangChain, LangGraph — 개발자 본능
    ↓
Architecture         시스템 설계의 중요성 발견
    ↓
추론 (Reasoning)     추론 방법론 탐구
    ↓
Vibe Coding          AI로 코딩하기
    ↓
Knowledge Mgmt       AI4PKM + VibeLearn AI 탄생
    ↓
Vibe Guiding         KM 이후, "어떻게 활용할까"
    ↓
GOBI                 강민석님, Vibe Guiding 구체화
    ↓
AI 일상 적용         지금, 일상 속 AI 실험들
```

**③ 피벗: BigHug 소상공인 AI 강좌 경험**
- "IT 전문가의 눈에서 일반인의 눈으로"
- 이 경험이 방향을 바꿨다: 기술 → 사람, 도구 → 일상

**슬라이드**: 타임라인 다이어그램 → BigHug 경험 한 장

---

### 2부: 기록이 왜 핵심인가 (10분)

> **목적**: 핵심 주장의 논리적 설명

**① AI는 Context 없이 일 못한다**
- AI에게 "영상 만들어줘"만 하면 → 표준적이고 무의미한 결과
- AI에게 내 경험, 내 언어, 내 사례를 주면 → 나만의 콘텐츠

**② 기록이 Context의 원천이다**

```
[기록]  경험, 인사이트, 실험 결과, 미팅 내용, 방송 내용
  ↓
[Context]  AI가 참조할 수 있는 구조화된 자료
  ↓
[AI 협업]  내 언어로, 내 경험으로 콘텐츠 생성
  ↓
[배포]  YouTube, SNS, 멤버십
  ↓
[새 경험]  다음 기록의 소재
```

**③ Live 방송에서 얻은 인사이트 (인용)**
- Live #13: 기록이 AI를 강하게 만든다 ← 실제 발언 인용
- Live #14: 기록이 있으면 아이디어가 바로 결과물이 된다 ← 실제 발언 인용

**슬라이드**: 순환 다이어그램 → 발언 인용 슬라이드

---

### 3부: 기록이 콘텐츠가 되는 실제 사례 (12분)

> **목적**: 추상적 주장을 구체적 증거로 뒷받침

**Case 1: 라이브 방송 → Remotion 요약 영상**
- GOBI Desktop으로 방송 Transcript 캡처
- Rundown 문서 작성
- AI → 슬라이드 플랜 → Remotion → 영상 (오프닝에서 보여준 그 영상)
- "기록이 없었다면 이 영상은 만들 수 없었다"

**Case 2: 미팅 기록 → 리서치 문서 + GitHub 공유**
- 김성진님 미팅 Transcript
- AI → 인사이트 추출 → 문서화 → 오픈소스 공개
- "대화도 기록하면 자산이 된다"

**Case 3: VibeLearn AI WorkLog → 학습 자료 재활용**
- 매 세션마다 WorkLog 작성
- AI가 다음 세션에서 이전 맥락을 바로 복원
- "기록이 AI의 장기 기억이 된다"

**Case 4 (간략): BeYouLifeUpWithUs — Vibe Guiding 사례**
- 이선생님과의 온라인 가이드 세션
- 세션 기록 → 다음 세션 연속성

**슬라이드**: 케이스별 Before/After 또는 flow 다이어그램

---

### 4부: 당신도 시작할 수 있다 (6분)

> **목적**: 청중이 오늘 바로 실행할 수 있는 구체적 제안

**① 무엇을 기록할까**
- 경험 (오늘 해본 실험)
- 인사이트 (깨달은 것)
- 실험 결과 (잘 됐든 안 됐든)
- 미팅/대화 내용
- 방송/강의 요약

**② 어떻게 기록할까 (도구 소개)**
- Obsidian: 텍스트 중심 로컬 기록
- GOBI Desktop: 음성/실시간 기록
- 형식: 완벽할 필요 없음, 파편적이어도 OK

**③ AI에게 어떻게 연결할까**
- 기록에 날짜와 맥락을 붙이면 AI가 검색 가능
- 구조화가 안 되어도 AI가 정리해 준다
- "기록을 시작하는 것이 먼저, 구조는 나중에"

**슬라이드**: 3단계 액션 카드 (기록 → 구조화 → AI 연결)
