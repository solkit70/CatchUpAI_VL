# M1 — 시니어 입구 조사

**모듈**: M1 / 시니어 입구 조사
**상태**: ✅ 완료 (2026-10-11 사용자 확인)
**예상 학습 시간**: 5시간
**다음 모듈**: [M2 — 첫 만남 자료 키트](../02-First-Meeting-Kit/README.md)

## 이 모듈이 하는 일

시니어가 AI를 처음 쓰려 할 때 어디서 막히는지, 이미 가진 자산 중 무엇을 쓸 수 있는지, 첫 대상(A 유형)이 어떤 분들일지를 정리한다. 모든 판단은 하나의 기준으로 내린다: **시니어가 처음에 진입 장벽을 덜 느끼는가.**

## 📚 학습 순서

1. [concepts/barrier-and-types.md](concepts/barrier-and-types.md) — 진입 장벽의 다섯 질문, 사례에서 확인된 가치와 장벽, 대상 유형 A~D
2. [guides/difficulty-map.md](guides/difficulty-map.md) — 만남에서 계속하기까지 단계별 어려움 지도 (근거 표기 포함)
3. [guides/asset-audit.md](guides/asset-audit.md) — 기존 가이드북·매뉴얼·신청서·Guiding 엔진 등을 시니어 입구 기준으로 판정
4. [examples/a-type-profile-and-cases.md](examples/a-type-profile-and-cases.md) — A 유형 가정 프로필, 익명 사례 세 건, 10/21 전후 모임 질문 후보 10개

## 이 모듈의 핵심 결과 (한 줄씩)

- 사용자 말씀으로 확인된 가장 큰 장벽은 **설치(VS Code)** 와 **원격 미팅 부담**이다.
- 사례 세 분이 공통으로 좋게 본 것은 **기록이 내 컴퓨터에 남고 정보가 밖으로 나가지 않는다**는 점이다.
- 이 가치가 클라우드 에이전트 입구와 부딪힐 수 있어 M4에서 시험으로 판단한다.
