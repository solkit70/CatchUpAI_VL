## 이 문서의 성격

첫 대상으로 예상되는 분들의 **가정 프로필**이다. 아직 만나지 않았으므로 사실이 아니라 10/21 전후 모임에서 확인할 가설이다. 사례는 익명이며 실명·연락처·상담 내용은 쓰지 않았다.

## A 유형 프로필 (가정)

| 항목 | 내용 | 상태 |
|---|---|---|
| 모집 경로 | 페더럴웨이의 한 선생님이 주변 시니어를 모집해 주기로 했다. 인원은 5명 이내 예상 | 사용자 말씀 |
| 경력 | 대부분 오랫동안 자기 사업을 운영해 오신 분들 | 사용자 말씀 |
| 컴퓨터 사용 | 쓰던 기능만 쓸 수 있고 다른 부분은 익숙하지 않다 | 사용자 말씀 |
| 평소 쓰는 도구 | 카카오톡은 잘 쓰신다. 이메일과 Google의 비즈니스 기능(Google 지도에 사업 노출, 후기 댓글 받기 등)은 대부분 경험이 있을 것이다 | 사용자 추정, 확인 필요 |
| 정보 노출에 대한 마음 | 정보가 밖으로 나가는 것을 염려할 가능성. 세 사례 모두 그랬다 | 사례 기반 가설 |
| 컴퓨터 종류 | Windows·macOS·크롬북 여부 | 모름 |
| 설치 권한·결제 카드 | 관리자 권한, 해외 결제 가능 카드 | 모름 |
| 하고 싶은 일 | 사업 정리, 후기 대응, 안내문 작성 등은 가설 | 모름 |
| 온라인 미팅 | 편안한지 불편한지 | 모름 (사례 S는 불편) |

## 익명 사례 (사용자 말씀 기반)

| 사례 | 상황 | 도움이 된 것 | 막힌 것 |
|---|---|---|---|
| U (유타주) | 60대, 몇 달간 주간 진행. 며칠 만에 자기 이야기를 녹음해 글·책으로 만드는 앱을 직접 만든 사례가 가이드북에 실려 있다 | 내 컴퓨터에 기록이 쌓이고 AI가 그 기록을 써서 점점 나를 잘 알게 된다. 정보가 밖으로 나가지 않아 안심 | VS Code 설치가 너무 어려웠다 |
| S (Shoreline, 식당 운영) | 제작자와 먼 곳에 거주. 몇 차례 진행 | U와 같음 | VS Code 설치가 너무 어려웠고, 온라인 미팅을 어려워해 계속 진행하기 힘들었다 |
| F (페더럴웨이, 상담 중) | 상담 과정에서 같은 방식을 접함 | 정보가 내 컴퓨터에 보관된다는 점에 같은 반응 | 이 사례는 아직 설치 단계 기록이 없다. 확인 필요 |

사례 F의 상담 내용은 🔒 내부 자료라서 이 폴더에 쓰지 않는다. 위 표의 칸은 사용자가 직접 말한 반응 하나뿐이다.

## 모임 질문 후보 10개 (M2에서 10문항 이내로 다듬는다)

1. 지금 컴퓨터로 가장 자주 하시는 일 세 가지는 무엇인가요?
2. 쓰시는 컴퓨터는 어떤 종류인가요? (Windows, 맥, 크롬북, 태블릿)
3. 이메일과 Google 비즈니스 기능(지도 노출, 후기 답글 등)을 어디까지 쓰고 계신가요?
4. 사업이나 일을 하시며 기록해 두셨으면 하는 노하우나 이야기가 있나요?
5. AI를 써 보신 적이 있나요? 있다면 어떤 것이고, 어떤 점이 불편했나요?
6. AI가 어떤 일을 대신 해 주면 가장 도움이 될 것 같으세요?
7. 내 정보가 내 컴퓨터 밖으로 나가는 것이 걱정되시나요? 어떤 정보가 특히 그런가요?
8. 프로그램을 새로 설치하거나 가입하는 일은 혼자 하실 수 있나요, 도움이 필요하신가요?
9. 온라인(화상) 미팅과 직접 만나는 것 중 어느 쪽이 편하신가요? 요일·시간대는요?
10. 배우는 데 쓸 수 있는 시간은 주에 얼마쯤인가요?

## 이 프로필이 설계에 주는 것

- 질문 2·8·9는 M3의 레벨 판정과 M4의 입구 선택(원격 세팅, 대면, 설치 대행)을 직접 좌우한다.
- 질문 3·6은 M2 시연 소재를 고르는 데 쓴다. Google 비즈니스 기능(예: 후기 답글 초안)은 A 유형이 이미 아는 곳이므로 시연 소재 후보지만, 가설이라 모임 답변을 본 뒤 정한다.
- 질문 7은 클라우드 에이전트를 입구로 쓸 때 가장 큰 변수다.
