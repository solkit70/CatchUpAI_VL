# M2 — 첫 만남 자료 키트

**모듈**: M2 / 첫 만남 자료 키트
**상태**: 🔄 진행 중 (문서 5종 초안 완료, 사용자 승인·소리 내어 읽기·리허설 대기)
**예상 학습 시간**: 5시간
**마감**: 2026-10-20 전 (의견 접수 모임 10/21 전후)
**이전 모듈**: [M1 — 시니어 입구 조사](../01-Senior-Difficulty-Map/README.md)
**다음 모듈**: M3 — 의견 접수 결과와 레벨 확정 (모임 직후, 폴더는 M3 시작 시 생성)

## 이 모듈이 하는 일

페더럴웨이 시니어 분들과의 첫 모임에서 쓸 자료를 만든다. 모임은 가르치는 자리가 아니라 **듣는 자리**이고, **설치나 가입을 시키지 않는다.** 모든 자료는 쉬운 말로 쓰고, 정해지지 않은 것(비용, 횟수, 방식)은 단정하지 않는다.

## 📚 사용 순서

1. [guides/meeting-flow.md](guides/meeting-flow.md) — 60분 모임 진행 순서와 사용자가 정해야 할 것
2. [guides/explanation-script.md](guides/explanation-script.md) — 말하는 사람용 3분 설명과 예상 질문
3. [examples/five-minute-demo.md](examples/five-minute-demo.md) — 가상 가게 후기 답글 시연, Codex→Muse 생활 질문 위임 후보와 대안
4. [guides/one-page-intro.md](guides/one-page-intro.md) — 참가자에게 나눠 드릴 한 장 소개 (인쇄본)
5. [examples/question-sheet.md](examples/question-sheet.md) — 말로 여쭙고 적는 10문항 질문지 (인쇄본)
6. [guides/consent-and-privacy.md](guides/consent-and-privacy.md) — 동의와 개인정보 초안 (사용자 승인 필요)

## 사용자가 정해야 하는 것

모임 방식(직접/온라인)과 길이, 시연 도구(로컬 기본안과 Muse 결과의 로컬 회수 후보 비교), 비용과 횟수 표기, 연락처, 동의 문구. 항목은 각 문서에 **[정해야 함]** 으로 표시했다.
