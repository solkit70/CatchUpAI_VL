> 시연은 **보여 주기만** 합니다. 참가자에게 설치나 가입을 시키지 않습니다. 기본 소재는 **가상의 가게**이며, 추가 후보는 개인 정보가 필요 없는 공개 장소 질문입니다. 실제 고객·후기·계정 정보는 화면에 올리지 않습니다.

## 시연 소재 (가설 — 모임 답변을 보고 바꿀 수 있음)

가상의 한식당 「해든 식당」에 올라온 Google 후기에 **사장님 말투의 답글 초안**을 AI가 쓰게 한다. A 유형은 이메일과 Google 지도 기능을 이미 써 봤을 가능성이 있어 낯설지 않다고 본다(사용자 추정, 확인 필요).

## 5분 흐름

| 시간 | 장면 | 보여 줄 것 | 전할 말 |
|---|---|---|---|
| 0:00 | 후기 한 건 | 화면에 가상 후기 2줄(칭찬 1건 또는 아쉬움 1건) | 「이런 후기가 올라오면 답을 쓰시지요」 |
| 0:30 | 말로 시키기 | 후기를 붙여 넣고 「사장님 말투로, 정중하고 짧게 답글 써 줘」 | 「그냥 말로 시킵니다」 |
| 1:30 | 결과 확인과 고치기 | 초안을 읽고 한 문장 고치게 시킴 | 「틀리거나 어색하면 말로 고칩니다. 최종 확인은 사람이 합니다」 |
| 2:30 | 기록으로 남기기 | 「이 가게의 말투 규칙을 기록해 줘」→ 내 컴퓨터 폴더에 파일이 생긴 것을 보여 줌 | 「이 기록이 내 컴퓨터에 남습니다」 |
| 3:30 | 다음에 이어서 | 새 후기를 주고 「이전 기록대로 답글」 | 「AI가 지난 기록을 읽고 이어서 합니다」 |
| 4:30 | 마무리 | — | 「오늘은 여기까지 보여 드렸습니다. 이제 여러분 이야기를 듣겠습니다」 |

## 사용 도구는 사용자가 고른다

| 선택 | 장점 | 걸리는 점 |
|---|---|---|
| A. 제 컴퓨터의 로컬 도구(VS Code + Claude Code) | 「기록이 내 컴퓨터에 남는다」를 파일로 직접 보여 줄 수 있다 | 화면에 코드 편집기가 보여 어렵게 느낄 수 있음. 글자를 크게 하고 폴더 화면 위주로 보여 줘야 함 |
| B. 클라우드 에이전트(Muse 웹) | 설치 없이 웹에서 바로 보여 줄 수 있고 무료 단계가 있다 | Muse만 사용하면 서비스에 기록된다. 결과를 복사·다운로드하거나 Codex로 가져와 로컬에 저장하는 후보를 추가했으며, 나중에 PC를 켜서 회수하는 전체 절차는 미시험 |

현재 기본 시연안은 A이며, B에 로컬 회수 단계를 붙이는 방법도 후보로 검토한다. Codex가 Muse의 답변을 로컬 문서로 정리한 사례가 있으므로 「A에서만 로컬 기록을 보여 줄 수 있다」는 기존 판단은 수정한다. 다만 지연 회수와 5분 시연의 성공은 아직 확인하지 않았으며, [클라우드 작성·로컬 회수 분석 후보](../../vl_materials/00-구상-정리와-추가-고려사항.md#9-클라우드에서-작성하고-나중에-로컬로-가져오기--분석-후보)를 M4·M5에서 평가한다. 선택은 사용자가 한다.

## 추가 시연 후보: Codex가 Muse에 생활 질문 위임

[실제 브라우저 업무 위임 사례](../../../AI-Agent-Apps-Compare/vl_materials/20261011_codex-muse-browser-delegation.md#관찰한-흐름)를 참고해 “Bonney Lake 주변 단풍 장소를 한국어로 추천해 주세요”를 생활형 시연 후보로 추가한다. 사용자가 Codex에 지시하자 Codex가 Muse 웹에 질문하고 한국어 결과를 받는 과정은 관찰했지만, 참가자의 이해도와 설치 부담 감소는 아직 시험하지 않았다. 기존 후기 답글 시연과 함께 검토할 후보이며 시연 도구 확정이나 M2 리허설 완료를 뜻하지 않는다.

| 장면 | 진행자가 보여 줄 것 | 쉬운 설명 |
|---|---|---|
| 원하는 결과 말하기 | Codex에 생활 질문과 한국어 답변 조건 입력 | “무엇을 알고 싶은지 말합니다.” |
| 다른 도구에 맡기기 | Codex가 브라우저의 Muse에 질문 입력 | “이 도구가 다른 도구에 일을 맡기는 모습입니다.” |
| 결과 읽고 확인하기 | 한국어 장소 목록과 미확인 표시 | “답이 맞는지 확인하고 고릅니다.” |
| 기록 남기기 | 로컬에 저장한 결과 문서 | “다음에도 이 기록을 열어 이어서 쓸 수 있습니다.” |

이미 설치·로그인된 진행자 컴퓨터에서 보여 주고 참가자에게 설치나 가입을 요구하지 않는다. 질문은 클라우드 서비스에 전달되고, 결과 파일만 로컬에 저장된다는 범위를 정확히 설명한다. 응답 대기나 연결 문제가 있으면 준비한 스크린샷을 사용하고, 실제 5분 내 진행 여부는 리허설에서 측정한다.

## 준비물과 점검

- [ ] 가상 후기 3건(칭찬 1, 아쉬움 1, 새 후기 1)을 파일로 준비
- [ ] 글자 크기를 크게 키운 화면(발표자 확대)
- [ ] 폴더 이름은 쉬운 말(예: 「내 가게 기록」)
- [ ] 시연 전에 한 번 끝까지 돌려 보기 (실제 소요 시간 측정)
- [ ] 인터넷이 안 될 때를 대비한 **스크린샷 또는 녹화본** 준비
- [ ] 개인 메일·일정 연결 없이 시연 (개인 정보가 화면에 나오지 않게)

## 실패했을 때의 대안

1. AI 응답이 늦으면 준비한 스크린샷으로 이어 간다.
2. 도구가 안 열리면 「오늘은 화면 대신 말씀으로 설명드릴게요」라고 하고 3분 스크립트로 돌아간다. 시연이 모임의 본론이 아니다.
3. 답글 초안이 어색하면 오히려 「틀릴 수 있으니 확인한다」는 설명 장면으로 쓴다.

## 아직 확인하지 못한 것

- 5분 안에 실제로 끝나는지: **리허설 필요(미실시)**
- 후기 소재가 참가자에게 와닿는지: 모임 질문 3번 답변으로 확인
