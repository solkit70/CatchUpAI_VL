> 이 문서는 **초안**입니다. 문구는 사용자가 정하고, 법적 효력이 필요하면 별도로 검토하세요. 온보딩 확정안에는 「별도 녹화 동의서는 아직 만들지 않았다」고 적혀 있습니다(Materials_For_Topics, 비공개). 지금은 모임 현장에서 말로 확인하고 간단히 적어 두는 정도의 초안입니다.

## 참가자께 말로 알릴 세 가지

1. 오늘 하신 말씀은 **이 과정을 만드는 데에만** 씁니다.
2. 이름과 사진은 **허락 없이 밖에 공개하지 않습니다.** 정리할 때는 이름 대신 P1, P2로 씁니다.
3. 녹화나 사진은 **허락하신 분만** 합니다. 허락하지 않으셔도 아무 불이익이 없습니다.

## 현장에서 확인할 항목 (참가자별, P코드로 기록)

| 항목 | 예 / 아니오 | 비고 |
|---|---|---|
| 오늘 말씀을 익명으로 정리해 과정 설계에 쓰는 것에 동의 | | |
| 사진 촬영 동의 | | |
| 녹화 동의 (동의 시 영상 콘텐츠에 쓰일 수 있음을 설명) | | |
| 다음 연락 방식 (전화 / 문자 / 카카오톡 / 이메일) | | |

연락처는 사용자만 보는 별도 목록에 두고, **이 폴더(공개 레포)에는 절대 넣지 않는다.**

## 이 과정에서 지킬 규칙

- 공개 레포와 영상에는 **실명, 연락처, 사업장 이름, 상담 내용**을 쓰지 않는다. 익명 사례만 쓴다.
- 동의하지 않은 분의 말씀과 모습은 사례나 영상에 쓰지 않는다.
- 동의 범위는 나중에 바뀔 수 있다. 바뀌면 이 표를 갱신한다.
- 참가자 정보에 AI를 쓸 때는 **실명과 연락처를 빼고** 쓴다.

## 이미 알고 있어야 할 사실

- 사례 분들이 좋아한 점은 **기록이 내 컴퓨터에 보관된다**는 것이다. 그러나 AI가 답을 만들려면 입력한 글이 AI 서비스로 전달될 수 있다. 참가자가 「내 정보가 밖으로 나가나요」라고 물으면 **정확한 범위를 설명할 수 있어야** 한다. 이 부분은 M4에서 선택한 입구에 따라 답이 달라지므로, 그 전까지는 [explanation-script.md](explanation-script.md)의 「예상 질문」 표를 사용자가 채워 둔다.

## 사용자가 정할 것

1. 위 세 가지 약속 문구를 그대로 쓸지
2. 현장 확인 항목을 종이로 받을지 말로만 확인할지
3. 사진·녹화를 아예 하지 않고 시작할지 (권장: 첫 모임은 하지 않음)
