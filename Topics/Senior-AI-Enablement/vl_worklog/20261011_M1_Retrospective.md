# Module Retrospective - M1

## 계획 대비 실제

| 항목 | 계획 | 실제 |
|---|---|---|
| 시간 | 5시간 | 시작·종료 시각 미기록. AI 작업은 한 세션에 끝났고 사용자 시간은 구술과 확인 정도 |
| 산출물 | 어려움 지도, 자산 감사, 프로필 | 계획 3종 + 개념 문서 1종 + README |
| 사례 요약 | 사용자에게 물어 익명 요약 | 사용자가 구술해 줌. 더 추가할 수 있다고 함 |

## 핵심 학습

1. 사용자 말씀으로 직접 확인된 장벽은 설치(VS Code)와 원격 미팅 부담 둘뿐이다. 나머지는 문서 근거이거나 가설이다.
2. 시니어가 좋아한 가치(기록이 내 컴퓨터에 남고 정보가 밖으로 안 나감)가 클라우드 입구와 부딪힐 수 있다. M4의 핵심 비교 축이 됐다.
3. 원격 세팅도 누군가에게는 장벽이다.

## 문제와 해결

- 상담 고객 건은 🔒 내부 자료라서 말씀하신 반응 한 줄만 썼다.
- 자산 감사에서 읽은 범위를 칸마다 표기하고 안 읽은 부분은 판정을 보류했다.

## Roadmap 정확도

M1 범위와 시간은 적절했다. 자산 감사를 정독까지 하려면 시간이 더 든다. 안 읽은 부분은 M6 전에 읽는 것으로 로드맵에 맞춰 두었다.

## 다음 모듈 준비

M2는 10/20 전 완료가 마감이다. 모임 장소(대면/원격)와 길이, 시연 도구는 아직 정해지지 않았다. 사용자 결정이 필요하다.
