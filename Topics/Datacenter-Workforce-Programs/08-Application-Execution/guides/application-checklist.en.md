# Application Checklist

Use this sheet to prepare, not to submit on someone else’s behalf.

| Program | Current requirement / action |
|---|---|
| Meta AWA Fiber | English résumé, application through CBRE/Avature, full-time four-week travel availability |
| BBCC Datacenter Academy | Ask about late admission/winter, tuition, financial aid, delivery mode, and work-based learning |
| Microsoft–NABTU | Identify the local apprenticeship training center that actually recruits |
| SW WA JATC | Confirm Inside Wireman eligibility, transcript rules, ETA Tech Math, aptitude test, and reopening |
| AWS WBLP | Create a job alert; submit only when a live posting exists |
| AWS Technical Apprenticeship | Do not proceed: veteran/military-spouse eligibility required |

Before any submission, verify the live application page, location, deadline, required documents, work authorization, and privacy implications.
