## ⑥ Amazon Technical Apprenticeship — **탈락 확정**

M2b 가 *"군 출신 한정 여부 미확인"* 으로 남긴 항목이다. 해소됐다.

> *"The Technical Apprenticeship program helps members of the **military community—veterans
> and their spouses**—transition to careers in cloud computing."*

**군 출신 본인 또는 배우자 전용이다.** 일반 지원 창구가 아니다.

[M7 탈락선 1번](../../07-Fit-and-Shortlist/guides/fit-criteria.md)이 *"군 복무를 요구하면 탈락"* 이므로
**기준 대입 결과 탈락**이다. 더 볼 것이 없다.

### 부수 확인 — 아마존 사내 프로그램은 직원 전용이다

| 프로그램 | 대상 |
|---|---|
| Technical Apprenticeship | 군 출신·배우자 |
| **Mechatronics & Robotics Apprenticeship (MRA)** | *"All **Amazon employees** can apply"* — **입사가 선행 조건** |
| **WBLP (⑤-a)** | **외부인 대상** |

> **아마존에서 외부인이 들어가는 교육 프로그램 문은 WBLP 하나다.**
> 나머지는 먼저 아마존 직원이 되어야 한다. ⑤-a 의 희소성이 이것으로 설명된다.

## ① Meta America's Workforce Academy — **M2 이후 전면 공개**

M2 는 *"공식 페이지에 지원 링크만 있고 날짜 없음 · 확인 불가"* 로 남겼다.
**8월 중 상세가 공개됐다.** M2 조사 시점에는 실제로 정보가 없었던 것이다.

### 확인된 내용

| 항목 | 내용 |
|---|---|
| 규모 | **$115M** 민간 이니셔티브 (첫해) |
| 비용 | **전액 무료** — 등록금·**여비·숙박** |
| 훈련 중 수입 | **유급** — *"paid while they train"* |
| 기간 | **4주** 집중 실습 |
| **취업** | *"After graduation, **a job with a Meta partner is already waiting**"* — **보장** |
| 자격 | **선행 경력 불필요.** 50개 주에서 지원 가능 |
| 취득 자격 | **NCCER** 자격 + AWA 수료증 |
| 트랙 | **파이버 기술자** · 건설 일반(construction-ready) |
| **2026 운영지** | **Louisiana · Ohio · Indiana · Texas** |
| 2027 | *"additional locations expected"* |
| 지원 | `meta.com/AmericasWorkforceAcademy` |
| 코호트 | *"graduations now happening every week"* — 상시 |

### 판정 — 조건은 최상급인데 **위치가 걸린다**

[M7 8개 기준](../../07-Fit-and-Shortlist/guides/fit-criteria.md)에 대입하면:

| # | 기준 | 판정 |
|---|---|---|
| 1 | 진입 요건 | ✅ **경력·학위 요구 없음** |
| 2 | 모집 시점 | ✅ **상시 코호트 — 지금 열려 있다** |
| 3 | **통근·체류** | ⚠️ **타주 4주 연속 체류.** 탈락선은 *"주 3일 이상 현지 체류"* |
| 4 | 훈련 중 수입 | ✅ **유급** |
| 5 | 소요 기간 | ✅ **4주** — 무수입 12개월 한도와 비교조차 안 된다 |
| 6 | 신체 | ⚠️ 건설·파이버 트랙. 요구 수준 미확인 |
| 7 | 병행 | ⚠️ 4주 전일 |
| 8 | 비용 | ✅ **$0 + 여비·숙박 지원** |

**3번 탈락선에 걸리지만, 이 탈락선의 취지를 다시 봐야 한다.**

M7 이 *"주 3일 이상 현지 체류 시 탈락"* 을 세울 때 상정한 것은
**"1년간 주 3일 통학"** 같은 장기 반복 부담이었다.
**4주 한 번 + 여비·숙박 지원 + 유급 + 취업 보장**은 성격이 다르다.

> 📌 **재검토 대상.** 탈락선을 그대로 적용하면 탈락이지만, 그 탈락선이 이 형태를
> 상정하고 만들어진 것이 아니다. **사용자 판단이 필요한 지점**이다.

### 다만 트랙이 건설·파이버다

M1 의 발견 *"6개 중 4개가 건설기 숙련직"* 이 여기에도 적용된다.
AWA 는 **데이터센터 운영 기술직(기술직 트랙)이 아니라 건설·인프라 트랙**이다.

M7 이 정한 **주 트랙 = 기술직 / 예비 트랙 = 숙련직** 구도에서 **예비 트랙**에 속한다.
