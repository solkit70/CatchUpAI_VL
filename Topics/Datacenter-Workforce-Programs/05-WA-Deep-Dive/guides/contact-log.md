## 이 문서의 용도

M2에서 "확인 불가"로 남긴 항목을 **직접 문의로 해소**한 기록을 남긴다. 일시·경로·답변을 적어 두면 나중에 같은 것을 두 번 묻지 않는다.

> ⚠️ **문의는 사용자가 직접 한다.** AI가 대리로 전화·이메일을 보내지 않는다. 이 문서는 **무엇을 어떻게 물을지**를 준비하고, 답변을 받아 채우는 자리다.

## 해소 기록

| | |
|---|---|
| 확인 항목 | 전기 견습 모집 시기 (M2에서 "확인 불가") |
| 경로 | psejatc.org 공개 페이지 |
| **답변** | **2026-05-01부터 신규 지원 접수 중단. 재개일 미정. 재개 시 최소 30일 전 공개 공지** (WA L&I 요건) |
| 부수 확보 | 온라인 지원 · **$75 비환불 지원비** · WA 운전면허 사본 필수 · 서류 60일 기한 · Renton 550 SW 7th St |

**M2의 "노조 견습은 마감일이 공개돼 있지 않다"는 판정이 이것으로 설명된다.** 마감일이 없는 게 아니라 **모집 자체가 열렸다 닫혔다 한다.**

### ✅ 2. WBLP 실제 공고 존재 여부 — API 조회로 해소 (2026-08-28)

| | |
|---|---|
| 확인 항목 | Kent WA에 WBLP 공고가 있는가 (M2b에서 M5로 이월) |
| 경로 | `amazon.jobs` 검색 JSON 엔드포인트 직접 조회 |
| **답변** | **전 세계 4건. 미국은 Plain City, Ohio 1건뿐. WA 0건** |

**웹 화면이 아니라 데이터 원천을 조회해 얻었다.** `web-data-extraction` 방법론 적용 사례다.

## 대기 중인 문의

### 🔴 1. BBCC — 가을 등록 마감이 임박했을 수 있다

| | |
|---|---|
| 대상 | **Tom Willingham** · 509-793-2321 · tomwi@bigbend.edu |
| 대안 창구 | computerscience@bigbend.edu |
| 긴급도 | **높음** — 오늘 8/28, WA 커뮤니티 칼리지 가을 학기는 통상 9월 하순 시작 |

**물어볼 것**

1. 데이터센터 과정 **2026년 가을 코호트 등록 마감일**은 언제인가
2. 지금 등록이 가능한가, 아니면 다음(겨울/봄) 코호트를 봐야 하는가
3. **Microsoft 장학금** 적용 요건과 신청 절차는 무엇인가 — 등록금·교재·응시료를 실제로 전액 커버하는가
4. 과정 **총 등록금**은 얼마인가 (장학금 미적용 시)
5. **원격·하이브리드 이수**가 가능한가 — Puget Sound 거주자가 통학 없이 이수할 방법이 있는가
6. 수료생의 **취업 경로** — Quincy 데이터센터 연계는 어떤 형태인가 (인턴십·채용 우대·보장 없음 중 무엇)

> **5번이 이 Topic에서 가장 값이 크다.** 원격 이수가 가능하면 [통근 분류](../examples/commute-feasibility.md)의 "이주 필요" 판정이 뒤집힌다.
