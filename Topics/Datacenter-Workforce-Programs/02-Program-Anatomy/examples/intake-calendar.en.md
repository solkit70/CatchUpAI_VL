## The conclusion first — no official deadline is published anywhere

**No official page for any of the six programs states an application deadline or
cohort start date.**

| Program | Intake info on the official page | Verdict |
|---|---|---|
| ① Meta AWA | "multiple cohorts per year" (secondary source) · official page has an apply link only, **no date** | Unconfirmed |
| ② MS Datacenter Academy | Community-college semester system → **each college's academic calendar is the deadline** | Needs per-college check |
| ③ MS NABTU | Ongoing (AI-literacy course) · apprenticeship entry follows TradesFutures/local-union schedules | Needs per-local check |
| ④ Google.org / etA | A funding program · intake run by IBEW/NECA regional training centers | Needs per-local check |
| ⑤ Amazon TWD | Not yet researched (sub-track breakdown pending in M2) | Unconfirmed |
| ⑥ Amazon Technical Apprenticeship | Official page has **no deadline** | Unconfirmed |

**This is the real result of exercise 2.** The goal was "obtain deadlines," and that
failed — but the reason it failed is itself informative: **most programs are run
through local institutions, so no national-level deadline exists.**

## Intake structure splits into three types

The failure to find a deadline turned out to be **structural**, not a research gap.

### Type A — national self-run intake (a deadline can exist)

| Program | Character |
|---|---|
| ① Meta AWA | Run directly by Meta, targets all 50 states, cohort-based |
| ⑥ Amazon Technical Apprenticeship | Run directly by Amazon, cohort-based |

→ **Only these two have anything resembling a "deadline."** The rest are different.

### Type B — tied to an institution's academic calendar

| Program | Who runs intake |
|---|---|
| ② MS Datacenter Academy | Each community college (e.g., Big Bend CC, Moses Lake WA) |

→ Deadline = **that college's semester enrollment deadline.** Asking Microsoft won't
  get an answer.

### Type C — tied to a local union/training provider's apprenticeship schedule

| Program | Who runs intake |
|---|---|
| ③ MS NABTU | TradesFutures apprenticeship-readiness network (34 states) |
| ④ Google.org | electrical training ALLIANCE (joint NECA + IBEW), regional training centers |

→ Deadline = **the local IBEW local or training center's apprenticeship intake
  schedule.** This varies by region, usually happens once a year, and is
  competitive once posted.
