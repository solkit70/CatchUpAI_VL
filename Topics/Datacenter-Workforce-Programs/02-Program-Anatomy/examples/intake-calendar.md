## 이 문서를 먼저 만든 이유

로드맵 규칙 1: **마감일이 로드맵을 앞지르면 순서를 바꾼다.**
M2의 실습 1(해부표)보다 이것을 먼저 했다. 로드맵 후반(M8)에 가서 마감을 확인하면
이미 닫혀 있을 수 있기 때문이다.

---

## 결론부터 — 공식 마감일은 어디에도 공개돼 있지 않다

6개 프로그램의 **공식 페이지 어디에서도 모집 마감일·코호트 시작일을 찾지 못했다.**

| 프로그램 | 공식 페이지의 모집 정보 | 판정 |
|---|---|---|
| ① Meta AWA | "multiple cohorts per year" (2차 자료) · 공식 페이지에는 지원 링크만 있고 **날짜 없음** | 확인 불가 |
| ② MS Datacenter Academy | 커뮤니티 칼리지 학기제 → **각 대학 학사일정이 곧 마감** | 대학별 확인 필요 |
| ③ MS NABTU | 상시 성격(AI 리터러시 과정) · 견습 진입은 TradesFutures/지역 노조 일정 | 지역 local별 확인 필요 |
| ④ Google.org / etA | 자금 지원 프로그램 · 모집 주체가 IBEW/NECA 지역 훈련센터 | 지역 local별 확인 필요 |
| ⑤ Amazon TWD | 미조사 (M2에서 하위 트랙 분해 미완) | 미확인 |
| ⑥ Amazon Technical Apprenticeship | 공식 페이지에 **마감일 없음** | 확인 불가 |

**이것이 실습 2의 실질 결과다.** "마감일을 확보한다"가 목표였는데 확보하지 못했고,
확보할 수 없는 이유가 드러났다 — **대부분의 프로그램이 지역 기관을 통해 모집하므로
전국 단위 마감일이 존재하지 않는다.**

## ⚠️ 확인이 필요한 미검증 주장 — 마감이 7일 뒤일 수 있다

2차 집계 사이트(apprenticeship 정보 취합 서비스)가 이렇게 적고 있다.

> "The spring 2026 intake closes in most markets by March 15,
> and the fall intake closes by **August 30**."
> — Amazon Technical Apprenticeship 관련, 출처: 집계 사이트

**오늘은 2026-08-23이다. 사실이라면 7일 남았다.**

그런데 **Amazon 공식 페이지 두 곳(`amazon.jobs` 군 대상 랜딩, `aboutamazon` 기사)
어디에도 이 날짜가 없다.** 1차 출처로 확인되지 않은 주장이다.

### 어떻게 다룰 것인가

M1에서 정한 원칙 — *인상적인 숫자일수록 원출처 확인이 필요하다* — 을 따른다.
**사실로 취급하지 않되, 무시하지도 않는다.**

- [x] **최우선 확인 항목**: Amazon 채용 포털에서 Technical Apprenticeship 공고를 직접 열어
      실제 지원 창이 열려 있는지, 마감이 표시되는지 확인
- [x] 열려 있고 마감이 임박했다면 → **로드맵 규칙 1 발동**
- [x] 닫혀 있다면 → 다음 코호트 일정을 문의하고 알림 설정

## ✅ 판정 결과 (2026-08-28) — 근거 없음. 로드맵 정상 순서 유지

**공식 페이지를 직접 열어 확인했다. 8월 30일 마감은 어디에도 없다.**

| 확인 대상 | 결과 |
|---|---|
| `amazon.jobs` Technical Apprenticeship 공식 페이지 | **마감일·코호트 시작일 표기 자체가 없음** |
| `aboutamazon` AWS 견습 기사 | 마감 언급 없음. 2021년 지원자가 *"final day for applications"* 에 지원했다는 일화만 존재 → **상시 모집 정황** |

**판정: 8/30 마감 주장은 1차 출처로 확인되지 않는다.** 5일 전(8/23) 판단대로 **정상 순서를 유지한다.** M3~M7을 건너뛸 이유가 없다.

> 💡 **이 판정 자체가 M2의 성과다.** "7일 남았다"는 숫자는 행동을 촉구하는 힘이 세다. 그 압박에 로드맵을 흔들지 않고 확인 후에 판단한 것이 옳았다. 만약 8/23에 그 주장을 믿고 순서를 바꿨다면, **오늘 확인해 보니 근거가 없는 마감** 때문에 조사 단계를 통째로 건너뛴 상태였을 것이다.

### 부수 확인 — ⑥은 애초에 해당 없을 가능성이 높다

마감을 확인하러 들어간 김에 두 가지가 더 드러났다.

1. **자격**: 공식 페이지는 여전히 *"members of the military community—veterans and their spouses"* 만 명시한다. 확대 주장은 2차 자료뿐이고 범위도 밝히지 않는다
2. **직무**: 현재 7개 트랙이 **전부 클라우드 직군**이다. Data Center Technician이 없다

→ 마감이 있었더라도 본인에게는 지원 대상이 아니었을 공산이 크다. 상세: [program-anatomy.md](program-anatomy.md) ⑥ 절.

## 모집 구조가 셋으로 갈린다

마감일을 못 찾은 것이 조사 부실이 아니라 **구조 때문**임이 드러났다.

### 유형 A — 전국 단위 자체 모집 (마감일이 있을 수 있음)

| 프로그램 | 성격 |
|---|---|
| ① Meta AWA | Meta가 직접 운영, 전국 50개 주 대상, 코호트 단위 |
| ⑥ Amazon Technical Apprenticeship | Amazon 직접 운영, 코호트 단위 |

→ **이 둘만 "마감일"이라는 개념이 성립한다.** 나머지는 다르다.

### 유형 B — 교육기관 학사일정에 종속

| 프로그램 | 모집 주체 |
|---|---|
| ② MS Datacenter Academy | 각 커뮤니티 칼리지 (예: Big Bend CC, Moses Lake WA) |

→ 마감일 = **그 대학의 학기 등록 마감**. Microsoft에 물어도 답이 없다.

### 유형 C — 지역 노조·훈련기관 견습 일정에 종속

| 프로그램 | 모집 주체 |
|---|---|
| ③ MS NABTU | TradesFutures 견습 준비 프로그램 네트워크 (34개 주) |
| ④ Google.org | electrical training ALLIANCE (NECA + IBEW 공동), 지역 훈련센터 |

→ 마감일 = **지역 IBEW local 또는 훈련센터의 견습 모집 일정.**
  이건 지역마다 다르고, 보통 연 1회이며, 공고가 나면 경쟁이 치열하다.
