## Purpose of this table, and what not to do with it

Builds the **evidence base** to be used in M7 (fit assessment) ahead of time.

> ⛔ **Rule 3 — do not write personal judgment into this document.**
> Don't add statements like "this fits me / this is too much / this is realistic."
> Record facts only; judgment happens in M7, using this table. Mixing in judgment
> now turns **the table into a tool that justifies a conclusion instead of
> informing one.**

## 7 fields × 2 tracks

| Field | **Track A — construction-phase trades** (electrician example) | **Track B — operations-phase technician** (Data Center Technician example) |
|---|---|---|
| **1. Entry requirement** | Pass selection at the local union JATC. Pre-apprenticeship completion gives priority. Specifics are set per local's own standards | **B-1** standard college admission / **B-2** no requirement officially stated — target includes *"high school or college graduates"*; cases exist of completing with a HS diploma and no experience |
| **2. Total duration** | **8,000 hrs on-the-job + 96 hrs classroom** → ~4–5 years, then the (01) licensing exam | **B-1** 1 yr (certificate) or 2 yrs (associate) / **B-2** **12 months** |
| **3. Total cost** | Free–low cost (union apprenticeship) | **B-1** tuition — MS scholarship covers tuition, books, exam fees / **B-2** **free** |
| **4. Income during training** | **Yes** — starts as a percentage of journeyman wage, escalating with hours/skill. **Starting percentage varies by program, no single value** | **B-1** none / **B-2** **yes (paid)** — amount not stated on the official page |
| **5. Physical requirements** | Construction-site work. Includes heights, heavy loads, outdoor work. **Specifics set in the local's own standards; unconfirmed in this research** | Facility-based equipment work inside a data center. Install/decommissioning roles include handling heavy loads. **Specifics unconfirmed** |
| **6. Age-related rules** | **No maximum age** in DOL/WSATC apprenticeships. Minimum age set per program (typically 18). Target explicitly includes *"career changers"* (① Meta AWA) | **No age requirement stated** |
| **7. Need to relocate** | Move project to project. Assigned within the union's jurisdiction. ① Meta AWA provides **all 50 states + airfare/lodging** | **B-1** commute to Moses Lake WA / **B-2** resident at the assigned site — e.g. **Kent, WA** |

## Sourcing per field

**1·2·4 (Track A)** — WA L&I electrical apprenticeship page and WSATC program
standards. Wages are defined as a *"progressively increasing wage scale ... based
on the specified journey-level wage,"* but the starting percentage differs by standard.

**1·2·3·4 (Track B-2)** — `amazon.jobs` AWS Work-Based Learning Program and AWS
Grow Our Own Talent pages. *"12-month paid training program,"* *"promoted into
their chosen roles at an AWS data center."*

**3 (Track B-1)** — M2 anatomy table, ② Microsoft Datacenter Academy.

**7** — M2 anatomy table, ① (all 50 states + airfare/lodging) and ⑤ (Haymarket VA
· Kent WA · Aurora CO).

## Unconfirmed items — blanks to fill before judging

| Item | What's missing | Next step |
|---|---|---|
| **4. Starting apprentice wage** | Percentage vs. journeyman | L&I Apprentice Wage Lookup, Puget Sound Electrical JATC |
| **4. WBLP wage** | Actual take-home pay during training | M5 — Kent WA postings (WA requires wage disclosure) |
| **5. Physical requirements** | **Unconfirmed for both** | Track A: the local's standards; Track B: the "physical requirements" field on actual postings |
| **1. JATC selection** | Competitiveness, waitlist, exam content | M5 — contact Puget Sound Electrical JATC directly |

**Item 5 is blank for both tracks.** Both are hands-on work, and this doesn't
appear well on official pages. **It only gets filled by reading the "physical
requirements" wording on real postings.** It directly affects the M7 decision,
so it must be secured in M5.
