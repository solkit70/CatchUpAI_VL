# What You Can Start Remotely Now

**Research date**: 2026-08-30 (M6 Exercise 2)

When application doors are closed, waiting can still become preparation. BBCC prepares students for CompTIA A+, Network+, Server+, and Microsoft credentials; those credentials can be pursued without enrolling at BBCC.

## Options

1. **CompTIA A+**—two exams (Core 1 and Core 2), $253 each / $548 total, online proctoring available.
2. **CompTIA Network+**—N10-009, $399 list price (authorized resellers may be lower), online proctoring available.
3. **Cisco Networking Academy and Packet Tracer**—free learning and simulator; virtual labs are an industry-standard way to practice networking.
4. **Microsoft Learn**—free learning paths for Windows Server; certification exams are separate.
5. **Linux with a VM**—free home server practice.

## Priority

Start with Packet Tracer, Microsoft Learn, and Linux VM practice. They cost nothing and test whether the work fits before paying exam fees. Then consider A+ and Network+.

## Do not assume credit

Certification can strengthen a résumé and make classes easier even if it does not shorten the certificate. Ask BBCC whether A+, Network+, NetAcad work, or another Credit for Prior Learning policy applies to this program.

## Questions for BBCC

Ask course-by-course OL/H availability; whether CS 103 requires real hardware; whether work-based learning is mandatory and must be in Moses Lake; and whether A+/Network+ obtain course credit.
