## 왜 사례를 따로 두는가

**내 조건에서 탈락한 것이 남에게는 최선일 수 있다.**

나는 워싱턴주 서부에 살고, 당장 수입이 필요하고, IT 경력 20년이 있다.
이 세 조건이 판단을 전부 좌우했다. **조건이 다르면 결론도 달라진다.**

그래서 [[Ingest/CatchUpAI_VL/Topics/Datacenter-Workforce-Programs/09-Public-Guide/public-guide|일반 안내]]와 이 사례를 분리했다.
안내는 누구에게나 적용되는 것만 담고, **여기에는 내 조건에서 나온 판단**을 적는다.

## 내 조건

| 항목 | 내용 |
|---|---|
| 거주 | 워싱턴주 Bonney Lake (서부). **주 거주 6년차** |
| 경력 | IT 약 20년 — 소프트웨어 개발, QA·테스트 자동화, 클라우드 인프라 |
| 자격 | AWS Certified Cloud Practitioner · 학사 |
| 🔴 **가장 중요한 조건** | **당장 생활비가 들어와야 한다** |

## 열흘 동안 일어난 일

| 날짜 | |
|---|---|
| 08-23 | 조사 시작. 프로그램 6개 확인 |
| 08-28~30 | 전미 지도 · 원격 경로 · 적합성 판별 |
| 08-31 | 타주 4주 체류 수용 결정 → 지원 확정. 이력서 작성 |
| **09-01** | ⭐ **Meta AWA 제출.** 나머지 5개 정리 |
| 09-02 | BBCC 재발송 |

**6개가 1개로 좁혀졌다.** 각각 다른 이유로 정리됐다.

| # | 프로그램 | 결과 | 왜 |
|---|---|---|---|
| ① | **Meta AWA (LevelUp)** | ✅ **제출** | 무료·유급·4주·조건부 채용. 이력서 하나면 됐다 |
| ② | BBCC | 🔻 4순위로 강등 | **수입 경로가 아니다** |
| ③ | NABTU | 닫음 | ④의 구조가 답을 대신했다 |
| ④ | SW WA JATC | 정보 수집으로 전환 | 5년 · 시작 임금 40% |
| ⑤ | AWS WBLP | 자동 감시 | WA 공고 0건이 3회 반복 |
| ⑥ | Amazon Technical Apprenticeship | ❌ 탈락 | 군 출신·배우자 전용 |

## 판단이 뒤집힌 순간

**오전까지 BBCC 는 2순위였다. 오후에 4순위로 내려갔다.**

프로그램을 다시 조사해서가 아니다. **목적을 명시했더니 순위가 바뀌었다.**

> "당장 생활비 들어오는게 목적이라서 Meta AWA 나 caregiver 자리를 알아보는 건데요.
> 여기는 당장 생활비 들어오는 과정이 아닌 것 같습니다."

같은 조건(1년 과정 · 자비 부담 · 취업 보장 없음)이 **기준이 바뀌자 장점에서 결격 사유가 됐다.**

📌 **이것이 이 사례에서 남에게 가장 쓸모 있는 부분이라고 생각한다.**
프로그램을 비교하기 전에 **자기 목적을 한 문장으로 적어 보는 것**이 순서다.

## 세 가지가 예상과 달랐다

### ① 병목은 자격이 아니라 지리였다

20년 경력이면 요건은 대부분 넘는다. 그런데 **WA 에 공고가 없었다.**
AWS WBLP 는 세 번 확인하는 동안 계속 0건이었다.

Meta AWA 지원 폼에서 이것이 그대로 드러났다 — **「희망 근무지」가 고정 목록이었고 워싱턴이 없었다.**
결국 `Anywhere (traveler status)` 를 선택했다. 조사 내내 걸렸던 문제가 **폼의 드롭다운에 그대로 있었다.**

### ② 하나를 제대로 파면 이웃 항목이 함께 정리된다

③ NABTU 는 **조사하지 않고 닫았다.** ④ JATC 의 실제 조건(5년 · 무급 야간수업 · 시작 임금 40%)을
확인하고 나니, 같은 건설 노조 견습인 ③을 따로 볼 이유가 사라졌다.

### ③ 이름이 직종을 알려주지 않는다

`Inside Wireman` 을 소프트웨어 직군으로 오해했다. 지원 시험에 **대수와 독해**가 있어서였다.
실제로는 **SOC 47-2111 건물 전기공**이고, 대수는 옴의 법칙·전압강하 계산용,
독해는 전기 코드(NEC) 를 읽기 위한 것이었다.

## 도구를 쓰면서 배운 것 두 가지

### AI 가 추론으로 채운 값이 오류가 됐다

Claude 가 "Tehaleh 2025-10 입주"를 **워싱턴주 도착 시점으로 읽고** 주내 등록금 요건에 대해
잘못된 결론을 냈다. 실제로는 **2020년 7월부터 WA 거주**였다.

⚠️ **8/31 문서에는 이 부분이 유보 표현으로 남아 있었는데, 9/1 재작성에서 단정으로 바뀌었다.**
정보가 늘어서가 아니라 **다시 쓰는 과정에서 헷지가 탈락했다.**
→ 날짜·거주·자격 같은 값은 **본인이 직접 확인**하는 편이 안전하다.

### 살아 있는 페이지에 죽은 주소가 있다

BBCC 문의 메일이 **수신·참조 두 주소 모두 반송**됐다. 둘 다 학교가 공개한 주소였다.
확인해 보니 담당자가 **교직원 디렉토리에 없었다** — 안내 페이지가 갱신되지 않은 것이다.

→ **프로그램 안내 페이지의 담당자 정보는 기관의 교직원 디렉토리에서 교차 확인한다.**
같은 페이지의 다른 두 이름도 디렉토리에 없었고, **통과한 것은 한 명뿐**이었다.
