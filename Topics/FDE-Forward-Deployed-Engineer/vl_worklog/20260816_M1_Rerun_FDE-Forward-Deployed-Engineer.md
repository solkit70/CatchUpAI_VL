## 문제 해결 로그

### 문제 1: 기존 M1은 완료되었지만 절차가 잘못됨

**증상**:
M1 산출물은 존재하고 DoD도 충족했지만, VibeLearn AI의 일일 학습 절차인 "오늘의 학습 계획 제시 → 사용자 승인 → 진행"이 누락되어 있었다.

**원인**:
Roadmap 승인과 일일 학습 세션 승인을 혼동했다.

**해결**:
이번 세션부터 `daily_learning_prompt.md`를 실행 프롬프트로 사용했다. 사용자에게 M1 재진행 계획을 제시하고 승인을 받은 뒤 파일 보강을 진행했다.

### 문제 2: 기존 문서가 설명 중심으로 치우침

**증상**:
M1 문서는 개념 설명은 충분했지만, 학습자가 직접 수행할 실습과 자기평가가 부족했다.

**원인**:
초기 작성이 산출물 제작 중심으로 진행되었고, VibeLearn AI의 "다음 학습자가 재사용 가능한 교재형 산출물" 기준이 충분히 반영되지 않았다.

**해결**:
각 문서에 학습 활동, 실습, 확인 질문, 자기평가 항목을 추가했다.
