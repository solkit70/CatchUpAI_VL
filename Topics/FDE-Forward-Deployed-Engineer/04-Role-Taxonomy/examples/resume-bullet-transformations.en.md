# Resume Bullet Transformations

## Transformation Formula

Weak bullets describe tasks. FDE-style bullets describe customer problem, technical action, deployment context, and impact.

```text
Transformed [customer workflow/problem] by [technical action], enabling [deployment/adoption/result] under [constraint].
```

## Software Engineer Example

Before:

```text
Built backend APIs for internal tools.
```

After:

```text
Built backend APIs for an internal operations workflow, integrating role-based access and audit logging to support production use by 120 customer-facing staff.
```

## SI / Implementation Example

Before:

```text
Participated in ERP implementation project.
```

After:

```text
Mapped finance and operations workflows during an ERP rollout, translating stakeholder requirements into integration scope, data migration checks, and user adoption milestones.
```

## Consultant Example

Before:

```text
Created digital transformation strategy for a client.
```

After:

```text
Led discovery for a digital transformation initiative, identifying three high-friction workflows and converting them into phased automation pilots with success metrics and rollout owners.
```

## PM Example

Before:

```text
Managed AI chatbot project.
```

After:

```text
Scoped and launched an AI support assistant pilot, aligning support, legal, and engineering stakeholders around escalation rules, answer quality metrics, and post-launch feedback loops.
```

## Data Engineer Example

Before:

```text
Built ETL pipelines for reporting.
```

After:

```text
Built data pipelines that unified fragmented customer operations data, enabling downstream AI-assisted triage and reducing manual reporting effort by 35%.
```

## Solutions Engineer Example

Before:

```text
Delivered product demos to enterprise customers.
```

After:

```text
Converted enterprise demo feedback into technical integration requirements, building tailored proof-of-concept workflows that unblocked security and data readiness reviews.
```

## Non-IT Domain Expert Example

Before:

```text
Worked on insurance claim review process.
```

After:

```text
Documented insurance claim review workflows and designed an AI-assisted triage prototype, defining risk categories, human review checkpoints, and measurable review-time reduction targets.
```

## Bad vs Good Pattern

| Weak Pattern | Stronger FDE Pattern |
|---|---|
| "Worked on AI project" | "Designed an AI workflow for a defined user and measured adoption" |
| "Used ChatGPT to automate tasks" | "Built a repeatable workflow with data boundary, eval, and handoff" |
| "Met with customers" | "Translated customer workflow constraints into technical scope" |
| "Created dashboards" | "Built adoption dashboard tied to rollout decisions" |

## Final Check

Each FDE-style bullet should answer at least three of these:

- What customer or workflow problem existed?
- What technical action did you take?
- What system or data boundary did you handle?
- What changed in production or operations?
- What metric or outcome improved?
- What reusable learning came from the work?
