# M4 - FDE and Adjacent Role Taxonomy

**Status**: Complete  
**Estimated study time**: 4h  
**Module goal**: Compare FDE with adjacent roles and learn how to read job titles without misjudging the actual work.

## Learning Order

1. [concepts/role-taxonomy.en.md](concepts/role-taxonomy.en.md)  
   Maps FDE against software engineer, solutions engineer, sales engineer, solutions architect, consultant, ML engineer, and implementation roles.

2. [guides/role-title-reading-guide.en.md](guides/role-title-reading-guide.en.md)  
   Provides a practical method for reading job postings by work pattern rather than title.

3. [examples/resume-bullet-transformations.en.md](examples/resume-bullet-transformations.en.md)  
   Shows how to convert existing work experience into FDE-style resume bullets.

## Core Takeaway

FDE is not defined by title alone. A posting may say FDE but behave like solutions engineering, or say applied AI engineer while containing FDE-like customer deployment work. Read the verbs, outputs, customer exposure, coding depth, and adoption responsibility.
