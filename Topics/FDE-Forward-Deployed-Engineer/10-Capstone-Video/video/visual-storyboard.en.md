# Visual Storyboard for Remotion Handoff

## Common Visual Direction

- Use a clean enterprise visual style.
- Prefer diagrams, role maps, lifecycle pipelines, and comparison tables.
- Keep each scene focused on one message.
- Use progressive reveal for dense information.
- Treat this file as pre-production input, not final Remotion code.
