# M10 - Portfolio and Remotion Video Capstone

**Status**: Complete  
**Estimated study time**: 6h  
**Module goal**: Convert the FDE learning topic into a candidate portfolio package and pre-production handoff documents for Remotion video creation.

## Learning Order

1. [guides/fde-portfolio-guide.en.md](guides/fde-portfolio-guide.en.md)  
   Explains how an FDE portfolio differs from a normal SWE portfolio.

2. [examples/portfolio-project-specs.en.md](examples/portfolio-project-specs.en.md)  
   Provides three implementable FDE portfolio project specs.

3. [guides/fde-interview-prep.en.md](guides/fde-interview-prep.en.md)  
   Defines the final candidate guide package and interview preparation structure.

4. [video/remotion-series-outline.en.md](video/remotion-series-outline.en.md)  
   Converts the topic into a six-episode educational video series.

5. [video/episode-scripts.en.md](video/episode-scripts.en.md)  
   Provides draft hooks, narration flows, and closing lines for each episode.

6. [video/visual-storyboard.en.md](video/visual-storyboard.en.md)  
   Provides scene-level visual direction for Claude Code or another Remotion implementation agent.

## Scope

This module stops before actual Remotion implementation. It does not create a Remotion project, generate assets, render video, or produce MP4 output. It prepares the content, script, storyboard, and implementation boundary.
