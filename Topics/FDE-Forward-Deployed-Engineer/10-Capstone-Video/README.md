# M10 - 포트폴리오와 Remotion 영상화 Capstone

**상태**: 완료  
**예상 학습 시간**: 6h  
**모듈 목표**: FDE 학습 결과를 지원자용 포트폴리오 패키지와 Remotion 영상 제작 전 단계의 기획 산출물로 재구성한다.

## 학습 순서

1. [guides/fde-portfolio-guide.md](guides/fde-portfolio-guide.md)  
   FDE 포트폴리오가 일반 SWE 포트폴리오와 다른 점을 정리하고, customer scenario, architecture, eval, rollout, adoption metric 중심의 구성법을 제시한다.

2. [examples/portfolio-project-specs.md](examples/portfolio-project-specs.md)  
   바로 구현 가능한 FDE 포트폴리오 프로젝트 3개 spec을 enterprise customer scenario 기준으로 설계한다.

3. [guides/fde-interview-prep.md](guides/fde-interview-prep.md)  
   FDE 지원자 최종 가이드 패키지 목차와 면접 유형별 준비 전략을 정리한다.

4. [video/remotion-series-outline.md](video/remotion-series-outline.md)  
   FDE Topic을 6편 영상 시리즈로 재구성한 curriculum outline을 제공한다.

5. [video/episode-scripts.md](video/episode-scripts.md)  
   각 에피소드의 30초 hook, narration 흐름, 주요 장면 메시지를 초안 형태로 작성한다.

6. [video/visual-storyboard.md](video/visual-storyboard.md)  
   Claude Code가 Remotion 제작을 시작할 수 있도록 scene, visual asset, motion cue, source document를 연결한다.

## 범위

이 모듈은 Remotion 실제 구현 전 단계까지 다룬다. Remotion 프로젝트 생성, 컴포넌트 구현, asset 생성, TTS, subtitle, MP4 렌더링은 포함하지 않는다. 대신 Claude Code에게 넘길 수 있는 제작 요구사항과 장면 설계 문서를 준비한다.

| 영상 script | `video/episode-scripts.md` | 에피소드별 내레이션 초안 |
| 영상 storyboard | `video/visual-storyboard.md` | Remotion 제작용 장면/시각화 지시 |
