# Junior Portfolio Project Briefs

## Project 1: Domain RAG Assistant

### Scenario

A small operations team needs to answer repeated questions from internal policy documents. The assistant retrieves relevant passages and generates answers with citations.

### What It Proves

- document ingestion
- retrieval
- citation discipline
- answer quality eval
- user-facing demo ability

### Success Metric

- 90% citation accuracy on a 30-question eval set
- average user usefulness score above 4/5

## Project 2: Workflow Automation Assistant

### Scenario

A support team receives messy intake requests. The system classifies request type, extracts key fields, and suggests next actions.

### What It Proves

- structured output
- classification
- workflow mapping
- human-in-the-loop design
- routing accuracy eval

### Success Metric

- 85% correct classification on labeled examples
- human override rate below 20%

## Project 3: Eval Dashboard

### Scenario

An AI assistant is already answering questions, but the team needs to track quality, latency, cost, and failure types.

### What It Proves

- eval thinking
- observability mindset
- dashboard design
- production-readiness awareness

### Success Metric

- dashboard shows answer quality, failure type, latency, cost, and user feedback
- each model or prompt change can be compared against prior baseline
