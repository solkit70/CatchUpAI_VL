# Six-Month Junior Preparation Plan

## Goal

The goal is not to become a senior FDE in six months. The goal is to become credible for junior, associate, solutions engineering, implementation, or applied AI roles that can lead toward FDE.

## Monthly Plan

| Month | Focus | Output |
|---|---|---|
| 1 | FDE and adjacent role understanding | Target role map and job posting notes |
| 2 | Backend/API/data basics | Small API integration project |
| 3 | RAG and AI workflow basics | Domain Q&A assistant |
| 4 | Evals and reliability | Eval set, failure taxonomy, improvement log |
| 5 | Portfolio project polishing | README, architecture, demo script |
| 6 | Applications and interview prep | Resume bullets, mock interviews, target company list |

## Weekly Routine

| Time Block | Activity |
|---|---|
| 2h | Technical build work |
| 1h | Job posting analysis |
| 1h | README and portfolio writing |
| 1h | Interview or demo practice |

## Portfolio Requirements

At the end of six months, the candidate should have:

- one polished AI workflow project
- one smaller supporting project
- a clear FDE-style resume narrative
- a 5-minute demo script
- a target company matrix
- answers to customer scenario interview questions

## Application Strategy

Junior candidates should apply broadly across FDE-adjacent roles:

- Forward Deployed Engineer Intern/Associate
- Solutions Engineer
- Implementation Engineer
- Applied AI Engineer
- AI Adoption Engineer
- Technical Consultant
- Customer Engineer

The first role does not need to be titled FDE. It should provide customer-facing technical evidence.
