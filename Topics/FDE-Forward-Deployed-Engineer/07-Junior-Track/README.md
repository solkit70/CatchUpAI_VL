- FDE 공고의 senior-level 요구사항을 junior-friendly milestone으로 번역할 수 있다.

## 핵심 요약

M6에서 확인한 미국 FDE 공고는 대부분 4-7년 이상의 실무 경험, production code, customer-facing delivery, evals, cloud, security, ambiguous scoping을 요구한다. 따라서 학생/주니어의 현실적인 전략은 "FDE 타이틀 직행"이 아니라 FDE형 증거를 만드는 것이다.

> "Production-grade engineering"

M6의 공통 역량 첫 번째 신호다. 주니어는 대규모 production 운영 경험이 부족할 수 있으므로, 작지만 작동하는 end-to-end workflow, 실패 처리, 로그, eval, 배포 기록으로 이를 대체 증명해야 한다.

> "Customer-facing technical delivery"

FDE는 기술만으로 평가되지 않는다. 학생/주니어는 실제 고객이 없더라도 동아리, 연구실, 소상공인, 비영리, 내부 팀 같은 작은 사용자 그룹을 대상으로 problem discovery와 feedback loop를 경험해야 한다.

## M7의 결론

학생/주니어가 바로 OpenAI, Anthropic, Scale AI의 senior FDE 공고에 맞는 경우는 드물다. 하지만 6개월 동안 AI workflow project, eval evidence, deployment habit, customer problem narrative를 만들면 Applied AI Engineer, Forward Deployed Software Engineer, Field Engineer, Solutions Engineer, Implementation Engineer 같은 우회 경로에 가까워질 수 있다.
