## 핵심 결론

비IT 배경자가 미국식 FDE에 바로 들어가는 것은 일반적으로 어렵다. FDE는 고객 문제를 이해하는 능력뿐 아니라 API, 데이터 흐름, 프로토타입 구현, production handoff, technical debugging을 요구하기 때문이다. 다만 domain specialist, AI consultant, implementation analyst, GTM engineer, vertical solution specialist 같은 역할을 통해 FDE 생태계에 들어간 뒤 기술 깊이를 키우는 경로는 현실적이다.

글로벌 문맥에서는 용어를 섞어 쓰면 판단이 흐려진다. 미국의 FDE는 대체로 role/title 중심이며 startup GTM, product adoption, customer deployment와 연결된다. 한국 AX와 일본 DX to AX는 조직 전환, 컨설팅, SI, 대기업 혁신 프로그램의 언어로 쓰이는 경우가 많고, 유럽은 regulated enterprise AI와 compliance boundary가 강하게 작동한다.
