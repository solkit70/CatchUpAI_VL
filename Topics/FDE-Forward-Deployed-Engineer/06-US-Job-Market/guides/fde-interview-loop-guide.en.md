# FDE Interview Loop Guide

## Likely Interview Stages

| Stage | What It Tests | How to Prepare |
|---|---|---|
| Recruiter Screen | Motivation, fit, location, communication | 60-second FDE narrative |
| Hiring Manager | Ownership, ambiguity, customer judgment | 3 project stories |
| Technical Screen | Coding, APIs, data, debugging | Small backend or AI workflow exercise |
| System Design | Architecture and trade-offs | RAG/agent/eval/security design template |
| Customer Scenario | Discovery and scoping | Question bank and structured response |
| Portfolio Demo | Evidence of FDE-like work | 5-minute demo script |
| Executive/Bar Raiser | Business impact and product signal | Adoption metrics and field learning examples |

## Customer Scenario Framework

Use this order:

1. Clarify the business outcome.
2. Map the current workflow.
3. Identify users, data sources, and constraints.
4. Propose a narrow pilot.
5. Define evals and success metrics.
6. Describe rollout and handoff.
7. Explain what product feedback could emerge.

## Technical Design Topics

Be ready to discuss:

- API integration
- authentication and permissions
- data ingestion and retrieval
- RAG design
- agent workflows and tool calling
- eval datasets and scoring
- observability
- security and privacy
- latency and cost trade-offs
- human-in-the-loop review

## Portfolio Demo Structure

Keep the demo to 5 minutes:

1. Customer problem: 30 seconds
2. Current workflow and pain point: 45 seconds
3. AI workflow demo: 2 minutes
4. Architecture and eval: 1 minute
5. Rollout, metric, risk: 45 seconds

## Common Questions

| Question | Strong Direction |
|---|---|
| Why FDE? | Connect engineering, customer ambiguity, and production adoption |
| How do you handle unclear requirements? | Ask discovery questions and define a small pilot |
| How would you evaluate an AI workflow? | Golden dataset, failure modes, human review, regression checks |
| How do you earn customer trust? | Transparency, citations, security boundary, measurable pilot |
| What makes your project production-like? | Integration, eval, security, monitoring, rollout plan |

## Final Advice

Do not present yourself as only a builder or only a communicator. FDE interviewers look for the combination: customer judgment plus technical execution plus adoption ownership.
