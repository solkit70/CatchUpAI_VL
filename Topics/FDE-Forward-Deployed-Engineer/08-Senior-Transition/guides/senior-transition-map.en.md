# Senior Transition Map

## Background-Based Mapping

| Background | Strength for FDE | Common Gap | Best Target |
|---|---|---|---|
| Software Engineer | Technical depth, system design, debugging | Customer discovery and adoption ownership | AI Lab FDE, FDSWE |
| SI / System Integrator | Enterprise rollout, integration, customer constraints | Product feedback and AI-native patterns | Enterprise FDE, implementation-heavy FDE |
| Technical PM | Scope, stakeholder alignment, metrics | Hands-on technical artifact | AI product deployment, FDE-adjacent |
| Consultant | Discovery, executive communication, transformation work | Coding and system implementation depth | AI consultant, vertical AI FDE-adjacent |
| Solutions Architect | Architecture, integration, customer trust | Hands-on prototype and eval evidence | Solutions architect to FDE |
| Solutions Engineer | Demos, technical selling, customer communication | Post-sale deployment ownership | Developer tool or AI adoption FDE |
| Data/ML Engineer | Data pipelines, model systems, evaluation | Customer workflow and adoption | Data/agent infrastructure FDE |

## Translation Principle

Senior candidates should not simply change job titles. They should translate responsibility:

- project delivery -> production adoption
- requirements gathering -> customer workflow discovery
- stakeholder management -> deployment alignment
- system integration -> customer environment integration
- operational support -> reliability and handoff
- lessons learned -> field-to-product feedback

## AI Gap

Most senior IT candidates need to add:

- LLM application patterns
- RAG and agent workflows
- eval design
- model behavior debugging
- AI observability
- security boundary for AI systems
- cost and latency trade-offs

## Strong Senior Narrative

```text
I have spent my career delivering systems in complex customer environments. I understand how requirements change, how stakeholders disagree, how data and permissions block adoption, and how production handoff works. I am now adding AI workflow, eval, and LLM application depth so I can apply that delivery experience to FDE roles.
```
