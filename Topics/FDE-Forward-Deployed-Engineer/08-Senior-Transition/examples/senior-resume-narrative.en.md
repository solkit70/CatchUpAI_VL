# Senior Resume Narrative

## Narrative Formula

```text
Led [customer/workflow problem] across [stakeholders/systems], delivering [technical or operational solution] that achieved [impact] and produced [reusable learning].
```

## SWE Example

Before:

```text
Built backend services for enterprise application.
```

After:

```text
Built backend services for a customer-facing enterprise workflow, integrating authentication, data validation, and operational logging to support reliable adoption across multiple business units.
```

## SI Example

Before:

```text
Managed system integration project for client.
```

After:

```text
Led enterprise system integration across finance, operations, and IT stakeholders, translating workflow constraints into deployment milestones, data migration checks, and production handoff plans.
```

## Technical PM Example

Before:

```text
Managed roadmap for AI project.
```

After:

```text
Scoped and launched an AI workflow pilot by aligning business owners, engineering, and compliance teams around success metrics, rollout criteria, and post-launch feedback loops.
```

## Consultant Example

Before:

```text
Created transformation strategy for enterprise client.
```

After:

```text
Mapped enterprise workflow bottlenecks and converted transformation recommendations into prioritized AI automation pilots with implementation owners and measurable adoption targets.
```

## Solutions Architect Example

Before:

```text
Designed cloud architecture for customer.
```

After:

```text
Designed customer cloud architecture for an AI-enabled workflow, defining API boundaries, data access controls, observability requirements, and staged rollout plan.
```

I work at the intersection of enterprise systems, customer workflow, and AI-enabled delivery.
