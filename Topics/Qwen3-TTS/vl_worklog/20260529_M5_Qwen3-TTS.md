### TTS 성능 비교 (edge-tts vs Qwen3-TTS)

| 항목 | edge-tts | Qwen3-TTS VC |
|------|---------|-------------|
| 비용 | 무료 | ~$0.02/슬라이드 |
| 응답 속도 | 1~2초 | 8~10초 |
| 한국어 자연도 | 3.5/5 (기계적) | 4/5 (자연스러움) |
| 목소리 정체성 | 표준 음성 | 실제 창수 목소리 |
| 오프라인 가능 | ✅ | ❌ (API 필수) |

## 💡 M5 핵심 인사이트

1. **Qwen3-TTS의 실질적 가치**: 속도와 비용을 감안하면 edge-tts가 합리적이나, 실제 목소리 클론은 "내 채널을 내 목소리로" 구현하는 아이덴티티 요소. 장기적으로 유지 가치 있음.

2. **15개 슬라이드 = ~2분**: 배치 처리 덕분에 TTS 생성이 병목이 아니다. 실질 병목은 Remotion 컴포넌트 구현 시간 (~2시간).

3. **AUDIO_HEAD_PAD + AUDIO_TAIL_PAD 패턴의 완성**: 오디오 앞뒤 여백을 일정하게 유지하면 슬라이드 전환이 자연스러움. 1.0s + 0.4s 패턴이 실제 방송 느낌에 가장 가깝다.

4. **여성 VC 4종 멀티보이스**: HerStory 섹션에 여성 목소리를 써서 실제 행사 분위기를 영상에 재현했다. 단일 목소리보다 훨씬 생동감 있음.
