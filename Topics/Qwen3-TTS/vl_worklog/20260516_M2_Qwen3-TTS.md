## 2. 결정 이력 (중요 — 환경 전환 사유)
- 로컬(Windows) → API(오해로) → 로컬 복귀 → **최종 API 확정**.
- **최종 근거**: 이 PC = GPU 없음 + Intel **i7-1355U**(15W 저전력 노트북, 10C/12T, 1.7GHz) + RAM 15.7GB(여유 1.7GB).
  - 공식 `qwen-tts` 패키지는 **CPU 미지원**(전 예제 CUDA, flash-attn=Linux 전용, `--no-flash-attn`도 공식 미문서).
  - 유일한 CPU 경로 = 비공식 Rust/GGUF Q4(`cgisky1980/Qwen3-TTS-Rust`). i9-13980HX 기준 CPU Q4 RTF≈1.14 → 이 15W 칩에선 30초 음성 1.5~3분+ 추정으로 비효율.
  - 결론: **API가 이 환경에 최적** — 로컬 설치·GPU·flash-attn·속도 문제 전부 제거.

## 4. 검증된 API 사실 (웹 1차 출처)
- 공식 API = Alibaba Cloud Model Studio / **DashScope**. 모델 `qwen3-tts-vc-*`(클론)·`qwen3-tts-vd-*`(음색).
- **OpenAI 호환 엔드포인트**: `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` → 기존 Remotion OpenAI-TTS 코드 드롭인.
- 요금: 합성 ≈ $0.013/1k자, 클론 $0.01/건, 가입 후 90일 무료 쿼터. **Intl 키 필수**(China 키 비호환).
- 폴백: Replicate `qwen/qwen3-tts`.
