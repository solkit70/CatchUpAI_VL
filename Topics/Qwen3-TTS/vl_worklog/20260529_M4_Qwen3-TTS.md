## 📚 구현된 Harness Skill 분석

### 핵심 파일: `gen_audio_qwen.py`

```python
# VOICE_MAP — 슬라이드별 음성 전략 분리
VC_CHANGSOO = "qwen-tts-vc-changsoo-voice-20260526021509918-daf1"  # 창수 클론
VC_FEMALE1  = "qwen-tts-vc-changsoo-voice-20260526022357025-4486"  # 여성 VC

SLIDES = {
    0:  (VC_CHANGSOO, VC_MODEL, "audio_00_title.wav"),
    2:  (VC_CHANGSOO, VC_MODEL, "audio_02_recap.wav"),
    ...
    11: (VC_FEMALE1,  VC_MODEL, "audio_11_herstory.wav"),  # 섹션별 다른 목소리
    ...
}
```

### Harness 핵심 패턴

**1. 배치 처리 (Batch Processing)**
```python
for slide_id in sorted(SLIDES.keys()):
    try:
        synthesize(slide_id)
    except Exception as e:
        errors.append((slide_id, str(e)))
        # 오류 발생해도 나머지 슬라이드 계속 처리
```

**2. 중복 생성 방지 (Idempotent)**
```python
if out_path.exists():
    print(f"  [SKIP] {out_name} 이미 존재")
    return
```

**3. 에러 핸들링**
```python
if response.status_code != 200:
    raise RuntimeError(
        f"Slide {slide_id} 합성 실패 (status={response.status_code}): {response.message}"
    )
```

**4. VOICE_MAP 분리 설계**
- 슬라이드별 음성(voice_id), 모델, 출력 파일명을 한 딕셔너리에 통합
- 나레이션(NARRATIONS)과 음성 설정(SLIDES)을 분리 → 각각 독립적으로 수정 가능

## 💡 M4 핵심 인사이트

1. **VOICE_MAP 패턴의 강점**: 슬라이드마다 다른 목소리를 쓸 수 있어 영상에 다이내믹이 생긴다. 남성 나레이터 + 여성 인터뷰이 조합이 실제 방송처럼 들린다.

2. **건너뛰기 로직이 개발 속도의 핵심**: 이미 생성된 파일은 건너뛰므로 스크립트 일부 수정 후 재실행 시 수정된 슬라이드만 재생성. 반복 실험에 필수적인 패턴.

3. **Harness = 실제 프로덕션**: M4를 독립 모듈로 만드는 것보다 실제 영상 제작 안에서 구현하는 게 "하네스"의 진짜 의미에 더 가까웠다.
