## 3. 문제 해결 로그 / 리스크
- **[중요 리스크] Windows 지원 미명시**: 공식 README는 Windows 호환을 명시하지 않음. 예제가 `device_map="cuda:0"`, `dtype=torch.bfloat16`, FlashAttention2(GPU 최적화) 기반 → **M2에서 Windows + NVIDIA GPU 가정, flash-attn은 선택(설치 난이도 높음)으로 우회 검토 필요**. GPU 없으면 CPU/bfloat16 미지원 가능성 → M2 실습 1에서 최우선 검증 대상.
- 보이스클론은 3초 샘플 + **참조 텍스트(`ref_text`) 필수** — M3 샘플 준비 시 반영.
