**핵심**: 두 단계로 분리됨

```
[단계 1] 음성 등록 (qwen-voice-enrollment)
  입력: base64 인코딩된 mp3 샘플
  출력: voice_id (예: "changsoo-xxxx")

[단계 2] 합성 (qwen3-tts-vc-2026-01-22)
  입력: text + voice=voice_id

```

### What could be improved (개선할 점)

### Insights (인사이트)
- **영어 프롬프트 → 일본 억양 현상**: VD 모델이 영어 프롬프트 입력 시 영어/일본어 발음 패턴을 적용하는 경향. 한국어 콘텐츠에는 한국어 프롬프트가 필수
- **VD vs VC 트레이드오프**: VC는 실제 목소리 복제 (정체성), VD는 스타일 설계 (용도 맞춤) — Remotion에는 VD 튜터가 현재 최적
- **응답시간 패턴**: Flash(4s) < VC·VD(8s) — 클론/디자인 연산이 2배 소요
