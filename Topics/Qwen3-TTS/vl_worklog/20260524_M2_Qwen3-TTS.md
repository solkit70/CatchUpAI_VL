### What went well (잘된 점)
- Live #11 방송 직후에도 집중력을 유지하며 M2 전 과정 완료
- API 키를 방송 중 수령하고 당일 바로 실습까지 연결한 흐름이 자연스러웠다

### What could be improved (개선할 점)
- 공식 문서를 먼저 확인하지 않고 OpenAI SDK를 시도해 1회 실패 — 신규 API는 공식 SDK 우선 확인 습관 필요

### Insights (인사이트)
- **OpenAI 호환 모드 ≠ 전체 기능 호환**: DashScope의 `/compatible-mode/v1`은 Chat Completion 전용. TTS·이미지 등 멀티모달은 네이티브 SDK 사용
- **Connection Harness의 가치**: 단순 호출 성공이 아니라 Latency를 수치로 기록하니 "빠른가 느린가"를 직관이 아닌 데이터로 판단할 수 있다
- 평균 응답 2.1s는 실시간 방송 데모에 충분히 빠른 속도
