# TTS 비교 매트릭스 — Qwen3-TTS vs edge-tts(MS) vs OpenAI TTS (M1)

> 도입 의사결정 근거. Qwen3-TTS 값은 공식 출처 검증, 타 엔진은 일반적으로 알려진 사실 기준. 불확실 항목은 "확인 필요"로 표기.

| 항목         | Qwen3-TTS                               | edge-tts (MS, 현행)         | OpenAI TTS (현행) |
| ---------- | --------------------------------------- | ------------------------- | --------------- |
| 지원 언어      | 10개 (한국어 포함) + 방언                       | 다국어(한국어 포함, 다수 Neural 음성) | 다국어(한국어 가능)     |
| 보이스 클론     | ✅ 3초 샘플 + `ref_text` 필수                 | ❌ 미지원                     | ❌ 표준 tts 미지원    |
| 음색 제어 방식   | 자연어 `instruct`(VoiceDesign/CustomVoice) | SSML 운율(rate/pitch) 수준    | 프리셋 보이스 + 일부 지시 |
| 스트리밍       | ✅ ~97ms 지연                              | 제한적(스트림 출력)               | ✅ 스트리밍 지원       |
| 라이선스/비용    | Apache-2.0, 오픈소스(무료)                    | 무료(MS 서비스)                | 유료 API(사용량 과금)  |
| 실행 방식      | 로컬(GPU 권장) / ModelScope                 | 클라우드(네트워크 필요)             | 클라우드 API        |
| Windows 지원 | 확인 필요(공식 미명시·CUDA 예제)                   | ✅ (Python 패키지)            | ✅ (API)         |

## 실행 경로 업데이트 (2026-05-16): API 확정
- 위 표의 "실행 방식: 로컬(GPU 권장)"은 이 환경(GPU 없음·i7-1355U 15W·RAM 16GB)에서 부적합 → **Qwen3-TTS는 DashScope API(Intl, OpenAI 호환)로 사용 확정**.
- 그에 따라 Qwen3-TTS의 실효 속성: "Windows 지원 = ✅ (API)", "비용 = 사용량 과금(합성 ≈ \$0.013/1k자, 클론 \$0.01/건, 90일 무료 쿼터)" — 모델 자체는 Apache-2.0지만 호스팅 API는 과금.
- 상세: [02-Setup-API](../../02-Setup-API/README.md) · 로컬 검토 부록: [02-Setup-Windows](../../02-Setup-Windows/README.md)

## 1줄 결론 (잠정, M3 품질 평가로 확정)
- **일관 캐릭터 보이스/보이스 클론** 필요 시 Qwen3-TTS(API) 우위.
- **빠르고 가벼운 다국어 내레이션·비용 0**은 현행 edge-tts가 여전히 유리.
- 최종 채택 기준은 **M3(품질 A/B) + M5(채택 가이드·비용 추정)**에서 수치로 확정.
