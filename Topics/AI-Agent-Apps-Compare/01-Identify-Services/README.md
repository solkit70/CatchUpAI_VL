## 범위 변경 (2026-10-09)

처음에는 Grok Bot · Muse · Dots 세 서비스를 조사했다. 이후 **Instinct를 네 번째 비교 대상으로 추가**했고, ChatGPT Plus에서는 Dots를 쓸 수 없음을 확인해 실습 대상에서 제외했다. Instinct는 사용자가 대기 명단에 등록했으므로 현재는 조사·비교 대상이며, 초대가 오면 접근 조건과 공식 정보를 다시 확인한다.

## 이 모듈에서 알아낸 것

비교 대상은 Grok Bot(xAI), Muse(Meta), Dots(OpenAI), Instinct(Spear Street Technology) 네 가지다. 서비스가 실제로 맡는 일, 공식 접근 경로, 과금·초대 조건은 제품별로 다르므로 같은 종류라고 단정하지 않고 공식 자료와 보조 자료를 구분한다. 현재 직접 사용을 준비하는 대상은 Muse이며, Dots는 ChatGPT Plus에서 사용할 수 없어 조사·비교만 하고, Instinct는 대기 명단 승인 전까지 조사·비교만 한다.
