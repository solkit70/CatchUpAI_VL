## Production Process

1. **Slide plan** — v1 (23 scenes, 10/13) → v2 (24 scenes, 10/14), adding the "Muse outside, my second brain at home" scene (S20).
2. **Livestream clips** — Two Live #31 scenes where Codex operated Muse in the browser, edited by the host; ranges set from the transcript. Korean subtitles only on clip segments, original audio kept.
3. **Images and videos** — The user generated images I1–I5 and Gemini videos V1–V4.
4. **Audio** — edge-tts draft → user approval → four Qwen3-TTS preset voices. The host's cloned voice was not used, by the user's decision.
5. **Rendering and publishing** — Remotion rendered the Korean version first, then the English version from the same structure by swapping on-screen text and narration. GitHub QR codes appear twice (S10 and the S24 outro). Music only in the outro, synthesized in code.

Production files live in `AI/RemotionStudio/` and are not included in this repository.

## What We Learned

- **Saying up front that only one service was actually tried built trust.** No rankings or time-savings claims were made.
- **An AI delegating work to another AI** (Codex → Muse) comes across better in the original-audio clip than in narration.
- **The English video was built directly from the Korean structure** — an advantage of code-based video tools.
