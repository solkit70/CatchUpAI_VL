2. **클립 1 전체(37초)는 S14** 에서 「알고 보니 AI 가 입력했다」 반전으로 보여 준다.
3. **클립 2 는 「새로운 경험입니다」까지(33초)를 S18** 에서 처음부터 다시 보여 준다. 오프닝에서 잘린 장면의 뒷이야기를 약속하고(S02) 여기서 푼다 — 시청 지속 장치.
4. **클립 2 의 답 · 출처 장면(약 13초)은 S19 도입**에 짧게 쓴다. 출처를 보여 주는 화면이 「그대로 믿어도 될까」로 바로 이어지기 때문이다.
5. **새 장면 S20 「밖에서는 Muse, 집에서는 내 2nd Brain」** — 클립 2 뒷부분의 이야기(박창수 10/14 설명)를 슬라이드로 풀었다. 그래서 장면이 23장 → 24장, 기존 S20~S23 은 S21~S24 가 됐다.
6. **음성**: Qwen3 의 여러 목소리를 쓰고, **이번 편은 박창수 목소리 복제도 쓴다**(10/14 박창수). 1인칭 경험 장면은 박창수 목소리, 설명 · 퀴즈 장면은 진행자 목소리. 라이브 클립의 실제 목소리와 자연스럽게 이어진다.
7. **이름 표기**: 영상의 화면 · 내레이션 · 자막에는 **박창수 이름을 쓰지 않고 「Catch Up AI」**로 쓴다(10/14 박창수). TTS 원고에서는 「캐치업 에이아이」로 적는다. 이 플랜 문서의 제작 메모에 남은 이름은 화면에 나가지 않는다.
8. **앞으로의 약속**: 지금은 Muse 를 설치하고 기본 기능만 써 본 단계다. 계속 쓰면서 새로 배우는 것을 이어서 공유하겠다는 말을 아웃트로(S24)에 넣었다(10/14 박창수).

## 기획 요약

M1~M5 의 결과를 한 편의 영상으로 묶는다. 근거는 이 Topic 의 문서뿐이며, 장면마다 「근거」 칸에 해당 문서를 적었다. 제작 기준은 Remotion 스킬(`_Settings_/Skills/remotion-video/SKILL.md`)과 볼트의 영상 스타일 기준(`AI/RemotionStudio/video-style-guide.md`), Codex 장면 교훈(`codex-design-lessons.md`)을 따른다.

**대상 시청자**: AI 에이전트라는 말은 들어 봤지만 써 본 적은 없는 일반인. 「새로 나온 것 중에 뭘 써야 하지? 뭘 맡겨도 되지?」가 궁금하다.

**영상의 약속**: 새로 나온 AI 에이전트 네 개가 무엇인지, 실제로 써 본 하나에 일을 맡겨 보니 무엇이 됐고 무엇이 안 됐는지 보여 주고, 끝에 **「맡기기 전에 묻는 네 가지 질문」** 하나를 준다.

**정직하게 밝힐 것** (영상 안에서 말한다): 네 개를 비교했지만 **직접 써 본 것은 Muse 하나**다. 과제는 가상 데이터 두 개였고, 걸린 시간은 재지 않았다. 그래서 순위를 매기지 않고, 「시간이 얼마나 절약된다」는 말도 하지 않는다.

**제목 후보** (사용자가 최종 결정):

## 밝기와 화면 설계

**밝기 대역**: **L2 중간밝음** (파스텔). 직전 2편 `crd-guide-0927` · `claude-artifacts-routines-1004` 가 모두 L1 이라 규칙 ①(직전 2편과 다른 대역)을 지키면서, 사용자의 「밝고 읽기 편한 화면」 선호도 지킨다. L3·L4 로 가지 않는 이유는 스타일 기준이 어두운 색을 「야간 · 위험 · 경고」 장면에만 쓰라고 하기 때문이다.

**배경 모티프**: 아주 옅은 「작업 카드」 윤곽(할 일 카드 · 체크 상자)이 느리게 흘러가는 드리프트. 장면마다 정지 화면이 없도록 한다.

**새 기법 후보** (구현 · 검수 후 `effects-library.md` 에 기록):

1. **잠긴 문 넷, 열린 문 하나** — 네 서비스 카드가 문처럼 서 있고 세 개에 자물쇠가 내려온다 (S08).
2. **배턴 전달** — VS Code 창에서 브라우저 창으로 작업 카드가 날아가 꽂히는 연결 모션 (S14 · S18 · S20).
3. **형광펜 반대 — 빨간 밑줄 채점** — 과제 B 의 영어 문장에서 근거 밖 구절에만 빨간 물결 밑줄이 그어진다 (S16).
4. **실습 / 조사 이중 표기** — 모든 서비스 언급에 「직접 써 봄」 / 「자료로만」 배지가 따라붙는다 (전편).

기본 출력 1920×1080, 30fps. 같은 장면 유형이 세 장 이상 이어지지 않게 배치했다.
