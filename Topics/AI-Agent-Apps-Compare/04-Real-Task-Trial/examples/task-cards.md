# M4 가상 과제 카드

아래 이름, 날짜, 행사 및 메모는 실습을 위해 만든 허구의 데이터다. 실제 사용자·고객·행사·방송 정보가 아니다. 두 과제는 Muse 채팅에 텍스트로 입력하고, 외부 앱의 일정·메일·게시물은 열거나 변경하지 않는다.

## 과제 A — 가상 행사 일정 검토

**목표**: 시간표에서 충돌과 총 진행 시간을 찾아 운영자에게 검토 결과를 전달한다.

**가상 입력**:

| 항목 | 시작 | 종료 |
|---|---:|---:|
| 환영 및 안내 | 09:00 | 09:10 |
| 짧은 강연 | 09:10 | 09:40 |
| 도구 시연 | 09:35 | 10:00 |
| 질의응답 | 10:00 | 10:20 |
| 휴식 | 10:20 | 10:30 |

**Muse 요청문**:

> 아래 가상 행사 시간표만 검토해 주세요. 겹치는 항목과 겹친 시간, 첫 항목부터 마지막 항목까지의 전체 시간, 각 항목의 합산 시간을 구분해 요약해 주세요. 일정은 고치거나 새로 만들지 마세요. 입력에 없는 사실은 추정하지 마세요.

[위 표 붙여넣기]

**기대 결과**: 09:35–09:40에 5분 겹침을 지적하고, 경과 범위는 90분, 항목별 시간을 합산하면 95분임을 구분한다. 수정안을 자동 적용하지 않는다.

**성공 기준**:
- [x] 겹치는 두 항목과 5분 충돌 구간을 정확히 찾음
- [x] 범위 경과 시간 90분과 항목 합계 95분을 구분
- [x] 제공되지 않은 정보를 만들지 않음 (가상 시간표 분석 응답에서 확인)
- [x] 일정 변경 없이 분석만 제공

## 과제 B — 가상 방송 메모로 영상 설명문 작성

**목표**: 구조화되지 않은 방송 메모를 검토 가능한 영상 설명문 초안으로 바꾼다.

**가상 입력**:

- 허구의 채널: Maple Lab
- 허구의 에피소드: 발코니에서 수분 매개 곤충을 돕는 작은 정원
- 핵심 메모: 초보자용 화분 계획, 지역에 맞는 꽃 선택, 얕은 물그릇, 살충제 피하기
- 어조: 친절하고 과장하지 않음
- 시청자: 발코니 정원을 처음 시작하는 사람

**Muse 요청문**:

> 아래 허구의 메모만 사용해 영상 설명문 초안을 작성해 주세요. 제목 1개, 100–140단어의 설명문, 핵심 내용 3개 글머리표, 해시태그 3개를 포함하세요. 메모에 없는 수치·효과·전문가 인용은 추가하지 마세요. 외부 링크나 게시 작업은 만들지 마세요.

[위 가상 메모 붙여넣기]

**기대 결과**: 지정한 형식과 길이를 지키고, 네 가지 핵심 메모를 반영하며, 근거 없는 생태 효과나 수치를 덧붙이지 않는다.

**성공 기준**:
- [x] 제목, 100–140단어 설명, 3개 글머리표, 해시태그 3개 포함
- [x] 네 가지 가상 메모가 빠짐없이 반영
- [ ] 메모에 없는 수치·효과·인용·링크를 추가하지 않음
- [x] 초안만 작성하고 게시하지 않음
