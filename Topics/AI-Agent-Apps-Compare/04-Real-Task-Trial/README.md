**예상 학습 시간**: 2시간 작업 + 30분 버퍼

## 이 모듈에서 알아보는 것

가상 자료로 실제 업무의 구조를 재현해 에이전트 과제 두 가지를 시험한다. 성공 기준과 사람의 수정 시간을 함께 기록하고, 결과를 쓸 만함·고치면 쓸 만함·못 씀으로 판정한다. 이번 실행은 Muse만 대상으로 하며, 연결된 메일·일정 등 실제 데이터는 사용하지 않는다.

2. [examples/task-cards.md](examples/task-cards.md) — 두 과제의 가상 입력, Muse 요청, 기대 결과 및 평가 기준
