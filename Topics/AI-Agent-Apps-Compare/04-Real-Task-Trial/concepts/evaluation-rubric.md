# 가상 업무 에이전트 평가 기준

[English](evaluation-rubric.en.md)

## 과제 설계

비교 전에 입력 자료, 원하는 결과 형식, 성공 기준을 고정한다. 사실 추출 과제는 확인 가능한 정답과 계산을 포함하고, 글쓰기 과제는 분량·구성·근거 범위를 정한다. 실행 후 기준을 바꾸면 결과 비교가 흔들리므로 변경 이유를 남긴다.

## 가상 데이터

실제 고객·일정·메일·계정 자료 대신 목적에 필요한 구조만 닮은 허구의 이름과 내용으로 시험한다. 에이전트에 제공하는 자료는 최소화하고, 외부 앱에서 행동할 필요가 없는 경우에는 대화에 텍스트를 붙여 넣는 것으로 제한한다.

## 품질과 사람 검토

정답·형식 준수·근거 없는 추가 내용·수정 필요량을 각각 살핀다. 빠진 정보나 틀린 값은 사람의 수정 시간에 포함한다. 에이전트 응답 시간, 사람 검토 시간, 수작업 기준 시간이 모두 실제로 측정되기 전에는 절약 시간을 숫자로 단정하지 않는다.

## 판정

- **쓸 만함**: 성공 기준을 모두 만족하고 사실 확인만으로 사용할 수 있다.
- **고치면 쓸 만함**: 기본 목적은 달성했지만 사람이 구체적인 수정·검증을 해야 한다.
- **못 씀**: 핵심 요구를 놓치거나 큰 오류가 있어 결과를 다시 만드는 편이 낫다.

M4의 구체적인 과제·실행 결과는 [과제 카드](../examples/task-cards.md)와 [실행 평가](../guides/trial-results.md)에 기록한다.
