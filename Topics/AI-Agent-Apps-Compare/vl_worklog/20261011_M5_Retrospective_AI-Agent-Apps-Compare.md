## 계획 대비 실제

선택 기준, Mermaid 흐름도, 예상·실제 비교표, Topic README를 작성하고 초안을 재검토했다. 승인된 계획은 72분 작업과 18분 버퍼였으며 실제 작업별 시간은 미측정이다. 결과는 [M5 가이드](../05-Decision-Guide/guides/which-agent-when.md#처음-예상과-실습-결과)와 [WorkLog](20261011_M5_AI-Agent-Apps-Compare.md#진행-내용)에 연결했다.

## 학습 목표 달성도

- [x] 업무·위험·접근·검증 기준과 판단 흐름도 작성
- [x] 미실행 서비스의 출력 품질 판단 한계 명시
- [x] Topic 첫 화면에 결과와 학습 순서 연결

이는 산출물 완성을 확인한 목록이다. 사용자가 기준을 설명하고 새 업무에 적용할 수 있는지는 별도 자기 평가로 남겨 둔다.

## 핵심 학습과 문제 해결

성공한 시간표 계산과 근거 제한을 부분적으로 놓친 글쓰기 결과는 업무에 따라 검증 방법이 달라야 한다는 근거가 됐다. [M4 판정표](../04-Real-Task-Trial/guides/trial-results.md#결과-기록표)를 중심으로 기준을 만들었으며 표본이 작아 서비스 순위를 정하지 않았다. 사례 수·출처 링크·계정별 활동 표현을 바로잡고, 저장 과정의 한글 인코딩 문제를 복구했다.

## Roadmap 정확도 평가

M5의 흐름도와 Topic 첫 화면 목표는 산출물과 맞았다. 네 서비스로 늘어난 범위를 반영하고 90분 계획 안에 18분 버퍼를 명시했다. 시간 계획의 정확도는 실측 자료가 없어 평가하지 않는다.

## 다음 모듈 준비

M6 영상은 핵심 비교, Muse 과제 A·B의 다른 결과, 선택 기준을 중심으로 구성한다. Codex가 Muse 화면을 직접 조작하고 스크린샷을 문서에 넣은 과정도 소개하며 공개에 적합하게 정리된 화면을 사용한다. 슬라이드 플랜 검토부터 시작하고 영상 완성 후 Topic README에 링크를 추가한다.

## 산출물 점검

상대 링크 105개가 연결되고 깨진 링크와 빈 폴더는 각각 0개였다. M5 문서의 섹션 링크 24개와 Wiki 링크의 대상·절도 확인했다. M5는 완료하고 영상 제작 M6는 대기 상태로 유지했다.
