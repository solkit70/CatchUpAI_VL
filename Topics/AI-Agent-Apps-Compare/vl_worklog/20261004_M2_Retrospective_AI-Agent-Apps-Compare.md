# Module Retrospective — M2 비교표 만들기

**완료일**: 2026-10-04 (Live #30 방송 중) · 2026-10-09 범위 갱신
**작성**: 2026-10-13 — M2 당시 회고가 빠져 있어 [M2 WorkLog](20261004_M2_AI-Agent-Apps-Compare.md)의 기록으로 보충했다. 새로 관찰한 내용은 없다.

## 계획 대비 실제

다섯 기준(맡길 수 있는 일 · 무료 범위 · 설정 난이도 · 개인정보 · 내 일에 쓸 곳)의 비교표와 승인 · 개인정보 정리를 마쳤다. 10/9 에 Instinct 열을 더하고 Dots 실습 판정을 「조사 · 비교만」으로 바꿨다. 실제 소요 시간은 따로 재지 않았다.

| 계획 | 실제 |
|---|---|
| 3 × 5 비교표 | 4 × 5 (Instinct 추가). 확인 못 한 칸은 「확인 필요」 |
| 실습 대상 확정 | Muse 단독. Dots(Plus 불가) · Grok Bot(유료) · Instinct(초대 대기)는 조사 · 비교만 |
| 승인 · 개인정보 | 서비스마다 승인 방식이 달라 같은 흐름을 가정하지 않음 |

## 핵심 학습

1. **서비스의 차이는 기능보다 대상에 있다.** Muse 는 누구나 · 생활, Dots 는 상위 구독자 · 이어지는 업무, Grok Bot 은 개발자 · 팀 업무, Instinct 는 문자 · 전화로 맡기는 개인 비서다.
2. **승인 장치는 CoMC · 캐치에서 직접 만든 「AI 제안 → 사람 승인」 구조와 같다.** 이미 아는 개념에 새 서비스를 연결해 이해했다.
3. **AI 서비스 정보는 빨리 바뀐다.** 9/4 리서치와 10/4 공식 문서가 달랐던 점을 「바뀐 것」 표로 남겼다.

## 발생한 문제와 해결

- OpenAI 계열 공식 페이지가 모두 403 → Dots 칸은 보조 출처 비중이 높다고 표에 표시했다.
- Grok Bot 회사 표기(「SpaceXAI」 vs xAI) → 공식 문서 도메인 기준으로 xAI 로 적었다.

## Roadmap 정확도 평가

비교표 형식과 산출물은 계획과 맞았다. 실습 판정은 사용자 구독 정보가 틀려 10/9 에 다시 썼다. 「Muse 는 AI 학습 사용이 기본 켜짐」이라는 당시 메모는 보조 출처 기반이었고, M3 에서 실제 Data controls 화면으로 확인하는 절차로 바뀌었다.

## 다음 모듈 준비 (당시)

M3 에서 Muse 에 가입하고 학습 사용 설정을 확인한 뒤 첫 과제를 맡긴다. Dots 는 접근 조건 때문에 실습에서 뺀다.
