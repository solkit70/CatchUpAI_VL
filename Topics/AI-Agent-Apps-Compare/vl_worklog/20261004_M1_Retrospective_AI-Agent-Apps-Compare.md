# Module Retrospective — M1 네 서비스 정체 확인

**완료일**: 2026-10-04 (Live #30 방송 중) · 2026-10-09 범위 갱신
**작성**: 2026-10-13 — M1 당시 회고가 빠져 있어 [M1 WorkLog](20261004_M1_AI-Agent-Apps-Compare.md)의 기록으로 보충했다. 새로 관찰한 내용은 없다.

## 계획 대비 실제

계획은 세 서비스(Grok Bot · Muse · Dots)의 회사 · 공식 페이지 · 접근 조건을 확인하는 1.5시간 모듈이었다. 방송 중 Topic 설정부터 M1까지 한 번에 마쳤고, 10/9 에 Instinct 를 네 번째 대상으로 추가했다. 실제 소요 시간은 따로 재지 않았다.

| 계획 | 실제 |
|---|---|
| 서비스 카드 3장 | 4장 (10/9 Instinct 추가) |
| 무료 실습 대상 확인 | 무료는 Muse 하나. Dots 를 ChatGPT Pro 로 실습하기로 했다가 10/9 Plus 라 불가로 정정 |
| 공식 출처로 확인 | xAI · Meta 는 공식 문서를 읽음. OpenAI 는 자동 읽기 차단(403)으로 보조 출처 교차 확인 |

## 핵심 학습

1. **요약 사이트와 공식 문서가 다를 때 공식을 기준으로 삼는다.** Grok Bot 의 접근 플랜이 요약 사이트(상위 플랜만)와 공식 문서(모든 유료 Cursor 개인 플랜)에서 달랐다.
2. **「누구나 써 볼 수 있느냐」가 시청자에게 가장 중요한 비교 기준이다.** 세 회사가 같은 달에 비슷한 구조의 에이전트를 냈지만 무료로 쓸 수 있는 것은 Meta 하나였다.
3. **사용자 자신의 조건도 확인 대상이다.** 「ChatGPT Pro 사용자」라는 전제가 틀려 실습 계획이 바뀌었다. 계정 · 플랜은 기억이 아니라 실제 화면으로 확인한다.

## 발생한 문제와 해결

- OpenAI 공식 페이지 403 → 보조 출처로 채우고 「공식 원문 확인 필요」로 표시했다. Dots 가 실습에서 빠져 이 원문은 끝내 확인하지 않았다.
- 구독 플랜 오인 → 10/9 정정 기록을 WorkLog 에 남기고 카드 · 비교표 · Roadmap 을 함께 고쳤다.

## Roadmap 정확도 평가

모듈 구조와 산출물은 계획대로였다. 다만 Topic 시작 시점의 실습 범위(Dots 포함)가 사실과 달라, Roadmap v1.1 에서 범위를 다시 썼다. 시간 계획의 정확도는 실측이 없어 평가하지 않는다.
