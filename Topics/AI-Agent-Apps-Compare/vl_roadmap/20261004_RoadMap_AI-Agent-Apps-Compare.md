## 📚 학습 개요

### 🔧 범위 갱신 (v1.1, 2026-10-09)

> 박창수 확인 · 결정 (10/9): ① **Dots 는 ChatGPT Plus 에서 사용할 수 없다** — 기존 계획의 「ChatGPT Pro 구독으로 실습」은 사실과 달랐다. Dots 는 Grok Bot 과 같이 **조사 · 비교만** 한다. ② **Instinct 를 네 번째 비교 대상으로 추가**한다 — 박창수가 대기 명단에 등록했고(초대 전용 베타), 승인되면 M3 방식(개인 계정 연결 없이 공개 정보 과제)으로 실습한다. 서비스 카드 4번 참고. ③ 따라서 M3 실습은 **Muse 단독**으로 진행하고(Live #31, [시연 가이드](../vl_materials/2026-10-11%20Live31%20Muse%20설치·첫%20사용%20시연%20가이드.md)), M4 의 「Muse · Dots 에 과제 2개씩」은 「Muse 에 과제 2개 (+ Instinct 승인 시)」로 읽는다. 아래 모듈 본문의 Dots 실습 문구는 이 갱신에 따라 읽는다.

### M3 결과 갱신 (2026-10-11)

> M3는 Muse 단독 실습으로 진행했다. 첫 화면, 읽기 중심 과제, 권한 설정 구조, 공식 출처를 확인하고 산출물을 작성했다. 공개 결과에는 실제 계정·일정·메일 내용과 계정별 설정값을 기록하지 않는다. Muse 구독 가격·유료 토큰 한도는 Meta Help Center에서 확인해 M1·M2 자료를 갱신했다.

### M4 결과 갱신 (2026-10-11)

> M4는 가상 일정 검토와 허구의 방송 설명문 작성 두 과제를 Muse에서 실행했다. 첫 과제는 정확해 사용 가능, 두 번째는 형식은 맞았지만 근거 밖 표현이 남아 사람 수정 필요로 판정했다. 응답·검토 시간은 별도 측정하지 않아 절약 시간을 계산하지 않았다. Dots는 접근 조건상 제외했다. 상세 결과: [M4 산출물](../04-Real-Task-Trial/README.md).

### M5 결과 갱신 (2026-10-11)

선택 기준과 Mermaid 흐름도, 예상·실제 비교표, Topic README를 완성했다. 직접 실행 근거는 Muse에 한정하고 나머지 서비스의 성능 판정은 보류했다. M6에는 Codex의 Muse 직접 조작과 스크린샷 문서화 과정 소개를 포함한다.

### 리뷰 보완 · M6 착수 (2026-10-13)

> Claude Code가 M1~M5 산출물을 리뷰하고 문서 사이의 불일치를 고쳤다. ① M1~M3 DoD의 내용 항목과 진행표 비고를 실제 상태에 맞췄다(10/9 범위 갱신 전 문구 정리). ② M1 서비스 카드의 Instinct 약관 출처 수준과 확인 필요 목록을 갱신했다. ③ 공개 레포에서 열리지 않는 볼트 내부 위키 링크와 개인 Muse 대화 주소를 공개 문서에서 뺐다. ④ M1·M2 Module Retrospective를 WorkLog 기록으로 보충했다. M6는 박창수 결정에 따라 **Codex가 Muse를 조작하는 장면은 Live 방송 녹화를 편집해 쓰고**, AI 이미지·Gemini 동영상은 API로 만들지 않고 **프롬프트 문서로 준비**하며, Bonney Lake 지명은 노출해도 된다. 슬라이드 플랜: [06-Capstone-Video/video-slide-plan.md](../06-Capstone-Video/video-slide-plan.md).

### Topic 소개
새 AI 에이전트 서비스 네 가지(Grok Bot · Muse · Dots · Instinct)를 공식 자료로 조사·비교하고, 현재 접근 가능한 Muse를 우선 사용해 본다. Dots는 ChatGPT Plus에서 사용할 수 없어, Instinct는 초대 대기 중이므로 우선 조사·비교만 한다. 모든 작업이 끝나면 그 결과로 유튜브 영상을 만든다.

### 학습 목표
- [ ] 네 서비스가 각각 무엇인지(만든 회사 · 공식 페이지 · 핵심 기능)를 공식 자료와 보조 자료를 구분해 설명할 수 있다
- [ ] 비교표를 만든다 — 무엇을 맡길 수 있나 · 무료 범위 · 설정 난이도 · 개인정보 · 내 일에 쓸 곳
- [ ] 쓸 수 있는 서비스(Muse 무료 · Instinct 는 대기 명단 승인 시)를 설치 · 사용해 보고 결과를 기록한다 — Dots 는 ChatGPT Plus 로 불가해 조사 · 비교만 (v1.1)
- [ ] 「나는 무엇을 언제 쓸까」 판단 기준을 정한다
- [ ] 완료된 결과를 바탕으로 영상을 만든다 (Remotion · 이 Topic GitHub 폴더 QR 포함)

### M1 - 네 서비스 정체 확인

**난이도**: ⭐
**예상 시간**: 1.5h
**산출물 폴더**: `01-Identify-Services/`

#### 학습 목표
- [ ] Grok Bot · Muse · Dots · Instinct의 만든 회사 · 공식 페이지 · 공개된 출시/접근 정보를 출처 수준과 함께 기록할 수 있다
- [ ] 각 서비스를 한 줄로 설명할 수 있다 (「무엇을 맡기는 에이전트인가」)
- [ ] 이름이 같은 다른 제품을 최소 1개씩 찾아 「이것이 아니다」를 구분할 수 있다
- [ ] 확인된 사실과 「확인 필요」를 나눈 목록을 만든다

#### 주요 개념
1. **AI 에이전트 vs 챗봇**: 챗봇은 답을 주고, 에이전트는 브라우저 · 파일 · 앱을 써서 일을 끝까지 수행한다. 「에이전트」라는 이름만 붙은 챗봇도 있으니 실제 기능으로 판단한다.
2. **공식 출처**: 회사 공식 사이트 · 문서 · 발표 블로그. 뉴스 · SNS 요약은 보조 자료이고 사실 확인은 공식 출처로 한다.
3. **동명 제품 혼동**: 「Muse」 「Dots」처럼 흔한 이름은 다른 회사 제품이 많다. 회사명 + 출시 시점으로 묶어서 구분한다.
4. **확인 필요 표시**: 모르는 것을 그럴듯하게 채우지 않고 빈칸으로 남기는 것이 이 Topic 의 품질 기준이다.

#### 실습 과제

**실습 1: 공식 페이지 찾기** ⭐
- **목적**: 네 서비스의 제품 정체와 공식 출처를 확인한다
- **단계**:
  1. 서비스마다 「이름 + AI agent + 회사 후보」로 검색한다 (Dots 는 OpenAI 발표 여부, Muse 는 9/29 언급 맥락부터)
  2. 공식 사이트 · 문서 · 발표문 URL 을 찾아 확인 날짜와 함께 적는다
  3. 9/4 Grok Bot 리서치의 공식 문서 링크가 지금도 살아 있는지 확인한다
- **예상 시간**: 30분
- **검증**: 네 서비스 모두 공식 URL 1개 이상, 또는 「공식 출처 못 찾음」 명시

**실습 2: 한 줄 카드 만들기** ⭐
- **목적**: 시청자가 바로 이해할 수 있는 정의를 만든다
- **단계**:
  1. 서비스마다 카드: 회사 · 공식 URL · 출시 · 한 줄 설명 · 접근 방법(웹/앱/데스크톱) · 무료 여부(1차)
  2. 동명 제품을 「이것이 아니다」 칸에 적는다
  3. 확인 못 한 칸에는 「확인 필요」를 쓴다
- **예상 시간**: 30분
- **검증**: 카드 4장, 사실마다 공식·보조 출처 구분 또는 「확인 필요」 표시

### M2 - 비교표 만들기

**난이도**: ⭐⭐
**예상 시간**: 1.5h
**산출물 폴더**: `02-Comparison-Table/`

#### 학습 목표
- [ ] 다섯 기준(맡길 수 있는 일 · 무료 범위 · 설정 난이도 · 개인정보 · 내 일에 쓸 곳)으로 비교표를 완성할 수 있다
- [ ] 접근·가격 조건을 확인하고 실습 대상(Muse 우선, Instinct 초대 승인 시 재검토)을 확정할 수 있다
- [ ] 각 서비스의 개인정보 · 승인 방식(어떤 행동 전에 사람에게 묻는지)을 설명할 수 있다

#### 주요 개념
1. **무료 범위**: 「무료 체험」 「무료 플랜」 「대기자 명단」은 다르다. 카드 등록이 필요한 체험은 이 Topic 에서 유료로 본다.
2. **승인 경계 (HITL)**: 에이전트가 결제 · 전송 · 삭제처럼 되돌리기 어려운 일을 하기 전에 사람에게 묻는 구조. CoMC · 캐치에서 직접 만든 개념과 같다.
3. **데이터 처리**: 내가 맡긴 파일 · 로그인 세션이 어디(클라우드/내 PC)에서 처리되고 학습에 쓰이는지.
4. **설정 난이도**: 가입 → 연결 → 첫 작업까지 몇 단계인가로 잰다.

#### 실습 과제

**실습 1: 요금 · 무료 범위 확인** ⭐
- **목적**: M3 실습 대상을 정한다
- **단계**:
  1. 서비스마다 공식 요금 페이지에서 무료 플랜 유무 · 제한을 적는다
  2. Grok Bot 이 여전히 SuperGrok · Cursor 유료 전용인지 확인한다
  3. ChatGPT Plus에서는 Dots를 사용할 수 없음을 반영해 조사·비교 대상으로 둔다
  4. Instinct의 대기 명단 승인 여부를 확인한다. 승인 전에는 조사·비교만 한다
  5. 실습 대상 확정: Muse 우선, Instinct는 승인 후 조건 재검토 — Grok Bot · Dots는 조사·비교만
- **예상 시간**: 25분
- **검증**: 서비스별 「실습 가능(무료 / 기존 구독) / 불가」 판정 + 출처

**실습 2: 다섯 기준 비교표** ⭐⭐
- **목적**: 시청자가 한눈에 고를 수 있는 표를 만든다
- **단계**:
  1. 공식 문서에서 기능 · 승인 · 개인정보 항목을 읽어 표를 채운다
  2. 「내 일에 쓸 곳」은 유튜브 · 상담 · 일정 관리 · Builders Lounge 중에서 고른다
