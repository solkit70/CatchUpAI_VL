# 다섯 기준 비교표 — Grok Bot · Muse · Dots

> **확인 날짜**: 2026-10-04 · 출처 상세는 [../../vl_materials/official-sources.md](../../vl_materials/official-sources.md)
> 「공식」은 회사 문서 · 발표, 「보조」는 언론 · 요약 사이트. 확인 못 한 칸은 「확인 필요」

## 한눈에 보기

| 기준 | Grok Bot (xAI) | Muse (Meta) | Dots (OpenAI) |
|---|---|---|---|
| **① 무엇을 맡길 수 있나** | 여러 앱에 걸친 업무 — 조사 · 정리 · 초안 · 반복 작업. 브라우저 · 파일 · **터미널**까지 쓰고, 여러 Bot 이 서로 협업 (공식) | 생활 업무 — 메일 · 일정 · 예약 · 양식 작성 · 쇼핑 · 결제 · 장기 목표 (공식) | 계속 이어지는 업무 — 목표를 주면 대화 사이에도 진행. 4,000개 이상 앱 연결, 여러 프로젝트 동시 (공식 도움말 요약 + 보조) |
| **② 무료 범위** | ❌ 없음. 유료 Cursor 개인 플랜 · Cursor Teams · SuperGrok 구독 (공식). 사용량 주 단위 초기화 | ✅ 「대부분은 무료」, 더 쓰려면 $20 · $100 구독 (공식 + 보조). 무료 한도 숫자는 확인 필요 | ❌ ChatGPT Pro($100 · $200) · Business Premium 전용. 첫 dot 은 플랜에 포함, 출시 후 한 달 사용량 미차감 (공식 도움말 요약 + 보조) |
| **③ 설정 난이도** | ⭐⭐⭐ 데스크톱 앱 설치 → Bot 이름 · 역할 정하기 → 서비스 로그인 → 자동 검토 규칙 설정 | ⭐ 앱(iOS · Android) 또는 muse.ai 가입 → 대화로 바로 시작 → 필요할 때 앱 연결 | ⭐⭐ ChatGPT 데스크톱 앱 · 웹의 안내 화면 → 이름 · 목표 · 연결 앱 · 「혼자 해도 되는 일」 설정 |
| **④ 개인정보 · 승인** | 승인 카드(한 번 허용 · 항상 허용 · 거부), 자동 검토 규칙, 내 PC 실행은 「매번 묻기 · 항상 · 안 함」 선택. 비밀번호 · 인증 코드는 사람이 직접 입력. 학습 제외는 Cursor 계정 설정 (공식) | 메일 전송 · 구매 같은 민감한 행동은 승인. 행동 기록(감사 기록) 제공. 광고 시스템과 공유 안 함. **AI 학습 사용은 기본 켜짐 → 끌 수 있음** (공식 + 보조) | 혼자 할 일 / 승인 / 차단을 Custom Rules 로 정함. 계정에 영향 주는 행동은 자동 검토. 개인 플랜은 학습 사용 여부를 고를 수 있음, 비즈니스는 기본 미사용 (보조 — 공식 원문 확인 필요) |
| **⑤ 내 일에 쓸 곳** | 실습 불가 — 조사로만 판단: 방송 자료 조사 · 반복 정리를 노트북 꺼진 동안 맡기기. CRD 와는 「내 PC 일 vs 클라우드 일」로 나뉨 | 일정 · 행사 정리, 메일 초안, 생활 예약 — **일정 관리 · Builders Lounge 운영 보조** 후보 | 방송 준비 조사 · 유튜브 설명문 · 커뮤니티 소식 요약처럼 **계속 이어지는 작업** 후보 (Codex · ChatGPT 와 같은 계정이라 연결이 쉬움) |

## 한 줄 결론

세 서비스 모두 「클라우드 컴퓨터에서 내가 없을 때도 일하고, 중요한 일 앞에서 묻는」 같은 구조다. 차이는 **누구를 위한 것인가**에 있다 — Muse 는 **누구나 · 생활**, Dots 는 **ChatGPT 상위 구독자 · 이어지는 업무**, Grok Bot 은 **개발자 · 팀 업무(터미널 · 여러 Bot 협업)**다.
