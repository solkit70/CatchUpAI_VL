# 에이전트 선택 기준

## 선택 전에 확인할 네 가지

1. **자료의 민감도**: 공개 자료, 가상 자료, 개인·고객 자료 중 무엇이 필요한지 확인한다. 공개 또는 허구 자료만으로 시험할 수 있으면 실제 데이터 대신 그 자료를 쓴다.
2. **행동의 영향**: 읽기·요약·초안인지, 외부 서비스에 쓰기·전송·변경·삭제하는지 구분한다. 되돌리기 어렵거나 다른 사람에게 영향을 주는 행동은 사람이 검토하고 승인하기 전까지 초안 단계에 둔다.
3. **실제 접근 조건**: 지역·플랜·초대·커넥터 권한에 따라 사용 가능 여부가 다르다. 조사만 한 서비스는 직접 써 본 것처럼 추천하지 않는다.
4. **결과를 확인할 방법**: 정답·출처·형식·수정량 가운데 무엇으로 품질을 판단할지 시작 전에 정한다. 정확성을 독립적으로 확인할 수 없으면 자동 실행 대신 검토 가능한 초안으로 제한한다.

## 실습 근거의 수준

- **직접 실습**: M3·M4의 Muse 결과처럼 실제 인터페이스에서 관찰한 결과. 작은 표본이므로 모든 작업에 일반화하지 않는다.
- **공식 자료 확인**: 제품 기능·가격·접근 조건의 문서 근거. 사용성이나 출력 품질을 입증하지 않는다.
- **조사만 수행**: Dots, Grok Bot, Instinct의 이번 Topic 범위. 해당 도구로 실제 과제를 수행한 성능 비교는 아니다.

도구별 현재 근거와 제약은 [M2 비교표](../../02-Comparison-Table/guides/comparison-table.md#이-topic-의-실습-판정), 실제 가상 과제의 평가 근거는 [M4 결과](../../04-Real-Task-Trial/guides/trial-results.md#결과-기록표)를 참조한다.
