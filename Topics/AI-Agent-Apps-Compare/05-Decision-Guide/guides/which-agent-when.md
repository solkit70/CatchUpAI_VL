# 언제 어떤 에이전트를 쓸까

## 판단 흐름도

```mermaid
flowchart TD
    A[맡길 일을 한 문장으로 정의] --> A1{현재 접근·플랜·권한 조건을 충족하는가?}
    A1 -- 아니오 --> A2[공식 자료 조사만 수행; 실행 판정 보류]
    A1 -- 예 --> B{개인·고객 자료나 민감한 정보가 필요한가?}
    B -- 예 --> C[자료를 최소화하거나 가상화할 수 있는가?]
    C -- 아니오 --> D[공유를 멈추고 사람이 직접 처리]
    C -- 예 --> E{외부 서비스에 쓰기·전송·변경·삭제하는가?}
    B -- 아니오 --> E
    E -- 예 --> F{되돌리기 어렵거나 타인에게 영향이 큰가?}
    F -- 예 --> G[AI는 검토 가능한 초안까지만; 사람 확인·승인]
    F -- 아니오 --> H[작업별 권한을 확인하고 작은 범위에서 실행]
    E -- 아니오 --> I{정답이나 출처를 독립적으로 확인할 수 있는가?}
    I -- 아니오 --> J[결론 대신 초안·질문 목록으로 제한]
    I -- 예 --> K{어떤 작업인가?}
    K -- 공개 자료 조사 --> L[공식 출처를 확인할 수 있는 검색 도구]
    K -- 일정·메일 등 연결 앱 --> M[연결·작업별 권한을 확인한 에이전트; 이번 실습 근거는 Muse]
    K -- 초안·요약 --> N[형식·근거 제한을 고정하고 사람 검토]
    K -- 로컬 코드·파일 --> O[기존 코딩 도구를 우선 검토; 이 Topic에서 성능 비교 안 함]
    L --> P[출력 검증 후 사용 여부 결정]
    M --> P
    N --> P
    O --> P
    G --> P
    H --> P
    J --> P
```

## 서비스별 근거 수준

| 서비스 | 이번 Topic의 근거 | 지금 말할 수 있는 것 |
|---|---|---|
| Muse | M3 설정·출처 확인, M4 가상 과제 2개 직접 실행 | M4 가상 시간표 분석은 정확했으며, 형식 초안은 근거 밖 문구가 남아 검토가 필요했다. |
| Dots | 공개 자료 조사 | 기능·접근 조건은 비교했지만, 직접 사용성·결과 품질은 판단하지 않았다. |
| Grok Bot | 공개 자료 조사 | 공개된 기능과 접근 조건을 정리했지만, 이 Topic에서는 실습하지 않았다. |
| Instinct | 공식 자료 조사, 접근 조건 미확정 | 소개·약관의 내용을 정리했으며 실제 접근·실행 결과는 없다. |

실습한 표본이 하나의 서비스와 두 가지 인위적 과제에 한정된다. 이 흐름도는 시작점이며, 현재 공식 자료·권한·가격·지역 제공 조건을 작업 직전에 다시 확인한다.
