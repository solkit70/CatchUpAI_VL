## 개정 배경

7/26 최초 기획 때는 식순도 참가자도 미확정이라 "형식"만 비교했다. 이후 확보한 프로그램 초안으로 세 가지가 확정됐다.

1. **"AI 특별기획"이 공식 식순에 이미 편성**되어 있고, 담당은 **페더럴웨이한인회 AI TF**다.
2. 그 **바로 앞 순서가 "독립유공자 소개"**다.
3. **독립유공자 12인은 모두 시애틀 권역 거주 유가족의 선친**이며, 유족이 현지에 살고 있다. 만세삼창도 유족이 선창한다.

따라서 이제 필요한 것은 형식 비교가 아니라, **어떤 실행 옵션이 성립 가능한지**에 대한 판단 체계다. 학생 섭외 성사 여부가 불확실하므로 단일안이 아니라 **성립 조건이 다른 3개 트랙**으로 분리한다.

## 3개 실행 옵션

### 옵션 A — 한인 학생 참여형 (가장 선호, 성사 불확실)

| 항목 | 내용 |
|---|---|
| **내용** | 통합한국학교 학생이 MC로 진행 + AI 콘텐츠 소개 + "나에게 광복이란" 학생 메시지 |
| **성립 조건** | 페더럴웨이 통합한국학교의 참여 승인 |
| **현재 상태** | **제안 완료, 답변 대기 중** |
| **리스크** | 8월 중순은 방학 기간이라 학생 활동이 적어 섭외가 어려울 수 있음 |
| **강점** | 스토리라인 연결고리 ②(세대 계승)를 가장 직접적으로 구현. 관객 호응 최고 |
| **준비 기간** | 최소 2주 (대본·리허설 2회) |
| **대안 파트너** | 현재 없음. PDF의 평안한국학교 합창단은 **작년 자료**이고 올해 합창 순서는 미확정이므로 백업으로 가정하지 않는다 (2026-08-01 확인) |

### 옵션 B — AI 광복 역사 교육 프로그램 "계획 발표"형 (안전, 확장성)

| 항목 | 내용 |
|---|---|
| **내용** | 재미 한인 어린이를 위한 AI 기반 광복 역사 교육 프로그램을 설계하고, 기념식에서 **그 계획을 발표**. 시연 화면 일부 포함 |
| **성립 조건** | 없음 — 우리 쪽 준비만으로 성립 |
| **리스크** | 낮음. 다만 "당장 보여줄 결과물"이 아니라 계획이라 현장 임팩트는 A·C보다 약함 |
| **강점** | 행사 이후로 이어지는 **지속 사업**이 됨. 통합한국학교와의 협력을 이번에 못 해도 다음 학기로 연결 가능 |
| **준비 기간** | 1~2주 (기획서 + 발표 슬라이드) |
| **비고** | A가 불발되면 A의 취지(어린이 교육)를 살리는 대체안이 됨 |

### 옵션 C — 독립유공자 12인 AI 소개 영상 (신규, 이번 자료로 가능해짐)

| 항목 | 내용 |
|---|---|
| **내용** | 12인의 사진을 AI로 동적 애니메이션화하고, 음성을 입혀 본인이 말하는 형식으로 공훈을 소개하는 영상 |
| **성립 조건** | 유족 동의 + 사진 확보 + 제작 기간 |
| **리스크** | 중간 — 사진 미보유 5인 처리, 유족 정서 배려, 제작 시간 |
| **강점** | **식순상 "독립유공자 소개" 바로 뒤에 배치되어 흐름이 완벽함.** 유족이 객석에 계신 상태에서 선친이 화면에서 말하는 연출은 이 행사에서만 가능한 장면 |
| **준비 기간** | 2~3주 (유족 동의 → 자료 수집 → 제작 → 검수) |
| **비고** | A·B와 **배타적이지 않다**. C를 본체로 하고 A 또는 B를 얹는 조합이 가능 |

## 권장 실행 전략 — C를 본체로, A는 얹고, B는 마무리로

단일 옵션을 고르는 것보다 **C를 기본 골격으로 확정**하고, A의 성사 여부에 따라 앞부분을 바꾸고, B를 클로징에 붙이는 구성이 가장 안전하면서 임팩트가 크다.

```
[C] 유공자 12인 AI 영상  ← 본체. 학생 섭외와 무관하게 준비 착수 가능
   +
[A] 학생 MC/메시지       ← 승인되면 진행·클로징에 투입, 불발 시 사회자가 대체
   +
[B] 교육 프로그램 예고    ← 마지막 1~2분. "이 영상을 만든 방식으로 어린이 교육 프로그램을 만들겠다"
```

**이 구성의 장점**: 학생 섭외 결과를 **기다리지 않고 지금 착수**할 수 있다. C는 준비 기간이 가장 길므로(2~3주), 8월 15일 기준 지금이 마지막 착수 시점이다.

## 7/26 최초 형식 비교 (참고용 보존)

아래는 개정 전 원본 비교표다. 옵션 A/B/C의 **내부 연출 방식**을 정할 때 여전히 유효하다.

| 형식 | 내용 | 장점 | 단점/리스크 | 필요 장비 | 리허설 난이도 |
|------|------|------|------------|----------|--------------|
| ① AI 라이브 데모 | 무대에서 실시간으로 AI에게 질문·생성 시연 | 즉흥성, 화제성 | 인터넷 불안정 시 그대로 실패 노출, 결과 예측 불가 | 노트북, 대형 스크린, 안정적 인터넷 | 높음 |
| ② 영상 상영 | AI 복원 독립운동가 영상 등을 편집해 틀기 | 안정적(사전 제작), 퀄리티 보장 | 일방향 관람, 참여감 낮음 | 프로젝터, 스피커, 재생 기기 | 낮음 |
| ③ 참여형 체험 | 청중이 직접 AI/AR 콘텐츠를 체험 | 기억에 남음, 3대 모두 참여 가능 | 인원 많으면 시간 관리 어려움 | 태블릿/스마트폰 여러 대, QR코드 | 중간 |
| ④ 어린이 주도형 | 통합한국학교 학생이 MC로 진행 | 스토리라인(세대 계승)과 직결 | 사전 준비·리허설 기간 필요 | 무선마이크, 큐카드 | 중간~높음 |

**여전히 유효한 판단**: ①(순수 라이브 데모)은 시민단체 행사에서 감당하기 어려운 기술 리스크 → **채택하지 않음**. 옵션 C의 영상은 ②(사전 제작)에 해당해 안정적이다.
