## 목적

파일럿 영상은 12명 중 **노백린·류동열·김동협** 3명으로 제작 완료했습니다. 이 문서는 나머지 **9명**을 같은 방식으로 확장할 수 있는지, 현재 사진과 자료가 얼마나 준비되어 있는지, 페더럴웨이 한인회와 유족에게 무엇을 요청해야 하는지 정리합니다.

## 2026-08-05 업데이트: 현재 자료로 우선 완성

8월 5일 이구님에게 샘플 영상 컨셉을 그대로 확장해도 되는지, 사진 있는 분들부터 제작해도 되는지, 사진 없는 다섯 분을 어떻게 처리할지, fact check를 한인회가 맡아줄 수 있는지 문의했습니다. 이구님은 **"전반적으로 이대로 진행해도 좋을 것 같습니다"**라고 답했고, 오노미님의 사진도 사용해도 된다고 했습니다. 다른 몇 분께도 사진을 부탁해 두었다고 하므로 추가 자료가 들어올 가능성은 있습니다.

따라서 이 문서의 실행 결론은 다음과 같이 바뀝니다. **자료가 모두 들어올 때까지 대기하지 않고, 현재 확보된 자료로 우선 1차 영상을 완성합니다.** 사진이 있는 노태준·이재덕·장수산·오노미는 파일럿과 유사한 방식으로 제작하고, 사진이 없는 박승호·박세건·박오기·오병수·전봉신은 텍스트 카드·공훈 내레이션·실루엣 등으로 우선 처리합니다. 추가 사진이나 유족 연결 이야기가 들어오면 그때 해당 구간을 교체하거나 보강합니다.

## 제작 가능성 판단 기준

파일럿 기준으로 한 사람의 영상이 성립하려면 아래 세 가지가 필요합니다.

| 필요 자료 | 이유 | 없을 때 대안 |
|-----------|------|--------------|
| 원본 사진 | 원본 → AI 복원 → 10초 말하는 동영상 구조의 출발점 | 실루엣/텍스트 카드 + 내레이션 |
| 주요 활동 내역 | 1인칭 사실 서술 대본의 근거 | 공훈록 원문을 조사해 보강 |
| 시애틀·유족 연결 | "이 지역의 가족사"라는 영상의 감정적 연결점 | 본인 연고가 없으면 유족의 정착 이야기로 연결 |

유족 동의는 별도 전제입니다. 특히 Gemini 10초 맺음말 영상은 얼굴·목소리·표정이 모두 AI로 구성되므로, 유족이 불편해하면 해당 인물은 **맺음말 영상 없이 사실 내레이션+사진**만으로 처리하는 백업이 필요합니다.

## 우선순위

### 1순위 - 바로 확장 제작 착수 가능

**노태준, 장수산**은 사진 파일이 있고 공훈 요약도 비교적 선명합니다. 공훈록 원문만 보강하면 파일럿과 같은 구조로 제작할 수 있습니다.

**이재덕**도 사진은 있으나 공훈 요약이 짧습니다. 공훈록 원문에서 사건·연도·장소를 확보해야 40초 내외 대본이 안정적으로 나옵니다.

### 2순위 - 현재 자료로 우선 처리 후 추가 자료 반영

**오노미**는 유족 제공 사진이 있고, 이구님 답변 기준으로 사용 가능하므로 제작에 포함할 수 있습니다. 다만 최종본 전에는 성함 표기, 유족 관계, 사진 출처를 다시 확인해야 합니다.

**박승호**는 PDF에도 사진이 없고 실제 이미지 파일도 없습니다. 유족에게 원본을 요청해야 합니다. 사진이 확인되면 박세건과 부자 독립운동 서사로 묶어 강한 흐름을 만들 수 있습니다.

### 3순위 - 한인회/유족 도움 없이는 영상 품질이 떨어짐

**박세건, 박오기, 오병수, 전봉신**은 현재 사진이 없습니다. 공훈 기록만으로도 이름·활동을 소개할 수는 있지만, 파일럿처럼 얼굴이 움직이며 말하는 형식은 어렵습니다. 이 네 분은 유족 소장 사진 요청이 최우선입니다.

## 한인회에 요청할 사항

한인회에는 기술적인 설명보다 아래처럼 구체적으로 요청하는 것이 좋습니다.

1. **유족 동의 확인**
   - 선친의 사진을 AI로 복원하고, 공훈 기록을 바탕으로 짧은 음성·영상으로 재구성해도 되는지
   - 맺음말 10초 영상까지 허용 가능한지, 아니면 사진+내레이션만 원하는지

2. **사진 원본 제공**
   - 박세건, 박오기, 오병수, 전봉신 사진 요청
   - 박승호 사진 원본 요청
   - 가능하면 휴대폰 캡처가 아니라 원본 스캔/촬영본 요청

3. **오노미 사진 확인**
   - 사진 속 인물이 오노미 선생 본인이 맞는지
   - 원본 사진인지, 이미 AI로 복원·생성된 이미지인지
   - AI 영상 재구성에 사용해도 되는지

4. **시애틀/유족 연결 정보**
   - 본인이 시애틀을 방문·거주한 기록이 있는지
   - 없으면 유족이 언제, 어떤 경로로 시애틀 권역에 정착했는지
   - 행사 당일 참석하는 유족의 이름과 선친과의 관계

5. **유족 사전 검토 일정**
   - 전체 영상을 행사 당일 처음 보여주면 안 됨
   - 최소한 동의한 유족에게 링크로 먼저 보여주고, 삭제·수정 요청을 받을 창구 필요

## 다음 단계 제안

1. **사진 있는 4명부터 제작 착수**
   - 노태준, 이재덕, 장수산, 오노미 사진을 AI 복원 테스트
   - 공훈록 원문을 보강해 30-40초 내외 대본 작성
   - 오노미는 사용 가능 답변을 기준으로 포함하되 최종 fact check에서 사진 출처와 유족 관계 재확인

2. **공훈록 원문 조사**
   - 나머지 9명 각각 40초 대본이 가능한지 공식 기록 기반으로 확인
   - 공훈 기록이 짧은 인물은 유족 구술을 보강 자료로 요청

3. **사진 없는 5명 1차 표현 방식 결정**
   - 박승호·박세건·박오기·오병수·전봉신은 우선 텍스트 카드, 공훈 기록 내레이션, 실루엣 방식 중 하나로 처리
   - 사진이 들어오면 해당 구간만 파일럿형 말하는 영상으로 교체

4. **전체 분량 조정**
   - 12명 전체를 8분 안에 넣으려면 인물당 30~35초 수준으로 줄여야 함
   - 파일럿처럼 ①생애+②지역 연결+③맺음말을 모두 넣으면 12명 전체는 10분 이상으로 늘어날 가능성이 큼

5. **한인회·유족 fact check**
   - 1차본 제작 후 공훈 내용, 성함 표기, 유족 관계, 시애틀/유족 연결 이야기를 반드시 확인
   - 추가 사진이 들어오면 최종본 전까지 반영

## 결론

현재 상태로 **나머지 9명 전원을 파일럿과 같은 품질로 바로 만들 수는 없습니다.** 하지만 **노태준·이재덕·장수산·오노미**는 사진이 있어 바로 제작 착수 가능하고, **박승호·박세건·박오기·오병수·전봉신**은 사진 없는 상태에서 텍스트 카드·공훈 내레이션 방식으로 1차 처리할 수 있습니다.

따라서 다음 단계는 **현재 자료로 1차본을 완성하는 것**입니다. 한인회와 유족에게는 제작을 멈추기 위한 자료 요청이 아니라, 완성도를 높이기 위한 추가 사진과 fact check를 요청하는 방식이 더 현실적입니다.
