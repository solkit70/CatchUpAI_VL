## 📚 학습 개요

### Topic 소개

페더럴웨이 한인회가 주관하는 2026년 광복절(제81주년) 기념식(시애틀 대한민국 총영사관, 2026-08-15)의
주제 "8·15 광복 AI 시대 독립을 외치다"를 실제 행사 콘텐츠로 구현하기 위한 기획 리서치. 식순 중 15분
분량의 AI 관련 세그먼트와, 그림 전시(안중근 의사 모자 그림, 광복을 기뻐하는 사람들 그림 등)와 연계한
AI 활용 이벤트 아이디어를 도출해 페더럴웨이 한인회에 실제로 전달할 수 있는 실행안을 만든다.

### 학습 목표

- 식순 중 15분 분량 AI 세그먼트의 구체적 진행안(누가·무엇을·어떤 순서로)을 만들 수 있다
- 그림 전시와 연계한 AI 활용 이벤트 아이디어를 최소 2~3개, 실행 가능한 수준으로 구체화할 수 있다
- "8·15 광복 AI 시대 독립을 외치다"라는 주제의식을 역사적 맥락(광복, 안중근 의사 등)과 자연스럽게 연결하는 스토리라인을 만들 수 있다
- 페더럴웨이 한인회 실무자가 바로 읽고 실행 여부를 판단할 수 있는 기획 문서를 완성할 수 있다

### 예상 학습 기간

2~3일 (7/26 방송 중 1차 기획안 도출 → 7/27~28 다듬어서 페더럴웨이 한인회에 전달) — 사용자 확인 완료 (2026-07-26, "그대로 진행")

## 📖 모듈별 상세 계획

### M1 - 리서치 & 스토리라인 잡기

**난이도**: ⭐
**예상 시간**: 1.5h
**산출물 폴더**: `01-Research-Storyline/`

#### 학습 목표
- [ ] 제81주년 광복절과 "8·15 광복 AI 시대 독립을 외치다"라는 주제 문구의 의미를 한 문단으로 설명할 수 있다
- [ ] 안중근 의사 관련 사실관계(그림 전시 소재로 쓸 만한 일화·상징)를 신뢰할 수 있는 출처로 정리할 수 있다
- [ ] "광복(독립) → AI 시대 독립"으로 이어지는 은유적 연결고리를 최소 2개 이상 도출할 수 있다
- [ ] 페더럴웨이 한인회 대상층(어린이·가족·시니어)에게 각각 다르게 와닿을 메시지 포인트를 정리할 수 있다
- [ ] 재미 한인 어린이의 "한국 역사 학습 시간 부족" 문제의식을 스토리라인에 반영하고, 한국 정부·단체가 운영하는 어린이 대상 광복절 프로그램 중 시애틀 권역에서 실제로 활용 가능한 것을 파악할 수 있다

#### 주요 개념
1. **주제 은유(Thematic Metaphor)**: "광복(외세로부터의 독립)"과 "AI 시대 독립(AI에 종속되지 않고 주체적으로 활용하는 능력)"을 잇는 비유 구조
2. **3대(三代) 타겟팅**: 어린이·가족·시니어라는 서로 다른 세대에게 같은 메시지를 다른 방식으로 전달하는 접근
3. **역사적 사실 검증**: 안중근 의사 관련 서술은 반드시 신뢰할 수 있는 출처로 확인 후 사용 (미검증 서술 그대로 인용 금지)
4. **재외동포 어린이 역사교육 공백**: 미국에서 자라는 한인 어린이는 한국사를 접할 시간이 절대적으로 부족 — 이 공백을 채우는 기존 프로그램(재외동포청, 국가보훈부, 한국학교 등)을 활용/연계하는 것이 이벤트를 처음부터 만드는 것보다 효율적일 수 있음

#### 실습 과제

**실습 1: 배경 리서치** ⭐
- **목적**: 광복절 81주년의 의미와 안중근 의사 관련 신뢰할 수 있는 자료, 그리고 재외 한인 어린이 대상 광복절 프로그램 현황을 확보한다
- **단계**:
  1. 제81주년 광복절(2026)의 의미, 올해 총영사관 행사 관례 조사
  2. 안중근 의사 관련 사실관계(그림 전시 소재로 쓰기 좋은 일화 위주) 신뢰할 수 있는 출처로 조사
  3. 한국 정부(재외동포청·국가보훈부 등)·관련 단체가 운영하는 어린이 대상 광복절/역사교육 프로그램 조사 — 시애틀 권역 재미 한인이 실제로 참여·활용 가능한지 확인
  4. `vl_materials/`에 출처와 함께 정리
- **예상 시간**: 50분
- **검증**: `vl_materials/research-notes.md`에 출처 링크와 함께 정리된 사실관계 3개 이상 + 활용 가능한 어린이 프로그램 조사 결과 1건 이상

**실습 2: 스토리라인 도출** ⭐⭐
- **목적**: "광복 → AI 시대 독립"을 잇는 실제 발표/전시에 쓸 수 있는 문장·구조를 만든다
- **단계**:
  1. 실습 1의 리서치를 바탕으로 은유적 연결고리 후보 3개 이상 브레인스토밍
  2. 3대(어린이/가족/시니어)별로 같은 메시지를 다르게 표현하는 문구 초안 작성
  3. 가장 강력한 연결고리 1~2개를 최종 선정
- **예상 시간**: 50분
- **검증**: `01-Research-Storyline/storyline.md`에 최종 선정된 스토리라인과 세대별 메시지 포인트 완성

#### 산출물
```

├── README.md              ← 학습 순서 안내 + 전체 문서 링크
└── storyline.md           ← 최종 스토리라인, 세대별 메시지 포인트
```

#### Definition of Done

- [ ] "광복 → AI 시대 독립" 은유적 연결고리 최소 2개 도출
- [ ] 세대별(어린이/가족/시니어) 메시지 포인트 각 1개 이상
- [ ] 재외 한인 어린이 대상 광복절/역사교육 프로그램 조사 결과 1건 이상, 시애틀 권역 활용 가능 여부 판단 포함
- [ ] `storyline.md` 작성 완료
- [ ] WorkLog 작성 완료
- [ ] Daily Retrospective 작성

#### Self-Assessment
**개념 이해**:
- [ ] "8·15 광복 AI 시대 독립을 외치다"라는 주제를 다른 사람에게 1~2문장으로 설명할 수 있다
- [ ] 이 스토리라인이 왜 3대 모두에게 통할 수 있는지 설명할 수 있다

**실무 활용**:
- [ ] 이 스토리라인을 M2·M3 기획의 기준선으로 바로 사용할 수 있다

#### 예상 시간 배분

### M2 - 15분 AI 세그먼트 기획

**난이도**: ⭐⭐
**예상 시간**: 2h
**산출물 폴더**: `02-AI-Segment-Plan/`

#### 학습 목표
- [ ] 국민의례 → 개회사 → 공연으로 이어지는 기존 식순 안에서 15분 세그먼트가 들어갈 최적 위치를 제안할 수 있다
- [ ] 15분을 채울 구체적 콘텐츠 형식(발표/시연/참여형 체험 등)을 최소 2개 안으로 제시할 수 있다
- [ ] 발표자·진행 방식·필요 장비를 구체적으로 명시할 수 있다
- [ ] 3대(어린이~시니어)가 동시에 이해하고 참여할 수 있는 난이도로 설계할 수 있다

#### 주요 개념
1. **식순 삽입 지점**: 기존 순서(국민의례-개회사-공연)를 깨지 않으면서 AI 세그먼트가 자연스럽게 들어갈 위치
2. **형식 vs 메시지**: AI를 "보여주기용 기술 시연"이 아니라 M1에서 잡은 스토리라인(광복→AI 시대 독립)을 실제로 전달하는 도구로 쓰는 것
3. **참여형 vs 관람형**: 15분 동안 청중이 수동적으로 보기만 할지, 일부라도 직접 참여하게 할지의 설계 선택

#### 실습 과제

**실습 1: 형식 후보 브레인스토밍** ⭐
- **목적**: 15분 세그먼트로 가능한 형식을 폭넓게 뽑아본다
- **단계**:
  1. AI 라이브 데모(예: 청중 질문에 실시간 답하는 AI, 즉석 이미지/영상 생성)
  2. 짧은 영상 상영(예: AI로 만든 광복절 기념 영상, 오늘 이 방송에서 쌓은 VibeLearn AI 사례 소개)
  3. 참여형 체험(예: 어린이들이 AI와 함께 만드는 무언가를 현장에서 완성)
  4. **어린이 주도형**: 시애틀 권역 한인 어린이(통합한국학교 학생 등)가 AI를 활용해 준비한 내용으로 15분을 직접 진행/장식 — M1에서 조사한 기존 어린이 광복절 프로그램과 연계 가능성 포함
  5. 각 형식의 장단점, 필요 장비, 리허설 난이도(특히 어린이 주도형은 사전 준비·리허설 기간 필요)를 비교표로 정리
- **예상 시간**: 40분
- **검증**: 형식 후보 3개 이상, 비교표 완성

**실습 2: 최종안 구체화** ⭐⭐
- **목적**: 후보 중 하나(또는 조합)를 골라 분 단위 진행안을 완성한다
- **단계**:
  1. M1 스토리라인과 가장 잘 맞는 형식 1개(또는 조합) 선정
  2. 0~15분 분 단위 타임라인 작성 (도입-전개-마무리)
  3. 발표자/진행자 역할 배분, 필요 장비(스크린, 스피커, 마이크 등) 목록화
  4. 리허설 필요 여부와 백업 플랜(기술 문제 발생 시) 정리
- **예상 시간**: 60분
- **검증**: `segment-plan.md`에 분 단위 타임라인 + 역할 + 장비 목록 완성

#### 산출물
```
02-AI-Segment-Plan/
├── README.md              ← 학습 순서 안내 + 전체 문서 링크
├── format-options.md      ← 형식 후보 비교표
└── segment-plan.md        ← 최종 15분 분 단위 진행안
```

#### Definition of Done
- [ ] 형식 후보 3개 이상 비교
- [ ] 최종 형식 1개(또는 조합) 확정 및 근거 명시
- [ ] 0~15분 분 단위 타임라인 완성
- [ ] 필요 장비·인력 목록 완성
- [ ] 백업 플랜 1개 이상 명시
- [ ] WorkLog 작성 완료
- [ ] Daily Retrospective 작성

#### Self-Assessment
**개념 이해**:
- [ ] 왜 이 형식이 이 행사 청중(3대)에게 적합한지 설명할 수 있다

**실무 활용**:
- [ ] 이 진행안을 그대로 한인회 실무자에게 설명할 수 있는 수준인지 스스로 점검할 수 있다
- [ ] 기술적 문제(인터넷 장애 등) 발생 시 대안을 즉석에서 제시할 수 있다

#### 예상 시간 배분
- 형식 브레인스토밍: 40분
- 최종안 구체화: 60분
- 문서화: 20분
- **합계**: 2h (버퍼 포함)

### M3 - 그림 전시 연계 AI 이벤트 기획

**난이도**: ⭐⭐
**예상 시간**: 2h
**산출물 폴더**: `03-Exhibit-AI-Event/`

#### 학습 목표
- [ ] 그림 전시 공간에서 관람객이 AI와 상호작용할 수 있는 아이디어를 최소 3개 도출할 수 있다
- [ ] 각 아이디어의 실행 난이도(예산·장비·운영 인력)를 비교할 수 있다
- [ ] 최소 2개를 실제로 실행 가능한 수준까지 구체화할 수 있다
- [ ] 안중근 의사 그림 등 특정 소재를 다룰 때 역사적 존중을 해치지 않는 톤을 유지할 수 있다

#### 주요 개념
1. **전시 연계(Exhibit-linked) 이벤트**: 그림을 "그냥 걸어두는 것"을 넘어 AI로 관람 경험을 확장하는 방식
2. **저비용·저운영 우선**: 시민단체 행사 특성상 예산·인력이 제한적이므로, 화려함보다 실행 가능성을 우선
3. **역사적 존중**: 안중근 의사 등 실존 인물·역사적 사건을 다루는 콘텐츠는 가벼운 유희거리로 소비되지 않도록 톤 관리 필요

#### 실습 과제

**실습 1: 아이디어 브레인스토밍** ⭐
- **목적**: 그림 전시와 AI를 엮을 수 있는 아이디어를 폭넓게 뽑는다
- **단계**:
  1. 예시 방향 탐색 — (a) 그림 앞에서 QR/키오스크로 그림 속 인물·시대 배경을 AI가 설명해주는 인터랙티브 가이드, (b) 관람객이 자신의 "독립"에 대한 생각을 남기면 AI가 짧은 감상/시로 화답하는 참여형 코너, (c) 그림 스타일을 참고해 관람객이 자기 얼굴/메시지를 AI 이미지로 변환해보는 체험 부스
  2. 각 아이디어별로 필요 장비·예상 비용·운영 인력 정리
  3. 최소 5개 이상 브레인스토밍 후 비교표 작성
- **예상 시간**: 50분
- **검증**: 아이디어 5개 이상, 비교표 완성

**실습 2: 최종 2~3개 구체화** ⭐⭐
- **목적**: 실행 가능성이 높은 아이디어를 실제 운영 가능한 수준으로 다듬는다
- **단계**:
  1. 비교표 기준으로 최종 2~3개 선정 (예산·인력·역사적 톤 기준)
  2. 각 이벤트별 운영 시나리오(관람객이 도착해서 떠날 때까지의 동선) 작성
  3. 필요 장비/소프트웨어, 담당 인력, 사전 준비물 목록화
- **예상 시간**: 60분
- **검증**: `exhibit-events.md`에 최종 2~3개 이벤트의 운영 시나리오 완성

### M4 - 통합 기획서 작성 & 전달 준비 (Capstone)

**난이도**: ⭐⭐⭐
**예상 시간**: 2h
**산출물 폴더**: `04-Final-Proposal/`

#### 학습 목표
- [ ] M1~M3 산출물을 하나의 일관된 기획서로 통합할 수 있다
- [ ] 페더럴웨이 한인회 실무자가 처음 봐도 5분 안에 전체 그림을 파악할 수 있는 문서 구조를 만들 수 있다
- [ ] 각 안건별로 "결정이 필요한 사항"과 "이미 확정된 사항"을 구분해 표시할 수 있다
- [ ] 실제 전달 방법(이메일/문서 공유 등)까지 계획할 수 있다

#### 주요 개념
1. **의사결정 보드 vs 실행 문서**: 아이디어를 나열하는 문서가 아니라, 실무자가 Yes/No만 판단하면 되는 수준으로 정리된 문서
2. **핵심 요약(Executive Summary)**: 바쁜 실무자를 위해 전체 내용을 맨 위 3~5줄로 압축
3. **결정 필요 사항 표시**: 아직 한인회 확인이 필요한 부분(예산, 장소 배치 등)을 명확히 구분

#### 실습 과제

**실습 1: 통합 초안 작성** ⭐⭐
- **목적**: M1~M3 산출물을 하나의 문서로 합친다
- **단계**:
  1. Executive Summary(3~5줄) 작성 — 주제, 15분 세그먼트 한 줄 요약, 전시 이벤트 한 줄 요약
  2. M1 스토리라인 → M2 세그먼트 → M3 전시 이벤트 순서로 통합
  3. 각 항목에 "결정 필요"/"확정" 태그 부여
- **예상 시간**: 50분
- **검증**: `final-proposal.md` 초안 완성

**실습 2: 실무자 관점 검토 & 전달 준비** ⭐⭐⭐
- **목적**: 실제로 전달했을 때 바로 이해되는지 점검하고 전달 방법을 정한다
- **단계**:
  1. 문서를 처음부터 끝까지 읽으며 "실무자가 여기서 막힐 만한 지점"을 찾아 보완
  2. 필요 시 1페이지 요약본(핵심만) 별도 작성
  3. 전달 방법(이메일 첨부/링크 공유 등)과 전달 시점 계획
- **예상 시간**: 50분
- **검증**: `final-proposal.md` 최종본 + 전달 계획 완성

**실무 활용**:
- [ ] 이 문서만으로 한인회 실무자가 별도 설명 없이 Yes/No 판단이 가능한지 스스로 점검했다
