## 1. What is GOBI?

GOBI is a **collaborative knowledge platform**.
It allows teams to manage, search, and share knowledge together with AI.
GOBI CLI is the client that lets you use this platform **from the terminal**.

```
Platform:  https://www.gobispace.com
CLI:       npm install -g @gobi-ai/cli
Version:   v0.6.15 (as of 2026-03-29)
```

## 2. The 5 Core Concepts

### Concept Relationship Diagram

```
Vault (top-level knowledge container)
├── BRAIN.md  ←  published via brain publish
├── .gobi/settings.yaml  ← vault config
└── Space (team collaboration area)
    ├── Brain (AI knowledge resource)
    │   └── Session (1:1 conversation with Brain)
    └── Thread (team discussion thread)
        └── Reply (thread reply)
```

---

### 2-1. Vault

| Item | Description |
|------|-------------|
| **Definition** | GOBI's top-level knowledge container. One unit per project/organization |
| **Analogy** | GitHub Organization, Notion Workspace |
| **Creation** | `gobi init` → create new or select existing |
| **Config file** | `.gobi/settings.yaml` (stores vaultSlug) |
| **BRAIN.md** | Located at vault root; source file for brain publish |

**Vault created in practice**:
```
Name: gobi-cli-study
Slug: gobi-cli-study
Config: .gobi/settings.yaml → vaultSlug: gobi-cli-study
```

---

### 2-2. Space

| Item | Description |
|------|-------------|
| **Definition** | Team collaboration area within a Vault. Groups related Brains and Threads |
| **Analogy** | GitHub Repository, Notion Page |
| **Selection** | `gobi space warp` → interactive selection or direct slug |
| **List** | `gobi space list` → view Spaces you belong to |
| **Option** | `--space-slug <slug>` → specify Space directly in any command |

**Key commands**:
```bash
gobi space list                        # list your Spaces
gobi space warp                        # select active Space (interactive)
gobi space warp <slug>                 # jump directly to a specific Space
gobi space list-threads                # list Threads in current Space
gobi space create-thread               # create a new Thread
```

---

### 2-3. Brain

| Item | Description |
|------|-------------|
| **Definition** | AI-powered knowledge resource. A knowledge unit you can search, query, and publish updates to |
| **Analogy** | Wiki + AI assistant |
| **Source** | `BRAIN.md` file (stored locally, uploaded to platform via publish) |
| **Publishing** | `gobi brain publish` → upload BRAIN.md to vault |

**Key commands**:
```bash
gobi brain search --query "keyword"    # search public Brains (text + semantic)
gobi brain ask --vault-slug <slug> --question "question"   # ask Brain → creates Session
gobi brain publish                     # upload BRAIN.md → vault
gobi brain unpublish                   # remove BRAIN.md from vault
gobi brain list-updates                # list recent Brain updates
gobi brain post-update                 # post a Brain update
```

**BRAIN.md structure** (default generated by gobi init):
```markdown
---
title: gobi-cli-study
tags: []
description:
thumbnail:
prompt:
---
(body: your Brain's knowledge content)
```

---

### 2-4. Session

| Item | Description |
|------|-------------|
| **Definition** | A 1:1 AI conversation session started with `gobi brain ask`, continued via `gobi session reply` |
| **Analogy** | ChatGPT chat window (connected to a specific Brain) |
| **Start** | `gobi brain ask` → returns sessionId |
| **Continue** | `gobi session reply <sessionId>` |
| **Review** | `gobi session get <sessionId>` |

**Core flow**:
```
Brain ask → Session created (sessionId)
                ↓
          session reply → continue conversation
                ↓
          session get → review full conversation
```

**Key commands**:
```bash
gobi brain ask --vault-slug <slug> --question "question"
gobi session list                         # list your Sessions
gobi session get <sessionId>              # view specific Session
gobi session reply <sessionId> --content "follow-up"   # continue conversation
```

---

### 2-5. Thread & Reply

| Item | Description |
|------|-------------|
| **Definition** | Team discussion thread within a Space. Asynchronous communication for multiple members |
| **Analogy** | GitHub Issues, Slack channel |
| **Location** | Exists inside a Space |
| **Structure** | Thread (original post) + Reply (responses) |

**Key commands**:
```bash
gobi space list-threads                  # list Threads
gobi space get-thread <threadId>         # view Thread content
gobi space create-thread                 # create a new Thread
gobi space create-reply <threadId>       # reply to a Thread
gobi space edit-thread <threadId>        # edit Thread (own only)
gobi space delete-thread <threadId>      # delete Thread (own only)
```

## 3. Brain vs Session vs Thread — When to Use What?

| Situation | Use |
|-----------|-----|
| Find information in a public knowledge base | `gobi brain search` |
| Ask a specific Brain's AI a question | `gobi brain ask` → Session |
| Continue an AI conversation | `gobi session reply` |
| Discuss with teammates | `gobi space create-thread` |
| Publish your knowledge to the platform | `gobi brain publish` |

## 4. Additional Commands Discovered (v0.6.15)

> Commands found by exploring `--help` after installation

### gobi sense
```bash
gobi sense activities       # retrieve activity logs (with time range)
gobi sense transcriptions   # retrieve transcription records
```
→ Likely related to activity logs and voice/meeting transcription features.

### gobi sync
```bash
gobi sync                          # sync local vault ↔ Gobi Webdrive
gobi sync --upload-only            # local → server only
gobi sync --download-only          # server → local only
gobi sync --dry-run                # preview changes (no actual sync)
gobi sync --conflict ask|server|client|skip   # conflict resolution strategy
```
→ Full file sync between local and platform. Different from `gobi brain publish` (whole file sync).


## 5. Full Command Quick Reference

```
gobi --version                    check version
gobi --help                       full help

# Auth
gobi auth login                   login
gobi auth status                  check auth status
gobi auth logout                  logout

# Init
gobi init                         vault setup (select or create)

# Brain
gobi brain search --query <q>     search public Brains
gobi brain ask --vault-slug <s> --question <q>   ask Brain
gobi brain publish                publish BRAIN.md
gobi brain unpublish              unpublish BRAIN.md
gobi brain list-updates           list Brain updates
gobi brain post-update            post Brain update

# Session
gobi session list                 list your Sessions
gobi session get <id>             view Session
gobi session reply <id>           reply to Session

# Space
gobi space list                   list Spaces
gobi space warp [slug]            select active Space
gobi space list-threads           list Threads
gobi space get-thread <id>        view Thread
gobi space create-thread          create Thread
gobi space edit-thread <id>       edit Thread
gobi space delete-thread <id>     delete Thread
gobi space create-reply <id>      reply to Thread
gobi space edit-reply <id>        edit Reply
gobi space delete-reply <id>      delete Reply

# Sense (additional discovery)
gobi sense activities             view activity logs
gobi sense transcriptions         view transcription logs

# Sync (additional discovery)
gobi sync                         sync local ↔ Webdrive
gobi sync --dry-run               preview sync
```
