## 📍 GOBI CLI 핵심 개념

| 개념 | 설명 |
|------|------|
| **Vault** | 최상위 지식 컨테이너 (조직의 workspace) |
| **Space** | Vault 내 팀 협업 공간 (관련 작업과 brain 그룹) |
| **Brain** | AI 기반 지식 자원 — 검색, 질의, 발행 가능 |
| **Thread** | Space 내 토론 스레드 (팀 커뮤니케이션) |
| **Session** | Brain과의 1:1 대화 세션 (AI 질의응답) |
