## 1. BRAIN.md Structure

Auto-generated by `gobi init`. Must be located at the vault root.

### Frontmatter Fields

```markdown
---
title: vault name              # required: Brain title
tags: ["tag1", "tag2"]        # optional: search tags
description: description text  # optional: Brain introduction
thumbnail:                     # optional: thumbnail URL
prompt: AI instruction prompt  # optional: assign role to Brain AI
---
```

### Example

```markdown
---
title: gobi-cli-study
tags: ["gobi-cli", "learning", "vibelearn-ai"]
description: GOBI CLI learning knowledge repository
thumbnail:
prompt: You are a GOBI CLI learning assistant. Help users understand CLI commands with examples.
---

# Brain Title

## Overview
Brain introduction

## Key Topics
- Topic 1
- Topic 2

## Resources
- [Resource name](URL)
```

## 2. gobi brain publish

Uploads BRAIN.md to the platform.

```bash
# Publish BRAIN.md in current directory
gobi brain publish

# Practice result:
# Published BRAIN.md to vault "gobi-cli-study"
```

**Prerequisites**:
- BRAIN.md exists in current directory
- `vaultSlug` configured in `.gobi/settings.yaml` (`gobi init` completed)

---

## 3. gobi brain unpublish

```bash
gobi brain unpublish
# removes BRAIN.md from vault
```

## 4. brain updates CRUD

Brain Updates is a **feed/notification feature for sharing progress with the team**.

### Create (post-update)

```bash
gobi brain post-update \
  --title "Update title" \
  --content "markdown content"

# To specify a particular vault:
gobi brain post-update \
  --vault-slug <slug> \
  --title "title" \
  --content "content"

# Response:
# Brain update posted!
#   ID: 256
#   Title: GOBI CLI Learning Started 🚀
#   Vault: gobi-cli-study
#   Created: 2026-03-29T13:31:02.477Z
```

### Read (list-updates)

```bash
gobi brain list-updates

# Output example:
# Brain updates (20 items):
# - [256] "GOBI CLI Learning Started 🚀" by Changsoo Park (vault: gobi-cli-study)
# - [254] "..." by Minsuk Kang (vault: brave-path-zr962w)
# ...
```

> list-updates shows **updates from all users** (timeline feed).

### Update (edit-update)

```bash
gobi brain edit-update <updateId> \
  --content "updated content"

# --title can also be updated:
gobi brain edit-update <updateId> \
  --title "new title" \
  --content "new content"
```

### Delete (delete-update)

```bash
gobi brain delete-update <updateId>
# Brain update 255 deleted.
```

### Full CRUD Flow Summary

```
post-update → ID issued
    ↓
list-updates → confirm ID
    ↓
edit-update <id> --content "edited"
    ↓
delete-update <id>
```

---

## 5. Key Difference: publish vs post-update

| Feature | publish | post-update |
|---------|---------|-------------|
| **Target** | Entire BRAIN.md file | Short update text |
| **Purpose** | Update Brain knowledge base | Share progress / notify team |
| **Frequency** | When Brain content changes | Daily / on task completion |
| **Visibility** | Reflected in Brain search | Team feed / timeline |
