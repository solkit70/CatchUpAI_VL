## 채굴 원칙

1. **요약 금지.** 원문을 보존한다. 요약은 명제를 만들고, 명제가 v1 실패의 원인이었다.
2. **인용 6요소**: 원문(영어) · 한국어 번역 · 화자명 · 소속 · 타임스탬프 · 영상 링크. 하나라도 빠지면 기고 시 검증 불가.
3. **장면 우선.** "AI가 진입장벽을 낮춘다"(명제)보다 "병상에서 보험 확인하다 의사에게 걸렸다"(장면)가 기사를 살린다.
4. **반론도 채굴.** 발표는 본질적으로 홍보성이다. 발표자가 스스로 밝힌 한계를 모아야 기사가 균형을 갖는다.
