## 이 모듈에서 정한 것

### 전체 프레임 — "두 개의 시애틀"

M5.5 대조표의 **"어긋남" 6건**에서 나온 논지를 연재 전체 프레임으로 채택했다.

> 하나는 하이퍼스케일러가 7,250억 달러를 쏟아붓는데 정작 지역 벤처 투자는 40% 줄어든 **자본의 시애틀**.
> 다른 하나는 벨뷰 시청에서 간호사가 8주 만에 보험 확인을 사흘에서 1분으로 줄인 **실행의 시애틀**.
> 같은 주 같은 도시인데 서로를 보지 못했다.

**외부 자료만으로도, 현장 자료만으로도 나오지 않는다.** 둘을 다 가진 사람만 쓸 수 있는 글이라는 점이
이 연재의 존재 이유다.

### 편수 3편 유지, 구성은 전면 변경

초판(현장 자료만으로 설계)과 개정판의 차이다.

| | 초판 | 개정판 |
|---|---|---|
| 1편 | 누가 만드는가 (창업) | **두 개의 시애틀 (총론)** ← 사용자가 원한 "전반적 분석"이 여기서 완결 |
| 2편 | 믿고 쓸 수 있는가 | **유리벽 안쪽 (창업)** ← 현장 고유 자산 |
| 3편 | 무엇이 발목을 잡는가 | **믿음과 한계** + 2027 전망 |
| 외부 자료 | "배경으로만, 절대 단락을 열지 않는다" | **1편은 외부 거시로 열어도 된다** |

### 주제 7개 → 9개

외부 채굴로 **현장에는 없던 주제 2개**가 추가되었고, 중 판정 3개가 모두 강으로 올라갔다.

- **주제 8**: 당신은 정말 AI 회사인가 (Todd Bishop / Manos Koukoumidis) — **외부 전용**
- **주제 9**: 자본과 실행의 분리 (AI2Work 자본 역설) — **외부 전용**

### 1편 리드 — 외부로 여는 유일한 편

총론이라 규모부터 제시하고, 그 직후 현장 장면과 부딪히게 해 **첫 문단에서 프레임이 성립**하도록 설계했다.
7,250억 달러 → 벤처 40% 감소 → 벨뷰 시청의 60초.

## 2차 개정 (2026-08-12) — 참여 가이드 2편 추가

사용자가 다시 지적했다. "행사 제공자로 참여하는 법, 참가자로 참여하는 법, 모르고 지나간 사람에게
2027년 준비법을 알려주고 싶다. 계획에 있는가?" → **없었다.**

**v1에는 있던 것을 또 뺐다(세 번째 축소).** v1 M3의 참여 가이드 카드 6장과 기사 구조 후보 4
"2027 준비법"이 그대로 남아 있었는데, **v1 문서 19개 중 `03-Article-Planning/` 4개는
이 지적을 받기까지 한 번도 열리지 않았다.**

### 4편의 뼈대는 별도 Topic이다

사용자가 지목한 **`Topics/Seattle-Tech-Week-2026`**에 AI 큐레이션 전 과정이 문서화돼 있다.
Luma 242개·AI 태그 77개, 판단 기준 5가지, Claude Code → Codex 전환(공개 JSON API 발견),
최종 일정·캘린더 등록·Remotion 영상까지.

여기서 나온 논지가 4편의 중심이다.

> AI가 242개 중에서 고를 수 있었던 것은 필자에게 **자기 프로젝트 목록**이 있었기 때문이다.
> **AI는 "좋은 행사"는 골라도, "나에게 맞는 행사"는 내가 누구인지 알아야 고른다.**

그리고 이 논지를 5편 결론 **"지금부터 기록하라"**로 회수한다.

## 링크 앵커 정책

**기사 본문에 필자 본인 링크는 넣지 않는다.** 지면은 링크가 불가하고, 온라인판도 신문사가
필자 채널 링크를 대개 제거하며, 5편 연재에서 매 편 본인 링크가 나오면 편집 부담이 된다.

대신 **앵커 문구 기법**을 쓴다 — 본문에 서술형 앵커("필자가 현장에서 녹화한 **○○ 영상**")를
심어 두면 신문판은 그대로 자연스럽게 읽히고, Substack판은 **링크만 걸면 된다.**
원고는 하나만 쓰고 URL은 `07-Articles/link-map.md`로 분리한다.
