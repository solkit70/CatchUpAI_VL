## 📌 Topic 기본 정보

### Topic 이름

```
Topic 이름: VibeCoding-Onboarding-Program
```

### Topic 설명

```
설명: 자신만의 경험과 경력에서 나온 도메인 지식이 있고, 그것을 바탕으로 앱을 만들어 보고
싶은데 "바이브 코딩 세팅"과 "앱 개발 시작"에서 막히는 분들을 위한 온보딩 지원 프로그램을
만든다. 신청 접수용 Google Form(오늘 최우선), 그분들 눈높이에 맞춘 가이드 커리큘럼과
문서(세팅 → 첫 성공 → 내 앱 만들기), 앞서 같은 길을 걸은 분들의 경험담까지 완성한다.
```

### 대상 독자 (이 Topic의 모든 산출물이 지켜야 할 기준)

```
- 자기 분야에서 오래 일해 도메인 지식과 경험이 풍부한 분
- 그 지식으로 앱을 만들어 보고 싶은 분
- 하지만 컴퓨터가 그렇게 익숙하지 않고, 개발 경험이 없는 분
- 바이브 코딩이라는 말을 처음 듣거나, 들어봤어도 어디서 시작할지 모르는 분

→ 따라서 이 Topic에서 만드는 모든 문서·용어·커리큘럼은 이분들이 읽고 바로 이해할 수 있어야
  한다. 전문 용어는 최소화하고, 꼭 필요한 용어는 처음 나올 때 일상 언어로 풀어 설명한다.
  (예: "터미널 = 컴퓨터에게 글자로 명령을 내리는 창")

**언어 범위 (2026-07-21 확정)**: 한국인과 미국인(영어권) 모두 대상으로 한다. 신청 Form(M1)은
한/영 병기 단일 Form으로 확정. M2(여정 커리큘럼)·M3(세팅 가이드)·M4(스토리)·M5(통합 가이드북)도
이후 진행 시 한/영 이중언어 여부를 다시 확인하고 반영한다.
```

### 학습 목적

```
학습 목적:
- 신청 접수용 Google Form을 오늘 완성해 Build with AI 영상에서 바로 안내한다
- 신청자가 겪게 될 전체 여정(신청 → 세팅 → 첫 성공 → 내 앱 만들기)을 커리큘럼으로 설계한다
- 컴퓨터가 낯선 분도 따라올 수 있는 세팅 가이드 문서를 만든다 (VS Code + Claude Code 기준)
- 유타주 이선생님 사례 등 먼저 걸어간 분들의 경험담·시행착오·성공 스토리를 정리한다
- 진행자(나)가 보고 가이드할 수도 있고, 참가자가 혼자 보고 따라할 수도 있는
  통합 가이드북을 완성한다
```

### 예상 학습 기간

```
예상 기간: 1-2주 (오늘 M1 Google Form + 영상 안내 문구 완성 최우선, 나머지 모듈은 이어서)
```
