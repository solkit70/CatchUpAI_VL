## 학습 계획 수립 프로세스

**AI는 다음 순서로 작업을 진행하세요:**

### Step 1: Roadmap 및 이전 WorkLog 분석

1. Roadmap 파일을 읽고 전체 모듈 구조와 현재 모듈 위치 파악
2. 현재 모듈의 학습 목표 / 주요 개념 / 실습 과제 / DoD / 예상 시간 추출
3. 이전 WorkLog가 있으면 미완료 작업·문제·Tomorrow's focus 확인
4. 현재 상태 요약 출력 (전체 진행률, DoD 달성률, 미완료 작업)

### Step 2: 오늘의 학습 계획 수립

- 우선순위: 미완료 작업 → 현재 모듈 DoD → 새 학습 목표
- 가용 시간 기준 배분 (버퍼 20%)
- 오늘의 목표(우선순위순) / 상세 실행 계획 / 타임라인 / 오늘의 DoD 제시

### Step 3: 사용자 승인 대기

계획을 제시하고 승인("시작합니다"/"Go") 후 진행합니다.

### Step 4: WorkLog 파일 생성

`vl_worklog/YYYYMMDD_M{X}_VibeCoding-Onboarding-Program.md` 생성.
(템플릿 구조는 `Ingest/CatchUpAI_VL/templates/daily_learning_prompt.md`의 WorkLog 템플릿을 따름 —
오늘의 학습 목표 / 진행 내용 / 문제 해결 로그 / DoD 체크리스트 / Daily Retrospective / 참조 및 산출물)

### Step 5: 학습 진행

각 활동 완료 시 확인받고, WorkLog를 실시간 업데이트합니다.

## [3단계] 학습 계획 수립 원칙

1. **진행 상황 기반 조정**: 미완료 우선, DoD 중심, Tomorrow's focus 반영
2. **현실적인 시간 계획**: 가용 시간 준수, 버퍼 20%
3. **실습 우선**: 이론 20-30% / 실습 70-80%
4. **검증 가능한 산출물**: 매 활동마다 명확한 성공 기준
5. **대상 독자 기준 상시 적용**: 산출물을 쓸 때마다 "컴퓨터가 낯선 분이 읽고 바로 이해되는가" 자문
