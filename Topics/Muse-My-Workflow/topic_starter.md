# VibeLearn AI Topic Starter

> 이 파일은 새로운 Topic 학습을 시작할 때 작성하는 템플릿입니다.
>
> **사용 방법**:
> 1. 이 파일을 복사하여 `[TopicName]_topic_starter.md`로 저장
> 2. 아래 항목들을 채워서 작성
> 3. AI에게 이 파일을 전달하여 Topic 폴더 구조 생성 요청

## 📌 Topic 기본 정보

### Topic 이름
**형식**: 영문, 하이픈 또는 언더스코어 사용 (공백 없음)
**예시**: `MCP-Basics`, `Docker_Fundamentals`, `FastAPI-Tutorial`

```
Topic 이름: Muse-My-Workflow
```

### Topic 설명
**목적**: 이 Topic이 무엇인지 한두 문장으로 설명

```
설명: Meta Muse 를 박창수가 매일 하는 작업에 맞춰, 노트북이 없을 때도 밖에서 일을 이어 가고
그 결과를 집 컴퓨터의 2nd Brain(Obsidian 볼트)으로 옮겨 쓰는 실제 사용 방법을 만든다.
기능 시험으로 끝내지 않고, 매일 쓰는 사용법과 규칙으로 굳히는 데까지 간다.
```

### 학습 목적
**왜 이것을 배우는가?**

```
학습 목적:
- 밖에서는 Muse 로 일하고 집에서는 볼트로 이어 가는 흐름을 만든다 — 원격으로 집 컴퓨터를 조종(Chrome Remote Desktop 등)할 필요가 없게 한다 (2026-10-14 박창수 구술)
- 박창수가 하는 여러 작업 가운데 Muse 에 맡기면 좋은 일 · 초안만 맡길 일 · 맡기면 안 되는 일을 근거와 함께 가른다
- 찾은 방법을 시험으로 끝내지 않고, 매일 쓰는 사용 가이드 · 프롬프트 모음 · 규칙으로 굳힌다
- 이 경험을 라이브 방송 · 영상 · 시니어 AI 가이드에서 다른 사람이 따라 할 수 있게 정리한다
```

예상 기간: 2주 (주당 4~5시간, 총 약 9시간) — 제안값, 기간 확인 단계에서 조정. 첫 세션은 2026-10-18 Live #32 방송 4부

- [ ] 적합도가 높은 작업 2~3개를 실제 박창수의 일로 Muse 에서 해 보고, 볼트로 가져와 마무리하는 데까지 성공한다
