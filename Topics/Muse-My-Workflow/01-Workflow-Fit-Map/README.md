# M1 — 작업 목록과 Muse 적합도 지도

**상태**: ✅ 완료 (2026-10-18, Live #32 방송 4부)
**예상 학습 시간**: 1.5시간

Muse 를 어디에 쓸지부터 정한 모듈이다. 박창수의 작업 18개를 「맡김 · 초안만 · 맡기지 않음」으로 판정하고, Muse 에 올리면 안 되는 것을 정리하고, 필요한 기능을 Meta 공식 자료로 확인했다.

## 📚 학습 순서

1. [concepts/fit-criteria.md](concepts/fit-criteria.md) — 적합도 3단계 · 판정 기준 4가지 · 음성과 문자 지시
2. [guides/workflow-fit-map.md](guides/workflow-fit-map.md) — 작업 18개 목록과 적합도 판정 · 상위 6개
3. [guides/do-not-upload.md](guides/do-not-upload.md) — Muse 에 올리면 안 되는 것 한 장 정리
4. [examples/muse-feature-check.md](examples/muse-feature-check.md) — 공식 자료로 확인한 기능 표와 미확인 목록

## 이 모듈에서 알아낸 것

- 판정 결과는 **맡김 3 · 초안만 10 · 맡기지 않음 5**. 밖에서는 생각을 붙잡아 두고 형식은 집에서 맞추는 「초안만」이 가장 많다.
- 상위 6개: 이동 중 아이디어 · 할 일 메모 · VibeLearn AI Topic 이어가기 · 구술 원문 받아쓰기 · 공개 행사 리서치 · 공개 글 초안 · Remotion 슬라이드 플랜 · 대본.
- Muse 는 **Markdown 파일을 만들고 Library 에 저장**하며, **내 데이터 전체 내려받기**가 있다(공식 자료). 하지만 **파일 하나씩 내려받기와 음성 입력은 공식 자료에 없다** — M2 에서 직접 확인한다.
