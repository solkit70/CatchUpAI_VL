# 적합도 판정 기준 — 어떤 일을 Muse 에 맡길까

> 작업마다 Muse 에 맡길지 정하는 기준이다. 「Muse 가 할 수 있다」와 「Muse 에 맡기는 게 낫다」는 다르다. 볼트 안에서 Claude Code · Codex 로 더 잘 되는 일은 밖에서 할 이유가 적다.

## 적합도 3단계

| 단계 | 뜻 | 집에서 할 일 |
|---|---|---|
| **맡김** | Muse 결과를 거의 그대로 쓴다 | 볼트로 옮기고 출처 표시만 |
| **초안만** | Muse 가 초안 · 메모를 만들고 사람이 마무리한다 | 옮긴 뒤 검토 · 고침 · 볼트 규칙 맞추기 |
| **맡기지 않음** | 올리면 안 되거나, 볼트 · 로컬 도구가 꼭 필요하다 | 처음부터 집에서 |

## 판정 기준 4가지

| # | 기준 | 질문 | 「맡기지 않음」 쪽 신호 |
|---|---|---|---|
| ① | **데이터 등급** | 공개 / 개인 / 내부 중 무엇인가 | 내부(`visibility: internal` · 🔒) · 다른 사람의 연락처 · 의뢰인 정보 |
| ② | **볼트 맥락이 필요한 정도** | 볼트 문서를 많이 읽어야 하는가 | 볼트 전체를 훑어야 하는 일 (Daily Roundup · Weekly Progress) |
| ③ | **밖에서 생기는 일인가** | 이동 중 · 행사장 · 대기 시간에 생기는가 | 집에서 정해진 시간에 하는 일 |
| ④ | **옮기는 수고** | 결과를 볼트에 넣는 데 손이 많이 가는가 | 형식 규칙이 까다로워 집에서 다시 쓰는 편이 빠른 일 |

**데이터 등급**: 공개(방송 · 공개 레포 · 공개 행사) · 개인(내 생각 · 내 할 일 · 내 일정) · 내부(단체 내부 문서 · 의뢰인 · 다른 사람의 연락처). **내부는 다른 기준과 상관없이 「맡기지 않음」이다.** 내부가 섞인 작업은 공개 부분만 떼어 맡길 수 있는지 따로 본다 — [../guides/do-not-upload.md](../guides/do-not-upload.md).

## 지시 방식 — 음성과 문자 (2026-10-18 박창수)

차 안에서는 **음성**으로, 행사장 · 카페에서는 **문자**로 Muse 에 지시한다. 음성 지시는 말한 그대로 받아 적히는지(원문 보존), 문자 지시는 짧게 쓴 메모를 Muse 가 지나치게 부풀리지 않는지가 확인할 점이다. 둘 다 M2 · M4 에서 실제로 시험한다.

## 오해하기 쉬운 점

- **공유 링크는 옮긴 것이 아니다.** 볼트에 파일로 남아야 2nd Brain 에 들어온 것이다(M2).
- **「초안만」은 실패가 아니다.** 밖에서 생각을 잃지 않고 붙잡아 두는 것만으로 값어치가 있다. 이 Topic 에서 가장 많이 쓰일 단계다.
