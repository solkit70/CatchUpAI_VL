# Muse Feature Check — v2 (2026-10-25)
[한국어](muse-feature-check.md)

> This table checks whether Muse has the features this Topic needs. v1 (2026-10-18) looked only at Meta's official documentation. v2 (2026-10-25 · Roadmap v2.0 revision) adds results from hands-on use since then and newly released official documentation. Each row states its **source type** — **official** (official documentation from Meta or a partner) · **hands-on** (results of Changsoo Park using it himself) · **secondary** (reports · unofficial material) · **unverified** (no evidence). Menu names follow the help pages and may differ if the app changes.
