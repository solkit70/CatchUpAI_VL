# Muse 기능 확인 — 공식 자료 기준 (2026-10-18)

> 이 Topic 에 필요한 기능이 Muse 에 있는지 **Meta 공식 자료로만** 확인했다. 공식 자료에 없으면 「미확인」이고, M2 · M3 에서 직접 해 본다. 화면 메뉴 이름은 Meta 도움말 표기를 따랐으며, 앱이 바뀌면 다를 수 있다.

## 기능 표

| 기능 | 상태 | 공식 자료 내용 | 이 Topic 에서 | 출처 |
|---|---|---|---|---|

## M2 · M3 로 넘기는 미확인 목록

1. **파일 하나씩 내려받기** — 웹과 휴대폰에서 Library 파일을 내려받을 수 있는지, Markdown 이 그대로 받아지는지
2. **음성 입력** — 앱 안 음성 기능 유무, 없으면 키보드 받아쓰기로 원문이 남는지
3. **전체 데이터 다운로드의 형식** — 무엇이 어떤 파일로 오는지
4. **GitHub · 공개 레포 읽기** — 웹 접근으로 레포 파일을 읽는지 (M3)
