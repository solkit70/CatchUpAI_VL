# M5 일상 사용 관찰 기록

## 2026년 11월 16~21일 관찰 (6일)

| 시애틀 날짜 | 사용과 근거 | 기기·회수 경로 | 기록할 항목 |
|---|---|---|---|
| 11/16 | 예정표 공유 및 현장 사용 준비가 Roundup에 기록됨. Muse 실제 사용 여부는 미확인 | 사용 기기와 현장 질의 여부 미기록 | Muse 사용 여부와 준비 시간 미기록 |
| 11/17 | 사용자 보고로 행사 현장 자료 조회 확인 | PC 종료 상태에서 Dropbox 자료와 직접 제공 자료 활용 | 기기·총 소요 시간 미기록 |
| 11/18 | 행사 일정 조회, 현장 기록과 질의응답 정리, 원본 형식 시험 | 현장 사용 기기 미기록. 사전 시험은 노트북 웹. 결과 두 파일은 Dropbox에서 PC로 회수 | 현장 작업 총 소요 시간 미기록 |
| 11/19 | 행사 현장에서 Muse로 일정 확인 및 후속 사항 정리. 공개 영상 초안 회수도 별도로 진행 | 현장 사용 기기 미기록. Dropbox에 작업 기록 저장 | 현장 총 소요 시간 미기록 |
| 11/20 | 사용자 보고와 Muse 작업기록: 집에서 하루 종일 사용. 뉴스레터 운영·홍보 초안·메일 및 등록 확인·기사 후속 업무 지원. 실제 발송·게재 등 외부 실행은 사용자가 담당 | 집, 컴퓨터 사용 가능. 실제 Muse 입력 기기는 미기록. Muse는 미리 공유된 업무용 Dropbox 자료만 참조 | Dropbox 작업기록을 로컬에서 검토해 M5 로그에 요약. 작업별 시간·수정량·정확한 입력 기기는 보고서에 없어 미기록 |
| 11/21 | Muse 작업기록에서 공개 행사 홍보 초안, 교육 준비, 메일 정리, 원격 자료 접근 검토 확인 | 일부 작업에서 휴대폰 브라우저 사용. 전체 기기와 PC 상태는 미기록. 작업 요약은 Dropbox로 회수 | 업무별 총 소요 시간과 Vault 편입 시 수정량은 미기록 |

11/20과 11/21의 사용 내역은 Muse가 정리한 Dropbox 기록으로 보완했다. 11/22 라이브에서 M6를 시작한다는 사용자 일정에 따라 관찰 기간은 6일로 마감했다. 11/16은 준비 기록만 있고 Muse 실제 사용 여부는 미확인이다. 11/22 원격 운영 방식 검토와 선택된 Dropbox 미러 설정을 M5 회고에 반영했다. 미러 폴더의 로컬 파일 생성과 일일 갱신 작업은 확인했으며, Dropbox 클라우드 업로드 완료는 미확인이다.
