# Muse 일상 사용 규칙

## 자료와 연결

- 공개 자료 위주로 작업한다. 내부 표시 문서, 개인정보, 계정·연락처 자료는 Vault에서 관리하며 예외는 사용자가 특정 작업과 목적지를 승인한 범위에만 적용한다.
- Dropbox 등 보조 저장소에는 승인 범위의 사본을 쓴다. 사본의 자료 기준일을 확인하고, 로컬 Dropbox와 원본 Vault의 위치를 구별한다.
- 기본 회수는 필요한 결과 한 건을 수동으로 옮기는 방식이다. 승인된 Dropbox 경로를 쓸 때에는 PC에서 파일을 실제로 연 다음 Vault 최종 위치에 수동으로 편입한다.

## 이름과 검토

- 결과 파일명은 `YYYY-MM-DD 제목 by Muse.md`로 둔다. 도구가 작성한 초안과 사람이 검토한 상태를 표시하고, 사람 이름은 확인 가능한 자료의 표기를 따른다.
- 일정의 예정과 실제, 집계의 기준 시각, 발언의 원문과 요약을 구분한다. 요청마다 원자료 링크를 달고 불확실한 내용은 표시한다.
- 가이드나 교육 자료에는 공개 가능한 사례 요약만 싣는다. 외부 게시·발송은 별도로 결정한다.
