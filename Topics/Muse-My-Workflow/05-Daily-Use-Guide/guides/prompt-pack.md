# Muse 작업별 프롬프트

## 공개 영상으로 글 초안 만들기

> 공개 영상 {URL}에서 {주제}만 다뤄 {언어·분량}의 글 초안을 만들어 줘. 원어 자막이 있으면 먼저 쓰고, 자동 번역 자막만 있으면 그 사실을 적어 줘. 중요한 주장과 숫자에 시간표시를 달고, 자막으로 확정할 수 없는 항목은 검토 목록에 넣어 줘. Markdown으로 반환해 줘.

## 행사 일정이나 현장 메모 정리하기

> 자료 {허용된 자료 목록}을 기준으로 {날짜·세션·질문}을 정리해 줘. 답마다 출처 파일·쪽·기준 시각을 적고, 예정표와 현장 확인, 등록과 실제 참석을 구분해 줘. 자료가 충돌하면 각각의 근거를 보여주고, 확인하지 못한 내용은 미확인으로 표시해 줘. 메모는 발언 원문과 요약을 구분해 줘.

## 결과를 회수하고 Vault에서 마무리하기

> {결과 이름}만 Markdown으로 회수할 수 있게 해 줘. 본문과 출처를 함께 담고 파일명에는 날짜·제목·작성 도구를 적어 줘. 이미 승인된 Dropbox 경로를 사용할 때에는 저장 경로와 파일 크기를 알려 줘. 저장 후 로컬에서 열어 원자료와 대조하고, 최종 저장 위치와 편집량을 기록한다.

## 막혔을 때

> 접근이 막힌 파일과 실패 이유를 적어 줘. 찾지 못한 자료는 검색한 범위를 밝히고 미확인으로 표시해 줘. 제공한 원자료 또는 지정한 파일 하나를 기준으로 다시 확인하고, 그래도 답을 확정할 수 없으면 내가 확인할 항목을 알려 줘.
