# M5 — Muse 일상 사용 가이드

**상태:** ✅ 완료 · 2026-11-22
**예상 시간:** 2.5시간 + 2026-11-16~21 일상 사용 관찰

## 학습 순서

1. [일상 사용 가이드](guides/daily-use-guide.md) — 업무 종류에 맞는 Muse 사용과 결과 회수 흐름을 고른다.
2. [작업별 프롬프트](guides/prompt-pack.md) — 요청 범위·근거·미확인 사항을 지정하는 문구를 참고한다.
3. [일상 사용 규칙](guides/rules.md) — 자료 등급, 이름, 근거, 검토와 수동 편입 원칙을 확인한다.
4. [일상 사용 관찰 기록](examples/one-week-log.md) — 사용·미사용 이유, 기기와 결과 회수 경로를 기록한다.

## 실습 결과와 현재 상태

- 실제 업무 두 건을 외부에서 시작해 Vault에서 마무리했다: Day 2 현장 기록, Day 3 일정 지원·후속 정리.
- 공개 영상 글 초안도 작성했지만 집에서 시작했으므로 외부 시작 업무 두 건에는 포함하지 않는다.
- 사용 가이드·프롬프트·규칙은 11/20 사용자 확인을 받았다. 6일 관찰과 11/22 원격 Vault 사용 분석을 마치고 운영 방식을 정리했다.
- 관찰은 2026-11-16~21의 6일로 마감했다. 11/20과 11/21 사용은 Dropbox 기록으로 보완했다. 원격 Vault 미러를 준비해 로컬 사본 8,930개 파일과 일일 갱신 작업을 확인했다. Dropbox 클라우드 업로드 완료 여부는 별도 확인이 필요하다.

실제 행사 기록과 내부 평가 원문(`examples/real-work-trials.md`), 가림 전 Muse 화면 캡처(`assets/`)는 로컬 내부 자료다. 공개 학습 순서에 포함하지 않으며 GitHub에서도 제외한다. 교육용 화면을 만들 때는 별도로 검토하고 필요한 부분을 가린다.
