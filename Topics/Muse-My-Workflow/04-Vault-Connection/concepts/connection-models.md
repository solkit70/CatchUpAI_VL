# 볼트와 Muse 를 잇는 두 가지 모델

[English](connection-models.en.md)

M4 에서 후보 8개를 비교하기 전에 알아 둘 개념이다. 로드맵 v2.0 의 M4 「주요 개념」과 M4 실습 1 · 2 에서 확인한 사실로 정리했다(2026-11-07 Claude Code 보강).

## 1. 클라우드 대리형과 원격 콘솔형

| | 클라우드 대리형 | 원격 콘솔형 |
|---|---|---|
| 일하는 곳 | Muse 의 컴퓨터(클라우드) | 집 PC (Claude Code 등) |
| 휴대폰의 역할 | 지시하고 결과를 받는 곳 | 집 PC 를 조작하는 리모컨 |
| 집 PC 가 꺼져 있으면 | 그래도 된다 | 안 된다 |
| 볼트 규칙 | 볼트 밖이라 규칙을 따로 알려 줘야 한다 | 볼트와 규칙을 그대로 쓴다 |
| 자료 | 사본 · 커넥터로 **볼트 밖에 나간다** | 볼트 안에 머문다 |
| 이 Topic 의 후보 | A Dropbox · B GitHub · C Drive · Box · G 데스크톱 · H 사용자 정의 커넥터 | E Remote Control · F Claude Code 웹 · 모바일 |

이전 Topic [Claude-Code-Mobile-Remote-Execution](../../../Claude-Code-Mobile-Remote-Execution/README.md) 의 결론은 「모바일은 조작 콘솔, 실행은 로컬」이었다. 수동 전달(D)은 두 모델 어디에도 속하지 않는 기준선이다 — 사람이 직접 내려받고 올린다.

## 2. 동기화가 아니라 연결

Muse 의 컴퓨터와 내 폴더를 맞춰 두는 「동기화」 기능은 공식 자료에서 찾지 못했다. 파일은 올리기(System Files)나 커넥터로 들어가고, 커넥터는 일할 때 필요한 만큼만 가져온다. 그래서 그림은 「Muse 안에 동기화된 볼트 사본」이 아니라 **「내 저장소를 Muse 가 그때그때 들여다보는 것」**이다. 이 Topic 의 출발점이었던 「밖에서 한 일이 집 PC 에 저절로 와 있다」(시나리오 S5)를 아직 어떤 후보도 충족하지 못한 이유도 여기에 있다. → [시나리오 비교표](../guides/seamless-scenarios.md#시나리오-비교)

## 3. 골라 담은 사본(mirror)과 받는 곳

- **원본은 늘 볼트다.** 사본은 볼트에서 사본 폴더로 **한 방향**으로만 복사한다.
- **공개로 표시한 것만 담는다.** `visibility: public` 인 Markdown 만 기본 포함하고, 내부 표식 · 개인 · 미분류 · 허용되지 않은 경로 · 큰 파일 · 비 Markdown 은 뺀다. → [사본 정책 초안](../guides/mirror-policy.md)
- **Muse 는 사본을 읽기만 하고, 결과는 받는 곳에 쓴다.** 사본은 다음 복사 때 덮어써지기 때문이다. 읽는 곳과 쓰는 곳을 나누면 충돌이 생기지 않는다.
- **미리 보기가 먼저다.** 실제 볼트로 미리 보기를 돌린 결과(11/5)는 포함 후보 3 · 제외 55,975 · 복사 0 이었고, 내부 표식 문서는 모두 빠졌다. 실제 복사는 미리 보기 보고서를 박창수가 승인한 뒤에만 한다.

## 4. 연결하면 이미 올린 것과 같다

커넥터를 이어 주면 그 저장소의 자료는 Muse 가 볼 수 있는 자료가 된다. 그래서 연결은 「파일을 올리는 것」과 같은 무게로 판단한다(M1 보강의 연결 규칙). 연결 전에 확인할 것은 세 가지다.

1. **권한** — 읽기만인가, 쓰기 · 삭제 · 공유까지인가 (Drive 는 동작별 설정이 보였다)
2. **범위** — 폴더 하나 · 레포 하나로 좁힐 수 있는가 (화면만으로는 판정하지 못했다 — 시험 필요)
3. **학습 사용** — 내 자료가 모델 학습에 쓰이는가 (웹의 Data controls 에서 끄는 스위치를 찾지 못했다)

## 오해하기 쉬운 점

- **private 레포와 클라우드 저장소도 볼트 밖이다.** 볼트 전체를 올리면 내부 자료 규칙을 어긴다. 「전부」가 아니라 「필요한 만큼」이다.
- **한 도구로 다 하지 않는다.** 결과물은 정답 하나가 아니라 「작업 종류별 경로표」다 — 음성 메모는 Muse, 볼트 자료 보기는 사본, 볼트 규칙이 필요한 일은 집의 Claude Code 처럼.
