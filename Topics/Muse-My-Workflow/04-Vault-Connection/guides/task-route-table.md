## 상태와 범위

[English](task-route-table.en.md)

**초안 — 운영 경로와 사본 정책은 승인·확정되지 않았다.** 이 표는 M2~M4에서 실제 확인한 경로와 아직 시험하지 않은 경로를 나눈다. 새 연결, 볼트 전체 사본, 자동화, 파일 이동·삭제를 실행하지 않는다. Dropbox/Drive의 합성 시험은 지정된 가상 파일에 한정했다. E · Claude Code Remote Control은 **Muse 자체 기능이 아닌 외부 대안 경로**다.

## 작업별 경로

| 작업 | 현재 근거가 있는 경로 | 남은 제한·판정 |
|---|---|---|
| 음성 메모를 원문으로 보존 | Muse 음성 입력 후 결과물을 개별 파일로 내려받거나 본인에게 메일로 전달하고, 집에서 `_Inbox_/`에 수동 편입 | 음성에서 Journal까지 자동 반영은 미시험. 원문 보존·검토 후 편입 |
| 이메일·일정 확인 | Muse의 해당 연결 기능에서 직접 처리 | 볼트로 자동 복사하지 않음. 외부 발송·일정 변경 등은 앱 확인 절차 준수 |
| 밖에서 시작한 Topic을 집에서 이어가기 | M2/M3 인계 꾸러미를 수동 전달해 로컬 볼트에서 이어가기 | 전체 볼트 동기화가 아님. E의 원격 세션은 Muse 밖 대안이며, 집 PC와 로컬 Claude Code 세션이 필요 |
| AI로 실제 볼트 자료 검색·편집 | 집 PC의 로컬 작업 도구에서 볼트 규칙에 따라 수행 | Muse의 전체 볼트 연결은 미승인·미구성. 현재 Dropbox/Drive 합성 시험은 실제 볼트 자료를 대상으로 하지 않음 |
| Muse 결과를 집 PC에서 회수 | 개별 파일 다운로드 또는 본인에게 이메일 전달; Dropbox 데스크톱 앱은 깨어 있는 PC에서 합성 시험 파일 자동 동기화 확인 | Dropbox 절전 효과·모바일 경로·실제 작업 자료 동기화 미검증. Drive 자동 동기화 미검증 |
| 볼트 사본 자동화 | 현재 운영 경로 없음. 검토 전용 미리 보기만 가능 | 원본 루트·포함/제외 경로·등급·목적지·실행 주기 미정. 내부 자료 외부 전송 금지. `--apply` 미실행 |

## 멈춤과 되돌림

현재 예약 복사나 자동 미러링은 구성하지 않았다. 향후 승인된 복사 작업에서 문제가 생기면 새 실행을 멈추고 원본 볼트를 기준으로 결과와 목적지 범위를 검토한다. 원본 파일을 되돌림 수단으로 삭제하거나 덮어쓰지 않는다. 재실행·범위 변경은 새 미리 보기와 승인 뒤에 한다.

이미 만들어진 외부 사본을 정리하거나 Dropbox/Drive 연결을 끊는 일은 이 표가 허용하지 않는다. 정확한 대상과 영향을 먼저 제시한 뒤 사용자 확인을 받아야 한다. 이번 작성에서 삭제·연결 해제·복사는 수행하지 않았다.

## 권고안 — 승인 전 초안

현재 검증 근거에 맞는 임시 조합은 **자동 볼트 미러 없음**이다. 밖에서 Muse를 사용할 때는 필요한 결과 파일만 수동으로 집에 전달하고, 실제 볼트 규칙이 필요한 작업은 로컬 도구로 처리한다. 집 PC가 켜져 있는 조건의 원격 작업은 E · Claude Code Remote Control을 선택할 수 있지만, 이는 Muse 바깥의 대안 경로다.

Dropbox와 Drive는 합성 파일 시험에서 동작했으나, 연결 권한이 한 폴더에만 제한됨을 검증하지 못했다. 따라서 이 성공을 실제 볼트 연결의 승인 근거로 보지 않는다. 이 임시 조합은 운영 경로를 가동했다는 뜻도 아니다.

## 결정 대기

- 임시 조합(자동 미러 없음) 승인 여부와 실제 볼트에서 허용할 자료 등급·명시적 포함 경로
- 저장소·목적지·접근 범위·보존 기간·자동 실행 여부
- 모바일·절전·폴더 제한 시험의 필요성과 범위
- 승인 후 실행 전 미리 보기 및 복구 절차
