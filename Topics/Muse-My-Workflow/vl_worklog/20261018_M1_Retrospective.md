# Module Retrospective — M1 작업 목록과 Muse 적합도 지도

## 계획 대비 실제

| 항목 | 계획 | 실제 |
|---|---|---|
| 시간 | 1.5h | 방송 4부 안 (약 50분 계획) |
| 작업 목록 | 15개 이상 | 18개 — 박창수가 추가 없이 확인 |
| 상위 작업 | 5개 | 6개 — 박창수가 Remotion 슬라이드 플랜 · 대본 추가 |
| 기능 확인 | 공식 자료 | Meta 발표문 + 도움말 6개 페이지, 미확인 4개 · 재확인 1개 |

## 핵심 학습 내용

- Muse 의 역할은 볼트를 대신하는 것이 아니라 **볼트로 들어오는 입구**다 — 판정 18개 중 10개가 「초안만」.
- 데이터 등급(공개 / 개인 / 내부)을 먼저 보면 판정이 빨라진다. 내부는 다른 기준을 볼 필요가 없다.
- 공식 자료로 확인된 것: Markdown 파일 만들기 · Library 저장 · 전체 데이터 내려받기 · 백그라운드 작업 · 웹 접근 · 이메일 커넥터 · 무료 한도.

## 발생한 문제와 해결

- 검색 요약에만 있는 기능(기억 가져오기)을 「확인」으로 쓸 뻔했다 → 원문 페이지에서 못 찾아 「재확인 필요」로 낮췄다.
- 박창수의 핵심 방식인 음성 지시가 공식 자료에 없다 → 키보드 받아쓰기를 대안으로 M2 에 넣었다.

## Roadmap 정확도 평가

M1 실습 세 개가 계획대로 맞았다. 다만 상위 「5개」는 고정할 필요가 없었다 — 박창수가 원하는 작업을 더하는 것이 자연스럽다. M2 의 「방법 4가지 이상」은 공식 자료 결과로 보아 Library 개별 다운로드 · 전체 다운로드 · 공유 링크 · 메일 커넥터 · 복사 · WhatsApp 으로 채울 수 있다.

## 다음 모듈 준비사항

- Muse 웹(집 PC)과 휴대폰 앱 둘 다 로그인된 상태
- 시험용 공개 내용 하나 (예: 수요일 특강 안내 요약)
- 메일 커넥터를 시험할지 박창수가 미리 결정
- 볼트 착지 위치 후보 생각해 두기
