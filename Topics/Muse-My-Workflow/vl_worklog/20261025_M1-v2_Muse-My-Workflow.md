## 📚 진행 내용

### 1. 실습 4 — 기능 표 v2

**과정**: Meta 도움말 5곳(Artifacts · 데이터 관리 · 시작하기 · 커넥터 · 안내와 승인) · 발표문 · Meta Connect 2026 · Dropbox 도움말을 다시 열어 확인했다. Microsoft 발표는 공식 블로그 검색 결과로, TIME 보도는 Malwarebytes 요약으로 확인했다. 여기에 박창수가 2026-10-20~22 안드로이드에서 직접 다뤄 본 결과(음성 입력 · Gmail · Google Calendar · 반복 알림 · 설정 2개)를 더했다.

**결과**:
- 표가 16행에서 25행이 됐다. 새 행 9개 — Gmail · Google Calendar · 반복 알림 · Dropbox · Google Drive · OneDrive / iCloud · 사용자 정의 커넥터 · 연결 권한 · 학습 사용 끄기 · 내 PC 직접 다루기
- 행마다 출처 종류(공식 / 직접 / 2차 / 미확인)와 확인일을 달았다
- v1 미확인 4개 → 음성 입력 ✅(직접), GitHub 🔶(커넥터 발표 · 권한 미확인). 개별 다운로드 · 전체 다운로드 형식은 그대로 M2 로
- 「기억 가져오기」는 데이터 관리 도움말에 없어 ⚠️ 재확인 필요 → ❓ 미확인으로 낮췄다
- 남은 것: 앱 Settings → Connectors 실제 목록 (방송, 계정 가림)

## 💡 Daily Retrospective

### What went well
- v2.0 보강 항목이 M1 파일 4개에 1:1로 맞아서, 새 문서를 만들지 않고 기존 문서를 고치는 것으로 끝났다.
- 근거를 「공식 / 직접 / 2차 / 미확인」으로 나누니, 같은 「된다」라도 무게가 다르다는 것이 표에서 바로 보인다.

### What could be improved
- 새 작업 5개는 Claude Code 가 볼트 기록과 대화로 골랐다. 박창수가 요즘 실제로 Muse 로 한 일을 들으면 더 정확해진다.
- 앱 화면을 볼 수 없어 커넥터 목록은 공식 자료로만 채웠다.

### Insights
- **연결은 올리는 것과 같다.** 커넥터를 연결하면 「올리지 않는다」는 규칙과 상관없이 그 안에 닿는다. 그래서 연결 규칙이 M2 · M4 의 문을 연다.
- 기준 ② 는 「Muse 가 볼트를 못 본다」는 전제였다. M4 가 그 전제를 바꾸면 판정 5개가 움직일 수 있다 — M1 은 끝난 문서가 아니라 M4 · M5 결과로 계속 고치는 지도다.
