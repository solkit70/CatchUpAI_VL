## M5 진행 상태

M5의 기존 7일 사용 WorkLog에는 날짜별 사용 여부, 입력 방식, 결과 경로, 수정량을 모두 담은 기록이 없다. 11/12와 11/13의 Muse 사용은 실제 업무 기여 증거로 남기되, 각각 처음부터 끝까지 Vault에서 마무리한 것으로 판정하지 않는다. 11/11 원격 Claude Code 작업과 11/8~11/15 M4 합성 실험도 M5 일상 사용과 구분한다.

11/15에는 사용자가 고른 공개 Matsutake 영상 업무를 Muse에서 시작해 영어 Substack 초안으로 만들었다. 33분가량의 영상 전체 재생은 중단하고 YouTube 내장 transcript를 사용했으며, 자동 더빙으로 인한 표현 오류 가능성을 초안의 출처 메모와 검증 목록에 남겼다. 초안은 Muse artifact로 저장되었으나 아직 Vault에 옮기거나 실제 Substack에 발행하지 않았고, 최종 편집량도 측정하지 않았다. 따라서 실제 업무 1건을 Muse에서 처리한 실습으로 기록하되, M5 end-to-end 완료 건수에는 포함하지 않는다.

Roadmap의 M5 실습 1·2와 DoD는 계속 미완료다. 11/8~11/14 사용 기록을 소급 작성하지 않으며, 다음에는 이 공개 초안을 검토해 Vault의 최종 위치에 편입하고 편집량을 기록하거나 다른 사용자가 고른 실제 작업을 같은 방식으로 시작한다.

## 계획한 다음 실습

사용자가 고른 공개 송이 영상 기반 Substack 초안을 Muse에서 작성했다. 다음 확인 지점은 초안 사실 검토, Vault 최종 위치로의 편입 여부, 집에서 고친 양과 전체 소요 시간이다. 발행은 하지 않았다.

## 진행 내용 — 사용 가이드와 실제 Muse 업무

로드맵의 M5 요구사항과 M1 적합도 지도, M2 Vault 편입 프롬프트, M4 작업 경로표 및 승인된 사본 원칙을 대조해 [일상 사용 가이드 초안](../05-Daily-Use-Guide/guides/daily-use-guide.md)을 작성했다. 가이드는 자료 등급 확인, Muse 초안 작성, 출처 검토, 수동 회수, `_Inbox_/` 편입의 5단계로 구성했다. 합성 자료 시험을 실제 Vault 동기화로 확대 해석하지 않았고, 기존 11/12·11/13 사례도 M5 end-to-end 완료로 집계하지 않았다.

M5 산출물 폴더는 이번에 처음 만들었다. 아직 `README.md`, 프롬프트 모음, 통합 규칙, 실제 업무 사례, 7일 로그는 작성하지 않았다. 11/15 작업은 공개 영상과 그 transcript만 근거로 Muse에서 초안을 작성했으며, parent chat이나 별도 로컬 자료를 입력하지 않았다. 초안 제목은 `Sixty-One Matsutake in the Woods`이고, Muse UI상 797단어로 표시된다. Muse에 표시된 생성·수정 시간은 05:54–06:17 PST로 약 23분이며, 초안을 Vault로 옮긴 시간이나 집에서의 편집량은 기록하지 않았다.

### M5 DoD 상태

- [ ] 실제 업무 2~3건을 밖에서 시작해 Vault에서 마무리하고 시간·수정량 기록 — Muse에서 초안 작성 1건. Vault 편입과 수정량이 없어 end-to-end에는 미산입
- [ ] 새 7일 관찰 구간의 사용·미사용 기록 — 미시작, 과거 날짜를 소급 기록하지 않음
- [ ] 사용 가이드·프롬프트 모음·규칙 — 가이드 초안만 작성, 미검증 절차는 초안 표시
- [ ] 적합도 지도·경로표 수정 — 새 실제 업무 검증 후 판단

**캡처 목록:** Muse의 공개 YouTube 영상 재생 장면, 새 작업 대화, 수정된 초안 화면을 CUA 화면 캡처로 확인했다. 캡처 이미지는 이 대화의 화면 기록에는 보이지만 M5 폴더의 파일로 저장하지 않았으므로, 영상 편집용 로컬 캡처 경로는 아직 없다. 실제 작업 때 계정·개인 정보는 가리고 공개 자료만 사용한다.

## Retrospective

이번 실제 작업에서는 영상 전체를 재생하지 않고 YouTube 내장 transcript를 사용해 처리 시간을 줄일 수 있었다. 반면 영어 자동 더빙 transcript만으로는 버섯 종류, 채취량과 폐기량의 산식, 위치 표현을 확정하기 어려워 검증 목록을 남겼다. Muse가 첫 초안에 영상의 AI·사업 계획까지 섞어 썼기에 사용자가 범위를 좁혀 달라고 요청했고, 수정본은 숲과 채취 이야기만 남겼다. M5 기록에는 Muse 초안, 전달 경로, Vault 최종 위치, 고친 양을 한 행으로 남겨 작업 완결을 확인한다.

## 다음 세션에 넘길 것

Muse artifact `Sixty-One Matsutake in the Woods`는 초안 상태이며 아직 발행하지 않았다. 별도의 자료 검토·Vault 편입 여부는 사용자가 결정한다. 11/16부터 11/22까지 새 7일 M5 실습을 진행할 계획을 [일상 사용 가이드](../05-Daily-Use-Guide/guides/daily-use-guide.md#2026-11-16부터-7일-실습-계획)에 추가했다. KSDD 호텔 숙박일이 확정되면 H1~H3을 실제 이동일에 맞추고, 공개·비민감 자료와 Muse 내부 저장을 기본으로 한다. 매일 실제 사용/미사용, 기기 전환, 결과 회수, 소요 시간과 편집량을 당일 기록한다. 계획 수립은 실습 완료로 세지 않는다.
