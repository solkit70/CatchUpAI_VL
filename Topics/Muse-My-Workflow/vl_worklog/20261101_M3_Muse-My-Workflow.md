#### 실습 2 — Muse 재시험 (muse.ai · 기존 계정 · Claude Code 가 직접 입력, 07:2x)

**조건**: muse.ai 웹, 박창수가 쓰는 기존 계정. Muse 는 대화가 **하나로 이어지는 구조**라 새 대화를 열 수 없어, 1차 대화 바로 뒤에 이어서 보냈다. 박창수 요청대로 「Meta AI 와 혼동해 거기서 시험했다, 여기 Muse 에서 처음부터 다시 한다, 전에 시작한 Topic 진행은 잇지 말자」는 알림을 앞에 붙이고, 지시문 본문은 1차와 같다. 이후 질문에는 짧게 답했다(대부분 「예시 그대로」). 1차 때 Muse 작업 기록에 「Fetched roadmap and daily learning templates」가 남아 있다 — 1차에 템플릿을 실제로 가져왔다.

**진행 순서 (Muse)**: 「Meta AI 에서 했던 건 전부 잊고 처음부터」 → 질문 1 Topic 이름(`AI-Public-Event-Scheduling` 제안) → 질문 2 학습 목적 → 질문 3 기간 → 질문 4 학습 목표(예시 3개) → 질문 5 환경 → 질문 6 사전 지식 → **수집 내용 요약 + 「이대로 Topic 폴더를 만들까요?」에서 멈춤** → (승인) 워크스페이스에 폴더 · `topic_info.md` · `vl_prompts/` 두 파일 생성, 「[1단계] 플레이스홀더만 주입, [2단계] · [3단계] 는 원본 그대로 유지」 → **「사용자 승인 없이는 로드맵 파일을 만들지 않습니다. 넘어갈까요?」에서 멈춤** → (승인) **「로드맵 프롬프트 전체를 다시 읽었습니다. [2단계] STEP 1 규칙에 따라, 로드맵 생성 전에 학습 기간 적정성 검토부터 하고 여기서 멈춥니다」** → 기간 분석(2주 · 주당 3시간 = 적정함) + 「사용자 확인 필요 — 그대로 진행 / 기간 조정 / 범위 조정」. 시험은 여기서 끝냈다(답하지 않음).

## 🎓 가르칠 때

- 「Muse」와 「Meta AI」는 다른 곳이다 — 주소부터 확인시킨다 (muse.ai)
- 밖에서 AI 에게 학습 절차를 맡길 때 지시문에 넣을 두 줄: 「원문을 못 읽으면 지어내지 말고 먼저 알려 줘」 · 「승인 전에는 다음 단계로 가지 마」
- AI 가 「기억해 둘게 / 노력할게」라고 하면 저장된 것이 아니다 — 「어디에 저장했는지」를 묻는다
- 「잊어 줘」는 계획을 먼저 읽고 승인한다. 지울 수 없는 것 · 부작용이 함께 나온다
