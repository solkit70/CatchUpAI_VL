## 핵심 학습 내용

- **「요약했다」와 「지시를 따랐다」는 다르다.** 지시문에 「멈춰라」를 일부러 넣지 않고, 지시 파일에 적힌 멈춤 지점에서 멈추는지를 채점했다. Muse 는 세 번 멈췄다.
- **같은 Meta 계열이라도 Muse 와 Meta AI 는 다른 제품이다.** 실수로 Meta AI 에서 먼저 시험했는데, Meta AI 는 원문을 못 읽은 채 Roadmap 까지 지어내고 기억도 못 했다. 「원문을 못 읽으면 먼저 알려 줘」 한 줄이 지어내기를 막는다.
- **밖에서 시작한 Topic 은 파일 3개로 집에 넘어온다.** Topic 정보 · 두 프롬프트만 있으면 다음 에이전트가 승인 대기 지점부터 이어받는다. 다운로드본 동일성 확인과 지시 내용 대조는 서로 다른 검증이다.
- **에이전트가 바뀌어도 이어졌다.** Claude Code 가 11/1 WorkLog 에 남긴 「다음 세션에 넘길 것」에서 Codex 가 11/5 에 그대로 시작했다. 로드맵의 「어느 에이전트가 이어받아도 WorkLog 만 읽고 시작」 설계가 처음 실제로 쓰였다.

## 발생한 문제와 해결

- **Claude Code 가 Muse 주소를 확인하지 않고 meta.ai 를 열었다.** Live #31 기록에 muse.ai 가 있었다. Muse 에서 다시 시험했고 Meta AI 결과는 비교 자료로만 남겼다. 시험 대상 서비스의 주소는 볼트 기록에서 먼저 찾는다.
- Chrome 확장은 사용자가 연 탭을 조작하지 못했다 — 「제 탭에 열고 로그인은 직접」으로 처음부터 안내했어야 했다.
- 방송 화면용 답변이 길었다(10/25) — 화면에는 표 하나와 할 일 3줄이 적당하다.
- **마지막 세션의 기록 형식이 앞 세션과 달라졌다.** 11/5 WorkLog 에는 머리(날짜 · 진행 에이전트), DoD 체크리스트 형식, 「다음 세션에 넘길 것」이 없었다 — 이번 점검에서 보강했다. 두 에이전트가 번갈아 할 때는 같은 WorkLog 양식을 쓴다.

## Roadmap 정확도 평가

실습 네 개와 판정 기준(가능 / 일부 가능 / 불가)이 잘 맞았다. 시간은 1.5시간 계획이었지만 세 세션 · 약 12일에 걸쳤다 — 방송 안에서 다른 실험과 나눠 진행했기 때문이고, 그만큼 M4 시작이 밀렸다. 「밖에서 할 수 있는 조각 / 집에서만 되는 일 목록」은 [집에서 이어받는 방법](../03-VibeLearn-on-Muse/guides/handoff-to-home.md)의 「밖에서 준비할 것 · 집에서 확인할 것」으로 대신 정리됐다. 로드맵이 계획한 별도 목록 형식보다 절차 문서가 실제로 더 쓸모 있었다.
