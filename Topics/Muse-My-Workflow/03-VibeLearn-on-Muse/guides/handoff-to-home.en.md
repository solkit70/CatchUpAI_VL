## What to Check at Home

1. In the Muse Library, open the Topic under **System files** → **workspace** → **Topics**. Use **More actions → Download** on each Markdown file.
2. Put `topic_info.md` in the vault's `_Inbox_/<Topic>/`, and the two prompts in `vl_prompts/` inside it, keeping the original structure.
3. Compare [Step 2] · [Step 3] of `roadmap_prompt.md` and `daily_learning_prompt.md` with the original templates. Have Codex or Claude Code at home read the actual input, and pick up from the point waiting for approval.
4. If a file is missing or the instructions changed, record which file or section is missing. Roadmap creation after the duration check goes ahead only after the user confirms that Topic's duration.
