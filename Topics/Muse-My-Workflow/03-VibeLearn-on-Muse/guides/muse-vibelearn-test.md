# Muse 시험과 결과

## 재현 순서

공개 주제로 시험한다. Muse에 공개 저장소의 지시 원문을 먼저 읽도록 하고, 원문을 읽을 수 없으면 그 사실을 알려 달라고 요청한다. 각 단계에서 질문, 승인 대기, 실제로 만든 파일을 확인한다.

| 시험 | 관찰 결과 | 근거 |
|---|---|---|
| 원문 읽기 | 공개 저장소를 읽고 Topic 시작 절차를 확인했다. | [10/25 실습 1](../../vl_worklog/20261025_M3_Muse-My-Workflow.md#1-실습-1--지시-파일-읽기-시험-웹-새-대화) |
| 순서 | 폴더 생성, Phase 2 진입, 로드맵 생성 앞에서 멈췄다. 첫 시험에서는 Topic 설명을 별도 질문으로 묻지 않았다. | [11/1 실습 2](../../vl_worklog/20261101_M3_Muse-My-Workflow.md#1-실습-2--순서-지키기-시험-웹-새-대화) |
| 기억 | 규칙을 `MEMORY.md`에 저장했고 새 사이드 대화에서 재현했다. 삭제를 요청하자 영향과 확인 절차를 보여 줬으며 기억은 유지했다. | [11/1 실습 3](../../vl_worklog/20261101_M3_Muse-My-Workflow.md#2-실습-3--기억에-규칙-넣기-muse--museai--기존-계정-0729) |
| 이어받기 | 원본 3개를 받아 두 프롬프트의 지시를 대조하고 Codex에서 기간을 검토했다. 판정은 **가능**이다. | [11/5 실습 4](../../vl_worklog/20261105_M3_Muse-My-Workflow.md#실습-4-결과) |

기억을 지우려면 저장 위치와 삭제 범위를 먼저 묻고, Muse가 보여 주는 영향과 부작용을 읽은 뒤 확인한다. 11/1에 진행한 Meta AI 시험은 같은 지시의 비교 사례로 기록했다. [기억·비교 기록](../../vl_worklog/20261101_M3_Muse-My-Workflow.md#2-실습-3--기억에-규칙-넣기-muse--museai--기존-계정-0729)
