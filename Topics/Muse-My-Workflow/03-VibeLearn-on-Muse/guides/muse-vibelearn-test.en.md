## How to Reproduce

Test with a public subject. Have Muse read the original instructions in the public repository first, and ask it to tell you if it can't read the original. At each step, check the questions, the waits for approval, and the files it actually made.

| Test | What was observed | Evidence |
|---|---|---|
| Reading the original | It read the public repository and checked the Topic start procedure. | [10/25 Exercise 1](../../vl_worklog/20261025_M3_Muse-My-Workflow.md#1-실습-1--지시-파일-읽기-시험-웹-새-대화) |
| Order | It stopped before creating folders, entering Phase 2, and creating the roadmap. In the first test, it did not ask about the Topic description as a separate question. | [11/1 Exercise 2](../../vl_worklog/20261101_M3_Muse-My-Workflow.md#1-실습-2--순서-지키기-시험-웹-새-대화) |
| Memory | It saved the rules to `MEMORY.md` and reproduced them in a new side conversation. When asked to delete, it showed the impact and the confirmation procedure, and the memory was kept. | [11/1 Exercise 3](../../vl_worklog/20261101_M3_Muse-My-Workflow.md#2-실습-3--기억에-규칙-넣기-muse--museai--기존-계정-0729) |
| Handoff | It received the 3 originals, compared the instructions in the two prompts, and reviewed the duration in Codex. The verdict is **possible**. | [11/5 Exercise 4](../../vl_worklog/20261105_M3_Muse-My-Workflow.md#실습-4-결과) |

To delete memory, first ask about the storage location and the scope of deletion, read the impact and side effects Muse shows, and then confirm.
