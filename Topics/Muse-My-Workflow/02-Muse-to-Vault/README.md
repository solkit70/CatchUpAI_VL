# M2 — Muse ↔ 볼트 옮기기 (양방향)

**상태**: ✅ 완료 (2026-10-25, Live #33 1부) — 밖 → 집 4가지 · 집 → 밖 2가지 · 음성 원문 · 휴대폰 시험 · 받는 곳 A · 추천표 승인 · 정리 프롬프트 1건 시험까지 마쳤다
**예상 학습 시간**: 2시간

밖에서 Muse 로 만든 결과를 집의 볼트로 옮기고, 집에서 하던 일을 Muse 가 이어받게 하는 방법을 **직접 해 보고** 비교했다. 네 방법 모두 Markdown 원문이 안 깨졌다 — 그래서 방법을 고르는 기준은 보존도가 아니라 단계 수 · 휴대폰에서 되는가 · 연결이 필요한가였다. 받는 곳은 볼트에 이미 있던 `_Inbox_/` 로 정했고, 옮긴 뒤의 정리 6단계와 프롬프트를 만들어 시험 파일 한 건으로 확인했다.

## 이 모듈에서 알아낸 것

- 파일 하나씩 내려받기는 공식 도움말에 없었지만 **앱에는 있다**(카드 → ⋯ → Download). 내 메일로 보낸 첨부는 원본과 **바이트까지 같았다**.
- 넘김 꾸러미(어디까지 · 정한 것 · 다음 할 일 + 「모르는 것은 모른다고 해」)를 올리면 Muse 가 한 줄 지시로 이어받는다. 다만 꾸러미에 없던 볼트 규칙을 몰라 **한글 키 머리말**을 만들었다.
- 공개 레포 링크는 읽히지만 **push 한 것만** 보인다(올라간 건 10/18 버전).
- 전체 데이터 내려받기는 폴더 구조가 남은 zip 이지만 개인 정보가 한꺼번에 든다 — 백업용이다.
- 음성으로 말한 메모는 「한 글자도 바꾸지 말고 마크다운 파일로 저장해줘」 한 줄로 **받아 적은 글 그대로** 파일이 됐다(군더더기 말까지 남음). 휴대폰에서 보낸 메일의 첨부도 웹에서 받은 파일과 바이트까지 같았다.
- 확인 못 한 것: 말소리 자체와 받아 적은 글의 일치(본인만 판단 가능), 휴대폰 Save to Files 의 저장 형식, 학습 끄기 스위치가 있는지(M4).
