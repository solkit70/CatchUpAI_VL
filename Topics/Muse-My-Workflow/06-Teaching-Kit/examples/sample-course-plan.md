# Muse 교육 블록 예시 과정

이 예시는 학습자 목표에 맞춰 블록을 조합하는 방법을 보여 준다. 모든 실습에는 공개 또는 가상 자료만 사용한다.

## L1 시작 사용자 — 60분 체험

정규 카드를 줄인 체험이다. 시작 전에 휴대폰에서 Muse를 열 수 있는지 확인한다. AI가 처음이면 한 번에 한 동작을 보여 주고 따라 할 시간을 준다.

| 순서 | 블록 | 시간 | 완료 결과 |
|---|---|---:|---|
| 1 | 1. Muse 시작과 자료 안전 | 15분 | Muse를 열고 가상 메모에서 입력할 내용 하나 고르기 |
| 2 | 2. 음성·메모·메일·일정 초안 요청 | 25분 | 안내 메일 또는 일정 문안 하나를 말로 요청하고 시간 확인 |
| 3 | 4. 결과를 파일로 회수하고 확인하기 | 20분 | 연습 파일 하나를 내려받아 열고 원문과 비교 |

### 한 장으로 따라 하기

큰 글씨로 인쇄하고, 직접 할 수 있으면 O, 도움이 더 필요하면 X에 동그라미를 친다. [시니어 과정 1주차 카드의 형식](../../../Senior-AI-Enablement/06-Curriculum-v1/guides/week1-card.md#오늘-배운-것)을 참고했다.

1. 휴대폰에서 Muse를 열고 입력창을 찾았어요. **( O　X )**
2. 마이크를 눌러 이렇게 말했어요. 「아래 가상 메모로 안내 메일 초안만 써 주세요. 시간이 틀리지 않았는지 확인해 주세요.」 **( O　X )**
3. 받은 파일을 직접 열고 시간과 장소를 확인했어요. **( O　X )**

꼭 지킬 약속은 세 가지다. ① 보낼지 묻는 화면에서는 멈춘다. ② 비밀번호와 실제 연락처는 말하지 않는다. ③ 어려우면 「한 단계씩 다시 알려 주세요」라고 말한다.

## 공통 실습 재료

### 가상 행사 메모

> 별빛 도서관 종이공작 모임은 12월 5일 오전 10시부터 11시까지 열린다. 장소는 연습실 A다. 신청 마감일은 아직 정해지지 않았다.

메일 연습은 「가상 행사 메모만 근거로 제목과 본문 3줄을 써 주세요. 발송하지 말고 신청 마감은 미정으로 표시해 주세요」라고 요청한다. 일정 연습은 「같은 메모를 제목·날짜·시작과 종료 시간·장소 순으로 정리해 주세요. 캘린더에는 등록하지 마세요」라고 요청한다. 기대 결과는 **12월 5일, 10:00–11:00, 연습실 A, 마감 미정**이다. 연도와 날씨는 자료에 없다. [M5 행사 메모 프롬프트](../../05-Daily-Use-Guide/guides/prompt-pack.md#행사-일정이나-현장-메모-정리하기)

회수 연습은 「확인한 내용을 `practice-result.md`라는 새 파일에 저장하고 파일 이름과 저장 위치를 알려 주세요」라고 요청한다. 파일을 열어 기대값과 대조한다. [M5 회수 프롬프트](../../05-Daily-Use-Guide/guides/prompt-pack.md#결과를-회수하고-vault에서-마무리하기)

### 가상 업무 카드 6개

각 행을 가리고 선택한다. 공개 자료이고 Muse를 쓰는 이점이 있으면 맡김, 사람의 검토나 외부 실행이 남으면 초안만, 민감한 원문이나 로컬 맥락이 필수면 맡기지 않음을 기본값으로 삼는다.

| 업무 설명 | 기대 판정 | 이유 |
|---|---|---|
| 공개 공지에서 일정만 추출 | 맡김 | 원문으로 확인 가능 |
| 가상 음성 메모를 항목별로 정리 | 맡김 | 휴대폰으로 바로 기록 가능 |
| 가상 행사 안내 메일 준비 | 초안만 | 수신자·사실 확인 필요 |
| 가상 행사 일정 등록 준비 | 초안만 | 시간 확인과 등록 결정 필요 |
| 진료 메모 원문 요약 | 맡기지 않음 | 민감한 원문 필요 |
| 내부 계약서 원문 검토 | 맡기지 않음 | 내부 자료와 맥락 필요 |

### 가상 검색 폴더

아래 세 파일을 작은 테스트 폴더에 복사한다. 인덱스에서 경로를 고르되 시간은 원문에서 확인한다.

```text
INDEX.md
- [일정](schedule.md)
- [장소](venue.md)

schedule.md
- 종이공작 10:00–11:00
- 그림책 10:30–11:30

venue.md
- 종이공작: 연습실 A
- 그림책: 연습실 B
```

「INDEX.md를 열어 두 행사의 공통 시간대를 찾아 주세요. 실제로 읽은 파일과 근거 줄을 적고 파일에 없는 것은 없다고 말해 주세요.」 기대값은 **10:30–11:00**, 시간 근거는 **schedule.md**의 두 줄이다. 검색 범위에 대한 접근이 없으면 파일을 열지 못했다는 답을 받고 가상 파일을 직접 제공한다.

## 선택 과제 — 한 주 써 보기

개인정보가 없는 업무 하나를 골라 일주일 동안 필요할 때 적용한다. 날짜, 맡긴 범위, 받은 결과, 사람이 고친 부분을 한 줄씩 기록한다. 마지막에 다음 주에도 쓸 요청 문장 한 개와 로컬에서 처리할 일 한 개를 고른다. [M5 실습 결과](../../05-Daily-Use-Guide/README.md#실습-결과와-현재-상태)

## 강사용 준비와 평가

수업 전에 Muse 로그인이나 계정 복구를 수업 시간에 포함할지 결정하고, 기본 화면을 미리 확인한다. 가상 행사 메모와 검색용 세 파일을 미리 준비한다. 수업 중 파일 생성이 막힐 때를 대비해 같은 내용으로 만든 가상 Markdown을 준비한다. 학습자는 목표에 맞는 프롬프트를 만들고, 답의 근거를 찾고, 파일을 회수해 검토한 뒤 다음에 사용할 작업 흐름을 설명하면 과정을 마친 것으로 본다.

학습자가 자료 연결이나 파일 회수에서 막히면 대신 조작하지 않는다. 화면에서 보이는 상태와 시도한 경로를 확인하고, 한 단계씩 다시 시험하게 한다.
