# 교육 블록과 학습자 레벨

## 교육 블록은 무엇인가

정규 교육 블록은 40~50분 안에 하나의 실무 능력을 연습하는 독립 수업 단위다. 커리큘럼은 학습자의 목표와 현재 수준에 맞게 여러 블록을 순서대로 묶은 과정이다. 모든 수업을 같은 순서와 속도로 진행하지 않고, 필요한 블록을 선택한다.

## 학습자 레벨

| 레벨 | 출발점 | 학습 목표 | 권장 블록 |
|---|---|---|---|
| L1 시작 사용자 | AI가 처음이거나 사용 경험이 거의 없음. 휴대폰을 혼자 쓰기 어렵다면 한 단계씩 먼저 연습 | 휴대폰에서 음성으로 메일·일정 문안을 요청하고 결과를 확인한다 | 1, 2, 4 |
| L2 업무 사용자 | AI를 써 봤으며 반복 업무에 적용하고 싶음 | 적합한 업무를 골라 자료를 주고 결과를 검토한다 | 1, 3, 4 |
| L3 개인 자료 사용자 | 노트·문서·프로젝트 자료를 체계적으로 관리함 | 허용된 자료 범위에서 찾고, 근거를 확인하고, 로컬 자료에 반영한다 | 1, 3, 4, 5 |

레벨은 나이, 직함, 기술 배경으로 추정하지 않는다. 학습자가 직접 해 본 일, 사용할 기기, 달성하고 싶은 결과를 질문해 고른다. 시작 블록은 모든 레벨에서 자료 안전이다.

첫 수업의 레벨을 이후에도 그대로 적용하지 않는다. 다음 수업 전에 「혼자 무엇을 만들었나요?」「어디까지 직접 했고 어느 부분에서 도움을 받았나요?」「오늘 더 잘하고 싶은 것은 무엇인가요?」를 묻는다. 결과물을 만들었다는 보고와 강사가 직접 확인한 능력을 구분하고, 확인한 부분에 맞춰 기초 단계를 줄이거나 필요한 블록을 선택한다. [시니어 과정의 수업 전 점검](../../../Senior-AI-Enablement/06-Curriculum-v1/guides/muse-5week-intro-course.md#수업-준비와-공백-뒤-현재-능력-확인)

정규 시간은 [수업 카드](../guides/lesson-cards.md)를 기준으로 삼는다. [60분 체험](../examples/sample-course-plan.md#l1-시작-사용자--60분-체험)은 블록 1·2·4의 핵심 동작만 연습하는 축약판이다. 짧은 실습 시간을 감안해 나머지 동작은 정규 카드로 이어 간다.

M5의 일상 사용 관찰은 모든 레벨이 자신의 업무를 돌아보는 데 쓸 수 있다. 별도 여섯 번째 블록 대신 [선택 과제](../examples/sample-course-plan.md#선택-과제--한-주-써-보기)로 두어 첫 수업에 추가 시간을 요구하지 않는다. [M5 실습 결과](../../05-Daily-Use-Guide/README.md#실습-결과와-현재-상태)

## 설계 원칙

1. 실제 사람의 이름·연락처·회사 문서를 수업용 예시로 쓰지 않는다.
2. 기능 설명은 공식 문서나 수업 중 직접 확인한 결과를 구분한다.
3. AI가 답을 만들었는지와 사람이 사실을 검증했는지를 따로 본다.
4. 실습은 결과물 하나를 완성하게 한다. 단순히 기능 목록을 훑지 않는다.
5. 발송·게시·결제·계정 설정 변경은 실습에서 수행하지 않는다. 안전한 가상 입력으로 초안을 만들고 사람이 검토하는 데까지 연습한다.
6. 개인 지식 자료 연결은 작은 공개·가상 폴더부터 시작한다. 연결 가능 범위와 회수 결과를 직접 확인하기 전에는 전체 자료에 접근한다고 가정하지 않는다.

## 수업 성과 확인

학습자는 목표에 맞는 요청을 작성하고, 결과의 출처와 미확인 사항을 찾아내며, 저장 또는 회수 경로를 설명할 수 있어야 한다. 강사는 정답을 대신 말해 주기보다 학습자가 자료를 확인하고 판단하는 과정을 관찰한다.
