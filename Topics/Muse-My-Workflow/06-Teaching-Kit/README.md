# M6 — 다른 사람을 위한 Muse 교육 블록

**상태:** Claude 리뷰 및 11/28 수업 기록 분석 반영 · 키트 적용·효과 검증은 미완료

**M6 자료 개발 예상 시간:** 2시간. 수업 시간은 카드와 예시 과정 참조  
**대상:** Muse를 처음 쓰는 사람부터 개인 지식 자료를 가진 사용자까지

## 학습 순서

1. [개념 — 교육 블록과 레벨](concepts/teaching-blocks.md) — 5개 수업 블록과 학습자 수준을 고르는 기준을 익힌다.
2. [수업 카드](guides/lesson-cards.md) — 각 블록의 목표, 시간, 준비물, 단계, 실습, 확인 질문, 흔한 실수와 안전 규칙을 확인한다.
3. [막힐 때 FAQ](guides/troubleshooting-faq.md) — 실제 Muse 사용·자료 이동·검색 과정에서 자주 생기는 문제에 대응한다.
4. [레벨별 예시 과정](examples/sample-course-plan.md) — 학습 목적에 맞게 블록을 골라 60분·3회 과정으로 구성한다.

## 블록 한눈에 보기

| 블록 | 핵심 주제 | 대상 |
|---|---|---|
| 1 | Muse 시작과 자료 안전 | 모든 학습자 |
| 2 | 음성·메모·메일·일정 초안 요청 | 입문자 |
| 3 | Muse에 맡길 업무 고르기 | 업무·개인 자료 사용자 |
| 4 | 결과를 파일로 회수하고 확인하기 | 모든 학습자 |
| 5 | 개인 자료와 연결해 검색·작업하기 | 개인 지식 자료 사용자 |

정규 블록은 40~50분이다. [입문 60분 체험](examples/sample-course-plan.md#l1-시작-사용자--60분-체험)은 블록 1·2·4의 핵심 동작을 짧게 연습한다. [공통 실습 재료](examples/sample-course-plan.md#공통-실습-재료)에는 입력 예시와 기대 결과가 있다.

## 운영 원칙

실습은 공개 또는 가상 자료로 진행한다. 실제 계정 연결, 개인정보, 내부 문서, 발송·게시 같은 외부 실행은 수업 데모에 사용하지 않는다. Muse가 만든 답은 출처와 미확인 항목을 학습자가 확인한 뒤 채택한다.

수업을 준비할 때는 [예시 과정의 준비·적용 기록](examples/sample-course-plan.md#수업을-준비하고-적용을-기록하는-방법)부터 확인한다. 최근 능력 재확인, 결과물 선택, 원문 보존 편집과 최종 결과 확인을 보완했다. 실제 수업 기록을 뒤늦게 대조한 개선이며, 과거 수업에 이 키트를 적용했다거나 카드 시간·효과가 검증됐다는 뜻은 아니다.
