# 시즌별 핵심 작업 체크리스트

## 봄 (3~5월)

### 🌱 최우선 작업
- [ ] **이끼 제거제 살포** → 2주 후 Dethatching
- [ ] **첫 비료 살포** (3월 초) — 질소(N) 중심 스타터 비료 (예: 30-0-4)
- [ ] **스프링클러 재가동** 및 헤드 점검, 계절별 조정 설정 시작
- [ ] **Pre-emergent 살포** — 잡초 씨앗이 싹트기 전 예방

### 예초
- [ ] 2.5인치로 설정 (중간 눈금)
- [ ] 칼날 교체 또는 연마 (연 1회 스프링에 반드시)
- [ ] 주 1~2회 시작 → 성장 빨라지면 주 2~3회로 증가

### 물 주기
- [ ] 주 2~3회, 주간 목표 1인치
- [ ] 새벽 4~6시 타이머 설정
- [ ] Rain Sensor 작동 여부 확인

### 토양 관리
- [ ] 통기(Aeration) 실시 (봄 아니면 가을 선택)
- [ ] Topdressing: 통기 후 Compost 1/4인치 살포
- [ ] 토양 pH 테스트 (2~3년마다 권장, $100) — 목표 pH 6.0~7.0
- [ ] pH 낮으면 **석회(Lime) 살포**

### 곰팡이 예방
- [ ] **예방 살균제(Fungicide) 봄 살포** — 매년 봄 예방 차원으로 적용

### 주의
- [ ] Pre-emergent 살포 후 8~10주 내 오버시딩 금지
- [ ] 봄 오버시딩은 여름 스트레스에 노출 → 가을이 더 권장

---

## 여름 (6~8월)

### ☀️ 최우선 작업
- [ ] **물 주기 늘리기**: 6월 80% → 7~8월 100~110% (Seasonal Adjust)
- [ ] **비료 유지**: 6월, 7~8월 각 1회 (질소 중심)

### 예초
- [ ] 높이를 3~4인치로 올려 뿌리 보호
- [ ] 계속 주 1회 이상 유지 (1/3 규칙 준수)
- [ ] 90도 이상 연속 고온 시: 물 주기 최우선, 뿌리 생존 우선

### 물 주기
- [ ] 주 3~5회, 주간 목표 1.5~2인치
- [ ] 고온 시 물 주기를 하루에 한 번 이상으로 늘려도 됨
- [ ] 컵 테스트로 실제 물 양 측정 권장

### 잡초 관리
- [ ] **잡초 제초제 주의**: 잔디 스트레스 상태 → 제초제가 잔디도 손상
- [ ] POA 발견 시 즉시 파내기 (약제 효과 없음)

### 오버시딩 (선택)
- [ ] 8~9월이 최적 → 여름 막바지에 준비
- [ ] 오버시딩 전 최대한 낮게 예초
- [ ] 발아 기간 물 주기 하루 3~5회로 증가

---

## 가을 (9~10월)

### 🍂 최우선 작업
- [ ] **통기(Aeration)** — 연 1회 권장, **가을이 최적**
- [ ] **오버시딩** (Aeration 직후)
- [ ] **가을 비료** (칼륨 K 비율 높은 제품으로 전환)

### 예초
- [ ] 서서히 높이 낮추기 (겨울 준비)
- [ ] 잔디 성장 줄어들면 빈도 줄이기

### 물 주기
- [ ] Seasonal Adjust 80%로 줄임
- [ ] 주 2회, 주간 목표 1인치
- [ ] 오버시딩 기간은 하루 3~5회로 예외 적용

### 잡초 관리
- [ ] **가을 잡초 관리** 실시 (여름보다 덜 위험)
- [ ] 오버시딩 후 새 잔디 확인 → 제초제 금지

### 스프링클러
- [ ] **겨울화(Winterize) 예약** — 첫 결빙 전 완료
- [ ] 비용: $100~150, 직접 하기 어려우면 전문 업체

---

## 겨울 (11~2월)

### ❄️ 최우선 작업
- [ ] **11월 비료** — 가장 중요한 연간 비료
  - 칼륨(K) 중심 겨울용(Winterizer) 제품 (예: 24-0-10 또는 8-0-24)
  - 뿌리 강화, 동해 방지
- [ ] **스프링클러 완전 OFF** + 겨울화 완료

> "My most important fertilizer is the one before winter."

### 예초
- [ ] 잔디 성장 멈추면 예초 중단 가능
- [ ] **마지막 예초: 2인치**로 낮게 마무리 (Snow Mold·눕힘 방지)

### 모니터링
- [ ] **Snow Mold(눈곰팡이) 및 곰팡이** 관찰 → 필요시 살균제 처치
- [ ] 잔디 휴면 중에도 **살균제는 사용 가능** (비료는 효과 없음)
- [ ] 이끼 발생 구역 표시 → 봄 처치 계획 수립

### 금지 사항
- [ ] 비료 살포 금지 (휴면 중 성장 없음 → 효과 없음)
- [ ] 오버시딩 금지 (발아 온도 미달)

## 연간 비료 달력

| 월 | 비료 | 핵심 성분 |
|----|------|-----------|
| 3월 초 | 1차 | 질소(N) 중심 |
| 4~5월 | 2차 | 균형 |
| 6월 | 3차 | 질소(N) |
| 7~8월 | 4차 | 질소(N) |
| 9~10월 | 5차 | 칼륨(K) 강화 |
| **11월** | **6차 (가장 중요)** | **칼륨(K) 중심** |

---

## 전문 업체 도움이 필요한 상황

- 반복 문제가 해결되지 않을 때 → 토양 테스트 먼저
- 스프링클러 설치·수리 → 전문 관개 업체 (RMA Irrigation 등)
- 잔디 나이 15년 이상, 오버시딩 없이 방치 → 전면 교체 검토
- 나무 가지치기 (특히 Japanese Maple 등 특수 수종)

> "Grass has a lifespan just like we do of seven to ten years. If you're in a 15-year-old house and you never overseed it, that grass is dead."
