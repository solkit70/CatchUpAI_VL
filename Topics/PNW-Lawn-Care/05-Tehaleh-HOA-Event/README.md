# M5: Tehaleh HOA 잔디 관리 강좌

**강좌 일시**: 2026년 4월 15일 (화) 오후 5:30 – 7:00  
**장소**: Discovery Park Community Center  
**강사**: Neighbors Lawn Services (지역 조경 전문업체)  
**이전 모듈**: [M4: Annual Plan](../04-Annual-Plan/README.md)

---

## 강좌 개요

Tehaleh HOA가 주민을 위해 마련한 잔디 관리 전문 강좌. Neighbors Lawn Services의 전문가가 PNW(태평양 북서부) 환경에 최적화된 잔디 관리 방법을 실전 중심으로 설명했다. 특히 **Tehaleh 단지 특유의 빙하 퇴적 토양**과 **Country Green Turf Farms 잔디 혼합 품종**에 맞는 관리법을 상세히 다뤘다.

## 핵심 교훈 요약

| 주제    | 전문가 핵심 포인트                                                        |
| ----- | ----------------------------------------------------------------- |
| 잔디 품종 | Kentucky Bluegrass(두께·색상) + Rye(빠른 성장) + Fine Fescue(가뭄 저항) 3종 혼합 |
| 토양    | 빙하 퇴적지라 표토 2인치뿐 — 비료와 통기로 보완 필수                                   |
| 물 주기  | 아침에, 깊게(6~8인치 침투), 드물게 → 뿌리를 깊게 유도                                |
| 예초    | 봄/여름 2.5~3인치, 칼날 항상 날카롭게 유지                                       |
| 비료    | 연 6회, 질소(N) 중심, 겨울 전 칼륨(K) 강화                                     |
| 오버시딩  | Pre-emergent 후 8~10주 경과 후 가을에 실시                                  |
| 통기    | 연 1회 (가을 권장), Dethatching 선행 후 Aeration                           |
|       |                                                                   |
