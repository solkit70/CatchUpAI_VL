## Key Takeaways

| Topic | Expert Key Point |
|-------|-----------------|
| Grass blend | Kentucky Bluegrass (thickness/color) + Rye (fast growth) + Fine Fescue (drought resistance) 3-blend |
| Soil | Glacial deposit — only 2" topsoil — compensate with fertilizer and aeration |
| Watering | Morning, deep (6–8" penetration), infrequent → drives roots deeper |
| Mowing | Spring/Summer 2.5–3", always keep blade sharp |
| Fertilizer | 6x/year, nitrogen (N) focus, boost potassium (K) before winter |
| Overseeding | 8–10 weeks after pre-emergent, best in fall |
| Aeration | Once/year (fall recommended), dethatch first then aerate |
