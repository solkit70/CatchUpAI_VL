## 🌿 4 Key Lessons

**1. Prepare your lawn in spring — for the summer**
PNW summers (July–August) are dry and hard on cool-season grass. Build strong roots in spring with Pre-emergent + fertilizer before the heat hits.

**2. Pre-emergent first — but no overseeding for 8–10 weeks after**
After applying Pre-emergent, overseeding is not possible for 8–10 weeks. Spring = Pre-emergent first; overseeding waits until September.

**3. Brown lawn ≠ dead lawn (Dormancy)**
Cool-season grass goes dormant (turns brown) during PNW dry summers. The roots are still alive — they recover naturally when fall rains return.

**4. One Seasonal Adjust controls the whole season**
No need to change each station's run time manually. Use the Seasonal Adjust % to scale the entire system up or down with one setting.

## 📅 Annual Key Timing (Tehaleh WA)

| Season | Key Task |
|--------|---------|
| **Mid-March** | Apply Pre-emergent (weed prevention — golden window) |
| **March–April** | Spring fertilizer, restart sprinklers (Seasonal Adjust 70%) |
| **May–June** | Increase Seasonal Adjust to 80–90% |
| **July–August** | Peak summer watering (Seasonal Adjust 100–110%) |
| **September** | Overseeding (most important — once a year) |
| **October** | Fall fertilizer, leaf management |
| **November** | Sprinkler Winterizing |
