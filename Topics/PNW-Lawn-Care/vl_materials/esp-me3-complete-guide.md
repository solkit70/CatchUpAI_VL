# Rain Bird ESP-ME3 완전 가이드

**출처**: ESP-ME3 Advanced User Manual (18페이지)
**정리일**: 2026-03-03
**적용 모델**: ESP-ME3 (2-12 또는 4-22 스테이션 모듈식)

## 기기 사양

| 항목 | 사양 |
|------|------|
| 최대 스테이션 수 | 22개 (모듈 확장) |
| 프로그램 수 | 4개 (A, B, C, D) |
| 프로그램당 최대 Start Times | 6개 |

## 기본 프로그래밍 (4단계)

### 1단계: 날짜 및 시간 설정

1. 다이얼을 **Date/Time**으로 돌리기
2. 현재 날짜 입력 (월/일/년)
3. 현재 시간 입력 (12H 또는 24H 형식)

### 2단계: Start Time 설정

1. 다이얼을 **Start Times**으로 돌리기
2. 프로그램 버튼 선택 (A, B, C, D)
3. Start Time 1 입력 (예: 4:00 AM)
4. 추가 Start Time 필요 시 반복 (최대 6개)

> ⚠️ **가장 흔한 실수**: Start Time을 여러 개 설정하면 하루에 여러 번 물이 나옴
> - 1구역 30분짜리 하나만 필요한데 Start Time 3개 → 같은 프로그램이 3번 실행
> - 해결: Start Time 1개만 설정, 나머지는 OFF

### 3단계: Run Time(가동 시간) 설정

1. 다이얼을 **Run Times**으로 돌리기
2. 프로그램 선택 (A, B, C, D)
3. 각 스테이션별 가동 시간 입력 (분:초 단위)
4. 스테이션 0분 = 해당 스테이션 비활성화

### 4단계: 물 주는 날짜 설정

1. 다이얼을 **Water Days**으로 돌리기
2. 프로그램 선택
3. 원하는 요일 또는 날짜 패턴 선택:
   - **특정 요일**: Mon, Wed, Fri 등 개별 선택
   - **홀수/짝수 날**: Odd Days / Even Days
   - **주기적**: Cyclic Days (간격 설정)

## 고급 프로그래밍

### Seasonal Adjust (계절 조정)

1. 다이얼을 **Seasonal Adjust**으로 돌리기
2. 현재 % 표시 확인
3. ▲▼ 버튼으로 5% 단위 조정 (5%~200%)

**계절별 권장 설정 (Tehaleh WA 기준)**:

| 월 | Seasonal Adjust | 관수 빈도 |
|----|----------------|---------|
| 1-2월 | 0% (OFF) | — |
| 3월 | 0~50% | 필요 시 |
| 4월 | 50~80% | 주 1-2회 |
| 5월 | 80~100% | 주 2회 |
| 6월 | 100~120% | 주 3회 |
| 7월 | 130~150% | 격일~매일 |
| 8월 | 140~160% | 격일~매일 |
| 9월 | 100~120% | 주 2-3회 |
| 10월 | 60~80% | 주 1회 |
| 11월 | 0~30% | 거의 없음 |
| 12월 | 0% (OFF) | — |

---

### Odd/Even Days (홀수/짝수 날 물 주기)

1. 다이얼을 **Water Days**으로 돌리기
2. ▲▼ 버튼으로 **Odd** 또는 **Even** 선택
3. 주의: 31일 또는 1일 = 두 Odd Days가 연속될 수 있음

**활용 예**: 지역 물 절약 조례 대응 (짝수 날 vs 홀수 날 제한)

---

### Cyclic Days (주기 관수)

1. 다이얼을 **Water Days**으로 돌리기
2. ▲▼ 버튼으로 **CYCL** 선택
3. 간격 일수 입력 (예: 3 = 3일마다 한 번)

**활용 예**: 매 3일마다 관수 (요일 상관없이 균일한 간격)

---

### Delay Watering (물 주기 지연)

- **기능**: 최대 14일 동안 자동 관수 일시 중단
- **활용**: 비가 충분히 올 것 같을 때, 여행 중, 잔디 작업 중

1. 다이얼을 **Run Times**으로 돌리기 (또는 전용 버튼)
2. DELAY 옵션 선택
3. 지연 일수 입력 (1-14일)
4. 지연 기간 종료 후 자동 재개

---

### Permanent Days Off (특정 요일 영구 제외)

- **기능**: 매주 특정 요일은 절대 물 안 줌 (Seasonal Adjust와 별개)
- **활용**: 주말 물 주기 금지, 잔디 깎는 날 제외

1. 다이얼을 **Water Days**으로 돌리기
2. 프로그램 선택
3. 제외할 요일 선택 (OFF로 표시)

---

### Advanced Cycles — Cycle+Soak (순환+흡수)

**목적**: 급격한 관수 대신 짧게 여러 번 → 경사지 유출 방지, 흙 흡수 촉진

**설정 예시**:
- 기존: 스테이션 1 = 30분 연속
- Advanced Cycles: 10분 × 3사이클 (10분 물→15분 흡수→10분 물→15분 흡수→10분 물)

**설정 방법**:
1. 다이얼을 **Run Times**으로 돌리기
2. 프로그램 및 스테이션 선택
3. CYCLE 옵션에서 사이클 수 및 SOAK 시간 입력

---

## 수동 관수 (Manual Watering)

### 방법 1: 모든 스테이션 테스트 (Test All Stations)

1. 다이얼을 **Manual Watering**으로 돌리기
2. `Test All` 선택
3. 각 스테이션 가동 시간 설정 (예: 3분씩)
4. ▶ 버튼 눌러 시작
5. 순서대로 모든 스테이션 작동 확인

**활용**: 스프링클러 점검, 설치 후 확인

---

### 방법 2: 특정 스테이션 단독 실행

1. 다이얼을 **Manual Watering**으로 돌리기
2. 원하는 스테이션 번호 선택
3. 가동 시간 입력
4. ▶ 버튼 눌러 시작

---

### 방법 3: 특정 프로그램 실행

1. 다이얼을 **Manual Watering**으로 돌리기
2. 프로그램 선택 (A, B, C, D)
3. ▶ 버튼 눌러 시작

## 문제 해결 (Troubleshooting)

### LED 상태 해석

| LED 상태 | 의미 | 조치 |
|---------|------|------|
| 정상 숫자 | 정상 작동 | — |
| 깜박임 | 프로그래밍 오류 | 설정 재확인 |
| 고정 빨간 LED | 전기적 오류 | 배선 확인 |
| ALERT 표시 | 경고 | 경고 내용 읽기 |

### 프로그래밍 오류 (Blinking LED)

| 증상 | 원인 | 해결책 |
|------|------|--------|
| 물이 예상보다 자주 나옴 | Start Time 여러 개 설정 | Start Time 1개만 유지, 나머지 OFF |
| 특정 구역만 안 나옴 | Run Time = 0분 | 해당 스테이션 Run Time 재설정 |
| 아무것도 안 나옴 | Water Days 설정 없음 | Water Days 재설정 |
| 밤에 갑자기 작동 | Start Time 오전/오후 혼동 | AM/PM 재확인 |

### 전기적 오류 (Solid LED)

| 증상 | 원인 | 해결책 |
|------|------|--------|
| 특정 스테이션 작동 안 됨 | 솔레노이드 단선 또는 단락 | 밸브 배선 점검 |
| 여러 스테이션 오류 | 공통선(Common) 문제 | 공통선 연결 점검 |
| 컨트롤러 전원 불안정 | AC 전원 문제 | 콘센트/어댑터 확인 |

### Flow Alarm (플로우 경보) — 플로우 센서 있을 때

| 경보 | 의미 |
|------|------|
| High Flow | 파이프 파열 또는 밸브 고착 |
| Low Flow | 막힘, 압력 저하 |
| No Flow | 밸브 비작동, 단선 |

## 스프링클러 점검 체크리스트 (봄 시작 전)

- [ ] 컨트롤러 날짜/시간 확인
- [ ] Seasonal Adjust 봄 설정 (50~80%)으로 변경
- [ ] Test All Stations → 모든 구역 물 나오는지 확인
- [ ] 파손된 스프링클러 헤드 교체
- [ ] 로터리 헤드 방향 조정
- [ ] 드립 라인 막힘 점검
- [ ] Delay Watering 해제 (겨울 동안 설정했다면)

## 겨울 종료 (Winterizing) — 11월

1. 컨트롤러 Seasonal Adjust → 0% 또는 전원 OFF
2. 백플로우 방지장치 닫기
3. 에어 컴프레서로 배관 Blow Out (전문가 권장)
4. 컨트롤러 실내 보관 또는 커버
