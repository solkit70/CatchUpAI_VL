# M1: PNW 잔디 기초 + 봄 준비

**모듈**: M1 / 4
**상태**: ✅ 완료 (2026-03-03 ~ 2026-03-11)
**위치**: Tehaleh, WA (Pierce County, USDA Zone 8b)
**총 학습 시간**: ~5h

---

## 이 모듈에서 배운 것

### 핵심 교훈 1: PNW 잔디는 여름을 위해 봄에 준비한다
PNW의 7-8월은 비가 거의 없고 덥습니다. Cool-season 잔디는 이 시기에 스트레스를 받거나 휴면합니다. 봄(3-4월)에 뿌리를 강하게 만들어두는 것이 여름 생존의 열쇠입니다.

### 핵심 교훈 2: 봄 작업 순서가 중요하다
Pre-emergent 살포 → 비료 → (가을) Aerating → Overseeding
Pre-emergent 후에는 8-10주 Overseeding 불가!

### 핵심 교훈 3: 3월 지금이 골든 타임
- Pre-emergent: 토양 10°C 도달 전 = 지금!
- 봄 비료: 성장 시작 직전 = 지금!
- 마당 현황 파악: 봄 작업 전 = 지금!
