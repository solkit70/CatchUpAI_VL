# Cool-season 잔디 연간 생장 주기

**위치**: Tehaleh, WA (USDA Zone 8b)
**잔디 종류**: Cool-season (Tall Fescue / Perennial Ryegrass / Kentucky Bluegrass)
**작성일**: 2026-03-03

## 계절별 핵심 작업 상세

### 🌱 봄 (3-5월) — 가장 바쁜 시기

**3월 (지금!)**:
- [ ] Pre-emergent herbicide 살포 (토양 10°C 전)
- [ ] 첫 번째 비료 (고질소, Slow-release)
- [ ] 잔디 첫 깎기 (너무 짧게 말 것 — 7-8cm 유지)
- [ ] 마당 현황 조사 (얇은 곳, 잡초 위치 파악)
- [ ] Dethatching 필요 여부 확인

**4월**:
- [ ] Aerating (Core Aeration — 렌탈 필요)
- [ ] Overseeding (Pre-emergent 안 살포한 경우)
- [ ] 비료 2차 (필요 시)
- [ ] 스프링클러 가동 시작 (건조 오면)

**5월**:
- [ ] 깎기 빈도 늘리기 (주 1-2회)
- [ ] 스프링클러 주 2회 시작
- [ ] Seasonal Adjust 80~100% 설정

---

### ☀️ 여름 (6-8월) — 관수가 핵심

**6월**:
- [ ] Seasonal Adjust 100~120%
- [ ] 잡초 제거 (Post-emergent 사용 가능)
- [ ] 깎기 높이 높이기 (7-10cm) — 그늘 효과로 수분 보호

**7-8월 (가장 중요!)**:
- [ ] 관수 시간: **새벽 4-8시** (증발 최소화)
- [ ] 관수량: 주 1~1.5인치 목표
- [ ] 깊게 덜 자주 (일 10분보다 격일 25분이 더 좋음)
- [ ] 비료 금지 (Burn 위험)
- [ ] 갈색 변색 = 휴면 (정상) — 관수 중단하지 말 것

---

### 🍂 가을 (9-10월) — 두 번째 황금기

**9-10월 (Overseeding 최적 시기!)**:
- [ ] Core Aerating
- [ ] Overseeding (봄보다 더 권장 — 발아 후 긴 성장 기간)
- [ ] 가을 비료 (칼륨 높은 것 — 0-0-20 또는 24-0-11)
- [ ] 잡초 관리 (이 시기 잡초도 왕성)
- [ ] Seasonal Adjust 서서히 낮추기

---

### ❄️ 겨울 (11-12월) — 시스템 보호

**11월 (서리 전)**:
- [ ] 스프링클러 Winterizing (Blow Out)
- [ ] Rain Bird ESP-ME3 OFF 또는 Seasonal Adjust 0%
- [ ] 낙엽 제거 (잔디 위 쌓이면 썩음)

---

## 물 주기 골든 룰

1. **깊게, 드물게** — 10분씩 매일보다 30분씩 격일이 뿌리를 깊게 만듦
2. **새벽에 주기** — 4-8시 최적. 저녁 관수는 곰팡이 위험
3. **흙 확인** — 5cm 깊이 흙이 건조하면 관수 시기
4. **발자국 테스트** — 잔디 밟은 자국이 10분 후에도 남으면 수분 부족
