## 🚶 살포 단계별 가이드

### Step 1: Spreader 설정 (10분)

1. 포대 뒷면에서 본인 Spreader 브랜드 찾기
2. 해당 설정값으로 Spreader 조절판 맞추기
3. **처음엔 권장값보다 약간 낮게 설정** (과다 살포 방지)
4. 포대에서 알갱이를 Spreader에 붓기 (반 포대씩 나눠 붓는 것 추천)

---

### Step 2: 살포 경로 계획 (5분)

```
뒷마당 먼저, 앞마당 나중에 살포하는 순서 추천

뒷마당 살포 패턴:
┌─────────────────────────────┐
│ → → → → → → → → → → → →  │
│ ← ← ← ← ← ← ← ← ← ← ← ← │
│ → → → → → → → → → → → →  │
│ ← ← ← ← ← ← ← ← ← ← ← ← │
└─────────────────────────────┘
      (가로 방향으로 왔다갔다)

끝나면 90도 돌려서 세로 방향으로 한 번 더:
┌─────────────────────────────┐
│ ↓ ↑ ↓ ↑ ↓ ↑ ↓ ↑ ↓ ↑ ↓ ↑ │
└─────────────────────────────┘
      (가로 + 세로 교차 = 균일한 살포)
```

> **교차 살포(Cross Pattern)**: 가로로 한 번, 세로로 한 번 → 골고루 분산
> 단, 교차 살포 시 **Spreader 설정값을 반으로 줄여야 총량이 맞음**

---

### Step 3: 살포 실행 (30~45분)

**살포 시 주의사항:**

1. **일정한 속도**로 걷기 — 천천히 걸으면 과다 살포됨
2. **핸들 레버 잡은 채로 이동** — 레버 놓으면 살포 멈춤
3. **마당 가장자리**: EdgeGuard 기능 있으면 ON → 꽃밭/화단 방향 차단
4. **겹치지 않게**: Spreader 바퀴 폭만큼 옆으로 이동
5. **멈추지 않기**: 멈추면 한 곳에 과다 살포 → 잔디 탈 수 있음

**살포 순서:**
```
1. 뒷마당 외곽 테두리 한 바퀴 (경계선 먼저)
2. 뒷마당 내부 가로 방향 살포
3. (선택) 뒷마당 내부 세로 방향 살포 (설정값 반으로)
4. 앞마당 외곽 테두리
5. 앞마당 내부 살포
```

---

### Step 4: 살포 후 처리 (10분)

1. **물주기**: 살포 후 스프링클러로 **15~20분** 작동
   - Pre-emergent는 흙 속으로 스며들어야 효과 있음
   - 비가 오면 자연 관수 OK (단, 폭우는 유출 위험)
2. **Spreader 세척**: 물로 씻어 보관 (알갱이 남으면 금속 부식)
3. **손 씻기**: 비누로 충분히
4. **포대 보관**: 남은 제품은 밀봉 후 서늘한 곳 (차고 OK)

## ❓ 자주 하는 질문

**Q: 살포 후 잔디에 하얀 알갱이가 보여요. 정상인가요?**
A: 정상입니다. 물주기 후 흙 속으로 스며들면서 사라집니다.

**Q: 살포 후 아이나 반려동물이 마당에 들어가도 되나요?**
A: 물주기 후 잔디가 완전히 마르면 OK. 보통 24시간 후.

**Q: 앞마당은 도로와 접해있는데 가장자리는 어떻게 하나요?**
A: EdgeGuard 기능 ON → 도로/인도 방향으로는 살포 차단됨. 없으면 가장자리 2ft는 손으로 살포하거나 건너뜀.

**Q: 비가 살포 후 바로 오면요?**
A: 가벼운 비(0.5인치 이하)는 괜찮거나 오히려 좋음. 폭우(1인치 이상)면 유출 위험.

**Q: 효과는 얼마나 지속되나요?**
A: Scotts Halts 기준 **3~4개월** (6월 중순까지 대부분의 잡초 차단)
