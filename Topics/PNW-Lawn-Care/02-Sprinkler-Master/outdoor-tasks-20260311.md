## ⚠️ Task 0: 시스템 첫 가동 절차 — 반드시 먼저 (30분)

> **배경**: 2025년 10월 입주 후 5-6개월간 스프링클러 미사용 (겨울 내내 OFF 상태). 이번이 이 집에서 처음으로 스프링클러를 작동시키는 것이므로 순서를 반드시 지켜야 합니다. 무작정 컨트롤러부터 켜지 마세요 — 물 공급이 안 된 상태에서 스테이션을 돌리면 펌프 손상 위험이 있습니다.

### Step 0-A: 집 오리엔테이션 영상 확인 (실내, 5분)

- [ ] 집 구매 당시 오리엔테이션 영상 찾아서 재생
- [ ] 영상에서 "스프링클러 밸브" 또는 "irrigation valve" 관련 부분 찾기
- [ ] **어떤 밸브인지, 어디에 있는지** 메모
  - 밸브 위치: _________________________
  - 밸브 종류 (레버형/핸들형): _________________________
  - 열기 방향 (시계방향/반시계방향): _________________________

> 💡 일반적으로 Tehaleh 신축 주택의 스프링클러 메인 밸브는 **차고 내부** 또는 **유틸리티룸** 벽면, 또는 **집 외벽 하단 (backflow preventer 근처)** 에 있습니다.

---

### Step 0-B: 메인 밸브 위치 확인 및 열기 (실내+야외, 10분)

**찾아야 할 것**: 스프링클러 전용 수도 공급 밸브 (irrigation shutoff valve)

**보통 생긴 모양**:
- 레버형 (lever ball valve): 레버가 파이프와 **평행**이면 열림, **수직**이면 잠김
- 핸들형 (gate valve): **반시계방향**으로 끝까지 돌리면 열림

**절차**:
1. [ ] 차고 → 배관이 지나가는 벽면이나 바닥 근처 확인
2. [ ] 없으면 → 집 외벽에서 backflow preventer(역류방지장치) 찾기
   - 보통 집 외벽 낮은 위치, 검은색/구리색 파이프 연결된 금속 장치
   - 사진: `photos/backflow-preventer.jpg`로 촬영해두기
3. [ ] 밸브 확인: 현재 상태 → [ ] 열림 / [ ] 잠김
4. [ ] **잠겨있으면**: 천천히 열기 — **한 번에 다 열지 말고 1/4씩 조금씩 돌려가며** 개방
   - 이유: 갑자기 전체 개방 시 "water hammer"(수격현상)로 배관 손상 위험
   - 천천히 돌리면서 소음 없으면 정상
5. [ ] 전체 열고 나서 30초 대기 → 비정상적인 소리(쿵, 쉬-, 뚝뚝) 없는지 확인
6. [ ] 밸브 주변 바닥/벽 물기 확인 → 없으면 정상

**기록**:
- 밸브 위치: _________________________
- 밸브 종류: _________________________
- 개방 후 상태: [ ] 정상 / [ ] 이상 (___________________________)

---

### Step 0-C: 컨트롤러 전원 ON + 날짜/시간 확인 (실내, 5분)

1. [ ] 컨트롤러 다이얼이 **OFF** 위치인지 확인
2. [ ] 전원 연결 상태 확인 (플러그 꽂혀 있는지)
3. [ ] 다이얼을 **OFF → SET Date/Time** 위치로 돌려 날짜/시간 확인
   - 현재 날짜: _________ (맞으면 OK, 틀리면 수정)
   - 현재 시간: _________ (12시간 AM/PM 형식)
4. [ ] 날짜/시간이 맞으면 → 다이얼을 **AUTO** (또는 RUN) 위치로 돌리기

> ⚠️ **아직 자동 프로그램이 실행되면 안 됩니다.** AUTO로 놓으면 예약된 시간에 물이 나올 수 있으므로, 기존에 설정된 Start Time을 먼저 확인해야 합니다 (Task 2에서 확인).

---

### Step 0-D: 첫 번째 수동 1개 스테이션 테스트 (야외, 5분)

> 시스템 전체 테스트 전에 가장 가까운 스테이션 1개만 먼저 켜서 물이 정상적으로 나오는지 확인합니다.

1. [ ] 다이얼 → **Manual Watering** → **Test By Station**
2. [ ] 스테이션 1 선택 → **2분** 설정 → ▶ 버튼
3. [ ] 밖으로 나가서 확인:
   - [ ] 스프링클러 헤드에서 물이 나오는가?
   - [ ] 헤드가 완전히 팝업되어 올라오는가?
   - [ ] 물줄기가 정상적인가 (분무/회전 정상)
   - [ ] 헤드 주변 땅에서 물이 솟거나 새는 곳 없는가?
4. [ ] 2분 후 자동 정지 확인
5. [ ] **이상 없으면** → Task 1로 계속 진행
6. [ ] **이상 있으면 (물이 안 나옴)** → 확인 사항:
   - 밸브가 완전히 열렸는가?
   - 컨트롤러 LCD에 ERROR 메시지 있는가?
   - AI에게 증상 설명 후 다음 단계 안내 받기

**테스트 결과**: [ ] 정상 / [ ] 이상 → 이상 내용: _________________________

## Task 1: 잔디 면적 걸음 측정 (15분)

**목적**: 제품 구매량(Pre-emergent 등) 정확히 계산

**방법**: 1걸음 ≈ 2.5 피트, 면적 = 가로걸음 × 세로걸음 × 6.25

### 앞마당
1. [ ] 도로와 평행하게 가로로 걷기 → **_____ 걸음**
2. [ ] 도로에서 집 방향으로 세로로 걷기 → **_____ 걸음**
3. [ ] 멀치 베드/진입로 제외하고 잔디만 측정
4. [ ] 계산: _____ × _____ × 6.25 = **_____ sq ft**

### 뒷마당
1. [ ] 울타리 따라 가로로 걷기 → **_____ 걸음**
2. [ ] 울타리 따라 세로로 걷기 → **_____ 걸음**
3. [ ] 불규칙 모양이면 × 0.85 보정
4. [ ] 계산: _____ × _____ × 6.25 × 0.85 = **_____ sq ft**

### 최종 합계
- 앞마당: _________ sq ft
- 뒷마당: _________ sq ft
- **총 잔디 면적: _________ sq ft**

> 결과를 AI에게 알려주면 Pre-emergent 포대 수 최종 확인해 드립니다.
