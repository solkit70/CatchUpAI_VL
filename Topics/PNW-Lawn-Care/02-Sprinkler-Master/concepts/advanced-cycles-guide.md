# Advanced Cycles (Cycle+Soak) 가이드

**작성일**: 2026-03-11
**적용**: Tehaleh WA — 경사 있는 앞마당 구역

---

## Advanced Cycles란?

긴 관수 1회 → 짧은 관수 여러 번으로 분할.

```
기존 방식:  [====30분====]
Advanced:   [=10분=] 대기15분 [=10분=] 대기15분 [=10분=]
            (Cycle 1)          (Cycle 2)          (Cycle 3)
```

---

## 왜 필요한가?

| 문제 | 발생 상황 | 해결 |
|------|----------|------|
| 경사지 유출 | 앞마당처럼 완만한 경사 | Cycle+Soak |
| 점토질 토양 흡수 느림 | 신축지 다짐 토양 | Cycle+Soak |
| 물 웅덩이 생김 | 단시간 대량 관수 | Cycle+Soak |

**Tehaleh 신축지 특성**: 건설 시 토양 다짐 + 앞마당 경사 → Advanced Cycles 강력 권장

---

## 설정 방법

```
1. 다이얼 → Run Times
2. 프로그램 선택 (A)
3. 스테이션 번호 이동
4. Run Time 입력 후 CYCLE 옵션 선택
5. Cycle 횟수 입력 (예: 3)
6. Soak 시간 입력 (예: 15분)
```

---

## Tehaleh 앞마당 권장 설정

| 항목 | 값 |
|------|-----|
| 1 Cycle 관수 시간 | 10분 |
| Cycle 횟수 | 3회 |
| Soak(흡수 대기) 시간 | 15분 |
| 총 소요 시간 | 10×3 + 15×2 = **60분** |

> ⏰ Start Time을 설정할 때 총 소요 시간 고려 필요
> Program A 5:00 AM 시작 → 6:00 AM 완료

---

## 어느 구역에 적용할까?

| 구역 | Advanced Cycles 필요? | 이유 |
|------|----------------------|------|
| 앞마당 잔디 (경사) | ✅ **권장** | 완만한 경사 → 유출 위험 |
| 뒷마당 잔디 (평지) | 선택 사항 | 평지지만 신축 토양 다짐 |
| 멀치 베드 드립 | ❌ 불필요 | 드립은 이미 천천히 흡수 |

---

## 적용 전후 비교

**적용 전**:
- 앞마당 경사에서 물이 흘러내림
- 도로/보도로 유출
- 잔디 균일하게 물 안 받음

**적용 후**:
- 10분 관수 → 흙이 물 흡수
- 15분 대기 → 완전 흡수
- 다시 10분 → 더 깊이 침투
- 결과: 균일하고 깊은 관수
