# Seasonal Adjust 완전 가이드

**작성일**: 2026-03-11
**적용**: Tehaleh WA (USDA Zone 8b, Pierce County)

---

## Seasonal Adjust란?

기준 Run Time(100%)을 기준으로 계절에 따라 전체 관수 시간을 % 단위로 조정.

```
실제 관수 시간 = 설정 Run Time × (Seasonal Adjust %)

예시: Run Time 10분, Seasonal Adjust 70%
  → 실제 관수 = 10 × 0.70 = 7분
```

**장점**: 각 스테이션 Run Time을 일일이 바꾸지 않아도 됨 → 버튼 하나로 전체 조정

## 현재(3월) 권장 설정

```
Seasonal Adjust: 70%
Water Days: 월/수/금
Start Time: 5:00 AM
```

**근거**:
- 3월 Tehaleh 평균 강수량: 약 4인치/월 → 자연 강우로 상당 부분 충당
- 잔디 물 요구량: 주당 약 0.5인치
- 봄 잔디 성장 촉진을 위해 약간의 보조 관수 도움

## 계절 전환 체크포인트

| 시기 | 해야 할 일 |
|------|----------|
| **4월 초** | 70% → 90%로 올리기 |
| **5월 중** | 90% → 100%로 올리기, Water Days 주 3회로 |
| **6월 중** | 100% → 120%, 날씨 보며 조정 |
| **7월 초** | 130~140%, Water Days 격일로 |
| **8월** | 150~160%까지 올릴 수 있음 (폭염 시) |
| **9월 초** | 120% → 100%로 낮추기 |
| **10월 초** | 80% → 60%로 낮추기 |
| **11월 초** | Winterizing 시작 → 0% 또는 OFF |

## 조정 방법 (컨트롤러에서)

```
1. 다이얼 → Seasonal Adjust 위치
2. 현재 % 확인
3. ▲ 또는 ▼ 버튼으로 5% 단위 조정
4. 원하는 % 도달 시 자동 저장 (별도 저장 불필요)
```

---

## Seasonal Adjust vs. 개별 Run Time 조정

| 상황 | 방법 |
|------|------|
| 전체 구역 물량 일괄 변경 | **Seasonal Adjust** 사용 (간편) |
| 특정 구역만 조정 필요 | 해당 스테이션 **Run Time** 개별 변경 |
| 구역별 비율이 다를 때 | Run Time 기준값을 다르게 설정 후 Seasonal Adjust 사용 |

---

## 절수 팁

- **비 예보 시**: Delay Watering 1-3일 설정 → 불필요한 관수 방지
- **실제 강우 후**: 다음 Water Day 자동으로 건너뜀 (Rain Sensor 있을 경우)
- **7-8월 폭염**: Seasonal Adjust 높이는 것보다 Water Days를 늘리는 것이 효과적
