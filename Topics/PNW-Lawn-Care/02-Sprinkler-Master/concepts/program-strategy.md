# ESP-ME3 프로그램 분리 전략 (A/B/C/D)

**작성일**: 2026-03-11
**적용**: Tehaleh WA 내 마당

---

## 왜 프로그램을 나눠야 하는가?

잔디와 화단은 물 요구량이 다르다. 하나의 프로그램에 모두 넣으면:
- 잔디는 물이 부족하거나 화단은 과잉 공급
- 계절 조정(Seasonal Adjust) 시 모든 구역이 동일하게 변경

→ **식물 종류별로 프로그램 분리** = 구역별 최적 관수 가능

---

## 내 마당 프로그램 배정 전략

### Program A — 앞마당 잔디

| 항목 | 설정값 |
|------|--------|
| Start Time | 5:00 AM (1개만) |
| Water Days | 월/수/금 (봄 기준) |
| Run Time | 스테이션별 10-15분 |
| Seasonal Adjust | 봄 70% → 여름 140% |

**특징**: 이른 아침 관수 → 증발 최소화, 곰팡이 예방

---

### Program B — 뒷마당 잔디

| 항목 | 설정값 |
|------|--------|
| Start Time | 5:30 AM (1개만) |
| Water Days | 월/수/금 (봄 기준) |
| Run Time | 스테이션별 10-15분 |
| Seasonal Adjust | 봄 70% → 여름 130% |

**특징**: A 종료 직후 시작 → 물 압력 분산

> ⚠️ 앞/뒤를 동시에 돌리면 수압이 낮아져 커버리지 감소

---

### Program C — 멀치 베드 / 화단 드립

| 항목 | 설정값 |
|------|--------|
| Start Time | 7:00 AM (1개만) |
| Water Days | 화/목 (잔디보다 적게) |
| Run Time | 드립 구역 20-30분 |
| Seasonal Adjust | 잔디와 별도 조정 |

**특징**: 드립 관개는 천천히 오래 → 잔디와 분리 필수

---

### Program D — 예비 / 수동 테스트

| 항목 | 설정값 |
|------|--------|
| 용도 | 임시 필요 구역, 테스트 |
| 평상시 | OFF |

---

## 시작 시간 간격 설계

```
5:00 AM  → Program A (앞마당 잔디) 시작
           ↓ (A 종료 후 자동)
5:30 AM  → Program B (뒷마당 잔디) 시작
           ↓
7:00 AM  → Program C (화단/드립) 시작
           ↓ 완료
일출 전 전체 관수 완료 ✅
```

## Program A/B 상세 — 봄 스케줄 설계

### 봄(3-4월) 물 요구량
- 목표: 주당 0.5인치 (3월, PNW 강우 보조)
- 스프링클러 강수율: 약 0.5인치/시간 (회전 헤드 기준)
- → **주 2-3회, 구역당 6-10분** (강수율 확인 후 조정)

### 현재 추천 봄 설정

| 구분 | 설정 |
|------|------|
| Water Days | 월/수/금 (주 3회) |
| Run Time | 구역당 10분 (봄 기준) |
| Seasonal Adjust | 70% |
| Start Time | 5:00 AM |

> 실제 스테이션 수와 위치 확인 후 조정 필요 (야외 실습 후)

## 흔한 실수 & 해결책

| 실수 | 원인 | 해결 |
|------|------|------|
| 하루에 여러 번 물 나옴 | Start Time 여러 개 설정 | 1개만 남기고 나머지 OFF |
| 특정 구역만 안 나옴 | Run Time = 0분 | 해당 스테이션 시간 재설정 |
| 앞뒤마당 동시 작동 | A/B 같은 Start Time | A→B 순서로 시간차 배분 |
| 화단이 너무 자주 물 받음 | A와 같은 프로그램 | C 프로그램으로 분리 |

## 실측 면적 기반 프로그램 검증 (2026-03-15)

| Program | 구역 | 실측 면적 | 추정 스테이션 수 | 예상 총 소요 시간 |
|---------|------|---------|--------------|----------------|
| A | 앞마당 | **2,265 sq ft** | 2-3개 | 20-30분 |
| B | 뒷마당 | **6,448 sq ft** | 4-6개 | 40-60분 |
| C | 멀치 베드 | 별도 측정 필요 | 1-2개 | 20-40분 |

### 시작 시간 간격 검증

```
5:00 AM → Program A 시작 (앞마당 2,265 sq ft)
           ↓ 최대 30분 (3스테이션 × 10분)
5:30 AM → Program B 시작 가능 ✅ (A 종료 후 즉시)
           ↓ 최대 60분 (6스테이션 × 10분)
6:30 AM → Program B 완료 (일출 전후)
7:00 AM → Program C 시작 (멀치 베드)
```

> 뒷마당이 앞마당의 **2.8배** 면적 → 스테이션 수도 비례하여 더 많을 가능성 높음
> 야외 실습에서 실제 스테이션 수 확인 후 B의 시작 시간 재조정 필요
