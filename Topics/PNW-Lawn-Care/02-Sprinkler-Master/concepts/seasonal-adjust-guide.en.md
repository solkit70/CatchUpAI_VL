# Seasonal Adjust Complete Guide

**Created**: 2026-03-11
**Application**: Tehaleh WA (USDA Zone 8b, Pierce County)

---

## What Is Seasonal Adjust?

Adjusts total watering time by percentage based on the base Run Time (100%), varying by season.

```
Actual watering time = Set Run Time × (Seasonal Adjust %)

Example: Run Time 10 min, Seasonal Adjust 70%
  → Actual watering = 10 × 0.70 = 7 min
```

**Advantage**: No need to change each station's Run Time individually → adjust the whole system with one button

## Monthly Recommended Settings for Tehaleh WA

| Month | Season | Seasonal Adjust | Watering Days | Reason |
|-------|--------|----------------|---------------|--------|
| January | Winter | **0% (OFF)** | — | PNW wet season, irrigation not needed |
| February | Winter | **0% (OFF)** | — | Wet season continues |
| March | Early Spring | **50–70%** | 2–3x/week | Rain starting to decrease, supplemental watering |
| April | Spring | **70–90%** | 2–3x/week | Drying out is beginning |
| May | Late Spring | **90–100%** | 3x/week | Dry season beginning |
| June | Early Summer | **100–120%** | 3–4x/week | Entering PNW dry season |
| July | Midsummer | **130–150%** | Every other day–daily | Peak drought, grass stress |
| August | Midsummer | **140–160%** | Every other day–daily | Peak water demand of the year |
| September | Early Fall | **100–120%** | 2–3x/week | Temperatures starting to drop |
| October | Fall | **60–80%** | 1–2x/week | Rain starting again |
| November | Late Fall | **0–30%** | Minimal | Return of wet season, prep for Winterizing |
| December | Winter | **0% (OFF)** | — | Full wet season |

## Seasonal Transition Checkpoints

| Time | Action |
|------|--------|
| **Early April** | Raise 70% → 90% |
| **Mid-May** | Raise 90% → 100%, Water Days to 3x/week |
| **Mid-June** | 100% → 120%, adjust based on weather |
| **Early July** | 130–140%, Water Days to every other day |
| **August** | Can go up to 150–160% (during heat waves) |
| **Early September** | Lower 120% → 100% |
| **Early October** | Lower 80% → 60% |
| **Early November** | Start Winterizing → 0% or OFF |

## How to Adjust (on the Controller)

```
1. Dial → Seasonal Adjust position
2. Check current percentage
3. ▲ or ▼ buttons to adjust in 5% increments
4. Automatically saved when desired % is reached (no separate save needed)
```

---

## Seasonal Adjust vs. Individual Run Time Adjustment

| Situation | Method |
|-----------|--------|
| Change water amount for all zones at once | Use **Seasonal Adjust** (convenient) |
| Only one specific zone needs adjustment | Change that station's **Run Time** individually |
| Different ratios needed per zone | Set different base Run Time values, then use Seasonal Adjust |

---

## Water Conservation Tips

- **When rain is forecast**: Set Delay Watering 1–3 days → prevents unnecessary watering
- **After actual rainfall**: Next Water Day automatically skipped (if Rain Sensor is installed)
- **July–August heat waves**: Increasing Water Days is more effective than raising Seasonal Adjust
