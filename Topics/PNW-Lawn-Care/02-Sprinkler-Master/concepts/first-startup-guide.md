# 스프링클러 시스템 첫 가동 가이드

> 이 문서는 **겨울 후 처음으로 스프링클러를 켜는 상황**을 위한 가이드입니다.
> 입주 후 처음 사용하거나, 겨울 동안 OFF로 유지했다가 봄에 재가동할 때 참조하세요.

**작성 배경**: 2025년 10월 Tehaleh(WA) 입주 후 5-6개월 동안 스프링클러 미사용.
이 집에서 처음으로 스프링클러를 가동하는 절차를 기록합니다.

---

## 왜 순서가 중요한가?

스프링클러 시스템은 **물 공급 → 컨트롤러 → 밸브 → 헤드** 순서로 연결되어 있습니다.
이 순서를 무시하고 컨트롤러부터 켜면:
- 물이 없는 상태에서 솔레노이드 밸브 과열 가능성
- 재가동 시 갑작스러운 수압으로 배관·헤드 손상 ("water hammer")
- 문제 발생 시 원인 파악이 어려움

**반드시 아래 순서를 지키세요.**

---

## 사전 확인 — 오리엔테이션 영상 복습

집 구매 시 받은 오리엔테이션 영상을 먼저 확인합니다.

**확인 포인트**:
- 스프링클러 메인 밸브가 어디 있는가?
- 어떻게 열고 닫는가?
- 혹시 별도로 주의할 사항이 있는가?

> 영상에서 찾기 어려우면 "irrigation", "sprinkler", "valve" 키워드로 검색

---

## Step 1: 메인 수도 공급 밸브 찾기

### 일반적인 위치 (Tehaleh 신축 주택 기준)

| 위치 | 설명 |
|------|------|
| **차고 내부 벽면** | 수도관이 지나가는 벽 근처, 레버형 볼밸브 |
| **유틸리티룸/세탁실** | 메인 수도관 분기 지점 |
| **집 외벽 하단** | Backflow preventer(역류방지장치) 옆 또는 앞에 위치 |

### Backflow Preventer (역류방지장치)란?

집 외벽 낮은 곳에 있는 금속 장치로, 스프링클러 물이 가정용 수도로 역류하는 것을 막습니다.
WA주 법규상 대부분의 신축 주택에 설치 의무가 있습니다.

```
[집 외벽]
    |
[Backflow Preventer] ← 여기를 찾으세요
    |
[메인 밸브]
    |
[땅속 배관 → 각 스테이션 밸브 → 헤드]
```

**사진 촬영**: 찾은 backflow preventer를 `photos/backflow-preventer.jpg`로 저장

## Step 2: 메인 밸브 개방

### 밸브 종류별 열기 방법

**레버형 볼밸브 (Ball Valve)**:
- 레버가 파이프와 **평행** = 열림 (Open)
- 레버가 파이프와 **수직** = 잠김 (Closed)
- 조작: 레버를 파이프 방향으로 돌리기

**핸들형 게이트밸브 (Gate Valve)**:
- **반시계방향** (CCW)으로 돌리면 열림
- 끝까지 돌린 다음 1/4바퀴 되돌리는 것이 권장 (완전 열림 고착 방지)

### ⚠️ 안전하게 열기 — Water Hammer 방지

```
❌ 잘못된 방법: 한 번에 확 열기 → 배관 충격, 연결부 손상 위험
✅ 올바른 방법: 1/4씩 천천히 → 소리 없으면 조금씩 더 열기
```

**절차**:
1. 현재 밸브 위치 확인 (닫혀있으면 열기 방향 파악)
2. 1/4씩 천천히 열기
3. 10초 대기 → 소리 확인 (쾅, 쉬-, 뚝뚝 소리 없어야 정상)
4. 다시 1/4 열기 → 반복
5. 완전히 열린 후 1분 대기
6. 밸브 주변, 배관 연결부 누수 없는지 육안 확인

## Step 3: 컨트롤러 상태 확인 (실내)

### 전원 확인
1. ESP-ME3 플러그가 꽂혀있는지 확인
2. LCD 화면이 켜지는지 확인
3. `NO AC` 메시지가 없는지 확인 (있으면 전원 문제)

### 날짜/시간 확인 및 수정
```
다이얼 → SET Date/Time
▲▼ 버튼으로 수정 → 다음 항목 이동
```
- 겨울 동안 전원이 끊겼다면 날짜/시간이 초기화됐을 수 있음
- 내장 리튬 배터리로 약 10년 유지 → 정상이라면 맞아야 함

### 기존 프로그램 확인
다이얼 → RUN TIMES → Program A/B/C/D 확인
→ 시간이 이상하게 설정되어 있으면 나중에 수정

### AUTO 모드로 전환
- 다이얼 → **AUTO** (또는 RUN) 위치
- ⚠️ Start Time에 예약이 있으면 물이 나올 수 있음 → 오전 일찍이라면 OK, 밤이라면 주의

## Step 4: 첫 수동 테스트 (야외)

모든 스테이션을 한꺼번에 돌리기 전에, **스테이션 1개만 먼저** 확인합니다.

```
다이얼 → MANUAL WATERING → Test By Station
스테이션 1 → 2분 설정 → ▶ 버튼
```

**야외에서 확인할 사항**:
- [ ] 헤드가 팝업되어 올라오는가?
- [ ] 물이 정상적으로 분무/회전하는가?
- [ ] 헤드 주변에서 물이 새지 않는가?
- [ ] 배관 경로 주변 땅이 솟아오르거나 물이 고이지 않는가?

**첫 테스트 정상이면** → `outdoor-tasks-20260311.md` Task 1~4 진행

---

## Step 5: 이상 발생 시 트러블슈팅

### 물이 전혀 안 나올 때
1. 메인 밸브가 완전히 열렸는가? → 다시 확인
2. 컨트롤러 LCD에 에러 메시지 있는가?
3. Backflow preventer에 잠금장치나 레버가 잠긴 것 없는가?
4. 수도 메인 공급이 정상인가? → 실내 수도꼭지 확인

### 헤드 주변에서 물이 샐 때
- 헤드 연결부 O-ring 손상 가능성 → 그 스테이션만 기록, 나머지 계속 진행
- Rain Bird 호환 교체 헤드: Home Depot/Lowe's에서 구매 가능

### 배관에서 물 소리가 나지만 헤드가 안 올라올 때
- 헤드 막힘 (debris) → 헤드 청소 또는 교체

### 컨트롤러 LED가 빨간색 점멸할 때
- Programming 오류 또는 Flow Sensor 알람 → LCD 스크롤 메시지 읽기
- 단락(short) 감지 시: 해당 스테이션 배선 확인

## 정상 가동 확인 체크리스트

```
□ 집 오리엔테이션 영상 확인 완료
□ 메인 밸브 위치 파악 + 사진 촬영
□ Backflow preventer 위치 파악 + 사진 촬영
□ 메인 밸브 천천히 개방 완료 (누수 없음)
□ 컨트롤러 전원 ON + 날짜/시간 정상
□ 스테이션 1 수동 테스트 2분 → 정상 확인
□ 전체 스테이션 수동 테스트 시작 가능 상태
```

## 참고: 시즌 마감 시 (겨울 준비)

가을이 되면 반대 절차를 수행합니다:
1. 컨트롤러 다이얼 → OFF
2. 메인 밸브 잠그기
3. Blow-out (압축 공기로 배관 물 제거) → 전문업체 추천 ($80-150)
4. Backflow preventer에 단열재 감싸기 (PNW는 필수는 아니지만 권장)

> Tehaleh는 해발이 높아 겨울 기온이 낮습니다 (-4°C 이하 가능). Blow-out 권장.
