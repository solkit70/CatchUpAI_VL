## 봄 Run Time 계산 근거

### 기본 가정
- 스프링클러 헤드 타입: 회전 헤드 (Rotor) — 강수율 약 **0.5인치/시간**
- 봄 목표 관수량: 주당 **0.5인치** (3-4월 PNW 강우 보조)
- Seasonal Adjust: **70%** (3월 초봄 기준)

### Run Time 계산

```
목표: 주 3회 × 1회 관수 = 주당 0.5인치
→ 1회당 필요 관수량 = 0.5 ÷ 3 ≈ 0.17인치

강수율 0.5인치/시간 → 0.17인치 소요 시간 = 약 20분

Seasonal Adjust 70% 적용 전 기준 Run Time:
20분 ÷ 0.70 = 약 28분 → 반올림 30분

하지만 실제 적용:
- 처음 가동이므로 보수적으로 시작: 기준 Run Time = 10분
- Seasonal Adjust 70% 적용 → 실제 7분/스테이션
- 2-3주 후 잔디 상태 보고 Run Time 올리기
```

> **첫 가동 권장**: 10분/스테이션 × 70% = 실제 7분. 잔디 상태 확인 후 조정.
