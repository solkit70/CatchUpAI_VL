# 잔디 문제 진단 가이드 — PNW Zone 8b

**작성일**: 2026-04-05
**적용 환경**: Tehaleh, WA / Cool-season 잔디 / 0.3에이커

---

## 빠른 진단 흐름

```
갈색/황변 패치 발견
      ↓
균일한가?
  ├─ 균일 → 영양 부족 or 건조 (전체적)
  └─ 불균일 → 병해 or 스프링클러 문제 or 해충
        ↓
원형 패치인가?
  ├─ 원형 → 곰팡이 (Brown Patch / Dollar Spot)
  └─ 줄무늬/불규칙 → 커버리지 불균일
```

## 10가지 주요 문제 진단표

| # | 증상 | 예상 원인 | 진단 방법 | 해결책 | 처리 시기 |
|---|------|----------|----------|--------|----------|
| 1 | 원형 갈색 패치 (5~30cm) | Brown Patch 곰팡이 | 패치 경계 핑크/흰 균사 확인 | 살균제 + 저녁 관수 중단 | 여름 고온다습 |
| 2 | 동전 크기 갈색 원형 | Dollar Spot 곰팡이 | 잎에 모래시계 병반 확인 | 질소 시비 + 살균제 | 봄~여름 |
| 3 | 불규칙 갈색 줄무늬 | 스프링클러 커버리지 불균일 | Manual Run으로 커버 범위 확인 | 헤드 방향/높이 조정 | 언제든 |
| 4 | 전체 균일 황변 | 질소 부족 | 토양 테스트 (N 수치) | 질소 비료 시비 | 봄/가을 |
| 5 | 특정 구역 지속 황변 | 과다 관수 or 배수 불량 | 해당 구역 토양 과습 확인 | Run Time 축소, 배수 개선 | 여름 |
| 6 | 잔디 밀도 저하, 맨땅 | Thatch 과다 or 밀도 부족 | 잔디층 두께 측정 (1.25cm 초과 = 문제) | Dethatching + Overseeding | **가을** (8월 이후) |
| 7 | 이끼(Moss) 번성 | 그늘, 배수 불량, 산성 토양 | pH 측정 (6.0 이하 = 산성) | 석회 살포, 배수 개선, 가지치기 | 봄/가을 |
| 8 | 잔디 잎 흰 가루 | Powdery Mildew | 잎에 흰 분말 긁어봄 | 그늘 개선, 살균제 | 봄~초여름 |
| 9 | 불규칙 갈색 패치 + 잔디 들림 | 풍뎅이 유충 (Grubs) | 패치 아래 토양 뒤집어 유충 확인 | Grub 전용 살충제 | 늦여름~가을 |
| 10 | 잡초 급속 번식 | 잔디 밀도 부족 | 잡초 종류 식별 | 잡초별 Post-emergent 제초제 | 봄~여름 |

## 곰팡이 병해 심층 가이드

### Brown Patch
- **발생 조건**: 기온 25°C+, 습도 높음, 저녁 관수
- **외관**: 원형 갈색 패치, 경계부 진한 갈색 테두리
- **예방**: 새벽 관수, 질소 과다 시비 금지
- **치료**: Scotts DiseaseEx Lawn Fungicide

### Dollar Spot
- **발생 조건**: 질소 부족, 건조 + 고온 교대
- **외관**: 동전 크기 (5~8cm) 갈색 원형, 잎에 모래시계 무늬
- **예방**: 적절한 질소 시비, 과도한 건조 방지
- **치료**: 질소 시비 + 살균제

## Thatch 관리

**Thatch란?** 잔디 줄기, 뿌리, 잎이 쌓인 유기물층 (토양 표면과 잔디 사이)

| Thatch 두께 | 상태 | 대응 |
|------------|------|------|
| 0.5cm 이하 | 정상 (보습·보온 효과) | 유지 |
| 0.5~1.25cm | 주의 구간 | 관찰 |
| **1.25cm 초과** | **문제** | **Dethatching 필요** |

**내 마당 체크 방법**: 작은 흙삽으로 단면 확인 → 갈색층 두께 측정

**Dethatching 시기**: 가을 (9~10월) — Pre-emergent 효과 종료 후, 잔디 활발한 성장기

---

## Dormancy vs. Death 판별

| 구분 | 외관 | 테스트 | 회복 가능? |
|------|------|--------|-----------|
| **Dormancy (휴면)** | 균일한 갈색 | 잡아당기면 저항 있음 | ✅ 관수 재개 2~4주 |
| **Death (고사)** | 불균일 갈색, 패치 | 쉽게 뽑힘, 뿌리 없음 | ❌ Overseeding 필요 |

**PNW 여름**: 2주 이상 관수 중단 시 Dormancy 시작 → 정상 현상, 겁먹지 말 것

## 스프링클러 커버리지 문제 진단

줄무늬/불규칙 갈색이 보이면:
1. Manual Run 실행
2. 각 스테이션 작동 중 커버 범위 육안 확인
3. 헤드가 막히거나 방향이 틀어진 곳 찾기
4. 헤드 청소 or 방향 재조정

**흔한 원인**:
- 헤드 위로 잔디가 자라 가림
- 헤드 필터 막힘 (이물질)
- 헤드 낮아져 살수 각도 감소
