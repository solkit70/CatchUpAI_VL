## 즉시 실행 액션 3가지

1. **4/8~9 (수)**: 토양 수분 체크 → 건조 시 Manual Run 1회
2. **5월 초**: 다이얼 → AUTO + Seasonal Adjust 80% + Scotts Turf Builder 2차 시비
3. **8월 초**: Pre-emergent 효과 종료 확인 → Overseeding 준비 시작

- **Pre-emergent 시기**: 3월 중하순 ~ 4월 초 (토양 온도 10°C 이하, Crabgrass 발아 전)
- **Spring Startup**: 3월 중순 (마지막 서리 위험 이후)
- **Backflow 테스트**: 연 1회 Pierce County 의무 — 가을 Winterizing 시 함께 예약
- **연간 예산**: 약 $260~300 (비료 + 씨앗 + 전문 서비스)
