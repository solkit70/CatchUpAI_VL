# M4: 연간 계획 + Topic 마무리

**모듈**: M4 / 4
**상태**: ✅ 완료 (2026-04-05)
**위치**: Tehaleh, WA (Pierce County, USDA Zone 8b)
**총 학습 시간**: ~3h

---

## 이 모듈에서 배운 것

### 핵심 교훈 1: 잔디 관리는 연간 사이클로 생각해야 한다
봄 한 번 잘 했다고 끝이 아닙니다. 봄 → 여름 → 가을 → 겨울 준비까지 연간 흐름을 미리 캘린더로 잡아두면 중요한 타이밍을 놓치지 않습니다.

### 핵심 교훈 2: 가을이 봄만큼 중요하다
9월 Overseeding, 10월 가을 비료, 11월 Winterizing — 가을 작업이 다음 해 봄 잔디 품질을 결정합니다. 특히 Overseeding은 봄에 Pre-emergent를 쓰면 할 수 없으므로 가을이 유일한 기회입니다.

### 핵심 교훈 3: 스프링클러 Winterizing은 반드시 한다
PNW는 온화하지만 Tehaleh는 고도가 있어 첫 서리가 옵니다. 배관 내 물을 완전히 빼지 않으면 동파 위험이 있습니다. Blow-out 또는 자연 배수로 겨울 준비를 완료해야 합니다.
