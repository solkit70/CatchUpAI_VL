## Winterizing 절차 (Blow Out 방법)

### 사전 준비

- [ ] 컴프레서 준비 (CFM 20~25 이상 권장) — 또는 전문가 예약
- [ ] 보호 안경 착용 (압축 공기 위험)
- [ ] 컨트롤러 위치 확인

### Step 1 — 컨트롤러 설정

- [ ] ESP-ME3 다이얼 → **Manual Watering** 위치
- [ ] Start Station: Station 1로 설정
- [ ] 모든 프로그램 비활성화 확인

### Step 2 — 메인 워터 차단

- [ ] 메인 공급 밸브 잠금 (백플로우 방지기 앞)
- [ ] 잠금 후 누수 없는지 확인

### Step 3 — Blow Out 실행

- [ ] 컴프레서를 백플로우 방지기의 Blow Out 포트에 연결
- [ ] **Station 1 수동 가동** → 압축 공기로 배관 내 물 제거
- [ ] 물 대신 공기만 나올 때까지 (약 2~3분/스테이션)
- [ ] Station 2~8 순서대로 반복
- [ ] **주의**: 1개 스테이션씩, 과도한 압력 금지 (헤드 파손 위험)

### Step 4 — 마무리

- [ ] 컴프레서 분리
- [ ] 백플로우 방지기 양쪽 밸브 45° 잠금 (완전 잠금 X — 배관 팽창 여유)
- [ ] 백플로우 방지기 보온재 감기 (옵션 — 혹한 대비)
- [ ] ESP-ME3 다이얼 → **OFF**
- [ ] Seasonal Adjust → **0%** (이중 안전장치)

### Step 5 — 기록

- [ ] Winterizing 완료 날짜 기록: ___________
- [ ] 특이사항 기록 (누수, 파손 헤드 등): ___________

## 봄 재가동 (Spring Startup) 체크리스트

### 시기

| 기준 | 날짜 |
|------|------|
| 마지막 서리 위험 | 3월 중순 |
| **권장 재가동 시기** | **3월 중순 ~ 4월 초** |

### 절차

**Step 1 — 육안 점검**
- [ ] 배관 및 헤드 외관 확인 (겨울 피해 여부)
- [ ] 백플로우 방지기 상태 확인

**Step 2 — 메인 밸브 천천히 열기**
- [ ] 백플로우 방지기 앞 메인 밸브를 **1/4씩 천천히** 열기
- [ ] 급격히 열면 Water Hammer(수격 현상)로 배관 손상 위험
- [ ] 완전히 열 때까지 약 30초 소요

**Step 3 — 컨트롤러 재가동**
- [ ] ESP-ME3 다이얼 → **Date/Time** → 날짜/시간 확인 및 수정
- [ ] Seasonal Adjust → **70%** (봄 초기값)
- [ ] 다이얼 → **OFF** 유지 (아직 AUTO 전환 안 함)

**Step 4 — Station별 수동 테스트**
- [ ] 다이얼 → **Manual Watering**
- [ ] Station 1부터 순서대로 2분씩 가동
- [ ] 각 스테이션 정상 작동 여부 확인
- [ ] 파손된 헤드, 누수 지점 기록

**Step 5 — 문제 수리 후 스케줄 복원**
- [ ] 파손 헤드 교체 (필요 시)
- [ ] Program A/B/C 설정 재확인
- [ ] Water Days 확인
- [ ] 5월 초: 다이얼 → **AUTO** 전환
