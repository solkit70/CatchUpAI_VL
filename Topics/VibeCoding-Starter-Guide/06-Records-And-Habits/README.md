## M6 - 활용편② 기록·회고의 복리 + AI와 일하는 원칙

**모듈**: M6 / **상태**: ✅ 완료 (2026-08-10) / **예상 학습 시간**: 2.5시간

이 폴더는 가이드북 **6장(오래 잘 쓰는 법)**을 채운다. 5장이 "시작하고 계획 세우는 법"이라면, 6장은 **왜 쓸수록 좋아지는가**를 다룬다. 그리고 마지막에 격려와 현실을 함께 놓아 첫 실패에서 무너지지 않게 한다.

**참가자 기준 읽는 시간**: 12~15분

2. [02-working-with-ai.md](02-working-with-ai.md) — 네 가지 원칙(목표·계획 먼저·기록·질문) + 하지 말아야 할 것

## 이 모듈에서 정한 것

**"AI에게는 어제가 없다"로 열었다.** 기록의 필요성을 도덕적으로("기록은 좋은 습관입니다") 설득하면 안 한다. **기능적 이유**를 준다 — 안 쓰면 AI가 어제를 알 방법이 없고, 결국 매번 처음부터 설명하게 된다.

**"직접 쓰지 않아도 된다"를 명시했다.** WorkLog 6개 항목을 보면 부담스럽다. AI가 써 준다는 것, 실제로 할 일은 **"오늘 여기까지 했어요, 기록해 주세요"** 한마디라는 것을 문서 말미에 배치했다.

**격려를 실제 숫자로, 현실도 실제 숫자로.** 9.5시간/22개, 4.5h→4h→2~3h, 나흘 공백 — 전부 볼트 회고에서 조회한 실측치다. 잘 안 된 이야기도 마찬가지로 실제 기록에서 가져왔다(시간 예측 실패, 진입장벽 자기 지적, 크레딧 한도, 서식 축약, 회고 생략).

**Clearly 수치를 정확히 썼다.** "9.5시간 → 22개"는 맞지만 **영상 2편은 별도 약 8시간**이다. 이걸 뭉뚱그리면 과장이 되므로 ⚠️ 박스로 명시했다.

**"진입장벽" 자기 지적을 이 가이드의 존재 이유로 연결했다.** FedWay 회고에 "보조 자료가 있으면 확산에 도움이 될 것"이라 적혀 있는데, **이 가이드가 바로 그 보조 자료**다. 독자에게 "당신이 읽는 문서가 필요하다고 판단돼 만들어진 것"임을 알리는 대목이다.

**자기 평가 점수를 신뢰하지 말라고 적었다.** 볼트 회고들의 Self-Assessment는 대체로 4.7~5.0으로 후하다. 이걸 근거로 내세우면 정직하지 않으므로 "동기 부여용으로만 참고하라"고 밝혔다.

**"처음이 가장 오래 걸립니다"로 닫았다.** 그리고 "여러분은 그 처음을 이미 지나오셨습니다"로 이어 3~4장을 끝낸 독자를 확인시켜 준다.
