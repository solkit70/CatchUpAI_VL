## AI와 일하는 네 가지 원칙

지금까지 나온 이야기를 네 가지로 추립니다. **이것만 지켜도 대부분 잘 굴러갑니다.**

## 하나 — 목표를 정하고 알린 뒤 시작하세요

가장 흔한 실수는 **막연하게 시작하는 것**입니다. "AI 공부하고 싶어요"라고 하면 AI도 막연하게 답합니다.

시작하기 전에 스스로 이 셋만 정리해 보세요.

| 질문 | 예시 |
|---|---|
| **무엇을** 만들거나 알고 싶은가 | 5분짜리 발표 자료 |
| **왜** 필요한가 | 광복절 기념식에서 발표해야 해서 |
| **어디까지** 하면 끝인가 | 대본을 소리 내어 읽어 볼 수 있으면 |

셋 다 못 정하셔도 됩니다. **아는 것만 말씀하시면 AI가 나머지를 되물어 봅니다.**

## 둘 — 만들라고 하기 전에 계획부터 세우게 하세요

이건 여러 사람이 반복해서 강조하는 원칙입니다. 그만큼 중요하다는 뜻입니다.

> **AI에게 전체 앱을 만들어달라고 요청하는 것으로 시작하지 말고, 먼저 계획을 요청하라.**

왜냐하면 이렇습니다. "만들어 줘"라고 하면 AI는 바로 만들기 시작합니다. 그런데 그게 내가 원하던 게 아니면, 그때는 이미 많이 진행된 뒤입니다. **계획을 고치는 건 5분이지만 만든 걸 고치는 건 훨씬 오래 걸립니다.**

실제로 이렇게 말해 보세요.

```
이런 걸 만들고 싶어요. 먼저 계획부터 세워 주세요.
```

```
바로 고치지 말고, 어떻게 할 건지 먼저 알려 주세요.
```

**계획 모드(Plan mode)** 라는 기능도 있습니다. 파일을 바로 고치지 않고 계획만 세우는 모드입니다. 익숙해지시면 써 보세요.

## 셋 — 기록을 남기세요

앞 문서에서 다뤘습니다. 하루를 마칠 때 **"오늘 여기까지 했어요, 기록해 주세요"** 한마디면 됩니다.

특히 **막혔던 것**을 남기세요. 다음에 같은 데서 막히면 AI가 지난번 해결 방법을 알려 줍니다.

## 넷 — 모르면 물어보세요

AI가 만들어 준 것을 그냥 받기만 하면, 나중에 고칠 수도 판단할 수도 없게 됩니다.

이렇게 물어보는 습관을 들이시면 좋습니다.

```
이건 왜 이렇게 하신 건가요?
```

```
제가 나중에 이 부분을 고치려면 어디를 보면 되나요?
```

**개발자가 되실 필요는 없습니다.** 다만 AI를 이끌 수 있을 정도는 아셔야 합니다. 물어보는 것 자체가 그 힘을 기릅니다.

## 하지 말아야 할 것

저장소가 정리해 둔 목록입니다. 그대로 옮깁니다.

> 1. **완벽주의**
>    - 모든 디테일 암기 불필요
>    - AI에게 지시할 수 있으면 충분
>
> 2. **문서만 작성**
>    - 실습 없이 이론만 읽지 않기
>    - 반드시 직접 실행
>
> 3. **계획 없이 진행**
>    - daily_learning_prompt.md 건너뛰지 않기
>    - 무작정 시작하면 비효율적
>
> — VibeLearn AI 저장소, `GETTING_STARTED.md` 497~509행

여기에 실제로 자주 겪는 것 셋을 덧붙입니다.

**여러 가지를 동시에 시작하지 마세요.** Topic 여러 개를 한꺼번에 벌이면 어느 것도 안 끝납니다. 저장소도 "가능하지만 비권장"이라고 적어 두었습니다.

**회고를 건너뛰지 마세요.** 5분입니다. 이걸 빼면 내일 AI가 읽을 게 없습니다.

**웹 채팅만 쓰지 마세요.** 파일을 직접 읽고 쓰지 못하면 매번 복사해 붙여 넣어야 합니다. 우리가 VS Code에 AI를 붙인 이유가 이것입니다.

## 잘 안 될 때는 이렇게

**AI가 엉뚱한 걸 만들었어요**
그냥 말씀하시면 됩니다. "그게 아니라 이런 걸 원했어요"라고요. 고쳐 달라고 말하는 게 정상적인 사용법입니다.

**AI가 너무 어렵게 설명해요**
```
컴퓨터를 잘 모르는 사람도 이해할 수 있게 다시 설명해 주세요.
```

**오늘 도무지 진도가 안 나가요**
그대로 말씀하세요. "오늘 좀 피곤해요"라고 하면 AI가 난이도를 낮추고 분량을 줄여 줍니다. **무리해서 빼는 진도보다, 내일 다시 여는 게 낫습니다.**

**너무 많이 써서 잠시 못 쓴다고 나와요**
고장이 아닙니다. 요금제 한도입니다. 오늘 한 것을 기록해 두고 쉬시면 됩니다.

## 다음으로

원칙은 여기까지입니다. 마지막으로 **먼저 이 길을 걸어간 기록들**을 보여 드리겠습니다. 잘된 것과 잘 안 된 것을 함께요.
