## Claude 가입하고 Claude Code 설치하기

이제 VS Code에 **AI를 붙입니다.** 두 가지를 합니다.

첫째, **Claude** 계정을 만들고 유료 구독을 신청합니다. Claude는 사람 말로 대화하며 일을 시킬 수 있는 AI입니다.

둘째, VS Code에 **Claude Code**를 설치합니다. Claude Code는 Claude가 **내 컴퓨터의 폴더와 파일을 직접 읽고 쓸 수 있게** 해 주는 도구입니다. 이게 핵심입니다 — 웹사이트에서 대화만 주고받는 것과 달리, 실제로 내 파일을 만들고 고쳐 줍니다.

**걸리는 시간**: 20~30분
**비용**: 유료 구독이 필요합니다 (아래에서 설명)

## 먼저 — 비용 이야기를 정직하게

Claude Code를 쓰려면 **Claude 유료 구독**이 필요합니다. 무료로는 쓸 수 없습니다. 이 부분을 감추지 않고 먼저 말씀드립니다.

| 무엇 | 내용 |
|---|---|
| 왜 필요한가 | Claude Code가 내 파일을 읽고 쓰는 작업은 무료 범위를 넘어섭니다 |
| 어떻게 내나 | 매달 자동 결제되는 **구독** 방식입니다 (넷플릭스처럼) |
| 얼마인가 | 요금제가 여러 단계로 나뉘어 있고 **가격은 바뀔 수 있습니다.** 가입 화면에 표시된 현재 가격을 직접 확인하세요 |
| 처음엔 어떤 걸 | 가장 낮은 단계로 시작하셔도 됩니다. 부족하면 나중에 올릴 수 있습니다 |
| 그만두려면 | 언제든 해지할 수 있습니다. 해지해도 그달 남은 기간은 계속 쓸 수 있습니다 |

> 💡 **먼저 확인해 보세요** — 이미 Claude 유료 구독을 쓰고 계신 분도 있습니다. 회사나 학교에서 계정을 주는 경우도 있습니다. 결제하기 전에 한 번 확인해 보시면 좋습니다.

> ⚠️ **미성년 학생이라면** — 결제는 보호자와 함께 진행하세요. 카드 정보를 입력하는 단계가 있습니다.

## 1단계 — Claude 계정 만들기

① 인터넷 브라우저를 열고 주소창에 다음을 입력합니다.

```
https://claude.ai
```

② 화면에서 **Sign up**(가입) 을 누릅니다. 이미 계정이 있으시면 **Log in**(로그인)을 누르고 3단계로 건너뛰세요.

③ 이메일 주소를 넣거나, **Continue with Google**을 눌러 구글 계정으로 가입합니다.

> 💡 구글 계정으로 가입하는 편이 간단합니다. 비밀번호를 새로 만들지 않아도 됩니다.

④ 이메일로 가입하셨다면, 받은 편지함에 온 확인 메일에서 코드를 확인해 입력합니다.

⑤ 이름과 몇 가지 간단한 질문에 답하면 가입이 끝납니다.

> ✅ **이 화면이 보이면 성공** — Claude와 대화할 수 있는 화면이 열립니다. 가운데에 메시지를 입력하는 칸이 있습니다. 시험 삼아 "안녕하세요"라고 보내 보셔도 좋습니다.

## 2단계 — 유료 구독 신청하기

① Claude 화면 **왼쪽 아래**에서 내 이름이나 계정 아이콘을 누릅니다.

② **Upgrade**(업그레이드) 또는 **Plans**(요금제) 를 고릅니다.

③ 요금제 목록이 나옵니다. **가장 낮은 유료 단계**를 고르셔도 충분히 시작할 수 있습니다.

④ 카드 정보를 입력하고 결제합니다.

> ✅ **이 화면이 보이면 성공** — 결제가 끝나면 계정 메뉴에 현재 요금제 이름이 표시됩니다. 확인 메일도 옵니다.

> 💡 **얼마나 쓸 수 있나** — 요금제마다 하루·주 단위로 쓸 수 있는 양이 정해져 있습니다. 많이 쓰면 잠시 기다려야 할 때가 있습니다. **이건 고장이 아니라 정상입니다.** 시간이 지나면 다시 쓸 수 있습니다.

## 3단계 — VS Code에 Claude Code 설치하기

이제 VS Code로 돌아옵니다.

① VS Code를 엽니다.

② **왼쪽 세로 막대**에서 **네모 네 개가 모인 아이콘**을 누릅니다. 이게 확장(기능을 덧붙이는 추가 부품)을 설치하는 곳입니다. 마우스를 올리면 "Extensions"라고 뜹니다.

③ 위쪽 검색칸에 다음을 입력합니다.

```
Claude Code
```

④ 목록 맨 위에 **Claude Code**가 나옵니다. 만든 곳이 **Anthropic**인지 확인하세요. 비슷한 이름의 다른 확장이 있을 수 있습니다.

⑤ **Install**(설치) 버튼을 누릅니다. 몇 초에서 1분 정도 걸립니다.

> ✅ **이 화면이 보이면 성공** — Install 버튼이 사라지고 톱니바퀴 아이콘이나 "Uninstall"로 바뀝니다. 왼쪽 세로 막대에 Claude 아이콘이 새로 생깁니다.

## 4단계 — Claude Code에 로그인하기

① 왼쪽 세로 막대에서 새로 생긴 **Claude 아이콘**을 누릅니다.

② 로그인하라는 안내가 나옵니다. **Sign in**(로그인) 을 누릅니다.

③ 브라우저 창이 자동으로 열리면서 Claude 로그인 화면이 나옵니다. 1단계에서 만든 계정으로 로그인합니다.

④ "VS Code에서 열도록 허용하시겠습니까?" 같은 창이 뜨면 **허용**(Open, Allow)을 누릅니다.

⑤ VS Code로 자동으로 돌아옵니다.

> ✅ **이 화면이 보이면 성공** — VS Code 안 Claude 화면에 메시지를 입력할 수 있는 칸이 나타납니다. 로그인하라는 안내가 사라져 있습니다.

## 5단계 — 잘 붙었는지 확인하기 (2분)

가장 확실한 확인 방법은 **말을 걸어 보는 것**입니다.

① VS Code 안 Claude 입력칸에 다음을 그대로 입력하고 Enter를 누릅니다.

```
안녕하세요. 지금 제 컴퓨터에서 잘 작동하고 있나요? 한 문장으로 답해 주세요.
```

② 잠시 뒤 답이 돌아옵니다.

> ✅ **여기까지 됐으면 성공입니다.** AI가 VS Code 안에서 대답했다면, 설치와 로그인이 모두 제대로 된 것입니다.

## 여기까지 됐으면

AI가 VS Code 안에 들어왔습니다. 하지만 아직 **작업할 폴더**를 정해 주지 않았습니다. AI에게 "어느 서랍을 열어 보라"고 알려 주는 단계가 남았습니다.

## 잘 안 될 때

**Claude Code를 검색해도 안 나와요**
자주 있는 일입니다. VS Code를 완전히 닫았다가 다시 열어 보세요. 그래도 안 나오면 인터넷 연결을 확인해 주세요.

**로그인하려는데 브라우저가 안 열려요**
자주 있는 일입니다. VS Code 안에 주소(링크)가 함께 표시되는 경우가 많습니다. 그 주소를 복사해서 브라우저 주소창에 직접 붙여 넣으셔도 됩니다.

**로그인은 됐는데 "구독이 필요합니다"라고 나와요**
2단계 유료 구독이 아직 안 된 상태입니다. claude.ai에 로그인해 요금제를 확인해 주세요. 결제 직후라면 몇 분 뒤 다시 시도해 보세요.

**"사용량을 초과했습니다" 같은 안내가 나와요**
고장이 아닙니다. 요금제마다 정해진 사용량이 있어서 많이 쓰면 잠시 기다려야 합니다. 시간이 지나면 다시 쓸 수 있습니다.

더 많은 상황은 [막힐 때 보는 문서](04-troubleshooting.md)에 정리해 두었습니다.
