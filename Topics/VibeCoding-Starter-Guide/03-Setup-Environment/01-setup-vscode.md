## VS Code 설치하기

가장 먼저 **VS Code**를 설치합니다. VS Code는 마이크로소프트가 만든 무료 프로그램으로, 글과 파일을 쓰고 고치는 데 씁니다. 메모장의 훨씬 똑똑한 버전이라고 생각하시면 됩니다.

우리가 VS Code를 쓰는 이유는 하나입니다. **여기에 AI를 붙여서, AI가 내 컴퓨터의 파일을 직접 읽고 쓰게 하기 위해서**입니다. VS Code 자체를 배우실 필요는 없습니다. 열고, 폴더를 열고, AI에게 말을 거는 것까지만 하시면 됩니다.

**걸리는 시간**: 10~15분
**비용**: 무료

## 시작하기 전에 — 내 컴퓨터가 되는지 확인

| 내 컴퓨터 | 가능 여부 |
|---|---|
| Windows 노트북·데스크톱 | ✅ 가능 |
| 맥북·아이맥 (macOS) | ✅ 가능 |
| **크롬북 (Chromebook)** | ❌ **이 방법으로는 안 됩니다** |
| 아이패드·태블릿·휴대폰 | ❌ 안 됩니다 |

> 💡 **크롬북을 쓰신다면** — 크롬북에는 VS Code를 이 방법으로 설치할 수 없습니다. 진행자에게 미리 알려 주세요. 다른 컴퓨터를 준비하거나 별도 방법을 안내해 드립니다. 크롬북 화면 왼쪽 아래에 동그란 버튼이 있고 앱이 격자로 뜬다면 크롬북일 가능성이 높습니다.

## 1단계 — 내려받기

① 인터넷 브라우저(크롬, 엣지, 사파리 등)를 엽니다.

② 주소창에 다음을 입력하고 Enter를 누릅니다.

```
https://code.visualstudio.com
```

③ 화면 가운데에 있는 **파란색 Download 버튼**을 누릅니다.

버튼에는 보통 내 컴퓨터에 맞는 이름이 함께 적혀 있습니다. Windows를 쓰시면 "Download for Windows", 맥을 쓰시면 "Download for macOS"라고 보입니다. **그 버튼을 그대로 누르시면 됩니다** — 내 컴퓨터에 맞는 것을 사이트가 알아서 골라 줍니다.

> ✅ **이 화면이 보이면 성공** — 브라우저 아래쪽이나 오른쪽 위에 파일을 내려받는 중이라는 표시가 나타납니다. 다 받으면 파일 이름이 보입니다.

## 2단계 — 설치하기

### Windows를 쓰신다면

① 내려받은 파일을 **두 번 클릭**합니다. 파일 이름은 `VSCodeUserSetup-...exe` 처럼 생겼습니다.

② "이 앱이 디바이스를 변경하도록 허용하시겠어요?"라는 창이 뜨면 **예**를 누릅니다.

③ 사용 조건에 동의하는 화면이 나오면 **동의함**을 고르고 **다음**을 누릅니다.

④ 설치 위치를 묻는 화면은 **그대로 두고 다음**을 누릅니다. 바꾸지 않으셔도 됩니다.

⑤ 추가 작업을 고르는 화면이 나옵니다. 여기서 **"Code을(를) PATH에 추가"** 항목에 체크가 되어 있는지만 확인하시고, 나머지는 그대로 두셔도 됩니다.

⑥ **설치** 버튼을 누르고 기다립니다. 1~2분 걸립니다.

⑦ 다 되면 **종료** 또는 **Finish**를 누릅니다. "Visual Studio Code 실행"에 체크가 되어 있으면 VS Code가 바로 열립니다.

### 맥(macOS)을 쓰신다면

① 내려받은 파일을 **두 번 클릭**합니다. 압축이 풀리면서 **Visual Studio Code** 아이콘이 나타납니다.

② 그 아이콘을 **응용 프로그램(Applications) 폴더로 끌어다 놓습니다**. 이게 맥에서의 설치입니다.

③ 응용 프로그램 폴더에서 **Visual Studio Code**를 두 번 클릭해 엽니다.

④ "인터넷에서 다운로드한 응용 프로그램입니다. 열겠습니까?"라는 창이 뜨면 **열기**를 누릅니다. 처음 한 번만 나옵니다.

> ✅ **이 화면이 보이면 성공** — 짙은 색 배경의 창이 열리고, 가운데에 "시작(Get Started)" 같은 안내 화면이 보입니다. 왼쪽에는 아이콘들이 세로로 늘어선 막대가 있습니다.

## 3단계 — 화면 익히기 (2분)

지금은 딱 **두 곳만** 알아 두시면 됩니다. 나머지는 쓸 일이 없습니다.

**왼쪽 세로 막대** — 아이콘이 위아래로 늘어서 있습니다. 여기서 파일을 보거나, 확장(기능을 덧붙이는 추가 부품)을 설치합니다. 다음 문서에서 이 막대를 써서 Claude Code를 설치합니다.

**가운데 넓은 부분** — 파일을 열면 그 내용이 여기 보입니다. 지금은 안내 화면이 있을 겁니다.

한국어로 쓰고 싶으시면 이렇게 하시면 됩니다.

① 왼쪽 세로 막대에서 **네모 네 개가 모인 아이콘**(확장)을 누릅니다.
② 위쪽 검색칸에 `korean` 을 입력합니다.
③ **Korean Language Pack for Visual Studio Code**를 찾아 **Install**을 누릅니다.
④ 오른쪽 아래에 다시 시작하겠느냐는 안내가 뜨면 **Restart** 또는 **다시 시작**을 누릅니다.

> 💡 한국어로 바꾸지 않으셔도 됩니다. 이 가이드는 영어 화면 기준으로도 따라오실 수 있게 버튼 이름을 영어로 함께 적어 두었습니다.

## 잘 안 될 때

**내려받은 파일을 못 찾겠어요**
브라우저에서 `Ctrl + J`(맥은 `Command + J`)를 누르면 내려받은 파일 목록이 나옵니다. 거기서 가장 위에 있는 것을 누르시면 됩니다.

**"이 앱이 디바이스를 변경하도록 허용" 창이 안 뜨고 아무 일도 안 일어나요**
자주 있는 일입니다. 다른 창에 가려져 있는 경우가 많습니다. 작업 표시줄(화면 아래 막대)에 깜빡이는 아이콘이 있는지 보시고, 있으면 눌러 주세요.

**맥에서 "확인되지 않은 개발자" 라며 안 열려요**
자주 있는 일입니다. 아이콘을 **마우스 오른쪽 버튼으로 누르고 → 열기**를 고르시면 열립니다.

더 많은 상황은 [막힐 때 보는 문서](04-troubleshooting.md)에 정리해 두었습니다.
