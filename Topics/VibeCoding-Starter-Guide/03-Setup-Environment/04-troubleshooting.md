## 막힐 때 보는 문서

설치하다 보면 반드시 어딘가에서 한 번은 걸립니다. **이건 여러분이 뭘 잘못해서가 아닙니다.** 컴퓨터마다 상황이 달라서 누구에게나 일어나는 일입니다. 저희가 옆에서 도와 드릴 때도 아래 상황들은 거의 매번 나옵니다.

여기 있는 것들은 **고장이 아니라 "자주 있는 일"** 입니다. 하나씩 보시면 대부분 몇 분 안에 넘어갑니다.

## 가장 먼저 해 볼 것 세 가지

무엇이 막혔든, 아래 세 가지를 먼저 해 보시면 절반 이상은 해결됩니다.

**하나, VS Code를 완전히 닫았다가 다시 엽니다.** 창을 닫는 게 아니라 프로그램을 종료했다 다시 실행하는 것입니다. 설치 직후에는 이것만으로 되는 경우가 많습니다.

**둘, 인터넷 연결을 확인합니다.** 브라우저에서 아무 사이트나 열어 보시면 됩니다.

**셋, 잠시 기다렸다 다시 해 봅니다.** 서버가 잠깐 붐빌 때가 있습니다. 2~3분 뒤 다시 눌러 보세요.

## 설치할 때

### 내려받은 파일을 못 찾겠어요

브라우저에서 `Ctrl + J`(맥은 `Command + J`)를 누르면 내려받은 파일 목록이 나옵니다. 가장 위에 있는 것이 방금 받은 파일입니다.

### 설치 창이 안 뜨고 아무 일도 안 일어나요

다른 창에 가려져 있는 경우가 많습니다. 화면 아래 작업 표시줄에 **깜빡이는 아이콘**이 있는지 보시고, 있으면 눌러 주세요. 맥이라면 화면 아래 Dock에서 튀어오르는 아이콘을 확인하세요.

### 맥에서 "확인되지 않은 개발자"라며 안 열려요

애플이 처음 보는 프로그램에 대해 한 번씩 확인하는 절차입니다. 아이콘을 **마우스 오른쪽 버튼으로 누르고 → 열기**를 고르시면 열립니다. 처음 한 번만 이렇게 하시면 됩니다.

### "관리자 권한이 필요합니다"라고 나와요

회사나 학교 컴퓨터에서 자주 있는 일입니다. 그 컴퓨터에 프로그램을 설치할 권한이 막혀 있는 경우입니다. **개인 컴퓨터를 쓰시거나, 관리자에게 설치를 요청**하셔야 합니다. 이건 저희가 해결해 드릴 수 없는 부분이라 미리 확인이 필요합니다.

## Claude 가입·결제할 때

### 가입 확인 메일이 안 와요

**스팸함(정크 메일함)을 확인해 주세요.** 여기 들어가 있는 경우가 대부분입니다. 5분이 지나도 없으면 가입 화면에서 다시 보내기를 눌러 주세요.

### 결제를 했는데 여전히 무료 상태로 보여요

결제가 반영되기까지 몇 분 걸릴 수 있습니다. 잠시 뒤 claude.ai에서 **로그아웃했다 다시 로그인**해 보세요.

### 카드가 거절돼요

해외 결제가 막혀 있는 카드일 수 있습니다. 카드사 앱이나 고객센터에서 **해외 결제 허용**을 확인해 보세요. 다른 카드를 써 보시는 것도 방법입니다.

## Claude Code 설치·로그인할 때

### Claude Code를 검색해도 안 나와요

VS Code를 완전히 닫았다가 다시 열어 보세요. 그래도 안 나오면 인터넷 연결을 확인해 주세요. 검색칸에 `Claude Code`를 띄어쓰기까지 정확히 넣으셨는지도 한 번 보시면 좋습니다.

### 비슷한 이름이 여러 개 나와서 뭘 골라야 할지 모르겠어요

만든 곳이 **Anthropic**인 것을 고르시면 됩니다. 확장 이름 아래에 만든 곳 이름이 작게 적혀 있습니다.

### 로그인하려는데 브라우저가 안 열려요

VS Code 안에 주소(링크)가 함께 표시되는 경우가 많습니다. 그 주소를 복사해서 브라우저 주소창에 직접 붙여 넣으셔도 똑같이 됩니다.

### 브라우저에서 로그인은 했는데 VS Code로 안 돌아와요

브라우저에 "VS Code에서 열기" 같은 버튼이나 창이 떠 있는지 확인해 주세요. 있으면 **허용**을 눌러 주세요. 그래도 안 되면 VS Code를 닫았다 다시 열고 로그인을 한 번 더 해 보세요.

### "구독이 필요합니다"라고 나와요

유료 구독이 아직 반영되지 않은 상태입니다. claude.ai에서 요금제를 확인해 주세요. 결제 직후라면 몇 분 뒤 다시 시도해 보세요.

### "사용량을 초과했습니다"라고 나와요

**고장이 아닙니다.** 요금제마다 일정 시간 안에 쓸 수 있는 양이 정해져 있습니다. 많이 쓰면 잠시 기다려야 합니다. 시간이 지나면 다시 쓸 수 있습니다.

이럴 때는 쉬어 가시면 됩니다. 오늘 한 것을 기록해 두시면(WorkLog) 다음에 이어서 하기 쉽습니다.

## 폴더를 열고 작업할 때

### 폴더 열기를 눌렀는데 내 폴더를 못 찾겠어요

창 위쪽 주소 부분에서 **문서**(Documents)를 먼저 찾아 들어가시면 그 안에 있습니다. 만든 위치가 기억나지 않으시면, 폴더 이름(`my-ai-work`)으로 검색해 보셔도 됩니다.

### AI가 "폴더가 열려 있지 않습니다"라고 해요

폴더 열기가 안 된 상태입니다. VS Code **왼쪽 위에 폴더 이름이 보이는지**가 기준입니다. 안 보이면 File → Open Folder를 다시 해 주세요.

### AI가 파일을 만들었다는데 목록에 안 보여요

왼쪽 목록 위쪽의 **새로 고침 아이콘**(둥근 화살표)을 눌러 보세요. 그래도 안 보이면 VS Code를 닫았다 다시 열면 나타납니다.

### AI가 자꾸 허락을 물어봐요. 귀찮은데 안 물어보게 할 수 없나요

**물어보는 게 정상이고, 안전합니다.** AI가 내 파일을 고치기 전에 확인받는 절차입니다. 익숙해지시면 무엇을 하려는지 한눈에 보이고, 그때 허용하시면 됩니다.

처음에는 오히려 이 물어보는 단계가 **AI가 무슨 일을 하는지 배우는 기회**가 됩니다.

### 실수로 파일을 지웠거나 이상하게 바뀌었어요

당황하지 않으셔도 됩니다. AI에게 그대로 말씀하시면 됩니다.

```
방금 바꾼 내용을 되돌려 주세요.
```

VS Code에서 `Ctrl + Z`(맥은 `Command + Z`)를 눌러 되돌릴 수도 있습니다.

## 그래도 안 될 때

여기까지 해도 막히시면 **혼자 오래 붙들지 마세요.** 설치는 한 번만 넘으면 되는 문턱이고, 옆에서 5분 봐 드리면 끝나는 일이 대부분입니다.

도움을 요청하실 때 아래 세 가지를 함께 알려 주시면 훨씬 빨리 해결됩니다.

1. **어느 단계에서 막혔는지** (예: "Claude Code 로그인 단계")
2. **화면에 뭐라고 나오는지** — 화면을 사진으로 찍거나 캡처해 주시면 가장 좋습니다
3. **어떤 컴퓨터인지** (Windows / 맥 / 크롬북)

문의처는 **Catch Up AI**(https://catchupai.net/) 에서 확인하실 수 있습니다.

## 미리 알아 두면 좋은 것

**크롬북은 이 방법으로 안 됩니다.** 3장 맨 앞에서도 말씀드렸지만, 크롬북에는 VS Code를 이렇게 설치할 수 없습니다. 세션 전에 미리 확인해 주세요.

**회사·학교 컴퓨터는 설치가 막혀 있을 수 있습니다.** 개인 컴퓨터를 쓰시는 편이 마음 편합니다.

**인터넷이 필요합니다.** AI가 답을 만들 때마다 인터넷을 씁니다. 연결이 불안정하면 답이 느리거나 끊길 수 있습니다.
