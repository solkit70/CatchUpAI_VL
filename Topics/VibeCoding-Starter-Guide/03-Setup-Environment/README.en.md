## M3 - Setup Part 1: VS Code + Claude subscription + Claude Code

**Module**: M3 / **Status**: ✅ Complete (2026-08-10) / **Estimated time**: 2.5 hours

This folder fills guidebook **chapter 3 (Getting ready) and Appendix B (when you get stuck).** A participant must be able to finish the install alone using just these documents, and the order must also fit a facilitator guiding alongside.

**Total time for participants**: 40 min – 1 hour (install 15 min + signup/payment 30 min + folder 10 min)

2. [02-setup-claude.en.md](02-setup-claude.en.md) — Sign up for Claude → paid subscription → install the Claude Code extension → log in

## What this module decided

**State the cost honestly up front.** Claude Code needs a paid subscription. Hide that at the back and the reader feels betrayed halfway through. Instead of nailing down "how much," we tell them to **check the price on the signup screen** — prices change, and documents aren't updated that often.

**The Chromebook constraint is at the top of chapter 3.** Better to know before starting than to hit "it doesn't work" after 30 minutes.

**Each step ends with "you'll see this screen when it works."** Someone unused to computers can't easily judge "is it OK to move on?" We give a standard with something visible.

**At the end, we have the AI actually make a file.** More than the words "it's installed," `hello.md` appearing before your eyes is the sure verification — and at the same time it's the **first success experience.** This is also the moment the difference from web chat sinks in.

**"A common thing that happens," not "an error."** The when-you-get-stuck document sets its tone from the title. To someone unused to computers, "error" reads as "I did something wrong."
