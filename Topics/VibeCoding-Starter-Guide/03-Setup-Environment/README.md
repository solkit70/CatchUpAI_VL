## 이 모듈에서 정한 것

**비용을 맨 앞에서 정직하게 밝힌다.** Claude Code는 유료 구독이 있어야 쓸 수 있다. 이걸 뒤에 숨겨 두면 독자가 절반쯤 진행한 뒤 배신감을 느낀다. 대신 "얼마"를 못 박지 않고 **가입 화면에서 직접 확인하라**고 안내했다 — 가격은 바뀌고, 문서는 그만큼 자주 갱신되지 않는다.

**크롬북 제약을 3장 맨 앞에 뒀다.** 30분을 따라온 뒤 "안 됩니다"를 만나는 것보다, 시작 전에 아는 편이 훨씬 낫다.

**각 단계 끝에 "이 화면이 보이면 성공"을 붙였다.** 컴퓨터가 낯선 분은 "다음으로 넘어가도 되는지"를 스스로 판단하기 어렵다. 눈에 보이는 것으로 기준을 준다.

**마지막에 AI가 실제로 파일을 만들게 한다.** 설치가 됐다는 말보다 `hello.md`가 눈앞에 생기는 것이 확실한 검증이고, 동시에 **첫 성공 경험**이기도 하다. 웹사이트 대화와 무엇이 다른지도 이 순간에 이해된다.

**"에러" 대신 "자주 있는 일".** 막힘 대비 문서는 제목부터 톤을 정했다. 컴퓨터가 낯선 분에게 "에러"는 "내가 뭘 잘못했다"로 읽힌다.

## 막힘 대비 항목 (부록 B)

총 **18건**을 5개 구간으로 나눠 정리했다.

| 구간 | 건수 | 대표 항목 |
|---|---|---|
| 가장 먼저 해 볼 것 | 3 | VS Code 재시작, 인터넷 확인, 잠시 기다리기 |
| 설치할 때 | 4 | 내려받은 파일 못 찾음, 맥 "확인되지 않은 개발자", 관리자 권한 |
| 가입·결제할 때 | 3 | 확인 메일 안 옴, 결제 반영 지연, 해외 결제 거절 |
| Claude Code 설치·로그인 | 6 | 검색 안 됨, 브라우저 안 열림, 구독 미반영, 사용량 초과 |
| 폴더·작업할 때 | 5 | 폴더 못 찾음, 파일 목록에 안 보임, 실수로 지움 |
