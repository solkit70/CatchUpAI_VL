## 작업 폴더 만들고 열기

AI가 VS Code 안에 들어왔습니다. 이제 **어느 서랍에서 일할지** 알려 줄 차례입니다.

AI는 아무 폴더나 마음대로 뒤지지 않습니다. **내가 열어 준 폴더 안에서만** 파일을 읽고 씁니다. 그래서 작업 폴더를 정하는 일은 안전장치이기도 합니다.

**걸리는 시간**: 5~10분
**비용**: 무료

## 어디에 만들까

찾기 쉬운 곳이면 어디든 좋습니다. 아래 중 하나를 권합니다.

| 컴퓨터 | 권하는 위치 |
|---|---|
| Windows | `문서` 폴더 안 (`C:\Users\내이름\Documents`) |
| 맥(macOS) | `서류(Documents)` 폴더 안 |

> ⚠️ **바탕화면은 피하시는 게 좋습니다.** 파일이 늘어나면 화면이 어지러워지고, 실수로 지우기도 쉽습니다.

> ⚠️ **폴더 이름은 영어로** 지으시길 권합니다. 한글 이름도 대개 잘 되지만, 가끔 문제가 생기는 도구가 있습니다. 예: `my-ai-work`, `vibe-study`

## 1단계 — 폴더 만들기

### Windows를 쓰신다면

① 작업 표시줄에서 **파일 탐색기**(노란 서류철 모양 아이콘)를 엽니다.

② 왼쪽 목록에서 **문서**를 누릅니다.

③ 빈 곳에서 **마우스 오른쪽 버튼**을 누릅니다.

④ **새로 만들기 → 폴더**를 고릅니다.

⑤ 폴더 이름을 `my-ai-work` 라고 입력하고 Enter를 누릅니다.

### 맥(macOS)을 쓰신다면

① 화면 아래 **Finder**(파란 얼굴 모양 아이콘)를 엽니다.

② 왼쪽 목록에서 **서류(Documents)**를 누릅니다.

③ 빈 곳에서 **마우스 오른쪽 버튼**(또는 두 손가락 클릭)을 누릅니다.

④ **새로운 폴더**를 고릅니다.

⑤ 폴더 이름을 `my-ai-work` 라고 입력하고 Enter를 누릅니다.

> ✅ **이 화면이 보이면 성공** — 문서(서류) 폴더 안에 `my-ai-work` 라는 이름의 빈 폴더가 보입니다.

## 2단계 — VS Code에서 그 폴더 열기

① VS Code를 엽니다.

② 위쪽 메뉴에서 **File**(파일) → **Open Folder...**(폴더 열기) 를 고릅니다.

> 💡 한국어 화면이면 **파일 → 폴더 열기** 입니다. 맥에서는 **File → Open Folder...** 입니다.

③ 방금 만든 `my-ai-work` 폴더를 찾아 **한 번 눌러 선택**합니다. 폴더 안으로 들어가지 않아도 됩니다.

④ 오른쪽 아래 **폴더 선택**(Select Folder / Open) 버튼을 누릅니다.

⑤ "이 폴더에 있는 파일 작성자를 신뢰합니까?"라는 창이 뜰 수 있습니다. 내가 만든 폴더이므로 **예, 신뢰합니다**(Yes, I trust the authors) 를 누릅니다.

> ✅ **이 화면이 보이면 성공** — VS Code 왼쪽 위에 `MY-AI-WORK` 라는 폴더 이름이 보입니다. 그 아래는 아직 비어 있습니다. 파일이 하나도 없는 게 정상입니다.

## 3단계 — AI에게 폴더를 보게 하기 (2분)

이제 AI가 이 폴더를 보고 있는지 확인해 봅니다.

① 왼쪽 세로 막대에서 **Claude 아이콘**을 누릅니다.

② 입력칸에 다음을 그대로 입력하고 Enter를 누릅니다.

```
지금 열려 있는 폴더 이름이 무엇인가요? 그 안에 파일이 몇 개 있는지도 알려 주세요.
```

③ AI가 `my-ai-work` 라는 폴더 이름을 말하고, 파일이 없다고 답하면 제대로 연결된 것입니다.

> ✅ **여기까지 됐으면 성공입니다.** AI가 내 폴더를 볼 수 있는 상태가 됐습니다.

## 4단계 — 첫 파일 만들어 보기 (3분)

기왕이면 AI가 **파일을 만들 수도 있는지**까지 확인해 보겠습니다. 이게 웹사이트 대화와 결정적으로 다른 점입니다.

① Claude 입력칸에 다음을 입력합니다.

```
이 폴더에 hello.md 라는 파일을 만들고,
그 안에 "AI와 함께 하는 첫 걸음"이라고 한 줄 써 주세요.
```

② AI가 파일을 만들겠다고 하면서 **허락을 구할 수 있습니다.** 그러면 **허용**(Allow / Yes) 을 누릅니다.

③ 잠시 뒤 VS Code 왼쪽 목록에 `hello.md` 파일이 새로 나타납니다.

④ 그 파일을 눌러 열어 보면 방금 부탁한 문장이 적혀 있습니다.

> ✅ **여기까지 되셨다면 준비가 모두 끝났습니다.** AI가 내 컴퓨터에서 실제로 파일을 만들었습니다. 이제부터는 "무엇을 만들지"만 정하시면 됩니다.

> 💡 **허락을 구하는 이유** — AI는 파일을 만들거나 고치기 전에 대개 먼저 물어봅니다. 내가 모르는 사이에 무언가 바뀌지 않도록 하는 안전장치입니다. 겁내지 마시고, 무엇을 하려는지 읽어 보신 뒤 허용하시면 됩니다.

## 여기까지 됐으면 — 준비 완료

## 잘 안 될 때

**폴더 열기를 눌렀는데 내 폴더를 못 찾겠어요**
자주 있는 일입니다. 창 위쪽 주소 부분에서 **문서**(Documents)를 먼저 찾아 들어가시면 그 안에 있습니다.

**AI가 "폴더가 열려 있지 않습니다" 라고 해요**
폴더 열기가 안 된 상태입니다. 2단계를 다시 해 보세요. VS Code 왼쪽 위에 폴더 이름이 보이는지가 기준입니다.

**AI가 파일을 만들었다는데 왼쪽 목록에 안 보여요**
자주 있는 일입니다. 왼쪽 목록 위쪽의 **새로 고침** 아이콘(둥근 화살표)을 누르거나, VS Code를 닫았다 다시 열어 보세요.

더 많은 상황은 [막힐 때 보는 문서](04-troubleshooting.md)에 정리해 두었습니다.
