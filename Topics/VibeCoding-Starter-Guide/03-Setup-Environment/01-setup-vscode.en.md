## Installing VS Code

First, install **VS Code**. VS Code is a free program made by Microsoft for writing and editing text and files. Think of it as a much smarter version of Notepad.

We use VS Code for one reason: **to attach an AI to it so the AI can read and write the files on our computer directly.** You don't need to learn VS Code itself. Just opening it, opening a folder, and talking to the AI is enough.

**Time**: 10–15 minutes
**Cost**: Free

## Before you start — check that your computer works

| Your computer | Works? |
|---|---|
| Windows laptop/desktop | ✅ Yes |
| MacBook / iMac (macOS) | ✅ Yes |
| **Chromebook** | ❌ **Not with this method** |
| iPad / tablet / phone | ❌ No |

> 💡 **If you use a Chromebook** — VS Code can't be installed this way on a Chromebook. Tell your facilitator in advance. We'll prepare a different computer or a separate method. If there's a round button at the bottom-left of the screen and apps appear in a grid, it's likely a Chromebook.

## Step 1 — Download

① Open an internet browser (Chrome, Edge, Safari, etc.).

② Type this in the address bar and press Enter.

```
https://code.visualstudio.com
```

③ Press the **blue Download button** in the middle of the screen.

The button usually has the name matching your computer on it. On Windows it reads "Download for Windows," on a Mac "Download for macOS." **Just press that button** — the site picks the right one for your computer.

> ✅ **You'll know it worked** — a downloading indicator appears at the bottom or top-right of the browser. When it finishes, you'll see the file name.

## Step 2 — Install

### If you use Windows

① **Double-click** the downloaded file. Its name looks like `VSCodeUserSetup-...exe`.

② If a window asks "Do you want to allow this app to make changes to your device?" press **Yes**.

③ When the license agreement screen appears, choose **I accept** and press **Next**.

④ On the install-location screen, **leave it as is and press Next.** You don't need to change it.

⑤ An "additional tasks" screen appears. Just confirm that **"Add to PATH"** is checked; you can leave the rest as is.

⑥ Press **Install** and wait. It takes 1–2 minutes.

⑦ When it's done, press **Finish**. If "Launch Visual Studio Code" is checked, VS Code opens right away.

### If you use a Mac (macOS)

① **Double-click** the downloaded file. It unzips and a **Visual Studio Code** icon appears.

② **Drag that icon into the Applications folder.** That's installing it on a Mac.

③ In the Applications folder, double-click **Visual Studio Code** to open it.

④ If a window says "This application was downloaded from the internet. Are you sure you want to open it?" press **Open**. It only appears the first time.

> ✅ **You'll know it worked** — a dark-colored window opens with a "Get Started" screen in the middle. On the left there's a vertical bar of icons.

## Step 3 — Learn the screen (2 min)

For now, you only need to know **two places.** You won't need the rest.

**The vertical bar on the left** — icons stacked top to bottom. Here you view files or install extensions (add-on parts that give new features). In the next document we use this bar to install Claude Code.

**The wide area in the middle** — open a file and its contents show here. Right now there's a welcome screen.

If you'd like it in English (it already is) — this guide notes button names in English throughout, so you can follow along even on the English screen.

> 💡 You don't have to change the language. This guide is written so you can follow along regardless.

## When it doesn't work

**I can't find the downloaded file**
In the browser press `Ctrl + J` (Mac: `Command + J`) to see your downloads. The one at the top is the one you just got.

**The "allow this app to make changes" window doesn't appear and nothing happens**
This is a common thing. It's often hidden behind another window. Look for a flashing icon on the taskbar (the bar at the bottom) and click it.

**On a Mac it won't open, saying "unidentified developer"**
Common. **Right-click the icon → Open** and it opens.

More situations are collected in the [when-you-get-stuck document](04-troubleshooting.en.md).
