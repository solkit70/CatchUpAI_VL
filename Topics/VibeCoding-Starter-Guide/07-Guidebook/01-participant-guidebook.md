## 환영합니다

**코딩을 몰라도 괜찮습니다. 컴퓨터가 익숙하지 않아도 괜찮습니다.**

이 가이드는 AI와 함께 일하는 환경을 여러분 컴퓨터에 갖추고, 실제로 무언가 하나를 만들어 보는 데까지 데려다 드리기 위해 만들었습니다.

미국 유타주에 계신 60대 선생님 한 분도 이렇게 시작하셨습니다. 컴퓨터 세팅을 도와드렸더니, **단 며칠 만에 자신의 인생 이야기를 녹음하고 글로 정리해 책으로 만들어 주는 앱을 직접 만드셨습니다.** 특별한 재능이 있어서가 아니라, 그동안 한 분야에서 쌓아 오신 경험 자체가 이미 충분한 재료였기 때문입니다.

이 가이드는 **Catch Up AI**(https://catchupai.net/)에서 만들었습니다.

## 1장 — 이 가이드로 무엇을 하게 되나

끝까지 따라오시면 이렇게 됩니다.

| 무엇 | 결과 |
|---|---|
| 내 컴퓨터에 AI 작업 환경 | VS Code + Claude Code |
| AI가 내 파일을 읽고 씀 | 대화가 아니라 **파일로 남음** |
| 체계적으로 진행하는 방법 | VibeLearn AI |
| **내 손에서 나온 결과물 하나** | 첫 성공 |

**걸리는 시간**: 설치 40분~1시간, 첫 성공까지 30분 더
**드는 비용**: Claude 유료 구독 (3장에서 자세히)

세 분을 함께 모시고 있습니다.

- **학생** — 발표나 과제를 AI와 함께 준비합니다
- **오래 일해 오신 분** — 내 경험과 지식으로 만들고 싶은 것을 만듭니다
- **시민단체 실무자** — 흩어진 업무 자료를 정리하고 행사를 기획합니다

하시려는 일은 다르지만 **쓰는 도구와 방법은 같습니다.**

## 2장 — 바이브 코딩이 뭔가요

### 한 문장으로

**하고 싶은 일을 사람 말로 설명하면, 세부적인 것은 AI가 처리하는 방식입니다.** 여러분은 무엇을 만들지, 그게 맞는지를 결정합니다.

### 예전에는

무언가를 컴퓨터로 만들려면 둘이 필요했습니다. **무엇을 만들지 아는 것**(그 분야에서 오래 일한 사람이 가장 잘 압니다)과 **그걸 만드는 기술**(배우는 데 몇 년). 문제는 이 둘이 한 사람에게 잘 모이지 않았다는 것입니다.

### 지금은

두 번째가 크게 줄었습니다. 이렇게 말하면 AI가 만들어 줍니다.

```
동네 어르신들이 쓰실 건강 기록장을 만들고 싶어요.
글자가 크고, 버튼이 몇 개 없어야 해요.
```

**첫 번째, "무엇을 만들지 아는 것"은 여전히 사람의 몫입니다.** 그리고 그건 여러분이 이미 갖고 계신 것입니다.

### 그럼 AI가 다 해 주나요

아닙니다. **AI는 도깨비방망이가 아닙니다.** 계획 없이 기능만 계속 붙이면 나중에 고치기 어려워집니다. "한 번에 완성해 줘"보다 **"먼저 계획을 세우고 1단계부터"** 가 훨씬 낫습니다.

개발자가 되실 필요는 없지만, **AI를 이끌 수 있을 정도**는 아셔야 합니다. 이 가이드가 알려 드리려는 게 그 부분입니다.

### 코딩만이 아닙니다

우리가 설치할 도구는 **내 컴퓨터의 폴더와 파일을 직접 읽고 씁니다.** 그래서 파일로 하는 일이면 무엇이든 함께할 수 있습니다 — 자료 조사, 문서 작성, 파일 정리, 회의록, 발표 준비, 배우기, 만들기.

### 웹사이트에서 AI와 대화하는 것과 다릅니다

| | 웹사이트에서 대화 | 우리가 설치할 방식 |
|---|---|---|
| 결과물 | 대화창의 글 | **내 폴더의 파일** |
| 창을 닫으면 | 사라짐 | **남아 있음** |
| 이어서 하려면 | 처음부터 다시 설명 | **AI가 지난 파일을 읽음** |
| 쌓이면 | 안 쌓임 | **내 자료가 됨** |

### AI는 도구가 아니라 동료입니다

| 같은 상황 | 검색창처럼 쓰면 | 동료처럼 맡기면 |
|---|---|---|
| 발표 준비 | "광복절이 뭐야?" | "5분 발표를 준비하려고 해요. 대상은 중학생이고, 무엇부터 정하면 좋을까요?" |
| 자료가 흩어져 있을 때 | "정리 잘하는 법 알려 줘" | "이 폴더 파일들을 보고, 정해진 것과 미정인 것을 나눠 주세요" |
| 무언가 만들고 싶을 때 | "앱 만드는 법 알려 줘" | "이런 앱을 만들고 싶어요. 먼저 계획부터 세워 주세요" |
| 일이 끝났을 때 | (창을 닫는다) | "오늘 한 일을 기록해 주세요" |

**무엇을, 왜, 어디까지.** 이 셋을 알려 주는 것이 핵심입니다. 옆자리 동료에게 설명하듯 말씀하시면 됩니다.

### 왜 시작이 어려울까요

AI 때문에 빨라진 구간은 딱 한 구간입니다. **100마일 도로 중 5마일만 10차선으로 넓혀 놓은 상태**라고 보시면 됩니다. 그런데 그 넓은 구간에 **들어가는 진입로가 여전히 좁습니다.**

이 가이드는 그 좁은 진입로를 함께 지나가려고 만들었습니다. **한 번만 넘으면 됩니다.**

## 3장 — 준비하기

### 먼저 확인 — 내 컴퓨터가 되나요

| 내 컴퓨터 | 가능 |
|---|---|
| Windows 노트북·데스크톱 | ✅ |
| 맥북·아이맥 (macOS) | ✅ |
| **크롬북 (Chromebook)** | ❌ **이 방법으로는 안 됩니다** |
| 아이패드·태블릿·휴대폰 | ❌ |

> ⚠️ **크롬북을 쓰신다면** 진행자에게 미리 알려 주세요. 다른 컴퓨터를 준비하거나 별도 방법을 안내해 드립니다.

### 비용 이야기를 먼저

Claude Code를 쓰려면 **Claude 유료 구독**이 필요합니다. 무료로는 안 됩니다. 숨기지 않고 먼저 말씀드립니다.

| 항목 | 내용 |
|---|---|
| 어떻게 내나 | 매달 자동 결제되는 구독 (넷플릭스처럼) |
| 얼마인가 | 요금제가 여러 단계고 **가격은 바뀝니다.** 가입 화면의 현재 가격을 직접 확인하세요 |
| 처음엔 | **가장 낮은 단계로 시작**하셔도 됩니다 |
| 그만두려면 | 언제든 해지 가능 |

> 💡 **이미 구독 중이실 수도 있습니다.** 회사·학교에서 계정을 주는 경우도 있으니 결제 전에 확인해 보세요.
> ⚠️ **미성년 학생이라면** 보호자와 함께 진행하세요.

### 3-1. VS Code 설치 (10~15분, 무료)

VS Code는 글과 파일을 쓰고 고치는 무료 프로그램입니다. **VS Code 자체를 배우실 필요는 없습니다.**

1. 브라우저 주소창에 `https://code.visualstudio.com` 입력
2. 화면 가운데 **파란색 Download 버튼**을 누릅니다 (내 컴퓨터에 맞는 것을 사이트가 알아서 골라 줍니다)
3. **Windows**: 내려받은 파일을 두 번 클릭 → "허용" → 동의 → 다음 → **설치**
   **맥**: 파일을 두 번 클릭 → 나온 아이콘을 **응용 프로그램 폴더로 끌어다 놓기** → 두 번 클릭해 열기 → "열기"

> ✅ **성공 확인** — 짙은 색 배경 창이 열리고, 왼쪽에 아이콘이 세로로 늘어선 막대가 보입니다.

지금은 **두 곳만** 알면 됩니다. **왼쪽 세로 막대**(여기서 확장을 설치합니다)와 **가운데 넓은 부분**(파일 내용이 보입니다).

### 3-2. Claude 가입 + 유료 구독 (15~20분)

1. 브라우저에서 `https://claude.ai` 접속
2. **Sign up**(가입)을 누릅니다. **Continue with Google**로 하면 간단합니다
3. 가입 후 **왼쪽 아래 내 이름·계정 아이콘** → **Upgrade**(업그레이드) 또는 **Plans**(요금제)
4. **가장 낮은 유료 단계**를 고르고 결제

> ✅ **성공 확인** — 계정 메뉴에 현재 요금제 이름이 표시됩니다. 확인 메일도 옵니다.
> 💡 나중에 "사용량을 초과했습니다"가 나오면 **고장이 아닙니다.** 요금제 한도이니 시간이 지나면 다시 됩니다.

### 3-3. Claude Code 설치·로그인 (10분)

Claude Code는 Claude가 **내 컴퓨터의 파일을 직접 읽고 쓸 수 있게** 해 주는 도구입니다. 이게 핵심입니다.

1. VS Code를 엽니다
2. **왼쪽 세로 막대**에서 **네모 네 개가 모인 아이콘**을 누릅니다 (확장)
3. 검색칸에 `Claude Code` 입력
4. 만든 곳이 **Anthropic**인 것을 확인하고 **Install** 클릭
5. 왼쪽 막대에 새로 생긴 **Claude 아이콘** → **Sign in** → 브라우저에서 로그인 → **허용**

> ✅ **성공 확인** — VS Code 안 Claude 화면에 메시지 입력칸이 나타납니다.

### 3-4. 작업 폴더 만들고 열기 (10분)

AI는 **내가 열어 준 폴더 안에서만** 파일을 읽고 씁니다. 안전장치이기도 합니다.

1. **문서**(맥은 서류) 폴더 안에 `my-ai-work` 라는 폴더를 만듭니다
2. VS Code에서 **File**(파일) → **Open Folder...**(폴더 열기) → 그 폴더 선택
3. "작성자를 신뢰합니까?" 창이 뜨면 **예, 신뢰합니다**

> ✅ **성공 확인** — VS Code 왼쪽 위에 `MY-AI-WORK`가 보입니다. 안이 비어 있는 게 정상입니다.

### 3-5. 진짜 되는지 확인 (3분)

Claude 입력칸에 그대로 넣어 보세요.

```
이 폴더에 hello.md 라는 파일을 만들고,
그 안에 "AI와 함께 하는 첫 걸음"이라고 한 줄 써 주세요.
```

AI가 허락을 물으면 **허용**을 누릅니다. 잠시 뒤 왼쪽 목록에 `hello.md`가 나타납니다.

> ✅ **여기까지 되셨다면 준비가 끝났습니다.** AI가 내 컴퓨터에서 실제로 파일을 만들었습니다.
>
> 💡 **AI가 허락을 묻는 것은 안전장치입니다.** 내가 모르는 사이에 무언가 바뀌지 않게 하는 것이니, 무엇을 하려는지 읽어 보고 허용하시면 됩니다.

> 막히셨나요? → [막힐 때 보는 문서](../03-Setup-Environment/04-troubleshooting.md) (18가지 상황)

## 4장 — VibeLearn AI 설치하고 첫걸음

### 4-1. 내려받기 (10분, 무료)

VibeLearn AI는 프로그램이 아니라 **AI와 함께 체계적으로 배우는 방법**입니다. 실제로 받는 건 안내문 묶음(폴더 하나)입니다.

**안심하셔도 되는 것**: 프로그램 설치 ❌ · Git ❌ · Python ❌ · 명령어 입력 ❌ · **이 방법론 공부 ❌**

1. 브라우저에서 `https://github.com/solkit70/VibeLearn-AI` 접속
2. 오른쪽 위 **초록색 Code 버튼** → **Download ZIP**
3. 내려받은 파일 압축 풀기 → 폴더 이름 `VibeLearn-AI-main`에서 뒤의 `-main`을 지웁니다
4. 그 폴더를 **문서** 폴더 안에 둡니다
5. VS Code에서 **File → Open Folder...** 로 `VibeLearn-AI` 폴더를 엽니다

> ✅ **성공 확인** — 왼쪽 위에 `VIBELEARN-AI`가 보이고, 아래에 `README.md`, `templates` 등이 나타납니다.

폴더 안에 파일이 많지만 **하나도 열어 보지 않으셔도 됩니다.** `CLAUDE.md`가 AI에게 주는 안내문이고, **AI가 읽습니다.**

> 💡 글보다 영상이 편하시면: [VibeLearn AI 소개 영상](https://youtu.be/rbc-6b0woJU)

### 4-2. 첫 Topic 시작 — 한 문장이면 됩니다

Claude 입력칸에 **하고 싶은 것**을 적으시면 됩니다.

```
광복절 발표 준비를 공부하고 싶어요.
```
```
제 경험을 정리해서 보여 주는 웹페이지 만들기를 공부하고 싶어요.
```
```
우리 단체 행사 자료를 정리하는 방법을 공부하고 싶어요.
```

AI가 몇 가지를 물어봅니다. **아는 대로 답하시면 되고, 모르면 "잘 모르겠어요"라고 하셔도 됩니다.**

> 💡 답하기 번거로우면 **"선택형 질문으로 물어봐 주세요"** 라고 하시면 보기를 주고 고르게 해 줍니다.

이어서 AI가 **계획표(Roadmap)** 를 만들어 줍니다. 그런데 만들기 전에 **먼저 물어봅니다.**

> 1. 그대로 진행 / 2. 기간 조정 / 3. 범위 조정

**고장이 아니라 안전장치입니다.** 잘 모르겠으면 **"그대로 진행"** 을 고르세요.

### 4-3. 첫 성공 — 5분 안에 결과물 하나

셋 중 **하나만** 골라 해 보세요.

```
제 소개를 담은 웹페이지를 한 장 만들어 주세요.
이름은 [내 이름]이고, [내 관심사]를 소개하고 싶어요.
```
```
오늘 제가 할 일을 정리해 주세요. [할 일 세 가지]
중요한 순서대로, 얼마나 걸릴지 표로 만들어 주세요.
```
```
[궁금한 주제]에 대해 알아야 할 것을 쉽게 정리해서 파일로 저장해 주세요.
```

**마음에 안 들면 그냥 말하세요.** "색이 어두워요, 밝게 바꿔 주세요." **고쳐 달라고 말하는 것이 정상적인 사용법입니다.**

## 5장 — 제대로 쓰는 법

도구를 갖췄어도 **쓰는 방식이 예전 그대로면 아무것도 달라지지 않습니다.**

### 챗봇처럼 쓰면 무엇이 다른가

| | 챗봇처럼 쓰면 | VibeLearn AI 방식 |
|---|---|---|
| 어제 한 일 | AI가 모름 | **기록을 읽고 이어감** |
| 언제 끝나나 | 알 수 없음 | **DoD**(Definition of Done, 완료 기준)로 미리 정함 |
| 결과물 | 대화창의 글 | **파일로 남음** |
| 도구를 바꾸면 | 처음부터 | **그대로 이어짐** |

**챗봇식이 나쁜 게 아닙니다.** 한 번 묻고 끝날 일은 그냥 물어보는 게 빠릅니다. 다만 **여러 번에 걸쳐 만들어 갈 일**에는 Topic을 만드세요.

### 시작을 잘하는 세 가지

**하나 — 목표를 구체화하고 알린다.** 무엇을 / 누구에게 / 어디까지 / 언제까지. 아는 것만 적으셔도 훨씬 낫습니다.

**둘 — 이름은 알아볼 수 있게.** `광복절-발표-준비`(O) / `발표`(X). 공백 대신 하이픈.

**셋 — 목표는 "할 수 있다"로.** "광복절에 대해 잘 알게 된다"(X) → **"5분 발표 대본을 완성해 소리 내어 읽어 볼 수 있다"**(O)

### 계획표에서 확인할 것 세 가지

- [ ] **예상 시간**이 적혀 있다
- [ ] **DoD**(완료 기준)가 체크박스로 있다
- [ ] 목표가 **"할 수 있다"** 로 쓰여 있다

마음에 안 들면 그냥 말씀하세요. "단계가 너무 많아요, 절반으로 줄여 주세요."

### 두 번 물어보는 이유

계획표를 만들기 전에 한 번, 매일 시작할 때 한 번. **AI가 혼자 판단해서 일을 벌이지 않게 하려는 것**입니다. 계획을 고치는 건 5분이지만 만든 걸 고치는 건 훨씬 오래 걸립니다.

> 자세히: [5장 상세](../05-Using-VibeLearn/README.md)

## 6장 — 오래 잘 쓰는 법

### 기록이 AI의 연료입니다

AI는 대화가 끝나면 잊습니다. 그런데 VibeLearn AI로 일하면 AI가 어제를 압니다. **기억력이 좋아서가 아니라 어제 남긴 기록을 읽기 때문입니다.**

**직접 쓰지 않으셔도 됩니다.** 하루를 마칠 때 이 한마디면 됩니다.

```
오늘 여기까지 했어요. 기록해 주세요.
```

**특히 막혔던 것을 남기세요.** 다음에 같은 데서 막히면 AI가 지난번 해결 방법을 알려 줍니다.

### 실제로 이런 일이 있었습니다

**나흘 쉬어도 이어졌습니다.** 7월 19일에 멈추고 23일에 다시 열었는데, 기록이 있어서 어디서 이어야 할지 헤매지 않았습니다.

**갈수록 빨라집니다.** 같은 작업이 처음 4.5시간 → 두 번째 4시간 → 다음 예상 2~3시간으로 줄었습니다.

**처음이 가장 오래 걸립니다.** 이건 좋은 소식입니다.

### 왜 "나만의 기록"인가

누구나 검색할 수 있는 정보로 물으면 **남들과 비슷한 답**이 나옵니다. 그런데 내 기록을 주면 다릅니다.

> **기록이 AI를 강하게 만듭니다. 내 기록이 나만의 AI를 만듭니다.**

> 💡 [기록이 AI를 강하게 만든다 | Live #13 요약](https://youtu.be/eL2TOtFXJNI)

### 돌아보기는 5분

매일 하는 건 **5~10분짜리 하나뿐**입니다. 잘된 것 / 아쉬운 것 / 배운 것 / 내일 할 것. **"내일 할 것"이 내일 AI가 읽는 첫 줄이 됩니다.**

### AI와 일하는 네 가지 원칙

1. **목표를 정하고 알린 뒤 시작한다** — 무엇을·왜·어디까지
2. **만들라고 하기 전에 계획부터 세우게 한다**
3. **기록을 남긴다** — 특히 막혔던 것
4. **모르면 물어본다** — "이건 왜 이렇게 하신 건가요?"

### 하지 말아야 할 것

완벽주의(다 외우려 하기) · 읽기만 하고 안 해 보기 · 계획 없이 시작 · 여러 Topic 동시에 · 회고 건너뛰기 · 웹 채팅만 쓰기

### 정직하게 — 잘 안 된 것들

**시간 예측은 자주 틀립니다.** 대체로 넉넉하게 잡히지만, 여러 언어로 만들거나 배포하는 작업은 반대로 오래 걸렸습니다.

**도구 쓰는 법 자체가 장벽입니다.** 실제 기록에 이렇게 적혀 있습니다 — *"AI 에이전트 도구 사용법 자체를 먼저 익혀야 하는 진입장벽이 있을 수 있음. 보조 자료가 있으면 확산에 도움이 될 것."* **여러분이 읽고 계신 이 가이드가 바로 그 보조 자료입니다.**

**비용이 예상보다 빨리 나갈 수 있습니다.** 한도에 걸리는 건 고장이 아닙니다. 기록해 두고 쉬시면 됩니다.

**회고를 가장 먼저 빠뜨립니다.** 완벽하게 하려 하지 마세요. **5분짜리 하루 회고만이라도** 충분합니다.

### 숫자를 어떻게 볼까

**격려로 받아들이시되, 약속으로는 받아들이지 마세요.** 기록에 남은 사람들은 이미 도구에 익숙한 상태였습니다. 처음 하시는 분은 더 걸립니다. **그게 정상입니다.**

## 7장 — 다음 단계

여기까지 오셨습니다.

**도구는 갖추셨습니다.** VS Code, Claude, Claude Code, VibeLearn AI.
**방법도 아셨습니다.** 목표 정하기, 계획 먼저, 기록 남기기, 물어보기.
**남은 건 하나입니다.** 실제로 무언가를 시작하는 것.

### 다음에 이어서 하실 때

`VibeLearn-AI` 폴더를 VS Code에서 열고 이렇게 말씀하세요.

```
오늘 학습을 시작해 주세요.
```

AI가 계획표와 지난 기록을 읽고 **어디까지 했고 오늘 뭘 하면 되는지** 알려 줍니다.

### 혼자 가기 어려우실 때

**혼자 오래 붙들지 마세요.** 설치는 한 번만 넘으면 되는 문턱이고, 옆에서 5분 봐 드리면 끝나는 일이 대부분입니다.

도움을 요청하실 때 세 가지를 알려 주시면 훨씬 빠릅니다.

1. 어느 단계에서 막혔는지
2. 화면에 뭐라고 나오는지 (사진·캡처가 가장 좋습니다)
3. 어떤 컴퓨터인지 (Windows / 맥 / 크롬북)

AI를 실제 일에 붙여 쓰는 방법과 사례를 나누는 곳입니다. 가이드 프로그램 안내와 문의도 여기서 하실 수 있습니다.
