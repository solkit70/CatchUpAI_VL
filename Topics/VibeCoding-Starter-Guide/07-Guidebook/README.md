## M7 (Capstone) - 통합 가이드북 + 진행자용 매뉴얼

**모듈**: M7 / **상태**: ✅ 완료 (2026-08-10) / **예상 학습 시간**: 2시간

M1~M6의 산출물을 **배포 가능한 두 권**으로 묶는다. 이 폴더의 두 문서가 이 Topic의 최종 결과물이다.

## 📚 학습 순서

1. [01-participant-guidebook.md](01-participant-guidebook.md) — **참가자에게 그대로 보내는 문서.** 환영 → 개념 → 설치 → 첫 성공 → 활용 → 다음 단계까지 완결
2. [02-facilitator-manual.md](02-facilitator-manual.md) — **진행자용.** 세션 전 확인, 진행 순서와 시간 배분, 자주 나오는 질문, 저지르기 쉬운 실수

## 이 모듈에서 정한 것

### 압축 — 2,234줄 → 397줄

M2~M6 본문을 그대로 합치면 2,234줄이다. 그대로 두면 아무도 완독하지 못한다. **가이드북은 "끝까지 갈 수 있는 최소한"만 담고, 상세는 각 모듈 문서로 링크**했다.

| 장 | 원본 | 가이드북 | 처리 |
|---|---|---|---|
| 2장 개념 | 302줄 | ~70줄 | 핵심만. 사례는 표로 압축 |
| 3장 설치 | 530줄 | ~90줄 | **절차는 다 남김.** 설명·막힘대비를 덜어냄 |
| 4장 VibeLearn | 570줄 | ~60줄 | 절차 유지, 부록으로 분리 |
| 5장 제대로 쓰기 | 426줄 | ~55줄 | 표 중심으로 재구성 |
| 6장 오래 쓰기 | 406줄 | ~70줄 | 사례를 한 줄씩으로 |

**설치 절차(3·4장)는 압축하되 단계를 빼지 않았다.** 참가자가 이 문서 하나로 끝까지 갈 수 있어야 한다는 게 DoD다. 대신 각 단계의 배경 설명과 "잘 안 될 때"를 덜어내고 링크로 보냈다.

### 두 권으로 나눈 이유

**참가자용**은 "내가 무엇을 하면 되는가"만 담는다. **진행자용**은 "이 사람을 어떻게 데려갈 것인가"를 담는다. 둘을 한 문서에 두면 참가자가 자기와 상관없는 내용을 읽으며 헤맨다.

### 진행자 매뉴얼에서 새로 판단한 것

**크롬북 확인을 "일정 잡을 때 물어볼 것"으로 올렸다.** 세션 당일에 발견하면 그 세션이 통째로 날아간다. 학생 대상이면 크롬북 비율이 높아 특히 중요하다.

**"대신 해 주지 말라"를 실수 목록 첫째로.** 시간이 없다고 진행자가 키보드를 잡으면 참가자가 다음에 혼자 못 한다. 이 프로그램의 목적 자체가 무너진다.

**"자르는 순서"를 명시했다.** 시간이 밀리는 건 필연이다. 무엇을 줄일지 미리 정해 두지 않으면 진행자가 즉석에서 잘못 자른다. **`hello.md` 검증과 첫 성공은 절대 자르지 않는다** — 그게 없으면 참가자가 다시 열지 않는다.

**결제 단계에서 자리를 비켜 주라고 적었다.** 카드 정보를 입력하는 순간 옆에 붙어 있는 건 실례다.

**알려진 한계를 문서에 남겼다.** 설치 화면 문구 미검증, 설치 영상 없음, 이선생님 영상 없음, 막힘대비가 아직 실제 사례 기반이 아님. 진행자가 모르고 들어가면 현장에서 당황한다.
