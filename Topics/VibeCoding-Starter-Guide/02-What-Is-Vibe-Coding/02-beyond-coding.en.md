## It's not only coding

The name "vibe coding" makes it easy to think only of making apps or programs. **The actual range of use is far wider.**

The reason is simple. The tool we'll install can **read and write the folders and files on your own computer directly.** So anything you do with files, it can do alongside you.

## If it involves files, it works

| The task | With AI |
|---|---|
| Research | Gather from many places into one document |
| Writing | Draft it, you fix it, then refine again |
| Organizing files | Sort scattered files by topic and make a list |
| Meeting notes | Turn a recording or memo into readable form |
| Talk prep | Research → structure → script → slides |
| Learning | Set a plan, record progress, organize it |
| Making | Apps, web pages, automation |

**"Coding" is just one of these.** In fact, many people see results first in organizing files or writing documents, before ever making an app.

## Three people's stories

This guide seats three different people together. Each wants to do something different, but **the tool and the method are the same.**

### A student — preparing a talk

Say you've been given a 5-minute talk at a Liberation Day ceremony. You could ask like this:

```
I want to prepare a 5-minute talk for a Liberation Day ceremony.
I'll pick one independence activist and lay out what they did,
in a way even a middle schooler can understand.
```

The AI finds and organizes the material, structures the flow, and writes a script. **All of that stays as files.** When you continue next time, you don't have to explain from scratch again.

Why that matters is covered later. For now, just remember **"it stays as files, not a conversation."**

### An experienced person — with something to make

If you've worked in a field for decades, there's surely something you've thought "it'd be nice if this existed."

```
I want to organize the work I've done for 30 years
into a guide that someone starting similar work can read.
```

```
I want to make a health journal for the elderly folks in my neighborhood.
Large text, only a few buttons.
```

The Utah teacher from earlier is this case. **Not for lack of ideas, but for not knowing how to start** — that's why they hadn't done it.

### A civic-group worker — organizing work

Say you're preparing an event. The proposal, attendee list, budget, promo copy, and minutes are scattered across email and messengers.

```
I want to organize the materials for this event.
Make it show at a glance what's decided and what's still undecided.
```

There's an actual record of finishing exactly this kind of work in a single day. **This Liberation Day ceremony planning is that very case.**

## What they share — all three are the same method

On the surface the three tasks are completely different. Talk prep, app making, organizing materials.

But **the method is identical.**

1. Say what you want to do
2. The AI makes a plan, you check it
3. Proceed step by step, results stay as files
4. The records left behind become the material for the next task

That's why this guide doesn't make separate documents for the three. **Learn it once and all three work.**

## How is this different from chatting with AI on a website?

Good question. This is the crucial difference.

| | Chatting on a website | The way we'll install |
|---|---|---|
| Output | Text in a chat window | **Files in my folder** |
| When you close the window | Gone | **Still there** |
| To continue | Explain from scratch | **The AI reads the past files** |
| Organizing files | Can't | **Reads, writes, and moves them directly** |
| When it piles up | Nothing piles up | **It becomes your material** |

This doesn't mean website chat is bad. For simple questions it's faster.

But it doesn't fit **work you build up over many sittings.** You have to explain from scratch each time, and yesterday's work disappears.
