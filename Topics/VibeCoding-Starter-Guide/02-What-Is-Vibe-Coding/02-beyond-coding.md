## 코딩만이 아닙니다

"바이브 코딩"이라는 이름 때문에 앱이나 프로그램 만드는 것만 떠올리기 쉽습니다. **실제로 쓰이는 범위는 훨씬 넓습니다.**

이유는 간단합니다. 우리가 설치할 도구는 **내 컴퓨터의 폴더와 파일을 직접 읽고 쓸 수 있기** 때문입니다. 그러니까 파일로 하는 일이면 무엇이든 함께할 수 있습니다.

## 파일로 하는 일이면 다 됩니다

| 하는 일 | AI와 함께하면 |
|---|---|
| 자료 조사 | 여러 곳에서 모아 한 문서로 정리 |
| 문서 작성 | 초안을 만들고, 내가 고치고, 다시 다듬기 |
| 파일 정리 | 흩어진 파일을 주제별로 분류하고 목록 만들기 |
| 회의록 정리 | 녹취나 메모를 읽을 수 있는 형태로 |
| 발표 준비 | 자료 조사 → 구성 → 대본 → 슬라이드 |
| 배우기 | 계획을 세우고, 진도를 기록하고, 정리하기 |
| 만들기 | 앱, 웹페이지, 자동화 |

**"코딩"은 이 중 하나일 뿐입니다.** 오히려 많은 분들이 앱을 만들기 전에 자료 정리나 문서 작업에서 먼저 효과를 봅니다.

## 세 분의 이야기

이 가이드는 서로 다른 세 분을 함께 모시고 있습니다. 각자 하시려는 일이 다르지만, **쓰는 도구와 방법은 같습니다.**

### 학생 — 발표를 준비합니다

광복절 기념식에서 5분 발표를 맡았다고 해 보겠습니다. 이렇게 부탁하실 수 있습니다.

```
광복절 기념식에서 5분 동안 발표할 자료를 준비하고 싶어요.
독립운동가 한 분을 정해서, 그분이 어떤 일을 하셨는지
중학생도 이해할 수 있게 정리하려고 해요.
```

AI가 자료를 찾아 정리하고, 발표 흐름을 짜고, 대본을 만들어 줍니다. **그 과정이 전부 파일로 남습니다.** 다음에 이어서 할 때 처음부터 다시 설명하지 않아도 됩니다.

이게 왜 중요한지는 뒤에서 다시 다룹니다. 지금은 **"대화가 아니라 파일로 남는다"** 는 것만 기억해 두세요.

### 경력이 있는 분 — 만들고 싶은 것이 있습니다

수십 년 한 분야에서 일하셨다면, "이런 게 있으면 좋겠는데" 싶은 것이 반드시 있습니다.

```
제가 30년 동안 해 온 일을 정리해서,
비슷한 일을 시작하는 사람이 볼 수 있는 안내서를 만들고 싶어요.
```

```
동네 어르신들이 쓰실 건강 기록장을 만들고 싶어요.
글자가 크고 버튼이 몇 개 없어야 해요.
```

앞에서 말씀드린 유타주 선생님이 이 경우입니다. **아이디어가 없어서가 아니라, 시작하는 방법을 몰라서** 못 하고 계셨던 것입니다.

### 시민단체 실무자 — 업무를 정리합니다

행사 하나를 준비한다고 해 보겠습니다. 기획안, 참가자 명단, 예산, 홍보문, 회의록이 이메일과 메신저에 흩어져 있습니다.

```
이번 행사 관련 자료를 정리하고 싶어요.
어떤 게 정해졌고 어떤 게 아직 미정인지 한눈에 보이게 해 주세요.
```

실제로 이런 작업을 하루 만에 끝낸 기록이 있습니다. **이번 광복절 기념식 기획이 바로 그 사례**입니다.

## 공통점 — 셋 다 같은 방식입니다

세 가지 일은 겉으로 보면 전혀 다릅니다. 발표 준비, 앱 만들기, 자료 정리.

그런데 **하는 방식은 똑같습니다.**

1. 무엇을 하고 싶은지 말한다
2. AI가 계획을 세우고, 내가 확인한다
3. 하나씩 진행하고, 결과가 파일로 남는다
4. 남은 기록이 다음 작업의 재료가 된다

그래서 이 가이드는 세 분을 위한 문서를 따로 만들지 않았습니다. **한 번 익히면 셋 다 됩니다.**

## 웹사이트에서 AI와 대화하는 것과 뭐가 다른가요

좋은 질문입니다. 이게 가장 중요한 차이입니다.

| | 웹사이트에서 대화 | 우리가 설치할 방식 |
|---|---|---|
| 결과물 | 대화창의 글 | **내 폴더의 파일** |
| 창을 닫으면 | 사라짐 | **남아 있음** |
| 이어서 하려면 | 처음부터 다시 설명 | **AI가 지난 파일을 읽음** |
| 파일 정리 | 못 함 | **직접 읽고 쓰고 옮김** |
| 쌓이면 | 안 쌓임 | **내 자료가 됨** |

웹사이트 대화가 나쁘다는 뜻이 아닙니다. 간단한 질문에는 그게 더 빠릅니다.

다만 **여러 번에 걸쳐 무언가를 만들어 가는 일**에는 맞지 않습니다. 매번 처음부터 설명해야 하고, 어제 한 일이 사라지니까요.
