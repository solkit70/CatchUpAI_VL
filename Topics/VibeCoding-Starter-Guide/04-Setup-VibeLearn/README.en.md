## What this module decided

**We pulled contributor-only setup completely out of the body.** `install-hooks.ps1`, `pip install`, `ANTHROPIC_API_KEY` are for the people who fix and maintain this method, not the learner. The official guide too says "if you just download the templates you can skip it." Yet a first-timer who reads the repo instructions as-is gives up right there.

So we removed it from the body but **didn't erase it — moved it to Appendix D.** Because someone who meets those commands online and got anxious needs a place that answers "you don't have to do this."

**A "what you can relax about" table up front.** Program install ❌, Git ❌, Python ❌, commands ❌, studying the method ❌. Telling them **what they don't have to do** lowers the barrier more than telling them what to do.

**ZIP as default, Git optional.** Most don't know Git, and the result is the same. We nailed down "if you don't know what Git is, use Method A."

**We explained the approval gate as "a safeguard, not a malfunction."** The AI asking before confirming a plan is core to this system, but it can read as "why is it asking instead of doing." We framed it as a reassurance point.

**We prepared first success in three branches.** Intro web page / today's to-dos / organizing a curiosity — so each reader tier (student, senior, worker) can pick what resonates.

**We stated that "saying please fix it is the normal way to use this."** Take not getting it right the first try as failure and you stop there.
