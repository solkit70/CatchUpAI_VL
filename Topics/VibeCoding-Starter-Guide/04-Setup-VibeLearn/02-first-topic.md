## 첫 Topic 시작하기

이제 가장 놀라운 부분입니다. **한 문장이면 시작됩니다.**

VibeLearn AI를 공부하실 필요가 없습니다. 방법론 이름도, 폴더 구조도, 규칙도 외우지 않으셔도 됩니다. **무엇을 하고 싶은지 말씀하시면 AI가 나머지를 처리합니다.**

**걸리는 시간**: 15~20분
**준비물**: 앞에서 연 `VibeLearn-AI` 폴더

## 1단계 — 한 문장 말하기

왼쪽 세로 막대에서 **Claude 아이콘**을 누르고, 입력칸에 **하고 싶은 것**을 적으시면 됩니다.

형식은 이렇습니다.

```
○○을 공부하고 싶어요.
```

정말 이게 전부입니다. 아래는 예시입니다. **자신에게 해당하는 것을 골라 그대로 써 보세요.**

**학생이라면**

```
광복절 발표 준비를 공부하고 싶어요.
```

**만들고 싶은 것이 있는 분이라면**

```
제 경험을 정리해서 보여 주는 웹페이지 만들기를 공부하고 싶어요.
```

**업무에 쓰고 싶은 분이라면**

```
우리 단체 행사 자료를 정리하는 방법을 공부하고 싶어요.
```

> 💡 **"공부"라는 말이 어색하시다면** — 꼭 학교 공부가 아닙니다. 만들기, 정리하기, 알아보기 전부 됩니다. "~을 해 보고 싶어요"라고 하셔도 AI가 알아듣습니다.

## 2단계 — AI의 질문에 답하기

AI가 몇 가지를 물어봅니다. 어렵게 생각하지 마시고 아는 대로 답하시면 됩니다. 모르면 "잘 모르겠어요"라고 하셔도 됩니다 — AI가 예시를 들어 다시 물어봅니다.

보통 이런 것들을 묻습니다.

| AI가 묻는 것 | 어떻게 답하면 되나 |
|---|---|
| 무엇을 만들거나 알고 싶은지 | 최대한 구체적으로. "발표 자료"보다 "광복절 기념식에서 5분간 발표할 자료" |
| 얼마나 걸릴 것 같은지 | 아는 대로. "3일", "일주일", "잘 모르겠어요" 전부 괜찮습니다 |
| 어떤 컴퓨터를 쓰는지 | Windows / 맥 |
| 미리 아는 것이 있는지 | 없으면 "없어요"라고 하시면 됩니다 |

> 💡 **더 편한 방법** — 질문에 답하기가 번거로우시면 이렇게 부탁해 보세요.
>
> ```
> 선택형 질문(고르기 방식)으로 하나씩 물어봐 주세요.
> ```
>
> 그러면 AI가 보기를 주고 고르게 해 줍니다.

> ✅ **여기까지 됐으면** — AI가 여러분의 답을 정리해서 보여 주고, 이 내용으로 진행해도 되는지 확인합니다.

## 3단계 — 폴더가 만들어지는 것 보기

AI가 폴더를 만들겠다고 하면 **허용**하세요. 잠시 뒤 왼쪽 목록에 이런 것이 생깁니다.

```
Topics/
└── 내가-정한-주제-이름/
    ├── topic_info.md      ← 내가 뭘 하려는지 정리한 것
    ├── vl_prompts/        ← AI가 쓸 안내문
    ├── vl_roadmap/        ← 전체 계획표가 여기 생깁니다
    ├── vl_worklog/        ← 매일의 기록이 여기 쌓입니다
    └── vl_materials/      ← 참고 자료를 넣어 두는 곳
```

**앞에 `vl_`이 붙은 폴더**는 VibeLearn AI가 쓰는 자리입니다. 여러분이 직접 관리하지 않으셔도 됩니다.

> ✅ **이 화면이 보이면 성공** — `Topics` 폴더 안에 내 주제 이름으로 된 폴더가 생겼습니다.

## 4단계 — 계획표(Roadmap) 받기

이어서 AI가 **전체 계획표**를 만들어 줍니다. 이걸 **Roadmap(로드맵)** 이라고 부릅니다. 어떤 순서로 무엇을 할지 단계별로 나눈 표입니다.

여기서 **중요한 일이 벌어집니다.** AI가 계획표를 바로 만들지 않고 **먼저 물어봅니다.**

> "말씀하신 기간이 이 주제에 적당한지 살펴봤습니다. 어떻게 하시겠어요?"
> 1. 그대로 진행
> 2. 기간 조정
> 3. 범위 조정

**이건 고장이 아니라 안전장치입니다.** AI가 여러분 확인 없이 멋대로 계획을 확정하지 않도록 만들어 둔 것입니다. 셋 중 하나를 고르시면 됩니다. 잘 모르겠으면 **"그대로 진행"** 을 고르세요. 나중에 언제든 바꿀 수 있습니다.

승인하시면 계획표 파일이 만들어집니다.

> ✅ **이 화면이 보이면 성공** — `vl_roadmap` 폴더 안에 `20260810_RoadMap_...md` 같은 이름의 파일이 생겼습니다. 열어 보면 M1, M2, M3… 로 나뉜 단계들이 보입니다.

## 5단계 — 계획표 훑어보기 (5분)

계획표를 열어서 한 번 읽어 보세요. 전부 이해하지 않으셔도 됩니다. **아래 세 가지만 확인**하시면 충분합니다.

**하나, 단계(M1, M2 …)가 몇 개이고 각각 무엇인가.** 내가 생각한 것과 크게 다르지 않으면 됩니다.

**둘, 각 단계마다 "예상 시간"이 있는가.** 하루에 할 수 있는 크기인지 봅니다.

**셋, "Definition of Done"이라는 목록이 있는가.** 우리말로 **완료 기준**입니다. "여기까지 하면 끝"을 미리 정해 둔 체크박스입니다. 이게 있으면 "언제 끝나는지 모르겠는" 상태에 빠지지 않습니다. 앞으로는 줄여서 **DoD**라고 부릅니다.

마음에 안 드는 부분이 있으면 그냥 말씀하시면 됩니다.

```
2단계가 너무 어려워 보여요. 좀 더 쉽게 나눠 주세요.
```

## 전체 흐름 — 앞으로 이렇게 돌아갑니다

VibeLearn AI는 세 단계가 반복되는 구조입니다. 지금 1·2단계를 마치셨습니다.

| 단계 | 언제 | 무엇을 |
|---|---|---|
| **① Topic 시작** | 처음 한 번 | "○○을 공부하고 싶어요" → 폴더 생성 |
| **② 계획표 만들기** | 처음 한 번 | AI가 단계별 계획 작성 → **내가 승인** |
| **③ 매일 공부하기** | 할 때마다 반복 | 오늘 할 일 계획 → **내가 승인** → 진행 → 기록 |

다음에 이어서 하실 때는 이렇게 말씀하시면 됩니다.

```
오늘 학습을 시작해 주세요.
```

그러면 AI가 계획표와 지난 기록을 읽고, **어디까지 했고 오늘 뭘 하면 되는지** 알려 줍니다. 여기서도 진행 전에 한 번 더 물어봅니다.

> 💡 **승인을 두 번 받는 이유** — 계획표를 만들 때 한 번, 매일 시작할 때 한 번. AI가 혼자 판단해서 일을 벌이지 않게 하는 장치입니다. 익숙해지시면 "그대로 진행"만 누르시게 되지만, 처음에는 **AI가 무엇을 하려는지 읽어 보는 습관**을 들이시면 좋습니다.

## 여기까지 됐으면

첫 Topic이 시작됐고 계획표까지 손에 들어왔습니다. 이제 실제로 **무언가를 만들어 보는 것**만 남았습니다.

## 잘 안 될 때

**AI가 VibeLearn AI 방식이 아니라 그냥 대답만 해요**
`VibeLearn-AI` 폴더가 열려 있지 않을 가능성이 큽니다. VS Code 왼쪽 위에 `VIBELEARN-AI`가 보이는지 확인해 주세요. 그래도 안 되면 이렇게 말해 보세요.

```
이 폴더의 CLAUDE.md를 읽고, 그 방식대로 진행해 주세요.
```

**만들어진 파일에 `{ }` 중괄호나 이상한 기호가 남아 있어요**
자주 있는 일입니다. 서식이 제대로 채워지지 않은 경우입니다. 그냥 이렇게 말씀하시면 됩니다.

```
이 파일에 채워지지 않은 부분이 남아 있어요. 다시 만들어 주세요.
```

**계획표가 너무 길고 어려워 보여요**
그대로 말씀하시면 됩니다. "너무 많아 보여요. 단계를 줄여 주세요" 라고 하시면 다시 짜 줍니다.

**질문에 뭐라고 답해야 할지 모르겠어요**
"잘 모르겠어요. 예를 들어 주세요"라고 하시면 AI가 보기를 들어 다시 물어봅니다. 모른다고 답해도 전혀 문제없습니다.
