## First success — a result in 5 minutes

Install and the plan are done. But you probably don't yet feel **"I made something."** You've only done a lot of prep.

This document is for making that feeling. **You'll have one visible result in your hands within 5 minutes.**

**Time**: 5–10 minutes

## Why do this

Getting a taste of success right after the prep decides whether you keep going. Stop at just installing, in the "so what now?" state, and most people never open it again.

It doesn't need to be grand. **Something that came from your own hand, however small,** is enough.

## Pick just one

Pick **just one** of the three below. Choose the one that resonates with you.

### One — Make a one-page introduction of yourself

```
Please make a one-page web page introducing me.
My name is [your name], and I want to present [what you do or care about].
Set nice colors and fonts too.
```

**What you get**: one `.html` file. Double-click it and your intro page opens in a browser.

**Success check**: if a page with your name shows in the browser, it worked.

### Two — Organize today's to-dos

```
Please organize what I have to do today.
[Write three to-dos freely]
Organize them in order of importance, and estimate how long each takes, as a table.
```

**What you get**: one `.md` file. Today's plan organized as a table.

**Success check**: a file appears, and opening it you see the table — it worked.

### Three — Organize something you want to know

```
Please organize what I should know about [a topic you're curious about].
Write it simply enough for someone who doesn't know computers,
and save it as a file.
```

**What you get**: one `.md` file. An organized explanation.

**Success check**: a file appears, and reading it you understand it — it worked.

## How to do it

① Press the **Claude icon** on the vertical bar on the left.

② Put the sentence you chose in the box, replace what's inside `[ ]` with your own, and press Enter.

③ If the AI asks whether it may make the file, press **Allow.**

④ A new file appears in the left list. Click it to open.

> ✅ **If a file appears with content inside, it worked.**

## If you don't like it, just say so

This is the heart of this way of working. It doesn't have to be perfect the first time.

```
The colors are too dark. Please make them lighter.
```

```
The text is too long. Please cut it in half.
```

```
Show it as a list instead of a table.
```

**Saying "please fix it" is the normal way to use this.** Not getting what you want on the first try isn't failure, it's the process.

## What just happened?

Briefly, this.

**The AI actually made a file on your computer.** That's the decisive difference from chatting with AI on a website. The text in a chat window disappears when you close it, but the file you just made stays in your folder.

**And that file becomes material for the next task.** Tell the AI "fix that file I made earlier" and it reads and fixes it. You don't have to explain from scratch each time.

What happens as this piles up is covered again later.

## When it doesn't work

**The AI shows text on screen instead of making a file**
Add this.

```
Please save that content as a file.
```

**I double-click the web page file and it won't open**
Right-click the file and choose **Open with → Chrome (or Edge, Safari)** and it opens.

**The result came out in Korean/English (not my language)**
Say "Please remake it in [your language]."

**I don't know what to ask for**
You can ask the AI.

```
Recommend three things I could try making for practice right now.
```
