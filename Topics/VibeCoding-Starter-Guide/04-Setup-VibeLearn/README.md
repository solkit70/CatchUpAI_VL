## M4 - 설치편② VibeLearn AI 설치하고 첫걸음

**모듈**: M4 / **상태**: ✅ 완료 (2026-08-10) / **예상 학습 시간**: 2.5시간

이 폴더는 가이드북 **4장(VibeLearn AI 설치하고 첫걸음)과 부록 D(조금 더 깊이)**를 채운다. M3에서 도구를 갖춘 참가자가 여기서 **실제로 무언가를 만들어 보고 끝난다** — 설치만 하고 "그래서 뭐 하지" 상태로 남지 않게 하는 것이 이 모듈의 목적이다.

**참가자 기준 총 소요 시간**: 30~40분 (내려받기 10분 + 첫 Topic 20분 + 첫 성공 10분)

## 이 모듈에서 정한 것

**기여자용 설정을 본문에서 완전히 뺐다.** `install-hooks.ps1`, `pip install`, `ANTHROPIC_API_KEY`는 이 방법론을 **고치고 관리하는 사람**을 위한 것이지 배우는 사람에게는 필요 없다. 공식 안내문도 "템플릿만 다운로드해 쓰면 건너뛰어도 된다"고 명시한다. 그런데 처음 오신 분이 저장소 안내를 그대로 보면 여기서 질려 버린다.

그래서 본문에서 빼되 **없애지는 않고 부록 D로 보냈다.** 인터넷에서 그 명령어들을 마주치고 불안해진 분에게 "안 하셔도 됩니다"라고 답해 주는 자리가 필요하기 때문이다.

**"미리 안심하셔도 되는 것" 표를 맨 앞에 뒀다.** 프로그램 설치 ❌, Git ❌, Python ❌, 명령어 입력 ❌, 방법론 공부 ❌. 무엇을 **안 해도 되는지**를 먼저 알려 주는 것이 무엇을 해야 하는지 알려 주는 것보다 문턱을 크게 낮춘다.

**ZIP 경로를 기본으로, Git은 선택으로.** Git을 모르는 분이 대다수이고, 결과는 똑같다. "Git이 무엇인지 모르시면 방법 A를 쓰세요"라고 못 박았다.

**승인 게이트를 "고장이 아니라 안전장치"로 설명했다.** AI가 계획을 확정하기 전에 물어보는 것은 이 시스템의 핵심 설계인데, 처음 보면 "왜 안 하고 물어보지" 싶을 수 있다. 이걸 안심 요소로 프레이밍했다.

**첫 성공을 세 갈래로 준비했다.** 내 소개 웹페이지 / 오늘 할 일 정리 / 궁금한 것 정리 — 독자층(학생·시니어·실무자)이 각자 와닿는 걸 고를 수 있게 했다.

**"고쳐 달라고 말하는 것이 정상적인 사용법"임을 명시했다.** 한 번에 원하는 게 안 나오는 것을 실패로 받아들이면 거기서 그만두게 된다.
