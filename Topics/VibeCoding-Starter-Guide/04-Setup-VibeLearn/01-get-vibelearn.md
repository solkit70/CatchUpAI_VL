## VibeLearn AI 내려받기

도구는 다 갖췄습니다. 이제 **VibeLearn AI**를 받습니다.

VibeLearn AI는 프로그램이 아닙니다. **AI와 함께 체계적으로 배우고, 그 과정을 다음 사람도 쓸 수 있는 자료로 남기는 방법**입니다. 실제로 받는 것은 글로 적힌 안내문 묶음(파일 몇 개)이고, AI가 그 안내문을 읽고 여러분을 이끌어 줍니다.

**걸리는 시간**: 10분
**비용**: 무료
**설치 프로그램 없음** — 그냥 폴더를 하나 받는 것입니다

> 💡 **글보다 영상이 편하시면** — VibeLearn AI가 무엇인지 소개하는 영상을 먼저 보셔도 좋습니다.
> 👉 [VibeLearn AI 소개 영상](https://youtu.be/rbc-6b0woJU)

## 미리 안심하셔도 되는 것

설치 안내를 찾아보시면 어려운 말이 나올 수 있습니다. 먼저 정리해 드립니다.

| 이런 게 필요할까요? | 답 |
|---|---|
| 프로그램 설치 | ❌ 없습니다. 폴더 하나 받으면 끝 |
| Git / GitHub 계정 | ❌ 없어도 됩니다 (ZIP으로 받는 길을 안내합니다) |
| Python, Node.js 같은 것 | ❌ 필요 없습니다 |
| 명령어 입력 | ❌ 하지 않으셔도 됩니다 |
| 이 방법론을 공부하기 | ❌ **필요 없습니다.** "○○을 공부하고 싶어" 한마디면 AI가 알아서 진행합니다 |

> 인터넷에서 이 프로젝트의 설치 안내를 보시면 `pip install`, `hook 설치`, `API 키 설정` 같은 내용이 나옵니다. **그건 이 방법론을 만들고 고치는 사람들을 위한 것이지, 배우는 사람에게는 필요 없습니다.** 궁금하시면 [조금 더 깊이](04-appendix-advanced.md)에 정리해 두었습니다.

## 1단계 — 받기 (둘 중 하나만)

### 방법 A — ZIP으로 받기 (권장, 가장 간단)

Git을 몰라도 되고, 계정도 필요 없습니다.

① 브라우저 주소창에 다음을 입력합니다.

```
https://github.com/solkit70/VibeLearn-AI
```

② 화면 오른쪽 위쯤에 있는 **초록색 Code 버튼**을 누릅니다.

③ 아래로 펼쳐진 목록에서 맨 아래 **Download ZIP**을 누릅니다.

④ 파일이 내려받아집니다. 이름은 `VibeLearn-AI-main.zip` 처럼 생겼습니다.

⑤ 내려받은 파일을 **두 번 클릭해 압축을 풉니다.**

- Windows: 파일을 오른쪽 버튼으로 누르고 **압축 풀기**를 고릅니다
- 맥: 두 번 클릭하면 자동으로 풀립니다

⑥ 풀린 폴더의 이름이 `VibeLearn-AI-main` 이면, **이름을 `VibeLearn-AI` 로 바꿔** 주세요. (뒤의 `-main`을 지우시면 됩니다)

⑦ 그 폴더를 **앞에서 만든 작업 폴더 옆에** 두시면 됩니다. 문서(Documents) 폴더 안이 좋습니다.

> ✅ **이 화면이 보이면 성공** — 문서 폴더 안에 `VibeLearn-AI` 라는 폴더가 있고, 그 안에 `README.md`, `templates` 같은 것들이 보입니다.

### 방법 B — Git으로 받기 (Git을 이미 쓰고 계신 분만)

Git이 무엇인지 모르시면 **방법 A를 쓰세요.** 결과는 똑같습니다.

```
git clone https://github.com/solkit70/VibeLearn-AI.git
```

## 2단계 — VS Code에서 열기

① VS Code를 엽니다.

② 위쪽 메뉴에서 **File**(파일) → **Open Folder...**(폴더 열기) 를 고릅니다.

③ 방금 받은 **`VibeLearn-AI` 폴더**를 골라 엽니다.

④ "이 폴더에 있는 파일 작성자를 신뢰합니까?"라는 창이 뜨면 **예, 신뢰합니다**를 누릅니다.

> ✅ **이 화면이 보이면 성공** — VS Code 왼쪽 위에 `VIBELEARN-AI` 라는 이름이 보이고, 그 아래에 파일과 폴더 목록이 죽 나타납니다.

## 3단계 — 폴더 안을 둘러보기 (3분)

파일이 여러 개 보여서 당황스러우실 수 있습니다. **딱 두 가지만 알아 두시면 됩니다.** 나머지는 열어 보실 일이 없습니다.

| 무엇 | 하는 일 | 내가 열어 봐야 하나 |
|---|---|---|
| `CLAUDE.md` | **AI에게 주는 안내문.** AI가 이걸 읽고 여러분을 이끕니다 | ❌ 안 열어 보셔도 됩니다 |
| `templates` 폴더 | AI가 계획표를 만들 때 쓰는 서식들 | ❌ 안 열어 보셔도 됩니다 |
| `README.md` | 이 방법론 전체 설명 (긴 글) | 🔸 궁금하실 때만 |
| `GETTING_STARTED.md` | 빠른 시작 안내 (긴 글) | 🔸 궁금하실 때만 |
| `Topics` 폴더 | **여러분이 공부를 시작하면 여기에 생깁니다.** 지금은 없습니다 | ✅ 나중에 여기가 내 작업 공간이 됩니다 |

가장 중요한 것은 **`CLAUDE.md`** 입니다. 이 파일이 AI에게 "이 사람을 이런 방식으로 도와주라"고 알려 주는 안내문입니다. 여러분이 읽으실 필요는 없습니다 — **AI가 읽습니다.**

> 💡 **왜 폴더를 받아야 하나요?**
> AI가 이 안내문들을 읽을 수 있어야 하기 때문입니다. AI에게 "VibeLearn AI 방식으로 도와줘"라고 말로만 하면, AI는 그게 뭔지 정확히 모릅니다. 폴더를 받아 열어 두면 AI가 직접 읽고 그대로 따릅니다.

## 4단계 — AI가 안내문을 읽었는지 확인 (2분)

① 왼쪽 세로 막대에서 **Claude 아이콘**을 누릅니다.

② 입력칸에 다음을 그대로 입력하고 Enter를 누릅니다.

```
지금 열려 있는 폴더의 CLAUDE.md를 읽고,
VibeLearn AI가 어떤 방법인지 세 문장으로 알려 주세요.
```

③ AI가 파일을 읽어도 되는지 물어보면 **허용**을 누릅니다.

④ AI가 VibeLearn AI를 설명하는 답을 내놓습니다.

> ✅ **여기까지 됐으면 성공입니다.** AI가 안내문을 읽었고, 이제 그 방식대로 여러분을 도울 준비가 됐습니다.

## 여기까지 됐으면

받는 일은 끝났습니다. 정리하면 이렇습니다.

| 폴더 | 무엇 |
|---|---|
| `my-ai-work` | 앞에서 만든 연습용 폴더 (지금은 안 씁니다) |
| `VibeLearn-AI` | **지금 열려 있는 폴더. 앞으로 여기서 공부합니다** |

이제 **첫 Topic을 시작**할 차례입니다. 놀라실 텐데, 한 문장이면 됩니다.

→ 다음: [첫 Topic 시작하기](02-first-topic.md)

## 잘 안 될 때

**초록색 Code 버튼이 안 보여요**
화면이 좁으면 버튼 위치가 달라집니다. 브라우저 창을 넓게 하시거나, 페이지를 조금 위로 올려 보세요.

**압축을 풀었는데 폴더 안에 또 폴더가 있어요**
자주 있는 일입니다. `VibeLearn-AI-main` 안에 또 `VibeLearn-AI-main`이 있는 경우가 있습니다. **`README.md` 파일이 바로 보이는 쪽**이 진짜 폴더입니다. 그 안쪽 폴더를 꺼내서 쓰시면 됩니다.

**AI가 "CLAUDE.md를 찾을 수 없습니다"라고 해요**
폴더를 잘못 열었을 가능성이 큽니다. VS Code 왼쪽 위에 `VIBELEARN-AI`가 보이는지, 그 아래에 `CLAUDE.md`가 있는지 확인해 주세요.

**폴더 이름을 바꾸는 걸 깜빡했어요**
괜찮습니다. `VibeLearn-AI-main` 이름 그대로도 잘 작동합니다. 나중에 바꾸셔도 됩니다.

더 많은 상황은 [막힐 때 보는 문서](../03-Setup-Environment/04-troubleshooting.md)에 정리해 두었습니다.
