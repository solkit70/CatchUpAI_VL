## 첫 성공 — 5분 만에 결과물 보기

설치와 계획표까지 끝났습니다. 하지만 아직 **"내가 뭘 만들었다"는 느낌**은 없으실 겁니다. 준비만 잔뜩 한 상태니까요.

이 문서는 그 느낌을 만드는 데 씁니다. **5분 안에 눈에 보이는 결과물 하나**를 손에 넣습니다.

**걸리는 시간**: 5~10분

## 왜 이걸 하나

준비가 끝난 직후에 성공을 한 번 맛보는 것이, 이후 계속 갈 수 있느냐를 가릅니다. 설치만 하고 "그래서 이제 뭐 하지?" 상태로 끝나면 대부분 다시 열지 않습니다.

거창할 필요가 없습니다. **작아도 내 손에서 나온 것**이면 됩니다.

## 골라서 하나만 해 보세요

아래 셋 중 **하나만** 고르시면 됩니다. 자신에게 와닿는 것으로 고르세요.

### 첫 번째 — 내 소개 한 장 만들기

```
제 소개를 담은 웹페이지를 한 장 만들어 주세요.
이름은 [내 이름]이고, [내가 하는 일이나 관심사]를 소개하고 싶어요.
보기 좋게 색과 글꼴도 정해 주세요.
```

**나오는 것**: `.html` 파일 하나. 그 파일을 두 번 클릭하면 브라우저에서 내 소개 페이지가 열립니다.

**성공 확인**: 브라우저에 내 이름이 보이는 페이지가 떴다면 성공입니다.

### 두 번째 — 오늘 할 일 정리하기

```
오늘 제가 할 일을 정리해 주세요.
[할 일 세 가지를 편하게 적으세요]
중요한 순서대로 정리하고, 각각 얼마나 걸릴지 짐작해서 표로 만들어 주세요.
```

**나오는 것**: `.md` 파일 하나. 표로 정리된 오늘의 계획입니다.

**성공 확인**: 파일이 생기고, 열어 보면 표가 보이면 성공입니다.

### 세 번째 — 알고 싶은 것 정리하기

```
[궁금한 주제]에 대해 제가 알아야 할 것을 정리해 주세요.
컴퓨터를 잘 모르는 사람도 이해할 수 있게 쉽게 써 주시고,
파일로 저장해 주세요.
```

**나오는 것**: `.md` 파일 하나. 정리된 설명입니다.

**성공 확인**: 파일이 생기고, 읽어 봤을 때 이해되면 성공입니다.

## 하는 방법

① 왼쪽 세로 막대에서 **Claude 아이콘**을 누릅니다.

② 위에서 고른 문장을 입력칸에 넣고, `[ ]` 안을 내 이야기로 바꿔서 Enter를 누릅니다.

③ AI가 파일을 만들어도 되는지 물으면 **허용**을 누릅니다.

④ 왼쪽 목록에 새 파일이 나타납니다. 눌러서 열어 봅니다.

> ✅ **파일이 생기고 그 안에 내용이 있으면 성공입니다.**

## 마음에 안 들면 그냥 말하세요

이게 이 방식의 핵심입니다. 처음부터 완벽할 필요가 없습니다.

```
색이 너무 어두워요. 밝게 바꿔 주세요.
```

```
글이 너무 길어요. 절반으로 줄여 주세요.
```

```
표 말고 목록으로 보여 주세요.
```

**고쳐 달라고 말하는 것이 이 방식의 정상적인 사용법입니다.** 한 번에 원하는 게 나오지 않는 것은 실패가 아니라 과정입니다.

## 방금 무슨 일이 일어난 건가

짧게 정리하면 이렇습니다.

**AI가 내 컴퓨터에 실제로 파일을 만들었습니다.** 웹사이트에서 AI와 대화하는 것과 결정적으로 다른 점입니다. 대화창의 글은 창을 닫으면 사라지지만, 방금 만든 파일은 내 폴더에 남아 있습니다.

**그리고 그 파일은 다음 작업의 재료가 됩니다.** AI에게 "아까 만든 그 파일 좀 고쳐 줘"라고 하면 그 파일을 읽고 고칩니다. 매번 처음부터 설명하지 않아도 됩니다.

이게 쌓이면 어떻게 되는지는 뒤에서 다시 다룹니다.

## 여기까지 오셨다면

**준비가 전부 끝났습니다.** 지금까지 하신 것을 정리하면 이렇습니다.


## 다음으로

도구는 갖췄고 첫 결과물도 나왔습니다. 하지만 **이 도구를 잘 쓰는 법**은 또 다른 이야기입니다.

많은 분들이 여기서 AI를 챗봇처럼 쓰기 시작합니다 — 궁금한 걸 묻고, 답을 받고, 창을 닫는 식으로요. 그렇게 쓰면 기껏 만든 이 구조가 아무 소용이 없습니다.

→ 다음: **5장 제대로 쓰는 법**에서 그 차이를 다룹니다.

## 잘 안 될 때

**AI가 파일을 안 만들고 화면에 글만 보여 줘요**
이렇게 덧붙여 말씀하시면 됩니다.

```
그 내용을 파일로 저장해 주세요.
```

**만든 웹페이지 파일을 두 번 클릭해도 안 열려요**
파일을 오른쪽 버튼으로 누르고 **연결 프로그램 → 크롬(또는 엣지, 사파리)** 을 고르시면 열립니다.

**결과가 영어로 나왔어요**
"한국어로 다시 만들어 주세요"라고 하시면 됩니다.

**뭘 부탁해야 할지 모르겠어요**
AI에게 물어보셔도 됩니다.

```
제가 지금 연습 삼아 만들어 볼 만한 것을 세 가지 추천해 주세요.
```
