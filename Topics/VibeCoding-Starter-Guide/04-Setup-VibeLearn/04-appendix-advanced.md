## 부록 D — 조금 더 깊이

**이 부록은 안 읽으셔도 됩니다.** 본문만 따라 하셔도 VibeLearn AI를 쓰시는 데 아무 지장이 없습니다.

이 문서는 두 분을 위해 있습니다. 하나는 인터넷에서 설치 안내를 보다가 **어려운 말을 만나 불안해진 분**, 다른 하나는 **이 방법론을 직접 고치거나 남에게 나눠 주고 싶은 분**입니다.

## 왜 본문에서 뺐나

VibeLearn AI 저장소의 공식 안내에는 아래 같은 내용이 나옵니다.

```
powershell -ExecutionPolicy Bypass -File scripts/install-hooks.ps1
pip install -r requirements.txt
$env:ANTHROPIC_API_KEY = "sk-ant-..."
```

처음 보시면 "이걸 다 해야 하나" 싶어 질리게 됩니다. **하지만 배우는 사람에게는 하나도 필요 없습니다.**

이건 **이 방법론 자체를 고치고 관리하는 사람들**을 위한 것입니다. 안내문(`CLAUDE.md`)을 고쳤을 때 다른 파일들에도 자동으로 반영되게 하고, 영어판을 자동 번역하는 용도입니다. 공식 안내문에도 이렇게 적혀 있습니다.

> "단순히 템플릿 파일만 다운로드하여 사용하는 경우에는 건너뛰어도 됩니다."

여러분이 하실 일은 **폴더를 받아서 열고, 하고 싶은 걸 말하는 것**까지입니다.

## 각각이 무엇인지 (궁금하실 때만)

| 나오는 말 | 무엇인가 | 배우는 사람에게 필요한가 |
|---|---|---|
| `install-hooks.ps1` | 파일을 저장할 때 자동으로 검사·정리를 돌리는 장치를 설치 | ❌ 필요 없음 |
| `pip install -r requirements.txt` | 자동 번역에 쓰이는 파이썬 부품을 설치 | ❌ 필요 없음 |
| `ANTHROPIC_API_KEY` | 자동 번역을 돌릴 때 쓰는 열쇠 | ❌ 필요 없음 |
| `Git`, `clone` | 저장소를 받아 오고 변경 이력을 관리하는 도구 | 🔸 없어도 됨 (ZIP으로 받으면 됨) |
| `Node.js`, `npm` | 다른 종류의 프로그램을 돌리는 도구 | ❌ **이 프로젝트에는 아예 쓰이지 않음** |

## 다른 AI 도구를 쓰고 싶다면

이 가이드는 **VS Code + Claude Code**를 기준으로 썼습니다. 다른 도구를 이미 쓰고 계신다면 그것으로도 됩니다. VibeLearn AI는 특정 AI에 묶여 있지 않습니다.

폴더 안에 도구별 안내문이 각각 들어 있고, **내용은 전부 같습니다.**

| 쓰시는 도구 | 읽는 파일 |
|---|---|
| Claude Code | `CLAUDE.md` |
| Codex | `AGENTS.md` |
| Gemini CLI | `GEMINI.md` |
| GitHub Copilot | `.github/copilot-instructions.md` |

**같은 내용을 이름만 다르게 복사해 둔 것**입니다. 도구를 바꾸셔도 같은 방식으로 진행됩니다.

> ⚠️ 다만 **웹사이트에서 대화만 하는 방식**(claude.ai, ChatGPT 웹)으로는 제대로 되지 않습니다. 파일을 직접 읽고 쓰지 못해서, 매번 복사해 붙여 넣어야 하기 때문입니다. 공식 안내에도 "복사/붙여넣기로 인한 시간 낭비가 발생합니다"라고 적혀 있습니다.

## 편의 기능 하나 (선택)

Claude Code를 쓰신다면, 폴더 만들기와 파일 찾기를 조금 더 자동으로 해 주는 보조 기능을 켤 수 있습니다. **없어도 전부 똑같이 작동합니다.**

원하시면 AI에게 이렇게 부탁하시면 됩니다.

```
extras에 있는 claude-skill 을 등록해 주세요.
```

## 만든 것을 남에게 나눠 주고 싶다면

공부한 결과가 쌓이면 다른 사람에게도 도움이 됩니다. 나누는 방법은 여러 가지입니다.

**가장 간단한 방법**은 `Topics` 폴더 안의 내 주제 폴더를 통째로 압축해서 보내는 것입니다. 받은 사람이 VS Code에서 열면 그대로 볼 수 있습니다.

**GitHub에 올리는 방법**도 있지만, 계정과 사용법을 따로 익히셔야 합니다. 급하지 않습니다.
