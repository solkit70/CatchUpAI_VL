## M1 - 가이드 뼈대 + 쉬운 용어 사전

**모듈**: M1 / **상태**: ✅ 완료 (2026-08-10) / **예상 학습 시간**: 1.5시간

이 폴더는 가이드 전체가 따를 **뼈대와 언어 기준**을 담는다. M2~M7의 모든 문서가 여기 정한 목차 자리에 들어가고, 여기 정한 용어와 검수 기준을 지킨다. 그래서 이 모듈이 가장 먼저 온다 — 기준 없이 쓰기 시작하면 나중에 전부 고쳐야 한다.

## 📚 학습 순서

1. [01-outline.md](01-outline.md) — 가이드 전체 목차와 각 장을 채울 모듈 매핑. 층별 동기 부여 문단 자리와 Catch Up AI 소개 위치도 여기서 확정했다
2. [02-glossary.md](02-glossary.md) — 쉬운 용어 사전 21개 + 쓰지 말아야 할 표현 16개. **모든 문서가 이 풀이를 그대로 쓴다**
3. [03-writing-checklist.md](03-writing-checklist.md) — 문서를 끝낼 때마다 훑는 8개 영역 검수 목록

## 이 모듈에서 정한 것

**가이드는 8장 + 부록 4개, 30쪽 내외**로 간다. 장 순서는 기능이 아니라 독자의 심리 순서를 따른다 — "나도 해도 되나"를 풀어 준 뒤(0~1장), "이게 뭔지" 이해시키고(2장), 손을 움직이게 하고(3~4장), 그다음에 잘 쓰는 법을 알려준다(5~6장).

**설치를 2장이 아니라 3장에 둔 이유**가 중요하다. 무엇을 왜 까는지 모르는 채 설치부터 시작하면, 막혔을 때 포기할 이유가 생긴다.

**층별로 문서를 쪼개지 않는다.** 학생·시니어·시민단체 실무자가 같은 가이드를 읽되, 각 층이 "이건 내 얘기"라고 느낄 대목을 최소 한 번씩 배치한다. 쪼개면 유지보수가 세 배가 되고 서로의 사례에서 배우는 효과도 사라진다.
