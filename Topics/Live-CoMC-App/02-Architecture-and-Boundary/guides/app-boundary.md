## M11 확장 범위 (2026-10-01)

Rundown·볼트·Tavily 웹 검색·창작의 경로 선택기를 기존 엔진에 통합한다. 검색 결과는 명령이 아닌 데이터로 전달하며 볼트 쓰기, 채팅 자동 수집, OBS 자동 제어는 계속 제외한다. 새 답변 경로는 LIVE 모드에서도 REVIEW로 보류한다.

루트 `.gitignore`의 `Ingest/*`, `Journal/*`, `Topics/*`, `AI/*`, `_Settings_/Tasks/*`는 볼트 전체를 scaffold Git 저장소에서 제외하는 규칙이므로 검색 제외 규칙으로 해석하지 않는다. 그 외 명시적 비공개 규칙과 하위 프로젝트의 `.gitignore`, `visibility: internal`, `private: true`, 내부 자료 표시는 검색에서 제외한다. 민감한 개인 일·연락처 패턴을 추가로 필터링하고 사용 직전에 원문을 다시 검사한다.
