## 제외 범위 (11개 — 이유 포함)

| # | 기능 | 제외 이유 |
|---|---|---|
| 1 | 상시 STT / 발화 자동 파트 감지 | 3시간 클라우드 비용 + 오탐 시 조용한 오작동 |
| 2 | 시청자 채팅 연동 | 통제 불가 외부 입력 = 프롬프트 인젝션 표면 |
| 3 | 볼트 파일 쓰기 | 방송 중 문서 변조 사고 리스크 — 앱은 읽기 전용 |
| 4 | 전체 볼트 벡터 검색 / RAG | 커버리지 원칙 정면 위반("Vault에 있다 ≠ 오늘 방송에서 했다"). **영구 제외 후보** |
| 5 | OBS 씬 자동 제어 | 방송 중 씬 오작동은 즉시 치명적 |
| 6 | 진행자 발화 중 끼어들기(barge-in) | 타이밍 제어 불가. **영구 제외** |
| 7 | 다중 Rundown / 과거 회차 조회 | 컨텍스트 혼입 — M1에서 확인한 "Rundown 단일 문서만 신뢰 소스" 원칙과 직결 |
| 8 | `.canvas` 파싱 | `.md`가 정본 (M1 개념 정리에서 확정) |
| 9 | 로컬 LLM 추론 | GPU 없음, i7-1355U 15W CPU |
| 10 | 모바일/웹 버전 | 사용자 확정사항 — 로컬 데스크톱 앱만. v2 이후 검토 |
| 11 | 영어 등 다국어 TTS 출력 | 1차 목표는 한국어 방송 진행. 다국어는 향후 확장 검토 |

## 컴포넌트별 "절대 하지 말아야 할 일"

| 컴포넌트 | 절대 하지 말아야 할 일 |
|---|---|
| Wake Word 모듈 | TTS 재생 중 wake 감지를 계속 켜두는 것 (에코 루프 직결) |
| STT 모듈 | wake word 감지 전에 클라우드로 오디오를 전송하는 것 (비용·프라이버시) |
| LLM 응답 모듈 | `claim_map` 없이 문장을 생성하는 것 (근거 없는 발화의 근본 원인) |
| 안전 검증 게이트 | 검증을 LLM 자기평가에 위임하는 것 (반드시 규칙 기반 문자열 대조) |
| Electron 셸 | 볼트 디렉터리에 쓰기 작업을 수행하는 것 |
| 전체 엔진 | Python 프로세스가 죽었을 때 Electron 셸(오버레이·패닉 스톱)까지 함께 멈추는 것 — 프로세스 분리로 방지 |
