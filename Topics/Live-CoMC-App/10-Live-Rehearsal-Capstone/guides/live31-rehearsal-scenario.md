## 이 문서는

박창수가 **방송 전에 새 CoMC 를 직접 만져 보며 익히기 위한** 가벼운 리허설 시나리오다. 세부 테스트 케이스(R-01~R-26)는 [manual-regression-test-cases.md](manual-regression-test-cases.md) 에 있고, 여기서는 **주요 기능과 새 기능을 한 번씩 써 보는 8단계(약 25분)** 만 뽑았다. 각 단계 끝의 R-번호가 세부 케이스다. 개편 내용을 방송에서 소개할 때 쓸 설명과 멘트도 함께 넣었다.

## 1. 이번 개편으로 달라진 것 (방송 소개용)

10/8 Codex 와 개편한 「공동 진행자」 버전이다. 이전 버전은 **Rundown 에 있는 내용만 답하고, 없으면 침묵**했다. 이번에는 사용자가 제보한 아홉 가지 불편을 풀었다.

| 이전 | 이번 개편 |
|---|---|
| 파트 버튼을 골라야 답함 · 문서 밖 질문엔 침묵 | **파트 조작 없이 자유 대화.** Rundown 은 「우선 참고하는 계획」일 뿐, 일반 대화·의견·공개 웹 확인도 한다. 모르면 지어내지 않고 되묻는다 |
| 오래된 일정·엉뚱한 날짜를 섞어 말함 | **방송일 기준 지난 일요일~토요일**이 기본 회고 기간 (Live31 은 10/4~10/10). 날짜를 말하면 그 날짜가 우선. 미래 일정을 한 일로 말하지 않는다 |
| 남성 기본 음성 | **다섯 페르소나(기본 · 하늘 · 다온 · 서연 · 지우) 모두 여성 음성**. 하늘은 고등학생 반말 |
| 시청자 인사 실패 | 이름을 등록하고 **이름 옆 「인사하기」** 또는 「OOO님께 인사해 줘」. 정확한 사람에게 자연스럽게, 내부 기록(참여 횟수)은 낭독하지 않는다 |
| 키보드 입력만 | **「말로 요청」** — 마이크로 말하면 전사해서 질문으로 보냄 |
| 방송을 못 듣고 문서만 봄 | **「함께 듣기」** — 마이크(와 공유 소리)를 약 10초마다 전사하고 45초마다 「지금 이야기 · 끝난 것 · 남은 계획 · 제안」을 갱신. 실제로 들은 내용만 완료의 근거로 쓴다 |
| 답변이 길면 음성이 끊김 | 접수 멘트(「잠시 확인하고 답변드릴게요」), 긴 답변의 **분할 재생과 자막**, 승인 후 빠른 재생 |
| 화면이 어두움 | 밝은 라벤더·피치 톤 |

안전 장치는 그대로다: **REVIEW**(화면 확인 후 승인해야 말함) · **LIVE**(바로 말함) · **MUTE**, **패닉 버튼 / Ctrl+Alt+Space**(즉시 중단), 화면 지우기.

### 방송 오프닝 멘트 (약 1분)

> 「지난 방송에서 발견한 문제들을 바탕으로 CoMC 를 자유로운 공동 진행자로 바꿨습니다. 이전에는 Rundown 에 있는 말만 했는데, 이제는 대화도 하고, 모르는 건 웹에서 확인하고, 제 이야기를 듣고 진행 상황을 정리해 줍니다. 오늘은 방송 내내 CoMC 가 함께 진행하고, 중간중간 새 기능을 보여 드릴게요.」

## 2. 현재 상태 — 알고 들어갈 것 (10/8 회귀 결과)

10/8 밤 실행 결과는 26개 중 **PASS 6 · FAIL 5 · BLOCKED 12 · NOT RUN 3**, 방송 투입 판단은 **NO-GO** 였다. 이후 TTS·OBS 재시험에서 일부가 고쳐졌다.

| 상태 | 내용 |
|---|---|
| ✅ 확인됨 | 자유 대화 · 개인정보 지어내지 않기(R-08) · 시청자 이름 인사(R-11·12) · 접수 멘트와 긴 답변 분할 재생 · REVIEW 승인 · 패닉 즉시 중단과 복구 · MUTE · 화면 지우기 · OBS 소스 새로고침 후 자막 복구 · 하늘 반말 |
| ⚠️ 고쳤지만 **재시험 전** | **「말로 요청」**: 한국어를 말했는데 스페인어·구자라트어로 전사됨 → 선택한 마이크를 쓰도록 수정, 재시험 전. **외국어로 전사되면 답변을 승인하지 않는다** |
| ❌ 문제 있었음 | 주간 활동 요약을 되묻기만 하고 답하지 않음(R-03) · 10/2·10/3 기록이 있는데 없다고 답함(R-04) · 오늘 기준 미래 일정을 한 일로 분류함(R-05). 수정 여부는 리허설에서 확인 |
| 🚫 아직 못 해 봄 | **함께 듣기**(마이크 권한 문제로 전사 0건), 다섯 페르소나 음성과 영어(R-09·10), 합성 도중 MUTE |

그래서 리허설의 가장 큰 목적은 **「말로 요청」과 「함께 듣기」가 실제로 되는지 확인하는 것**이다. 안 되면 방송에서는 키보드 입력과 REVIEW 중심으로 쓰고, 안 되는 기능은 「아직 안정화 중」이라고 솔직히 말하면 된다.

## 3. 준비 (약 5분)

1. **OBS 방송 송출은 켜지 않은 채로** `comc 31` 실행 → 브라우저 탭 `http://127.0.0.1:8778/` (콘솔), OBS 오버레이 `http://127.0.0.1:8777/`.
2. 상단 **방송일이 2026-10-11, 회고 기간이 10/4~10/10** 인지, 모드가 **REVIEW** 인지 확인.
3. **마이크 장치 고르기** — 방송 때 OBS `Live` 컬렉션의 Mic/Aux 는 **Motiv Mix (Shure)** 이므로 리허설도 같은 장치로 해 본다. CoMC 콘솔 「함께 듣기」·「말로 요청」의 **입력 장치 드롭다운**에서 `MOTIV Mix`(없으면 `Microphone (Shure MV7)`)를 고른다. 순서: Motiv Mix 를 USB 로 먼저 연결 → OBS(Live 컬렉션) → 콘솔. Buds 마이크(Headset)는 고르지 않는다 (통화 모드로 바뀌어 음질이 떨어짐). 브라우저가 **localhost 마이크를 허용**하는지도 한 번 확인 (10/8 에 막혔던 곳).
   - **자기 목소리가 이중으로 전사되거나 CoMC 가 자기 말을 다시 듣는 것 같으면**, Motiv Mix 가 컴퓨터 소리까지 섞어 보내는 것이므로 `Microphone (Shure MV7)` 직결로 바꿔 다시 해 본다. 어느 쪽이 맞는지는 이번 리허설에서 정한다.
   - 「말로 요청」의 외국어 오전사(10/8)는 브라우저 기본 마이크를 쓴 탓이었고 선택한 장치를 쓰도록 고쳤으므로, 장치를 직접 고르는 것이 중요하다.
   - 이어폰(Galaxy Buds2)은 듣는 용도, OBS AI 음성 미터도 함께 확인.
4. 테스트 시청자 이름 두 개를 준비: `테스트가람`, `테스트나래` (끝나고 지운다).
5. 방송 중 보여 줄 **합성 대본 문장 두 개**를 정한다 — 예) 「오늘은 Catch 앱 개선을 이야기했고, CoMC 개편은 이미 끝났습니다.」 / 「세 번째 앱은 아직 시작 전입니다.」 (실제 비공개 이야기는 쓰지 않는다)

## 4. 리허설 시나리오 — 8단계 (약 25분)

각 단계는 **할 일 → 볼 것** 만 적는다. 어긋나면 메모만 해 두고 다음으로 넘어간다.

### ① 시작과 화면 (2분) — R-01
- 콘솔을 열고 상단의 회차·방송일·REVIEW, 밝은 화면, 파트 버튼이 없는 것을 본다. 「지금 점검」(프리플라이트)을 눌러 본다.
- **볼 것**: 올바른 날짜와 REVIEW. FAIL 이 뜨면 이유만 메모 (Rundown 이 목·금·토까지 계속 고쳐지는 초안이라 Rundown 관련 경고는 예상됨).

### ② 자유 대화 — 파트 조작 없이 (4분) — R-02·R-06
- 질문란에 `오늘 방송 계획을 간단히 소개해 줘.` → 이어서 `AI로 앱을 쉽게 만들 수 있다면 빌더는 어떤 가치를 만들어야 할까? 네 의견도 이야기해 줘.`
- **볼 것**: 파트를 안 골라도 답함 · 계획을 참고하다 자유 대화로 넘어감 · 의견은 의견이라고 표시. (오늘 방송 ④번 주제와 이어지는 질문이다.)

### ③ 이번 주 이야기 — 방송일 기준 날짜 (3분) — R-03·R-05
- `이번 주에는 어떤 일을 했고 어떤 일정이 있었어? 먼저 기준 날짜를 알려 줘.`
- **볼 것**: 「10/4~10/10」을 먼저 말하고 실제 한 일(예: Claude 영어 영상 업로드, CTS)과 아직 안 한 일을 구분. 10/8 에 되묻기만 하던 부분이 고쳐졌는지 확인.

### ④ 모르는 것은 지어내지 않기 (1분) — R-08
- `내가 어젯밤 비공개 전화에서 결정한 앱 판매 가격이 얼마였지?`
- **볼 것**: 금액을 만들지 않고 모른다고 답함.

### ⑤ 여성 음성 페르소나와 시청자 인사 (5분) — R-09·R-11·R-12
- 페르소나를 **하늘**로 바꿔 「자기소개」 → REVIEW 에서 **승인**하고 소리를 듣는다. 다온 등 한두 명 더 들어 본다.
- `테스트가람` 등록 → 이름 옆 **「인사하기」** → 승인. `테스트나래` 등록 → `지금 등록한 테스트나래님께 반갑게 인사해 줘.`
- **볼 것**: 여성 음성 · 하늘 반말 · 정확한 이름 · 참여 횟수 같은 내부 값을 읽지 않음.

### ⑥ 웹 확인 (2분) — R-07
- `Python 공식 문서에서 asyncio.TaskGroup 이 무엇인지 웹에서 확인해서 쉽게 설명해 줘. 출처도 알려 줘.`
- **볼 것**: 출처 URL 이 화면에 표시됨(음성은 URL 을 읽지 않는 것이 정상).

### ⑦ 말로 요청과 함께 듣기 — 가장 중요 (6분) — R-14·R-15~R-18
- **말로 요청**: 「말로 요청」 → `코엠씨, 함께 방송할 준비가 됐니? 한 문장으로 답해 줘.` → 전사 결과를 **먼저 보고** 한국어가 맞으면 승인. 엉뚱한 외국어면 승인하지 않고 메모.
- **함께 듣기**: 시작 전에 `지금까지 방송에서 무엇을 했어?` → 「아직 듣지 못했다」고 답하는지 확인. 「함께 듣기 시작」 → 합성 대본 첫 문장 읽기 → 약 10초 뒤 전사 확인 → 둘째 문장 → 「지금 진행 평가」 → 「들은 근거」 펼치기 → 「들은 방송으로 진행 정리」 → 승인.
- **볼 것**: 마이크 미터가 움직임 · 전사가 한국어로 나옴 · 평가가 **들은 것만** 완료로 적음(「아직 시작 전」은 예정으로) · 방송에 없던 가정은 완료로 바꾸지 않음.

### ⑧ 안전 장치 (2분) — R-21~R-23
- REVIEW 에서 짧은 질문 → 자동 음성 없음 → 승인하면 한 번 말함. LIVE 로 바꿔 짧은 질문 → 바로 말함. 긴 답변(`AI 시대 빌더에게 필요한 역량을 조금 길게 설명해 줘.`)이 재생되는 동안 **패닉**(Ctrl+Alt+Space) → 즉시 멈춤 → REVIEW 복귀 → 「화면 지우기」.
- **볼 것**: 자막과 음성이 맞음 · 패닉 후에는 아무것도 말하지 않음 · 접수 멘트 「잠시 확인하고 답변드릴게요」. 끝나면 「함께 듣기 멈춤」을 누르고 테스트 이름을 지운다.

## 5. 리허설 뒤에 판단할 것

| 결과 | 방송에서 |
|---|---|
| ⑦ 말로 요청·함께 듣기 모두 OK | 오프닝에서 소개하고 방송 내내 「함께 듣기」를 켜 둔 채 진행. 중간에 「진행 정리」 한 번 |
| 말로 요청만 안 됨 | 키보드로 질문하고 「말로 요청은 아직 안정화 중」이라고 솔직하게 말한다 |
| 함께 듣기 안 됨 | 자유 대화·시청자 인사·웹 확인·안전 장치 중심으로 시연. 진행 정리는 하지 않는다 |
| ③ 주간 요약이 여전히 되묻기만 함 | 날짜를 직접 말해 주며 질문(`10월 4일부터 10일까지 한 일…`)하거나 해당 기능은 시연에서 뺀다 |

결과는 이 문서 아래에 **✅ / ⚠️ / ❌ 한 줄씩** 적어 주시면, 안 된 것을 고치거나 방송 오프닝 멘트를 그에 맞게 바꾸겠다.

| ⑤ 페르소나·시청자 인사 | ⚠️ | 여성 음성 · OBS 자막 ✅. **다섯 페르소나가 모두 같은 목소리(SunHi, 속도·높낮이만 다름)**라 귀로는 구분 불가 → 다음 주 과제. 하늘은 존댓말·반말 혼용. 인사: 버튼 ✅ · 글로 시키면 **이름 띄어쓰기가 다를 때 명단 전체에 인사** |
| ⑥ 웹 확인 | ⚠️ | 답 · 출처 URL 4개 · 내용 ✅(asyncio.TaskGroup). **음성이 「docs.python.org」와 코드 예시를 읽음** ❌, 재생 1분 55초 |
| ⑦ 말로 요청 · 함께 듣기 | ✅ | **말로 요청 한국어 전사 성공**(10/8 외국어 오전사 해결, MOTIV Mix 직접 선택). 함께 듣기 전사 · 평가 ✅(들은 것만 완료, 「세 번째 앱」은 미시작). ⚠️ 고유명사 오인식(코엠씨→소엠씨·호엠씨, Catch→패치). 진행 정리는 정확하나 길고 Rundown 내부 체크리스트까지 말함(→ 해당 절 「미편성」 처리) |
| ⑧ 안전 장치 | ✅ | REVIEW(승인해야 소리) · LIVE(바로 소리) · 패닉 즉시 정지와 MUTE · 화면 지우기 · 자막 정상. ⚠️ 자동 모드에서 「잠깐 자리 비움」이 대체 문장으로 끝나 소리로 나감, 웹 제외에서는 정상 |

## 7. 리허설 뒤 정리 (2026-10-10, Claude Code · 박창수 보고 기준)

**한 줄 결론**: 말로 요청 · 함께 듣기 · 안전 장치 · 시청자 인사 · 지어내지 않기는 방송에 쓸 수 있다. **자동(웹 켜짐) 모드에서 일반 대화 답이 가끔 통째로 버려지는 문제**가 가장 크다. 코드(`cohost.py` 439~441행)상 「모델이 적은 출처가 제공된 문서 경로나 검증된 웹 URL이 아니면 답 전체를 대체 문장으로 바꾼다」는 규칙이 원인으로 추정되며, 같은 질문을 웹 제외로 보내면 정상 답이 나온 것으로 뒷받침됐다(원문 답은 기록에 없어 직접 확인은 못 함).

### 방송 전 운영 요령 (코드 수정 없이)

### 2026-10-10 적용한 수정

- **답 대체 규칙(결정 B)**: 웹 검색이 켜진 답의 출처가 검증되지 않으면 답을 버리기 전에 **웹 없이 한 번 더** 답하게 했다(안전 규칙은 그대로). 기록(`runtime/cohost_fallback.jsonl`)에서 실제 원인은 모델이 **로컬 문서 경로의 철자를 조금 바꿔 쓰는 것**(예: 끝의 `.md` 누락)으로 확인돼, 같은 파일이면 철자 차이를 받아 주도록 했다. 수정 뒤 ②의 의견 질문 · 「잠깐 자리 비움」을 자동 모드에서 다시 보내 모두 정상 답을 확인했다.
- **음성에서 괄호 도메인 제거**: 「(docs.python.org)」 같은 괄호 속 출처 표기는 화면 · 음성 모두에서 지우고, 프롬프트에도 쓰지 말라고 적었다. 문장 속 도메인(muse.ai 등)은 그대로 둔다.
- **목소리 방식 「다양한 음성」**: Persona 카드의 드롭다운으로 켠다(기본은 무료 · 전부 Edge TTS). 기본 코엠씨는 Edge, 다온 · 서연은 OpenAI(nova · shimmer), 하늘 · 지우는 Qwen3(Cherry · Serena). 합성 실패 시 Edge 로 대신한다. → [[Ingest/CatchUpAI_VL/Topics/Live-CoMC-App/10-Live-Rehearsal-Capstone/guides/operator-guide#목소리 방식 — 「다양한 음성」 (2026-10-10 추가)|운영 가이드]]
- 테스트 5건 추가(답 재시도 · 출처 철자 · 도메인 제거 · 목소리 방식 · 합성 실패 대체). 기존의 다른 5건(`test_captions` · `test_cvl8_deny_terms`)은 수정 전에도 같은 이유(`Console` 에 `memory` 없음)로 실패하던 것이다.
