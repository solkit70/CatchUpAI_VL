## 먼저 — 이 앱의 「UI」는 무엇인가

**브라우저 탭 하나**다. `start_comc.ps1` 을 돌리면 PowerShell 창 하나(콘솔 프로세스)와 브라우저 탭 `http://127.0.0.1:8778/` 이 열린다. 질문 · 모드 · 패닉 · 파트 · 프리플라이트 · 결과 · 로그를 전부 그 탭에서 본다. PowerShell 창은 건드리지 않아도 된다 — 끝낼 때 Ctrl+C 를 누르는 곳일 뿐이다.

| 무엇 | 어디 |
|---|---|
| 보는 것 | 콘솔 탭 「오버레이」 칸 = **OBS 미리보기의 오버레이**(Browser Source 「Co-MC 오버레이」)와 같은 내용. 답이 뜨고, 침묵이면 「비어 있음」 |
| 듣는 것 | Buds(모니터) — LIVE 일 때만 (또는 「대기 발화 승인 → 소리」를 눌렀을 때) |
| 넣는 것 | 콘솔 탭 「질문」 칸에 치고 Enter — 시청자 채팅을 그대로 옮겨 쳐도 되고 내 질문을 쳐도 된다 |
| 바꾸는 것 | 콘솔 탭의 모드 · 패닉 · 파트 버튼. **핫키** Ctrl+Alt+… 도 그대로 살아 있다 |

### 왜 창 하나로 바꿨나 (CVL 3, 2026-09-17)

CVL 2 까지는 오버레이 서버 · 재생기 · 핫키 · 엔진이 PowerShell 창 4개였다. 9/17 실사용에서 「어느 창에 치나 · 핫키 창이 죽었는지 어떻게 아나 · 결과는 어디서 보나」가 전부 막혔다. 그래서 네 모듈을 **프로세스 하나**(`comc_console.py`)에 스레드로 넣고, 진행자가 보는 면을 로컬 웹 페이지 하나로 모았다. 검증된 모듈 코드는 그대로 import 한다 — 새 로직은 콘솔 HTTP 뿐이다. 이 과정에서 잡은 실사고 하나: 재생기를 스레드로 돌리자 WASAPI 콜백 스트림이 「Unanticipated host error」로 죽었다 → 스레드마다 COM 초기화(`spoken_player._com_init`) 로 해결 ([incident-classification.md](incident-classification.md) 사고 17).

## 1. 켜기 — 방송 30분 전

PowerShell 하나 열고 (어느 폴더든):

```
comc
```

`C:\Users\dougg\comc.cmd` 가 `start_comc.ps1` 을 부른다. 회차는 `AI\Roundup` 의 최신 「LiveNN Weekly Rundown」에서 자동으로 읽는다 (다른 회차는 `comc 29`). **PowerShell 창을 닫으면 콘솔·오버레이 서버·재생기·핫키가 전부 같이 꺼진다** — OBS 오버레이도 사라진다.

이 한 줄이 ① 오늘 Rundown 파싱 ② 1부 컨텍스트 ③ 모드 REVIEW ④ 콘솔 기동(오버레이 서버 · 재생기 · 핫키 · 엔진) ⑤ 브라우저 탭 열기까지 한다. 약 5초 뒤 탭이 뜨면 「프리플라이트 → 지금 점검」을 누르고 **FAIL 0** 인지 본다 (WARN 2 는 정상 — 1부 커버리지 미정 · 타임라인 샘플). FAIL 이 있으면 그 줄을 읽고 고친 뒤 다시.

OBS 는 `Untitled` 프로필 그대로 — Audio Input Capture 모니터링 Enabled · 모니터링 장치 Buds. **Scene Collection 이 `Live` 인지 본다** (상단 메뉴 Scene Collection). 컬렉션은 둘이다 — **9/25 실제 생성·파일 확인** (9/20 에 계획만 적혀 있었고 실제로는 `Untitled` 하나였다). Desktop Audio·Mic/Aux 장치는 컬렉션에 저장되므로 고르는 것만으로 바뀐다. ⚠️ **장치를 바꾸기 전에 반드시 컬렉션부터 전환한다** — 켜진 컬렉션의 값이 덮어써진다 (9/25 복제 전에 바꿔 녹화용까지 방송용이 됐다):

| Scene Collection | Desktop Audio | Mic/Aux | 언제 |
|---|---|---|---|
| **`Live`** | Speaker (Realtek) — Buds 로 두면 CoMC 소리가 두 번 난다 | Motiv Mix (Shure) | 라이브 방송 |
| `Recording` | Headphones (Galaxy Buds2 Pro) | Microphone Array (내장) | 마이크 없이 화면+유튜브 소리+목소리 녹화 |

📌 **매주 방송 전 — `Live` 의 채팅 Browser 소스 URL 을 이번 주 방송 ID 로 바꾼다** (`https://studio.youtube.com/live_chat?is_popout=1&v=<방송ID>`). 9/25 확인 때 지난 방송 ID(`o7EdTYymoRs`)가 남아 있었다. `CoMC-Test` 컬렉션은 영상 소스가 없어 쓰지 않는다.

⚠️ Motiv Mix 는 USB 를 꽂아야 목록에 나온다 — 꽂기 전에 `Live` 를 열면 Mic/Aux 가 비어 보인다. **Buds 마이크(Headset)는 어느 쪽에서도 고르지 않는다** — 고르는 순간 블루투스가 통화 모드로 바뀌어 Buds 출력 음질이 떨어지고 Desktop Audio 캡처가 끊긴다 (9/20 Live #28 이어폰 무음의 유력 원인). 영상을 틀 회차면 `Live` 에서 Desktop Audio 를 Buds 로 되돌린다.

⚠️ **OBS 가 먼저 켜져 있었다면** Browser Source 가 서버 없는 상태로 굳어 오버레이가 안 보인다 (9/17 실사고 15). Sources 에서 「Co-MC 오버레이」 클릭 → 소스 툴바 **Refresh**. 순서를 `start_comc.ps1` → OBS 로 하면 이 일이 없다. 「Co-MC 오버레이」가 2개면 하나는 눈을 꺼 둔다 (겹치면 글자가 두꺼워진다).

## 2. 말 시키기

콘솔 탭 「질문」 칸에 한 줄 치고 **Enter** (Shift+Enter 는 줄바꿈). 「이 파트 뭐 다뤄요?」「첫 항목이 뭐죠?」 버튼은 현재 파트에 맞춘 질문을 바로 보낸다.

```
오늘 2부에서 뭘 다루나요?
```

약 5초 뒤 「오버레이」 칸과 「결과」 목록에 답이 뜬다. 결과는 세 가지 중 하나다:

| 결과 | 뜻 | 할 일 |
|---|---|---|
| 답이 뜬다 | 근거 있음, 게이트 통과 | REVIEW 면 화면만 · LIVE 면 소리도 |
| **「비어 있음 — 침묵」** | 근거 없음 / 다른 파트 질문 / 못 알아들음 → 침묵. 결과 줄에 `⛔ 04 …` 사유가 붙는다 | 내가 직접 답하거나 질문을 바꿔 친다. 앱이 틀린 게 아니라 **말하지 않기로 한 것** |
| 결과 줄에 `hitl` · `completion_confusion` | 모호해서 멈춤 (예: 이미 완료된 항목?) | 질문을 구체적으로 다시 |

**소리를 내려면 모드가 LIVE 여야 한다.** REVIEW 에서 뜬 답을 그 한 번만 소리로 내보내려면 「**대기 발화 승인 → 소리**」 버튼 (답이 대기 중일 때만 보인다).

## 2-b. 코엠씨 캐주얼 — 방송 내용 밖의 말 (CVL 4, 2026-09-17)

방송 내용(오늘 뭘 하나)은 Rundown 만 근거로 짧고 정확하게 — 그건 그대로다. 그 밖에 **주간 맥락·날씨·잡담·시청자 인사**는 두 번째 근거 풀 「캐주얼 브리프」(이번 주 Weekly Progress · Daily Roundup · Journal 구술 · 지난 방송 기록 · Open-Meteo 날씨)로 말한다. `start_comc.ps1` 이 방송 전에 만들고, 탭의 「캐주얼 브리프」 카드에 근거 수·날씨가 보인다. 날씨를 새로 받으려면 「다시 만들기」.

| 하고 싶은 것 | 치는 말 (버튼 있음) | 길이 |
|---|---|---|
| 날씨 | `오늘 서울이랑 시애틀 날씨는 어때요?` | ≈10초 |
| 이번 주 한 일 | `이번 주에 뭘 했어요?` | ≈50초 |
| 인사이트 | `이번 주 인사이트가 뭐예요?` | ≈50초 |
| **잠깐 자리 비움** | `잠깐 물 마시고 올게요. 그동안 시청자분들께 재미있는 얘기 해 주세요` / `니가 진행하고 있어` | **≈50초** (450자 상한) |
| 지금까지·남은 일 | `잠깐 볼일 보고 올게요. 지금까지 한 일과 앞으로 남은 일을 설명해 주세요` | ≈50초 |
| **시청자 언급** | 「시청자 언급」 버튼 → 계정 이름 입력 (또는 `압구정메디에튜 님이 댓글 남겨 주셨어요. 감사 인사 해 주세요`) | ≈10초 |
| 영어로 | 아무 질문 끝에 `영어로 답해 주세요` | 영어 목소리(Jenny)로 나감 |
| **🌏 15개 국어 자기소개 (샘플)** | 버튼 (확인창) 또는 `15개 국어로 소개해 주세요` | **15개 언어 · 약 2분** — 방송 중간 시연용. 「안녕하세요, 저는 Catch Up AI 라이브의 AI 부MC 코엠씨입니다. 만나서 반갑습니다.」 언어마다 오버레이. 패닉으로 중단 |
| **🌏 시그니처 끝인사** | 버튼 (확인창) 또는 `끝인사 해 주세요` | **15개 언어 · 2분 16초** — 배경음악 위로. 언어마다 오버레이에 그 언어 줄. 패닉으로 중단 |

- 단골 시청자 메모는 `07-CoMC-Engine-POC/output/private/viewers.json` 에 `"계정이름": "한 줄 메모"` 로 적어 두면 코엠씨가 덧붙인다 (없는 분은 이름만 부른다). 이 폴더는 공개 레포에 안 올라간다
- 잡담 소재를 미리 주고 싶으면 Rundown 에 `## 코엠씨 잡담 소재` 섹션을 만들고 불릿으로 적는다 — 브리프가 읽는다
- 긴 발화(≈50초)는 **패닉**으로 언제든 끊는다. LIVE 면 바로 소리, REVIEW 면 승인 뒤 소리
- 다국어 대본·번역은 `output/private/signoff.json`(끝인사) · `intro.json`(자기소개) — 고치면 `python signoff_build.py [--set intro]` 로 바뀐 줄만 다시 합성 (방송 중엔 합성 안 함, 미리 만든 mp3 를 튼다). 순서는 한국어 → 총 화자 수 순 (English · 中文 · हिन्दी · Español · Français · العربية · বাংলা · Português · Русский · اردو · Bahasa Indonesia · Deutsch · 日本語 · Tiếng Việt)
- 코엠씨가 아는 것은 브리프에 있는 것뿐이다 — 「이번 주 기록에 없는 것」은 말하지 않는다 (침묵이 정답)

## 3. 모드 — 버튼 또는 핫키

| 버튼 / 키 | 뜻 |
|---|---|
| **REVIEW · 화면만** / Ctrl+Alt+R | 화면만, 소리 없음 (기본) |
| **LIVE · 소리** / Ctrl+Alt+L | 답이 곧바로 소리로 나간다 (**2부 CoMC 구간에서만**) |
| **MUTE** / Ctrl+Alt+M | 화면만, 소리 없음, 재생 중이면 즉시 끊김 |
| **■ 패닉** / Ctrl+Alt+Space | 재생 즉시 끊고 MUTE 로. ⚠️ **다시 소리를 내려면 LIVE 버튼(또는 Ctrl+Alt+L)** — REVIEW 는 화면만이라 소리가 안 난다 (9/17 연습에서 헷갈린 지점) |
| 파트 버튼 / Ctrl+Alt+1~9 · ← → | 파트 이동 — 엔진이 다음 질문 전에 컨텍스트를 다시 만든다. 지금 파트는 흰 테두리 |

핫키는 콘솔 프로세스 안에서 등록된다 — 별도 창이 없으니 「핫키 창이 죽었나」를 볼 필요가 없다. 로그에 `hotkeys 15개 등록` 이 있으면 살아 있는 것이다.

## 4. 멈추기

| 상황 | 방법 |
|---|---|
| **지금 말하는 걸 당장 끊기** | **■ 패닉** 버튼 또는 Ctrl+Alt+Space (MUTE 버튼도 같다). 재생기가 수십 ms 안에 끊는다 — 9/17 콘솔 실측: 재생 3.9초 시점 패닉 → `⛔ 중단 … mode=MUTE` |
| 소리만 끄고 화면은 계속 | REVIEW — 이것도 재생 중이면 끊긴다 |
| OBS 에서 AI 소리만 뮤트 | 믹서 「Audio Input Capture」 스피커 아이콘 (진행자 목소리는 그대로) |
| **자막(오버레이)만 치우기** | 오버레이 칸 오른쪽 **「화면 지우기」** 버튼 — 소리·모드는 그대로. 급하면 OBS 「Co-MC 오버레이」 눈 아이콘 |
| 앱 전부 종료 | PowerShell 창에서 **Ctrl+C** 한 번. 오버레이 서버도 같이 꺼지므로 OBS 오버레이가 사라진다 |

⚠️ **Space 만 누르지 않는다** (9/26 리허설) — 패닉 핫키는 **Ctrl+Alt+Space** 다. 콘솔 탭에서 Space 만 누르면 브라우저가 **마지막에 누른 버튼을 다시 누른다** — 「15개 국어」는 확인 창이 떠서 멈췄지만 날씨·이번 주 한 일 같은 버튼이면 확인 없이 바로 말을 시작한다. 9/26 콘솔 수정: 버튼은 누르는 즉시 포커스를 놓고, 버튼 위의 Space·Enter 는 무시한다(콘솔 재시작 후 적용). 화면 안내 문구도 「Ctrl+Alt+Space = 패닉」으로 고쳤다.

## 5. 방송 후

`07-CoMC-Engine-POC/output/` 의 `daemon_latency.json` · `session_trace.jsonl` · `spoken_log.jsonl` 을 `output/debug/live28/` 로 옮기고, Rundown 「방송 후 기록」에 CoMC 한 줄(시도/통과/침묵/사고). 사고가 있으면 [incident-classification.md](incident-classification.md) 에 번호를 붙인다. 콘솔 탭의 「결과」 목록은 프로세스를 끄면 사라지니, 남길 게 있으면 끄기 전에 본다.

## 자주 걸리는 것

- **소리가 안 난다** → 배지가 LIVE 인가 — 패닉 뒤 REVIEW 를 눌렀으면 화면만 나온다, **LIVE** 를 누른다 · 로그에 `player ⛔` 가 있나 · OBS 모니터링 장치가 Buds 인가
- **질문했는데 「비어 있음」이고 결과 줄에 `⛔ 04 unknown`** → ③ 이 질문으로 못 알아들은 것. 「~뭐예요 / 어디까지 / 설명해 주세요 / 알려 주세요」 꼴로 다시. 새 말투가 자주 걸리면 `03_classify_intent.py` INTENT_RULES 에 추가하고 콘솔 재시작 (Ctrl+C → 다시 `comc`)
- **소리가 두 번 난다** → Scene Collection 이 `Recording` 이거나 Desktop Audio 가 Buds 로 되돌아가 있다 → `Live` 로 / Realtek 으로
- **마이크 막대가 안 움직인다** → Mic/Aux 가 안 꽂힌 장치를 가리킨다 (Motiv 미연결) → Motiv 를 꽂거나, 녹화라면 `Recording` 컬렉션(내장 마이크)
- **답이 후보를 말한다 / 상태를 안 말한다** → Rundown 이 앱이 읽는 형식인지 (`rundown-writer` 스킬 「CoMC 앱이 읽는 방식」)
- **파트 바꿨는데 옛 파트 얘기를 한다** → 상단 「파트」 표시가 바뀌었는지. 콘솔 버튼과 핫키는 같은 `session_state.json` 을 바꾼다
- **너무 길게 말한다** → `safety_policy.json` `length_hardcut.max_chars` (원본 + `data/` 사본 둘 다)
- **탭을 닫아 버렸다** → 브라우저에서 `http://127.0.0.1:8778/` 다시 열면 된다. 프로세스는 PowerShell 창에 그대로 있다
