# 금칙 섹션 목록

**모듈**: M1 - 개념 정의와 Rundown 파싱 계약
**실습**: 실습 3 — 금칙 섹션 목록화 (안전장치 1: 컨텍스트 진입 차단의 입력)

---

## 원칙

안전장치 1층("컨텍스트 진입 차단")은 아래 섹션을 **파싱 단계에서 파서 출력(`rundown_index.json`)의 `excluded_sections[]`로 분리**하고, LLM 프롬프트 조립 단계에서 애초에 포함하지 않는다. "말하지 마"라고 프롬프트에 지시하는 방식은 채택하지 않는다 — 지시가 아니라 **입력 자체에서 제거**하는 것이 방어다.

## 확인한 실제 사례 (Live21 Rundown 기준)

| #   | 섹션 헤딩                        | 왜 금칙인가                                                                                                                                                                                   |
| --- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `## 보류된 인사이트 후보 (이번 방송 미편성)` | 헤딩 자체에 "미편성"이 명시됨 — 이번 회차에서 다루지 않기로 확정한 내용. 발화되면 아직 정리되지 않은 개인 생각이 방송에 그대로 나가는 사고가 된다 (예: "AI는 일을 줄이는가" 항목은 사용자 자신의 burn-out 경험 초안)                                                      |
| 2   | `## 주간 영상 후보 (이번 방송 코너 미편성)` | "미편성"이 헤딩에 명시. 제작 중단(`ai-workload-0728`) 같은 내부 상태 정보까지 포함되어 있어, 그대로 발화되면 시청자에게 혼란스러운 내부 사정이 노출된다                                                                                         |
| 3   | `### 대기 목록 (시간이 남으면)`        | Live21에서는 다른 두 섹션과 성격이 다르다 — **완전 금칙이 아니라 조건부 발화 허용**(시간이 남으면 진행). `coverage_state="directive"`로 분류하고, `current_part_id`가 3부이고 남은 시간 여유가 있을 때만 화이트리스트에 편입하는 별도 규칙이 필요함(M3에서 조건부 로직으로 설계) |

## 파서 규칙 (초안)

1. 헤딩 텍스트에 `미편성`, `보류`, `후보`(단, "주간 영상 후보"처럼 상태 컬럼이 있는 표는 통째로 후보 표로 판정) 키워드가 있으면 `excluded_sections[]`로 분류하고 `reason: "unscheduled"` 태그를 붙인다.
2. `### 대기 목록`처럼 **조건부 안내 문구가 붙은 섹션**은 완전 배제(`excluded`)가 아니라 `conditional_sections[]`로 별도 분리하고, 조건(`시간이 남으면`)을 문자열 그대로 보존한다 — 이후 M3에서 이 조건을 규칙으로 기계화한다.
3. 두 목록 모두 `answer_draft.json` 생성 단계(파이프라인 4단계 컨텍스트 조립)에서 LLM 프롬프트에 절대 포함하지 않는다.

## 실증되지 않은 패턴

계획서는 "금칙 섹션"을 3종 이상 확보하는 것을 DoD로 요구했다. 이번 대조에서는 Live21 한 회차에서 3종(보류 인사이트/주간 영상 후보/대기 목록)을 모두 확인했다. 다른 회차(Live14, Live17, Live19, Live20)에도 유사 섹션이 반복 등장하는지는 이번 세션 범위에서는 확인하지 않았다 — 필요 시 M3에서 전체 회차 스캔으로 확장한다.
