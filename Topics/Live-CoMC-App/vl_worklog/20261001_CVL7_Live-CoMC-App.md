## 📚 진행 내용

### 말투와 캐릭터 선택

[personas.json](../07-CoMC-Engine-POC/data/personas.json)에 기본 코엠씨, 고등학생 하늘, 아나운서 지망 대학생 다온, 프로 아나운서 서연, 진행자의 친구 지우를 정의했다. 이름·가상 나이·배경·존댓말 또는 반말·문장 길이·유머·표현·피할 말을 편집할 수 있으며, 모두 실제 인물이 아닌 AI 가상 캐릭터로 표시한다. 커버리지 목록을 기계적으로 낭독하지 않도록 생성 지침을 보완하고 자기소개는 날씨 브리핑 없이도 동작하게 했다.

콘솔에서 방송 중에도 선택할 수 있고 다음 답변부터 적용한다. [persona_store.py](../07-CoMC-Engine-POC/src/persona_store.py)는 선택과 정의 해시를 요청 시점에 고정하므로 생성 도중 변경하거나 승인 대기 후 변경해도 이미 만든 답변의 말투·음성은 바뀌지 않는다. 선택은 재시작 후 유지되며 콘솔 결과와 OBS에도 AI Persona 이름을 표시한다.

### 음성과 근거 보존

네 캐릭터에 한국어·영어 Edge TTS 음성과 속도·피치를 연결했다. 다온과 지우는 한국어 InJoon 음성을 공유하지만 속도·피치가 다르며, 기본 Persona는 기존 콘솔의 TTS 선택을 유지한다. 합성마다 설정을 적용하고 성공·실패 후 복원한다. → [운영 방법과 음성 표](../10-Live-Rehearsal-Capstone/guides/operator-guide.md#persona-선택-cvl7--2026-10-01) · [Edge TTS 공식 저장소](https://github.com/rany2/edge-tts)

Persona는 말투를 바꾸며 기존 근거·숫자·이름·커버리지·진행 상태 검사를 그대로 거친다. 친구의 진행자 과거 이야기 요청은 실제 볼트 근거로 제한하고 웹·창작으로 우회하지 못하게 했다. 실존 인물 행세, AI 표시 없는 자기소개, 지어낸 공동 경험을 추가 검사하며 비상 중지·반복·진행 명령은 Persona 설정 오류에도 동작한다. 패턴 검사만으로 모든 문장의 의미 보존을 증명할 수는 없으므로 실제 운영에서는 REVIEW로 내용을 확인한다.

### 회차 기록과 반응 메모

회차별 선택·렌더링·실제 재생 완료 이력과 반응 메모를 `output/private/personas/state.json`에 저장한다. 승인 대기·음소거·중단·실패를 재생 완료로 기록하지 않으며, 파일 잠금과 원자적 저장을 기존 시청자 저장 방식과 함께 사용한다. 실제 볼트 검색을 포함한 리허설 결과와 음성 샘플도 무시되는 비공개 출력 경로에만 저장했다.

## 🐛 문제 해결 로그

같은 근거로 네 Persona를 비교하면서 ‘개발 검증 완료’와 ‘운영 확인 미완료’가 혼동될 수 있는 원문을 발견했다. 기존 CVL6 기록을 ‘전체 DoD 8개 중 7개 달성, 실제 출력 장치와 다음 라이브 확인은 남음’으로 명확히 고치고 생성 지침에도 상태 보존을 추가했다. 수정 후 채택된 답변의 숫자·남은 운영 확인을 사람이 비교했으며, 정규식 검증의 의미 판단 한계도 운영 안내에 명시했다.

기본 Persona가 콘솔의 기존 TTS 설정을 덮어쓰는 문제를 수정했고 실패 시 음성 설정 복원을 검증했다. 반말의 정상 종결을 허용하는 기존 검사를 유지하면서 ‘다요’와 허구 숫자 차단도 확인했다. 문장 부호가 빠진 초안에는 단어·사실을 바꾸지 않고 종결 부호만 추가하도록 보완했다.

실제 친구 과거 이야기 검색에서는 생성된 세 문장이 근거 불일치·출처 표시 누락으로 모두 차단됐다. 이 경우 답변과 음성을 내보내지 않았으며, 볼트 이야기가 항상 성공적으로 생성된다고 판정하지 않았다. 이 검색 품질은 REVIEW 운영에서 추가 확인할 항목이다.

| 검증 | 결과 |

| 실제 Edge TTS 합성 | 네 캐릭터 × 한국어·영어 = 8개 파일 생성 |
| 실제 모델 네 캐릭터 비교 | 모두 부분 통과, 채택 문장의 사실·상태·말투 비교 확인 |

## 💡 Daily Retrospective

캐릭터 스타일과 사실 검증을 함께 유지하려면 요청 시점 정의를 고정하고 재생 완료를 별도 기록하는 것이 필요했다. 실제 모델 비교는 근거 문구의 모호함과 패턴 검사의 한계를 드러냈으며, 자연스러운 목소리의 최종 판단은 진행자 청취가 남아 있다.

다음 운영 확인은 CoMC를 재시작해 Persona를 고르고 ‘자기소개’를 요청한 뒤 REVIEW 내용을 확인하고 승인해 듣는 순서로 진행한다. 친구의 과거 이야기에는 근거와 출처 표시를 특히 확인하며, 라이브 이후 회차 반응 메모를 남긴다. CVL5 사고 손질과 Motiv Mix 재검증은 이번 구현 범위에 포함하지 않았다.
