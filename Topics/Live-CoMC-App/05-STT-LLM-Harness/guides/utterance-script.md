# M5 실습 1 — 한국어 WER 측정용 낭독 스크립트

**모듈**: M5 - STT + 멀티 LLM 하네스
**용도**: `gpt-live-transcribe` 한국어 WER 실측의 정답(ground truth) 세트
**문장 수**: 20개 (질문형 10 + 명령형 10)

---

## 왜 이 문장들인가

공개된 WER 수치는 대부분 영어 기준이고, 깨끗한 낭독체 데이터셋에서 잰 값이다. 이 방송의 실제 조건은 그것과 세 가지가 다르다.

1. **한국어다.** 조사·어미 변화가 많아 영어 WER을 그대로 가져다 쓸 수 없다.
2. **영어 기술 용어가 한국어 문장에 섞인다.** `RAG`, `Remotion`, `API`, `FDE` 같은 단어가 한국어 발음으로 나온다. 전사기가 가장 자주 틀리는 지점이 여기다.
3. **호출어 `코엠씨`가 들어간다.** M4에서 확인했듯 이건 사전에 없는 단어라 전사기가 임의로 바꿔 쓴다.

그래서 이 세트는 **일부러 어렵게** 만들었다. 쉬운 문장으로 재면 실제 방송에서 무너진다.

## 두 가지 조건에서 각각 녹음한다

| 조건 | 설명 | 출력 폴더 |
|---|---|---|
| `clean` | 조용한 환경, BGM 없음 | `examples/utterances/clean/` |
| `bgm` | 방송에서 쓰는 BGM을 평소 볼륨으로 재생하며 녹음 | `examples/utterances/bgm/` |

두 조건의 WER 차이가 곧 **"BGM을 켠 채로 이 파이프라인을 돌려도 되는가"**에 대한 답이다.

## 녹음 방법

```bash
cd 05-STT-LLM-Harness/examples

# 0) 장치 신원부터 확인한다 — 인덱스는 매번 바뀐다 (M4 함정 4)
python record_utterances.py --list-devices

# 1) 조용한 조건
python record_utterances.py --device "MV7" --condition clean

# 2) BGM 조건 — 같은 명령에 조건만 바꾸고, BGM을 평소 방송 볼륨으로 재생하며 낭독
python record_utterances.py --device "MV7" --condition bgm
```

### 낭독 시 지킬 것

- **평소 방송하듯이 읽는다.** 또박또박 읽으면 WER이 실제보다 좋게 나와서 측정 의미가 없어진다
- 문장 앞뒤로 0.5초 정도 여유를 둔다 — 창 경계에서 잘리면 그 문장은 버려야 한다
- 틀리면 그 문장만 다시 녹음한다: `--only 07` 처럼 번호를 지정한다
- 두 조건 모두 **같은 마이크·같은 거리·같은 게인**으로 녹음한다. 조건 외의 변수가 섞이면 비교가 무의미하다

### M4에서 배운 주의사항

- 장치는 **이름으로 지정**한다. 인덱스는 같은 세션에서도 밀린다 (MV7이 1→22→3→1로 바뀐 사례)
- 이 스크립트는 스트림을 **세션당 한 번만 연다.** 문장마다 열고 닫으면 장치 오픈 지연 4~9초가 매번 붙는다
