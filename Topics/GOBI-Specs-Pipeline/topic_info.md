# CUA_VL Topic Info: GOBI-Specs-Pipeline

## 📌 Topic 기본 정보

**Topic 이름**: `GOBI-Specs-Pipeline`

**Topic 설명**:
`gobi-ai/gobi-monorepo`의 `/specs` 구조와 `gobi-ai/docs` 레포를 통해 `docs.gobihq.com`으로 deploy되는 GOBI 문서화 파이프라인 전체를 이해하고, Vibe Guiding 프로젝트를 어떻게 접목하거나 활용할지 방향을 결정하기 위한 학습

**학습 목적**:
- gobi-monorepo/specs의 파일 구조, 포맷, 작성 방식 파악
- gobi-ai/docs 레포가 specs를 어떻게 받아서 docs.gobihq.com으로 deploy하는지 이해
- 현재 파이프라인에 VibeLearn AI / Vibe Guiding을 접목할 수 있는 접점 파악
- Vibe Guiding을 현재 파이프라인과 통합할지, 별도로 운영할지 결정할 근거 마련
- 장기 목표: GOBI Desktop / Gobi Space 앱에서 Vibe Guiding이 실시간으로 가동되는 구조 설계

**예상 학습 기간**: 2주 (주당 4-6시간)

---

## 🎯 학습 목표

- [ ] gobi-monorepo/specs 의 디렉토리 구조와 파일 포맷을 파악한다
- [ ] 각 spec 파일이 어떤 내용을 담고 있는지 설명할 수 있다
- [ ] gobi-ai/docs 레포의 구조와 deploy 메커니즘을 이해한다
- [ ] docs.gobihq.com 의 현재 콘텐츠와 구성을 파악한다
- [ ] 현재 파이프라인에서 Vibe Guiding 접목 가능한 지점 3개 이상을 식별한다
- [ ] Vibe Guiding 프로젝트 접근 방식(통합 vs 별도)에 대한 의견을 정리한다
