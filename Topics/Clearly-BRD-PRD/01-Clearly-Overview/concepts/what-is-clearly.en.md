# What is Clearly?

> **[← Korean Version](what-is-clearly.md)**

## One-Line Definition

> **Clearly** is a platform that generates BRD (Business Requirements Document) and PRD (Product Requirements Document) through an AI-powered Q&A wizard.

---

## Core Value

**"Clear requirements = better AI-generated code"**

In the age of AI coding, the quality of your requirements determines the quality of your output. Clearly makes it easy for anyone to write professional requirements documents.

---

## How It Works

### Project Creation Flow

```
Step 1: Create New Project
  ↓ Enter Project Title + Initial Idea (min. 20 characters)
Step 2: Choose Your Mode
  ↓ Select Plain Mode or Technical Mode
Step 3: AI Wizard (BRD)
  ↓ Business requirements Q&A (5+ questions)
Step 4: Generate PRD
  ↓ Elaborate on product requirements
Step 5: Export
  → Export documents or generate prompts for AI coding tools
```

---

## Two Modes

### Plain Mode
- **For**: Non-technical users, business stakeholders
- **Compatible tools**: V0, Lovable, Bubble, Replit, Bolt
- **Output**: BRD + PRD with **vibe coding prompts**
- **Characteristic**: Business-focused questions, accessible language

### Technical Mode
- **For**: Developers, technical teams
- **Compatible tools**: CLI, Cursor, Claude Code, VS Code, IDEs
- **Output**: BRD + PRD + **detailed technical task lists**
- **Characteristic**: Sprint task lists, dependencies, priorities, effort estimates

## BRD Wizard Experience

BRD Wizard question flow observed through real sessions:

| Order | Question Topic | Example |
|-------|---------------|---------|
| Q1 | **Purpose** | Problem this project solves, goals to achieve |
| Q2 | **Target Audience** | Who the product is for |
| Q3+ | (Additional questions) | Features, constraints, etc. |

**Characteristics**:
- Progress indicator (e.g., 1/5+, 20%)
- 3 sample answers per question
- Conversational chat interface

---

## Core Features

### 1. AI Wizard
- Collects requirements through a conversational interface
- Organizes information systematically through step-by-step questions
- Generates a BRD draft within 5–10 minutes

### 2. Contextual Tips
- Provides explanations and sample answers for each question
- Guides understandable by non-technical users
- Supports decision-making with pros/cons explanations

### 3. Real-time Collaboration
- Invite team members (Viewer / Editor permissions)
- Real-time collaboration among stakeholders
- Single Source of Truth

---

## Relationship with Vibe Coding

Clearly is a core tool in the **Vibe Coding** workflow:

1. **Vision → Documentation**: Convert ideas into BRD/PRD with Clearly
2. **Document → Prompt**: Use the generated document as a prompt for AI coding tools
3. **Prompt → Code**: AI generates code based on clear requirements

## Getting Started

1. Go to https://www.clearlyreqs.com/
2. Log in with your Google account
3. Click "Create Project"
4. Enter Project Title + Initial Idea
5. Select Mode (Plain / Technical)
6. Answer the AI Wizard questions
7. Generate and export BRD/PRD
