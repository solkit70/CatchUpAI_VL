## Key Concepts Summary

### Clearly
AI-powered BRD/PRD generation platform. Even non-technical users can create requirements documents easily through a Q&A wizard.

### BRD vs PRD

| BRD | PRD |
|-----|-----|
| Why + What | What + How |
| Business perspective | Product/technical perspective |
| Audience: executives | Audience: development team |

### Plain Mode vs Technical Mode

| Plain Mode | Technical Mode |
|------------|----------------|
| For non-technical users | For developers |
| V0, Bubble, Replit, etc. | Cursor, Claude Code, VS Code, etc. |
| Vibe coding prompts | Detailed task lists |

### Core Principle of Vibe Coding
> **"Clear requirements = better AI-generated code"**

---

## Key Insights (The "Aha!" Moments of This Module)

1. **BRD is not a specification** — it is a strategic document that explains "why this project exists"
2. **The AI Wizard removes the blank page problem** — just answer the questions and the document is generated
3. **Plain Mode vs Technical Mode** — the same project can produce very different outputs depending on your output tool
4. **Requirements quality = AI output quality** — the most critical insight of Vibe Coding
