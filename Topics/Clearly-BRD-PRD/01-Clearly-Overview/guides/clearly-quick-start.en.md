# Clearly Quick Start Guide

> **[← Korean Version](clearly-quick-start.md)**

## Overview

This guide walks a first-time Clearly user through generating their first BRD.

**Time required**: 10–15 minutes
**What you need**: A web browser, a Google account

---

## Step 1: Access and Log In

1. Go to https://www.clearlyreqs.com/
2. Click **"Get Started"** or **"Login"**
3. Log in with your Google account

---

## Step 2: Create a New Project

Click the **"Create Project"** button on the dashboard.

### 2-1. Enter a Project Title

```
Example: Catch Up AI 2026 Homepage
```

- A simple name that identifies the project
- Keep it easy to find later in the dashboard

### 2-2. Enter the Initial Idea

```
Example: To introduce Catch Up AI's 2026 methodologies and projects
(Vibe Coding, Vibe Learning, Vibe Guiding, AI4PKM) to visitors,
helping them understand and apply AI-powered approaches for
personal knowledge management and software development.
```

- Describe the project's purpose, goals, and what you want to achieve
- **Minimum 20 characters** required
- Be as specific as possible

Click **"Next"**.

---

## Step 3: Choose a Mode

### Plain Mode
| Item | Details |
|------|---------|
| **For** | Non-technical users, business stakeholders |
| **Compatible tools** | V0, Lovable, Bubble, Replit, Bolt |
| **Output** | BRD + PRD + **Vibe Coding Prompts** |

### Technical Mode
| Item | Details |
|------|---------|
| **For** | Developers, technical teams |
| **Compatible tools** | CLI, Cursor, Claude Code, VS Code, IDEs |
| **Output** | BRD + PRD + **Detailed Task Lists** |

**How to choose**:
- Using no-code / low-code tools → **Plain Mode**
- Using a traditional IDE / coding tools → **Technical Mode**
- Not sure → **Plain Mode** (more accessible)

Click **"Create & Start BRD"**.

---

## Step 4: Complete the BRD Wizard

The AI Assistant guides you through questions one by one.

### Question Flow (Example)

| Order | Topic | Description |
|-------|-------|-------------|
| Q1 | **Purpose** | Project purpose, the problem it solves |
| Q2 | **Target Audience** | Who the product is for |
| Q3 | **Key Features** | Core functionality |
| Q4 | **Constraints** | Budget, timeline, limitations |
| Q5+ | **Additional Questions** | Varies by project |

### Tips

- **Check progress**: "Questions answered: X/5+" shown at the top
- **Use sample answers**: 3 examples provided per question
- **Perfection not required**: You can edit later

---

## Step 5: Generate and Review BRD

Once you've answered all questions, your BRD is generated.

### BRD Components

- Executive Summary
- Business Objectives
- Target Audience
- Key Requirements
- Success Metrics
- Constraints & Assumptions

### Review and Edit

- Read through the generated BRD
- Edit if needed (Edit feature)
- When satisfied, move to the next step

---

## Step 6: Generate PRD (Optional)

After completing the BRD, you can generate a PRD.

### Additional PRD Components

- Detailed Feature Specs
- User Stories
- Technical Requirements
- Implementation Details

---

## Step 7: Export

### Export Options

| Format | Use Case |
|--------|----------|
| **Markdown** | Saving documents, GitHub |
| **PDF** | Sharing, archiving |
| **Vibe Coding Prompt** | Use directly with AI coding tools |

---

## FAQ

### Q: I entered something wrong
**A**: You can edit the content using the Edit feature after the BRD is generated.

### Q: Which mode should I choose — Plain or Technical?
**A**: Choose based on the development tools you'll use. No-code tools → Plain; IDE → Technical.

### Q: Can I generate just the BRD and come back for the PRD later?
**A**: Yes, you can generate the PRD at any time after the BRD is complete.

### Q: How do I share with my team?
**A**: Invite team members with Viewer or Editor permissions using the Real-time Collaboration feature.
