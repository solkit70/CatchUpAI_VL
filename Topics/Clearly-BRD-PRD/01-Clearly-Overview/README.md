## 📝 핵심 개념 요약

### Clearly
AI 기반 BRD/PRD 생성 플랫폼. Q&A 위자드를 통해 비기술자도 쉽게 요구사항 문서 작성 가능.

### BRD vs PRD
| BRD | PRD |
|-----|-----|
| Why + What | What + How |
| 비즈니스 관점 | 제품/기술 관점 |
| 경영진 대상 | 개발팀 대상 |

### Plain Mode vs Technical Mode
| Plain Mode | Technical Mode |
|------------|----------------|
| 비기술자용 | 개발자용 |
| V0, Bubble, Replit 등 | Cursor, Claude Code, VS Code 등 |
| Vibe coding prompts | Detailed task lists |

### Vibe Coding 핵심 원칙
> **"Clear requirements = better AI-generated code"**
