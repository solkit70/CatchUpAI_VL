## 학습 개요

BigHug의 DFS Crowd Manager Training 수강 기록을 시민단체와 자원봉사 운영자를 위한 근거 기반 안내 영상으로 전환한다. Massachusetts DFS 교육은 출발점이며 실제 적용 전에는 현지 관할·시설·행사 허가 조건을 별도로 확인한다.

**기간**: 2주, 12-16시간 (스크린샷 반영 시간 별도)

| 모듈  | 내용                 |   시간 | 산출물                   |
| --- | ------------------ | ---: | --------------------- |
| M1  | 원자료 인벤토리와 증거 지도    |   2h | 01-evidence-map/      |
| M2  | 교육 핵심 개념과 적용 경계    | 2.5h | 02-concepts/          |
| M3  | 시민단체 현장 점검 시나리오    |   3h | 03-field-application/ |
| M4  | 영상 스토리와 시각 자료 계획   |   3h | 04-video-plan/        |
| M5  | Remotion 제작·검토 캡스톤 | 3-5h | 05-remotion-capstone/ |

## M1 - 원자료 인벤토리와 증거 지도

**난이도**: ⭐  **시간**: 2h  **산출물**: `01-evidence-map/`

**학습 목표**: - [ ] 원자료 4종을 목록화한다. - [ ] 주장·출처·검증 필요 여부를 구분한다. - [ ] 누락 스크린샷을 기록한다.

**핵심 개념**: 원자료 우선, 주장-근거 매핑, 관할 의존성.

**실습 과제**: 교육 정리·공유 가이드·수료증·FP-250에서 영상 후보 내용을 추출하고, BigHug 사례와 일반 안내를 분리한다.

**예상 산출물**: `concepts/evidence-map.md`, `README.md`.

**DoD**: - [ ] 원자료 연결 - [ ] 출처 없는 주장 제외 - [ ] 스크린샷 공백 기록 - [ ] 법규 확인 항목 표시 - [ ] README 갱신.

**Self-Assessment**: - [ ] 원자료와 해석을 구분한다. - [ ] AI에게 출처별 주장 추출을 지시한다. - [ ] 지역 요건을 단정하지 않는다.

**시간 배분**: 개념 25분, 추출 70분, 문서화 25분 (버퍼 포함).

**참조**: [[AI/Initiatives/BigHug/RPD KPOP Chuseok 2026/safety/2026-08-05 BigHug Crowd Manager Training#Summary|BigHug Crowd Manager Training]].

## M2 - 교육 핵심 개념과 적용 경계

**난이도**: ⭐⭐  **시간**: 2.5h  **산출물**: `02-concepts/`

**학습 목표**: - [ ] 역할·인원 산정·출구 관리를 설명한다. - [ ] 법적 수용 인원과 실제 인원을 구분한다. - [ ] 관할 확인 필요 사항을 표시한다.

**핵심 개념**: fire and life safety, occupant load, egress, exit announcement, exemption.

**실습 과제**: 1,500명 BigHug 사례 산정을 재현하고, 역할 오해와 현지 Fire Marshal 확인 문구를 작성한다.

**예상 산출물**: `concepts/core-concepts.md`, `examples/capacity-scenarios.md`, `README.md`.

**DoD**: - [ ] 5개 개념 정의 - [ ] 사례 재현 - [ ] 일반화 금지 문구 - [ ] 출처 링크 - [ ] README 갱신.

**Self-Assessment**: - [ ] 적용 범위를 설명한다. - [ ] legal capacity를 구분한다. - [ ] AI 산출물의 과도한 일반화를 찾는다.

**시간 배분**: 개념 40분, 사례 80분, 문서화 30분.

**참조**: [[AI/Initiatives/BigHug/RPD KPOP Chuseok 2026/safety/2026-08-05 Crowd Manager Training Share Guide#Core Concepts|Training Share Guide]].

## M3 - 시민단체 현장 점검 시나리오

**난이도**: ⭐⭐  **시간**: 3h  **산출물**: `03-field-application/`

**학습 목표**: - [ ] 체크리스트를 현장 행동으로 바꾼다. - [ ] 행사 전·운영 중·비상 시 역할을 나눈다. - [ ] 관할 질문을 만든다.

**핵심 개념**: clear egress, walkthrough, deficiency correction, role assignment.

**실습 과제**: FP-250을 출구·조명·소화기·안내·인원으로 묶고, 부스·줄·케이블 시나리오를 해결한다.

**예상 산출물**: `guides/nonprofit-field-checklist.md`, `examples/role-scenarios.md`, `README.md`.

**DoD**: - [ ] 5개 점검 범주 - [ ] 책임자 예시 - [ ] 부족 사항 조치 - [ ] 관할 질문 - [ ] README 갱신.

**Self-Assessment**: - [ ] 체크리스트를 동선으로 설명한다. - [ ] 안전 시나리오를 AI에 요청한다. - [ ] 승인 요건과 교육 예시를 구분한다.

**시간 배분**: 개념 35분, 시나리오 110분, 문서화 35분.

## M4 - 영상 스토리와 시각 자료 계획
