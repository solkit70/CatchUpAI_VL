## 학습 개요

이 Roadmap은 BigHug의 DFS Crowd Manager Training 원자료를 시민단체 실무자와 자원봉사자가 자기 행사에 적용할 수 있는 정보로 번역하는 4주 과정이다. 기존 교육 분석과 한국어 영상 설계에 더해, Massachusetts DFS 공식 교육의 수강 경로와 보완 교육·계획 도구를 출처와 적용 범위까지 포함해 안내한다.

주된 1차 자료는 [[2026-09-07 DFS Training Full Screenshot Transcript|DFS Training Full Screenshot Transcript]]와 [[2026-09-07 DFS Training Screenshot Evidence Index|DFS Training Screenshot Evidence Index]]다. 수강 방법, 기간, 시험, 인증 주기처럼 변경될 수 있는 정보는 화면 기록이 아니라 Massachusetts DFS의 현재 공식 페이지를 우선한다.

이 과정의 정보 패키지는 공식 DFS 교육, 시설별 요구사항, 법률 자문 또는 행사 안전계획을 대체하지 않는다. 실제 행사를 열기 전에는 시설 운영자, 관할 fire department 또는 fire marshal, building official, 허가 기관과 적용 조건을 확인한다.

제작 순서는 한국어 기준 영상의 사실·표현·시청자 검토를 먼저 완료한 뒤 영어 현지화 영상을 만드는 방식이다. 영어판은 한국어 대본을 기계적으로 역번역하지 않으며, 같은 원문 근거와 claim ledger를 사용해 영어 공식 용어, 적용 지역, 링크, 면책 문구, 자막과 나레이션을 다시 검토한다.

### 최종 학습 기간

**4주, 총 30시간**. 기존 3주·20.5시간에서 연장했다. 공식 수강 경로의 최신성 검증, 시민단체 대상 보완 교육 비교, 안내 자료의 경계 검토, 영상·문서 패키지 검증 시간을 추가한다. 각 모듈 시간에는 약 20%의 검토·수정 버퍼가 포함된다.

### 학습 목표

- [ ] Massachusetts DFS Crowd Manager Training의 목적, 적용 범위, 수강·시험·수료 흐름을 공식 출처와 원자료로 구분해 설명한다.
- [ ] 시민단체 실무자와 자원봉사자가 DFS 공식 교육을 찾고 현재 수강 절차를 확인할 수 있는 한국어 안내를 만든다.
- [ ] legal capacity, occupant load, Crowd Manager 배치, egress와 일일 점검을 Massachusetts 맥락과 지역별 확인 사항으로 나누어 설명한다.
- [ ] 개장 전 점검과 행사 중 인원·출구·안내 운영을 시민단체 현장 체크리스트와 역할표로 전환한다.
- [ ] FEMA IS-15.B, CISA Mass Gathering Security Planning Tool, First Aid/CPR/AED 등 보완 자료의 목적·대상·한계를 비교해 선택 기준을 제공한다.
- [ ] 시민단체의 의사결정을 돕는 한국어 안내 문서, 리소스 경로, 검증 가능한 영상 슬라이드 플랜과 Remotion handoff을 완성한다.
- [ ] 한국어 기준 대본과 장면 ID별 영어 현지화 준비 패키지(용어집, 출처 매핑, 영문 대본 구조, 자막·나레이션 QA 기준)를 완성한다.

### 정보 제공 원칙과 사용 경계

| 정보 종류 | 시민단체에 제공할 내용 | 반드시 함께 표시할 경계 |
|---|---|---|
| DFS 공식 교육 | 공식 허브, 교육 목적, 수강 링크 확인 방법 | Massachusetts의 특정 시설·행사 조건에 관한 교육이며 다른 지역의 의무를 판정하지 않음 |
| DFS 책임·체크리스트 | egress, occupant load, exit announcement, 일일 점검의 의미 | 실제 적용 여부와 시설 수용 인원은 관할 기관과 Certificate of Inspection으로 확인 |
| 보완 교육 | 특별행사 계획, 보안 계획, 응급처치 역량을 위한 선택지 | DFS 인증이나 현지 허가를 대체하지 않으며 대상·수료 요건이 다름 |
| 영상·문서 | 한국어 요약, 역할표, 질문 목록, 다음 행동 | 실제 시험 재현·합격 보장·법률 자문으로 표현하지 않음 |
| 개인정보 | 익명화한 도식과 일반화한 설명 | 수료증, 이메일, 인증번호, 로그인·시험 화면은 공개하지 않음 |

### DFS 공식 수강 정보 안내 기준

Massachusetts DFS는 Crowd Manager 과정을 무료 온라인 교육으로 안내한다. 현재 공식 페이지는 약 40분 교육 후 시험, 70% 이상 정답 시 수료증 출력, 3년마다 교육과 시험을 포함한 재인증을 설명한다. 수강 전에는 반드시 [Crowd Manager Regulations and Training Program](https://www.mass.gov/crowd-manager-regulations-and-training-program)에서 현재 Take the Crowd Manager Online Training Program 링크와 계정·브라우저 요구사항을 확인한다.

1. 행사장과 행사 유형이 Massachusetts DFS Crowd Manager 요건에 해당할 수 있는지 시설 운영자와 관할 기관에 문의한다.
2. 해당하는 경우 DFS 공식 허브에서 현재 온라인 교육 링크를 연다.
3. 개인별 등록과 확인 절차는 해당 화면의 최신 안내를 따른다. 단체 계정을 가정하거나 오래된 기술 요구사항을 재배포하지 않는다.
4. 교육과 시험을 완료한 뒤, 수료증 보관·재인증·현장 배치 요건은 DFS와 시설의 최신 안내를 확인한다.
5. 다른 주·국가의 행사에는 현지 fire, building, permitting 기관이 제공하는 교육과 조건을 별도로 확인한다.

### M1 - 증거 지도와 공식 정보 검증

**난이도**: 1
**예상 시간**: 3시간
**산출물 폴더**: 01-Source-Map/

#### 학습 목표

- [ ] 전사, 증거 색인, BigHug 원문, Massachusetts DFS 공식 페이지의 역할을 구분한다.
- [ ] 수강 흐름과 법규·인증 주기처럼 최신 확인이 필요한 주장을 분리한다.
- [ ] 공개 가능, 맥락 필요, 비공개인 자료를 표시한 claim ledger 초안을 만든다.

#### 주요 개념

1. **1차 증거**: 수강 화면과 공식 페이지처럼 직접 사실 확인에 쓰는 자료다.
2. **최신성 검증**: 과거 화면이나 안내문을 현재 수강 절차의 유일한 근거로 쓰지 않는 절차다.
3. **claim ledger**: 모든 공개 주장에 출처, 날짜, 적용 범위, 공개 상태를 연결하는 표다.

#### 실습 과제

1. **증거-주장 연결표**: 핵심 주장 12개를 고르고 원자료·공식 페이지·추가 확인 필요로 분류해 URL 또는 로컬 문서와 확인일을 적는다. 70분. 12개 주장 모두에 근거와 공개 상태가 있으면 완료한다.
2. **공식 정보 재확인 카드**: DFS 공식 허브에서 교육 링크·FAQ·체크리스트 위치를 확인하고 확인일·화면 변경 시 행동·원자료와의 차이를 기록한다. 55분. 변경 가능 정보마다 공식 확인 경로가 있으면 완료한다.

### M2 - 적용 범위와 시민단체 역할 경계

**난이도**: 1
**예상 시간**: 3시간
**산출물 폴더**: 02-Scope-and-Roles/

#### 학습 목표

- [ ] Massachusetts DFS Crowd Manager의 책임과 비책임 업무를 구분한다.
- [ ] 100명, A-2/A-3, 음악·춤 공간 등 과정의 Massachusetts 맥락을 설명한다.
- [ ] 시민단체가 시설·관할 기관에 물어볼 확인 질문을 작성한다.

#### 주요 개념

1. **Crowd Manager 책임**: egress 유지, 수용 인원 한도 관리, exit announcement, 일일 점검처럼 fire and life safety에 관한 역할이다.
2. **적용 범위**: 교육 내용은 Massachusetts의 특정 assembly use 조건과 연결되어 있으며 모든 행사에 자동 적용되지 않는다.
3. **역할 분리**: 행사 주최자, 시설 운영자, Crowd Manager, 자원봉사자, 공연 진행자의 책임을 분명히 한다.

#### 실습 과제

1. **적용·확인 시나리오 분류**: 8개 가상 행사의 DFS 과정상 관련 여부와 현지 확인 필요 사항을 두 열로 쓰고 시설·관할 질문을 추가한다. 65분. 각 사례에 근거와 확인 질문이 있으면 완료한다.
2. **역할 경계 카드**: 역할별 책임과 escalation 대상을 적고 출구 차단·초과 입장·의료 사건 상황을 배정한다. 50분. 행사 전·중·후 각 상황에 책임자와 연락 대상이 있으면 완료한다.

### M3 - 인원 산정·동선·자원봉사자 배치

**난이도**: 2
**예상 시간**: 3.5시간
**산출물 폴더**: 03-Staffing-and-Occupant-Load/

#### 학습 목표

- [ ] Certificate of Inspection의 legal capacity와 현장 crowd count를 구별한다.
- [ ] DFS 교육의 250명 또는 그 일부마다 1명이라는 기준을 교육 맥락으로 계산한다.
- [ ] 입구·출구·공연장·운영본부의 역할과 대체 인력을 배치한다.

#### 주요 개념

1. **occupant load**: 관객뿐 아니라 직원·공연자 등 현장 인원 범주를 포함해 관리해야 하는 수치다.
2. **legal capacity**: 현장 추정이 아니라 유효한 Certificate of Inspection에서 확인하는 한도다.
3. **동선 역할표**: 인원 계수, 줄 관리, 출구 관찰, 보고를 특정 위치와 담당자에게 연결한 표다.

#### 실습 과제

1. **산정표와 가정 기록**: 8개 가상 capacity에 ceil(capacity / 250) 계산을 적용하고 capacity 출처·실제 입장 인원·현장 근무 인원을 분리한다. 75분. 모든 계산에 식·가정·관할 확인 항목이 있으면 완료한다.
2. **구역별 역할 보드**: 입구·대기열·공연장·출구·운영본부를 정하고 count 방식·보고 주기·대체 담당·접근 가능한 통로를 기록한다. 65분. 교대·휴식·비상 상황에도 보고와 동선 관찰이 비지 않으면 완료한다.

2. **영어 현지화 handoff**: 장면 ID별 원문 근거, 영어 용어, 예상 내레이션 길이, 자막 규칙, 링크, 면책 문구, 영어권 검토 필요 항목을 기록한다. 100분. 실제 영어 제작 전 확인할 항목과 승인자가 정리되면 완료한다.
