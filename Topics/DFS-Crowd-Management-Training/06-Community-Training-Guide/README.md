## M6 보완 교육과 시민단체 계획 도구

이 모듈은 DFS Crowd Manager 교육을 중심에 두되, 특별행사 계획·보안 계획·응급처치 역량을 보완할 수 있는 공식 자료를 비교한다. 어느 교육이나 도구도 시설의 법적 적용 여부, 현지 허가, 행사 안전계획, 의료 운영을 자동으로 충족하거나 대신하지 않는다.

## 사용 원칙

각 자료는 2026-09-13에 해당 기관의 공식 페이지로 확인했다. 과정 길이, 수료 조건, 대상, 도구 형식은 바뀔 수 있으므로 실제 수강·다운로드·행사 준비 시 다시 확인한다. 특정 행사가 어떤 요건을 충족해야 하는지는 시설 운영자와 local fire/building/permitting 기관, 그리고 필요 시 지정 의료 운영 주체에게 확인한다.
