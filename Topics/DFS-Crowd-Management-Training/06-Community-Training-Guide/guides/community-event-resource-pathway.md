## 리소스 선택 전에 확인할 순서

아래 경로는 교육·도구를 고르는 순서이지, 행사 진행을 승인하는 도식이 아니다. 세 시나리오 모두 시설 운영자와 local fire/building/permitting 기관의 확인으로 시작하며, 필요하면 의료 운영 주체와도 별도로 협의한다.

## 1. 소규모 실내 행사

예: 회의실 또는 커뮤니티 공간에서 진행하는 발표·식사 중심 행사.

1. **관할·시설 확인**: 시설 사용 조건, occupant load, 출구·접근성, 행사 허가 필요 여부를 운영자와 관할 기관에 묻는다.
2. **DFS 여부 확인**: 규모가 작다는 이유로 자동 면제라고 하지 않는다. 음악·춤·시설 분류 등 실제 조건이 요건과 관련될 수 있는지 [DFS Requirements FAQ](https://www.mass.gov/info-details/crowd-manager-requirements-faq)와 관할 기관으로 확인한다.
3. **계획 도구 선택**: 별도의 mass gathering 도구가 필요하다고 가정하지 않는다. 다만 역할·비상 연락·출구 안내가 필요한 경우 CISA의 질문 틀이나 내부 점검표를 계획팀 논의에 제한해 사용할 수 있다.
4. **응급처치 역량 검토**: 행사 규모·위험·참석자 특성에 맞는 대응 준비를 현지 요구와 함께 검토한다. First Aid/CPR/AED 수료는 의료 운영 배치나 허가를 대체하지 않는다.

**남는 실무 산출물**: 시설·관할 질문과 답변 기록, 행사 역할·비상 연락 카드.

## 2. 음악·춤이 있는 행사

예: live band 또는 큰 음악과 춤 공간이 있는 실내 행사.

1. **관할·시설 확인**: 시설 use group, Certificate of Inspection, occupant load, 음악·춤·운영 조건을 시설 운영자와 local fire/building 기관에 확인한다.
2. **DFS 여부 확인**: Massachusetts에서 실제 조건이 Crowd Manager 요건과 관련될 수 있으면 DFS 공식 허브에서 현재 교육 링크·FAQ·점검표를 다시 확인한다. 교육 수료 자체가 적용 여부 판정은 아니다.
3. **계획 도구 선택**: 계획팀·위험 분석·incident response의 공통 언어가 필요하면 FEMA IS-15.B를 학습 자료로 검토한다. 보안·장소·관계기관 질문을 구조화할 때 CISA 도구를 사용하되, 출력물을 안전계획 완성본으로 부르지 않는다.
4. **응급처치 역량 검토**: 응급 역할을 맡길 사람의 역량과 행사 의료 운영 필요성을 별도로 검토한다. First Aid/CPR/AED는 개인의 대응 역량을 보완하는 선택지다.

**남는 실무 산출물**: 관할 확인 기록, DFS 경로 확인일, 위험 분석 또는 CISA 검토 질문, 지정 책임자·보고선.

## 3. 야외 대규모 행사

예: 축제·공원 행사·다수의 관객과 임시 동선이 있는 행사.

1. **관할·시설 확인**: 토지·임시 구조물·교통·소방·보건·의료·허가 기관을 행사 초기에 식별하고, 각 기관의 요구 사항을 기록한다.
2. **DFS 여부 확인**: 행사에 Massachusetts DFS Crowd Manager 요건이 적용된다고 추정하지 않는다. 실내 시설이나 관련 운영이 포함된 경우에는 해당 시설별로 관할 기관에 확인한다.
3. **계획 도구 선택**: 복수 조직의 계획팀·위험 분석·incident response 논의에는 FEMA IS-15.B의 사고틀을, 장소·보안·비상계획·협업 항목 점검에는 CISA 도구를 검토한다. 두 자료 모두 현장 답사와 관계기관 협의를 대체하지 않는다.
4. **응급처치 역량 검토**: 자원봉사자 교육과 의료 운영 계획을 구분한다. 지역 요구와 위험 분석에 따라 EMS·의료 제공·응급 이송 계획의 필요 여부를 적절한 기관과 결정한다.

**남는 실무 산출물**: 관계기관 목록과 질의 결과, 위험 분석·계획 고려사항, 의료 운영 관련 결정·담당자 기록.
