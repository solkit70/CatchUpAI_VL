## 모듈 안내

Massachusetts DFS의 Crowd Manager 기준을 시민단체가 자기 행사에 적용하기 전의 확인 질문과 역할 경계로 바꾼다. 이 모듈은 규칙의 적용 여부를 판정하지 않으며, 시설 운영자와 관할 fire, building, permitting 기관에 확인할 내용을 명확히 한다.

## 학습 순서

1. [concepts/ma-scope-and-local-boundaries.md](concepts/ma-scope-and-local-boundaries.md) — Massachusetts 범위와 지역별 확인 경계
2. [examples/scenario-sorting.md](examples/scenario-sorting.md) — 8개 가상 행사의 확인 질문
3. [guides/jurisdiction-question-list.md](guides/jurisdiction-question-list.md) — 시설·관할 기관 질문 목록
4. [guides/volunteer-role-boundaries.md](guides/volunteer-role-boundaries.md) — 역할별 보고와 escalation 경계

M1에서 확정한 12개 주장과 최신성 경계를 출발점으로 사용한다. 이 모듈의 산출물은 영상에서 “해당할 수 있다”, “확인해야 한다”는 조건부 표현을 지키게 하는 근거다.
