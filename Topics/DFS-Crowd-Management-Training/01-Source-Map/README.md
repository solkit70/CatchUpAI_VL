## 모듈 안내

**모듈**: M1 — 증거 지도와 교육 흐름  
**상태**: 완료  
**예상 시간**: 3시간

이 폴더는 DFS 교육 화면, BigHug 원문, 공유 가이드를 영상 주장 단위로 연결한다. 수강 화면은 교육의 직접 기록이지만 공개 영상 자산으로 자동 승인되는 것은 아니다. 특히 계정, 수료증, 이메일, 인증번호가 보이는 화면은 원본을 쓰지 않고 익명화한 도식으로 대체한다.

2. [examples/evidence-claim-map.md](examples/evidence-claim-map.md) — 영상의 핵심 주장 12개와 원문 근거를 확인한다.

M1은 2026-09-13에 공식 허브·FAQ·FP-250 공개 자료를 다시 확인해 완료했다. 영상에는 익명화한 설명만 사용하며, 화면에 적힌 수강 링크·계정 절차·시험 구성은 현재 공식 경로로 재확인하도록 안내한다.
