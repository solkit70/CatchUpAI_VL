## 수강 여정 안내 목적

이 가이드는 영상 마지막에 넣을 “다음 행동”의 근거다. 시청자는 영상으로 개념을 익힌 뒤에도 공식 과정에서 현재 절차와 요구 사항을 직접 확인해야 한다.

## 5단계 수강 여정

1. **계정 만들기와 이메일 인증**: 공식 계정 생성 페이지에서 계정을 만들고 인증을 완료한다. 개인 이메일 화면은 영상에 쓰지 않는다.
2. **공식 과정 열기**: 로그인 후 DFS-Crowd Manager Training 2026 과정을 선택하고 course content로 들어간다.
3. **교육을 끝까지 수강**: 영상과 중간 knowledge check를 완료한다. Share Guide는 fast forward가 수강 기록에 영향을 줄 수 있다고 안내한다.
4. **현재 평가 요건 확인 후 완료**: 당시 기록에는 20문항·70% 기준이 보이지만, 수강자는 화면의 현재 기준을 직접 확인한다.
5. **수료증을 개인적으로 저장**: 당시 기록에서는 My certificates에서 다운로드했다. 수료증은 개인·행사 증빙 문서이므로 공개 영상에 사용하지 않는다.

## 영상용 안내 문구 초안

“이 영상은 DFS Crowd Manager 교육의 핵심 개념을 이해하도록 돕는 안내입니다. 실제 수강과 수료 요건은 공식 DFS 과정 화면에서 확인하고, 행사 적용 전에는 시설 관리자와 관할 소방 당국에 확인하세요.”

## 2026-09-13 공식 정보 재확인

이 가이드의 계정 생성 URL, 과정 ID `965`, 20문항, fast forward 및 My certificates 화면은 2026-08 수강 당시의 기록이다. 현재 수강 경로로 단정하지 않으며, 영상에는 로그인·시험·수료증 화면을 사용하지 않는다.

| 현재 공식 정보 | 2026-09-13 확인 결과 | 영상 처리 |
|---|---|---|
| 공식 허브 | [Crowd Manager Regulations and Training Program](https://www.mass.gov/crowd-manager-regulations-and-training-program)은 현재 온라인 교육 프로그램과 FAQ의 진입점이다. | 마지막 장면은 허브 링크와 게시 전 재확인 문구를 사용한다. |
| 적용 범위·인원 | [Requirements FAQ](https://www.mass.gov/info-details/crowd-manager-requirements-faq)는 Massachusetts의 특정 시설 맥락, 100명 이상 occupant load, 250명 또는 그 일부마다 1명의 기준을 안내한다. | 다른 관할에 자동 적용하지 않으며 시설·관할 확인을 붙인다. |
| 역할·점검 | [Crowd Managers](https://www.mass.gov/info-details/crowd-managers)는 egress, occupant load, exit announcement, 일일 점검을 안내하고, [FP-250](https://www.mass.gov/doc/fp-250-crowd-manager-fire-and-building-safety-checklist/download)은 개장 전 점검 양식이다. | 실제 화면 대신 역할·점검 도식으로 전달한다. |
| 교육·인증 | [Crowd Managers](https://www.mass.gov/info-details/crowd-managers)는 무료 온라인 교육, 약 40분, 70% 시험 통과 시 수료증 출력, 3년마다 재인증을 안내한다. | 수치에는 확인일을 붙이고 게시 직전에 공식 페이지를 다시 확인한다. |

공식 페이지는 자동 조회에서 접근 제한이 발생할 수 있으므로, 이번 확인은 DFS의 공개 검색 색인과 연결된 공식 페이지 제목·요약을 대조해 수행했다. 실제 수강 전과 영상 게시 직전에는 공식 허브를 직접 열어 교육 링크, 수강 절차, 시험·수료 요건, FAQ와 FP-250의 변경 여부를 확인한다.
