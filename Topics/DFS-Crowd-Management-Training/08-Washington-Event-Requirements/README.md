## M8 Washington 행사 요건과 역할별 교육 경로

이 모듈은 Washington주에서 시민단체가 실내·실외 행사를 준비할 때, Massachusetts DFS 과정을 일반 안전 학습 자료로 활용하는 일과 Washington의 실제 법규·허가·시설 요구 사항을 확인하는 일을 분리한다. 법적 적용은 행사 주최자 혼자, 또는 행사장 담당자 혼자 결정하는 것이 아니다. 주최 단체가 행사의 규모·운영 방식·역할을 정리하고, 시설 운영자와 관할 fire code official·허가 기관이 적용 조건과 계획을 함께 확인하는 과정이다.

## 2026-09-19 확인 기준과 경계

[WAC 51-54A-0403](https://app.leg.wa.gov/WAC/default.aspx?cite=51-54A-0403) §403.11.3은 1,000명을 **초과**하는 집회 또는 fire code official이 요구하는 경우 Crowd Manager를 두도록 한다. 이 조문은 Washington주가 운영하는 단일 Crowd Manager 수료증·과정명·유효기간을 지정하지 않는다. 따라서 “주 전체에 통용되는 Washington Crowd Manager 인증”이 있다고 단정하지 않고, 해당 시·카운티·venue·permit의 현재 교육 승인 및 증빙 조건을 확인한다.

Seattle은 주 기준을 실제 특별행사 운영에 구체화한 한 사례다. Seattle의 공개 안내는 1,000명 이상 동시 참석 예상 행사에 Public Safety Plan 제출을 요구하고, 1,000명을 초과해 모이는 시설·행사에는 250명당 최소 1명의 trained Crowd Manager를 안내한다. 이 비율과 계획 제출 방식은 Seattle 사례이며, 다른 도시·카운티·사유 venue의 자동 기준이 아니다.

이 문서는 법률 자문이나 permit application의 대체물이 아니다. 행사 날짜, 장소, 예상 동시 인원, 임시 구조물·울타리·조리·주류 판매 여부가 정해지면 해당 관할과 venue의 최신 요건을 문서로 확인한다.
