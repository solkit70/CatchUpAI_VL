## 한 행사에 여러 교육·허가가 겹칠 수 있다

시민단체 행사에서 필요한 교육이나 증빙은 “Crowd Manager 교육 하나”로 끝나지 않을 수 있다. 아래 표는 역할별로 무엇을 물어봐야 하는지 정리한 지도다. 어떤 칸도 행사 허가의 자동 승인이나 모든 자원봉사자의 의무를 뜻하지 않는다.

| 역할 또는 활동 | 확인할 공식 기준 | 누가 확인·결정하는가 | 필요한 경우의 교육·증빙 | 혼동하면 안 되는 점 |
|---|---|---|---|---|
| Crowd Manager / 안전 안내 | WAC 51-54A-0403 §403.11.3: 1,000명 초과 또는 fire code official 요구 시; local code·permit·venue 조건 | 주최 단체가 행사 정보를 제출하고 venue·관할 fire code official이 조건을 확인 | 관할 또는 venue가 승인한 교육, 행사별 emergency/public-safety plan briefing, 요구 시 수료·교육 기록 | DFS는 기본 역할 학습 자료일 수 있으나 Washington의 승인 교육을 자동 대체하지 않는다. |
| 일반 안내·입구·대기열 자원봉사자 | 행사 plan에서 맡긴 역할과 venue/permit 조건 | 주최 단체와 승인된 plan의 책임자 | 역할 오리엔테이션, 보고·911·대피·출구 방해 발견 절차 | 모두를 Crowd Manager로 부르거나, 단순 안내 역할자가 개장·수용 인원·안전계획 판단을 한다고 가정하지 않는다. |
| 공개 제공 음식의 취급 | Washington DOH는 unpackaged food, 음식 장비·utensil 또는 포장되지 않은 음식이 닿는 표면을 다루는 사람을 food worker로 설명 | local health department와 음식 운영 책임자 | 유효한 Washington Food Worker Card; local health department의 event food permit/운영 요건 확인 | 모든 행사 자원봉사자에게 필요한 카드가 아니라, 실제 food worker 역할에 관한 기준이다. 포장식품·vendor·temporary food establishment 조건은 지역 보건기관에 확인한다. |
| 비영리 특별행사의 주류 제공·판매 | WSLCB special occasion license 및 행사 형태·license 조건 | 비영리 주최 단체와 WSLCB, venue·local permit 조건 | Special Occasion License 등 해당 license; MAST 적용 여부는 행사 license와 역할에 확인 | WSLCB의 special occasion FAQ는 그 형태의 행사에서 MAST가 법적 필수는 아니지만 권장된다고 설명한다. 반면 on-premises licensed establishment에서 판매·서비스·판매 감독을 하는 사람에게는 MAST가 법적으로 요구될 수 있다. 두 경우를 같은 규칙으로 말하지 않는다. |

## 세 가지 사례로 확인하기

### 사례 A: 180명 실내 문화행사, 케이터링만 사용

주최 단체는 venue의 occupant load·출구·대관 조건과 local permit 필요 여부를 확인한다. 인원만으로 “Crowd Manager가 필요 없다”고 단정하지 않고 fire code official의 추가 요구가 있는지 묻는다. 케이터러가 음식을 운영한다면 어느 쪽이 food permit과 Food Worker Card 의무를 맡는지 계약서와 local health department 안내로 확인한다.

### 사례 B: 1,200명 야외 축제, tent·fence·음식 vendor 포함

WAC의 1,000명 초과 조건이 관련될 수 있으므로, Crowd Manager 수·교육 승인·계획과 기록 형식을 관할 fire code official에게 확인한다. site plan에는 fence, emergency vehicle route, 출입·대피 동선, tent·조리 위치를 표시한다. vendor와 주최 단체의 음식 역할을 분리하고, Seattle이면 Public Safety Plan과 Crowd Management Plan의 현재 요건을 확인한다.

### 사례 C: 비영리 모금행사, 현장에서 유료 주류 제공

Crowd Manager 질문과 별개로 WSLCB의 special occasion license 요건을 먼저 확인한다. special occasion FAQ의 MAST 안내를 이 행사 license 형태에 맞춰 읽고, venue가 더 엄격한 staff training을 요구하는지도 확인한다. 주류 서버가 있다는 사실만으로 모든 행사 자원봉사자에게 MAST가 필요하다고 말하지 않는다.

## 담당자에게 보낼 한 문장 질문

“우리 행사는 [날짜·주소]에 [최대 동시 인원]명을 예상하며 [실내/실외, tent·fence·조리·주류]를 포함합니다. Crowd Manager 배치·승인 교육·교육 기록, safety/public-safety plan 및 permit에 관한 귀 기관의 현재 요구 사항과 공식 문서 링크를 알려 주실 수 있습니까?”

이 질문에 대한 답은 행사별 기록으로 보관하고, 이 표나 Massachusetts DFS 수료증만으로 자체 판정하지 않는다.
