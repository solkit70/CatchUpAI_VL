# 워싱턴 주 녹화·녹음 관련 법률 학습

> **학습 목적**: PKM, 콘텐츠 제작, 미팅 기록 등 일상적인 녹음·녹화 활동이 워싱턴 주에서 법적으로 허용되는지 파악하고 실무 가이드라인을 도출한다.
> **참고 법률**: RCW 9.73 (Washington Privacy Act)
> **참고 자료**: RCFP Reporters Recording Guide — Washington

---

## 1. 핵심 원칙: All-Party Consent (모든 당사자 동의)

워싱턴 주는 미국에서 가장 엄격한 녹음 동의 기준을 가진 주 중 하나입니다.

| 구분 | 내용 |
|------|------|
| **연방법 (Federal Wiretap Act)** | **One-party consent** — 대화 참여자 중 한 명(자기 자신 포함)만 동의하면 녹음 가능 |
| **워싱턴 주법 (RCW 9.73.030)** | **All-party consent** — 대화에 참여하는 **모든** 사람의 동의 필요 |
| **결론** | 워싱턴 주는 연방법보다 **훨씬 엄격**. 연방법 기준으로 합법이어도 워싱턴 주에서는 불법일 수 있음 |

> 💡 미국 50개 주 중 약 12개 주가 All-party consent 주. 나머지는 one-party consent.

---

## 2. 주요 법률: RCW 9.73.030

### 기본 금지 조항

다음을 녹음·도청하는 것은 **불법**:

- **(a)** 전화·전신·전파 등 전자통신 수단을 통한 **사적 통신** — "모든 참가자의 동의 없이"
- **(b)** 어떤 녹음·전송 장치를 통한 **사적 대화** — "대화에 참여한 모든 사람의 동의 없이"

### 동의의 형태

동의를 얻는 방법은 두 가지:

1. **명시적 동의**: 각자에게 직접 동의를 받는 것
2. **고지에 의한 동의 (Constructive Consent)**: 녹음 전 모든 상대방에게 "합리적으로 효과적인 방법"으로 녹음 사실을 알리는 것 → 이후 대화를 계속하면 동의한 것으로 간주

```
예: "이 대화는 녹음됩니다." 라고 말하고 상대방이 계속 대화하면 → 동의 성립
```

### 핵심 키워드: "사적 통신 (Private Communication)"

법이 보호하는 것은 **사적 통신**입니다. 즉, **합리적인 프라이버시 기대(Reasonable Expectation of Privacy)** 가 없는 상황에서의 대화는 이 법의 적용을 받지 않을 수 있습니다.

---

## 3. 예외 조항 (동의 없이도 허용되는 경우)

RCW 9.73.030 섹션 (2)에서 규정:

| 예외 상황 | 내용 |
|-----------|------|
| **긴급 상황** | 화재, 의료 응급, 범죄, 재난 보고 관련 |
| **협박·갈취·위협** | 상대방의 불법적 언동이 포함된 통신 |
| **익명·반복·괴롭힘** | 익명 전화, 반복적 전화, 불편한 시간대 연락 |
| **인질 상황** | 바리케이드 또는 인질 관련 상황 |

### 언론인 예외 (Journalist Exception)

정규 뉴스 매체 소속 기자는 다음 중 하나가 충족되면 동의 없이 녹음 가능:
- 동의가 명시적으로 주어진 경우
- **녹음 장치가 발화자에게 명백히 보이거나 분명한 경우 (readily apparent or obvious)**

> ⚠️ 이 예외는 **정규 뉴스 매체 소속**에만 해당. 일반 유튜버·블로거에게는 자동 적용 불가.

## 4. 공공장소 vs. 사적 공간

### 핵심 기준: "합리적인 프라이버시 기대"

```
프라이버시 기대 높음 → 동의 필요
프라이버시 기대 없음 → 녹음 가능 (단, 대화 내용은 별도 판단)
```

| 장소 | 프라이버시 기대 | 녹음 가능 여부 |
|------|----------------|----------------|
| 공공 거리·공원 | 없음 | 일반적으로 가능 (촬영·녹화) |
| 공개 집회·시위 | 없음 | 가능 |
| 레스토랑·카페 (공개 발언) | 낮음 | 대체로 가능 |
| 세미나·강연 (공개 행사) | 낮음 | 대체로 가능 (단, 주최자 방침 확인) |
| 사무실·회의실 | 높음 | **동의 필요** |
| 개인 주거 공간 | 매우 높음 | **반드시 동의 필요** |
| 온라인 미팅 | 높음 | **동의 필요** |
| 학교 강의실 | 중간 (판례 불명확) | **동의 권장** |

> ⚠️ 중요: 공공장소에서 **영상 촬영**은 대체로 합법이지만, 그 안에서 주고받는 **사적 대화를 오디오로 녹음**하는 것은 별도 판단이 필요합니다.

## 5. 시나리오별 분석

### 🎙️ Limitless AI Recorder — 하루 종일 주변 녹음

**리스크 수준: 매우 높음**

| 상황 | 판단 |
|------|------|
| 혼자 독백·메모 | ✅ 합법 — 상대방 없음 |
| 가족·동거인과 대화 | ⚠️ 동의 필요 — 사적 통신 |
| 직장 동료와 대화 | ❌ 동의 없으면 불법 |
| 공공장소에서 타인의 대화 수집 | ❌ 명확히 불법 |
| 상점·카페 직원과 대화 | ⚠️ 동의 권장 |

**실용적 해결책**:
- 대화 시작 전 "이 대화는 기록됩니다"라고 말하고 계속 대화하면 동의 성립
- Limitless 앱 설정에서 "녹음 안내 문구 자동 재생" 기능 활용 검토
- 본인의 독백·사유·메모 용도로만 사용 시 문제 없음

---

### 📹 유튜버·크리에이터 — 야외 촬영, 세미나 녹화

**리스크 수준: 상황별 다름**

| 상황 | 판단 |
|------|------|
| 야외 공공장소 풍경·이벤트 촬영 | ✅ 합법 |
| 공개 시위·집회 촬영 | ✅ 합법 (First Amendment 보호) |
| 거리에서 사람 얼굴 촬영 | ✅ 합법 (공공장소 프라이버시 기대 없음) |
| 공개 세미나 주요 발표 녹화 | ✅ 대체로 합법 (주최자 방침 확인 필요) |
| 비공개·유료 세미나 무단 녹화 | ❌ 계약 위반 + 법적 위험 |
| 참석자들의 사적 대화 녹음 | ❌ 동의 없으면 불법 |
| 주최자 동의 받고 전체 녹화 | ✅ 합법 |

**권장 절차**:
1. 세미나 시작 전 주최자에게 "녹화해도 됩니까?" 확인
2. 참석자 대상 "오늘 행사는 촬영·녹음됩니다" 공지 있는지 확인
3. 공지가 없으면 개인적으로 동의 구하기

---

### 🎓 학교 강의 녹음 — 복습용

**리스크 수준: 중간 (학교 방침에 따라 다름)**

| 상황 | 판단 |
|------|------|
| 교수에게 사전 허락 받고 녹음 | ✅ 합법 |
| 교수 몰래 녹음 | ⚠️ 법적으로 불명확, 학칙 위반 가능 |
| 온라인 수업 화면 녹화 | ⚠️ 대부분 학교 방침으로 금지 + 저작권 문제 |
| ADA(장애인법) 편의제공으로 녹음 | ✅ 합법 (공식 승인 받은 경우) |

**실용적 해결책**:
- 학기 초 교수에게 이메일로 녹음 허가 요청
- "복습 목적으로만 개인 사용하겠습니다"라고 명시
- 대부분의 교수가 개인 복습 목적에는 허락

---

### 💻 온라인 미팅 — Zoom, Teams, Google Meet

**리스크 수준: 낮음 (플랫폼 기능 활용 시)**

| 상황 | 판단 |
|------|------|
| Zoom 호스트가 공식 녹화 기능 사용 | ✅ 합법 — 자동으로 참가자에게 알림 전송 |
| 내가 참가자인데 몰래 화면 녹화 | ❌ 워싱턴 주에서 불법 |
| 시작 전 "이 미팅은 녹화됩니다" 공지 | ✅ 합법 |
| AI 노트 도구 (Otter.ai 등) 사용 | ⚠️ 반드시 참가자에게 사전 고지 필요 |

**워싱턴 주에서 안전한 온라인 미팅 녹화 방법**:
```
① 미팅 시작 시: "오늘 미팅은 기록됩니다" 구두 안내
② 채팅창에: "This meeting is being recorded" 텍스트 공지
③ Zoom 호스트라면: 내장 녹화 기능 사용 (자동 동의 알림)
```

---

### 🏢 회사·업무 미팅 녹음

**리스크 수준: 중간 (고지 여부에 따라)**

| 상황 | 판단 |
|------|------|
| 미팅 시작 전 "녹음합니다" 고지 | ✅ 합법 |
| 몰래 녹음 (증거 목적 등) | ❌ 워싱턴 주에서 불법 (예외 없음) |
| 1:1 미팅을 상대 동의 없이 녹음 | ❌ 불법 |
| 회의실 AI 스피커가 자동 녹음 | ⚠️ 모든 참가자에게 고지 필요 |

> ⚠️ 워싱턴 주는 미국에서 **직장 내 비밀 녹음에 관해 가장 엄격한 주** 중 하나. 일부 주에서는 자신이 참여한 대화는 one-party consent로 녹음 가능하지만, 워싱턴은 불법.

---

### 📱 PKM 활용 — 녹음 후 AI Transcript → 지식 관리

**핵심**: 녹음의 **합법성**은 저장·활용 목적이 아니라 **녹음 행위 자체**에 달려 있음.

- 개인 메모·독백 → ✅ 합법
- 상대방 동의 받고 녹음 → ✅ 합법, AI 처리·저장 모두 가능
- 동의 없이 녹음 → ❌ 불법 (나중에 개인 PKM에만 쓰더라도)

## 6. 처벌 규정

### 형사 처벌 (RCW 9.73.080)

| 위반 | 처벌 |
|------|------|
| RCW 9.73.030 위반 (무단 녹음) | **Gross Misdemeanor** (경중죄) |
| 녹음물 불법 공개·변조 | **Gross Misdemeanor** |

**Gross Misdemeanor 처벌 수준**: 최대 364일 구금 + 최대 $5,000 벌금

### 민사 처벌 (RCW 9.73.060)

| 구분 | 금액 |
|------|------|
| 실제 손해배상 | 정신적 고통 포함 실제 피해액 |
| 법정 손해배상 (Liquidated damages) | **$100/일**, 최대 **$1,000** |
| 변호사 비용 | 승소 시 상대방이 부담 |

> ⚠️ 형사 처벌 + 민사 소송이 **동시에** 가능합니다.

## 7. 실무 가이드라인 (요약)

### 안전하게 녹음하는 7가지 원칙

```
1. 항상 먼저 고지하라
   "이 대화/미팅/강의는 녹음됩니다" → 계속 대화하면 동의 성립

2. 혼자 있을 때는 자유롭게
   독백, 메모, 사유 녹음은 문제없음

3. 공개 행사는 먼저 확인
   주최자의 녹화 방침 → 공지 있으면 OK, 없으면 문의

4. 온라인 미팅은 플랫폼 기능 활용
   Zoom 내장 녹화 기능 → 자동으로 모든 참가자에게 알림

5. 직장에서는 반드시 고지
   업무 미팅 시작 시 구두 + 채팅 공지

6. 학교에서는 교수 허가
   이메일로 학기 초에 요청, 복습 목적 명시

7. Limitless 등 ambient recorder는 신중하게
   공공장소 풍경은 OK, 타인의 사적 대화 녹음은 NG
```

### 위험도 신호등

| 색상 | 상황 |
|------|------|
| 🟢 **안전** | 내 독백, 주최자 허락 받은 공개 행사, Zoom 내장 녹화 |
| 🟡 **주의** | 공개 세미나 (방침 확인 필요), 학교 강의, 카페 대화 |
| 🔴 **위험** | 몰래 녹음, 상대방 모르게 업무 미팅 녹음, 타인 사적 대화 수집 |

## 8. 자주 묻는 질문 (FAQ)

**Q: Limitless AI로 하루 종일 녹음해서 개인 PKM에만 쓰면 괜찮지 않나요?**
A: 아니요. 워싱턴 주는 녹음의 **목적**이 아니라 **행위**를 기준으로 판단합니다. 타인과의 대화를 동의 없이 녹음하면 사용 목적에 관계없이 불법입니다.

**Q: 공공장소에서 카메라로 촬영하는 것은 합법인가요?**
A: 영상 촬영 자체는 대체로 합법입니다. 다만, 특정 개인들 사이의 사적 대화를 **오디오로 포착**하는 것은 별도로 불법일 수 있습니다.

**Q: 상대방이 나를 위협하거나 괴롭히면 몰래 녹음해도 되나요?**
A: 예, 이 경우 예외 조항이 적용됩니다. 협박·갈취·위협이 포함된 통신은 one-party consent로 녹음 가능합니다.

**Q: 온라인 수업을 캡처해서 복습용으로 쓰면요?**
A: 학교 방침과 강사 동의가 필요합니다. 방침상 금지된 경우 법적 위험 + 저작권 문제도 있습니다.

**Q: 워싱턴 주를 벗어난 출장지에서 미팅을 녹음하면?**
A: 해당 주의 법률이 적용됩니다. 예: 캘리포니아도 all-party consent 주. 뉴욕은 one-party consent.

## 9. AI 기술 발전과 법적 지형 변화

> **배경**: M1-M5 학습(2026-05-31) 이후, AI 기술이 기존 녹음법과 어떻게 충돌·진화하는지 심화 연구 (M6, 2026-06-07).

### 9-1. AI 상시 녹음 기기의 등장

Limitless AI(펜던트), Meta Ray-Ban Smart Glasses, Bee AI 등 **상시 녹음 웨어러블** 기기가 급속히 보급되고 있다. 2025년 메타 레이밴은 7백만 대가 판매됐다. 이 기기들은 일반 안경처럼 보이도록 설계되어 피촬영자가 인식하기 어려우며, 소형 표시등이 유일한 고지 수단이다. WA 주 all-party consent 원칙상, 타인과의 대화를 이 기기로 녹음하려면 **사전 동의가 필수**다. 메타는 2025년 4월 개인정보 정책을 개정해 AI 기능을 기본 활성화하고 클라우드 저장 거부 옵션을 제거해 논란이 됐다. 2026년 3월에는 케냐 하청업체 직원들이 녹화 영상을 AI 훈련에 사용했다는 집단 소송이 제기됐다.

### 9-2. AI 음성 복제와 퍼소낼리티 권리

AI TTS(Qwen3-TTS, ElevenLabs 등)를 이용한 음성 복제는 **두 가지 법률 층위**를 통과해야 한다. 녹음법(RCW 9.73)은 수집 단계를, 퍼소낼리티 권리법(RCW 63.60)은 이용·배포 단계를 각각 규율한다. **자기 목소리를 자기가 복제하는 것은 합법**이지만, 타인의 목소리를 동의 없이 복제하는 것은 RCW 63.60 위반이며 최소 $1,500 손해배상 대상이다. WA 주는 2026년 3월 SB 5886을 통해 퍼소낼리티 권리법을 AI 딥페이크에도 명시적으로 적용하는 개정을 완료했다(2026.06.11 발효). 연방 차원에서는 NO FAKES Act(H.R.2794/S.1367)가 2025년 4월 재발의되어 상원 사법위원회에 계류 중이다.

### 9-3. AI 미팅 봇과 동의 문제

Otter.ai, Fireflies.ai 같은 AI 미팅 봇은 회의에 자동 참가해 녹음·전사한다. 2025-2026년 두 건의 주요 소송이 제기됐다. Otter.ai는 계정도 없는 외부 참가자의 통화를 무단 녹음했다는 연방 집단 소송(캘리포니아 북부 연방법원)을, Fireflies.ai는 참가자의 성문(voiceprint)을 무단 생성했다는 Illinois BIPA 소송(2025.12.18)을 각각 직면하고 있다. WA 주에서 AI 봇을 안전하게 사용하려면 캘린더 초대, 미팅 시작 시 구두 안내, 채팅 공지의 **3단계 고지**가 권장된다.

### 9-5. 이해관계자 지형도

기업(Meta, OpenAI, Google)과 시민사회(EFF, ACLU)는 AI 녹음 규제의 방향을 두고 대립한다. 기업들은 연방 단일 기준을 선호하며 "기술 혁신 저해"를 이유로 강한 주별 규제에 반대한다. EFF는 NO FAKES Act의 DMCA식 통지-삭제 조항이 합법적 표현물을 삭제하는 데 악용될 수 있다고 반대하며, ACLU는 AI 기반 감시가 공공장소에서 표현의 자유를 위축시킨다고 경고한다. **공통 방향은 "금지"가 아닌 "고지·동의·데이터 범위 명확화"**로 수렴하고 있다.
