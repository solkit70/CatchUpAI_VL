# RCW 9.73.030 핵심 조항 분석

## 금지 조항 (무엇을 금지하는가)

```
RCW 9.73.030이 금지하는 것:

(a) 전화·전신 등 전자 수단을 통한 사적 통신
    → 모든 참가자 동의 없이 녹음·도청 금지

(b) 어떤 장치로든 이루어지는 사적 대화
    → 모든 참가자 동의 없이 녹음·도청 금지
```

**핵심 키워드**: "사적(private)" — 합리적인 프라이버시 기대가 있는 대화가 보호 대상.

## 예외 조항 4가지 (동의 없이도 녹음 가능한 경우)

| # | 예외 상황 | 예시 |
|---|-----------|------|
| ① | **긴급 상황** | 화재 신고, 의료 응급, 범죄 현장 보고, 재난 |
| ② | **협박·갈취·위협 통신** | 상대방이 나를 위협·협박하는 통화 |
| ③| **익명·반복 괴롭힘 전화** | 모르는 번호가 반복적으로 전화해 욕설 |
| ④ | **인질 상황** | 경찰의 인질 협상 통화 |

> ⚠️ 직장 내 부당 대우를 증거로 남기려는 목적은 예외에 해당하지 않음
> (상대가 협박·위협적 발언을 하는 경우에만 ② 적용 가능)

## 언론인 예외 (Journalist Exception)

정규 뉴스 매체 소속 기자는 녹음 장치가 **명백히 보일 때(readily apparent)** 동의 없이 녹음 가능.

> ⚠️ 유튜버·블로거·일반인에게는 **자동 적용 안 됨**

## 처벌 규정

### 형사 처벌 (RCW 9.73.080)
```
죄목: Gross Misdemeanor (경중죄)
처벌: 최대 364일 구금 + 최대 $5,000 벌금
```

### 민사 처벌 (RCW 9.73.060)
```
피해자 청구 가능 금액:
- 실제 손해배상 (정신적 고통 포함)
- 또는 $100/일, 최대 $1,000
- + 변호사비

형사와 민사 동시 진행 가능
```

### 증거 능력
불법 녹음은 법원에서 **증거로 사용 불가**.
