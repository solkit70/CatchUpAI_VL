## 🗂️ 학습 참고 메모

### 빠른 판단을 위한 핵심 암기 사항

```
워싱턴 주 = ALL-PARTY CONSENT 주
(미국 약 12개 주 중 하나)

연방법 = ONE-PARTY CONSENT
→ 연방법으로 OK여도 워싱턴 주에서 불법 가능!

처벌:
- 형사: Gross Misdemeanor (최대 364일 + $5,000)
- 민사: $100/일, 최대 $1,000 + 변호사비

동의 없어도 OK인 예외:
① 긴급 상황 (화재·의료·범죄)
② 협박·갈취·위협 통신
③ 익명·반복 괴롭힘 전화
④ 인질 상황

기자 예외: 녹음 장치가 명백히 보일 때
→ 정규 뉴스 매체 소속에만 해당!
```

### 조항-내용 매핑

```
9.73.030 → 핵심 금지 + 예외 (★ 가장 중요)
9.73.060 → 민사 처벌
9.73.070 → 적용 제외
9.73.080 → 형사 처벌
```
