# 연방법 vs 워싱턴 주법 — 녹음 동의 기준 비교

## 핵심 차이

| 항목        | 연방법 (Federal Wiretap Act) | 워싱턴 주법 (RCW 9.73)              |
| --------- | ------------------------- | ------------------------------ |
| 동의 기준     | **One-party consent**     | **All-party consent**          |
| 내가 참여한 대화 | ✅ 나만 동의하면 녹음 가능           | ❌ 상대방 동의도 필요                   |
| 상대 모르게 녹음 | ✅ 연방법상 합법                 | ❌ 워싱턴 주에서 불법                   |
| 형사 처벌 수준  | 연방 중범죄 (5년 이하 징역)         | Gross Misdemeanor (364일 이하 구금) |
| 적용 범위     | 미국 전체 최소 기준               | 워싱턴 주 거주자·워싱턴 내 대화             |

## 주법 우선 원칙

```
연방법 OK + 주법 OK → 합법
연방법 OK + 주법 X  → 워싱턴 주에서 불법 (주법 우선)
```

> 미국 38개 주 + DC = one-party consent
> 약 12개 주 (워싱턴, 캘리포니아, 플로리다 등) = all-party consent

## 실전 의미

워싱턴 주에서 생활하는 경우, 연방법 기준으로 생각하면 안 됩니다.
"내가 참여한 대화니까 녹음해도 되겠지" → **워싱턴 주에서는 틀린 생각**

## 동의를 얻는 두 가지 방법

1. **명시적 동의 (Explicit)**: "녹음해도 됩니까?" → 상대방 "네" → 동의 성립
2. **고지에 의한 동의 (Constructive)**: "이 대화는 녹음됩니다"라고 알리고 상대방이 계속 대화하면 동의 성립. 실무에서 가장 많이 쓰이는 방법.
