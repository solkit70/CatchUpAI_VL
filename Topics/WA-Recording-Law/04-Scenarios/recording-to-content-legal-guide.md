# 녹음·녹화 → 콘텐츠 제작·공개 시 법률 적용 완전 가이드

> 워싱턴 주 + 연방법 기준
> **⚠️ 법률 조언 아님 — 실제 법적 판단은 변호사 상담 권장**
> 작성일: 2026-05-31

---

## 핵심 구조: 법이 두 단계에서 따로 적용된다

```
[단계 1] 녹음·녹화 행위
          ↓
[단계 2A] 그대로 공개 (콘텐츠화)
[단계 2B] 가공해서 새 콘텐츠 제작·공개
```

**중요**: 단계 1이 합법이어도 단계 2가 불법일 수 있고,
단계 1이 불법이면 단계 2는 자동으로 더 큰 문제가 됩니다.

각 단계마다 **적용되는 법률이 다릅니다.**

---

## 단계 1: 녹음·녹화 행위

### 적용 법률

| 법률 | 관할 | 기준 |
|------|------|------|
| Federal Wiretap Act (18 U.S.C. § 2511) | 연방 | One-party consent |
| RCW 9.73.030 | 워싱턴 주 | **All-party consent** (더 엄격) |

### 판단 원칙

워싱턴 주에서는 **All-party consent** 가 적용됩니다.
모든 대화 참여자의 동의 없이 녹음하면 → 이미 이 단계에서 불법.
이후 단계가 어떻든 단계 1 위반의 형사·민사 책임은 그대로 유지됩니다.

> 단계 1이 불법이면:
> - 형사: Gross Misdemeanor (최대 364일 + $5,000)
> - 민사: $100/일 최대 $1,000 + 변호사비
> - 녹음물은 법원에서 증거로 사용 불가

## 단계 2A: 녹음·녹화한 내용을 그대로 공개하는 경우

### 적용되는 법률 (단계 1과 별개로 추가 적용)

#### ① 저작권법 (Copyright — 연방법, 17 U.S.C.)

녹음한 내용에는 **상대방의 저작권**이 존재할 수 있습니다.

| 콘텐츠 유형 | 저작권 보호 여부 | 공개 시 영향 |
|------------|----------------|------------|
| 강연·발표·연설 | ✅ 발표자 저작물 | 무단 공개 = 저작권 침해 |
| 음악 공연 | ✅ 연주자·작곡가 저작물 | 무단 공개 = 저작권 침해 |
| 영화·영상 상영 | ✅ 제작자 저작물 | 무단 공개 = 저작권 침해 |
| 일상 대화 | ⚠️ 창작성이 있으면 보호 | 회색지대 |
| 단순 사실·정보 | ❌ 저작권 없음 | 내용 자체는 공개 가능 |

**핵심**: 누군가의 강연·발표·공연을 녹화해서 그대로 YouTube에 올리면 → 저작권 침해.
설령 그 행사가 공개 행사이고 입장료도 없었어도, 저작물을 무단으로 배포하는 것은 별개 문제입니다.

**Fair Use (공정 이용, 17 U.S.C. § 107)**

저작권이 있어도 다음 4가지 요소를 고려해 fair use로 인정될 수 있습니다:

```
① 사용 목적·성격
   - 상업적 목적 → 불리
   - 비영리·교육·비평·보도·연구 → 유리
   - 변형적(transformative) 사용 → 유리

② 원저작물의 성격
   - 창작적 작품(음악, 소설) → 보호 강함
   - 사실적 정보(뉴스, 데이터) → 보호 약함

③ 사용한 분량
   - 전체 사용 → 불리
   - 일부 발췌 → 유리
   - 단, "핵심 부분" 사용 시 소량도 불리할 수 있음

④ 시장 영향
   - 원저작물 시장을 해침 → 불리
   - 시장 영향 없음 → 유리
```

> ⚠️ Fair use는 법원이 사후에 판단하는 것입니다.
> "fair use일 것 같다"고 생각하고 공개했다가 소송당할 수 있습니다.

#### ② 프라이버시 침해 불법행위 (Privacy Torts — 연방 공통법)

단계 1이 합법적이었어도(동의 받고 녹음), 공개 시 다음 프라이버시 불법행위가 적용될 수 있습니다:

| 불법행위 유형 | 내용 | 예시 |
|-------------|------|------|
| 사적 사실의 공개 (Public disclosure of private facts) | 합리적인 사람이 공개에 반대할 사적 정보를 공개 | 의료 상담 녹음을 공개 |
| 잘못된 인상 부여 (False light) | 사실이지만 오해를 일으키는 맥락으로 공개 | 대화 일부만 편집해 의도 왜곡 |
| 명예훼손 (Defamation) | 허위 사실을 공개해 명예 손상 | 발언 내용을 왜곡해 공개 |

**중요**: 사적 대화를 동의 받고 녹음했어도, 그 대화 내용을 상대방 동의 없이 공개하면 프라이버시 침해 소송이 가능합니다.

#### ③ 퍼소낼리티 권리 (Right of Publicity — 워싱턴 주 RCW 63.60)

워싱턴 주는 개인의 이름·목소리·서명·사진·초상을 **재산권**으로 보호합니다.

```
RCW 63.60.010: 개인의 이름, 목소리, 서명, 사진, 초상은
재산권이며 자유롭게 양도·라이선스 가능하다.
사망 후에도 영구적으로 유지된다.
```

**적용**: 누군가의 목소리·얼굴이 담긴 녹음을 **상업적 목적**으로 공개하면 → 퍼소낼리티 권리 침해.

**예외 (RCW 63.60.070)**: 다음 경우 동의 없이 사용 가능:
- 뉴스 보도, 공공 이슈, 역사적·교육적 목적
- 풍자(satire)·패러디
- 허구적 창작물 (오해를 일으키지 않는 경우)
- 부수적·사소한 사용

## 단계 2B: 녹음·녹화 데이터를 가공해 새 콘텐츠 제작·공개

### 가공의 스펙트럼

```
[원본 그대로] ──────────────────── [완전 변형]
    ↑                                    ↑
저작권 침해 위험 높음              Fair use 가능성 높음
프라이버시 침해 위험 높음          퍼소낼리티 권리 침해 낮음
```

### 가공 유형별 법적 판단

#### 유형 1: 편집·요약·하이라이트

녹음 원본을 편집해 짧은 클립이나 하이라이트로 만드는 경우.

| 항목 | 판단 |
|------|------|
| 저작권 | ⚠️ 원저작물 사용. 변형성이 낮으면 fair use 어려움 |
| 프라이버시 | ⚠️ 편집으로 맥락이 바뀌면 "false light" 위험 |
| 퍼소낼리티 | ⚠️ 상업적 사용이면 동의 필요 |

**사례**: 세미나 발표를 5분으로 편집해 YouTube 공개 → 저작권 침해 가능성 높음.

#### 유형 2: 비평·논평 (Commentary/Criticism)

녹음 내용을 인용하면서 자신의 의견·분석을 덧붙이는 경우.

| 항목 | 판단 |
|------|------|
| 저작권 | ✅ Fair use 가능성 높음 (비평·논평 목적) |
| 프라이버시 | ⚠️ 사적 대화 공개 시 여전히 문제 가능 |
| 퍼소낼리티 | ⚠️ 비판적 논평은 허용, 상업적 전용은 불가 |

**사례**: 강연 내용 일부 인용 + 비평 YouTube 영상 → Fair use 가능성 있음.

#### 유형 3: Transcript 활용 (AI 요약·정리)

녹음을 텍스트로 변환(transcript)해서 정리·요약하는 경우.

| 항목 | 판단 |
|------|------|
| 저작권 | ⚠️ Transcript 자체는 원저작물의 복제. 단, 요약·정리는 변형적 사용 |
| 프라이버시 | ⚠️ 내용을 공개하면 사적 사실 공개 위험 |
| 개인 사용 | ✅ 공개하지 않고 개인 PKM에만 사용하면 위험 낮음 |

**PKM 활용**: 동의 받고 녹음 → transcript → 개인 Obsidian 보관 → **합법**
공개 세미나 녹음 → transcript → 블로그 공개 → **저작권 침해 가능**

#### 유형 4: AI 생성 파생 콘텐츠

녹음 데이터를 AI에 입력해 새 콘텐츠를 만드는 경우.

| 시나리오 | 판단 |
|---------|------|
| 강연 transcript로 AI 요약 작성 → 블로그 공개 | ⚠️ 원저작물 기반 파생물. Fair use 검토 필요 |
| 누군가의 목소리 녹음으로 AI 보이스 클론 생성 | ❌ 퍼소낼리티 권리 침해 (RCW 63.60) + 동의 필요 |
| 세미나 내용 기반으로 AI가 완전히 새 글 작성 | ✅ 아이디어는 저작권 없음. 표현이 아닌 정보 활용은 일반적으로 OK |
| 회의 녹음으로 AI 회의록 작성 → 팀 내부 공유 | ✅ 참가자 동의 있으면 합법. 내부 사용은 저작권 위험 낮음 |

> **중요**: 아이디어·사실·정보는 저작권 보호 대상이 아닙니다.
> 보호되는 것은 그 아이디어를 표현한 **구체적 표현** 입니다.
> → "이 강연에서 배운 내용을 바탕으로" 내 글을 쓰는 것은 합법.
> → 강연 녹취록을 그대로 가져다 내 이름으로 올리는 것은 불법.

#### 유형 5: 뉴스 보도·다큐멘터리

공공 이익을 위한 보도·다큐 목적으로 녹음 내용을 사용하는 경우.

| 항목 | 판단 |
|------|------|
| 저작권 | ✅ Fair use 가능성 높음 (뉴스 보도 목적) |
| 프라이버시 | ✅ 공공 이익이 프라이버시보다 우선할 수 있음 |
| 퍼소낼리티 | ✅ RCW 63.60.070 뉴스·공공 이슈 예외 적용 |

**단, 조건**: 실제 공공 이익이 있어야 하고, 허위 내용이 없어야 함.

## 연방법 vs 워싱턴 주법 — 단계별 비교표

| 단계 | 적용 법률 | 연방 기준 | 워싱턴 주 기준 | 더 엄격한 쪽 |
|------|-----------|----------|--------------|------------|
| **1. 녹음·녹화** | Wiretap Act / RCW 9.73 | One-party consent | All-party consent | **워싱턴 주** |
| **2A. 그대로 공개** | 저작권법 (17 U.S.C.) | Fair use 4요소 | 동일 (연방법 적용) | 연방법 |
| **2A. 그대로 공개** | 프라이버시 불법행위 | 공통법 기준 | 공통법 기준 | 동일 |
| **2A. 그대로 공개** | 퍼소낼리티 권리 | Lanham Act (연방) | RCW 63.60 (사망 후도 영구) | **워싱턴 주** |
| **2B. 가공 콘텐츠** | 저작권 Fair Use | 4요소 판단 | 동일 (연방법) | 연방법 |
| **2B. AI 보이스 클론** | 퍼소낼리티 권리 | Lanham Act | RCW 63.60 | **워싱턴 주** |

## 실무 시나리오 매트릭스 (Creator 관점)

| 시나리오 | 단계 1 | 단계 2 | 전체 판단 |
|---------|--------|--------|---------|
| 공개 강연 녹화 → 개인 복습 | ✅ (주최자 동의) | ✅ (비공개) | **✅ 합법** |
| 공개 강연 녹화 → 그대로 YouTube | ✅ (주최자 동의) | ❌ 저작권 침해 | **❌ 불법** |
| 강연 내용 요약+비평 → YouTube | ✅ (주최자 동의) | ⚠️ Fair use 검토 | **⚠️ 조건부** |
| 강연 아이디어 참고 → 내 글 작성 | ✅ | ✅ 아이디어 저작권 없음 | **✅ 합법** |
| 회의 녹음 → AI 요약 → 팀 내부 | ✅ (참가자 동의) | ✅ 내부 사용 | **✅ 합법** |
| 동의 없이 녹음 → 편집 → 공개 | ❌ RCW 9.73 위반 | ❌ 저작권+프라이버시 | **❌ 이중 불법** |
| 인터뷰 녹음 → 팟캐스트 공개 | ✅ (인터뷰이 동의) | ✅ 공개 동의 포함이면 | **✅ 합법** |
| 강연 목소리로 AI 클론 생성 | ✅ (동의 있어도) | ❌ RCW 63.60 위반 | **❌ 불법** |
| Limitless 녹음 → transcript → PKM | ❌ (직장 타인 동의 없음) | ⚠️ 비공개지만 단계 1 위반 | **❌ 단계 1 위반** |

## Creator를 위한 안전 가이드

### 가장 안전한 방법

```
① 녹음 전: "이 대화/강연은 녹음되며 [목적]으로 활용됩니다"
   → 동의 + 목적까지 명확히

② 공개 전: "이 내용을 공개해도 됩니까?" 별도 확인
   → 녹음 동의 ≠ 공개 동의

③ 강연·발표 인용 시: 5~10초 이내 짧은 클립 + 비평·논평 추가
   → Fair use 가능성 높임

④ 절대 하지 말 것:
   - 강연 전체 무단 업로드
   - 동의 없이 얻은 목소리로 AI 클론 생성
   - 사적 대화 공개 (동의 받았어도 공개 별도 동의 필요)
```

### 공개 전 체크리스트

```
□ 녹음 단계에서 모든 참가자 동의 받았는가?
□ 공개 단계의 동의도 별도로 받았는가?
□ 저작권이 있는 내용을 그대로 사용하지 않는가?
□ Fair use 요건(비평/논평/교육/변형적 사용)이 있는가?
□ 상업적 목적으로 타인의 얼굴·목소리를 사용하는가?
□ 편집으로 발언의 맥락이 왜곡되지 않는가?
```
