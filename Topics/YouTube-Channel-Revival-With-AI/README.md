# 몰락해 가는 유튜브 채널을 데이터로 다시 본다

구독자 4,300명대에서 **다섯 달 동안 멈춰 있던 채널**을, 기억이 아니라 **API 로 받은 숫자**로 다시 본 기록입니다.

가설 다섯 개를 세우고 검증했는데 **하나는 틀렸고, 틀린 자리에서 진짜 축이 나왔습니다.**
그 과정을 결론만이 아니라 **틀린 판정과 그걸 바로잡은 경위까지** 그대로 두었습니다.

> 📅 **데이터 기준: 2026-09-10.** 이 조사는 2026-06-26 창발 발표
> [The AI Powered Creator](../The-AI-Powered-Creator/README.md) 의 **2편**입니다.
> 1편은 데이터가 2026-06-23 에서 끊겨 있고, 여기서 그 뒤 석 달을 잇습니다.

## 🔴 먼저 읽을 것

숫자를 보기 전에 **지표의 한계**부터 읽습니다. 여기 적힌 것들은 **전부 오류를 내지 않아서**,
모르면 그냥 지나갑니다.

→ [01-Data-Pipeline/concepts/metric-limitations.md](01-Data-Pipeline/concepts/metric-limitations.md)

특히 **구독 지표에는 방향이 있습니다.** 증가는 「기여의 하한선」으로만 읽고,
**감소는 원인 추적에 쓰지 않습니다** — 해지도 «누른 페이지»에 기록되기 때문입니다.

## 판정 결과

기준은 **데이터를 보기 전에** 코드에 박아 넣었습니다 (2.0배 이상 «맞다» · 1.3배 미만 «차이 없다» · 표본 5편 미만 «알 수 없다»).

| # | 가설 | 판정 | 수치 |
|---|---|---|---|
| **0** | Shorts 는 구독으로 이어지지 않는다 | ✅ **맞다** | **52.2배** |
| 1 | 자막이 구독 전환을 높인다 | ⏳ **알 수 없다** | 자막 20편 중 **공개된 건 6편** |
| 2 | 사람이 나오는 영상이 낫다 | 🔴 **틀렸다** | ~~1.71~~ → **0.86배** |
| 3 | 분할 편집이 효과가 있다 | ➖ 차이 없다 / ⭐ 사례는 강하다 | 1.21배 |
| 4 | 조회-구독 시차 | ⏳ 발표 후 | — |

**가장 아픈 숫자** — 현장에 가서 찍고, 전사하고, 번역하고, 자막까지 입힌 **지역 세미나 녹화 34편이 만든 구독자가 3명**입니다. 구독 한 명당 **11.3편**. 같은 기간 자체 제작은 **0.7편**이면 됐습니다.

## ⭐ 가설이 틀린 자리에서 나온 것

가설 2 를 다시 판정하다가, **사람이 나오는 영상 중 제일 잘된 것과 제일 안된 것이 둘 다 사람이 나오는 영상**이라는 걸 봤습니다.

| 갈래 | 사람 | 1천뷰당 구독 |
|---|:---:|---:|
| 내가 여는 행사 | ○ | **14.01** |
| 내가 조사해 만든 영상 | ✗ | **12.06** |
| 내 라이브 방송 | △ | 7.12 |
| **남이 여는 세미나** | ○ | **3.88** |

갈리는 것은 사람이 아니라 **주인**이었습니다 — 내 콘텐츠 대 남의 행사 녹화 **2.92배**.

> ⚠️ **데이터를 본 뒤에 찾은 축이라 검증한 것이 아닙니다.**
> 사전 등록 기준을 넘지만 **「가설 5, 다음에 검증」으로 적었습니다.**
> 발표에서 제일 잘 먹힐 숫자인데, 그걸 검증 결과라고 말하면 조사 전체가 무너집니다.

## 「퀄리티를 올리자」는 결정이 아니라 기간이었다

라이브 요약을 그만두고 단일 주제로 바꾼 뒤 **6주 동안 구독이 안 움직였습니다.**
그런데 같은 기간 **시청 지속률이 18.6% → 16.0% 로 떨어졌다가 27.2% 로 뛰었습니다.**

**형식을 바꾼 직후엔 오히려 서툴렀던 겁니다.** 결과 지표만 보면 「6주간 무효」이고,
선행 지표를 보면 「6주간 학습」입니다.

→ [03-Revival-Inventory/analysis/operations-1-and-2.md](03-Revival-Inventory/analysis/operations-1-and-2.md)

## ⚠️ 이 기록을 읽을 때

**AI 가 분석하고 채널 주인이 검증했습니다.** 그 과정에서 **AI 의 결론이 네 번 뒤집혔습니다.**

| | 무엇 |
|---|---|
| 오타 하나 | 기록의 `4,203` 이 `4,293` 의 오기 — 그대로 뒀으면 회복폭을 **4배로 부풀릴** 뻔했다 |
| 중복 응답 | API 가 같은 영상을 두 번 줘서 **654편으로 집계**했다가 532편으로 정정 |
| 교란 요인 | 자막 영상 대부분이 멤버 전용 — 못 봤으면 **"자막은 효과 없다"** 는 정반대 결론 |
| 학습 곡선 | *"6주간 무효"* 로 쓸 뻔한 것을 채널 주인이 **"퀄리티는 꾸준히 해야 한다"** 고 바로잡음 |

**넷 다 오류 메시지가 안 나는 종류**입니다. 그래서 이 토픽은 숫자보다 **어떻게 틀렸고 어떻게 잡았나**를 더 길게 적었습니다.
