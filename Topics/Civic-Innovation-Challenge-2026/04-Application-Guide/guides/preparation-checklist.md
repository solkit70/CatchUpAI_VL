# 준비 체크리스트와 역산 일정

마감 **2026-11-13(금) 오후 5시(태평양 시간)** 에서 거꾸로 계산한 준비 순서입니다. 공고는 **마감 전에 일찍 제출하라**고 강하게 권합니다. 서류가 빠졌을 때 연락할 시간을 두기 위해서입니다.[^submission]

## 1. 먼저 — 지원해도 될까 (5분 점검)

| # | 확인 | 예 / 아니요 |
|---|---|---|
| 1 | 18세 이상이고, 본인이나 회사를 대표해 계약할 수 있다 | |
| 2 | 사용 사례 8개(또는 King County 정책 목표) 중 내 해법이 돕는 문제가 있다 | |
| 3 | 해법이 **이미 있거나 만드는 중**이다 (최소한 시연할 수 있는 시제품) | |
| 4 | 약 30~35주 동안 **주 3~5시간**을 낼 수 있다 | |
| 5 | 최종 후보가 되면 **세금 번호(W-9/TIN)** 와 **보험 증명서**를 낼 수 있다 | |

하나라도 「아니요」면 아래 [4. 지원하기 어려운 경우](#4-지원하기-어려운-경우)를 먼저 보세요. 3번은 **클릭해 볼 수 있는 시제품이면 충분**합니다(10/26 설명회 확인). 5번의 미국 법인 · 세금 번호 기준은 설명회에서도 답을 듣지 못해 **공고 기준**을 따릅니다 → [설명회에서 확인한 것](../concepts/office-hours-findings.md)

## 3. 제출 전 최종 점검

- [ ] 16문항 모두 답했고, 각 175단어 이내
- [ ] 4번 개요에 **어느 기관과 왜**를 적었다
- [ ] 4번 · 10번에 **제품이 지금 어느 단계인지**(사용자 수 · 시범 사용 결과 등)를 적었다 — 성숙도는 전용 문항이 없다
- [ ] 5번 일정이 **5개월** 안에 들어가고, 기관 담당자 주 1~2시간 · 멘토 월 2~3시간 기준에 맞다
- [ ] 8번 · 12번에 **지역사회 혜택과 협력 단체**를 적었다
- [ ] 11번에 **파일럿 → 전면 도입** 단계를 적었다
- [ ] 13번에 **측정할 지표**를 숫자로 적었다
- [ ] 14번 비용이 현실적이다 (지원금은 대부분 하한 쪽)
- [ ] 16번 피치 영상 링크가 열리고, 비밀번호가 있으면 함께 적었다
- [ ] 제출 확인을 받았다

## 4. 지원하기 어려운 경우

| 상황 | 이번에 할 수 있는 것 |
|---|---|
| **아이디어만 있다** | 해법이 「이미 있거나 만드는 중」이어야 합니다. 클릭해 볼 수 있는 시제품도 인정되므로(10/26 설명회) 마감까지 그 정도를 만들 수 있는지 보고, 어렵다면 해법을 가진 팀에 **함께 참여**하거나 **다음 차수**를 준비하세요 |
| **미국 세금 번호가 없다** | 최종 후보는 W-9 또는 TIN 을 내야 합니다. 워싱턴주 밖은 지원할 수 있다고 확인했지만, **미국 밖 팀 · 거주자**는 설명회에서도 답을 듣지 못했습니다. 11/4 상담이나 innovation@bellevuewa.gov 로 먼저 확인하세요 |
| **18세 미만이다** | 1차와 달리 2차는 18세 이상입니다. 성인이 대표인 팀으로 참여할 수 있는지는 확인하지 못했습니다(공식 문의로 확인) |
| **시간을 낼 수 없다** | 파일럿 기간(2027-01~07) 동안 주 3~5시간이 필요합니다. 팀 안에서 담당을 나눌 수 있는지 먼저 보세요 |
| **주제가 사용 사례와 안 맞는다** | King County 정책 목표(노숙 · 주택 · 지역사회 · 투명한 정부)에 맞는지 보세요. 그것도 아니면 다음 차수의 사용 사례를 기다리는 편이 낫습니다 |
