## Topic Basic Information

**Topic Name**: `VibeLearn-AI`

**Topic Description**:
```
A project to deeply understand the VibeLearn AI learning methodology system,
create textbook-quality documentation that first-time users can immediately start with,
and ultimately produce Korean and English intro videos to spread awareness widely.
```

**Learning Purpose**:
```
1. Fully understand the philosophy, structure, and workflow of the VibeLearn AI system
2. Create high-quality guide documents that others can use immediately
3. Produce KR+EN intro videos using the same pipeline as the Clearly intro video
```

**Estimated Learning Period**: `Intensive and fast (1-2 weeks, daily sessions)`

---

## Learning Objectives

```
- [ ] Can explain the core philosophy and 4-phase workflow of VibeLearn AI
- [ ] Can directly execute the topic_starter → roadmap → daily_learning → worklog cycle
- [ ] Can create a guide for first-time users to get started in 30 minutes

- [ ] Can produce KR+EN intro videos with the markdown-video pipeline
```
