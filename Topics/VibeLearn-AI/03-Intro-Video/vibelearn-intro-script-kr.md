### 슬라이드 4: 기존 학습의 악순환

## 😩 대부분의 학습이 이런 패턴입니다

```
유튜브 영상 봄 → "이해했다!" → 1주일 뒤 → "어떻게 했더라?"
                                            ↓
                              다시 유튜브 검색 (무한 반복)
```

**결과**: 시간은 쓰는데 지식이 안 쌓임

이게 왜 일어날까요? 가장 큰 이유는 배운 내용이 어디에도 **축적되지 않기** 때문입니다. 영상을 보는 동안은 이해가 되지만, 그 이해가 체계적인 지식으로 정리되지 않으면 시간이 지나면 사라집니다. 유튜브 알고리즘이 관련 영상을 계속 추천해주는 것도, 사실은 이 악순환을 더 강화하고 있는 거예요.

### 슬라이드 5: AI로 공부할 때의 새로운 문제

## 🤖 AI로 공부할 때만의 새로운 문제

| 문제 | 설명 |
|------|------|
| **맥락 소실** | 대화 창 닫으면 AI가 이전 내용을 모름 |
| **일관성 없는 가이드** | 매번 다른 AI에게 물으면 방향이 달라짐 |
| **공유 불가** | 내가 배운 것이 다른 사람에게 전달되지 않음 |
| **진도 추적 불가** | "내가 어디까지 했더라?" 파악이 어려움 |

AI가 나왔다고 해서 이 문제가 해결된 건 아닙니다. 오히려 새로운 문제가 생겼어요. AI와의 대화는 창을 닫으면 맥락이 다 날아가버리고, 매번 처음부터 설명해야 합니다. 그래서 AI를 배움의 파트너로 제대로 활용하려면, 새로운 방법론이 필요합니다.

### 슬라이드 6: 이 네 가지 문제를 동시에 해결하는 방법은?

## 🎯 네 가지 문제를 한 번에 해결하려면?

| 문제 | 해결책 |
|------|--------|
| 기억에서 사라짐 | **WorkLog**로 모든 학습 기록 |

| AI 맥락 소실 | **파일 기반 지속성** — 파일이 맥락을 기억 |
| 공유 불가 | **교과서 품질 산출물** — 다른 학습자도 활용 |

이 네 가지를 한 번에 해결하는 방법이 있습니다. 바로 지금 소개해드릴 VibeLearn AI입니다.

### 슬라이드 9: 핵심 설계 원칙

## 🎨 가장 중요한 설계 원칙 하나

> **"이 방법론을 배울 필요가 없습니다"**
>
> "Python 기초를 배우고 싶어."
> → AI가 나머지를 알아서 처리합니다.

**자동으로 처리되는 것**:
- ✅ 학습 정보 수집 (AI가 대화로 질문)
- ✅ 폴더 구조 생성
- ✅ 학습 Roadmap 작성
- ✅ 매일 학습 계획 수립
- ✅ WorkLog 기록

이게 VibeLearn AI에서 제가 가장 신경 쓴 부분입니다. 이 방법론을 사용하기 위해 방법론 자체를 배울 필요가 없어야 한다는 거예요. "Python 기초를 배우고 싶어"라고 말 한마디만 하면, AI가 필요한 정보를 물어보고, 폴더를 만들고, 로드맵을 생성하고, 매일 학습을 안내합니다. 사용자는 그냥 배우고 싶은 걸 말하고, AI의 안내를 따라가면 됩니다.

### 슬라이드 10: 4단계 워크플로우

## 🔄 VibeLearn AI 4단계 워크플로우

```
Phase 1: Topic 설정 (최초 1회)
  "Python 배우고 싶어" → AI가 정보 수집 → 폴더 & 파일 자동 생성

Phase 2: Roadmap 생성 (Topic당 1회)
  AI가 맞춤 학습 계획 자동 생성 → 모듈별 목표·실습·산출물 정의

Phase 3: 일일 학습 (반복)
  "오늘 학습 시작해줘" → AI가 진도 파악 → 오늘의 계획 → 실습 → 기록

Phase 4: 완료 & 회고 (Topic당 1회)
  모듈 완료 → 교과서 품질 산출물 완성 → Topic 회고
```

전체 프로세스는 4단계입니다. 처음에 딱 한 번 Topic 설정을 하면, AI가 그 Topic에 맞는 학습 로드맵을 생성합니다. 그 다음부터는 매일 "오늘 학습 시작해줘"라고 하면 AI가 어제까지 뭘 했는지 파악하고 오늘의 계획을 세워줍니다. 학습이 끝나면 배운 내용이 교과서로 남습니다. 이게 반복됩니다.
