## 페르소나 1: 김준호 (직장인 개발자, 32세)

### 프로필
- 3년차 백엔드 개발자
- 회사에서 AI 관련 기능 개발 담당 예정
- 퇴근 후 1-2시간 개인 학습 가능
- 이미 ChatGPT를 쓰고 있지만 "제대로 배우는 느낌"이 없음

### 현재 학습 방법
```
유튜브 영상 보기 → 대략 이해 → 까먹음 → 다음 영상 보기 (반복)
```

**문제**: 학습 내용이 축적되지 않음, 같은 내용을 반복해서 찾아봄

### VibeLearn AI를 쓰면?
```
"Claude API 써보고 싶어" → AI와 대화로 Topic 설정 (10분)
→ 체계적 Roadmap (M1: 기초, M2: 실습, M3: 프로젝트)
→ 매일 1시간 WorkLog 작성하며 실습
→ 2주 후: GitHub에 올릴 수 있는 포트폴리오 + 재사용 가능한 학습 문서
```

### 진입 장벽
- 처음 설정이 복잡해 보임 → **해결**: GETTING_STARTED.md의 5단계 가이드로 30분 안에 시작
- "나만의 학습인데 왜 문서를 써야 하나?" → **해결**: 나중에 본인이 가장 많이 참조함

### 핵심 메시지
> "매일 1시간씩 공부하는데, 그 결과물이 GitHub 포트폴리오로 쌓인다."

## 페르소나 2: 이수진 (비개발자 직장인, 28세)

### 프로필
- 마케팅 팀 소속, AI 도구 활용에 관심
- 코딩 경험 없음, Python 기초 학습 중
- 학습 동기가 높지만 방향을 잡기 어려움
- "AI 시대에 뒤처질까 봐" 불안감 보유

### 현재 학습 방법
```
구글링 → 각자 다른 스타일의 튜토리얼 → 혼란 → 포기
```

**문제**: 체계가 없어서 어디서 시작해야 할지 모름, 학습 방향 부재

### VibeLearn AI를 쓰면?
```
"ChatGPT API 써보고 싶어" 라고 말하는 것만으로 시작
→ AI가 질문하며 학습 계획 수립
→ "1. API 키 발급 → 2. 첫 요청 보내기 → 3. 간단한 앱 만들기" 식의 단계별 가이드
→ 각 단계마다 "이걸 했어요!" WorkLog 작성 → 성취감
```

### 진입 장벽
- GitHub 사용법을 모름 → **해결**: GitHub 없이도 시작 가능 (로컬 폴더로 운영)
- "나는 AI를 쓸 줄 모르는데..." → **해결**: 모르는 게 정상, 그걸 배우는 게 목적

### 핵심 메시지
> "코딩을 모르는 사람도 AI 도구를 활용해 30분 안에 첫 학습을 시작할 수 있다."

## 페르소나 3: 박창수 (유튜브 크리에이터 & 학습 콘텐츠 제작자, 40세)

### 프로필
- AI/기술 분야 유튜브 채널 운영
- 새 기술을 배우고 영상으로 만드는 것이 직업
- 배운 내용을 구조화하는 데 많은 시간 소요
- 영상 제작과 학습을 병행해야 함

### 현재 학습 방법
```
기술 문서 읽기 → 노션에 메모 → 영상 스크립트 작성 (시간 오래 걸림)
```

**문제**: 학습 내용 → 영상 콘텐츠 변환 과정이 비효율적, 체계가 없어 빠뜨리는 부분 발생

### VibeLearn AI를 쓰면?
```
"Remotion 배우고 영상으로 만들고 싶어"
→ Roadmap (M1: 개념, M2: 실습, M3: 영상 제작 Capstone)
→ 실습 과정이 자동으로 영상 스크립트 소재로 변환
→ WorkLog = 영상 내용의 뼈대
→ 01-Tutorial/ 폴더 = 시청자에게 줄 자료
```

### 진입 장벽
- 이미 자기만의 방식이 있어서 새 시스템 도입 저항 → **해결**: 기존 방식과 병행 가능
- 산출물 품질 기준이 높음 → **해결**: "교과서 품질" 기준이 오히려 크리에이터에게 적합

### 핵심 메시지
> "배우는 과정 자체가 콘텐츠가 된다. 학습 일지가 영상 스크립트다."

## VibeLearn AI의 3가지 핵심 차별화 포인트

### 1. "시작이 쉽다" — 최소 진입 장벽

기존 학습 시스템의 가장 큰 문제는 "어디서 시작해야 할지 모름"입니다.

VibeLearn AI는:
- "배우고 싶어"라는 말 하나로 AI가 모든 것을 설정
- topic_starter.md 작성조차도 AI와 대화하면서 자동 완성
- 30분 안에 첫 학습 세션 시작 가능

### 2. "학습이 쌓인다" — 재사용 가능한 교과서 품질

기존 학습의 가장 큰 문제는 "배워도 남는 게 없음"입니다.

VibeLearn AI는:
- 매일 WorkLog로 학습 기록이 자동 축적
- 산출물 폴더(`NN-ModuleName/`)가 실제 참조 가능한 문서로 생성
- 다른 사람도 바로 따라할 수 있는 품질 기준

### 3. "AI가 파트너다" — CLI 통합 AI 협업

기존 AI 활용의 문제는 "복사/붙여넣기 방식의 비효율"입니다.

VibeLearn AI는:
- Claude Code, Cursor 등 CLI 환경 AI가 파일을 직접 읽고 씀
- Roadmap → WorkLog → 산출물이 모두 같은 환경에서 자동 연결
- AI가 이전 학습 내용을 기억하고 이어서 진행
