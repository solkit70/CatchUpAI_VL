## Persona 1: Junho Kim (Working Developer, 32)

### Profile
- 3-year backend developer
- Assigned to develop AI-related features at work
- Can study 1–2 hours personally after work
- Already uses ChatGPT but doesn't feel like he's "actually learning"

### Current Learning Method
```
Watch YouTube videos → Roughly understand → Forget → Watch next video (repeat)
```

**Problem**: Learning doesn't accumulate; keeps searching for the same content

### With VibeLearn AI
```
"I want to try the Claude API" → Topic setup via AI conversation (10 min)
→ Systematic Roadmap (M1: basics, M2: practice, M3: project)
→ Daily 1-hour WorkLog writing with hands-on practice
→ 2 weeks later: Portfolio to put on GitHub + reusable learning docs
```

### Entry Barriers
- Initial setup looks complicated → **Solution**: Saying "I want to learn" triggers AI to auto-handle folder creation, Roadmap, and learning guidance
- "Why write docs for my own personal study?" → **Solution**: You'll reference it yourself most later

### Core Message
> "Study 1 hour a day and the results stack up as your GitHub portfolio."

## Persona 2: Sujin Lee (Non-developer Office Worker, 28)

### Profile
- Marketing team member, interested in utilizing AI tools
- No coding experience, studying Python basics
- Highly motivated but struggling to find direction
- Anxiety from "falling behind in the AI era"

### Current Learning Method
```
Google search → Tutorials in different styles → Confusion → Give up
```

**Problem**: No structure so doesn't know where to start; lacks learning direction

### With VibeLearn AI
```
Just say "I want to try the ChatGPT API" to get started
→ AI asks questions and builds learning plan
→ Step-by-step guide like "1. Get API key → 2. Send first request → 3. Build simple app"
→ Writing WorkLog at each step → sense of achievement
```

### Entry Barriers
- Doesn't know how to use GitHub → **Solution**: Can start without GitHub (run locally)
- "I don't know how to use AI..." → **Solution**: Not knowing is normal; that's what you're here to learn

### Core Message
> "Even someone without coding experience can start their first learning session in 30 minutes using AI tools."

## 3 Core Differentiating Points of VibeLearn AI

### 1. "Easy to Start" — Minimum Entry Barrier

The biggest problem with existing learning systems is "not knowing where to start."

VibeLearn AI:
- Saying "I want to learn" triggers AI to set everything up
- Even topic_starter.md is auto-completed via AI conversation
- First learning session can begin in 30 minutes

### 2. "Learning Accumulates" — Reusable Textbook Quality

The biggest problem with existing learning is "nothing remains after studying."

VibeLearn AI:
- Daily WorkLog automatically accumulates learning records
- Output folders (`NN-ModuleName/`) are generated as actually referenceable documents
- Quality standard that others can immediately follow

### 3. "AI Is the Partner" — CLI-Integrated AI Collaboration

The problem with existing AI use is "inefficiency of copy/paste methods."

VibeLearn AI:
- VS Code + GitHub Copilot, Claude Code, Cursor and similar AI tools read and write files directly
- Roadmap → WorkLog → outputs are all automatically connected in the same environment
- AI remembers previous learning content and continues from where it left off
