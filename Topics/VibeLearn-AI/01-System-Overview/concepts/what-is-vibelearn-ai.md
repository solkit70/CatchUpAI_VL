## 30초 설명

> **VibeLearn AI**는 AI와 함께 무언가를 배우는 과정 전체를 체계적으로 이끌어주는 학습 방법론입니다.
>
> "배우고 싶어"라는 말 한마디로 시작하면, AI가 학습 계획을 세우고, 매일 진도를 안내하며, 배운 내용이 다음 학습자도 쓸 수 있는 교과서로 쌓입니다.

```
AI를 학습 파트너로 삼아, 개인의 학습 과정을

```

## VibeLearn AI가 탄생한 이유

### 기존 학습의 문제

많은 사람들이 이런 경험을 합니다:

```
유튜브 영상 봄 → "이해했다!" → 일주일 뒤 → "어떻게 했더라?"
                                              ↓
                              다시 유튜브 검색 (무한 반복)
```

**핵심 문제**:
1. 배운 내용이 **축적되지 않음** — 기억에서 사라짐
2. **일관된 구조** 없이 정보가 흩어짐
3. AI를 쓰더라도 **대화가 끊기면 맥락이 사라짐**
4. 혼자 배운 것이 **다른 사람에게 전달되지 않음**

### VibeLearn AI의 해답

이 네 가지 문제를 한 번에 해결하는 방법론:

| 문제 | VibeLearn AI의 해결책 |
|------|---------------------|
| 기억에서 사라짐 | WorkLog로 모든 학습 기록 |
| 구조 없이 흩어짐 | 표준 폴더 구조 (vl_prompts, vl_roadmap, vl_worklog) |
| AI 맥락 소실 | 파일 기반 지속성 — AI가 파일을 읽으면 맥락 복원 |
| 공유 불가 | 교과서 품질 산출물 — 다른 학습자도 바로 활용 |

## 핵심 구성 요소

### 1. AI와의 협업 구조

VibeLearn AI는 AI를 단순한 "질문 응답 도구"가 아닌 **학습 파트너**로 활용합니다.

```
전통적 AI 사용:
나 → "이거 설명해줘" → AI → 답변 → 대화 종료 (맥락 소실)

VibeLearn AI 방식:
나 → AI가 파일 읽기 → 내 학습 상태 파악 → 맞춤 계획 수립
   → 실습 안내 → 산출물 생성 → WorkLog에 기록 → 내일도 이어서
```

### 2. 템플릿 기반 시스템

누구나 같은 방법으로 시작할 수 있도록 AI가 사용하는 **표준 템플릿**이 내장되어 있습니다.

사용자는 이 파일들을 직접 열거나 수정할 필요가 없습니다.
"Python 기초를 배우고 싶어"라고 말하면, AI가 템플릿을 활용해 자동으로 Topic 설정 → Roadmap 생성 → 매일 학습 안내까지 처리합니다.

### 3. 교과서 품질 산출물

단순히 배우는 것에서 그치지 않고, **다른 학습자도 활용할 수 있는 문서**를 만듭니다.

```
01-System-Overview/
├── README.md           ← 이 Topic이 뭔지 한눈에
├── concepts/           ← 개념 설명 문서
│   ├── what-is-*.md    ← "이게 뭐야?"에 대한 답
│   └── workflow-*.md   ← "어떻게 돌아가?"에 대한 답
├── examples/           ← 실제로 해볼 수 있는 예제
└── guides/             ← 단계별 실행 가이드
```

## VibeLearn AI의 이름이 의미하는 것

**Vibe** + **Learn** + **AI** = ?

- **Vibe**: 자연스럽게, AI와 함께 흘러가는 학습
  - "Vibe Coding" (코딩에서 유래) — AI와 함께 직관적으로 만들어가는 방식
- **Learn**: 체계적인 학습, 지식의 구조화
- **AI**: AI를 핵심 파트너로 활용

종합하면: **AI와 자연스럽게 협업하여 체계적으로 배우는 것**

VibeLearn AI는 주제를 가리지 않습니다:

| 분야 | 예시 Topic |
|------|-----------|
| 프로그래밍 언어 | Python-Basics, Rust-Advanced |

| AI/ML 도구 | Claude-API, LangChain |

**핵심**: 배우고 싶다는 의지 + AI 접근 가능한 환경 = 시작 조건 완료

## 설계 철학: 진입 장벽 최소화

VibeLearn AI의 핵심 설계 원칙은 **처음 사용자의 진입 장벽을 최소화**하는 것입니다.

```
설계 원칙:
"이 방법론을 배울 필요 없이 그냥 무엇을 배우고 싶다라고 말하면,
AI가 필요한 정보를 얻어서 자동으로 진행한다."
```

**자동화 범위**:
- Topic 정보 수집 (AI가 대화로 묻고 답 받음)
- 폴더 구조 생성
- Roadmap 생성
- 매일 학습 계획 (어제까지의 진도 자동 파악)
- WorkLog 작성

**만약 자동화가 작동하지 않는다면**: 설계 의도와 다른 것입니다.
[GitHub Issues](https://github.com/solkit70/VibeLearn-AI/issues)로 리포트해주세요.

**익숙해진 후**: 더 상세한 Context를 제공하면 더 높은 품질의 Roadmap과 학습 계획을 받을 수 있습니다.
