## 핵심 인사이트 (이 모듈의 "아하!" 모멘트)

1. **메타 학습의 역설**: VibeLearn AI를 VibeLearn AI로 배우는 것 자체가 방법론 검증
2. **파일이 기억이다**: AI가 파일을 읽으면 대화 세션이 바뀌어도 맥락 복원 가능
3. **시작의 낮은 장벽**: "배우고 싶어"라는 말 하나로 AI가 모든 설정을 처리
4. **개인 학습 → 공동 자산**: 교과서 품질 기준이 혼자가 아닌 커뮤니티를 위한 것
