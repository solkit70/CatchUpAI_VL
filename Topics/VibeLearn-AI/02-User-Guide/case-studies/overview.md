## 당신도 케이스가 될 수 있습니다

VibeLearn AI로 무언가를 배우고, 산출물을 만들면 그것이 케이스 스터디가 됩니다.

케이스를 공유하려면:
1. Topics/{TopicName}/ 폴더를 GitHub에 올리기
2. GitHub Issues로 케이스 공유 알림
3. 이 overview.md에 추가 요청
