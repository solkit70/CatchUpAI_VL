## 영상 소재 메모

Claude Code 초기 작업의 병목은 "페이지를 찾는 것"과 "동적 웹앱의 구조화된 이벤트 데이터를 수집하는 것"이 다른 문제였다는 데 있었다. Codex는 Luma가 내부적으로 쓰는 공개 JSON API를 찾아 화면 캡처 기반 수작업을 전체 일정 자동 수집으로 바꾸었다. 2026-07-24 재확인에서는 현재 예정 행사 242개와 AI 태그 77개를 기준으로, 전체 후보를 AI와 함께 분석하고 AI/Agent/Pitch/Demo/Hackathon/Workshop/오프라인 가치/캘린더 충돌 기준으로 추려 실제 참가 계획을 세웠다는 점을 영상 소재로 사용할 수 있다. 이 사례는 AI Agent 워크플로에서 첫 단계의 검색 능력보다 데이터 원천과 병목 구간을 찾아내는 설계가 더 중요하다는 메시지로 사용할 수 있다. 결론 문장으로는 **"이번 건은 Codex Win"**을 사용할 수 있다.
