# M3 - 참석 결정 + Google Calendar 등록

**상태**: 최종 참가 계획 확정 + Google Calendar 등록 완료 + 오프라인 우선 기준 반영  
**기준 문서**: [final.md](final.md)  
**이전 단계**: `../02-Curation/shortlist.md`, `../02-Curation/priority-review.md`

## 현재 상태

M3는 최종 참석 후보를 확정하고 Google Calendar에 등록하는 단계다. 2026-07-23 세션에서 핵심 후보의 최신 Luma 상태를 재확인했고, 실제 참가 가능성이 높은 일정과 강한 신청 후보를 Google Calendar에 등록했다. 이후 사용자 기준에 맞춰 Lee & Park Meeting은 연기 가능 일정으로 보고, 7/30에는 온라인 `AI Agents as Force Multipliers`보다 오프라인 `ACM Data Conclave`를 우선하도록 보강했다. 그 뒤 Virtual 행사는 캘린더에서 제거하고, 7/30 캘린더는 오프라인 중심으로 정리했다. `final.md`는 이제 의사결정 보드가 아니라 최종 참가 계획 문서다.

## 남은 사용자 액션

1. `final.md`의 **실제 Luma 신청 필요 목록**을 열어 `Request to Join` 또는 `Register`를 직접 완료한다.
2. 승인 후 OpenAI Builder Lounge와 일부 Register-to-see-location 이벤트의 정확한 장소/종료 시간을 캘린더에 보강한다.
3. 7/30 `OpenAI Builder Lounge` 승인 결과가 나오면 4:00 PM 이후 일정을 확정한다.
4. 승인 실패 또는 waitlist 전환 시 해당 캘린더 이벤트를 `[Interest]` 또는 삭제 대상으로 조정한다.

## 캘린더 등록 기준

Google Calendar에는 확정 참석 또는 강하게 참석하고 싶은 오프라인 이벤트를 넣었다. Pending Approval 항목은 제목 앞에 `[Pending Approval]`을 붙이고 투명 일정으로 관리한다. Virtual 이벤트는 캘린더에서 제거하고, 문서에는 참고 후보 또는 제외/보류 후보로만 남긴다. 일부 종료 시간이 확인되지 않은 이벤트는 설명에 확인 필요 메모를 남겼다.
