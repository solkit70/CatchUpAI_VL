## 📚 학습 개요

### Topic 소개
2026년 7월 27일(월)~31일(금) 열리는 **Seattle Tech Week 2026**(Madrona Ventures 주최, 시애틀 전역 30개+ 이벤트) 기간의 **AI 관련 이벤트를 전수 조사**하고, 관심 이벤트의 일시·장소·형식을 검토해 **참석할 이벤트를 결정**한 뒤, 최종적으로 **Google Calendar에 등록**한다. 학습보다 "AI와 함께 조사·비교·의사결정·등록"하는 실전 태스크형 Topic이다.

### 학습 목표
- [ ] AI 관련 이벤트 목록을 표로 정리(제목·날짜·시간·장소·형식·등록)
- [ ] 관심 이벤트 후보 선별
- [ ] 시간 충돌 정리 → 하루별 참석 일정 확정
- [ ] Google Calendar 등록

### 예상 학습 기간
약 1일 (핵심 3~5시간, 방송 중 착수 + 후속 마무리)

### 학습 환경
- OS: Windows 11
- 도구: 웹 브라우저(luma), Google Calendar(MCP), Claude Code
- 사전 지식: 웹 검색·정보 정리(필수), Google Calendar 사용(권장)

### 선별 기준 (사용자 확정)
- **관심 트랙**: AI 관련 이벤트 전반 (AI 기술·제품, 창업·펀딩·GTM, 네트워킹·밋업, 해커톤·워크샵, 피치 대회 등 모두)
- **형식**: 오프라인 + 온라인 모두
- **밀도**: 관심 있는 것 전부 (수 제한 없음, 시간 충돌만 정리)

## 📖 모듈별 상세 계획

### M1 - 이벤트 전수 조사 (Research)

**난이도**: ⭐
**예상 시간**: 1.5h
**산출물 폴더**: `01-Event-Research/`

#### 학습 목표
- [ ] Seattle Tech Week가 무엇인지(시작·주최·철학·운영 방식·분야·규모) 설명할 수 있다
- [ ] luma 허브에서 Tech Week 2026 전체 이벤트 목록을 확인할 수 있다
- [ ] AI 관련 이벤트를 빠짐없이 표로 수집할 수 있다 (제목·날짜·시간·장소·형식·등록 링크)
- [ ] 온라인/오프라인, 유·무료, 등록 필요 여부를 함께 기록할 수 있다

#### 주요 개념
1. **Seattle Tech Week(STW)**: Madrona Ventures 주도, 커뮤니티 주도·오픈소스형 테크 생태계 축제. 누구나 이벤트를 호스팅하고 하나의 캘린더로 묶임.
2. **이벤트 허브(luma)**: Tech Week의 모든 이벤트가 모인 페이지. 날짜·호스트·형식별로 나열됨.
3. **AI 관련 판별**: 제목·설명에 AI/ML/에이전트/데이터/파운더 등 키워드가 있거나 세션 성격이 AI인 이벤트.
4. **메타데이터**: 각 이벤트의 날짜, 시작~종료 시간, 장소(또는 온라인), 등록 방식.

#### 실습 과제

**실습 0: Seattle Tech Week 개요 조사** ⭐
- **목적**: 행사의 성격·주최·운영 방식·분야·규모를 먼저 이해 (이벤트 선별의 맥락)
- **단계**:
  1. STW가 무엇인지, 언제 시작했고 누가 왜 운영하는지, 어떤 분야를 다루는지 조사
  2. 운영 방식(오픈소스형·누구나 호스트)·규모·대표 참여 기관 정리
  3. `01-Event-Research/overview.md`에 저장
- **예상 시간**: 20분
- **검증**: 개요 문서로 STW를 한 문단으로 설명 가능

**실습 1: 전체 이벤트 목록 확보** ⭐
- **목적**: 7/27~31 전체 이벤트를 놓치지 않고 확보
- **단계**:
  1. `https://luma.com/seattletechweek2026` 접속
  2. 날짜별(7/27~31)로 이벤트 목록을 훑으며 캡처/텍스트 확보
  3. `vl_materials/`에 원본 저장
- **예상 시간**: 30분
- **검증**: 5일치 이벤트가 하나의 원본에 모임

**실습 2: AI 관련 이벤트 표 작성** ⭐⭐
- **목적**: 조사 결과를 비교 가능한 표로 구조화
- **단계**:
  1. 목록에서 AI 관련 이벤트만 추림
  2. `제목 · 날짜 · 시간 · 장소/온라인 · 형식 · 유무료 · 등록링크` 열로 표 작성
  3. `01-Event-Research/events.md`에 저장
- **예상 시간**: 45분
- **검증**: 표의 각 행에 날짜·시간·장소가 채워짐

#### 산출물

### M2 - 관심 이벤트 검토·선별 (Curate)

**난이도**: ⭐⭐
**예상 시간**: 1.5h
**산출물 폴더**: `02-Curation/`

#### 학습 목표
- [ ] M1 표에서 관심 이벤트를 선별 기준에 따라 추릴 수 있다
- [ ] 각 후보의 시간대를 날짜별로 배치해 충돌을 파악할 수 있다
- [ ] 겹치는 이벤트 중 우선순위를 정할 수 있다

#### 주요 개념
1. **선별 기준**: 사용자 확정 — AI 관련 전반, 오프라인+온라인, 관심 있는 것 전부.
2. **시간 충돌(conflict)**: 같은 시간대에 겹치는 이벤트. 하나를 골라야 함.
3. **동선/형식**: 오프라인은 장소 이동 시간, 온라인은 동시 참여 여부 고려.

#### 실습 과제

**실습 1: 관심 후보 표시** ⭐
- **목적**: 전체 표에서 참석 후보를 좁힘
- **단계**:
  1. M1 `events.md`에서 관심 이벤트에 ⭐ 표시
  2. 제외한 것은 사유 한 줄 기록
- **예상 시간**: 30분
- **검증**: 후보/제외가 구분됨

**실습 2: 날짜별 타임라인 + 충돌 정리** ⭐⭐
- **목적**: 실제 참석 가능한 조합 도출
- **단계**:
  1. 7/27~31 날짜별로 후보를 시간순 배치
  2. 겹치는 시간대 표시 → 우선순위로 하나 선택
  3. 오프라인 이동 시간·온라인 중복 가능성 반영
  4. `02-Curation/shortlist.md`에 "날짜별 확정 후보" 정리
- **예상 시간**: 45분
- **검증**: 날짜별로 충돌 없는 참석 후보 리스트 완성

#### 산출물
```
02-Curation/
├── README.md          ← 선별 기준·결과 요약
└── shortlist.md       ← 날짜별 확정 후보 + 충돌 정리
```

#### Definition of Done
- [ ] 관심 후보 표시 완료
- [ ] 날짜별 타임라인 작성
- [ ] 시간 충돌 정리 및 우선순위 결정
- [ ] `02-Curation/` 폴더 + README
- [ ] WorkLog 작성

#### Self-Assessment
**개념 이해**: [ ] 왜 이 이벤트를 골랐는지·뺐는지 설명 가능
**실무 활용**: [ ] AI에게 "이 두 이벤트가 시간 겹치는지" 판단 요청 가능

#### 예상 시간 배분
- 기준 확인: 15분 · 실습1: 30분 · 실습2: 45분 · 문서화: 15분(중 버퍼) · **합계: 1.5h**

#### 참조 자료
- M1 산출물 `01-Event-Research/events.md`

### M3 - 참석 결정 + Google Calendar 등록 (Commit) 🎯 Capstone

**난이도**: ⭐⭐
**예상 시간**: 1.5h
**산출물 폴더**: `03-Schedule/`

- [ ] 최종 참석 이벤트를 확정할 수 있다
- [ ] 각 이벤트를 Google Calendar에 정확한 일시·장소·링크로 등록할 수 있다
- [ ] 등록 결과를 확인하고 기록으로 남길 수 있다

#### 주요 개념
1. **최종 확정**: shortlist에서 실제 갈 이벤트만 남김.
2. **캘린더 이벤트 필드**: 제목, 시작~종료(America/Los_Angeles), 장소, 설명(등록 링크·주최).
3. **등록 확인**: 생성된 이벤트의 htmlLink로 재확인.

#### 실습 과제

**실습 1: 최종 참석 리스트 확정** ⭐
- **목적**: 등록 대상 확정
- **단계**:
  1. `02-Curation/shortlist.md`에서 최종 참석만 남김
  2. `03-Schedule/final.md`에 제목·일시·장소·링크 정리
- **예상 시간**: 20분
- **검증**: 등록할 이벤트가 명확히 목록화

**실습 2: Google Calendar 등록** ⭐⭐
- **목적**: 실제 일정 등록 (이 Topic 최종 목적)
- **단계**:
  1. 각 이벤트를 Google Calendar에 등록 (일시·장소·설명 포함, 타임존 PT)
  2. 온라인 이벤트는 접속 링크를 설명에 포함
  3. 등록된 이벤트 링크를 `final.md`에 기록
- **예상 시간**: 40분
- **검증**: 캘린더에 이벤트가 생성되고 htmlLink 확보

#### 산출물

```
03-Schedule/
├── README.md          ← 최종 참석 일정 요약

```
