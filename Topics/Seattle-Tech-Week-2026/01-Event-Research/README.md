# M1 - 이벤트 전수 조사

**모듈**: M1 - Seattle Tech Week 2026 AI 이벤트 전수 조사  
**상태**: 완료 + 2026-07-24 최신 수치 확인  
**기준 문서**: [events-auto.md](events-auto.md)

## 조사 요약

Seattle Tech Week 2026은 2026-07-27(월)부터 2026-07-31(금)까지 진행된다. 기존에는 7/27 화면 캡처 기반으로만 정리되어 있었지만, 이후 Luma 공개 JSON API를 확인해 5일 전체 이벤트를 자동 수집했다.

2026-07-19 자동 수집 당시 전체 이벤트는 237개이며, AI 태그 이벤트는 74개였다. 2026-07-24에 Luma 공개 캘린더를 다시 확인한 결과 현재 예정 행사는 242개, AI 태그 이벤트는 77개로 늘었다. 자동 수집 결과 원본은 `events-auto.md`에 저장했고, 기존 `events.md`는 7/27 캡처 기반 정리본으로 보존한다.

## 문서 안내

1. [overview.md](overview.md) - Seattle Tech Week의 성격, 주최, 운영 방식, 분야, 규모
2. [events.md](events.md) - 기존 7/27 화면 캡처 기반 정리본
3. [events-auto.md](events-auto.md) - Luma API 기반 5일 전체 자동 수집 결과

## 자동화 가능성

이 과정은 자동화 가능하다. Luma 허브에서 직접 화면 캡처를 전달하지 않아도, 공개 JSON API를 통해 전체 이벤트 목록, 날짜, 시간, 장소, 태그, 등록 상태, Luma 링크를 수집할 수 있었다. 다만 등록 상태와 장소는 행사 직전까지 바뀔 수 있으므로, 실제 참석 결정 전에는 최신 상태를 다시 확인해야 한다.
