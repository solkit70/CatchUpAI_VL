# 004 Python 3.13 — 화면은 HTML 한 파일 + 로컬 서버

- **날짜 · 모듈**: 2026-09-12 결정 · 2026-09-27 M0 기록
- **상태**: ✅ 채택

## 맥락
스크립트(인덱서 등)와 화면을 무엇으로 만들지 정해야 했다. 사용자 PC 는 Windows 11 한 대이고, Python 3.13 이 이미 깔려 있다.

## 검토한 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| Node + React 빌드 | 화면 생태계 풍부 | 빌드 도구 · 의존성 · 유지 부담 |
| Electron 데스크톱 앱 | 설치형 앱 느낌 | 무겁고 v1 에 과함 |
| **Python 3.13 + HTML 한 파일 + 로컬 서버** | 이미 설치됨 · `python-frontmatter` 로 파싱 쉬움 · 빌드 없음 | 화면이 소박함 |

## 결정
Python 3.13 만 쓴다. 화면은 `AI/Tasks/app/index.html` 한 파일 + `serve.py` 로컬 서버(127.0.0.1). Node 빌드 · Electron 을 쓰지 않는다.

## 이유
v1 에서 화면은 확인 창구다 (AI Agent Application). 가볍고 고치기 쉬운 쪽이 맞다.

## 결과 · 대가
- 대가: 화면 기능(드래그 등)이 제한된다. v1 비목표라 괜찮다
- 다시 볼 조건: 휴대폰 접속 · 여러 사람 사용이 필요해질 때
