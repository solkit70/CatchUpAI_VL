## 대조와 승인 게이트

마이그레이션은 기존 Task Board 행과 `items/`의 작업을 비교해 차이를 찾는 과정이다. 자동 검색 결과는 후보일 뿐 확정 연결이 아니다. 제목이 비슷하거나 같은 미리보기 행에 나타났다는 이유로 중복·동일 작업이라 판정하지 않는다.

## 권한 단계

| 단계 | 의미 | 원본 변경 |
|---|---|---|
| 후보 | 검색기 또는 사람이 찾은 가능한 연결 | 없음 |
| 판정 | 연결·신규 제안·수정 제안·보류·제외 중 하나를 기록 | 없음 |
| 승인 대기 | 사용자가 아직 승인하지 않은 제안 | 없음 |
| 승인 | 사용자가 구체적으로 승인한 변경 | 해당 item 또는 정해진 운영 경로만 수정 |
| 생성 view | 승인된 `items/` 상태를 읽어 만든 표시 | 원본이 아닌 재생성 가능한 파일 |

사람의 승인은 대상과 내용이 특정된 경우에만 적용한다. 한 행이나 일괄 처리에 대한 승인으로 다른 제안까지 승인된 것으로 확장하지 않는다. 모호한 항목은 미결 상태로 보존한다.

## 단일 원본과 handoff

POST-HANDOFF에서는 `AI/Tasks/items/`가 task 원본이고 `views/priority-board.md`가 생성 화면이다. 이전 수동 Task Board는 원본 이력으로 보존하며 직접 운영 상태를 갱신하지 않는다. 현재 소유권 전환은 2026-10-02 사용자 승인 및 보존·회귀 확인 뒤 적용했다. 이는 미결 48건이나 미승인 제안을 해결한 것으로 간주하지 않는다.

실제 task 변경이 없는 Roundup은 유효한 no-op이지만, items 갱신 경로의 변경 사례를 검증하지는 않는다. 따라서 다음 task 상태 변경이 발생하는 GDR/GWR 실행에서 item 수정, index 재생성, Board 갱신을 순서대로 확인한다.
