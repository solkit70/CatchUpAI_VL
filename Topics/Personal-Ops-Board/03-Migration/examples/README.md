## 합성 대조 사례

아래 예시는 실제 인명·고객 정보 대신 합성 task 제목을 사용한다. 모두 판정표에 기록할 예시이며, 제목만으로 원본을 바꾸지는 않는다.

| 기존 Board 행 | `items/` 후보 | 판정 예시 | 다음 동작 |
|---|---|---|---|
| `샘플 프로젝트 제안서 초안 작성` | 같은 범위·기한을 가진 동일 제목 item | 연결 후보 | 사람이 같은 작업인지 확인한 뒤 연결 확정 |
| `샘플 프로젝트 제안서 초안 작성` | `샘플 프로젝트 고객 인터뷰 일정 조율` | 별개 작업 후보 | 제목 유사도만으로 합치지 않고 각각 유지 |
| `샘플 백로그 아이디어 조사` | 후보 없음 | 보류 | 이유와 재검토 시점을 기록하고 원본 제안은 승인 대기 |
| `샘플 구형 도구 설정` | 이미 폐기 확인 | 제외 | 사용자 확인을 남기고 현재 task 원본에는 생성하지 않음 |

실제 판정에는 [전환 원장](../../../../../../AI/Tasks/migration-review.md)의 행 ID, 판정, 근거 메모를 사용한다.
