## 파일 공유로 시작하고 구조는 열어 둔다

v1의 선택은 파일 공유다. 각 에이전트의 입력·출력·쓸 수 있는 곳·부를 수 있는 대상을 계약 표에 모으고, 필요할 때 연결 방식을 재검토한다. → [ADR 007의 결정](../../architecture/decisions/007-에이전트%20연결은%20열어%20둔다.md#결정)

| 구조 | 소통 | 이 Topic에서의 위치 |
|---|---|---|
| 파일 공유 | 생성 파일을 읽고 쓴다 | v1 출발점 |
| Supervisor | 관리자가 팀원을 호출하고 모은다 | 향후 후보 |
| Peer | 같은 레벨끼리 소통한다 | 향후 후보 |
| 계층형 | 관리자 아래 관리자를 둔다 | 현재 불필요 |
| 순차 파이프라인 | 앞 단계 출력을 다음 단계가 읽는다 | 파일 공유에서 구성 가능 |

현재 인덱서는 LLM 에이전트가 아니라 규칙 기반 스크립트다. Board와 Deadline은 모두 인덱스를 입력으로 받는 계획이므로, Board가 Deadline에 입력을 주는 의존성이 구현되어 있다고 읽으면 안 된다. → [에이전트 입력 계약](../../architecture/ARCHITECTURE.md#3-에이전트-계약)

## 구조를 바꾸는 조건

파일 공유로 부족한 구체적 요구가 생기면 새 ADR에 이유·변경할 계약·되돌리는 방법을 적고 사용자 설계 승인을 받는다. 어떤 연결 구조를 택해도 원본·권한·사람 승인 경계는 유지한다. 업계 비교 출처는 기존 ADR에 보존되어 있다. → [구조 검토 기록](../../architecture/decisions/007-에이전트%20연결은%20열어%20둔다.md#검토한-선택지)
