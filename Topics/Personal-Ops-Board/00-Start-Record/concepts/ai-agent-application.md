## 원본·캐시·제안·화면

이 Topic의 원본은 `items/*.md`다. 인덱서는 읽기만 하고 `views/index.json`을 생성한다. Board·Deadline은 원본을 바꾸지 않고 생성물을 만들며, Intake·Discovery의 후보는 `inbox/`에서 사람 승인을 기다린다. → [현재 설계의 층](../../architecture/ARCHITECTURE.md#2-층)

| 역할 | 읽거나 쓰는 것 | 현재 상태 |
|---|---|---|
| 사람 | 원본·승인 | 운영 중 |
| 인덱서 | 원본 읽기 → JSON 캐시 | M1 구현 |
| 에이전트 | 보드·경고·승인 전 제안 | M2 이후 예정 |
| 화면 | 표시·승인된 원본 변경 | M6 예정 |

화면을 열지 않아도 원본은 읽을 수 있어야 하고, 캐시를 잃어도 원본으로 다시 만들 수 있어야 한다. 인덱서가 파싱 오류를 자동 고치거나 실패 task를 숨기면 사람이 판단할 근거가 사라진다. → [원본 결정](../../architecture/decisions/001-원본은%20마크다운%20-%20DB%20없음.md#결정)

## 학습 확인

합성 task 한 개를 생각하고 원본·캐시·제안 중 어느 곳에 해당하는지 설명한다. 에이전트가 할 일을 발견해도 바로 원본에 추가하지 않는 이유를 권한 표로 확인한다. → [에이전트 계약](../../architecture/ARCHITECTURE.md#3-에이전트-계약)
