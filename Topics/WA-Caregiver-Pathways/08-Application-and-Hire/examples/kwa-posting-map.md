## ⭐ 결론 — 찾던 Pierce County 공고가 있다

2026-09-01 지원 포털에서 `Caregiver` 검색 결과 **22건 전부를 확인했다.**

> ⭐ **`TACOMA, LAKEWOOD, PUYALLUP Caregiver`** — 주소가 **3625 Perkins Lane Southwest,
> Lakewood** 로 **KWA 본부 주소와 정확히 일치**한다. 본부에서 직접 운영하는 공고다.
>
> **Bonney Lake 는 Pierce County 다.** 이 공고로 채용되면 **배정 범위가 Pierce County 전역** —
> Tacoma · Lakewood · Puyallup · Orting · Sumner **그리고 Bonney Lake 자체**가 들어온다.
> **통근 문제가 사라진다.**

그리고 이 공고는 **본부 번호 253-946-1995 ext.1 이 그대로 통하는 유일한 공고**이기도 하다
(다른 공고는 지역 번호가 따로 있다).

## 공고를 다 읽을 필요는 없었다

여러 공고 본문과 첨부 PDF 를 대조한 결과 **전부 같은 템플릿**이다.

| | 공고마다 다른가 |
|---|---|
| 첨부 직무기술서 PDF | ❌ **완전히 동일.** 18개 파일을 받아도 **고유 문서는 1건** (md5 2종 · 텍스트 10,491자 일치) |
| 복리후생 문구 | ❌ 동일 — *"Medical, Vision, Dental...**Paid Travel Time between clients**; **Mileage reimbursement**"* |
| 자격 요건 | ❌ 동일 — 18세 · **본인 차량** · 면허 · 보험 · 자격 취득 의사 · 범죄경력 조회 |
| 근무 형태 문구 | ❌ 동일 — *"not required to work a minimum number of hours per week"* |
| 기관 소개 | ❌ 동일 (Vancouver 만 *"Committed to diversity, equity, inclusion"* 한 줄 추가) |
| 게시일 | 대부분 **2026-08-06** (예외: Bainbridge 8/17 · Longview 야간 8/10 · **한국어 6/30**) |
| 마감 | 전부 **`Until Filled`** — 마감 압박 없음 |
| ⭐ **근무 지역 = 배정 카운티** | ✅ **다르다** |
| ⭐ **시급 상한** | ✅ **다르다** ($27.28 일반 / **$28.53 한국어 1건뿐**) |
| ⭐ **지역 전화번호** | ✅ **다르다** |

> **공고에서 볼 것은 셋뿐이다 — 지역 · 시급 상한 · 전화번호.** PDF 를 더 받을 필요가 없다.
>
> \U0001F4CC **한국어 공고만 게시일이 6/30 으로 두 달 이르다.** 다른 공고가 일괄 8/06 에
> 갱신될 때 이것만 남아 있었다는 뜻이고, **채우기 어려운 자리**일 가능성이 있다 — 지원자에게 유리한 신호다.

## 지원 전략 — 두 건에 지원한다

### 상충: 통근이냐 시급이냐

| | ⭐ **TACOMA/LAKEWOOD/PUYALLUP** | ⭐ **KOREAN Bilingual** |
|---|---|---|
| 배정 범위 | ✅ **Pierce 전역 — Bonney Lake 포함** | King 전역 — **시애틀·벨뷰까지 갈 수 있다** |
| 시급 상한 | $27.28 | ⭐ **$28.53** |
| 한국어 활용 | ❓ 확인 필요 | ⭐ 공고의 전제 |
| 전화 | ✅ **253-946-1995 ext.1** (본부) | 공고에 적힌 번호 확인 |

**둘 다 지원한다.** 첫 지원은 *"initial **3-minute**, mobile-friendly application"* 이라
부담이 없고, 같은 기관에 2건은 **「지역 유연성」으로 읽힌다.**

### ⭐ 전화에서 이 둘을 확인하면 결론이 난다

| # | 질문 | 왜 |
|---|---|---|
| \U0001F534 1 | **Bonney Lake 반경에 월 80시간을 채울 만큼 client 가 있는가** (2개월 연속) | **보험 자격의 전부.** 공고의 *"최소 시간 요구 없음"* 은 **최소 시간 보장도 없다**는 뜻이다 — 「배정해 주는가」가 아니라 **「수요가 있는가」** 로 물어야 한다 |
| ⭐ 2 | **Lakewood(Pierce) 채용으로 한국어 client 를 맡을 수 있는가** | 되면 **높은 시급과 짧은 통근을 동시에** 가진다. Tacoma·Lakewood 에도 한국인 인구가 있고 **본부가 거기다** |

> 2번이 「예」면 **TACOMA/LAKEWOOD/PUYALLUP 단독이 최선**이고,
> 「아니오」면 **시급 $1.25 vs 통근 거리**를 놓고 저울질한다.

## 이미 해소된 질문 (공고 본문에서 확인)

| 질문 | 답 |
|---|---|
| client 간 이동시간은 유급인가 | ✅ **유급** (`Paid Travel Time between clients`) |
| 마일리지 환급이 되는가 | ✅ **된다** (`Mileage reimbursement`) |
| HCA 훈련은 유급인가 | ✅ **유급** (`Paid Home Care Aide Certification Training`) |
| 보험에 치과·안과 포함인가 | ✅ **Medical + Vision + Dental** |
| HCA 자격 없이 지원 가능한가 | ✅ 가능. **취업 후 200일(영어가 제2언어면 260일)** 안에 취득 |
| 파트타임이 되는가 | ✅ 전 공고 **FT/PT** 표기 |
