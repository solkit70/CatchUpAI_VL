## Summary

이 문서는 실제 지원 전에 준비할 서류와 문의 스크립트를 정리한다. 원칙은 단순하다. 볼트에는 지원서 원문, SSN, 생년월일, 면허번호, 운전면허번호, 주소 전체, 배경조회 세부값을 저장하지 않는다. 필요한 경우에는 항목명과 제출 여부만 기록하고, 사본을 보관할 때는 마스킹본만 둔다.

## First Contact Message - Family Resource

안녕하세요. Tacoma/Puyallup in-home caregiver position에 관심이 있습니다. 현재 HCA certification은 없지만, 공고에 나온 2주 in-house HCA training 경로로 시작 가능한지 확인하고 싶습니다. Bonney Lake/Tehaleh 근처에서 주 20~25시간 정도의 안정적인 파트타임 배정이 가능한지, 그리고 월 80시간 전후 근무 시 medical benefits eligibility와 waiting period가 어떻게 되는지 알려주실 수 있을까요?

확인하고 싶은 항목은 다음과 같습니다.

| 질문 | 답변 기록 |
|------|------|
| HCA 미보유 상태에서 지원 가능한가? |  |
| 2주 HCA in-house training은 paid인가, unpaid인가? |  |
| training 후 client 배정까지 평균 얼마나 걸리는가? |  |
| Bonney Lake/Tehaleh 근처 또는 Puyallup/Orting/Edgewood 중심 배정이 가능한가? |  |
| 주 20~25시간 또는 월 80시간을 안정적으로 받을 가능성이 있는가? |  |
| full benefits의 eligibility 기준은 hours/week, month, waiting period 중 무엇인가? |  |
| paid travel time과 mileage는 client 사이 이동에 어떻게 적용되는가? |  |

## First Contact Message - Visiting Angels Puyallup

안녕하세요. Puyallup caregiver part-time position에 관심이 있습니다. 현재 HCA/CNA license는 없지만, 공고에 "willingness to begin coursework within 14 days"와 licensure training assist가 보여서 무자격 상태에서도 지원 가능한지 확인하고 싶습니다. Bonney Lake/Tehaleh 기준으로 North Pierce/South King service area에서 주 20~25시간 또는 월 80시간에 가까운 파트타임 배정이 가능한지도 알고 싶습니다.

확인하고 싶은 항목은 다음과 같습니다.

| 질문 | 답변 기록 |
|------|------|
| HCA/CNA 미보유 상태에서 채용 가능한가? |  |

안녕하세요. Washington Individual Provider 경로를 검토하고 있습니다. 신규 IP로 지원할 때 hiring steps, required training, background check, orientation을 어떤 순서로 진행해야 하는지 확인하고 싶습니다. 또한 Bonney Lake/Tehaleh 근처에서 Carina를 통해 local clients를 찾고 월 80 paid hours를 안정적으로 확보할 수 있는지 판단하려고 합니다.

## Resume Positioning Notes

경력이 없다는 점을 숨기기보다, 다음 네 가지를 전면에 둔다. 첫째, 일정 신뢰성이다. 돌봄은 배정 후 결근 리스크가 employer에게 크므로, 가능한 요일과 시간을 과장하지 않는다. 둘째, 운전 가능성과 지역 선호다. 재가 돌봄은 client home 배정이 핵심이므로 Bonney Lake/Tehaleh, Puyallup, Orting, Edgewood 중심 선호를 분명히 한다. 셋째, training readiness다. HCA coursework와 background check를 채용 후 바로 진행할 의지가 있다는 점을 말한다. 넷째, 월 80시간 기준이다. 의료보험이 중요하다면 처음부터 주 20~25시간의 안정 배정을 원하는 이유를 밝힌다.
