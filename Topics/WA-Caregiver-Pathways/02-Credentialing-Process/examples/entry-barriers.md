## 결론

무경력자에게 가장 큰 장벽은 전문지식 부족이 아니라 **순서 착각**이다. 워싱턴 HCA 경로는 자격을 미리 따서 취업하는 모델이 아니라, 먼저 고용된 뒤 정해진 기한 안에 교육·시험·자격을 끝내는 모델이다.

## 공통 장벽

| 장벽 | 왜 문제가 되는가 | 대응 |
|---|---|---|
| 고용 전 배경조회 선행 불가 | DOH FAQ와 DSHS 안내 모두 hiring entity와 연결된 절차를 전제로 한다 | 먼저 고용주/계약 경로를 정하고, 배경조회는 그 절차 안에서 진행 |
| 120일 교육 시계 | 채용 후 75시간 교육을 제때 못 끝내면 근무 중단 리스크가 생긴다 | M4에서 교육기관과 일정 선확보 |
| 시험 언어와 형식 | HCA knowledge/skills exam, NAC knowledge/skills exam 모두 시험 부담이 있다 | 시험 언어 지원과 연습 자료 확인 |
| 비용 | 신청비, 시험비, 교육비가 분리된다 | 고용주/교육기관 대납 여부를 M3/M4에서 확인 |
| 교통과 일정 | 교육·시험 장소가 반경 50마일 안에 있어도 시간표가 맞지 않을 수 있다 | 근거리/중거리/원거리로 나눠 일정 확보 |
| 개인정보 | 지원·배경조회·자격 신청에서 신원 정보가 필요하다 | 볼트에는 SSN·생년월일·면허번호를 기록하지 않음 |

## HCA 장벽

| 지점 | 장벽 | 현재 판단 |
|---|---|---|
| 채용 | 고용주가 없으면 DSHS background check를 시작하기 어렵다 | 자격 취득보다 지원 경로 탐색이 먼저 필요 |
| 신청 | 채용 +14일 안에 DOH 신청 필요 | 채용 전 DOH 계정/서류 목록을 미리 확인해야 함 |
| 교육 | 75시간 training을 +120일 안에 완료 | M4 교육기관 확보가 핵심 리스크 완화 |
| 시험 | Prometric knowledge + skills | 비용과 시험 언어 지원 확인 완료, 준비 자료는 추후 필요 |
| 발급 | 현재 한시 규칙상 +365일 | 200일 문구와 혼동 주의 |

## IP 장벽

| 지점 | 장벽 | 현재 판단 |
|---|---|---|
| client 연결 | IP는 보통 돌볼 client/consumer와 연결되어야 한다 | Carina/CDWA 경로를 M4에서 확인 |
| CDWA hiring | Workday/DirectMyCare 등 포털 사용 필요 | 영어·온라인 절차 부담 가능 |
| 배경조회 | background check code와 fingerprint가 필요 | CDWA가 process를 안내하지만, 120일 제한이 있음 |
| 면제 판단 | 월 20시간 이하, 가족 돌봄 등 조건 해석 필요 | WAC 246-980-025로 큰 틀 해결. 실제 케이스는 CDWA 확인 필요 |
| 복지 | part-time이면 의료보험 조건이 달라질 수 있음 | M3 핵심 확인 대상 |

## NAC/NAR 장벽

| 지점 | 장벽 | 현재 판단 |
|---|---|---|
| 프로그램 선택 | traditional / HCA Bridge / MA Bridge 중 경로 선택 필요 | 무경력자는 traditional, HCA 후에는 bridge 가능 |
| skills test | training program별 시험 운영·비용이 다름 | M4에서 실제 provider별 확인 필요 |
| knowledge test | online knowledge test $55 | 영어 온라인 시험 환경 확인 필요 |
| 규제 이관 | 2026-07-01 WABON 이관 직후 | 안내 페이지와 서식 갱신 가능성 주의 |
| HCA와의 관계 | NAC는 HCA 면제 자격이지만 바로 파트타임 IP와 같은 층위가 아님 | M5 전까지 적합성 판단 유보 |

## 파트타임 관점에서 중요한 장벽

파트타임이면 IP 월 20시간 이하 면제 조항이 가장 큰 변수다. 하지만 이 조항은 **HCA certification 면제**에 관한 것이고, 의료보험이나 PTO 같은 복지 자격을 보장하지 않는다. 사용자가 궁금해한 "파트타임으로 가능하냐"는 질문은 M3에서 급여·복지 조건과 함께 봐야 결론이 난다.

## 아직 남은 질문

| 질문 | 왜 남기는가 | 다음 모듈 |
|---|---|---|
| 월 20시간 이하 IP도 어떤 orientation/training은 필요한가 | WAC 246-980-025는 certification exemption이고 minimum training 가능성을 남긴다 | M3/M4, CDWA 확인 |
| HCA 교육비를 누가 내는가 | 실제 진입 비용을 결정한다 | M3 |
| 파트타임 의료보험 자격 기준은 몇 시간인가 | 사용자 의사결정 핵심 | M3 |
| Tehaleh/Bonney Lake 기준 가장 가까운 교육·시험 위치는 어디인가 | 120일 리스크를 줄인다 | M4 |
