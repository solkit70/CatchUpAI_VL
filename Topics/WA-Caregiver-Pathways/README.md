# 자격증 없이 당장 취업되는 요양보호사 — 워싱턴주 조사 기록

워싱턴주 요양보호사(Caregiver) 세 경로를 **조사하고, 실제로 지원까지 해 본 기록**입니다.

결론만 정리한 요약본이 아닙니다. **틀렸던 판단과 끝내 확인하지 못한 것까지** 그대로 두었습니다.

> 📅 **조사 시점: 2026년 8~9월.** 워싱턴주 규정은 **한시 규칙(2025-08-25 ~ 2027-12-31)** 이 적용 중이라
> 기한이 달라질 수 있습니다. **행동하기 전에 반드시 DOH·DSHS 원문을 다시 확인하세요.**

## 🔴 조사 시작 전 알던 것과 정반대였던 것

**「자격증을 따고 취업한다」가 아닙니다. 취업이 먼저입니다.**

워싱턴주 보건부(DOH) 원문이 순서를 못 박습니다.

> *"If you are not currently working, you are not able to obtain the DSHS background check."*

배경조회를 **고용 기관을 통해서만** 받을 수 있기 때문입니다. 그래서 순서가 이렇게 됩니다.

```
취업  →  배경조회  →  75시간 교육  →  시험  →  자격 취득
```

기한은 전부 **채용일 기준**입니다 — 교육 이수와 자격 취득까지 **365일**(provisional certificate 는 425일).
🔴 **기한을 넘기면 근무를 멈춰야 합니다** — *"You must stop working until you receive a home care aide certification."*

## 세 경로는 같은 층위가 아니다

처음엔 셋을 나란한 선택지로 봤는데, **층위가 다릅니다.**

| | 정체 |
|---|---|
| **HCA** (Home Care Aide) | **자격** — 대부분이 따야 하는 것 |
| **IP** (Individual Provider) | **고용 형태** — 주정부와 직접 계약 |
| **NAC** (Nursing Assistant Certified) | **상위 자격** — HCA 면제. 2026-07-01 WABON 이관 |

상위 개념은 **Long-Term Care Worker** 이고, 기관 소속과 IP 가 모두 그 아래에 들어갑니다.

⭐ **IP 로 월 20시간 이하면 HCA 자격이 면제**됩니다 — 파트타임으로 바로 시작할 수 있는 길입니다.
⭐ **HCA → NAC Bridge 는 38시간**이면 됩니다.

## ⚠️ 이 기록을 읽을 때

**AI 가 조사하고 사람이 검증했습니다.** 그 과정에서 **AI 가 지어낸 숫자를 세 번 걷어냈습니다** —
*"2002년에는 $7이었다"* · *"90% 이상이 하나의 노조에 속해 있다"* · *"세 배가 넘게 올랐다"*.
볼트 전체를 검색했지만 **어떤 조사 문서에도 근거가 없었습니다.**

그래서 이 기록의 규칙은 하나입니다 — **출처를 못 대는 문장은 뺀다.**
숫자마다 출처가 붙어 있고, 확인하지 못한 것은 「확인하지 못했다」고 적었습니다.
