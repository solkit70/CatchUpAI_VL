## 📚 학습 개요

### Topic 소개

워싱턴주 요양보호사 3개 경로(HCA·IP·NAC)를 조사해 하는 일·자격 취득 절차·급여와 복지·거주지에서 가능한 일자리를 파악하고, 본인에게 맞는 역할에 실제로 지원해 교육을 이수하고 일할 수 있는 상태까지 만든다. 조사 결과는 한인 커뮤니티용 안내 자료와 영상으로 공유한다.

**알고 있는 3개 경로** — 명칭·정의는 M1에서 1차 출처로 검증한다.

| 약칭 | 통용 명칭 | 사용자 이해 |
|---|---|---|
| **HCA** | Home Care Aide | 재가 돌봄 보조인 |
| **IP** | Individual Provider | 개인 돌봄 제공자 |
| **NAC** | Nursing Assistant-Certified | 간호조무 인력 |

### 학습 목표

- [ ] HCA·IP·NAC 세 경로의 업무·자격·고용 주체·근무 형태를 구분해 설명할 수 있다
- [ ] 각 경로의 자격 취득 절차(교육 시간·시험·배경조회·자격증 발급)를 단계별로 제시할 수 있다
- [ ] 급여 수준과 복지(**의료보험 제공 여부와 그 조건**)를 경로별로 비교할 수 있다
- [ ] **거주지 반경 50마일** 안에서 실제 지원 가능한 고용주·기관 목록을 확보한다
- [ ] **전업과 파트타임 각각의 현실적 조건**을 근거와 함께 정리한다
- [ ] 본인 조건에 맞는 경로를 근거를 들어 선택하고 **실제로 지원한다**
- [ ] 필수 교육을 이수하고 자격 취득 절차를 진행한다
- [ ] 한인 커뮤니티용 안내 자료(한/영)와 영상을 만든다

## 📏 이 Topic의 진행 규칙

### 규칙 1 — 일정 우선 스캔 ⭐

**M1 실습 1에서 교육 일정과 모집 상태를 가장 먼저 스캔한다.** 마감이나 코호트 시작일이 로드맵 진행보다 앞서면 **순서를 바꾼다.**

> `Datacenter-Workforce-Programs`에서 조사를 다 끝내고 나서야 유력 두 경로가 **모집을 닫아 놓은 상태**임을 알았다. 같은 일을 반복하지 않는다.
>
> **"프로그램이 있다"와 "지금 지원할 수 있다"는 다른 말이다.**

WA 요양보호사 교육이 코호트제로 운영될 가능성이 있다 — **이는 확인 전 추정이며 M1에서 검증한다.** 코호트제라면 놓쳤을 때 다음 기수까지 기다려야 한다.

### 규칙 2 — 1차 출처 원칙

기관명·제도명·숫자는 **공식 출처로 확인하기 전에는 사실로 쓰지 않는다.** 확인하지 못한 것은 아래 셋을 구분해 적는다.

| 표기 | 뜻 |
|---|---|
| **확인 불가** | 찾아봤으나 공개돼 있지 않다. 시도한 경로와 다음 문의처를 함께 적는다 |
| **미착수** | 아직 안 봤다 |
| **층위 오류** | 상위(주·연방) 층위엔 없고 하위(기관·프로그램)에 있다 |

### 규칙 3 — 판단 유보

**M5 전까지 비교표에 본인 판단을 적지 않는다.** "나에게 맞다 / 무리다" 같은 서술을 넣지 않는다. 판단을 미리 섞으면 **표가 결론을 정당화하는 도구가 된다.**

### 규칙 4 — 개인정보 취급 🔒

이 Topic은 신원 정보와 배경조회를 다룬다.

- 볼트에 **실제 신원 정보(SSN·면허번호·생년월일)를 기록하지 않는다**
- 지원서 사본 저장 시 해당 필드를 마스킹한다
- **공유 산출물(M9·M10)에 본인 정보가 들어가지 않게 한다**

### 규칙 5 — 문의는 사용자가 직접

전화·이메일 문의는 **사용자가 수행한다.** AI는 질문지를 준비하고 답변을 기록한다. 대리로 연락하지 않는다.

### M1 - 세 경로 지도와 일정 스캔

**난이도**: ⭐

> **규칙 1이 적용되는 모듈이다.** 지도를 그리기 전에 일정부터 본다.

#### 학습 목표

- [ ] HCA·IP·NAC 각각의 **담당 규제 기관**과 **정식 명칭**을 1차 출처로 확인할 수 있다
- [ ] 세 경로의 업무 범위·근무 장소·고용 주체를 구분해 설명할 수 있다
- [ ] 교육·모집 일정이 로드맵보다 앞서는지 판정할 수 있다
- [ ] 세 경로 사이의 관계(상하위·전환 가능성)를 도식으로 제시할 수 있다

#### 주요 개념

1. **규제 기관 분리** — 미국 주 정부는 자격 발급과 서비스 운영을 다른 부처가 맡는 경우가 많다. **자격을 주는 곳과 일자리를 주는 곳이 다를 수 있다.**
2. **재가(in-home) vs 시설(facility)** — 돌봄이 이뤄지는 장소가 다르면 자격·고용주·근무 형태가 전부 달라진다.
3. **Individual Provider의 성격** — 특정 대상자를 돌보는 형태로 알려져 있다. **고용주가 기관이 아닐 수 있다** — M1에서 확인한다.
4. **오해하기 쉬운 포인트** — 세 약칭이 나란히 쓰이지만 **같은 층위의 선택지가 아닐 수 있다.** 하나가 다른 것의 상위 자격이거나, 애초에 다른 산업일 수 있다. **나란히 놓고 비교하기 전에 층위부터 확인한다.**

#### 실습 과제

**실습 1: 일정·모집 상태 스캔** ⭐ ← **가장 먼저 한다**
- **목적**: 마감이 로드맵을 앞지르는지 판정한다. 뒤에 하면 늦는다.
- **단계**:
  1. 세 경로 각각의 **교육 등록 마감일·코호트 시작일**을 공식 페이지에서 찾는다
  2. 찾지 못하면 **왜 없는지**를 규명한다 (상시 모집 / 기관별 상이 / 비공개)
  3. 로드맵 기간(1~2주) 안에 걸리는 마감이 있는지 판정한다
  4. 있으면 **즉시 보고하고 순서 재조정을 제안한다**
- **예상 시간**: 15분
- **난이도**: ⭐
- **검증 방법**: 3개 경로 전부에 대해 "마감일" 칸이 값 또는 "확인 불가 + 이유 + 다음 문의처"로 채워짐

**실습 2: 규제 기관·정식 명칭 확정** ⭐⭐
- **목적**: 사용자 사전 지식을 1차 출처로 검증한다. 이름이 틀리면 이후 조사가 전부 어긋난다.
- **단계**:
  1. WA 주 공식 사이트에서 HCA·IP·NAC 각각의 **정식 명칭**을 확인한다
  2. 각각의 **담당 기관**(자격 발급 / 서비스 운영)을 확인한다
  3. 사용자가 알고 있던 명칭과 다른 점을 기록한다
  4. **세 경로가 같은 층위인지** 판정한다
- **예상 시간**: 15분
- **난이도**: ⭐⭐
- **검증 방법**: 3개 전부 정식 명칭·담당 기관·1차 출처 URL이 채워짐. 층위 판정 결과가 한 문장으로 적힘

**실습 3: 세 경로 관계도** ⭐⭐
- **목적**: 나란한 선택지인지, 계단식인지 눈으로 본다.
- **단계**:
  1. 업무 범위·근무 장소·고용 주체를 축으로 배치한다
  2. 경로 간 **전환 가능성**(예: HCA → NAC)이 있는지 표시한다
  3. Mermaid 다이어그램으로 그린다
- **예상 시간**: 10분

#### 학습 목표

- [ ] 각 경로의 자격 취득 단계를 **순서대로** 제시할 수 있다
- [ ] 교육 시간 요건·시험 유무·배경조회 절차를 경로별로 구분할 수 있다

- [ ] 무경력자가 어느 단계에서 막힐 수 있는지 짚을 수 있다

#### 주요 개념

1. **교육 시간 요건** — 주 법으로 최소 시간이 정해져 있을 수 있다. 시간 수와 인정 기관을 함께 확인한다.
2. **배경조회(background check)** — 돌봄 직종은 대개 범죄경력 조회가 필수다. **처리 기간이 주 정부 일정에 종속**되므로 전체 일정의 병목이 되기 쉽다.
3. **자격증 발급과 갱신** — 취득 후 유지 요건(보수교육·갱신 주기)이 따로 있다.
4. **오해하기 쉬운 포인트** — "교육을 마치면 일할 수 있다"가 아닐 수 있다. **교육 → 시험 → 배경조회 → 발급** 중 어느 하나라도 남으면 취업이 안 된다. 각 단계의 **선후 관계**를 정확히 그린다.

#### 실습 과제

**실습 1: 경로별 절차 단계도** ⭐⭐
- **목적**: "지금 위치에서 자격 취득까지"를 그림으로 만든다.
- **단계**:
  1. 경로별로 단계를 순서대로 나열한다 (교육·시험·배경조회·발급)
  2. 각 단계의 **소요 기간**과 **비용**을 채운다
  3. 단계 간 선후 관계(동시 진행 가능 / 순차 필수)를 표시한다
  4. Mermaid로 그린다
- **예상 시간**: 20분
- **난이도**: ⭐⭐
- **검증 방법**: 3개 경로 전부 단계도 완성. 기간·비용 칸이 값 또는 "확인 불가 + 다음 문의처"로 채워짐

**실습 2: 무경력자 진입 장벽 점검** ⭐⭐
- **목적**: 실제로 어디서 막히는지 미리 안다.
- **단계**:
  1. 각 단계마다 **무경력자가 충족 못 할 수 있는 요건**을 뽑는다
  2. 학력·연령·언어·신체·거주 요건이 명시돼 있는지 확인한다
  3. 막히는 지점이 있으면 **우회 경로**가 있는지 확인한다
- **예상 시간**: 15분
- **난이도**: ⭐⭐

### M3 - 급여·복지 비교 (의료보험 중심)

**난이도**: ⭐⭐
**예상 시간**: 40m
**산출물 폴더**: `03-Pay-and-Benefits/`

> **사용자가 명시적으로 궁금해한 항목이다.** 특히 **의료보험 제공 여부**.

#### 학습 목표

- [ ] 경로별 급여 수준을 시급·연봉 기준으로 제시할 수 있다

- [ ] **전업과 파트타임**의 복지 차이를 구분해 설명할 수 있다
- [ ] 급여 외 지원(교육비·교통비·유급휴가)이 있는지 확인할 수 있다

#### 주요 개념

1. **시간 요건과 복지의 연결** — 미국에서 의료보험은 대개 **주당 근무 시간이 일정 수준 이상**일 때 제공된다. **파트타임이면 안 나올 수 있고**, 이것이 전업/파트타임 판단의 핵심 변수다.
2. **고용주별 상이** — 같은 자격이라도 고용주(기관·주 정부·조합)에 따라 복지가 다르다.
3. **조합(union)의 역할** — 돌봄 직종에 조합이 관여하는 경우가 있고, 교육·복지를 조합 기금이 담당하기도 한다. **확인 대상이며 추정하지 않는다.**
4. **오해하기 쉬운 포인트** — 구인 광고의 시급은 **최고액**을 표시하는 경우가 많다. 시작 시급과 상승 조건을 따로 확인한다.

#### 실습 과제

**실습 1: 급여 자료 확보** ⭐⭐
- **목적**: 추정이 아니라 출처 있는 숫자를 모은다.
- **단계**:
  1. 주 정부 통계 또는 공식 임금표에서 경로별 임금을 찾는다
  2. 실제 구인 공고에서 **시작 시급 범위**를 수집한다 (WA는 채용공고 임금 공개 의무 주)
  3. 통계값과 실제 공고값의 차이를 기록한다
- **예상 시간**: 15분
- **난이도**: ⭐⭐
- **검증 방법**: 경로별 임금이 **출처 2종**(통계 + 실제 공고)으로 채워짐

**실습 2: 복지 비교표 — 전업 vs 파트타임** ⭐⭐⭐
- **목적**: 사용자의 핵심 질문에 답한다.
- **단계**:
  1. 항목 고정: 의료보험 / 치과·안과 / 유급휴가 / 은퇴연금 / 교육비 지원 / 교통비
  2. **경로 3개 × 근무형태 2개 = 6칸**을 채운다
  3. 의료보험은 **제공 여부만이 아니라 자격 조건**(주당 시간·근속)을 함께 적는다
  4. **규칙 3 적용** — 본인 판단을 적지 않는다
- **예상 시간**: 20분
- **난이도**: ⭐⭐⭐
- **검증 방법**: 6칸 전부 값 또는 "확인 불가 + 다음 문의처". 의료보험 칸에 조건이 함께 적힘

### M4 - 반경 50마일 일자리·교육기관

**난이도**: ⭐⭐
**예상 시간**: 40m
**산출물 폴더**: `04-Local-Opportunities/`

> **조사 반경은 거주지 기준 약 50마일이다.** 피어스 카운티에 한정하지 않는다.

#### 학습 목표

- [ ] **반경 50마일 안의 교육기관**을 3곳 이상 확보한다
- [ ] **반경 50마일 안의 고용주·기관**을 3곳 이상 확보한다 (근거리·중거리·원거리 각 1곳 이상)
- [ ] 각 기관의 요건·비용·일정·연락처를 표로 정리한다
- [ ] **근무 형태별로** 통근 현실성을 분류한다 (전업 기준 / 파트타임 기준)

#### 주요 개념

1. **재가 돌봄의 근무지** — 재가 서비스는 **이용자의 집**이 근무지다. 기관 위치가 아니라 **배정 지역**이 통근 거리를 정한다.
2. **온라인 이수 가능성** — 교육 일부가 온라인으로 가능하면 통근 제약이 크게 줄어든다.
3. **카운티 경계** — 반경 50마일은 **피어스·킹 두 카운티**에 걸친다. 카운티가 다르면 기관·임금 수준·프로그램 운영이 다를 수 있다. **경계를 넘는 것이 조건을 바꾸는지 확인한다.**
4. **근무 형태와 통근의 관계** — 파트타임이 주당 **일수**가 적으면 긴 통근을 감수할 만하지만, 회당 **근무 시간**이 짧으면 통근 대비 근무 비율이 나빠진다. **주당 일수인지 회당 시간인지를 구분해 본다.**
5. **오해하기 쉬운 포인트** — 기관이 가깝다고 근무지가 가깝지 않다. **배정 방식을 반드시 확인한다.**

#### 실습 과제

**실습 1: 교육기관 목록화** ⭐⭐
- **목적**: 실제로 등록 가능한 것만 남긴다.
- **단계**:
  1. **반경 50마일 안의** 커뮤니티 칼리지·직업훈련기관·기관 자체 교육을 조사한다 (피어스·킹 카운티 양쪽)
  2. 과정별 요건·기간·비용·**다음 개강일**·연락처를 채운다
  3. **온라인·하이브리드 이수 가능 여부**를 확인한다
- **예상 시간**: 15분
- **검증 방법**: 기관 3곳 이상, "다음 개강일"과 "연락처"가 채워짐

**실습 2: 고용주 목록화 + 실제 공고 확인** ⭐⭐
- **목적**: "있다"가 아니라 "지금 뽑는다"를 본다.
- **단계**:
  1. **반경 50마일 안의** 재가 돌봄 기관·요양시설을 조사한다. **레드몬드 권역을 반드시 포함**한다 — 지인이 실제로 일하는 곳이라 사례가 있다
  2. **현재 공고가 열려 있는지** 확인한다 (규칙 1의 연장)
  3. 공고의 자격 요건·근무 형태(전업/파트타임)·임금을 기록한다
  4. **근무지 배정 방식**을 확인한다
- **예상 시간**: 15분
- **검증 방법**: 고용주 3곳 이상. 각각 공고 유무가 **날짜와 함께** 기록됨

**실습 3: 통근 분류** ⭐
- **목적**: 지도 위 거리와 생활 가능성은 다르다.
- **단계**:
  1. 기관·근무지별 거리·소요 시간을 조사한다 (출퇴근 시간대 기준)
  2. **전업 기준**과 **파트타임 기준**으로 각각 분류한다 — 같은 곳이 두 기준에서 다르게 나올 수 있다
  3. 원거리(30~50마일)는 **주당 일수와 회당 근무 시간**을 함께 적어 통근 대비 근무 비율을 볼 수 있게 한다
- **예상 시간**: 10분
- **검증 방법**: 전 기관이 **두 기준 각각**에서 분류되고 근거가 적힘

#### 주요 개념

1. **판단 기준의 사전 고정** — 자료를 다 본 뒤에 기준을 만들면 이미 마음이 기운 쪽에 맞춰진다. **기준을 먼저 적고 가중치를 매긴 다음** 대조한다.
2. **탈락 사유 기록** — 제외한 경로의 이유를 적어 두면 상황이 바뀌었을 때(예: 파트타임 공고가 사라짐) 재검토가 빠르다.
3. **오해하기 쉬운 포인트** — 최적 경로가 **지금 열려 있지 않을 수 있다.** 그때는 "차선을 택한다"와 "열릴 때까지 기다린다"가 모두 선택지다. 미리 정해 둔다.

#### 실습 과제

**실습 1: 본인 조건 항목화** ⭐⭐
- **목적**: 판단 기준을 자료보다 먼저 고정한다.
- **단계**:
  1. 항목을 적는다 — 주당 가용 시간 / 통근 허용 범위 / 필요 수입 / 의료보험 필요 여부 / 신체 조건 / 시작 가능 시점
  2. 각 항목에 **가중치**를 매긴다
  3. **타협 불가 항목**을 표시한다
- **예상 시간**: 15분
- **검증 방법**: 항목별 값과 가중치가 채워지고, 타협 불가 항목이 표시됨

**실습 2: 대조와 순위 결정** ⭐⭐⭐
- **목적**: 근거 있는 선택을 만든다.
- **단계**:
  1. M1~M4 자료를 **3경로 × 2근무형태 = 6개 후보**로 펼친다
  2. 타협 불가 항목으로 **1차 탈락**시킨다
  3. 남은 후보를 가중치로 점수화한다
  4. **현재 지원 가능 여부**를 반영한다 (규칙 1)
- **예상 시간**: 20분
- **검증 방법**: 6개 후보 전부 점수 또는 탈락 사유가 적힘. 1순위와 차순위가 정해짐

**실습 3: 결정 문서 작성** ⭐⭐
- **목적**: 나중에 흔들릴 때 돌아볼 근거를 남긴다.
- **단계**: 선택한 경로 / 근거 3가지 / 제외 사유 / **재검토 조건**(무엇이 바뀌면 다시 볼 것인가)을 적는다
- **예상 시간**: 10분
- **검증 방법**: 재검토 조건이 구체적으로 적힘

#### 학습 목표

- [ ] 조사·실행 과정을 영상 서사로 재구성할 수 있다
- [ ] 슬라이드 플랜을 작성하고 승인받을 수 있다

#### 주요 개념

1. **서사 축** — 정보 나열이 아니라 **"몰랐던 것을 어떻게 알아냈고 무엇이 예상과 달랐는가"** 가 축이다.
2. **3단계 승인** — `remotion-video` 스킬의 규칙: **슬라이드 플랜 → 오디오 → 렌더링**. 각 단계 승인 후 진행.
3. **오해하기 쉬운 포인트** — 화면에 비치는 서류·계정·주소가 개인정보다. **캡처 단계에서 마스킹**한다.

#### 실습 과제

**실습 1: 슬라이드 플랜** ⭐⭐⭐
- **단계**: 서사 구조 → 슬라이드별 메시지·비주얼 → 나레이션 초안 → **사용자 승인**
- **예상 시간**: 2시간
- **검증 방법**: 플랜만 보고 영상 흐름이 그려짐. 승인 획득

**실습 2: 오디오 생성** ⭐⭐
- **단계**: `remotion-video` 스킬 절차에 따름 → **사용자 승인**
- **예상 시간**: 1시간

**실습 3: 렌더링·공개** ⭐⭐⭐
- **단계**: 컴포지션 작성 → 렌더 → 검수 → 업로드 자료(제목·Description·태그) 작성
- **예상 시간**: 4시간
- **검증 방법**: MP4 완성. 업로드 자료 문서 작성
